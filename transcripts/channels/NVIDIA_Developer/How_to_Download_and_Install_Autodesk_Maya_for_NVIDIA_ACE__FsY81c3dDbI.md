## 스크립트

이 비디오에서는 Maya Ace를 설치하기 위해 다운로드해야 할 파일들을 살펴보겠습니다. 하지만 그 전에 먼저 필요한 요구 사항을 충족하는지 확인해야 합니다. 우선 Maya 2023, 2024 또는 2025 버전이 설치되어 있어야 합니다. 여기서는 2024 버전을 권장한다고 되어 있지만, 저는 이 튜토리얼에서 2025 버전을 사용하고 있으므로 어느 버전이든 상관없습니다. Windows 10 64비트 또는 11이 필요합니다. 인터넷 연결도 필수입니다. 설치 파일을 다운로드할 뿐만 아니라, 마이크로서비스가 있는 NVCF 클라우드에 접속하기 위해서도 인터넷 연결이 필요합니다. 마이크로서비스에 접속하려면 API 키도 필요합니다. 다음 비디오에서 API 키 설정 방법을 자세히 설명하겠습니다. API 키는 매우 중요하므로 꼭 필요합니다. 마지막으로 몇 가지 파일을 준비하여 결과를 확인해 보겠습니다. 필요한 파일 형식은 WAV 16비트 또는 32비트 부동 소수점입니다. 샘플링 속도는 16kHz 또는 3248kHz여야 하고 모노로 설정해야 합니다. 이 설정만 완료되면 바로 시작할 수 있습니다. 이제 GitHub의 Nvidia Maya 사이트에 접속할 차례입니다. 사이트에 접속하면 모든 코드가 나와 있습니다. 모든 코드는 오픈 소스이므로 다운로드하여 사용할 수 있습니다. 코드 와 애플리케이션 또는 플러그인에 대한 문서도 모두 여기에 있으니 참고하시면 됩니다. 튜토리얼에서 다룰 내용 대부분은 문서에 자세히 설명되어 있으므로, 더 자세한 정보가 필요하면 문서를 참조하세요. 이 비디오에서는 최소한의 필수 파일만 다운로드하여 설정하는 방법을 보여드리겠습니다. 먼저 릴리스 폴더로 이동하여 필요한 파일을 다운로드합니다. 여기서 이 ZIP 파일을 다운로드해야 합니다. 이게 바로 플러그인인데, 빌드된 플러그인이라 빌드할 필요 없이 바로 다운로드해서 사용할 수 있는 버전입니다. 다운로드가 시작되면 다시 상단 메뉴로 돌아가 보겠습니다. ' 샘플 데이터'라는 폴더가 있고, 그 안에는 몇 가지 파일이 있습니다. 제대로 포맷된 오디오 파일 몇 개와 fpx 파일도 있습니다. 하지만 최소한 필요한 것은 Maya 프로젝트로 들어가서 Ace 애니메이션 플레이어 샘플을 확인하는 것입니다. 어, 이건 마야 파일인데, 마야 배너 파일인 것 같아요. 그래서 다운로드할게요. 원하시면 이 오디오 파일 중 하나를 다운로드해서 작업할 수도 있어요. 여기 있는 것 중에 가장 긴 게 6C예요. 이것도 다운로드할게요. 이 세 가지 파일이 프로젝트를 시작하는 데 최소한 필요한 파일들이에요. 자, 이제 파일을 다운로드했으면 마야에서 모듈 경로를 찾아야 해요. 마야 2023이 설치되어 있다면 내 문서 &gt; Maya 2023 모듈에 있을 거예요. 2024도 비슷한 경로이고, 2025는 프로그램 파일 &gt; Autodesk &gt; my25 모듈에 있을 거예요. 컴퓨터 설정에 따라 다른 위치에 있을 수도 있어요. 어쨌든 모듈 경로를 알았으니, 다운로드 폴더를 보면 웨이브 파일, pl H 파일, 그리고 샘플 파일이 있네요. 모듈 경로로 이동해서 복사, 즉 잘라내기를 통해 여기에 붙여넣겠습니다. 붙여넣기가 완료되면 여기서 압축을 풀고, 압축이 풀리면 미로 파일이 있는 것을 확인할 수 있습니다. 이제 마야를 시작할 준비가 되었으니, 나머지 두 파일은 제가 위치를 알고 있는 폴더에 넣어두겠습니다. ' 샘플 장면'이라는 폴더를 만들어서 여기에 넣고, 이제 마야를 시작할 준비가 되었습니다. 마야를 실행하면 ' Ace'라는 메뉴가 보일 겁니다. 여기서 마야 Ace 플러그인을 사용할 겁니다. 만약 Ace가 보이지 않는다면, Windows 설정에서 플러그인 관리자로 이동하여 Ace를 찾으세요. ' 모듈' 폴더의 '플러그인 모듈'에서 찾을 수 있을 겁니다. Ace가 로드되어 있고 자동 로드가 활성화되어 있는지 확인하세요. 만약 활성화되어 있지 않다면, 활성화되어 있는지 확인하면 됩니다. 마야 Ace 플러그인이 제대로 작동하려면 초당 30프레임이 필요합니다. 프레임 속도 설정에서 초당 30프레임으로 설정하겠습니다. 초당 30프레임, 초당 30프레임으로 재생됩니다. 그리고 또 하나 중요한 것은 캐시 재생 기능인데, 이것도 꺼야 합니다. 이제 Ace를 사용할 준비가 되었으니, 다운로드한 샘플 장면을 불러와서 살펴보겠습니다. 장면을 열면 샘플 Ace 애니메이션 파일이 있습니다. 파일을 열어보면 Mark와 CA가 보이는데, 만약 이 기능이 켜져 있으면 두 개의 지오메트리와 두 개의 U 그룹만 표시됩니다. 모든 것을 보려면 이 기능을 켜야 합니다. 그러면 Ace 애니메이션 플레이어가 보일 겁니다. 플레이어를 선택하면 애니메이션 플레이어가 나타납니다. 아직 마이크로서비스에 연결되지 않았기 때문에 바로 사용할 수는 없습니다. API 키를 설정해야 하는데, 이는 다음 영상에서 다루겠습니다. 하지만 적어도 제대로 설치되었다는 것을 알 수 있습니다. 플레이어가 보이네요. 마이크로서비스에 연결되면 그때부터 해당 기능을 사용해 볼 수 있을 겁니다.
