## 스크립트

새로운 핫 스토리지, 웜 스토리지, 콜드 스토리지 계층 출시로 검색 속도, 정확도, 비용의 균형을 맞추기 위해 리소스를 어떻게 관리해야 할지 궁금하실 수 있습니다. 저희가 방금 공개한 유용한 가이드를 먼저 살펴보겠습니다. 결정을 내리기 전에 핫 스토리지, 웜 스토리지, 콜드 스토리지 계층이 무엇인지 간단히 알아보겠습니다. 핫 스토리지는 메모리에 벡터 인덱스를 저장하므로 매우 빠르며 주로 HNSW 유형 벡터 인덱스를 사용합니다. 또한 사용자가 항상 사용할 수 있으므로 운영에 가장 많은 리소스가 필요합니다. 웜 스토리지는 디스크에 데이터를 저장하므로 핫 스토리지보다 속도는 느리지만 비용은 저렴합니다. 벡터 검색 객체 데이터용 플랫 인덱스와 역인덱스를 사용합니다. 사용자가 항상 사용할 수 있지만 핫 스토리지보다 메모리 사용량이 훨씬 적어 리소스 측면에서 훨씬 저렴합니다. 콜드 스토리지는 클라우드로 오프로드된 데이터로, 리소스를 즉시 사용할 수 없습니다. 따라서 데이터를 사용 가능하게 하려면 워밍업해야 하므로 세 가지 계층 중 속도가 가장 느리지만 비용은 매우 저렴합니다. 성능, 비용, 데이터 접근성의 균형을 맞추기 위해 여러 가지 결정을 내려야 합니다. 세 가지 주요 요소는 다음과 같습니다. 벡터 인덱스 유형은 압축 기술을 사용하고 테넌트 상태를 유연하게 관리할 수 있습니다. 먼저 벡터 인덱스에 대해 알아보겠습니다. 벡터 인덱스에는 세 가지 유형이 있습니다. 테넌트에 10만 개 이상의 객체가 있는 경우 성능 저하를 방지하기 위해 husw 또는 핫 스토리지 유형을 사용하는 것이 좋습니다. 테넌트에 10만 개 미만의 객체가 있고 앞으로도 그 수준을 유지할 가능성이 높다면 플랫 인덱스 또는 웜 스토리지 유형을 사용할 수 있습니다. 테넌트에 10만 개 미만의 객체가 유지될지 확신할 수 없다면 동적 인덱스를 사용할 수 있습니다. 동적 인덱스는 객체 수가 특정 임계값에 도달할 때까지는 플랫 인덱스로 사용되다가 그 이후에는 husw 인덱스로 전환됩니다. 압축에 대해서는 현재 세 가지 압축 기술(곱 양자화, 이진 양자화, 스칼라 양자화)을 제공합니다. 이러한 압축 기술은 리소스 비용을 절감하고 검색 속도를 향상시키는 데 도움이 되지만, 적절한 유형을 선택하고 정확도를 고려하는 것이 중요합니다. 데이터 컬렉션 규모가 작으면 플랫 인덱스를 사용하거나, husw 인덱스를 사용하지만 최종 데이터 세트를 대표하는 샘플이 없는 경우에는 이진 양자화를 사용하는 것을 고려해 보세요. 양자화 방식 중 BQ 인덱스는 비압축 벡터 보다 크기가 32배 작고 속도가 훨씬 빠릅니다. 매우 큰 데이터 세트에서 특수한 요구 사항이 있는 경우 PQ( Product Quantumization)를 고려해 보세요. PQ 압축은 설정 옵션이 다양하지만 SQ(Square Quantum)나 BQ보다 최적화에 더 많은 전문 지식이 필요합니다. 파라미터 최적화에 크게 신경 쓰지 않거나 시작 단계에서 고민하는 경우 스케일러 양자화가 좋은 선택입니다. 중대형 데이터 세트를 사용하는 대부분의 사용자는 SQ 압축을 고려해야 합니다. SQ로 압축된 벡터는 비압축 벡터 크기의 1/4에 불과하며, SQ를 사용한 검색은 비압축 벡터를 사용한 검색보다 훨씬 빠르면서도 정밀도와 재현율은 유사하게 유지합니다. 마지막으로, Vate는 활성, 비활성, 오프로드의 세 가지 테넌트 상태를 지원합니다. 테넌트가 항상 사용 가능해야 하는 경우 활성 상태로 설정하고, 지금 당장 사용 가능하지는 않지만 매우 빠르게 사용 가능해야 하는 경우 비활성 상태로 설정할 수 있습니다. 비활성 상태는 테넌트를 로컬에 저장하지만 즉시 사용할 수 없도록 하는 것을 의미합니다. 또는 테넌트를 콜드 스토리지로 오프로드할 수 있습니다. 콜드 스토리지는 테넌트를 사용할 수 없도록 하고, 다시 사용 가능하게 되기까지 약간의 시간이 걸리는 것을 의미합니다. 자주 액세스하지 않는 테넌트는 비활성화하고, 거의 액세스하지 않는 테넌트는 오프로드하는 것이 좋은 전략일 수 있습니다. 다양한 스토리지 유형 과 리소스 관리의 유연성을 통해 다양한 사용 사례를 구축할 수 있도록 지원하며, Weeva Instant를 최대한 활용할 수 있도록 도와드리고자 합니다. 이 유용한 가이드는 위 설명란에 링크되어 있으며, 궁금한 점이 있으면 언제든지 커뮤니티 Slack에서 문의해 주세요.
