## 스크립트

GitHub의 하이브리드 검색 증강 생성 프로젝트를 위한 Nvidia AI Workbench 데모에 오신 것을 환영합니다. 이 프로젝트를 사용하면 로컬 머신의 GPU부터 클라우드 엔드포인트 또는 자체 호스팅 마이크로서비스에 이르기까지 다양한 소스를 사용하여 추론할 수 있는 RAG 애플리케이션을 실행할 수 있습니다. 이 데모는 Nvidia RTX 6000 ADA GPU가 장착된 워크스테이션에서 실행되며, 로컬 모드와 자체 호스팅 마이크로서비스 모드, 두 가지 모드에서 추론하는 방법을 보여줍니다. 이 데모를 위해 AI Workbench가 시스템에 설치되어 있고 GitHub 계정이 있다고 가정합니다. 먼저 GitHub에서 하이브리드 RAG 프로젝트를 찾습니다. 이 프로젝트는 프로젝트를 빌드하고 사용하는 데 필요한 코드와 환경 구성이 포함된 Git 저장소입니다. AI Workbench에서 이 저장소를 클론합니다. AI Workbench는 저장소를 로컬 머신으로 가져와 개발 환경을 위한 Jupyter Lab 과 RAG 애플리케이션 사용을 위한 Gradio 앱을 포함하는 컨테이너화된 환경을 구축합니다. 컨테이너 구축이 완료되면 " 채팅 열기" 버튼이 녹색으로 바뀌고, 이 버튼을 클릭하여 Gradio 앱을 시작할 수 있습니다. 채팅 앱은 RAG에 대한 세 가지 추론 모드를 제공합니다. 로컬 클라우드 및 자체 호스팅 마이크로서비스 데모에 사용된 워크스테이션에는 NVIDIA GPU가 탑재되어 있으므로 로컬 추론 옵션부터 시작합니다. 랙 서버를 시작하고 4비트 정밀도의 Lama 38b를 선택합니다. 모델 다운로드가 완료되면 워크스테이션의 GPU에서 직접 실행되는 추론 서버를 시작할 수 있습니다. 이 비디오는 데모를 위해 상당히 빠르게 재생됩니다. 초기 설정은 약 3분 정도 소요됩니다. 서버가 준비되면 서비스에 연결할 수 있다는 메시지가 표시됩니다. 모델이 제대로 작동하는지 확인하기 위해 인사를 건네고 NVIDIA Blackwell Super 칩 출시 관련 질문을 합니다. NVIDIA Blackwell에 대한 세부 정보가 모델 학습 데이터에 포함되어 있지 않기 때문에 약간의 오류가 발생합니다. 이는 결함이 아니라 모델 학습 데이터에 포함되지 않은 주제에 대한 사실 확인 쿼리에서 예상되는 현상입니다. RAG는 모델에 적절한 컨텍스트를 제공하여 이러한 유형의 쿼리에 더 잘 답변할 수 있도록 하는 방법입니다. 개선 사항을 보여주기 위해 NVIDIA Blackwell 아키텍처에 대한 PDF 파일을 추가합니다. RAG 애플리케이션은 텍스트를 추출하여 벡터 데이터베이스에 삽입합니다. 데이터가 내장되어 저장되고 쿼리 준비가 된 상태인 벡터 데이터베이스를 활성화하면, Blackw와 Hopper 아키텍처를 비교하는 질문에 대해 정확 하지 않은 답변이 나옵니다. 하지만 벡터 데이터베이스를 활성화하면 정확한 응답을 얻을 수 있습니다. 또한, 컨텍스트 표시 기능을 사용하면 LLM이 응답을 생성하는 데 사용하는 텍스트를 직접 확인할 수 있어 원격 추론을 수행하기 위한 명확한 검색 컨텍스트를 제공합니다. 먼저 채팅 앱에서 자체 호스팅 마이크로서비스로 전환합니다. Nim에 액세스하기 위한 NGC 계정이 있는지 확인하고 인증에 필요한 API 키를 생성합니다. NGC 카탈로그에서 최신 이미지를 사용하여 최신 업데이트 및 개선 사항을 활용합니다. 그런 다음 Docker에 로그인하고 채팅 앱에서 Nim 컨테이너를 실행합니다. IP 주소 및 모델 자체와 같은 컨테이너화된 모델에 필요한 세부 정보를 입력합니다. 로컬 추론과 동일한 단계를 따릅니다. 벡터 데이터베이스는 추론 모드에 관계없이 모든 모드에 대한 응답을 제공합니다. 벡터 데이터베이스를 활성화하면 더 정확한 응답을 얻을 수 있습니다. 워크스테이션에서 Nvidia AI Workbench를 사용하여 하이브리드 RAG를 설정하는 데모를 시청해 주셔서 감사합니다.
