## 스크립트

[음악] NVIDIA Grace CPU는 NVIDIA 최초로 데이터 센터 규모 컴퓨팅을 위해 설계된 CPU로, 높은 단일 및 멀티 스레드 성능, 높은 메모리 대역폭, 그리고 뛰어난 와트당 성능을 제공합니다. 이 비디오에서는 Grace CPU와 Grace Hopper 슈퍼칩의 성능 튜닝을 통해 애플리케이션이 NVIDIA 데이터 센터 컴퓨팅 플랫폼을 최대한 활용하는 방법을 살펴보겠습니다. Grace CPU에 탑재된 ARM 성능 모니터링 장치(PMU)의 이벤트 카운터를 통해 성능 분석 도구는 하드웨어 성능을 캡처하고 특성화할 수 있습니다. 또한 Grace CPU는 ARM 통계 프로파일링 확장(SP)을 구현하여 오버 헤드가 낮은 고해상도 성능 측정을 위한 하드웨어 기반 통계 샘플링을 제공합니다. Insight 시스템은 Grace CPU 이벤트뿐만 아니라 GPU, DPU, 메모리 및 네트워크 이벤트, 그리고 동시 API 활동을 샘플링하여 데이터 센터 전체의 워크로드를 시스템 차원에서 시각화할 수 있습니다. 이제 CPU 프로파일링 시 표시되는 데이터를 살펴보겠습니다. Grace CPU 코어 이벤트율은 CPU 사이클, 완료된 명령어 수, 캐시 참조 수와 같은 코어 자체의 성능을 나타냅니다. 이러한 지표를 통해 개별 Grace CPU 코어에서 명령어가 어떻게 실행되는지 잘 파악할 수 있습니다. 또한 Grace CPU 언코어 이벤트율은 코어 외부의 CPU 활동에 대한 정보를 제공합니다. 코어는 메모리 액세스, PCIe 이벤트 및 NVIDIA Envy Link CTC 활동과 같은 정보를 수집합니다. Envy Link CTC 데이터는 Grace가 탑재된 슈퍼칩( Grace Hopper 슈퍼칩 및 Grace CPU 슈퍼칩)에 중요합니다. 이 두 슈퍼칩은 고속 Envy Link CTC를 사용하여 Grace CPU를 NVIDIA Hopper GPU 또는 다른 Gray CPU에 각각 연결합니다. 이를 통해 언코어 및 코어 이벤트를 파악하여 알고리즘을 더 잘 분석하고 Gray CPU 플랫폼에서 실행되는 애플리케이션에 가장 적합한 최적화 전략을 찾을 수 있습니다. 성능 튜닝의 또 다른 중요한 부분은 NVIDIA Power Data Center에서 CUDA 커널을 분석하는 것입니다. Insight Compute는 NVIDIA의 커널 성능 검사 도구입니다. Insight Compute의 새로운 성능 모니터 샘플링(PM 샘플링)은 시간 상관 관계가 있는 커널 성능 데이터를 제공합니다. 즉, 표준 집계 메트릭 외에도 타임라인에서 CUDA 커널 내에서 발생하는 성능 문제를 검사할 수 있습니다. PM 샘플링은 집계 메트릭만으로는 발견되지 않을 수 있는 시간적 성능 문제를 밝혀낼 수 있습니다. PM 샘플링을 활성화하면 애플리케이션의 최적화 요구 사항에 대한 명확성과 통찰력을 얻을 수 있으며, 최적화 요구 사항을 파악한 후에는 그 성공 여부를 직접 비교할 수 있습니다. 새로운 소스 코드 비교 기능을 통해 성능 튜닝 작업을 최적화하세요. 이 기능은 소스 수준 수정 사항이 CUDA 커널 성능에 미치는 영향을 자동으로 비교하고 변경 사항과 관련 성능 지표를 연관시켜 검사할 수 있도록 지원합니다. GPU에서 실행되는 CUDA 코드를 최적화하고 그레이 CPU에서 성능 튜닝 작업을 수행하면 데이터 센터 의 모든 NVIDIA 실리콘을 애플리케이션이 최대한 활용할 수 있습니다. NVIDIA 그레이 CPU에 대한 자세한 자료와 Insight 시스템 및 Insight 컴퓨팅 시작 방법은 아래 설명란의 링크를 참조하세요. 시청해 주셔서 감사합니다.
