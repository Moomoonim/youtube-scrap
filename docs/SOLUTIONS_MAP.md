# AX 솔루션 지도 — 회사·솔루션·기능·역할 (2026-08-01 갱신)

> 코퍼스(**7,967건**, 공식 채널 90개 + 키워드 171건) 정독·통계에서 추출한 **행위자·제품·기능·역할** 정리.
> ⚠️ **읽는 법**: 이 표는 제품 감사(audit)가 아니라 **담론에서 각 회사가 스스로 무엇이라 주장하는가**의 지도다. "역할" 열은 그 회사가 **AX 생태계 안에서 구체적으로 무슨 일을 하는지**를 한두 문장으로 풀어 쓴 것 — 카테고리 이름이 아니라 실제 기능 설명이다. 수치·주장은 자사 발화 기준이며 워싱 위험을 함께 표기했다.
> 기능 통계(전체 대비 출현율)는 `CAPABILITY_STATS.md` 참조: 거버넌스·평가(45%) > 분석·최적화(42%) > 인프라(41%) > 에이전트(27%) 순.

## 10. ⭐ 계층을 관통하는 5개 본질

1. **"측정 단위를 쥔 자가 ROI를 쥔다"** — 토큰→에이전트, usage→outcome, "15% 임계"(Kore.ai)까지, 성과를 무엇으로 셀지 정하는 자가 서사를 쥔다.
2. **"진짜 락인은 모델이 아니라 데이터/거버넌스 계층"** — Palantir·ServiceNow·Oracle·벡터DB가 경쟁하는 곳이 진짜 전장(위 §3, ax_core의 77%).
3. **"에이전트=인력"의 문자화** — Alibaba·OpenAI·삼성SDS 모두 에이전트를 사람 세듯 센다.
4. **"데이터≠결정"** — Oracle·Huawei가 공통 지적: 데이터를 쌓는 것과 결정을 내리는 것은 다른 문제.
5. **"AI를 말하는/안 말하는 방식 자체가 전략"** — 자동차 4분화(침묵~정체성화), state 블록화(중국 탈주권~서방 동맹주권)가 이를 보여준다.

## 11. ⚠️ 데이터 신뢰 경계
- 위 "역할" 서술은 **자사 발화 기준**이며 실제 제품 성능 검증이 아니다.
- 자막 오역으로 회사명·수치가 훼손된 경우 다수(예: `agent`→"부동산 중개인", 도메인 명사→"음악"). 인용 전 원본 확인 필수.
- 채널명≠담론성격 사례 다수(Cohere=학술, Huawei=주권 지움, Chegg=edtech인데 순수 학습영상). 채널명으로 역할을 예단 금지.
- 미국 51개 채널(59%)은 큐레이션 결과이지 자연 표본이 아님 — "미국이 AX를 더 많이 한다"가 아니라 "제가 미국 벤더를 더 많이 등록했다"는 뜻.
