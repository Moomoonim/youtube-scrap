## 스크립트

Today we're launching plugin sharing in Codex. We're making it easy to share plugins with the people you work with. One example is the first week quest plugin. From the plugin directory, I can actually find this plugin that I built. I can go into it. I can see the default prompts available. And now I want to send it to one of my teammates. I'm going to click the share button. We have this modal here where I can specify who I want to share this to. Or I can also change this to anyone in the workspace. What this means is after I click save, now I've shared this plugin for anybody in the workspace. I can copy this link and share it out with my team. They're able to see this plugin in their own directory. Plugin sharing also works the other way: in the shared with you tab. If I go back to the plugins directory, I can see all the plugins that have been shared with me by my teammates. I can see an example here called finalize code plugin, which is very helpful before I finish my PRs. I can run this for validation and code refactoring, and also make sure my PR is in a great state before review. We're also adding share URLs for the curated directory. I can send them the exact plugin page instead of making them search. Let's take Slack as an example. I'm going to copy the link. I'm going to open this up in Chrome. I can paste this URL and share it, and it deep links directly into Codex. That's the simple idea: the workflows you build for your team don't have to stay on your machine. If a plugin helps one teammate, share it. If someone shares one with you, it shows up right where you need it.
