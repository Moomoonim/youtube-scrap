## 스크립트

좋아요, 그럼 처음부터 시작해 볼까요? GitHub Copilot이란 무엇인가요? GitHub Copilot은 코드를 더 빠르게 작성할 수 있도록 도와주는 AI 기반 페어 프로그래머입니다. 이 도구는 프로그래밍 작업을 지원하도록 설계되었으며, 편집기 및 github.com에서 작업하는 동안 사용자의 보조 역할을 합니다. 그 부분을 잊지 마세요. 하지만 단순한 코드 자동 완성 기능 그 이상입니다. 자연어로 코드를 작성하고, 셸 명령어를 이해하고, 잊어버린 내용을 기억하고, 풀 리퀘스트의 변경 사항을 설명하고, 디버깅까지 도와주는 등 다양한 기능을 제공하는 완벽한 코딩 도우미입니다. 이 기능은 Visual Studio Code, Visual Studio, Jet Brains, Neoim, Xcode, GitHub 모바일 앱, 터미널 및 github.com에서 사용할 수 있습니다. 원하는 편집기에서 다양한 프로그래밍 언어와 함께 사용할 수 있습니다 . 그렇다면 GitHub Copilot에 어떻게 접근할 수 있을까요 ? GitHub Copilot을 사용하려면 GitHub 계정과 GitHub Copilot 라이선스가 있어야 합니다. 이용 가능한 라이선스 옵션은 네 가지입니다. GitHub Copilot은 무료로 가입할 수 있으며, 개인 사용자는 Copilot Pro를 이용할 수 있습니다. 또는 Copilot 비즈니스 또는 엔터프라이즈 라이선스를 통해 직장에서 이용할 수도 있습니다. 학생이나 교육자라면 GitHub Education을 통해 Copilot Pro를 무료로 이용할 수 있습니다. 인기 있는 오픈 소스 프로젝트 관리자라면 무료로 이용할 수 있습니다. 각 등급 또는 라이선스별로 사용 ​​가능한 모든 기능 목록을 보려면 화면에 나타나는 링크를 클릭하십시오 . GitHub Copilot을 사용해 본 적이 없다면 , 무료로 가입해서 사용해 보시길 권합니다. 정말 좋아요. GitHub Copilot에 가입하시면 바로 설치하여 에디터에서 사용하실 수 있습니다. GitHub Copilot 설치 방법은 사용 환경에 따라 다릅니다 . VS Code를 사용 중이라면 확장 프로그램 마켓플레이스로 이동하여 GitHub Copilot을 검색하세요. 팝업되는 확장 프로그램을 클릭하고 설치를 클릭하세요. 이렇게 하면 두 개의 확장 프로그램이 설치됩니다. GitHub Copilot은 코드 작성 시 바로가기 제안을 제공하며 , GitHub Copilot Chat은 코딩 관련 특정 작업을 지원하는 대화형 AI 비서입니다. 설치가 완료되면 GitHub Copilot에 접근 권한이 있는 GitHub 계정으로 VS Code에 로그인해야 합니다 . 이전에 GitHub 계정에 VS Code를 승인하지 않은 경우 VS Code에서 GitHub에 로그인하라는 메시지가 표시됩니다. 또는 활동 표시줄의 계정 메뉴를 선택한 다음 GitHub로 로그인하여 GitHub Copilot을 사용할 수도 있습니다. 그렇게 하면 GitHub Copilot에 필요한 권한을 GitHub에 부여할 수 있는 브라우저로 이동합니다. 계속을 클릭하여 Visual Studio Code의 승인을 받으면 모든 설정이 완료됩니다. 편집기로 돌아가면 상단 명령 센터 옆에 Copilot 아이콘이 표시됩니다. 편집기 하단에 Copilot 아이콘이 있는데, 이 아이콘을 클릭하면 사용할 계정을 선택하라는 메시지가 나타날 수 있습니다. 그럼 이제 상태가 '준비됨'으로 표시되어야 하는 메뉴 옵션을 보여드리겠습니다 . VS Code에서 이러한 아이콘이 보이면 GitHub Copilot 설치가 성공적으로 완료된 것이며, 이제 사용할 준비가 되었습니다 . 자, Jetrains IDE를 사용하고 계신다면 GitHub Copilot을 설치하는 방법을 보여드리겠습니다. 오늘은 PyCharm을 사용하겠지만, 이 지침은 모든 Jetrains 편집기에서 동일하게 적용됩니다. 원하는 에디터를 열고 플러그인 마켓플레이스로 이동하세요 . GitHub Copilot을 검색하여 설치하고 IDE를 다시 시작하세요 . 프로젝트를 열면 편집기 오른쪽 편에 Copilot 아이콘이 있는 것을 확인할 수 있습니다. 왼쪽에는 GitHub Copilot 아이콘과 물음표 아이콘, 그리고 채팅 아이콘 두 개가 있는 것을 확인할 수 있습니다. 물음표 아이콘이 있는 첫 번째 Copilot을 선택하면 GitHub Copilot이 무엇인지에 대한 간략한 개요와 환영 메시지를 볼 수 있습니다. 채팅 아이콘이 있는 코파일럿을 클릭하면 코파일럿 채팅창이 열리고 프로그래밍 관련 질문에 대한 도움을 받을 수 있습니다 . Jetrains IDE에서 이러한 아이콘이 보이면 GitHub Copilot 설치가 성공적으로 완료된 것입니다. GitHub 계정에서 Jet Brains를 이전에 승인하지 않은 경우 편집기에서 GitHub에 로그인하라는 메시지가 표시됩니다 . 또는 하단의 Copilot 아이콘을 클릭하고 GitHub에 로그인하기를 선택할 수도 있습니다. '복사'를 클릭한 다음 ' 브라우저에서 열기'를 클릭하여 필요한 권한을 승인하세요. CommandV 또는 ControlV를 눌러 코드를 붙여넣으세요. 계속을 클릭한 다음 마지막으로 GitHub Copilot 플러그인 승인을 선택하세요. 편집기로 돌아가면 GitHub Copilot이 성공적으로 설치되었다는 메시지가 표시됩니다. 이제 GitHub Copilot 채팅을 승인할 수 있습니다. 채팅 아이콘을 클릭한 다음 승인 버튼을 클릭하세요 . 복사를 선택하고 브라우저에서 코드를 열어 붙여넣으세요. JetBrains IDE용 GitHub Copilot 승인을 클릭하세요 . 편집기로 돌아가면 GitHub Copilot 채팅에서 보낸 인사말이 표시될 것입니다. 이 과정을 완료하면 이제 Jet Brains에서 GitHub Copilot을 사용할 준비가 되었습니다 . 자, 이제 에디터에 Copilot을 설치했으니 사용 방법을 살펴보겠습니다. 오늘 예시에서는 VS Code에서 Python을 사용하겠습니다. validate_email.py라는 새 파일을 만드세요. 입력을 시작하면 GitHub Copilot이 사용자가 하려는 작업을 예측하여 제안을 생성합니다. 예를 들어, ` re` 모듈을 임포트하고 엔터 키를 누르면 Copilot이 제가 하려는 작업을 예측하여 제안 코드를 제시해 줍니다 . 파일 이름이 validate email이므로 이메일 유효성 검사를 위한 코드를 제공합니다. 키보드의 탭 키를 눌러 제안을 수락할 수 있습니다. 엔터 키를 누르면 메인 함수가 제공되어 코드가 계속 실행됩니다. 제안된 코드 위에 마우스 커서를 올리면 사용 가능한 여러 옵션을 볼 수 있습니다. 또한 완료 패널을 열어 생성된 더 많은 제안을 확인하고 거기에서 제안을 수락할 수도 있습니다 . 이는 인라인 코드 완성 기능을 보여주는 예시이며, 회색 텍스트는 코파일럿의 제안이 포함된 가상 텍스트를 나타냅니다 . 만약 여러분의 컴퓨터에서 시도해 보시고 다른 결과가 나오더라도 괜찮습니다. GitHub Copilot이나 다른 LLM을 사용할 때 명심해야 할 한 가지는 응답이 비결정적이라는 점입니다. 즉, GitHub Copilot을 사용할 때마다 다른 결과가 나올 가능성이 높다는 뜻입니다 . 그리고 제가 얻는 결과는 당신이 얻는 결과와 다를 수 있습니다. GitHub Copilot 채팅을 사용하면 이 기능을 한 단계 더 발전시킬 수 있습니다 . 이 코드가 무엇을 의미하는지 이해하고 싶다고 가정해 봅시다. 저는 이 작품을 처음 보는데, 최대한 빨리 내용을 파악하고 싶어요. Copilot Chat을 열고 ` slashexplain`을 입력하면 코드 에서 무슨 일이 일어나고 있는지에 대한 자세한 설명을 볼 수 있습니다 . Copilot 채팅에서 현재 열려 있는 파일 목록을 볼 수 있다는 것을 여기 아이콘으로 확인하실 수 있습니다. 엔터 키를 누르면 코드에 대한 보기 좋게 정리된 설명이 나타납니다. 자 , 이제 제가 반응을 개선해서 사용자들이 여러 개의 이메일 주소를 입력할 수 있도록 하고 싶다고 가정해 보겠습니다. 코파일럿 채팅에서 바로 그 질문을 할 수 있습니다. 사용자가 유효성 검사를 위해 여러 이메일 주소를 입력할 수 있도록 하고, 반응을 더욱 견고하게 개선하는 것이 좋겠습니다. 그러면 계획서, 업데이트된 코드 블록, 그리고 변경 사항 목록을 받게 됩니다. 편집기에서 적용 버튼을 클릭하여 변경 사항을 적용하면 GitHub Copilot이 자동으로 업데이트를 진행합니다 . 자, 여기서 마무리하기 전에, 모두가 알고 있지만 언급하기 꺼려하는 문제에 대해 이야기해 보겠습니다 . 세상에는 훌륭한 부조종사가 정말 많습니다 . 그렇다면 GitHub Copilot은 무엇이 다르고, 다른 코파일럿 서비스와는 어떤 차이점이 있을까요? GitHub Copilot은 프로그래밍을 위해 특별히 설계된 도구입니다. 또한 에디터와 github.com에서 바로 작동하고 존재하기 때문에 브라우저나 다른 애플리케이션과 코드 사이를 왔다 갔다 할 필요가 없습니다. 진정으로 집중력을 유지하고 더 이상 작업 전환을 하지 않아도 됩니다. 그러므로 ' 깃허브 코파일럿'이라는 말을 들으면, 그것은 여러분의 개인 AI 프로그래머를 가리키는 것임을 알아두세요. 오늘 꽤 많은 내용을 다뤘 지만, 이제 여러분은 GitHub Copilot이 무엇인지, 어떻게 접근하고, 설치하고, 인증하고, 사용을 시작하는 방법을 알게 되었습니다. GitHub Copilot과 다른 Copilot 도구들의 차이점도 알고 계시겠죠. 저는 여러분에게 대규모 언어 모델(LLM)에 대해 알아야 할 모든 것과 신속한 엔지니어링을 통해 LLM과 상호 작용하는 방법을 알려드리겠습니다. 프롬프트는 LLM 과정 학생들이 업무 생산성을 높이는 데 도움이 되는 핵심 요소입니다. 프롬프트의 효과와 한계를 이해하면 훨씬 더 빠르게 많은 작업을 처리할 수 있습니다 . 신속한 엔지니어링에 들어가기 전에 LLM이 내부적으로 어떻게 작동하는지 좀 더 자세히 이해해야 합니다 . 대규모 언어 모델은 이름에서 알 수 있듯이 방대한 양의 텍스트 데이터를 학습하여 인간과 유사한 언어를 이해하고 생성하는 인공지능의 한 유형입니다 . 이러한 도구들은 앞 단어들의 문맥을 바탕으로 문장에서 다음에 나올 단어를 예측하는 방식으로 작동하며, 따라서 사용자가 이해하기 쉽고 일관성 있는 답변을 제공합니다 . 매우 똑똑한 자동 완성 기능이라고 생각하시면 됩니다. LLM 과정을 이해하려면 꼭 알아야 할 세 가지가 있습니다 . 맥락, 토큰 및 제한 사항. 맥락이란 LLM(법학 석사) 과정 학생이 당신의 말을 이해하는 데 도움이 되는 주변 정보라고 생각하면 됩니다. 친구와의 대화와 마찬가지로, 맥락이 많을수록 대화가 더 잘 이해될 것입니다. LLM(언어 관리 모델)의 세계에서 텍스트는 토큰 단위로 분해됩니다. 토큰은 단어, 단어의 일부 또는 심지어 단일 문자일 수도 있습니다. AI 모델은 토큰을 처리하여 응답을 생성합니다. LLM에서 사용하는 토큰 수는 응답 속도에 영향을 미칠 수 있습니다 . 토큰 수가 너무 적으면 맥락이 부족할 수 있고 , 너무 많으면 과부하가 걸릴 수 있습니다. LLM은 강력하지만, 모든 것을 다 갖춘 것은 아닙니다. 그들은 인간처럼 언어를 진정으로 이해하지 못합니다. 그들은 학습에 사용된 데이터에 포함된 패턴과 확률에 의존합니다 . 이번 에피소드에서는 훈련 측면은 다루지 않겠지만 , 최상의 대응을 위해서는 다양하고 폭넓은 훈련이 왜 필요한지 빠르게 이해할 수 있을 것입니다 . 모델은 결코 완벽하지 않기 때문에 때때로 잘못되거나 터무니없는 답변, 즉 환각을 제공하기도 합니다.
