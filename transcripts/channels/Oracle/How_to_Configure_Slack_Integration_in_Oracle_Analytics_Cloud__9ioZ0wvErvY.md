## 스크립트

이 튜토리얼에서는 Oracle Analytics Cloud 및 Fusion Data Intelligence에서 Slack 통합을 구성하는 방법을 알아보겠습니다. 관리자로서 저는 Oracle Analytics Cloud를 Slack에 연결하여 워크북 작성자가 캔버스와 시각화를 조직 Slack에 직접 공유할 수 있도록 할 수 있습니다. 이를 통해 수동으로 콘텐츠를 내보내지 않고도 팀 ​​슬랙 채널에 쉽게 콘텐츠를 배포하고 협업을 간소화할 수 있습니다. 먼저 슬랙의 조직 워크스페이스에 새 앱을 만들겠습니다 . api.slack.com/apps로 이동하겠습니다. 저는 이미 로그인되어 있어서 바로 접속할 수 있습니다 . ' 내 앱' 페이지에 기존 앱이 없으므로 '앱 만들기'를 선택합니다. 저는 처음부터 직접 만드는 옵션을 선택하겠습니다. Slack 앱 이름을 OAC 통합으로 지정 하고 개발할 워크스페이스를 선택하겠습니다 . 제 워크스페이스 이름은 Acme Co입니다. 이제 앱 만들기를 선택하겠습니다. 새 앱 설정의 기본 정보 페이지에서 클라이언트 ID와 클라이언트 시크릿을 확인할 수 있습니다. 오라클 애널리틱스 클라우드 측에서 연결을 구성하려면 이러한 자격 증명이 필요합니다 . 이제 Oracle Analytics Cloud에 로그인하여 통합을 시작하겠습니다. 콘솔로 이동해서 구성 및 설정 섹션으로 스크롤한 다음 콘텐츠 공유 플랫폼을 선택하겠습니다. 콘텐츠 공유 플랫폼 페이지에서 서비스 드롭다운 메뉴에 사용 가능한 소셜 플랫폼이 표시됩니다. Slack을 선택하고 상태를 활성으로 설정한 다음 새로 생성한 Slack 앱의 이름을 OAC 통합으로 입력하겠습니다. 다음으로 Slack의 기본 정보 페이지에서 클라이언트 ID와 클라이언트 시크릿을 복사하여 Oracle Analytics Cloud의 콘텐츠 공유 플랫폼 페이지에 있는 해당 필드에 붙여넣겠습니다. Slack에 추가해야 하므로 리디렉션 URL을 클립보드에 복사하겠습니다. 그다음, 업데이트를 선택하고 확인을 눌러 이 구성을 저장하겠습니다. Slack 설정으로 돌아가서 리디렉션 URL을 추가하겠습니다. 왼쪽 탐색 메뉴에서 OAuth 및 권한 페이지를 선택하겠습니다. 리디렉션 URL 섹션으로 스크롤하여 새 리디렉션 URL 추가를 선택하겠습니다. 오라클 애널리틱스 클라우드에서 복사한 리디렉션 URL을 붙여넣고 추가를 선택한 다음 URL을 저장하겠습니다. Slack과 Oracle Analytics Cloud 모두에서 설정을 완료했으니 이제 워크북 작성자가 Slack에 콘텐츠를 공유할 수 있는지 확인하기 위해 테스트하겠습니다. 오라클 애널리틱스 클라우드로 돌아가서 편집 모드로 통합 문서를 열겠습니다. 여기서 내보내기를 선택하고 Slack을 선택하겠습니다. 자 , 이제 슬랙 게시물을 작성하겠습니다. 저는 'all Acme Co'라는 슬랙 채널을 선택해서 제 채널 목록에 추가하겠습니다 . 내 콘텐츠는 PowerPoint, PDF, 이미지의 세 가지 형식으로 제공됩니다. PDF를 선택하겠습니다. 또한 현재 캔버스, 선택한 시각화 또는 통합 문서의 모든 캔버스를 공유할지 여부를 선택합니다 . 현재 작업 중인 캔버스를 공유하기 위해 '활성 캔버스'를 선택하겠습니다 . PDF를 선택했으므로 접근을 제한하기 위해 비밀번호를 추가하는 옵션이 있습니다. 맥락을 제공하기 위해 기존 필터와 통합 문서 제목도 함께 첨부하겠습니다. 크기와 방향은 그대로 두겠습니다 . 마지막으로, '게시'를 선택하겠습니다. 팝업이 활성화된 경우 Oracle Analytics Cloud는 새 브라우저 창을 열어 Slack 채널에 직접 게시된 PDF를 볼 수 있도록 합니다. 저도 슬랙을 열어서 제가 지정한 채널에 캔버스 PDF 파일이 공유되었는지 확인할 수 있습니다. 이제 Oracle Analytics Cloud에 Slack 연동을 설정했으므로, 작성자는 콘텐츠를 팀의 Slack 채널에 직접 공유할 수 있어 협업이 더욱 빠르고 간편해졌습니다. 아래 링크에서 이 시리즈의 다른 비디오와 Oracle Analytics Cloud 및 Fusion Data Intelligence 사용에 대한 추가 자료를 찾아보세요.
