## 0. 요약 — 이 코퍼스가 논문에 대해 할 수 있는 말

| 논문의 주장/공백 | 코퍼스의 응답 | 강도 |
|---|---|---|
| AX는 DX의 "추가적 확장이자 심화"(§II-A) | 한국 AX 담론이 **정확히 같은 명제를 반복**. 단 "연장선"파와 "단순 확장이 아니다"파가 병존 | 강함(A축) |
| AX와 DX를 측정에서 분리하지 못함(핵심 공백) | 담론은 **분모(측정단위) 자체를 두고 싸운다** — 키워드 빈도로는 잡히지 않는 축 | 강함(B축) |
| AI 전환이 공급망 집중도를 낮춘다(1% 유의) | **양방향 사례가 모두 존재**. 탈집중 사례와 집중 강화 사례가 나란히 관측됨 | 강함·반증 포함(C축) |
| 관계 거버넌스가 알고리즘 매개 조정으로 치환 | A2A·에이전틱 커머스·조달 에이전트에서 **부분적 치환** 관측. 단 최종 의사결정권은 사람이 보유 | 중간(D축) |
| 제도 맥락 의존성 | 주권 AI·오픈웨이트 종속 전략·공공 조달 규제에서 **제도 변수 강하게 작동** | 강함(D축) |
| 간접효과의 실질적 무의미성(−0.0005) | 담론에 **"15% 미만이면 P&L에 안 잡힌다"는 실질 유의성 문턱**이 존재 | 강함(E축) |
| 양방향 내생성(Scii ⇄ CRTC) | 담론에서 **거의 발화되지 않음**. 검색 후보 32건 중 인용 가능한 사례 소수 | **약함 — 공백**(F축) |
| 거버넌스는 수사, 검증은 재무 지표로만 | 코퍼스에서 **동일 패턴 재현**. 거버넌스 논의가 ROI·KPI 문장으로 착지 | 강함(G축) |
| 조직 조건부성(비국유 > 국유, 성숙·성장 > 쇠퇴) | 부채·레거시·규제 부담이 전환 속도를 가른다는 진술 다수 | 중간(H축) |
| CRTC = ROA 변동성(개념 혼동) | 담론의 "위험감수"는 **실험 허용·실패 예산**으로 나타남 — 재무 변동성과 다른 구성개념 | 중간(I축) |

**가장 활용 가치 있는 결론 두 가지**

1. 논문이 "AX ≠ DX"를 개념으로만 분리하고 측정에서 붕괴시킨 그 자리에, 담론은 **분모 논쟁**(무엇을 셀 것인가)이라는 관측 가능한 대상을 제공한다. AX 구성요소를 "DX 지표로 포착되지 않는 것"으로 정의하려는 작업에 직접 재료가 된다.
2. 논문의 "AI → 공급망 탈집중" 부호는 **일반 명제가 아니다**. 같은 코퍼스에서 탈집중(Huawei 광고경매 고객·스윗테크놀러지스)과 집중 강화(Lenovo 단일 공급업체 논리·AI 벤더 락인)가 동시에 관측된다. 제도·계층(AI 스택의 어느 층인가)에 따라 부호가 갈린다는 가설을 세울 근거가 있다.

## I축 — 위험감수 역량(CRTC)의 구성개념 문제

## 4. 이 매핑의 한계 (정직 고지)

1. **담론 ≠ 실행**. 코퍼스는 공개 발화이며 대부분 벤더 채널이다(7,954/8,155). 논문이 재무 패널로 잡은 것을 이 데이터로 대체할 수 없다. 삼각검증(K1 기업 공개자료·인터뷰) 필요.
2. **1차 규칙 기반 추출**. `paper_case_search.py`는 정규식 매칭이며 반어·부정·맥락을 놓친다. 본문에 인용한 사례는 원문 확인을 거쳤으나, `analysis/PAPER_CASES_SUN2024.md`의 후보 전량은 미검증이다.
3. **자막 오역·번역 인용**. 한국어 자동번역 자막에 오기가 있다(예: "AOI"←ROI, "레그"←RAG). 또한 영어 원문 스크립트(Palantir·Huawei·Google Cloud·Accenture 등)의 인용문은 이 문서에서 우리말로 옮긴 것이므로, 논문에 직접 인용할 때는 영상의 영어 원문을 확인해 그대로 쓸 것.
4. **시점 편향**. 업로드 연도 기준 2026년분이 53.7%(4,381/8,155), 2025년 이후가 79%이고 키워드 검색분은 최근에 몰려 있다. 시계열 주장은 불가(`CONTENT_REVIEW.md` §0-C 참조).
5. **F축은 사실상 빈칸**. 위에 적은 대로, 이는 검색 실패가 아니라 담론의 부재로 읽는 편이 타당하다.
6. **발화자 식별의 한계**. 자막에 화자 표지가 없어 발화자는 사회자의 소개말·인수인계 발화 등 텍스트 단서로 추정했다. 2026-08-04 검증에서 다섯 건의 귀속 오류(중기부↔코아비스, Scale AI 발표자↔사회자, Philips 임상의 소속, Continental AWS↔콘티넨탈, KLID 발표자 2인)를 정정했다. 인용 전 영상에서 화자를 재확인할 것.

## 5. 재현 방법

```bash
python paper_case_search.py            # 전체 축, 축별 상위 30건
python paper_case_search.py --axis C D --top 50
```

- 축 정의(정규식 core/context/boost/gate)는 `paper_case_search.py` 상단 `AXES`에 있다.
- 산출: `analysis/PAPER_CASES_SUN2024.md`(사람용), `analysis/paper_cases_sun2024.csv`(문장 단위, 회귀·코딩용).
- 축을 추가하려면 `AXES`에 항목을 넣고 gate(2=core+맥락, 3=주장어휘 필수, 4=주장어휘+맥락 동시)를 잡으면 된다.
