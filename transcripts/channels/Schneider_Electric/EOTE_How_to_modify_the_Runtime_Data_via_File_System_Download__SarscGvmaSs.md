## 스크립트

이 비디오에서는 Operator Terminal Expert를 사용하여 파일 시스템을 통해 다운로드할 때 HMI의 런타임 데이터를 업데이트하는 방법을 설명합니다 . 런타임 데이터란 HMI의 인터넷 정보, 즉 IP 주소와 서브넷 마스크와 같은 정보를 말합니다. 보안 설정뿐만 아니라 비밀번호나 사용자 정보를 변경하거나 새 사용자를 추가할 때도 마찬가지입니다. [음악] 기본적으로 런타임 데이터는 파일 시스템을 통해 다운로드할 때 HMI에 보존됩니다. [음악] 이 동작을 변경하려면 대상 속성, 고급, [음악], 설정, 기본 설정으로 이동한 다음 " 파일 시스템 다운로드를 위한 런타임 데이터 유지" 아래에서 사용자 관리 및 인터넷 설정 확인란을 선택 해제합니다. 그런 다음 파일 시스템을 통해 HMI로 다운로드합니다 . 처음 다운로드할 때 HMI는 이후 전송 중에 런타임 데이터를 덮어쓰도록 설정됩니다. 따라서 런타임 데이터를 덮어쓰 려면 파일 시스템을 통해 HMI에 최소 두 번 다운로드해야 합니다 .
