## 스크립트

[음악] 안녕하세요, 저는 GitHub의 Clean Nson입니다. 저희 산업 솔루션 팀을 관리하고 있습니다. GitHub는 전 세계 소프트웨어 개발자들이 개발 및 협업하는 플랫폼입니다. 최근 Arma GitHub는 GitHub Actions 와 ARM 네이티브 하드웨어를 결합하기 위해 파트너십을 맺었습니다. 이를 통해 개발 속도를 크게 높이고 비용을 절감할 수 있게 되었습니다. 궁극적으로 이는 Windows on ARM 환경에서 머신러닝 워크플로우를 구현할 수 있는 가능성을 열어줄 것입니다. 개발자들이 추론 모델을 애플리케이션 개발에 통합하는 방법을 연구하고, 모든 것을 GPU에서 실행할 필요가 없다는 것을 깨닫게 되면서, 이는 개발자와 기업 모두에게 매우 긍정적인 변화입니다. 개발 비용을 절감하고, 개발 경험을 개선하여 더 빠르게 작업을 완료하고, 빌드 대기 시간을 줄여 코드 작성 에 더 많은 시간을 할애할 수 있게 되었습니다. 출시 이후 반응은 폭발적이었습니다. 많은 개발자들이 클라우드 네이티브 Windows on ARM 및 클라우드-엣지 워크플로우를 위해 ARM 하드웨어 기반 러너를 사용하고 싶어합니다. 이는 개발자들이 배포할 수 있는 완벽한 조합입니다. 하나의 플랫폼에서 이 모든 목표에 도달하세요
