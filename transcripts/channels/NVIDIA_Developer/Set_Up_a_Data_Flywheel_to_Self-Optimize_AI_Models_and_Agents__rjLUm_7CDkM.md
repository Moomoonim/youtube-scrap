Here's how the flywheel works, step by step. The&nbsp; input to the flywheel is logs collected from an&nbsp;&nbsp; Agentic AI application running in production, as&nbsp; depicted on the left side of this diagram. These&nbsp;&nbsp; logs can include user and agent interactions as&nbsp; well as potential user feedback. The application&nbsp;&nbsp; is instrumented to collect these logs,&nbsp; which are then uploaded to Elasticsearch.&nbsp; This makes it available to the Orchestrator&nbsp; service, which is the brain of the flywheel.&nbsp;&nbsp; It is a unified control plane that abstracts&nbsp; the complexity of interacting directly with&nbsp;&nbsp; NeMo microservices. The Orchestrator runs a series&nbsp; of experiments on one or more candidate models as&nbsp;&nbsp; configured in your search space. These can include&nbsp; zero-shot or in-context learning evaluations using&nbsp;&nbsp; NeMo Evaluator, or even fine-tuning using&nbsp; NeMo Customizer followed by evaluation.&nbsp; Evaluation benchmarks thus reported can then&nbsp; be used to determine if there is a suitable&nbsp;&nbsp; candidate that can replace the larger model you&nbsp; have running in your production application.&nbsp;&nbsp; This reduces the cost of ownership by&nbsp; serving faster and leaner models — all&nbsp;&nbsp; this by leveraging live production traffic&nbsp; data for distilling your existing model.&nbsp; This Data Flywheel service is available as a&nbsp; set of Docker containers that can be deployed&nbsp;&nbsp; anywhere — on cloud, data centers, or the edge.&nbsp; It exposes simple-to-use REST APIs to schedule&nbsp;&nbsp; and monitor your flywheel jobs, interacting with&nbsp; the NeMo microservices platform on your behalf.&nbsp; Now we will demonstrate how the system can be&nbsp; used to optimize a customer service agent for&nbsp;&nbsp; tool calling, with the objective of identifying a&nbsp; more efficient LLM that can match the performance&nbsp;&nbsp; of the Llama 3 370B model, which is running by&nbsp; default. To simplify the setup, we will use NVIDIA&nbsp;&nbsp; Brev Launchables, which are preconfigured GPU&nbsp; development environments, and that have some of&nbsp;&nbsp; the prerequisites and dependencies pre-installed&nbsp; out of the box.
