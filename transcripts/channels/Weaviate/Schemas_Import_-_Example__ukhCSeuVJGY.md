## 스크립트

안녕하세요! 이 섹션에서는 인터넷에서 가져온 실제 데이터 세트를 사용하여 새로 배운 지식을 실습해 보겠습니다. 이 데이터 세트를 통해 작은 데이터 세트를 로드하고, 데이터를 기반으로 스키마를 구축하고, EV8로 가져오는 전체 과정을 안내해 드리겠습니다. 이 데이터 세트는 Kaggle에서 가져온 것으로, 다양한 데이터 유형과 속성 구성에 적합한 여러 열로 구성되어 있습니다. 먼저 데이터 세트에 대응하는 속성과 데이터 유형을 가진 새로운 데이터 클래스의 스키마를 구축합니다. 그런 다음 추론 서비스를 사용하여 객체 벡터를 얻어 질문의 의미에 따라 검색할 수 있도록 합니다. 물론 데이터 세트를 Aviate로 가져옵니다. 여기서는 배치 가져오기 프로세스, 배치당 객체 수 지정 및 병렬 처리에 대한 새로운 지식을 적용할 수 있습니다. 또한 가져오기 프로세스에서 중복이 발생하는 방법과 이를 방지하는 방법, 선택적 객체 ID를 사용하여 가져오기 시 동작을 수정하는 방법, 고유한 항목만 인스턴스에 추가되도록 하는 방법도 살펴보겠습니다. 이 섹션을 마치면 모든 것을 배우게 될 것입니다. 이제 여러분은 자신만의 웹 인스턴스를 구축하게 될 거예요. 정말 신나는 일이겠죠? 즐겁게 사용하시고 곧 다시 만나요!
