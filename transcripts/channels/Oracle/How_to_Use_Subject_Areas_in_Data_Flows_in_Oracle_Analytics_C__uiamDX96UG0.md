## 스크립트

이 튜토리얼에서는 Oracle Analytics Cloud의 데이터 흐름에서 주제 영역을 사용하는 방법을 알아봅니다 . 데이터 흐름을 사용하면 데이터를 구성, 조작, 결합 및 집계하여 선별된 데이터 세트를 생성할 수 있습니다. 데이터 세트를 생성한 후에는 해당 주제 영역을 다른 데이터 세트와 결합할 수 있습니다. 이 시나리오에서 저희 조직은 마케팅 캠페인을 시작하며 새로운 제품 유형의 리브랜딩에 따른 보고서가 필요합니다. 신뢰할 수 있는 매출 및 제품 데이터는 관리되는 주제 영역에 있으며, 업데이트된 브랜드 변경 데이터는 별도의 데이터 세트에 있습니다. 데이터 흐름을 사용하여 이들을 결합하고 분석을 위한 선별된 데이터 세트를 만들겠습니다. 홈페이지에서 시작해서 만들기를 선택한 다음 데이터 흐름을 선택하겠습니다. 데이터 추가 대화 상자에서 이 데이터 흐름 에 포함할 주제 영역을 검색합니다 . 저는 영업 애플리케이션 주제 영역을 선택하겠습니다. 이제 제가 원하는 주제 영역 열을 선택하겠습니다 . 수익 지표에서 할인율과 수익을 선택하겠습니다. 고객 중에서 고객 세그먼트를 선택하겠습니다. 그리고 제품 중에서 브랜드와 제품 유형을 선택하겠습니다. 그다음에는 '선택 항목 추가'를 선택하여 이러한 주제 영역 열을 데이터 흐름에 추가하겠습니다. 다음으로, 리브랜딩 관련 데이터를 가져오겠습니다. 단계 추가를 선택한 다음 데이터를 추가하겠습니다. 데이터 세트를 선택한 다음 추가하겠습니다. 이 데이터 세트를 추가하면 Oracle Analytics는 일치하는 열(이 경우 제품 유형)을 사용하여 조인을 자동으로 제안합니다. 제품 유형에 따른 가입 여부를 검토하고 확인하겠습니다. 제 리브랜딩 데이터 세트는 제품 유형과 새로운 브랜딩이라는 두 개의 열로 구성되어 있습니다. 조인 작업은 해당 열들을 주제 영역의 수익 및 고객 필드와 결합합니다 . 다음으로 '단계 추가'를 선택한 다음 '열'을 선택하겠습니다 . 여기서는 중복을 방지하기 위해 이전 브랜딩이 적용된 열을 선택 해제하고 새 브랜딩이 적용된 열만 남겨두겠습니다 . 이제 다시 '단계 추가'를 선택하고 ' 데이터 저장'을 선택하여 출력 데이터 세트를 생성하겠습니다. 출력 데이터 세트의 이름을 '주제 영역 데이터 세트 블렌드'로 지정하겠습니다. 이 데이터 흐름을 실행하기 전에 저장해야 합니다. 이제 데이터 흐름을 실행하여 데이터를 처리하겠습니다. 완료되면 데이터 흐름이 성공적으로 실행되었다는 알림이 표시됩니다. 이제 출력 데이터 세트를 찾아보겠습니다. 홈페이지로 돌아가겠습니다. 내비게이터에서 데이터를 선택하겠습니다. 여기서는 출력 결과가 새로운 데이터 세트로 나타나는 것을 볼 수 있습니다 . 데이터 흐름 탭에서 방금 실행한 데이터 흐름도 확인할 수 있습니다. 이제 선별된 데이터를 시각화할 수 있도록 통합 문서를 만들 출력 데이터 세트를 선택해 주세요 . 결과를 검증하기 위해 캔버스에 매출과 새로운 브랜딩 속성을 드래그하여 가로 막대 차트를 만들겠습니다. 데이터가 예상대로 표시되는 것을 확인할 수 있습니다. 주제 영역과 데이터 세트를 포함하는 데이터 흐름을 사용하면 관리되는 지표와 최신 비즈니스 매핑을 결합한 맞춤형 데이터 세트를 생성할 수 있으므로 분석 속도가 빠르고 유연하며 재사용이 용이해집니다. 아래 링크에서 이 시리즈의 다른 비디오와 Oracle Analytics Cloud 사용에 대한 추가 자료를 찾아보세요.
