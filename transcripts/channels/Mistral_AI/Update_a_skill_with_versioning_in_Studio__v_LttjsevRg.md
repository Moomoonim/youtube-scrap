## 스크립트

Let’s edit a Skill in Studio. Head over to the Skills tab and select the Skill to edit. Here, we’re adding more instructions to improve how an agent reviews GitHub issues. Add the change to the Skill. Save changes to create a new version of the Skill. Version notes help you keep track of why the change was made. Each change is attributed to the user who made it. When you’re happy with a Skill version, click “publish to Vibe” to make it available. Now we have a v2 version of our Skill. Let’s test it out in Vibe. We provide the skill and GitHub connector along with our prompt, Then Vibe gets to work. As a best practice, make small, iterative changes when improving Skills. Vibe is done! With versioned Skills, you can iterate, improve, and revert, while keeping an auditable trail of versions. Get started today in Studio
