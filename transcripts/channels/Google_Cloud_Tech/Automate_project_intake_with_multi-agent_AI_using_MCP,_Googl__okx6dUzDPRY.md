ADK가 이 모든 것을 처리합니다. 단 하나의 수업, 모델, 지침 및 도구만 있으면 됩니다. 그게 바로 에이전트에 대한 전체 정의입니다. 조정자는 세 명의 요원을 동시에 파견한 다음 한 명을 순차적으로 파견합니다. 이는 에이전트 간 프로토콜을 사용합니다 . 총괄 책임자는 전문 요원들이 내부적으로 어떻게 작동하는지 제대로 알지 못합니다. 그것은 단지 URL로 작업을 보내고 결과를 기다려야 한다는 것만 알고 있습니다. 즉, 오케 스트레이터를 건드리지 않고도 에이전트를 교체하거나 새 에이전트를 추가하거나 변경할 수 있다는 뜻입니다. 단순한 접근 방식은 모든 데이터를 CSV 파일에 저장하고 실행할 때마다 프롬프트에 입력하는 것입니다 . 그렇게 하면 당연히 컨텍스트 창(음악)이 너무 커지고 API 비용이 급증하며 데이터가 변경되는 순간 바로 쓸모없어지게 됩니다. 대신, 이 에이전트는 BigQuery 도구 세트를 사용하여 수백 개의 과거 프로젝트에서 몇 초 만에 패턴을 찾아냅니다. 단 한 줄로 에이전트를 Google의 완전 관리형 BigQuery MCP 서버에 연결할 수 있습니다. 에이전트는 특정 요청을 처리하는 데 필요한 내용을 기반으로 런타임에 자체 SQL을 작성합니다 . 또한, 애플리케이션의 기본 자격 증명 과 비밀 관리자를 자동으로 사용합니다. 이 에이전트는 런타임 시 Asana MCP 서버에 실시간으로 쿼리를 보냅니다. 이 기능은 새로운 요청 과 중복될 수 있는 활성 프로젝트를 찾고 현재 팀의 작업량을 확인합니다. 이것은 동일한 프로젝트를 사용하지만 다른 자격 증명을 사용합니다.
