## 스크립트

Quadrant Cloud를 시작하려면 먼저 등록해야 합니다. Google 계정 또는 GitHub 자격 증명을 사용하여 가입할 수 있습니다. 로그인하시면 클라우드 대시보드로 이동합니다. 여기에서 클러스터 페이지로 이동하여 온 보딩 지침에 따라 첫 번째 클러스터를 생성하세요. 클러스터를 생성하면 API 키가 제공됩니다. 복사해서 안전한 곳에 저장해 두세요. 곧 필요할 거예요 . 새 클러스터는 클러스터 섹션에 표시되며 완전히 프로비저닝되는 데 몇 분 정도 소요될 수 있습니다 . 준비가 완료되면 클러스터 대시보드를 엽니다. 여기. 인증을 위해 API 키를 붙여넣으세요 . 대시보드 안에서 튜토리얼 샌드박스를 사용해 볼 수 있는 옵션을 찾을 수 있습니다 . 이곳은 사용자가 직접 아무것도 설정할 필요 없이 실제 쿼드런트 클러스터를 실험해 볼 수 있는 실습 환경입니다 . 먼저 컬렉션을 생성합니다. 벡터 크기를 4차원으로 설정하고 기본 거리 측정 방식을 선택합니다. 컬렉션을 설정한 후에는 몇 가지 샘플 벡터를 추가합니다. 이 벡터들은 서로 다른 위치를 나타냅니다. 데이터가 로드되면 검색을 실행할 수 있습니다. 질문을 직접 입력하는 대신 벡터를 쿼리로 보내면 Quadrant가 가장 유사한 결과를 반환합니다. 결과는 화면 오른쪽에 표시되며, 입력 벡터에 가장 가까운 위치를 보여줍니다. 전체 API 사양은 전용 문서 웹사이트에서 확인하세요.
