## 스크립트

오늘은 GitHub Pages에 사이트를 배포하는 데 필요한 모든 것을 알려드리겠습니다. 대부분의 사람들은 GitHub에서 무료로 안전한 호스팅을 이용할 수 있다는 사실을 모르고 있습니다. 저와 함께하시면 이 영상이 끝날 때쯤에는 여러분의 프로젝트가 게시되고, 검색 가능하며, 공유할 준비가 완료될 것입니다. 안녕하세요, 저는 케다샤입니다. 오늘 이렇게 함께해 주셔서 정말 기쁩니다 . GitHub Pages에 사이트를 배포하려면 GitHub 계정, 배포할 프로젝트, 그리고 몇 분 의 시간만 있으면 됩니다. 본격적으로 시작하기 전에 GitHub Pages가 실제로 무엇인지 살펴보겠습니다. GitHub Pages를 사용하면 정적 웹사이트가 있는 모든 GitHub 저장소를 무료로 라이브 웹사이트로 전환할 수 있습니다. 오늘은 개발자 포트폴리오 사이트를 공개하겠습니다. 예제 프로젝트를 보려면 gh.io/gfp-pages로 이동하세요. GitHub Pages에 여러분의 웹사이트를 게시하는 방법을 살펴보겠습니다. Next.js로 만든 정적 웹사이트가 있습니다. GitHub에 변경 사항을 푸시하면 웹사이트를 배포할 준비가 완료됩니다. 설정으로 이동한 다음, 코드 및 자동화 섹션에서 페이지를 클릭합니다. 빌드 및 배포 섹션에는 두 가지 소스가 있습니다. 브랜치에서 배포하거나 GitHub Actions 워크플로를 사용할 수 있습니다. 두 가지 모두 살펴보겠습니다. 브랜치에서 배포하려면 웹사이트 의 소스로 사용할 브랜치를 선택하세요 . '메인'을 선택하고 '저장'을 클릭하여 웹사이트를 게시하겠습니다. 이제 GitHub Actions 워크플로를 사용하여 배포하는 방법을 살펴보겠습니다 . 빌드 및 배포 섹션에서 작업을 선택하면 Next.js 또는 정적 HTML과 같은 몇 가지 제안된 워크플로가 표시됩니다. 사용 가능한 모든 워크플로를 보려면 '모든 워크플로 찾아보기'를 클릭하세요 . 여기서는 페이지별 워크플로를 볼 수 있습니다 . Jekyll, Astro, Hugo, Gatsby, Next.js 등으로 웹사이트를 구축했거나 정적 HTML을 생성했다면, 여기에서 적합한 워크플로를 찾을 수 있을 것입니다. 제 웹사이트는 Next.js로 구축되었으므로 GitHub Pages Next.js 워크플로를 선택하고 구성을 클릭하면 워크플로 파일로 이동합니다. 여기서는 빌드 및 배포 지침과 함께 권한이 설정됩니다 . 변경할 사항이 없으므로 변경 내용을 커밋하겠습니다. Copilot을 사용하면 커밋 메시지를 작성하는 데 도움이 될 수 있습니다. 데모 목적으로 워크플로우를 메인 브랜치에 직접 커밋하겠습니다. 이렇게 하면 작업이 실행되고, 작업 탭에서 해당 작업을 확인할 수 있습니다. 실행이 완료되면 웹사이트가 게시됩니다. 페이지 설정 페이지에서 마지막 배포를 누가 언제 실행했는지 확인할 수 있습니다. 저장소가 비공개이더라도 게시된 웹사이트는 공개된다는 점을 명심하십시오. 이제 웹사이트 링크를 클릭하실 수 있습니다 . 짜잔! 생방송 중입니다. 멋지죠 ? 몇 번의 클릭만으로 웹사이트가 게시됩니다. 현재 귀하의 사이트는 username.github.io/repository-name 주소에서 접속 가능 하지만, 원하시면 사용자 지정 도메인을 사용할 수도 있습니다 . 페이지 설정 페이지에서 사용자 지정 도메인 섹션까지 아래로 스크롤합니다 . yourwebsite.com과 같은 도메인 이름을 입력하고 저장을 클릭하세요. GitHub는 도메인의 DNS 구성을 확인합니다. 모든 것이 정상적이면 초록색 체크 표시가 나타납니다. 도메인을 연결하려면 도메인 제공업체에서 DNS 레코드를 구성해야 합니다. DNS 및 서브도메인 구성에 대한 자세한 내용은 이 링크를 참조하세요. 도메인 인증이 완료되면 ' HTTPS 적용' 상자를 선택하여 무료 SSL 인증서로 사이트를 보호하세요. 이렇게 하면 방문자가 브라우저에서 보안 자물쇠 아이콘을 볼 수 있습니다. 그게 다입니다. 이제 GitHub Pages 사이트가 사용자 지정 도메인에서 운영되고 있습니다. 자, 그럼 방금 우리가 했던 내용을 정리해 볼까요? 배포할 프로젝트를 선택하고, 브랜치 및 Actions 워크플로를 통해 설정에서 GitHub Pages를 활성화하고 , Actions에서 배포되는 것을 확인하고, [음악]이 사용자 지정 도메인을 추가하면 이제 무료로 웹사이트를 운영할 수 있습니다. 이 영상이 도움이 되었기를 바랍니다. GitHub의 YouTube 채널을 구독하시면 앞으로 업로드될 영상들을 놓치지 않고 보실 수 있습니다. 또한 이 정보가 필요한 개발자 친구와도 공유해 주세요. 즐거운 출판 되세요.
