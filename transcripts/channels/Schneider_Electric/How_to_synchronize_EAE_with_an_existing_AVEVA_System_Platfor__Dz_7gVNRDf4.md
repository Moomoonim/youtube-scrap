## 스크립트

여러분, 안녕하세요. EcoStruxure Automation Expert를 기존 Aviva System Platform Galaxy와 동기화하는 방법을 살펴보겠습니다. 아직 Galaxy를 갖고 있지 않다면, Galaxy 생성 방법을 담은 영상을 시청해 주세요 . EcoStruxure Automation Expert에서 프로젝트를 열고 CAT 섹션으로 이동합니다. 기존 CAT 계정을 열거나 새 계정을 만드세요. CAT 생성에 도움이 필요하시면, CAT 생성 방법을 설명하는 전용 튜토리얼을 시청하세요. CAT 준비가 완료되면 두 가지 워크플로우를 사용할 수 있습니다. 옵션을 선택하기 전에, OPCUA 변수가 Idis 인터페이스에 노출되어 있는지, 그리고 Idis 블록이 CAT 로직 내에 존재하는지 반드시 확인하십시오 . 이렇게 하면 Aviva 객체가 데이터를 올바르게 수신할 수 있습니다. 첫 번째 방법은 Galaxy에 이미 템플릿이 있는 경우 솔루션을 마우스 오른쪽 버튼으로 클릭하고 구성으로 이동한 다음 Aviva SP 템플릿 동기화를 선택하는 것입니다. 이 작업은 갤럭시에서 사용 가능한 모든 템플릿을 검색합니다. 그런 다음 ASP 템플릿 매핑 편집기를 열고 해당 템플릿을 CAT에 할당합니다. 기존 Aviva 템플릿을 선택할 때는 템플릿 속성이 CAT 인터페이스 변수에 매핑되어 있는지 확인하십시오 . 슈나이더 라이브러리(예: 앱과 공통 프로세스)에서는 이러한 매핑이 이미 준비되어 있습니다. 예를 들어, 밸브 템플릿에는 입력 및 출력 속성이 이미 포함되어 있으며 CAT HMI 변수와 미리 연결되어 있습니다 . 하지만 사용자 지정 템플릿을 사용하는 경우 이 매핑을 직접 만들어야 할 수도 있습니다 . 매핑이 완료되면 탭을 닫아주세요. 두 번째 옵션은, 직접 Aviva 그래픽을 만들고 싶다면 CAT HMI를 마우스 오른쪽 버튼으로 클릭하고 "Aviva 산업용 그래픽 추가"를 선택하는 것입니다 . 열리는 에디터는 Viva 시스템 플랫폼 내부에서 사용되는 것과 동일한 산업용 그래픽 IDE입니다 . 사용자 지정 심볼을 디자인하거나 슈나이더 일렉트릭 에서 제공하는 ASP 그래픽 라이브러리를 재사용할 수 있습니다 . CAD 그래픽 또는 템플릿이 준비되면 애플리케이션 노드를 마우스 오른쪽 버튼으로 클릭 하고 "Viva SP 템플릿에 자동 매핑 동기화"를 선택합니다 . 이 기능은 CAD 설계를 기반으로 Aviva 템플릿을 생성하거나 업데이트합니다 . 다음으로 계층 구조 보기를 엽니다. 은하 구조를 불러온 다음 CAD 인스턴스를 올바른 영역으로 드래그하세요. 이 단계는 Viva 시스템 플랫폼 내에서 개체를 올바른 위치에 배치하는 데 필요합니다 . 작은 팁 하나 드릴게요. 해당 영역이 은하계에 존재하지 않으면 Aviva 시스템 플랫폼 IDE를 열고 템플릿 섹션으로 이동한 다음 영역을 마우스 오른쪽 버튼으로 클릭하고 새 영역 인스턴스를 생성하십시오. 앱 엔진에 할당한 다음 EcoStruxure Automation Expert로 돌아가 계층 구조 보기를 새로 고칩니다. 이제 시스템 섹션으로 이동하세요. 기기를 열고 새 기기를 추가하세요. Aviva_Server 유형을 선택하십시오. 서버 노드 및 게이트웨이 매개변수를 포함하여 OPC UA 게이트웨이 설정을 구성합니다. 설정이 완료되면 배포 및 진단 섹션을 엽니다. Aviva 서버 장치를 클릭하고 컴파일을 선택하십시오. 이 과정을 통해 CAD 인스턴스를 추출하고 동기화를 위한 준비를 합니다. 컴파일이 완료되면 장치를 다시 클릭하고 Aviva 시스템 플랫폼과 동기화를 선택하십시오. 변경 사항 동기화를 사용하여 수정된 항목만 업데이트하거나, 선택 사항 동기화를 사용하여 선택한 특정 CAT 인스턴스를 동기화할 수 있습니다 . 마지막으로 Aviva 시스템 플랫폼 IDE를 열고 CAT 인스턴스가 올바르게 생성되었는지 확인하십시오. 올바른 템플릿 과 그래픽 연결을 통해 해당 개체가 올바른 영역 아래에 표시되어야 합니다. 그게 다입니다 . 이제 EcoStruxure Automation Expert를 기존 Aviva Galaxy와 동기화하는 방법을 알게 되셨습니다.
