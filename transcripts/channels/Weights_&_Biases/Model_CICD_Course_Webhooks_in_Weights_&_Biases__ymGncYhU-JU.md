## 스크립트

다음으로 웹훅과 가중치 및 편향을 설정할 것입니다. 다시 한번 말씀드리지만, 제가 공유한 GitHub 프로젝트(WDB 모달 웹훅)에 README 파일이 있습니다. 이 README 파일에는 제가 지금 진행하고 있는 모든 단계가 자세히 설명되어 있으므로, 진행 과정에서 어려움을 겪 거나 이 튜토리얼의 서면 버전을 참조하고 싶을 때 README 파일을 참고하시면 됩니다. 웹훅을 설정하려면 팀 페이지로 이동해야 합니다. 제 팀 이름은 Review Co입니다. 몇 가지 설정을 해야 하는데, 먼저 비밀 키를 생성해야 합니다. 저는 이미 여기에 비밀 키를 가지고 있지만, 기본적으로는 이 버튼을 클릭하면 새 비밀 키를 생성하라는 메시지가 나타납니다. 비밀 키의 이름은 O 토큰으로 지정하고, 실제 비밀 키는 ' secret random token'이라고 입력합니다. 입력란 에 ' secret random token'을 입력하면 됩니다. 비밀 키를 공개하여 철자가 맞는지 확인할 수 있습니다. 저도 철자를 틀렸었네요. 확인하는 것이 좋습니다. 그런 다음 설정을 완료하면 됩니다. 비밀 키를 추가해 볼게요. 이미 추가했으니 여기서 확인할 수 있죠. 음, 다시 한번 확인하기 위해 README 파일로 돌아가서 복사 붙여넣기를 할게요. 제가 좀 꼼꼼한 편이라요. 다시 돌아가서 업데이트할게요. 이제 웹훅을 만들어 볼게요. 이미 웹훅을 만들었지만, 처음부터 다시 만들어서 전체 과정을 보여드릴게요. 웹훅을 새로 만들려면, 아마 기존에 웹훅이 없을 거예요. ' 새 웹훅'을 클릭하고 원하는 이름을 입력하세요. 저는 ' 모달 웹훅 테스트'라고 할게요. 그리고 웹훅의 엔드포인트 URL을 입력해야 해요. 제 터미널을 다시 보시면 모달 앱을 실행했을 때 두 개의 URL이 표시되는 걸 보셨을 거예요. 'run'으로 끝나는 URL이 엔드포인트 URL이에요. 그걸 복사해서 여기에 붙여넣으면 돼요. 모달 대시보드에서도 이 URL을 확인할 수 있어요. 음, 여기로 들어가서 앱으로 이동하면 원하시면 엔드포인트를 바로 여기에서 확인할 수 있습니다. 다시 가중치 및 편향으로 돌아가서, 여기 URL이 있습니다. 이제 우리가 해야 할 일은 시크릿에 액세스 토큰을 저장하는 것입니다. 이 부분이 조금 까다로워서 저도 헷갈릴 때가 있는데, 이 연습에서는 아래로 내려가면 어떻게 해야 하는지 알려줄 겁니다. 액세스 토큰을 설정해야 하는데, ' 오프 토큰'을 선택해야 합니다. 그래서 다시 돌아가서 ' 오프 토큰'을 선택하고 ' 좋습니다'라고 말한 다음 ' 웹훅 생성'을 클릭합니다. 이제 웹훅이 생성되었으므로 자동화를 연결할 준비가 되었습니다.
