Q 채팅 명령어, 즉 신뢰 명령어를 사용할 수 있습니다. 사실 Q 채팅을 시작할 때 Q에서 추천하는 도구를 신뢰한다고 말할 수도 있지만, 특히 운영 환경에서 작업할 때는 처음부터 모든 도구를 신뢰하지 않는 것이 좋습니다. 그래서 저는 처음에 이 명령어를 입력하지 않았습니다. 이제 Q가 이 도구를 실행할 수 있는지 다시 확인할 수 있는 옵션이 생겼습니다. 그렇다면 Q가 제대로 실행할 거라고 믿어도 될까요 ? 그리고 이번에는, 우리가 이 과정을 꽤 여러 번 거쳤기 때문에, T를 입력하여 신뢰한다는 뜻을 나타내고, Q가 이 셸 명령어를 생성하고 실행하도록 하겠습니다. 제가 Q를 입력했으니 이제 Q가 애플리케이션 에 필요한 파일들을 생성하기 시작할 겁니다 . 이제 생성될 모든 파일과 그 파일들이 실제로 저장될 경로를 알려주고 있습니다. 다시 한번 저에게 명령어를 실행해도 되는지 묻고 있는데, 저는 '네, 믿습니다'라고 답하고 있습니다. 잠시 생각하는 동안 신뢰를 나타내는 T를 다시 입력하겠습니다. 생성되는 파일들을 알려드리겠습니다. 백엔드용 Python 체스 파일이 있고, 프런트엔드용 Flask 파일이 있습니다. 지금까지는 이렇습니다. 그리고 do do unicorn은 체스 애플리케이션 자체에 사용되는 것 같은데, 또 뭐가 생성되는지 확인해 보겠습니다. 데이터베이스 관련 파일들이 보이네요.
