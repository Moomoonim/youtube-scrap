## 스크립트

알리, Azure 데이터 브릭이 마이크로소프트 및 Azure 생태계와 어떻게 연동되는지 좀 더 자세히 설명해 주시겠어요? 고객에게 어떤 이점이 있습니까? 네, 작동 방식은 이렇습니다. 우선 Azure 데이터 브릭이 Entra와 통합됩니다 . Entra에 있는 모든 ID는 Azure 데이터 브릭을 통해 바로 전달되며, 모든 데이터는 개방형 형식으로 저장됩니다. 그리고 지금 저희가 정말 기대하고 있는 것은 Unity 카탈로그를 사용하여 구성하고 거버넌스와 보안을 설정한 데이터 브릭에 있는 모든 데이터를 이제 데이터 마이그레이션 없이 Unity 카탈로그에 미러링하여 액세스할 수 있다는 것입니다. 이건 복제품이 아닙니다. 그리고 반대 방향으로도 똑같이 하실 수 있을 거예요. 그리고 Azure Data Bricks의 ADLS에 저장된 모든 데이터는 제로 카피 미러링을 통해 One Lake에서도 사용할 수 있게 됩니다. 그래서 통합이 정말 잘 되고, 물론 전체 eAI 스택과도 통합되어 있습니다. 그러니까 Agent 365, Foundry, Copilot Studio 같은 것들이죠. 그래서 이 모든 것들에 완벽하게 통합됩니다 . 파워앱은 Azure 데이터 브릭과의 통합에서 매우 인기 있는 도구입니다 . 사람들은 이런 강력한 앱을 만드는 것을 좋아합니다 . 아시다시피, 이건 노코드, 로우코드 방식이고, 특히 요즘은 뭐든지 마음대로 코딩할 수 있잖아요. 하지만 핵심은 기업에게 매우 중요한 데이터를 안전하게 보호하여 개인정보를 보호하는 것입니다 .
