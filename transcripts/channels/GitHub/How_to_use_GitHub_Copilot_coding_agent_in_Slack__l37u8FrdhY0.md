## 스크립트

저는 슬랙 채널에 있는데, 방금 동료 한 명이 버그 보고서를 공유해 주었습니다. 다행히 이 작업은 GitHub 코파일럿 코딩 에이전트에 위임할 수 있습니다. GitHub 앱을 언급 하고 요청 사항을 전달하기만 하면 됩니다. 해당 스레드의 모든 컨텍스트가 자동으로 포함되어 새 에이전트 작업이 생성됩니다. GitHub에서 새 브랜치와 풀 리퀘스트 초안을 찾을 수 있으며, Copilot은 작업을 진행하면서 이를 최신 상태로 유지합니다. 진행 상황을 파악할 수 있도록 슬랙에서 해당 스레드를 업데이트할 예정입니다. 작업이 완료되면 제가 Copilot에게 작업을 위임한 담당자로 언급되어 다시 확인해야 할 시간이라는 알림을 받게 됩니다. 모든 작업이 GitHub에서 이루어지기 때문에 GitHub Actions, 통과해야 하는 워크플로 , 코드 소유자의 검토 필요성, 브랜치 보호 등 기존 정책 및 구성이 모두 적용됩니다.
