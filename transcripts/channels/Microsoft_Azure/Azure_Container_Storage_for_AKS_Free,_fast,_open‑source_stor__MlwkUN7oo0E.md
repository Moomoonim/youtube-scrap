## 스크립트

AI, 분석 및 고처리량 워크로드가 일반화됨에 따라 Kubernetes 개발자는 이를 따라갈 수 있는 스토리지가 필요합니다 . Azure Container Storage는 Azure에서 Kubernetes를 위해 특별히 구축된 클라우드 네이티브 스토리지 플랫폼입니다. 이제 로컬 NVMe 스토리지 및 Elastic SAN과 같은 다른 스토리지 백엔드도 지원하므로 Azure Container Storage는 AKS용 Azure에서 가장 빠른 스토리지입니다. 로컬 NVMe를 사용하면 초저 지연과 대폭 향상된 처리량을 얻을 수 있으며, 이는 데이터베이스, AI 워크로드 또는 분석 도구를 실행하는 경우 사용자 경험 향상으로 직결됩니다. 무엇 보다도 Azure Container Storage는 완전히 무료로 사용할 수 있습니다. 기본 저장 공간에 대한 비용만 지불하시면 됩니다 . 그리고 완전히 오픈 소스입니다. 커뮤니티 버전을 설치하고 사용하시면 동일한 훌륭한 혜택을 누리실 수 있습니다. Kubernetes 워크로드의 성능을 획기적으로 향상시킬 준비가 되셨습니까? 비즈니스 규모에 맞춰 확장 가능한 고성능, 비용 효율적인 Kubernetes 스토리지 솔루션인 Azure Container Storage를 사용해 보세요. 이제 일반에서 구매 가능합니다.
