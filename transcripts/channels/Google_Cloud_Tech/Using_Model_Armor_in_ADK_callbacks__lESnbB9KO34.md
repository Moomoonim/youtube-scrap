## 스크립트

[음악] 자체 AI 에이전트를 구축하면 사용자가 비즈니스를 경험하는 방식이 완전히 바뀔 수 있습니다 . 하지만 이러한 새로운 접근 권한 수준은 즉각적인 바이러스 주입, 데이터 유출, 유해 콘텐츠 생성과 같은 위협을 야기합니다. ADK를 사용할 때 이러한 위험을 완화하는 핵심은 콜백을 사용하여 에이전트가 모델과 상호 작용하는 과정에서 보안 검사 지점을 만드는 것입니다 . Model Armor는 사용자 프롬프트와 모델 응답을 필터링하는 정책을 시행하여 이러한 위협으로부터 보호하는 전용 서비스입니다. 관련 영상 몇 개를 아래 설명란에 올려놨으니, 관심 있으시면 확인해 보세요 . 콜백 메커니즘을 사용하여 모델 아머를 ADK 에이전트와 통합할 수 있습니다 . 콜백 메커니즘은 에이전트의 동작을 관찰, 사용자 지정 및 제어할 수 있는 강력한 기능을 제공합니다 . 가장 중요한 통제 지점은 상담원이 LLM에 전화를 걸기 직전입니다. 입력값에 대한 안전장치를 구현하기 위해 이전 모델 콜백을 사용합니다 . 이 함수는 LLM 요청이 전송되기 직전에 실행되어 모델 아머 API의 사용자 프롬프트 정제 메서드를 사용하여 사용자 프롬프트를 검사하고 정제할 수 있도록 합니다. 모델 아머 체크에서 프롬프트 주입 시도 또는 기타 유해 콘텐츠가 감지되면 콜백은 LLM 호출을 건너뛰고 미리 정해진 응답을 반환합니다. 이렇게 하면 요청이 모델에 도달하는 것을 완전히 막을 수 있습니다. 모델이 응답을 생성한 후에는 출력 유효성 검사 절차를 구현해야 합니다. 모델 콜백 이후에는 LLM 응답이 최종 확정되어 사용자에게 반환되기 전에 원시 응답을 검사합니다. 이 콜백은 모델 아머의 sanitize 모델 응답 메서드를 호출합니다. 응답에 유출된 데이터나 유해한 출력이 포함된 경우, 해당 응답을 교체하거나 차단할 수 있습니다. 바꾸기 기능은 응답의 대부분은 유지하면서 이름 이나 신용카드 번호와 같은 특정 부분만 걸러내고 싶을 때 유용합니다. 자세한 예시는 아래 영상을 참고하세요. 먼저, 에이전트의 기본 동작을 보여주기 위해 진행이 허용되는 무해한 질문을 하나 던집니다. 모델 아머 정책이 충족되면 모델 아머 검사가 통과됩니다. 콜백 함수는 진행 중임을 출력하고 LLM이 호출됩니다. 콜백 과정에서 아무런 문제가 없었으므로 정상적인 응답을 받았습니다. 자, 이제 진짜 테스트를 위해, 우리는 질문에 오류가 발생했을 때 알아챌 수 있는 명백한 단서를 포함시켰습니다 . 이는 신속한 주사 시도 또는 정책 위반을 시뮬레이션합니다. before 모델 콜백이 요청을 가로챕니다 . 모델 아머가 시도를 감지했습니다 . 콜백 함수는 LLM에 요청을 보내는 대신 정적이고 안전한 응답을 반환합니다. LLM은 완전히 생략되어 모델이 노출되지 않도록 보호됩니다 . 또한 LLM에서 직접 전달되는 상담원의 응답을 확보해야 합니다 . 모델 호출 후 콜백을 통해 호출 에이전트가 추가 처리를 하기 전에 원시 LLM 출력을 검사하고 수정할 수 있습니다 . 이는 모델이 의도치 않게 민감한 정보를 생성할 때 데이터 유출을 방지하는 데 매우 중요합니다. 예를 들어, LLM 출력에 신용카드 번호나 CCN(카드 정보 번호)과 같이 생성되어서는 안 되는 데이터가 포함된 경우 , 이 콜백은 해당 데이터를 삭제하는 정책을 적용할 수 있습니다 . CCN과 일치하는 시퀀스가 ​​감지되면 콜백 함수는 텍스트에서 마지막 네 자리 숫자만 남기고 나머지를 모두 제거하여 정보 유출을 방지하면서도 사용자에게 필요한 정보를 제공합니다 . 콜백을 사용하여 이러한 모델 아머 보안 체크포인트를 삽입하면 에이전트가 모델과 상호 작용하는 각 지점에 방어 계층을 추가할 수 있습니다. 아래 링크에서 유용한 ADK 콜백 및 모델 아머 관련 문서를 확인해 보세요. 또한 클라우드 환경에 접근 권한이 있는 에이전트에서 이를 사용하는 방법을 설명하는 에이전트 팩토리 에피소드도 시청하실 수 있습니다 . 저는 당신이 무엇을 개발하고 있는지, 어떤 문제에 직면하고 있는지, 그리고 앞으로 어떤 기능을 추가하고 싶은지 정말 알고 싶습니다 . 저는 모든 댓글을 읽고 있으니 아래에 의견을 남겨주세요. 다음 영상에서는 이 영상에서 논의한 아이디어를 바탕으로 ADK에서 모델 갑옷을 사용하는 에이전트를 구현하기 위해 반중력을 활용하는 방법을 알아보겠습니다 . 시청해 주셔서 감사합니다. 열.열.N.
