## 스크립트

인공지능의 역량은 빠르게 발전하고 있으며, 마이크로소프트 퀀텀 개발 키트와 VS 코드 및 GitHub Copilot과의 긴밀한 통합을 통해 양자 학습, 연구 및 개발에서 이러한 역량을 활용할 수 있습니다. 이 짧은 영상에서 이러한 기능 중 몇 가지를 간략하게 소개해 드리겠습니다. 이 과정을 따라하려면 QDK가 설치되어 있어야 합니다. 자세한 내용은 aka.ms/qdk.install을 참조하세요. 시작해 볼까요? GitHub Copilot을 사용하려면 GitHub 계정으로 로그인해야 합니다. Copilot 설정에서 플랜과 이용 가능한 모델을 확인할 수 있습니다. 제 테스트 계정을 사용하여 VS Code에서 AI 기능을 활성화하고 무료 GitHub 계정으로 로그인하는 방법을 보여드리겠습니다. VS Code에서 채팅 창을 열고 AI 기능을 활성화한 다음 GitHub 계정으로 로그인하세요 . 로그인 후에는 사용 중인 요금제에서 이용 가능한 모델 중에서 선택할 수 있습니다. 여기서는 모델 선택을 자동으로 두고 현재 열려 있는 Quantum 코드에 대한 간단한 질문을 하겠습니다. 본격적인 데모를 위해 제 개인 GitHub 계정으로 이동하겠습니다. 그곳에는 더 많은 모델이 있으며, 녹화 당시의 모델 목록은 여기에서 확인하실 수 있습니다. 이번 데모에서는 양자 컴퓨팅 관련 코드를 직접 작성하는 것을 최대한 피하려고 합니다. 그래서 먼저 양자 회로의 화면 캡처 이미지를 넣고 Copilot에게 이것이 무엇인지, 그리고 이를 구현하는 QASM 코드를 작성할 수 있는지 물어보겠습니다 . 순간 이동을 인식하고 구현하는 데 꽤 성공적이며, 제대로 작동합니다. AI가 빛을 발하는 분야 중 하나는 코드 포팅이므로, Q#의 단위 테스트 기능을 활용할 수 있도록 이 QASM 코드를 Q#으로 다시 작성해 달라고 요청하겠습니다 . QASM에서 Q#으로 코드를 성공적으로 포팅한 것 같네요. 이 코드를 테스트하기 쉽게 리팩토링하고, 다양한 양자 상태의 순간 이동을 검증하는 단위 테스트를 작성하도록 요청해 봅시다 . 필요한 모듈을 추가하고 테스트를 작성했으며, 모든 테스트를 통과했습니다. 또한, 작성한 테스트에 대한 깔끔한 요약본도 제공해 주었습니다 . 이것은 임의의 상태로 순간 이동하는 테스트 코드인데, 저는 이 코드가 어떻게 작동하는지 설명해달라고 요청할 겁니다. 이 코드는 대상 큐비트의 준비된 상태를 되돌리고 0 상태를 확인하기 위해 수반 연산을 사용하는 방법을 꽤 잘 설명하고 있습니다. 양자 역학적 이해도를 확인하기 위해, 회로 중간 측정을 모두 제거하고 고전적인 제어 흐름 대신 양자 제어 게이트를 사용하여 알고리즘을 구현한 다음에도 테스트가 통과하는지 확인해 보겠습니다. 그리고 그 시스템은 그러한 변화를 잘 이루어냈고, 테스트도 여전히 통과하고 있습니다. 좋아요, 그럼 버그를 하나 소개하죠. 오타나 복사 붙여넣기 오류일 수도 있겠네요. 이제 테스트가 실패하고 있음을 알 수 있습니다. 깨끗한 코파일럿 세션에서 시작하여 버그를 찾아 수정하고 테스트가 통과하는지 확인해 보겠습니다. 그리고 문제를 정확하게 파악하고 변경 사항을 적용했으며, 이제 모든 테스트가 다시 통과하고 있습니다. 이 코드를 정리하고 편집기 자동 완성 목록에서 제공되는 그로버 알고리즘 예제처럼 좀 더 복잡한 코드를 다뤄보겠습니다 . 우리는 부조종사에게 이 알고리즘의 일부, 예를 들어 균일한 작동에 대한 반영이 어떻게 작동하는지 설명해 달라고 요청할 수 있습니다. 그리고 우리는 그것이 코드에 대한 이해와 양자역학 지식을 결합하여 포괄적인 답변을 제공한다는 것을 알 수 있습니다. 또한, "Q# 안에서 적용되는 패턴은 무엇을 하는가?"와 같이 우리가 이해하지 못하는 언어적 측면에 대해 설명을 요청할 수도 있습니다. 여기서 보시다시피, 코 파일럿을 사용하면 양자 프로그래밍 언어를 배우는 데 도움이 됩니다. 오류가 수정된 시스템에서 이 프로그램을 실행하는 데 필요한 리소스 추정치를 요청하면 , 통합된 리소스 추정 기능을 사용하여 종합적인 분석 결과를 제공할 것입니다. 이 코드가 마음에 들면 Azure Quantum Workspace에서 사용 가능한 호스팅 시뮬레이터의 상태를 확인 하고 사용하려는 시뮬레이터에 작업을 제출하도록 요청할 수 있습니다 . 현재 대기 시간이 약간 있으므로 해당 작업 공간에서 마지막으로 완료된 작업 결과를 가져오도록 요청하겠습니다 . 이 기능은 서비스에서 결과를 가져와 VS Code에서 히스토그램으로 표시해 줍니다. 단 몇 분 만에 Copilot은 간단한 회로 이미지 에서 시작하여 양자 코드를 작성하고, 리팩토링하고, 테스트하고, 알고리즘 일부를 설명하고 , 다른 양자 개념을 설명하고, 버그를 수정하고, 시뮬레이션을 실행하고, 서비스에 연결하고, 작업을 제출하고, 결과를 가져오는 모든 과정을 제가 단 한 줄의 코드도 작성하지 않고 수행했습니다. 직접 사용해보고 다양한 기능을 살펴보시기를 강력히 권장합니다 . 즐거운 양자 코딩 되세요.
