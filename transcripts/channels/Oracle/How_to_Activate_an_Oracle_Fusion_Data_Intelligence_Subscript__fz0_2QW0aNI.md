## 스크립트

In this tutorial, we'll learn how to activate an Oracle Fusion Data Intelligence subscription by linking it to an Oracle Cloud Infrastructure tenancy. In this scenario, my organization has already purchased Oracle Fusion Data Intelligence, and I've received the welcome email. As the cloud account administrator, I'll review the welcome email and verify the subscription details. Then, activate the subscription in the same OCI tenancy as Oracle Fusion Applications to simplify security integration and data synchronization. If I didn't place the original order, I'll contact my Oracle account manager. If I'm not a cloud account administrator, I'll forward the email to one for activation. My organization already has an Oracle Cloud Infrastructure tenancy for Fusion Applications. So, I'll select add to existing cloud account. Next, I'll sign in to the OCI tenancy where I activate the subscription and complete any required multi-factor authentication. On the add subscription page, I'll verify the tenancy name and subscription details before continuing. If the subscription isn't displayed, I'll confirm that I'm signed in with the appropriate administrator privileges before proceeding. If it still isn't displayed, I'll contact my cloud account administrator or Oracle support. After confirming the tenancy information, I'll select add subscription. Oracle warns this action can't be undone, so I'll verify the tenancy one final time before selecting confirm. Oracle links the subscription to the tenancy and begins provisioning the entitlement. When processing is complete, Oracle sends an email confirming that my services are ready. This process can take up to an hour. After receiving the confirmation email, I'll sign back in to Oracle Cloud Infrastructure to verify the subscription status is active in one of two ways. From the applications homepage under quick actions, I can select view subscriptions. Or from the navigator, I'll open billing and cost management. Then, under billing, select subscriptions to confirm my subscriptions are active. This means my FDI activation is complete. Next, I'll verify that my tenancy is entitled to create Fusion Data Intelligence instances. From the navigator, I'll open analytics and AI. Then, select Data Intelligence. On the tenancy entitlements page, I'll verify that my Fusion Data Intelligence subscription is available. I'll open the instances page and confirm the create instances button is enabled. This verifies my Fusion Data Intelligence subscription has been activated successfully and the tenancy is ready to create instances. Now that my subscription is activated, I can either create an integrated or standalone Fusion Data Intelligence instance.
