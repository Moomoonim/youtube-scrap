LLM에서 생성된 콘텐츠의 관련성과 정확도를 향상시키기 위해 R 기법을 적용합니다. 자동 프롬프트의 경우, LLM을 사용하여 구조화된 프롬프트를 자동으로 생성하고, 이러한 자동화된 방법을 활용하여 유사성을 측정합니다. 마지막으로, 생성된 텍스트를 반복적으로 편집하여 사용자 피드백이나 추가 정보를 바탕으로 결과물을 개선하고 다듬습니다. 구조 생성에서 중간 계획의 역할에 대한 연구를 진행하면서, 첫 번째 단계에서는 관련 작품 섹션을 어떻게 구성해야 하는지 개략적으로 설명하는 구조화된 글쓰기 계획을 개발합니다. 이 계획에는 구체적인 인용과 텍스트 내에서의 배치 위치가 포함될 수 있습니다. 그런 다음 이러한 계획을 LLM의 상세 가이드로 사용하고, 계획 평가를 위해 자동화된 평가와 사람의 평가를 모두 수행합니다. 또한 계획 프로세스를 조정하고 개선합니다. 사용자가 최종 텍스트 생성 전에 생성된 계획을 상호 작용하고 수정할 수 있도록 하여 결과물에 대한 높은 수준의 제어권을 제공합니다. 또한 사용자가 변경 사항의 효과를 실시간으로 확인할 수 있는 대화형 도구를 사용하여 더욱 정확한 맞춤 설정을 지원합니다. 이 부분은 데모에서 보여드리겠습니다. 이제 데이터 세트와 도구에 대한 LLM 전략의 실증적 평가를 위해 multix를 확장했습니다. 과학 코퍼스에는 연구 논문 전문이 포함되어 있으며, 자체적으로 개발한 두 가지 롤링 평가 데이터 세트도 있습니다. 평가에는 Root School via Hugging Face Evaluation Library를 사용하는데, 이에 대해서는 간단히 설명드리겠습니다. 기준선 및 모델로는 Extractive Abstractive, Fine Tuning, Zero Short Abstractive를 사용했으며, 모든 모델에는 계획이 포함되어 있습니다. 고급 LLM 접근 방식으로는 오픈 소스 모델 과 클로즈드 소스 모델을 모두 사용했습니다. 오픈 소스 모델로는 Lama 2 Chat과 다양한 변형 모델을 사용했고, 클로즈드 소스 모델로는 GPT 3.5 Turbo와 GPT 4를 사용했습니다. 계획 기반 방식(저희 방법)에서도 오픈 소스 모델과 클로즈드 소스 모델을 모두 사용했습니다. 기본적으로 오픈 소스 및 클로즈드 소스 모델의 성능을 비교하기 위해 먼저 Root Score에 대해 간략히 설명드리겠습니다. Root Score는 요약 의 품질을 평가하는 데 사용되는 일련의 지표로, 요약의 참조와 비교합니다. Zero Short Learning은 모델이 해당 작업의 예제를 명시적으로 학습하지 않고도 작업을 수행할 수 있는 능력을 나타냅니다. 여기 x축에는 Root One, Root 2, Root L이 표시되어 있습니다.
