## 스크립트

간단히 둘러보겠습니다. 오늘 Replet 에이전트에 대한 사용자 지정 MCP 지원을 발표합니다 . 즉, O를 사용하든 안 하든 상관없이 원하는 원격 MCP 서버를 Replet 에이전트에 연결할 수 있다는 뜻입니다. 이제 그 의미와 작동 방식을 자세히 설명해 드리겠습니다. 연동 페이지 주소는 replet.com/integrations입니다. 아래쪽에는 리플릿 에이전트용 MCP 서버가 표시됩니다. 이제 사용자 지정 MCP 서버를 추가할 수 있습니다. 그럼 두 가지 예를 통해 살펴보겠습니다. 먼저, 무료로 공개적으로 이용 가능한 리소스 목록에 대한 접근을 제공하는 서버에 대해 이야기해 보겠습니다. 그다음에는 OOTH MCP 서버의 예를 보여드리겠습니다. 음, 제가 context awesome이라는 멋진 MCP 서버를 하나 찾았어요. AI 에이전트에게 엄선된 리소스가 담긴 8,500개의 유용한 목록에 대한 접근 권한을 부여할 수 있습니다. 그러니까, 이건 참조용 MCP 서버나 정보를 찾는 데 도움이 되는 서버의 좋은 예는 아닙니다. 그런데 제가 여기서 발견한 것은 원격 서버를 사용하고 있다는 점입니다. 자, 그럼 그걸 복사해서 통합 설정으로 돌아가서 사용자 지정 MCP 서버를 추가해 보겠습니다. 이 모달 창이 보일 겁니다. 저희는 계속해서 멋진 MCP 서버를 추가할 예정입니다. 우리는 이 목록을 ' 멋진 목록'이라고 부를 거예요. 그런 다음 테스트하고 저장할 거예요. 이 서버는 승인 되지 않은 MCP 서버이므로 목록에 추가하겠습니다. 꽤 쉽게 할 수 있어요 . 자, 이제 Replet 앱을 실행해 보세요 . 아무 Replet 앱이나 괜찮습니다. 기술 문서 작성에 도움이 되는 훌륭한 자료들을 몇 가지 소개해 드릴 수 있습니다. 리부트 에이전트는 MCP 서버와 저희 도구를 사용하여 해당 작업을 시작할 것이며, 몇 초 안에 해당 서버와 일치하는 것을 확인하실 수 있을 것입니다. 보시다시피, 상담원은 MCP 통합을 선택했고 해당 도구를 사용했으며, 이제 해당 도구의 컨텍스트, 즉 엄선된 리소스 목록에 대한 액세스 권한을 가지고 응답할 것입니다. 그래서 문서가 잘 갖춰져 있거나, 원격 MCPA 서버 또는 사용자 지정 리소스를 사용하는 특정 도구를 사용해야 하는데 문서화가 제대로 되어 있지 않은 경우에 이 패턴이 정말 유용합니다. 또한, 원하는 리소스 목록이나 작업 방식을 활용하여 자신만의 MCP 서버를 구축하려는 경우에도 매우 유용한 패턴입니다 . 해당 내용을 리플렛 에이전트에 노출시킬 수 있습니다 . 그래서, 여기에서 상담원이 제공한 검색 결과를 볼 수 있습니다. 자, 또 다른 정말 훌륭한 패턴은 OATH MCP 서버입니다. 저희는 OOTH 서버와의 통합도 지원합니다. 자, 이제 사용자 지정 MCP 서버를 추가해 보겠습니다. 제가 가장 좋아하는 MCP 서버 중 하나인 Amplitude MCP 서버를 사용할게요. 보시다시피 , Amplitude 문서에서 Amplitude는 데이터 분석 도구입니다. MCP 서버를 추가하고 이름을 Amplitude로 지정한 다음 테스트하고 저장할 수 있습니다. 자, 여기가 O MCP 서버니까 Rebel이 "이거 승인해야 해"라고 말하는 겁니다. 작은 팝업창이 뜰 거예요. 저는 이미 로그인되어 있는 Amplitude 계정으로 승인할 예정이며, 연결은 이처럼 간단합니다. 이제 Replet 에이전트를 통해 쿼리할 수 있는 Amplitude MCP 서버가 구축되었습니다. 이렇게 하면 Replet 에이전트에 MCP 서버를 추가할 수 있습니다. 현재 저희는 인증 유무에 관계없이 원격 MCP 서버를 지원합니다 . 원격 MCP 서버를 배포하는 정말 쉬운 방법 중 하나는 API 키 인증 기능이 기본적으로 제공되는 당사의 MCP onrelet 템플릿을 사용하는 것입니다. 그러면 저희 통합 패널에서 헤더와 인증 값을 포함하는 사용자 지정 MCP를 추가하는 것만으로 간단하게 지원될 것입니다 . 그러면 API 키 인증을 사용할 수 있습니다. 곧 Replet 내에서 OOTH를 사용하여 서버를 직접 배포할 수 있는 기능이 제공될 예정입니다 . 하지만 이것은 Replet 에이전트에 대한 MCP 지원입니다. 저는 맷입니다. 다음에 또 뵙겠습니다 .
