## 스크립트

안녕하세요, Nsight Python이라는 새로운 파이썬 커널 프로파일링 인터페이스에 대한 소개 영상에 오신 것을 환영합니다 . Ensite Python은 NVIDIA의 프로파일링 도구의 강력한 기능을 새로운 API, 데코레이터 및 컨텍스트 관리자를 통해 Python 개발자에게 직접 제공하며, 이러한 기능은 Python 코드에서 바로 사용할 수 있습니다 . 이번 초기 릴리스를 통해 최소한의 코드 변경만으로 다양한 구성에서 모든 Python 프레임워크를 사용하여 CUDA 커널 프로파일링을 원활하게 수행할 수 있으며 , 이 모든 작업은 Python 애플리케이션을 종료하지 않고도 가능합니다. 여기서는 Nsite Python에 포함된 파라미터 스윕 예제를 사용하고 있습니다. 컨텍스트 관리자에서 [음악] 주석 및 분석 데코레이터에 접근할 수 있도록 Nsite Python 모듈을 가져왔습니다. Annotate는 해당 범위 내에서 실행되는 커널에 고유한 이름을 지정하는 데 사용됩니다 . 또한 NSIT Python [음악]에게 어떤 커널을 프로파일링하고 어떤 커널을 무시할지 알려주는 가이드 역할도 합니다. 여기서는 [음악] 주석 컨텍스트 관리자를 사용하여 맵 몰트 커널에 레이블을 지정합니다. Nsight analyze kernel 데코레이터는 Nsite Python에게 이 범위 내에서 주석이 달린 모든 커널을 프로파일링하도록 지시합니다. `configs` 매개변수는 데코레이터가 적용된 함수에 하나씩 전달될 구성 목록이며, 각 구성에 대해 별도의 프로필이 생성됩니다. 여기서는 크기 목록에 있는 다양한 행렬 크기를 벤치마크 맵 몰 크기의 n 인수에 전달합니다 . Runs는 여러 번의 실행에 걸쳐 평균값을 얻기 위해 각 구성을 프로파일링할 횟수를 지정합니다. 플롯 데코레이터를 추가하면 구성별로 주석이 달린 커널을 비교하는 PNG 플롯이 자동으로 생성됩니다. 이제 저는 평소처럼 프로그램을 실행하기만 하면 Ensite Python이 나머지를 알아서 처리해 줄 것입니다. 별도의 설정이나 다른 도구를 사용하여 실행할 필요가 없습니다. 데코레이터가 적용된 함수는 프로파일 결과 객체 [music]을 반환하며, 이 객체를 Pandandas 데이터프레임으로 변환하여 Python에서 추가 분석을 수행할 수 있습니다. 또는 생성된 그래프를 열어 성능 그래프를 바로 확인할 수도 있습니다. Ensite의 Python 소스 코드는 GitHub에 호스팅되어 있으며, Python 모듈은 이제 Pippi에서 사용할 수 있습니다. 무료 CUDA 툴킷에 포함되어 있거나 별도 다운로드로 제공되는 Insight Compute [음악]도 설치하는 것을 잊지 마세요. Insight Python이 프로파일링에 자동으로 사용할 수 있도록 Python 환경에서 접근 가능해야 합니다 . 오늘 한번 사용해 보시고, 문제나 의견이 있으시면 알려주세요. 이 도구는 현재 개발 중이며, 여러분의 요구사항을 충족할 수 있도록 개선 방안에 대한 의견을 기다리고 있습니다. 시청해 주셔서 감사합니다.
