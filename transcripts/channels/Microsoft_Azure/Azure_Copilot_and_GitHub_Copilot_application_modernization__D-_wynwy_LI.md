## 스크립트

Zava는 비즈니스에 필수적인 애플리케이션을 클라우드와 온 프레미스 VMware 환경 모두에서 호스팅합니다. Zava의 IT 관리자인 알렉스와 개발자인 티나를 소개합니다. 두 사람 모두 이 프로젝트에서 협력하고 있습니다 . Alex는 프로젝트 계획 및 실행을 위해 Azure C-Pilot 마이그레이션 에이전트를 사용합니다 . 그는 투자 수익률(ROI) 분석을 완료하고 애플리케이션을 Azure로 이전하는 것에 대한 승인을 받았으며, 특히 현대화를 우선시했습니다. 알렉스는 각 애플리케이션에 대한 마이그레이션 전략을 개발해야 합니다 . 에이전트는 태그를 사용하여 애플리케이션 정의를 캡처하는 데 도움을 줍니다 . 그는 비즈니스 핵심 애플리케이션 자산 관리자부터 시작합니다. 에이전트는 이름을 기반으로 애플리케이션을 호스팅하는 리소스에 태그를 지정합니다 . 알렉스는 상담원에게 애플리케이션의 클라우드 준비 상태를 평가해 달라고 요청합니다 . 이 문서에서는 Azure 앱 서비스 컨테이너와 Azure 데이터베이스를 PostGRQL 유연 서버로 사용하는 마이그레이션 경로를 권장하여 이점을 극대화하도록 안내합니다. 그는 Azure 마이그레이션 평가에서 적용 전략 및 준비 상태와 관련된 추가 세부 정보를 검토합니다 . 이는 그가 해당 애플리케이션에 적합한 현대화 접근 방식을 선택하는 데 도움이 됩니다 . Azure Migrate는 Alex에게 코드 분석 기능을 추가하여 웹 애플리케이션 평가를 향상시킬 수 있는 옵션을 제공합니다. 알렉스는 티나와 자산 관리 회사의 현대화 접근 방식에 대해 논의하고 코드 분석을 진행하기로 합의합니다 . 티나는 협업을 이어가기 위해 알렉스에게 애플리케이션의 GitHub 저장소 URL을 공유했습니다 . 그는 Azure Migrate에서 GitHub 연결을 생성하고 코드 인사이트 추가를 요청합니다. 현재 마이그레이션 평가 상황과 관련된 GitHub 이슈가 생성되어 인사이트를 요청합니다 . 티나는 GitHub 이슈를 살펴보고 GitHub C-Pilot 앱 현대화 확장 프로그램을 사용하여 Visual Studio Code 내에서 코드 분석을 수행합니다 . 이 분석은 기존 패턴, 오래된 종속성 및 구성 불일치를 파악하여 애플리케이션을 Azure에서 최적으로 실행되도록 현대화하는 데 도움을 줍니다. 분석 보고서는 필요한 변경 사항과 권장되는 다음 단계를 자세히 설명하고, 이를 클라우드 준비 상태 관련 문제 및 필요한 Java 버전 업그레이드로 분류합니다. 티나는 분석 보고서를 GitHub 이슈에 첨부하고 알렉스에게 현대화 계획을 계속 진행하라고 알립니다 . Azure Migrate에서 Alex는 코드 준비 상태 및 작업량 추정치를 포함하는 업데이트된 평가를 검토하여 현대화 권장 사항의 정확도를 높입니다. 그는 티나에게 자산운용사 현대화를 추진하라고 승인한다 . 티나는 Visual Studio Code에서 GitHub Copilot을 사용하여 분석 보고서의 문제를 하나씩 수정합니다. GitHub Copilot은 선택한 문제에 대한 해결 계획을 생성하고 실행합니다. 그녀는 GitHub Copilot이 적용한 변경 사항을 검토하고 각 문제에 대해 이러한 단계를 반복합니다 . GitHub Copilot은 Tina가 Azure에 애플리케이션을 배포하는 것도 지원합니다. 해당 애플리케이션은 Azure에서 실행되도록 업그레이드 및 현대화되었습니다. GitHub Copilot과 연동되는 마이그레이션 에이전트 덕분에 Alex와 Zava 팀은 자신 있게 애플리케이션을 Azure로 현대화할 수 있었습니다.
