## 스크립트

슈나이더 세금 신고서에 엑셀 파일을 업로드하여 세금 보고서를 작성하는 방법은 무엇인가요? 주문 개요를 선택하세요. 반품 탭을 클릭한 다음 반품 시작을 클릭하세요. 구매자 반품 번호를 입력하고 드롭다운 목록에서 반품 사유를 선택하세요. 설명이 요청 내용과 일치하는지 검토하십시오. 추가 정보는 자유 텍스트 상자에 입력 하거나 관련 문서를 업로드하세요. 엑셀 파일을 준비하고 저장하세요. 엑셀 파일에 다음 형식으로 데이터를 추가하세요 . A열은 부품 번호입니다. B열, 반품 수량. C열은 슈나이더 주문 번호이고, D열은 구매 주문 번호입니다. 세금 신고서를 제출하기 전에 기존 데이터를 덮어써야 한다는 점에 유의하십시오. 제품 목록을 업로드하거나 가져오기를 클릭하여 돌아가세요. 엑셀 파일을 드래그 앤 드롭한 다음, ' 목록 추가'를 클릭하여 돌아가세요. 입력한 정보가 정확한지 확인한 후 제출 버튼을 클릭하세요. 성공. 고객님의 반품 요청이 ERP 시스템에 제출되었습니다. 반품 화면에서 반품 번호와 상태를 확인하세요. 참고로, 세금 신고서 가져오기에 실패하면 My Schneider 알림과 이메일을 통해 신고서 초안 화면을 확인하라는 안내를 받게 됩니다. 이런 일이 발생하면 고객센터에 문의하여 도움을 받으세요. 제 슈나이더 제품을 이용해 주셔서 감사합니다. 음.
