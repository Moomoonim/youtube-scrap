안녕하세요 여러분, 수학 마법사 CH입니다. 이번 영상에서는 연립 부등식에 대해 알아보겠습니다. 예시로, x + y ≥ 1이고 2x - y ≤ 4인 연립 부등식을 풀어보도록 하겠습니다. 이 연립 부등식은 해집합을 그래프로 나타내는 문제입니다. 차근차근 풀이해 보겠습니다. 먼저 그래프를 하나씩 그리고 마지막에 모두 합칠 것입니다. 위쪽 부분부터 시작해 볼까요? 먼저 x + y ≥ 1인 부분을 살펴보겠습니다. 이 부분에 집중해서 먼저 등식을 그려보겠습니다. x + y = 1을 그리고 등호가 있으므로 실선을 그립니다. 등호 없이 크거나 작다고만 되어 있으면 점선을 그립니다. 자, 이제 대략적인 그래프를 그려보겠습니다. 여기는 y축이고 여기는 x 축입니다. 그림이 완벽할 필요는 없어요. 얼마나 잘 그리고 싶은지에 따라 다르지만, 꽤 정확해야 합니다. x와 y에 0을 대입하면 꽤 괜찮은 그림을 얻을 수 있을 것 같아요. 예를 들어 x를 0으로 놓으면 0 + y = 1이 됩니다. x가 z일 때 y는 1이고, x가 0일 때 y는 1입니다. 그러면 여기에 점이 찍히겠죠. 그리고 y가 0일 때는 x + = 1이 됩니다. 따라서 y가 0일 때 x는 1이고, y가 0일 때 x는 1입니다. 여기에 점이 찍히고, 이건 실선이 되죠. 부등식에 등호가 있으니까요. 이제 선을 그렸으니 어디를 음영 처리해야 할지 알아내야 합니다. 몇 가지 방법이 있는데, 가장 확실한 방법은 테스트 함수를 사용하는 것입니다. 자, 이제 테스트 포인트를 하나 선택해 볼게요. 기본적으로 이 선 위에 있지 않은 아무 점이나 고르면 됩니다. 보통 0을 테스트 포인트로 사용해 볼 수 있죠. 0을 선택해서 테스트해 보겠습니다. 0을 부등식 x + y ≥ 1에 대입하면 0 + 0 ≥ 1이 됩니다. 즉, 0 ≥ 1은 참이 아니므로 0을 선택하지 않습니다. 0은 원점이니까요. 0을 선택했는데 참이 아니었으니, 참이 아닌 다른 부분을 칠해야겠죠. 만약 참이었다면 테스트 포인트가 있는 부분을 칠했을 테니까요. 테스트 포인트를 대입해서 참이면 해당 부분을 칠하고, 거짓이면 다른 부분을 칠합니다. 우리는 0을 선택했는데 참이 아니므로 다른 부분을 칠하는 겁니다. 만약 참이었다면 이 부분을 칠했을 거예요. 자, 이제 다음 부등식인 2x - y &lt; 4로 넘어가 보겠습니다. 같은 방법으로 진행하면 됩니다. 이건 아주 절차적인 문제라서 이제 2x - y &lt; 4를 살펴보겠습니다. 첫 번째 단계는 등식을 그래프로 나타내는 것입니다. 2x - y = 4를 그려보죠. 네, 이게 첫 번째 단계입니다. 그리고 좀 더 쉽게 하기 위해 y 값을 구할 수도 있고, 구하지 않고 그대로 두겠습니다. '&lt;'라는 조건이 있으니 점선을 사용하겠습니다. 아래에 그래프를 그리겠습니다. 여기가 y축이고, 여기가 x축입니다.
