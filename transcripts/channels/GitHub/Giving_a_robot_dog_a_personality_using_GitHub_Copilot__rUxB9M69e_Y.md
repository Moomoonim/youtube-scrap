## 스크립트

최근에 제가 애정을 담아 픽셀이라고 이름 붙인 로봇 강아지를 완성했습니다. 픽셀에는 라즈베리 파이 5가 장착되어 있습니다. 그리고 코에는 아주 작은 라즈베리 파이 카메라가 달려 있죠. 머리 부분에 터치 센서가 있습니다. 그리고 보시다시피 모든 관절의 위치에는 픽셀의 움직임을 원활하게 해주는 서보 모터가 있습니다. GitHub Copilot을 이용해 실험을 해보고 싶습니다. GitHub Copilot이 Pixel의 서보 모터를 제어하는 ​​스크립트를 직접 생성할 수 있는지 , 단순히 아무 작업이나 하는 것이 아니라 특정 동작만 제어할 수 있는지 확인하고 싶습니다. GitHub Copilot이 Pixel을 강아지처럼 움직이는 스크립트를 만들 수 있는지 확인하고 싶습니다 . 우리는 모든 프로그래밍 작업을 비주얼 스튜디오 코드에서 할 수 있습니다. 하지만 기억하시겠지만, Pixel에는 Raspberry Pi 5가 탑재되어 있고, Pixel이나 Raspberry Pi 5에는 모니터가 연결되어 있지 않습니다. 따라서 우리는 모니터를 직접 연결하지 않은 상태에서 헤드리스 모드로 작업할 수 있습니다. 즉, Pi에 모니터를 연결하지 않고도 프로그래밍을 진행할 수 있다는 뜻입니다. 대신, 모니터가 연결된 훨씬 큰 컴퓨터에서 라즈베리 파이 5에 SSH로 접속할 겁니다 . 그러면 거기서부터 픽셀의 마이크로 SD 카드에 저장된 모든 파일( 라즈베리 파이 OS 포함)에 접근할 수 있게 됩니다. 그리고 제 컴퓨터에서 스크립트를 실행할 수도 있는데 , 그 스크립트는 Pixel에서도 실행됩니다. 자, 그럼 시작하겠습니다 . 여기 Pixel 제조사의 Vilib 라이브러리를 사용하는 스크립트가 있는데, 이 라이브러리에는 얼굴 인식 기능이 포함되어 있습니다. 사람 얼굴이 감지되면 감지된 수를 단말기에 기록합니다. 그렇지 않으면 감지된 사람 얼굴의 수는 0이 됩니다. 자, 여기서 제 얼굴이 감지되었습니다. 하지만 실제로 픽셀을 사용할 때는 이렇게 들고 있지는 않을 겁니다. 픽셀을 적절한 위치에 놓으면 픽셀이 이미 위로 올라가 있는 상태가 되므로 카메라 초점이 제 얼굴에 더 잘 맞춰질 것입니다. 지금처럼 코가 아래로 향해 있어서 제가 직접 들어 올려야 하는 번거로움이 없어질 거예요 . 자, 이제 픽셀의 카메라에 접근할 수 있다는 것을 알았으니, 픽셀이 수행할 수 있는 다양한 애니메이션 시퀀스를 추가해 볼 수 있습니다 . 저는 Pixel이 인사할 때 보여줄 기본적인 등장 및 퇴장 애니메이션과 사람 얼굴을 감지하는 코드를 결합한 인사 스크립트를 만들었습니다 . 스크립트가 실행되면 Pixel은 대기 상태가 됩니다. 앉기 동작은 위에서 가져온 PyDog 라이브러리에 포함되어 있습니다 . Pixel이 너무 느리지도 않고 너무 빠르지도 않도록 동작 속도를 50으로 설정했습니다. 다음으로, 앞서 사용한 Vilib 라이브러리를 이용하여 Pixel 카메라가 시작되고 얼굴 인식이 시작됩니다. 저는 N 변수를 사용하여 감지된 사람 얼굴의 수를 추적하고 있습니다. Pixel의 인사말 시퀀스를 시작하려면 0보다 큰 값만 있으면 됩니다. 인사 동작에 대해 말씀드리자면, 픽셀이 사람 얼굴을 감지하면 짖는 소리부터 시작합니다. 그다음 가운데 부분에 GitHub Copilot의 사용자 지정 서보 모터 움직임을 추가하여 Pixel의 인사 동작을 반영하겠습니다. 그리고 마지막으로 픽셀이 꼬리를 흔드는 모습으로 마무리하겠습니다. 꼬리 흔들기 동작을 위한 for 루프는 30°에서 -30°까지 앞뒤로 20번 반복됩니다. 그리고 저는 꼬리를 빠르게 흔드는 걸 좋아해서 속도를 90으로 조절했어요. 어쨌든 강아지는 행복해 보이네요. 또한 GitHub Copilot에게 강아지처럼 움직이는 서보 모터 조합이 무엇인지에 대한 맥락을 제공하는 것이 도움이 될 것이라고 생각했습니다. 그래서 저는 개처럼 작동하는 서보 모터 로직 의 예시를 담은 마크다운 파일을 만들었습니다 . 그리고 저는 개의 부위별로 정리해 두었어요 . 그래서 위쪽에는 다리가 있습니다. 그리고 그 바로 아래에는 머리 부분을 위한 공간이 있습니다. 그리고 맨 아래쪽에는 꼬리 움직임만을 위한 섹션이 있습니다. GitHub Copilot을 사용하여 Pixel의 짖는 소리와 꼬리 흔드는 동작 사이에 greet.py 파일에 강아지처럼 행동하는 일련의 동작을 추가하도록 요청할 것입니다. 제가 여기서 한 일은 greet.py 파일을 열어서 Copilot이 해당 파일을 컨텍스트로 사용할 수 있도록 한 것입니다. 그리고 제가 servos.md 파일을 언급할 때 @ 기호를 사용하는 것을 보실 수 있을 겁니다. 그러면 생성된 서보 마크다운 파일을 참조하게 됩니다. 자, 그럼 실행시켜보고 무슨 일이 일어나는지 봅시다. 네 , GitHub Copilot에서 응답이 왔습니다 . 어떤 결과가 나왔는지 봅시다. 그래서 우리는 그 논리를 이해할 수 있습니다. 해당 파일을 살펴본 후, 거기서 강아지처럼 인사하는 동작을 만들어냈고, 강아지가 신나서 일어서고 , 고개를 갸우뚱거리고, 고개를 끄덕인 다음, 장난스럽게 몸을 숙이는 동작을 하도록 했습니다. 그래서 아래쪽에 GitHub Copilot이 코드 자체 에 추가한 내용에 대한 설명을 볼 수 있는데 , 저는 이것이 매우 흥미롭다고 생각합니다. 다시 말씀드리지만, 이것은 순전히 실험적인 것으로, GitHub Copilot에 컨텍스트를 제공하고 강아지의 움직임을 어떻게 이해하는지 살펴보는 것입니다. 좋습니다, 그럼 GitHub Copilot이 어떤 결과를 내놓았는지 살펴보겠습니다 . 좋아, 내 얼굴을 찾고 있는 것 같군 . 그리고 제가 그를 조금 움직여 볼 수도 있겠네요. 네 , 그가 봤어요. 아 .
