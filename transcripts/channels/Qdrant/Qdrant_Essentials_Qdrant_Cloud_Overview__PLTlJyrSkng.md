## 스크립트

Quadrant를 사용하여 본격적인 개발을 시작하기 전에 먼저 설치해야 합니다. Quadrant는 완전한 오픈 소스이므로 배포할 수 있는 방법이 여러 가지 있습니다. 그럼 여기서 가장 중요한 몇 가지에 대해 이야기해 보겠습니다. Quadrant를 사용하는 가장 쉽고 일반적인 방법 중 하나는 Docker를 이용하여 로컬 테스트 및 배포 에만 사용하는 것입니다. 하지만 이는 프로덕션 환경에 이상적인 방법은 아닙니다 . 하지만 여기 있는 두 가지 명령어를 사용하면 쉽게 시작할 수 있습니다 . 경로 2의 데이터를 실제로 데이터를 저장하려는 위치로 변경해야 합니다. Docker가 실행 중인지 확인 하고 터미널에 위 두 명령어를 붙여넣으세요 . Docker Compos를 사용하여 쿼드런트를 실행할 수도 있습니다 . 다음은 단일 노드 쿼드런트 클러스터를 실행하는 데 사용할 수 있는 사용자 지정 구성 파일의 예입니다 . Kubernetes Helm 차트를 사용하여 Kubernetes 클러스터에 Quadrant를 배포하거나, Quadrant 바이너리를 직접 사용하여 원하는 프로세서 아키텍처에서 실행할 수도 있습니다 . 하지만 이 과정에서는 애플리케이션 확장을 위해 쿠버네티스 클러스터나 서버를 관리하는 것은 원하지 않습니다. 그래서 우리는 인프라 구축보다는 벡터 검색을 배우는 것이 목표이기 때문에 Quadrant Cloud를 사용할 것입니다. 자, 이제 쿼드런트 클라우드 클러스터에서 첫 번째 API 키를 받는 과정을 안내해 드리겠습니다. 쿼드런트 클라우드에 접속하는 가장 쉬운 방법은 Quadrant.te에 접속하여 " 시작하기"를 클릭하는 것입니다. 이렇게 하면 쿼드런트 클라우드 가입 페이지로 이동하게 되며, 원하는 방식으로 간단히 가입할 수 있습니다 . 저는 그냥 구글을 이용할 거예요. 좋아요. 이제 로그인했으니, 여기에서 Quadron이 신용 카드 없이 제공하는 1GBTE 무료 클러스터를 영구적으로 생성할 수 있습니다. 그래서 우리는 그것을 사용할 것이고, 그것은 우리 실험에 충분하고도 남을 것입니다. 그리고 이 클러스터를 제 첫 번째 클러스터라고 이름 붙이겠습니다. 클러스터 생성 버튼을 클릭하세요. 이제 API 키를 생성하는 옵션이 표시됩니다. 이게 제 열쇠입니다. 나중에 필요할 것 같아서 복사해 둘게요. 그리고 이 API 키는 다시 볼 수 없으므로 안전한 곳에 저장해 두시기 바랍니다. 다시 요청하실 수 있습니다. 하지만 아시다시피, 그냥 복사하면 되잖아요. 당신의 삶을 더 편하게 만들어 줄 거예요. 이제 저희는 클러스터가 시작되기를 기다리고 있습니다. 여기 클러스터 페이지에서 상태가 '생성 중'으로 표시되는 것을 볼 수 있으며, 몇 초 후면 이 클러스터를 사용할 수 있게 됩니다. 그럼 클릭해 볼까요? 그리고 여기에는 이 클러스터에서 사용 중인 RAM, CPU 및 디스크 용량에 대한 많은 정보가 있습니다 . 또한 클러스터의 상태를 추적하는 데 사용할 수 있는 다양한 옵션이 있습니다. 이제 클러스터 준비가 완료되었습니다. 그럼 이제 웹 UI를 살펴보겠습니다. Quadron 웹 UI는 여기 열린 대시보드에서 접속할 수 있습니다. 여기서는 앞서 복사한 API 키를 붙여넣어야 합니다. 그럼 API 키를 여기에 보내드리겠습니다. 지금 우리는 쿼드런트의 웹 UI 안에 있습니다. 웹 UI는 Quadrant 클러스터 내에서 발생하는 상황을 확인 하고 상호 작용할 수 있는 공간입니다. 콘솔을 사용하여 클러스터에 직접 명령을 보낼 수 있습니다. 보유하고 있는 컬렉션 목록도 볼 수 있습니다. 현재 저희는 컬렉션을 보유하고 있지 않습니다. 그래서 아무것도 볼 수 없어요. 그리고 Quant가 실제로 어떻게 작동하는지 살펴보고 몇 가지 기능을 사용해 볼 수 있는 멋진 튜토리얼이 많이 있습니다. 어, 데이터 세트 탭도 있는데, 거기에는 튜토리얼에서 활용해 볼 수 있는 몇 가지 데이터 세트가 있습니다. 웹 UI에 대해서는 나중에 더 자세히 살펴보겠지만, 지금은 Quadrant를 사용하고 Quadrant 클러스터를 활용하는 데 필요한 모든 것을 갖추고 있습니다. 다음 영상을 시작하려면 Quadrant Cloud 대시보드로 돌아가세요. 클러스터에 필요한 URL 엔드포인트와 방금 전에 저장한 API 키가 필요합니다 . 두 파일을 안전하게 저장하고 튜토리얼을 시작하겠습니다. 컬렉션에 관점을 삽입합니다 .
