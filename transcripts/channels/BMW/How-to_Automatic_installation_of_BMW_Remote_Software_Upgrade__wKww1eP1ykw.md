## 스크립트

더욱 편리하게 이용하세요! BMW Remote Software Upgrade를 자동으로 설치하도록 설정할 수 있습니다! 새로운 업데이트가 있을 경우 푸시 알림을 따르기만 하면 됩니다. Remote Software Upgrade 페이지에서 새로운 '자동 설치' 기능을 이용할 수 있습니다. 활성화하면 향후 모든 업데이트가 수동 작업 없이 자동으로 설치됩니다! 각 업데이트를 확인하기 전, 설치가 진행되는 동안에는 차량을 움직일 수 없으므로 안전하게 주차해야 합니다. 걱정하지 마세요. 자동 설치 기능을 사용하면 놓칠 일이 없습니다! 새 업데이트를 설치할 준비가 되면 알림을 통해 예정된 설치에 대해 알 수 있습니다. 물론 설정은 언제든지 조정할 수 있습니다. 미리 설정되어 있는 설치 시간이 불편하신가요? 설치 시간을 변경하기만 하면 됩니다. 오늘 다른 일정이 있으신가요? 다음 날로 실행을 건너뛰면 설치 날짜가 자동으로 조정됩니다. 너무 기대되시나요? '지금 시작'을 클릭하기만 하면 수동으로 설치가 트리거됩니다. 새로운 BMW 경험을 즐기고 항상 차량을 최신 상태로 유지하세요! BMW에 대해서는 이미 잘 알고 계시겠지만 아직 더 많은 기능이 남아 있습니다. 구독 버튼을 누르고, 댓글을 남겨 보세요. 공유하고, 알림을 설정하여 BMW의 모든 잠재력을 알아보세요. 지금 바로 살펴보세요!
