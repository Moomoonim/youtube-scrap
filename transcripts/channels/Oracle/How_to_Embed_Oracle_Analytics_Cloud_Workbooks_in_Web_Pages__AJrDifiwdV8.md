## 스크립트

이 튜토리얼에서는 Oracle Analytics Cloud 통합 문서를 웹 페이지에 삽입하여 내부 또는 외부 웹사이트에 대화형 대시보드를 표시하는 방법을 알아봅니다 . 통합 문서를 웹 페이지에 삽입하면 분석 데이터를 공유할 수 있으므로 사용자는 Oracle Analytics Cloud로 이동 하지 않고도 대시보드와 상호 작용할 수 있습니다 . 이 시나리오에서 저는 관리자 이고 더 많은 사람들이 접근할 수 있도록 판매 분석 통합 문서를 웹 페이지에 공유하고 싶습니다 . 환경을 설정한 다음 iframe 안에서 통합 문서 URL을 사용하겠습니다. 먼저 콘솔로 이동하여 안전 도메인을 선택하겠습니다. 이 단계에는 서비스 관리자 권한이 필요합니다. 워크북을 삽입할 도메인을 추가하겠습니다. 이 예시에서는 GitHub입니다. 그런 다음 필요한 권한을 활성화하겠습니다. 가장 중요한 옵션은 임베딩으로, 이를 통해 통합 문서를 사이트 내에 표시할 수 있습니다. 도메인을 선택하면 자동으로 저장됩니다. 다음으로, 임베디드 콘텐츠를 호스팅할 웹 페이지를 만들겠습니다 . 이 경우에는 GitHub를 열고 새 저장소를 만들겠습니다. 저장소 이름을 지정하고 외부에서 접근할 수 있도록 공개로 설정하겠습니다. 그럼 제가 만들겠습니다. 이제 워크북을 삽입하기 위한 iframe 코드가 포함될 index.html이라는 새 파일을 만들겠습니다. 이 파일에 iframe을 추가하겠습니다. 소스 필드가 비어 있는 것을 확인하세요. 여기에 통합 문서의 URL을 제공해야 합니다. 그럼 공유 카탈로그에서 통합 문서를 열고 해당 URL을 복사하겠습니다. 통합 문서는 공유 폴더에 저장해야 합니다 . 그렇지 않으면 삽입 시 접근할 수 없습니다. 이 링크를 iframe 소스 필드에 붙여넣고 변경 사항을 적용하여 파일을 저장하겠습니다. 다음으로, 설정으로 이동하여 페이지를 선택하고, 메인 브랜치 에서 배포하도록 소스를 구성한 다음 변경 사항을 저장하여 GitHub Pages를 활성화하겠습니다. 이제 GitHub에서 페이지를 빌드하고 배포합니다. 작업 탭에서 이 과정을 모니터링할 수 있습니다. 배포가 완료되면 생성된 URL을 선택하여 사용하겠습니다. 여기서 저는 웹 페이지에 Oracle Analytics 통합 문서가 포함되어 있고 , 완전히 상호 작용 가능한 상태로 표시되는 것을 볼 수 있습니다. 이 iframe 코드는 다른 모든 HTML 페이지에서도 사용할 수 있습니다. 내장된 통합 문서를 보려면 사용자는 Oracle Analytics Cloud에 로그인해야 합니다 . 이제 워크북을 웹페이지에 삽입했으므로, 모든 웹페이지를 통해 인터랙티브 분석 데이터를 공유할 수 있어 사용자들이 더욱 쉽게 인사이트를 얻을 수 있습니다. 아래 링크에서 이 시리즈의 다른 비디오와 Oracle Analytics Cloud 사용에 대한 추가 자료를 찾아보세요.
