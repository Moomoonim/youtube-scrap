## 스크립트

오늘은 Brain Trust와 Cerebras를 활용하여 AI 애플리케이션을 모니터링, 평가 및 개선하는 가장 빠른 방법을 소개해 드리게 되어 기쁩니다 . 초고속 LLM 추론을 위해 Cerebrris를 사용할 예정입니다 . Brain Trust는 지표, 평가 및 실험 추적을 모두 한 곳에서 제공하여 가시성과 제어력을 확보할 수 있도록 지원합니다. 시작하려면 Cerebrus API 키와 Brain Trust API 키가 필요합니다. cloud.serebrus.ai에서 무료 API 키를 신청할 수 있습니다. 다음으로 브레인 트러스트에 로그인하세요. 설정의 AI 공급자에서 Cerebrus 키를 추가하세요 . 다음으로 브레인 트러스트 API 키를 생성하세요. 이제 프로젝트 디렉터리에 두 키가 모두 포함된 N 파일을 생성해야 합니다. 설정이 완료되면 모든 것을 연결해 보겠습니다. Brain Trust 로깅으로 래핑된 클라이언트를 초기화합니다. 이제 모든 모델 호출을 자동으로 추적하도록 로깅 기능을 추가하세요 . 트랙 완료 테스트를 실행하면 Brain Trust는 지연 시간, 토큰 사용량 및 첫 토큰 획득 시간을 자동으로 기록합니다. 마지막으로 브레인 트러스트 대시보드로 이동하세요 . 프로젝트를 열면 모든 요청에 ​​대한 자세한 로그를 볼 수 있습니다. 사용자 인터페이스에서 직접 프롬프트를 재현하고 수정할 수도 있습니다. 자, 이제 실제로 작동하는 모습을 살펴보겠습니다. 평가는 다양한 데이터 세트와 점수 함수를 사용하여 모델의 성능을 테스트합니다 . 다음 프로젝트에서 시도해 보세요. 두 가지 장점을 모두 누릴 수 있을 겁니다. 매우 빠른 추론 속도와 모델에 대한 실시간 가시성 .
