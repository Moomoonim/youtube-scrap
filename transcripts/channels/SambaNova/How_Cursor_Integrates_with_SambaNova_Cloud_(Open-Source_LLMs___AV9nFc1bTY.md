## 스크립트

안녕하세요, 오늘은 Kurszer를 Samanova 클라우드와 통합하는 방법을 보여드리겠습니다 . Kurszer는 인공지능을 사용하여 코딩할 수 있게 해주는 매우 인기 있는 AI 코드 편집기입니다. 원하는 코드를 입력하기만 하면 프로그램이 그대로 작성해 줍니다. 기본적으로 Kurszer는 Claude, Gemini, GPT와 같은 여러 자체 개발 모델을 사용합니다 . 하지만 저는 Sambonova 클라우드를 사용해서 DeepSek Lama나 Quen 같은 다양한 오픈 소스 모델에 접근하고 싶습니다 . 원하시면 Sova 문서에서 커서를 Sambovo 코드에 통합하는 방법을 따라해 보실 수 있습니다. 해당 문서에는 이 통합만을 다룬 페이지가 있습니다. 그럼 바로 시작해 볼까요? Kursa를 실행하면 Visual Studio Code와 매우 유사하게 보입니다. 왜냐하면 Kursa는 Visual Studio Code IDE를 기반으로 개발되었기 때문입니다. 간단한 HTML 페이지를 만들어 달라는 코드를 생성해 보겠습니다. 기본적으로 어떤 대규모 언어 모델을 사용할지 자동으로 결정됩니다. 그래서 저는 소노바 클라우드에서 오픈 소스 모델을 사용하고 싶었기 때문에 해당 기능을 비활성화하겠습니다. 그러기 위해서는 몇 가지 단계를 거쳐야 합니다. 우선, 여기에 Open AI API 키를 입력하고 Open AI API 키를 사용하도록 선택하여 인증해야 합니다 . 이제 저는 검증 절차 자체를 위해 이 작업을 진행할 것이고, 실제로 제 오픈 AI API 키는 사용하지 않을 것입니다. 그렇게 하고 나면 Kursa에서 기본적으로 사용하는 독점 모델들을 모두 선택 해제하겠습니다 . 그 후에는 몇 가지 일을 할 거예요. 우선, OpenAI와 호환되는 Sambonova API의 엔드포인트를 여기에 그대로 옮겨오겠습니다. 제가 직접 입력하고 OpenAI 기본 URL을 재정의하도록 하겠습니다. 그럼 이제 소노바 클라우드에서 새 API 키를 생성하겠습니다 . 여기서 커서용 아이콘을 하나 생성하겠습니다 . 이 API 키를 여기에 복사하겠습니다. 그리고 마지막으로, 제가 원하는 모델 목록에 해당 모델을 추가하겠습니다 . 제가 정말 좋아하는 모델은 DeepSeek v3입니다. 그리고 모델 이름을 복사해서 커서에 추가하겠습니다. 그 작업을 마친 후에는 모델에 접근 가능한지 확인하겠습니다 . 이렇게 하면 아래쪽 모델 메뉴에서 모델을 선택할 수 있습니다. 그래서 저는 " 이걸 훨씬 더 좋게 만들어 보세요" 같은 말을 할 거예요. 그리고 실제로 저는 사마노바 클라우드에서 딥시크 V3 0324와 같은 오픈 소스 모델을 실행하는 커저(Kurszer)를 사용해 봤습니다. 오픈 소스 모델을 사용하는 이유는 더 안전하고 보안이 뛰어나며 개인 정보 보호에도 도움이 될 뿐만 아니라, 일부 독점 모델보다 코드를 더 빠르게 생성할 수 있기 때문입니다 . 매우 감사합니다.
