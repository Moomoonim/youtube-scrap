## 스크립트

안녕하세요, Onyx Runtime Gen 파이썬 패키지 설치 및 실행에 대한 간단한 개요에 오신 것을 환영합니다. 이 간단한 노트북은 처음부터 시작하여 LLM의 첫 번째 추론 결과를 얻는 데 도움을 드립니다. 설치 과정은 매우 간단하며 몇 가지 PIT 패키지만 설치하면 됩니다. 특히 Onyx Runtime Gen 라이브러리를 설치할 때 이 접미사에 주목해 주시기 바랍니다. 이 접미사는 Onyx Runtime과 함께 패키징될 실행 공급자를 지정하는 역할을 합니다. 따라서 Onyx 모델을 추론할 때 이전 프레젠테이션 에서 설명했던 것처럼 DirectML 실행 공급자를 사용하게 됩니다. 라이브러리 설치가 완료되면 다음 단계는 라이브러리와 함께 사용할 Onyx 모델을 준비하는 것입니다. Onyx Runtime Gen은 디코딩 루프를 사용하는 생성형 모델에 특화되어 있으므로 모든 Onyx 모델이 이 라이브러리와 호환되는 것은 아닙니다. 호환되는 모델을 얻으려면 라이브러리에 포함된 도구를 사용해야 합니다. 모델 빌더는 이렇게 실행할 수 있습니다. 이 도구는 Onyx 모델 카드 이름( 이 경우 Microsoft 53.5를 사용)을 입력받고, 실행 공급자(이 경우 DML 또는 DirectML), 출력값을 양자화할 정밀도(이 경우 int4), 출력 위치( Onyx 모델 2)를 지정합니다. 이 셀을 실행하는 데 몇 분 정도 걸리므로 녹화 전에 실행해 두었습니다. 출력 결과는 6개의 파일이 포함된 디렉터리 형태로 나타납니다. 이 중 3개는 토크나이저 관련 파일이고, 2개는 앞서 설명한 Onyx 코어 모델과 관련 데이터, 그리고 Onyx 런타임 생성에 특화된 구성 파일입니다. 이 구성 파일에는 여러 가지 내용이 포함되어 있지만, 모든 내용을 자세히 설명하지는 않겠습니다. 기본적으로 모델과 검색 두 부분으로 구성됩니다. 모델 부분은 모델 빌더가 제공한 Onyx 모델 카드를 사용하여 자동으로 채워지므로 사용자가 크게 수정할 필요는 없습니다. 검색 부분은 모델과 관련된 내용입니다. 출력의 최대 길이, 최소 길이, 온도, 빔 검색 사용 여부 등 조절할 수 있는 여러 가지 설정이 있지만, 대부분 기본값으로 두겠습니다. 노트북으로 돌아가서, 사용할 모델과 라이브러리가 설치되면 첫 번째 추론을 실행하는 파이썬 코드는 매우 간단합니다. Onyx 런타임, 모델, 토크나이저, 생성기 매개변수 이렇게 세 개의 객체를 인스턴스화하면 됩니다. 생성기 매개 변수는 방금 살펴본 검색 섹션처럼 구성 파일에서 확인할 수 있습니다. 샘플링 값과 특정 알고리즘을 조정할 수 있습니다. 다시 말씀드리지만, 출력의 최대 길이를 1,000으로 변경하는 것 외에는 모든 것을 기본값으로 두겠습니다. 이렇게 하면 이 셀을 실행할 때 엄청난 양의 텍스트로 인해 출력이 폭주하는 것을 방지할 수 있습니다. 이제 프롬프트를 구성해 보겠습니다. 제가 모델 빌더에게 제공한 모델 카드와 일치하는 방식으로, 마이크로소프트는 프롬프트 생성에 대한 지침을 제공하므로 저는 그 지침을 따르겠습니다. LLM에게 요리 도우미라고 소개하고 딸기, 우유, 휘핑크림을 사용하여 무언가를 만들 수 있는 레시피를 요청하는 프롬프트를 생성하겠습니다. 토크나이저를 사용하여 프롬프트를 인코딩하고 생성 API를 사용하겠습니다. 이렇게 하면 생성기 매개변수인 프롬프트와 모델을 사용하여 모든 것이 시작되고 종료 조건에 도달할 때까지 모든 출력을 생성한 다음 출력 ID를 출력합니다. 이제 실행해 보겠습니다. 현재 제 NVIDIA GPU에서 직접 지원되는 하드웨어에서 실행 중이며 출력 결과는 다음과 같습니다. 유용한 레시피가 제공되었고 재료, 조리법, 팁 등 제가 찾던 모든 정보가 있습니다. 이렇게 간단합니다. 모델을 설치하고 추론하는 것은 몇 분 만에 완료할 수 있습니다. 말씀드렸듯이요. 조정할 수 있는 옵션이 훨씬 더 많고, 다양한 설정 값을 시험해 볼 수 있으며, 모델과 라이브러리에서 어떤 일이 일어나는지 더 깊이 이해할 수 있는 자료도 훨씬 더 많습니다. 이러한 자료들을 자유롭게 살펴보시고 Onyx R Time Gen으로 즐겁게 개발해 보세요.
