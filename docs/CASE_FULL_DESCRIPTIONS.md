**① Chad Interviews Francisco (2025-01-24, en)** — 팔란티어 아키텍트 Chad Walquist가 사내 동료 Francisco
Parga(Apex 팟 리드)를 인터뷰한다. **온톨로지 교리의 이론적 정식화**가 여기 있다. LLM은 미켈란젤로,
온톨로지는 끌이라는 비유. 아웃오브더박스 소프트웨어를 거부하고 "계획과 실행의 간극"을 문제로 설정한다.

**② 미 국무부 의료 운영 (2025-06-10, en)** — AIPCon 7 고객 단독 키노트. 발표자는 국무부 의료프로그램

**③ AIG 언더라이터 어시스턴스 (2025-06-13, en)** — AIPCon 7 고객 단독 키노트. 발표자는 AIG 글로벌
최고데이터책임자 Jim Young. 이 코퍼스에서 **정량 지표가 가장 조밀한 자료**다.

- **"가치 있는 시간의 90%를 검색·추출·수기 입력에 소모"**
- 다섯 원칙: 단일 유스케이스 집중, 현업 공동 설계, **human in the loop**, 에이전틱 모듈 아키텍처, 측정
- 세 기능: 인제스천(100개 속성 자동 추출), 증강(내외부 소스 검색·검증), 우선순위 부여
- RAG 구조를 직접 설명 — 프롬프트 생성 → 관련 컨텍스트 반환 → LLM이 출처 청크와 함께 응답 → 언더라이터가 확인·수정
- 성과: **3~4주 → 1일 미만**, 데이터 품질 정확도 **90% 이상**, 언더라이터 캐파 **2~5배**, 파일럿에서 bind/submit 비율 상승
