## 스크립트

[음악] 파이썬의 다재다능함, 강력한 라이브러리, 그리고 활발한 커뮤니티는 오늘날 AI 및 딥러닝 애플리케이션의 발전을 적극적으로 이끌고 있습니다. NVIDIA는 GPU 가속 파이썬 코드 최적화가 때때로 까다로울 수 있다는 것을 알고 있습니다. NVIDIA는 파이썬 커뮤니티를 지원하기 위해 Insight 개발자 도구 제품군을 여러 가지 방식으로 확장하고 있습니다. 현재 사용 가능한 파이썬 프로파일링 기능 몇 가지를 살펴보겠습니다. Insight 도구의 Jupiter Lab 확장 프로그램은 NVIDIA 개발자 도구 제품군에 가장 최근에 추가된 기능입니다. 이 확장 프로그램을 통해 Insight 시스템 및 Insight 컴퓨팅의 성능 프로파일링 기능을 Jupiter Lab에서 사용할 수 있습니다. 다음 시간에 이러한 도구에 대해 자세히 살펴보겠습니다. 지금은 Jupiter Lab 개발 환경을 벗어나지 않고 파이썬 및 기타 지원되는 언어로 작성된 노트북 셀의 자세한 성능 분석을 수행할 수 있다는 의미입니다. 이 도구는 pii에서 다운로드할 수 있습니다. 프로파일링된 셀의 출력 영역에서 함수 호출별 코드 실행 시간 , GPU에서 실행되는 CUDA API 이벤트 등 성능 및 잠재적 병목 현상을 신속하게 진단하는 데 도움이 되는 중요한 지표를 확인할 수 있습니다. Insight 시스템 GUI를 실행하면 전체 타임라인이 포함된 새 탭이 열립니다. 여기에서 코드 실행을 자세히 분석할 수 있습니다. Insight Systems는 전체 시스템 컨텍스트에서 코드가 어떻게 실행되는지 시각적으로 보여주므로 성능 향상 기회를 명확하게 파악할 수 있습니다. 예를 들어 Python 백트레이스 샘플링을 사용하면 Insight Systems는 Python 호출 스택을 주기적으로 샘플링하며, 샘플링 주기는 1Hz에서 2kHz 사이로 조정할 수 있습니다. Python 호출은 타임라인에 표시되므로 언제든지 어떤 호출이 실행되고 있는지 확인할 수 있습니다. 이를 통해 코드가 멈추는 지점을 검사하고 성능 문제를 연관시킬 수 있습니다. Insight Systems는 또한 mvtx로 주석 처리된 Python 함수를 추적하고 Python 스레드가 전역 인터프리터 잠금을 유지하거나 유지하려고 대기하는 시점을 그래프로 표시할 수 있습니다. 이는 많은 Python 성능 문제의 주요 원인 중 하나입니다. Python 호출 스택 샘플링 및 프로파일링은 ight compute 버전 20242 이상에서 지원됩니다. 이러한 도구는 프로파일링 워크플로에서 밀접하게 관련되어 있습니다. ight Systems는 포괄적인 시스템 전체 하드웨어 및 소프트웨어 추적을 제공하고, ight compute는 CUDA 커널 성능 및 소스 코드 상관 관계를 심층적으로 분석할 수 있도록 합니다. ight compute의 컨텍스트 페이지는 커널 실행으로 이어진 호출 순서를 보여주며, 이제 Python 및 네이티브 함수를 모두 포함합니다. 이렇게 하면 코드가 예상대로 실행되는지 빠르게 확인할 수 있습니다. Insight Compute는 소스 뷰어에서 Python 구문 강조 표시를 지원하여 Python 파일의 성능 데이터를 네이티브 코드처럼 쉽게 해석할 수 있도록 합니다. 또한 Numba와 같이 JIT 컴파일된 커널을 사용하고 충분한 라인 정보가 있는 경우, 많은 GPU 성능 지표를 Python 소스 코드와 연관시킬 수 있습니다. 마지막으로, ight Systems와 ight Compute의 많은 분석 프레임워크는 확장성이 뛰어난 Python 스크립트로 구동됩니다. Python 개발자라면 이미 이러한 도구를 사용 사례에 맞게 사용자 지정할 수 있는 기술을 갖추고 있습니다. 예를 들어, ight Compute의 규칙 시스템은 코드에서 성능 최적화 문제를 자동으로 감지하고 수정 사항을 권장합니다. 이 시스템은 Python 기반이며 Insight Systems에서 새 규칙을 만들거나 기존 규칙을 편집할 수 있습니다. 다중 노드 분석은 레시피라고 하는 Python으로 작성된 분석 스크립트를 통해 활성화됩니다. ight Systems에는 다양한 레시피가 포함되어 있으며 사용자 지정 성능 보고서를 위해 직접 레시피를 만들 수도 있습니다. Python은 여러분에게 중요한 만큼 저희에게도 중요하며, 향후 Insight Tools 릴리스에서 Python 커뮤니티를 지원하는 기능을 계속 추가할 계획입니다. 자세한 내용을 확인하고 이 비디오에 나오는 도구를 다운로드하려면 설명란의 링크를 참조하세요. 이러한 도구 사용 방법에 대한 튜토리얼은 Insight 튜토리얼 센터를 참조하세요. 시청해 주셔서 감사합니다.
