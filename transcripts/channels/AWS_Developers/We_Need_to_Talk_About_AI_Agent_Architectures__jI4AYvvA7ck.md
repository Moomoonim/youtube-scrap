Agent Core 런타임은 AI 에이전트를 호스팅하기 위한 관리형 서버리스 환경입니다. 이 서비스는 배포, 확장, 세션 격리를 처리하며 AWS 내부 및 외부의 다양한 도구 및 서비스와 통합할 수 있습니다. 런타임은 AM 및 OOTH 기반 ID를 모두 지원하는 인바운드 인증과 같은 많은 작업을 자동으로 처리합니다. 모델 이나 프레임워크에 구애받지 않으므로 어떤 프레임워크나 모델 제공업체를 사용하든 에이전트를 호스팅할 수 있습니다 . 이 점을 염두에 두고, 이 에이전트를 에이전트 코어 런타임에 배포할 수 있는 형태로 빠르게 변환해 보겠습니다. 그렇게 하려면 Bedrock Agent Core 런타임에서 가져오는 코드를 맨 위에 추가해야 합니다.
