## 스크립트

이 튜토리얼에서는 Oracle Analytics Cloud 및 Oracle Fusion Data Intelligence에서 페이지를 만들고 공유하는 방법을 알아봅니다. 페이지 기능을 사용하면 여러 팀의 콘텐츠를 체계적으로 관리할 수 있어 , 프로젝트를 바꿀 때마다 홈페이지를 재구성하지 않고도 필요한 통합 문서, 데이터 세트 및 기타 자료를 쉽게 찾을 수 있습니다 . 이 시나리오에서는 OAC 인스턴스에 새로운 고객 세분화 팀을 추가해야 하며 , 해당 팀이 가장 자주 사용하는 자료가 담긴 전용 페이지를 갖도록 하고 싶습니다. 먼저, 네비게이터를 열어 판매 분석과 같이 이 인스턴스에 이미 존재하는 페이지들을 살펴보겠습니다 . 이 페이지는 워크북, 데이터 세트, 머신 러닝 섹션 등 해당 팀에 필요한 가장 중요한 콘텐츠를 중심으로 이미 구성되어 있습니다. 다음으로, 다양한 유형의 콘텐츠(예: 주요 통합 문서 및 데이터 세트)를 구성하는 데 사용할 수 있는 사용자 지정 그룹을 사용하는 공급망 페이지로 이동하겠습니다. 작업 메뉴를 선택한 다음 검사를 클릭하면 기존 페이지를 사용자 지정할 수 있습니다. 일반 탭에서는 페이지 의 카테고리, 아이콘, 테마 색상과 같은 페이지 설정을 편집할 수 있습니다. 액세스 탭에서 이 페이지를 적절한 사용자 또는 역할과 공유하고 각 사용자에게 부여할 액세스 수준을 선택할 수 있습니다. 레이아웃 탭에서 페이지 편집 권한이 있는 경우 페이지 레이아웃, 표시되는 섹션 및 표시 순서를 조정할 수 있습니다 . 이제 고객 세분화 팀을 위한 새 페이지를 만들고 싶습니다. 네비게이터를 다시 열고 새 페이지 추가를 선택하겠습니다. 일반 탭에서 페이지 이름을 지정하고, 카테고리, 아이콘, 테마 색상을 선택하여 쉽게 알아볼 수 있도록 하겠습니다. 액세스 탭에서 팀 구성원을 추가 하고 액세스 수준을 정의하겠습니다. 만약 사용자들만 이 페이지를 찾아서 열 수 있도록 하고 싶다면, 읽기 전용으로 설정하겠습니다. 페이지 유지 관리를 돕도록 하려면 읽기/쓰기 권한을 부여합니다. 만약 누군가에게 페이지 관리 권한( 접근 권한 업데이트 포함)을 완전히 부여하고 싶다면, 전체 제어 권한을 사용하겠습니다. 레이아웃 탭에서 기본 섹션을 그대로 두고 저장을 선택하겠습니다. 이 페이지에 대한 사용자 지정 그룹을 만든 후 레이아웃 작업으로 돌아가겠습니다. 탐색기를 열고 새 고객 세분화 페이지를 선택한 다음 페이지에 표시될 사용자 지정 콘텐츠 그룹을 만들기 시작하겠습니다. 이 경우에는 머신러닝 모델, 데이터 세트, 데이터 흐름과 같은 고객 세분화 관련 자산이 이미 존재합니다. 새로운 사용자 지정 그룹을 시작하려면 머신 러닝 모델 중 하나의 작업 메뉴를 선택하고 , 사용자 지정 그룹에 추가를 선택한 다음, 새 사용자 지정 그룹을 선택합니다. 이 사용자 지정 그룹의 이름을 ' 고객 세분화 자산'으로 입력한 다음 ' 추가'를 선택합니다. 다음으로, 나머지 주요 자산의 액션 메뉴를 선택하여 이 사용자 지정 그룹에 추가하겠습니다. 추가적인 세분화 모델과 마찬가지로, 이러한 모델을 생성하는 데 사용된 데이터 흐름 및 이 프로젝트의 데이터 세트도 포함됩니다. 사용자 지정 그룹이 생성되었으니 이제 페이지 레이아웃을 업데이트하여 맨 위에 표시되도록 하겠습니다. 탐색기에서 해당 페이지를 찾고, 작업 메뉴를 선택한 다음 검사를 하겠습니다. 레이아웃 탭에서 이 사용자 지정 그룹을 클릭하고 드래그하여 페이지 맨 위로 옮기겠습니다. 팀에서 이 콘텐츠 섹션을 가장 많이 사용할 것이기 때문입니다. 그다음, 저장을 선택하겠습니다. 이제 페이지 레이아웃이 새롭게 바뀌었고, 제가 만든 사용자 지정 그룹이 맨 위에 표시되네요. 제가 관리자라면 사용자가 해당 페이지로 직접 이동하지 않고도 바로 접속할 수 있도록 특정 페이지를 사용자의 기본 홈페이지로 설정할 수 있습니다 . 내비게이터에서 랜딩 페이지 관리를 선택하겠습니다. 사용자 또는 역할을 검색한 다음 해당 사용자의 랜딩 페이지를 고객 세분화 페이지로 설정하겠습니다. Oracle Analytics Home 기능도 활성화하겠습니다 . 따라서 사용자의 기본 홈페이지는 이제 고객 세분화 페이지가 됩니다. 그다음, 저장을 선택하겠습니다. 만약 제가 읽기, 읽기/쓰기 또는 전체 제어 권한을 가지고 있다면, 페이지의 작업 메뉴를 선택하고 해당 페이지를 랜딩 페이지로 설정할 수 있습니다. 브라우저를 새로고침하면 이제 고객 세분화 페이지가 랜딩 페이지로 표시됩니다. 전용 페이지를 만들고 정리하고 공유했으므로 이제 각 팀이 로그인하자마자 가장 많이 사용하는 자료에 빠르게 액세스할 수 있도록 지원할 수 있습니다 . 아래 링크에서 이 시리즈의 다른 비디오와 Oracle Analytics Cloud 및 Fusion Data Intelligence 사용에 대한 추가 자료를 찾아보세요.
