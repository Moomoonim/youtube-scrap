## 스크립트

Opal은 Google Labs에서 개발한 새로운 실험적인 도구로, 자연어 및 시각적 워크플로를 사용하여 몇 분 만에 연결된 AI 시스템을 구축하고 테스트할 수 있습니다. 이 비디오에서는 Opal을 사용하여 Git Clarity라는 완벽하게 작동하는 미니 앱을 만들어 보겠습니다. Git Clarity는 AI 기반 도구로, 모든 GitHub 풀 리퀘스트를 기술적인 지식이 없는 이해관계자들이 이해하기 쉬운 한 단락 요약으로 바꿔줍니다. 우리는 자연어 프롬프트와 Opal의 시각적 워크플로 편집기만을 사용하여 빈 Opal 캔버스에서 이 모든 것을 구축할 것입니다. 여기에는 코딩이 필요하지 않습니다. 대신, 원하는 바를 설명하고 시각적으로 반복합니다. 오팔은 최대한의 활용성을 위해 설계되었습니다. Opal은 신속한 AI 프로토타이핑을 위한 샌드박스로, 모델을 연결하고, 아이디어를 테스트하고, 프롬프트를 반복적으로 개선하고, 프로덕션 단계로 넘어가기 전에 도구 설정을 실험하려는 모든 사용자에게 적합합니다. 오늘은 개발자 중심의 사용 사례를 보여드리겠습니다. Opal을 사용하면 " PR을 요약하는 앱을 만들고 싶다"는 생각에서 시작하여 단 몇 분 만에 작동하는 UI, 연결된 AI 워크플로, 공유 가능한 도구를 만들 수 있습니다. Opal을 처음 사용하시는 분들을 위해 이 데모를 진행하는 동안 도움이 될 수 있는 개념을 설명해 드리겠습니다. Opal은 웹 콘텐츠 가져오기, 데이터 처리, 결과 표시와 같은 단계를 자동으로 추가하여 여러 단계로 구성된 워크플로를 지능적으로 생성합니다. 시각적 워크플로 편집기에서는 모든 단계가 구성 요소입니다. 입력, 생성 단계 및 출력은 모두 연결 관계와 함께 표시됩니다. 이를 통해 빠른 반복 작업이 가능합니다. 자연어를 사용하여 프롬프트를 변경하고, 단계를 조정하고 , 즉시 다시 실행할 수 있습니다 . 즉시 호스팅 및 공유 기능을 통해 앱이 자동으로 배포되고 URL을 통해 공유할 수 있게 됩니다. 또한, 프로토타입 제작은 처음부터 완벽하게 만드는 것이 목적이 아니기 때문에 Opal을 사용한 반복 프로세스에 대해서도 자세히 살펴보겠습니다. 빠르게 아이디어를 탐색하고 시도해 보는 것에 관한 것입니다. 자, 시작해 볼까요? 여기서는 빈 Opal 캔버스에서 시작하여 자연어를 사용하여 전체 앱을 구축할 것입니다. 먼저 프롬프트를 입력합니다. 오팔은 이를 즉시 해석하여 단순한 양식이 아닌, 여러 단계를 거치는 완벽한 워크플로 기반 앱을 생성합니다 . Opal이 PR [음악] 콘텐츠를 가져오고 처리하기 위한 워크플로 단계를 지능적으로 생성하는 동시에 제목과 입력 필드를 자동으로 생성하는 방식을 확인해 보세요 . 좋아요, 이 워크플로는 꽤 괜찮네요. 한번 살펴볼까요? 지금까지 우리는 PR 링크를 입력하는 사용자 입력 단계 , 웹페이지 가져오기 도구를 사용하여 PR 콘텐츠를 가져오는 단계, 콘텐츠를 요약하는 단계, 그리고 결과를 표시하는 출력 단계를 구현했습니다 . 각 단계에서 지도나 웹 음악 검색과 같은 다양한 도구를 활용할 수 있다는 점에 주목하세요 . PR 요약 단계를 클릭하여 구성을 확인해 보겠습니다. 단계를 선택하면 Opal은 오른쪽에 구성 패널을 엽니다 . 여기에서 모델 드롭다운 메뉴를 볼 수 있습니다. Opal은 각 단계에 맞는 다양한 모델을 쉽게 선택할 수 있도록 해줍니다. 아래 편집 영역에서 현재 프롬프트를 확인할 수도 있습니다. 먼저 고급 설정에서 모델이 어떻게 동작하기를 원하는지에 대한 컨텍스트를 수동으로 추가하겠습니다 . 프롬프트를 직접 편집하거나 Opal의 자연어 편집 기능을 사용하여 프롬프트를 업데이트할 수 있습니다. 이 내용을 반영하여 수정하겠습니다. Opal은 자동 [음악] 워크플로 생성의 일부로 이미 출력 화면을 만들어 놓았습니다. 이는 모델 출력 결과를 미리 보는 데 유용 하지만, 모델이 시간이 지남에 따라 동일한 질문에 대해 다른 응답을 제공할 수 있다는 점을 염두에 두어야 합니다 . 이제 워크플로가 완료되었는지 확인하겠습니다. 편집기 보기에서 GitHub PR 링크를 클릭하면 PR 내용을 가져오고, 이 링크는 PR 요약으로 연결되며, 마지막으로 PR 요약을 생성하는 단계로 이어집니다. 모든 연결이 안전하게 완료되었습니다. Opal의 시각적 워크플로 편집기는 전체 흐름을 보여줍니다. 이 워크플로를 개선하고 싶다면 단계나 도구를 쉽게 추가할 수 있습니다. 예를 들어, 자산 추가 기능을 사용하여 Google Drive에서 참조 문서를 업로드 하거나 추가 처리 단계를 추가할 수 있습니다. 하지만 현재로서는 워크플로우가 완료되어 테스트 준비가 되었습니다. 이제 실제 GitHub 풀 리퀘스트를 통해 앱을 테스트해 볼 시간입니다 . 앱 화면을 클릭하면 몰입감 넘치는 앱 환경을 경험할 수 있습니다. 지금은 편집기 보기의 사이드 패널에서 앱을 미리 보겠습니다. 출력 결과에는 Git Clarity라는 제목과 시작 버튼이 표시됩니다. 시작하기 위해 클릭하겠습니다. Google의 Now in Android 저장소에 있는 PR을 사용해 보겠습니다 . 링크를 입력란에 붙여넣고 제출 버튼을 클릭하세요. Opal이 당사의 연결된 AI 워크플로를 거치는 과정을 지켜보세요. 웹에서 보도자료 콘텐츠를 가져오는 중입니다. 인공지능을 이용해 처리하여 요약본을 생성합니다 . 그리고 결과를 표시합니다. [음악] 몇 초 만에, 우리는 기술적인 용어를 사용하지 않고도 풀 리퀘스트에 대한 명확하고 간결한 요약을 얻을 수 있습니다 . 바로 우리가 이 앱을 만든 목적입니다 . 멋진. Opal의 핵심적인 [음악] 강점 중 하나는 변경 사항을 쉽게 반복하고 테스트할 수 있다는 점입니다. 그럼, 출력 결과를 개선하기 위해 요약 프롬프트를 다듬어 보겠습니다 . 편집기 보기로 돌아가서 제안 및 편집 상자를 사용하여 생성 단계를 구체화하세요. 오팔은 프롬프트를 즉시 업데이트합니다. 아무것도 재배포하거나 재시작할 필요가 없습니다. 개선된 결과를 확인하기 위해 바로 다시 테스트해 볼 수 있습니다. 이것이 바로 Opal을 이용한 신속 프로토타이핑의 힘입니다. 빠르게 반복하고, 즉시 테스트하고, 연결된 AI 워크플로우를 실시간으로 개선하세요 . 프로토타입이 마음에 들면 공유 버튼을 클릭하세요. Opal은 팀과 공유할 수 있는 공개 URL을 생성합니다 . 자, 여기 생중계 영상입니다. Opal은 실제 운영 환경 에 적용하기 전에 AI 워크플로 아이디어를 탐색하고, 실험하고, 검증하는 공간이라고 생각하시면 됩니다 . 우리는 단 몇 분 만에 자연어와 시각적 편집만으로 Git Clarity를 ​​완전히 구축했습니다 . 웹 콘텐츠를 가져와 인공지능으로 처리하고 결과를 표시하는 체인 시스템. Git Clarity 외에도 Opal을 사용하여 고객 지원 봇, 내부 대시보드, 크리에이티브 도구, 데이터 처리 파이프라인 또는 상상할 수 있는 모든 종류의 AI 워크플로를 프로토타입으로 만들 수 있습니다. 가능성은 무궁무진합니다. opal.google에서 Opal을 사용해보고 지금 바로 나만의 미니 앱 개발을 시작해 보세요.
