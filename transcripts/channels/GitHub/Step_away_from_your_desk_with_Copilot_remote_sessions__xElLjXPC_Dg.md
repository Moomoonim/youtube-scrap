## 스크립트

이제 컴퓨터 에서 실행 중인 Copilot CLI 세션을 휴대폰이나 어디에서든 이어서 작업할 수 있습니다. 터미널에서 작업하든 Visual Studio Code에서 작업하든 상관없습니다. 이제 자리를 비우셔도 되지만, 필요할 때 언제든 작업을 계속하실 수 있습니다. 작동 방식은 이렇습니다. 터미널에 링크 공유 웹사이트를 열어놓고 Copilot에 작업을 할당했습니다. 제가 공유하는 페이지 상단에 특정 링크를 즐겨찾기에 추가하거나 고정할 수 있는 새로운 기능에 대한 계획을 세워주세요. 계획은 실행 준비가 완료되었고 저는 이제 손을 떼고 싶지만, 이 작업은 계속 진행하겠습니다 . 그래서 저는 {슬래시} 원격 켜기를 입력할 수 있습니다. 이를 통해 제 GitHub 로그인으로 보호되는 웹 인터페이스를 통해 원격으로 액세스할 수 있으며, 모든 세션은 비공개로 유지되어 저에게만 보이지만, 로컬 CLI 세션과 상호 작용하고 여기에서 바로 작업을 계속할 수 있습니다. 하지만 Ctrl+E를 누르면 QR 코드가 나타납니다. 제가 휴대폰으로 그걸 스캔하면, 이제 제 휴대폰에서 바로 그 실시간 세션을 볼 수 있어요. 하지만 GitHub 앱이 설치되어 있다면 브라우저 탭보다 훨씬 더 나은 기능을 이용할 수 있습니다. 네이티브 앱과 같은 환경을 경험할 수 있습니다. 내 세션은 Copilot 탭에 바로 표시됩니다 . 이 기능 구현을 시작하고 상담원의 활동을 실시간으로 스트리밍으로 확인할 수 있습니다. 질문에 답변하고 , 도구 요청을 승인 또는 거부할 수 있습니다. 차이점 검토도 할 수 있어요. 또는 현재 단계가 실행되는 동안 다음 메시지를 대기열에 추가할 수도 있습니다 . 또한 여러 프로젝트에 걸쳐 다양한 원격 세션에 액세스할 수 있습니다 . 웹에서 제 모든 세션은 github.com/agents에 표시되며, 현재 액세스 권한이 있는 원격 세션을 확인할 수 있습니다. GitHub 앱에서는 모든 것이 Copilot 아래에 표시되며, 모든 세션에 동일한 액세스 권한을 갖습니다 . 또한 Copilot CLI와 VS Code가 완벽하게 통합되어 있기 때문에 CLI에서 VS Code 채팅으로 동일한 원격 세션을 열 수 있습니다 . 재시작할 필요도 없고, 진행 상황도 잃지 않아요 . 그리고 내부적으로 모두 동일한 CLI를 사용하기 때문에 VS Code 채팅에서 {슬래시} 원격을 입력해도 정확히 같은 경험을 얻을 수 있습니다. QR 코드, 웹 인터페이스, GitHub 모바일 앱 등 어디에서든 단 하나의 명령으로 작동합니다 . 믿기 ​​어려우시겠지만, 이 모든 과정에는 소스 코드 관리를 위해 GitHub가 실제로 필요하지 않습니다. 이 프로그램은 모든 소스 제어 시스템과 호환되며, 소스 제어 시스템을 전혀 사용하지 않아도 작동합니다 . 여전히 작동하며 {slash} 원격 기능을 계속 사용할 수 있습니다. 원격 기능은 현재 GitHub Copilot CLI와 Visual Studio Code에서 사용할 수 있습니다.
