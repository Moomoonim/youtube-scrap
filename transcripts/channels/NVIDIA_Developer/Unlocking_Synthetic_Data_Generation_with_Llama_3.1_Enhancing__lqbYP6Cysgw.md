Meta에서 최근 최첨단 오픈 소스 LMS 모음인 Lama 3.1을 발표했습니다. 이 모델들은 여러 주요 경제 벤치마크에서 다른 주요 모델들을 능가하는 성능을 보여주었습니다. 이 영상에서는 특히 뛰어난 추론 능력과 합성 데이터 생성 능력이 돋보이는 405b 파라미터 모델에 대해 자세히 살펴보겠습니다. 더 구체적으로는 LMS 추론을 위한 합성 선호도 데이터 세트를 생성하는 다양한 단계를 살펴보겠습니다. 자세히 알아보겠습니다. NVIDIA는 Meta와 협력하여 Lama 3.1 모델을 저지연 고처리량으로 더욱 최적화했습니다. Meta API 카탈로그에서 Lama 3.1을 제공하게 되어 매우 기쁩니다. NVIDIA Enterprise의 일부인 NVIDIA NIMS는 클라우드 데이터 센터와 워크스테이션 전반에 걸쳐 고성능 AI 모델 추론을 안전하고 안정적으로 배포할 수 있도록 설계된 사용하기 쉬운 마이크로서비스 세트입니다. 현재까지 ISV, GSIS, MLOP를 포함한 여러 파트너가 NVIDIA NIMS를 사용하여 엔터프라이즈 AI 애플리케이션 배포 속도를 높이고 있습니다. 이제 여러분도 사용할 수 있습니다. Nvidia 컴퓨팅 스택에서 완벽하게 가속되는 Lama 3.1을 API 카탈로그를 통해 무료로 경험해 보세요. 더욱이, API 엔드포인트를 사용하여 애플리케이션 프로토타입을 원활하게 개발할 수 있습니다. API를 통해 Nvidia 호스팅 GPU를 활용하여 모델을 테스트해 볼 수도 있습니다. Lama 모델 제품군에 새롭게 추가된 모델은 405B, 70B, 8B의 세 가지 크기로 제공됩니다. 이제 합성 데이터 생성 파이프라인의 아키텍처를 살펴보겠습니다. 이 파이프라인을 통해 기업은 Lama 3.14 fibb 모델을 사용하여 도메인에 대한 합성 데이터를 생성할 수 있으며, 이 데이터는 Neotron 4 340B 보상 모델로 평가하고 Nvidia Nemo를 사용하여 인간 선호도에 맞춰 정렬할 수 있습니다. 이 과정은 다음과 같은 단계를 포함합니다. 먼저 Lama 3.1 모델을 사용하여 수백 또는 수천 개의 질문과 각 질문에 대한 몇 가지 답변을 생성합니다. 그런 다음 새로운 Neotron 4 340B 보상 모델을 사용하여 답변에 점수를 매겨 선호도 데이터 세트를 생성합니다. 이 데이터 세트를 추가로 필터링하여 높은 품질을 확보하고, 정제된 선호도 데이터 세트를 얻습니다. 마지막으로 이 고품질 선호도 데이터 세트를 사용하여 Nemo 얼라이너로 LLM을 정렬합니다. 라이브러리의 각 구성 요소가 어떻게 함께 작동하는지 이해했으니 이제 코드를 살펴보겠습니다. 먼저 동영상 설명에서 Jupyter Notebook을 다운로드하세요. 첫 번째 단계는 API 카탈로그에서 API 키를 생성하는 것입니다. 이 키를 사용하여 사용 가능한 다양한 이름에 연결합니다. API 키를 생성하는 방법은 다음과 같습니다. 먼저 API 카탈로그로 이동하여 회사 이메일로 가입하면 프로토타이핑용 무료 토큰 5,000개를 받을 수 있습니다. 그런 다음 API 키를 생성하고 복사합니다. 노트북의 첫 번째 단계에서는 사용자가 제공한 주제에서 하위 주제를 생성하는 프롬프트 템플릿을 만듭니다. 그런 다음 주어진 하위 주제에 대한 질문을 생성하고, 마지막으로 이전에 생성한 프롬프트 템플릿을 사용하여 주어진 질문에 대한 응답을 생성합니다. 머신 러닝을 위한 하위 주제를 생성해 보겠습니다. 이 셀을 실행하면 지도 학습, 비지도 학습, 강화 학습과 같은 하위 주제 목록이 반환됩니다. 다음으로 질문 생성기 함수를 사용하여 이러한 하위 주제에 대한 몇 가지 질문을 생성합니다. 이 단계는 모든 질문을 하나의 큰 목록으로 수집합니다. 그런 다음 Lama 3.1 405b 모델을 사용하여 목록에 있는 각 질문에 대한 두 가지 답변을 생성합니다. 이제 모든 것을 파악했으므로 질문과 응답 쌍을 사용하여 Neotron 4 340b 보상 모델을 통해 유용성, 정확성, 일관성, 복잡성, 상세도의 다섯 가지 속성에 따라 응답을 평가합니다. 샘플 데이터 포인트는 다음과 같습니다. 이 선호도 데이터 세트는 LLMS를 RLF DPO 또는 Nemo Steerm 기법과 정렬하는 데 사용할 수 있습니다. 이러한 기법을 사용하려면 설명란의 링크를 참조하십시오.
