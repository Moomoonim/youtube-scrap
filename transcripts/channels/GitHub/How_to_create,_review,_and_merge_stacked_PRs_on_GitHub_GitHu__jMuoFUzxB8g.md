UI, 즉 github.com에서 스택을 생성할 수 있다고 말씀하셨는데, 이제는 GitHub에서 사용할 수 있는 CLI도 생겼습니다. 혹시 아직 GitHub를 설치하지 않았거나 이전 버전을 사용 중인 분들을 위해, 터미널에서 CLI를 사용하려면 어떻게 해야 하는지 단계별로 설명해 주시겠어요? 스택 확장 프로그램 설치는 정말 간단합니다. 그러니까, GH 스택은 기존 GH CLI 위에 구축된 확장 기능일 뿐입니다 . 그러므로 터미널을 열고 GH extension install github/gh-stack이라고 입력하기만 하면 됩니다. 하지만 최신 버전을 사용하는 사람들은 GH 스택이라고 입력하기만 하면 자동으로 프로세스가 시작될 것입니다. 풀 리퀘스트를 제출할 때와 같은 절차를 그대로 진행해도 되는 거죠?
