NVIDIA Neotron Nano 모델에 대한 액세스 권한이 필요하며, 이는 로컬 또는 클라우드에 배포된 형태여야 합니다. 또한 bash 터미널이 설치된 운영 체제가 필요합니다 . 이는 우분투, 맥 OS 또는 윈도우용 리눅스 서브시스템일 수 있습니다. 또한, 파이썬 환경은 버전 3.10 이상이어야 하며 OpenAI 패키지가 설치되어 있어야 합니다. 선택적으로, Langraph를 사용하려면 Langchain OpenAI 및 Langraph 패키지도 설치되어 있는지 확인하십시오. 마지막으로, 약 한 시간 정도의 여유 시간이 필요합니다. 자, 이제 코드를 살펴보겠습니다. 주요 파일은 다음과 같습니다. 설정 파일은 시스템 설정, 에이전트를 구동하는 LLM 및 해당 매개변수, 그리고 허용된 명령 및 시스템 프롬프트와 같은 에이전트 구성을 정의합니다. 다음은 에이전트가 터미널을 통해 명령을 실행할 수 있도록 하는 bash 파일입니다 . 여기 있는 bash 클래스는 두 개의 공개 함수를 제공합니다. exit bash 명령어는 명령어를 입력받아 허용 목록과 비교한 후, 실행을 위해 비공개 run bash 명령어 함수에 전달합니다. 두 번째 공개 함수는 LLM에게 exec bash 명령 함수를 실행하는 방법을 알려줍니다. 명령 실행은 터미널에서 실행할 대상 명령을 입력으로 받는 비공개 bash 명령 실행 함수 내부에서 이루어집니다 . 이 명령은 마커와 pwd로 감싸진 다음 Python의 subprocess.run을 사용하여 실행됩니다. 이 기능은 출력 및 오류 스트림을 모두 캡처하고 작업 디렉터리를 업데이트합니다. 출력이 없으면 성공 메시지를 반환합니다. 오류가 발생하면 오류를 포착하여 깔끔하게 반환합니다. 이 함수는 항상 출력, 오류 정보 및 현재 작업 디렉터리를 포함하는 딕셔너리를 반환하며, 이는 에이전트가 다음 단계를 수행하는 데 필요한 모든 정보입니다. 다음은 두 가지 간단한 추상화를 도입하는 헬퍼 파일입니다. messages 클래스는 대화 기록을 추적하고 시스템 프롬프트, 사용자 입력, 어시스턴트 응답 및 도구 호출 결과를 저장합니다. 이는 상담원과의 상호작용 중에 맥락의 일관성을 유지하는 데 필요합니다 . LLM 클래스는 네이모트론에 요청을 보내고 응답을 분석하는 기능을 담당합니다. 이제 에이전트 루프를 처음부터 다시 구축합니다. 해당 구현은 이 파일 안에 있습니다. 구조는 간단합니다. 사용자 입력을 받아 네오트론으로 전송하고 응답에 도구 호출이 포함되어 있는지 확인합니다. 만약 그렇다면, 해당 요청을 bash 종료 명령 함수로 전달하십시오 . 그런 다음 결과를 다시 입력하고 반복합니다. 그렇지 않으면 응답을 반환하고 사용자의 다음 입력을 기다립니다. 마지막으로, Lang Graph를 사용하여 동일한 루프를 구성한 예시를 보여드리겠습니다 . Langraph의 `create react agent` 함수를 사용하여 Numatron 모델, bash 클래스 및 시스템 프롬프트를 연결합니다 . 이 함수는 사용자 입력, 명령 실행 및 결과 라우팅을 자동으로 처리하는 에이전트 객체를 반환하여 로직 및 오류 처리를 크게 단순화합니다. 그게 다입니다 . 처음부터 직접 개발한 맞춤형 컴퓨터 사용 에이전트입니다. 여기서 논의된 원칙들은 훨씬 더 발전된 에이전트에도 동일하게 적용됩니다. 그러니 한번 직접 실험해 보세요. 무엇이 가능한지 알아보세요. 아래 자료들을 참고하시거나, 개발자 포럼 또는 디스코드에서 저와 소통하며 여러분이 만든 것을 공유해 주세요. 당신이 어떤 결과물을 내놓을지 정말 기대돼요.
