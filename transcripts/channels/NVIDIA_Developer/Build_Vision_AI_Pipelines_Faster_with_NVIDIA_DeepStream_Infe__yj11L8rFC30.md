Gstreamer 코드를 작성하는 대신, 복잡한 과정을 건너뛰고 모델, 메타데이터, 그리고 비전 AI 애플리케이션 및 에이전트를 위한 파이프라인 사용자 정의에 집중할 수 있습니다 . 간단한 구성 파일로 시작하면 추론 파이프라인이 자동으로 생성되며, 선택적으로 오픈 API 사양도 추가됩니다. 추론 빌더는 재사용 가능한 템플릿과 표준 추론 흐름을 결합하여 마이크로 서비스 또는 애플리케이션을 생성합니다. 최종 파이프라인에는 모델 로딩, 전처리 및 후처리, 다중 모델 지원, 그리고 필요 에 따라 내장 API 서버 통합 기능이 포함됩니다 . Deepstream 추론 빌더를 사용하면 개발자는 이제 여러 백엔드 중에서 선택할 수 있으므로 새로운 가능성을 열 수 있습니다 . DeepStream 추론 백엔드를 사용하면 멀티 카메라 추적과 같은 고급 기능을 계속 사용할 수 있으며 실시간 메타데이터 출력을 위해 메시지 브로커를 연결할 수 있습니다. Tensor RTL LLM 또는 Triton 백엔드를 사용하면 파이프라인에서 GPU 가속 입력 및 출력을 통해 최첨단 AI 모델을 실행할 수 있습니다. DeepStream과 NVIDIA VSSS 비디오 검색 및 요약 청사진을 활용하여 비전 변환기, 오픈 소스 비전 모델, 비전 언어 모델을 사용하면 몇 분 만 에 새로운 생성형 AI 애플리케이션을 구축할 수 있습니다 . 간단한 예제를 통해 Deepstream Inference Builder 사용 방법을 살펴보겠습니다. 여기서는 정밀하게 조정된 실시간 결함 감지 변환기 모델을 사용하여 PCB 기판의 결함을 감지하겠습니다. 이 모델이나 다른 모델을 사용 사례에 맞게 미세 조정하는 방법에 대한 자세한 내용은 NVIDIA TO 6 및 NVIDIA DeepStream 8을 사용한 실시간 시각 검사 파이프라인 구축에 대한 기술 블로그를 참조하세요. 먼저 추론 빌더 GitHub 저장소를 살펴보겠습니다. 이 프로젝트는 완전한 오픈 소스이므로 개발자가 사용자 지정 템플릿과 기능을 쉽게 추가할 수 있습니다. 내부에는 지원되는 세 가지 백엔드를 포함한 모든 예제가 포함되어 있습니다. 샘플은 폴더 빌더 아래의 샘플 폴더에 있습니다. 빌더 샘플 스타일의 구성 파일을 검토해 보겠습니다. 이 파일의 기본 아이디어는 간단합니다. 첫 번째 섹션에서는 모델 저장소를 정의합니다. 이 경우, 기존에 세밀하게 조정된 모델을 저장하기 위해 캐시 폴더를 사용하겠습니다 . 입력 섹션에는 지원되는 입력 유형(이미지 또는 비디오)이 나열됩니다. 이 예시에서는 이미지를 사용하지만, 이 예시는 두 가지 모두를 지원하도록 준비되어 있습니다. 서버 섹션에서는 오픈 API 사양을 처리하는 방식을 정의합니다 . 저희는 API의 기본 구현을 제공하지만, 개발자가 자체 사양에 맞게 API 호출을 조정할 수 있도록 유연성을 제공합니다. 모델 섹션에서는 백엔드를 정의합니다. 이 예제에서는 딥 스트림 백엔드를 사용하겠습니다. 마지막으로 출력 섹션에서는 결과 처리 방식을 명시합니다 . 여기서는 모델이 생성한 메타데이터로 풍부하게 채워진 이미지를 생성합니다 . 자세한 내용은 관련 문서를 참조하십시오. 다음으로 터미널을 열어 보겠습니다. 먼저, 제가 세밀하게 조정한 모델 파일이 올바른 폴더에 있는지 확인해 보겠습니다 . 다음 단계는 애플리케이션을 구축하는 것인데 , 잠시 시간이 걸릴 것입니다. 추론 빌더 애플리케이션을 쉽게 테스트할 수 있도록 빌드 인자에 오픈 API 사양을 포함시켰습니다 . 빌드 프로세스가 완료되면 DeepStream 파이프라인은 압축 파일 형태로 제공됩니다. 이 경우 파일 이름은 toao입니다.
