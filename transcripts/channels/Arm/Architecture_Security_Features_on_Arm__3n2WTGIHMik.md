## 스크립트

ARM은 30년 이상 디지털 세계의 진화하는 아키텍처 요구 사항에 전념해 왔습니다. 모든 시스템과 보안 요구 사항은 고유하기 때문에 ARM은 업계 표준 아키텍처 보안 기능이 내장된 IP 빌딩 블록을 제공합니다. 이를 통해 단일 솔루션으로 모든 시스템에 적용하는 대신 계층형 보안을 구현할 수 있습니다. ARM의 아키텍처 보안 기능은 격리 기술, 방어적 실행 기술, 공통 플랫폼 보안 서비스의 네 가지 범주로 나뉩니다. 격리 기술은 명확하게 정의된 보안 경계를 적용하는 데 도움이 됩니다. 방어적 실행 기술은 실행 시점의 취약점을 방어하여 제어 흐름 공격, 데이터 액세스 공격 및 사이드 채널 공격으로부터 보호합니다. 공통 플랫폼 보안 서비스는 하드웨어 신뢰를 간소화하고 비용을 절감하며 장기적인 안정성을 보장합니다. 표준 보안 API를 통해 애플리케이션은 플랫폼 보안 서비스에 액세스할 수 있습니다.
