## 스크립트

이 비디오에서는 변수를 사용하여 Operator Terminal Expert에서 객체의 표시 여부를 제어하는 ​​방법을 보여드리겠습니다 . 기본적으로 운영자 터미널 전문가의 표시 범위는 다음과 같이 작동합니다. 0은 보이고, 1은 숨겨져 있으며, 2는 접혀 있습니다. 가시성을 제어하는 ​​방법에는 두 가지 옵션이 있습니다. 하나는 스크립트를 사용하고, 다른 하나는 변환기를 사용합니다. 저는 변환기 방식을 선호합니다. 여러 번 재사용할 수 있기 때문입니다. 하지만, 프로젝트에 가장 적합한 방식을 선택하세요 . 먼저 변환기 솔루션부터 시작하겠습니다. 먼저 변환기 섹션으로 이동하여 새 범위 변환기를 만듭니다. 우리는 이것을 가시성이라고 부를 겁니다. 다음으로 소스 데이터 유형을 부울로 구성하겠습니다. 정수형 변수를 사용하는 경우 숫자형일 수도 있습니다. 결과 데이터 유형은 Boolean입니다. 다음으로 범위 정보를 확장합니다. 첫 번째 범위의 경우 데이터 출력을 true로 수정하겠습니다. 나머지 설정은 모두 기본값으로 두겠습니다. 자, 이제 이를 테스트하기 위해 첫 번째 화면에 스위치와 객체를 추가해 보겠습니다. 먼저, 가시성을 제어하기 위해 부울 변수를 토글하도록 스위치를 구성하겠습니다 . 이 예시에서 변수는 ' 이 컨트롤'이라고 합니다. 다음으로 객체의 표시 여부를 설정합니다 . 모양을 선택한 다음 크기를 지정하여 변수를 가시성 애니메이션에 바인딩합니다. ' 가시성' 옆의 흰색 사각형을 클릭하고 '변수'를 선택하세요. 변수 선택 화면에서 가시성 변수를 선택하고 방향을 단방향으로 변경한 다음 변환기 확인란을 활성화하고 생성한 가시성 변환기를 선택합니다. 이제 시뮬레이션을 실행하고 테스트를 진행합니다. 보시다시피, 이제 스위치를 사용하여 객체의 표시 여부를 제어할 수 있습니다 . 이 방법의 장점은 동일한 변환기를 여러 객체 또는 인스턴스에 사용할 수 있다는 것입니다. 두 번째 해결책은 스크립트를 사용하는 것입니다. 먼저 객체의 가시성 애니메이션을 bool 변수에 바인딩합니다. 이 예시에서 변수 이름은 vis script입니다. 정수 변수를 사용하여 가시성을 제어하려면 스크립트를 작성해야 합니다. 우리가 모니터링할 변수의 이름은 var one이며, 이 예시에서는 변수 값이 8이면 객체를 표시하고, 다른 값이면 객체를 숨깁니다 . 먼저 var one 변수를 사용하여 값 변경 트리거를 추가하는 것으로 스크립트를 시작합니다 . 그다음에는 if-else 블록을 추가합니다. if 문 안에서 비교를 하는데, var1이 8이면 Vis 스크립트를 수정하여 변수 값을 재설정합니다. else 조건의 경우, 또 다른 bool 값 변경을 추가하는데, 이번에는 Vis 스크립트를 변수에 설정하기 위해서입니다. 이제 숫자 표시를 사용하여 var1 변수를 제어하는 ​​​​방법을 테스트해 보겠습니다. 자 , 이제 시뮬레이션을 실행해 보겠습니다. 기본적으로 로드될 때는 표시되지만, 변수 값을 변경하기 시작하면 제대로 작동하는 것을 확인할 수 있습니다. 변수 값이 8일 때는 표시되지만, 다른 값일 때는 표시되지 않습니다 .
