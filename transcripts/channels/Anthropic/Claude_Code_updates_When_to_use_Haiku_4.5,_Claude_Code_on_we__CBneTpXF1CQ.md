## 스크립트

클로드 코드(Claude Code)가 이제 웹에서 이용 가능합니다. 따라서 터미널을 열거 나 IDE를 실행하지 않고도 이제는 브라우저나 Claude 모바일 앱에서 직접 코딩 작업을 위임할 수 있습니다. GitHub 계정을 연결하고, 저장소를 선택하고, 필요한 작업을 설명하기만 하면 Claude가 나머지를 모두 처리합니다. 모든 작업은 당사의 클라우드 인프라에서 실행됩니다. 그리고 가장 좋은 점은 이제 여러 저장소에서 여러 작업을 병렬로 실행할 수 있다는 것입니다 . 따라서 버그 백로그가 있든, 일상적인 수정이 필요하든, 아니면 새롭고 훌륭한 아이디어나 기능을 추가하고 싶든, 세션을 하나 또는 여러 개 실행하여 Claude가 동시에 처리하도록 할 수 있습니다. 이게 어떻게 작동하는지 보여드리겠습니다. 그럼, claude.ai/code에서 클로드 코드 웹사이트를 열어보겠습니다 . 저장소를 선택하겠습니다. 이미 저장소를 선택했으니, 이제 프롬프트를 표시하겠습니다. 예를 들어, "사용자 등록 엔드포인트에 입력 유효성 검사를 추가하세요 . 또한 프런트엔드 와 백엔드 API 모두에서 강력한 비밀번호를 사용하도록 하세요."라고 말해 보겠습니다. 엔터 키를 누르면 이제 시작입니다 . Claude는 완전한 Git 접근 권한을 가진 자체 격리된 샌드박스에서 작업 중이며, 우리는 진행 상황을 실시간으로 확인할 수 있습니다. 하지만, 이 방송이 진행되는 동안, 저희가 최근에 출시한 다른 몇 가지 기능에 대해 말씀드리겠습니다 . 가장 큰 건 클로드 하이쿠 4.5입니다. 그리고 몇 주 전에 저희는 세계 최고의 코딩 모델이 된 클로드 소네 4.5를 출시했습니다. 그리고 바로 지난주에, 저희는 클로드 하이쿠 4.5를 공개했습니다. 그리고 정말 놀라운 점은 바로 이것입니다. 5개월 전만 해도 소네트 4는 최첨단 기술이었습니다. 이제 Haiku 4.5는 1/3의 비용으로 두 배 이상의 속도로 비슷한 코딩 성능을 제공합니다. 심지어 컴퓨터 사용과 같은 특정 작업에서는 소네트 4를 능가하기도 합니다. 이제, 기준치는 인상적입니다. SweetBench에서 73.3%, TerminalBench에서 41%의 검증된 성능을 보였으며, 에이전트 코딩 평가에서는 Sonnet 4.5 성능의 90%를 달성했습니다 . 하지만 여러분이 가장 궁금해하는 것은 아마도 개발자들이 언제 Haiku 4.5를 사용해야 하는지일 것입니다. 우리 커뮤니티에서 나타나는 큰 패턴은 Sonnet 4.5가 고수준의 문제 분해 및 계획을 수행하고, Haiku 4.5는 실제 구현 및 코드 작성에 사용된다는 것입니다. 현재 이러한 다중 에이전트 접근 방식은 대규모 리팩토링이나 기술 부채 해결과 같은 작업에서 매우 인기를 얻고 있습니다. Haiku 4.5는 Claude를 구매하는 곳이라면 어디에서든 이용 가능하며, 입력 토큰 백만 개당 1달러, 출력 토큰 백만 개당 5달러에 구매할 수 있습니다. 좋습니다, 그럼 우리가 맡은 일이 어떻게 진행되고 있는지 다시 한번 확인해 봅시다. [음악] 자, 여기를 열어보면 클로드가 service.go 파일과 프런트엔드의 타입스크립트에서 변경된 모든 내용을 잘 요약해 놓은 것을 볼 수 있습니다. 그리고 제가 웹 버전 클로드 코드에서 가장 좋아하는 기능은 바로 이 CLI에서 열기 버튼입니다. 제가 이 도구를 정말 좋아하는 이유는 간단히 클릭해서 터미널을 열고, 제공된 명령어를 붙여넣기만 하면 웹에서 진행했던 모든 컨텍스트와 작업 내용이 그대로 유지된 채로 로컬 개발 환경에서 작업할 수 있기 때문입니다. 그래서 저는 메시지도 볼 수 있고 , 변경된 파일도 모두 볼 수 있습니다 . VS Code에 들어가면 서비스, 회원가입, signup.typescript 파일 등에 적용된 모든 변경 사항을 확인할 수 있습니다. 그리고 휴대폰이나 웹 브라우저에서 중단했던 부분부터 이어서 작업을 계속할 수 있습니다. 자, 이제 Claude Code에 최근 추가된 마지막 기능을 보여드리겠습니다 . 제가 이전에 제 애플리케이션에 캐싱을 추가하고 싶다고 언급하면서 이런 요청을 했었는데, " 제 애플리케이션에 캐싱을 추가하고 싶습니다."라고 너무 포괄적으로 요청했던 것 같습니다. 클로드 코드(Claude Code)는 구현이 정확한지 확인하기 위해 몇 가지 후속 질문을 할 것입니다. 그러면 여기서 캐싱 수준을 묻게 될 겁니다 . 음, 데이터베이스 쿼리 캐싱이라고 해야 할까요, 아니면 API 응답 캐싱이라고 해야 할까요? 그리고 저는 이 중에서 아무거나 골라서 다음 섹션으로 넘어가 제 목표가 무엇인지 파악할 수 있습니다 . 성능 향상이나 데이터베이스 부하 감소를 위한 것인가요? 목표 영역은 운동 데이터, 사용자 데이터, 분석 데이터 중 어느 것입니까? 사용할 기술을 선택하세요. Redis, 인메모리, Postgres 중에서 고르세요. 그런 다음 제출 버튼을 누르면 제가 제공한 후속 정보를 바탕으로 구현이 진행됩니다. 자, 이제 아시겠죠? Claude Code는 집이나 이동 중에도 클라우드 기반의 병렬 개발을 지원하는 웹 기반 코드 개발 플랫폼입니다. Haiku 4.5는 훨씬 저렴한 비용으로 초고속 코딩을 지원하며, 다중 질문 지원 기능을 통해 더욱 스마트한 로컬 워크플로우를 제공합니다. Claude Code 웹 버전은 Pro 및 Max 사용자라면 claude.ai/code에서 지금 바로 이용할 수 있습니다. 한번 사용해 보시고 어떻게 생각하시는지 알려주세요 . 즐거운 건축 되세요. [음악]
