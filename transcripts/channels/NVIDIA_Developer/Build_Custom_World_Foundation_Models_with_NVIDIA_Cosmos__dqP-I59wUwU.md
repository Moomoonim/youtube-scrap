## 스크립트

최근 엔비디아는 휴머노이드 로봇 및 자율 주행 차량과 같은 물리적 AI 애플리케이션 개발을 가속화하는 세계 기반 모델 플랫폼인 코스모스(Cosmos)를 발표했습니다. 안녕하세요, 저는 모란 무미입니다. 5분 안에 코스모스 확산 텍스트-세계 모델을 시작하는 방법을 보여드리겠습니다. 자신 만의 텍스트 프롬프트를 사용하여 비디오를 생성하는 방법 과 Nemo 프레임워크를 사용하여 생성 목표에 맞게 이 모델을 사용자 정의하는 방법을 보여드리겠습니다. 코스모스 세계 기반 모델은 빌드에서 사용해 볼 수 있습니다. nv.com에서 입력 이미지 또는 비디오를 기반으로 미래 비디오 프레임을 예측하는 자동 회귀 모델을 사용해 볼 수 있습니다. 이미지 또는 텍스트 프롬프트에서 비디오를 생성하는 확산 모델도 사용해 볼 수 있습니다. 이러한 모든 모델은 다운로드하여 모든 가속 플랫폼에서 사용할 수 있습니다. 이러한 모델을 로컬에서 사용하려면 API 키를 통해 NVIDIA 컨테이너 레지스트리에 액세스해야 합니다. 계정이 없으면 nc.com에서 생성할 수 있습니다. nvidia.com에서 API 키를 발급받아야 합니다. 코스모스 모델 및 기타 종속성을 다운로드 하려면 유효한 허깅 페이스(Hugging Face) API 키도 필요합니다. 시작하는 데 필요한 모든 것은 코스모스 GitHub 저장소에서 확인할 수 있습니다. 이제 명령 줄에서 프로세스를 살펴보겠습니다. 먼저 NVIDIA 컨테이너 레지스트리에 로그인해야 합니다. 사용자 이름은 달러 기호($)로 시작하는 'OA token'을 사용하고, 비밀번호에는 발급받은 API 키를 입력합니다. 컨테이너 레지스트리 인증 후 코스모스 GitHub 저장소를 클론하고 작업 디렉토리를 변경합니다. 다음으로 허깅 페이스 API 키를 저장할 'HF token'이라는 환경 변수를 생성합니다. 이제 다음 Docker 명령어를 실행하여 코스모스 Nemo 컨테이너를 시작할 준비가 되었습니다. 이 명령어는 나중에 필요한 환경과 경로를 설정하고 컨테이너를 시작합니다. 컨테이너 셸에 접속하면 작업 디렉토리를 Cosmos로 변경합니다. 이제 다운로드 스크립트를 실행하여 코스모스 확산 모델을 다운로드해 보겠습니다. 여기 보이는 것처럼 시간이 좀 걸릴 겁니다. 이제 Cosmos Diffusion 7B Text to World 모델을 사용하여 텍스트 프롬프트에서 비디오를 생성해 보겠습니다. 이를 위해서는 80GB 비디오 메모리를 가진 NVIDIA GPU 하나가 필요합니다. 환경 변수를 몇 개 생성해야 하는데, 첫 번째 변수는 추론에 단일 GPU를 사용하도록 지정하고, 두 번째 변수는 텍스트- 비디오 프롬프트를 지정합니다. 여기서는 모델에게 청록색 로봇이 부엌에서 일하는 비디오를 생성하도록 프롬프트를 지정합니다. 다음으로 추론 명령을 입력합니다. 이 명령은 추론을 실행할 모델과 텍스트 프롬프트, 그리고 생성된 비디오의 파일 이름을 지정합니다. 이 명령을 실행하는 데 시간이 좀 걸릴 겁니다. 방금 생성된 비디오를 살펴보겠습니다. 모델이 청록색 로봇의 모습을 미리 알고 있는 지식을 활용하여 이 비디오를 생성한 것을 볼 수 있습니다. 다음으로 특정 주제에 대한 비디오 모음을 사용하여 주제 기반 비디오 생성을 위해 이 모델을 사용자 정의하는 방법을 보여드리겠습니다. 이 모델을 적용하여 새로운 환경 에서 해당 주제의 비디오를 생성할 수 있습니다. 학습 후 이 모델에는 8GB의 메모리가 필요하다는 점을 기억하세요. 80GB 메모리를 갖춘 NVIDIA GPU를 사용하면 NVIDIA Nemo Curator를 사용하여 데이터를 처리할 수 있습니다. Nemo Curator는 의미론적으로 유의미한 클립을 생성하여 사후 학습을 지원합니다. 데모 Curator를 사용하지 않으려면 다음 단계로 넘어가세요. Nemo Curator를 사용하여 데이터를 처리하는 데 필요한 샘플 데이터 세트를 보여드리겠습니다. Cosmos 데이터 큐레이션 Jupiter 노트북으로 이동합니다. 다음 경로에서 최소 하드웨어 요구 사항을 충족하는지 확인한 후 Curator 명령줄 인터페이스를 설정합니다. 먼저 이 셀을 실행하여 필요한 환경 변수를 설정해 보겠습니다. 다음 셀을 실행하여 Hugging Face에서 샘플 데이터 세트를 다운로드합니다. 이 샘플 데이터 세트에는 주제 기반 생성에 사용되는 몇 가지 비디오 클립이 포함되어 있습니다. 방금 다운로드한 클립 중 하나를 살펴보겠습니다. 이 클립에서는 청록색 로봇이 주방에서 작업하는 모습을 볼 수 있습니다. 이 청록색 로봇은 사후 학습 후 주제 기반 생성의 참조 주제가 됩니다. 다음으로 Hugging Face 자격 증명을 설정하고 데이터 큐레이션 실행에 필요한 모델을 다운로드합니다. Nemo Curator는 이러한 모델을 사용하여 데이터를 분석합니다. 다음 셀에서는 비디오 파일을 클립하고 캡션을 추가하는 방법을 보여주지만, 여기서는 캡션 없이 비디오를 클립하는 다음 셀을 실행하겠습니다. 입력 비디오의 경로와 결과를 저장할 출력 경로를 지정합니다. 또한 5초 간격의 고정 스트라이드 분할 알고리즘을 사용하도록 지정합니다. 이는 Nemo Curator에게 입력 데이터를 사용하여 의미적으로 유의미한 5초 길이의 비디오 클립을 여러 개 생성하도록 지시합니다. 이 작업은 약 1분 정도 소요되며, 결과는 지정한 출력 경로에서 확인할 수 있습니다. 원시 데이터 환경 변수를 이 경로를 가리키도록 설정하면 이 클립을 사용하여 실습을 진행할 수 있습니다. 다시 명령줄로 돌아가 보겠습니다. Nemo Curator를 사용하지 않은 경우, 이전에 보여드린 샘플 데이터 세트를 명령줄에서 다운로드할 수 있습니다. 다음 명령을 실행하여 데이터를 로컬에 다운로드하세요. 학습 후 처리를 시작하기 전에 비디오 파일을 전처리하고 Cosmos 토크나이저를 사용하여 임베딩을 생성해야 합니다. 먼저 환경 변수를 정의합니다. 사용할 비디오 클립을 가리키는 환경 변수를 정의하고, 임베딩을 저장할 위치를 지정하는 또 다른 환경 변수를 정의합니다. 그런 다음 준비된 데이터 세트 스크립트를 실행합니다. 이 스크립트를 실행하려면 임베딩 생성에 사용할 텍스트 프롬프트를 지정합니다. 프롬프트에서 특수 토큰 SKS를 사용하는 것에 유의하세요. 이 토큰은 모델이 알아야 할 주제의 이름을 지정하고, 학습 후 주제 중심 비디오를 생성하는 데 도움이 됩니다. 또한 각 비디오에서 샘플링할 청크 수를 지정합니다. 이는 임베딩에 포함될 학습 샘플 수를 결정합니다. 숫자가 높을수록 학습 샘플 수는 많아지지만 학습 시간도 길어지므로 필요에 따라 이 값을 조정하세요. Nemo Curator에서 생성된 클립을 사용하는 경우 10에서 50 사이의 값으로 설정하는 것이 좋습니다. 이제 스크립트를 실행하여 Cosmos 토크나이저에서 임베딩을 가져옵니다. 지정한 청크 수에 따라 완료하는 데 시간이 다소 걸릴 수 있습니다. 이제 학습 프로세스를 시작하는 데 필요한 모든 것이 준비되었습니다. 다음으로 환경 변수에 사용 가능한 GPU 수를 정의하고 학습을 시작합니다. 이 스크립트에서는 작은 학습률을 사용하여 1,000단계 동안 실행합니다. 이 정도면 목적에 충분할 것입니다. 학습이 완료되면 원래 텍스트 프롬프트를 사용하여 모델이 틸 로봇에 대해 학습한 후 비디오를 생성할 수 있습니다. 이 절차는 앞서 보여드린 것과 동일합니다. 생성된 비디오를 살펴보겠습니다. 학습 전후에 생성된 비디오를 비교해 보면, 모델이 틸 로봇에 대한 새로운 이해도를 바탕으로 시각적으로 매력적이고 맥락적으로 정확한 결과를 제공함을 알 수 있습니다. 이것으로 코스모스 확산 모델을 사용하여 추론을 사용자 정의하고 실행하는 방법에 대한 간략한 설명을 마치겠습니다. 설명란 에 있는 자료를 활용하여 지금 바로 시작해 보세요.
