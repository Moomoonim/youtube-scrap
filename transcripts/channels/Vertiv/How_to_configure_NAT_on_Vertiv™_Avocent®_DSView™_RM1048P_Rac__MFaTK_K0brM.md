## 스크립트

이 항목에서는 Verdive DSV 솔루션 RM1048N의 구성에 대해 다룹니다. 이번 세션에서는 NAT의 작동 방식, IP 풀 설정 방법, NAT 규칙 구성 방법, 그리고 연결된 서비스 프로세서에 대한 외부 액세스 확인 방법을 살펴보겠습니다. NAT(네트워크 주소 변환)는 일반적으로 192.168.10과 같은 IP 주소를 사용하는 RM1048의 내부 네트워크에 연결된 장치가 라우팅 가능한 IP 주소를 사용하여 외부 네트워크에서 액세스할 수 있도록 합니다. 이는 VKVM, SSH 또는 웹 인터페이스와 같은 원격 세션을 서비스 프로세서에 연결하는 데 필수적입니다. 먼저 RM1048 웹 인터페이스에 로그인하십시오 . 다음으로 왼쪽 사이드바에서 네트워크 구성으로 이동하여 IP 풀을 선택합니다 . 더하기 아이콘을 클릭하여 새 풀을 추가하세요. IP 범위1을 선택하고 라우팅 가능한 IP 블록을 정의하십시오. 그런 다음 '추가'를 클릭하여 풀을 저장하세요. 이제 네트워크 구성에서 대상 포트 매핑을 선택하십시오. 여기서는 내부 포트를 IP 풀의 외부 IP에 매핑하여 NAT 규칙을 할당합니다 . 이를 통해 외부 시스템은 NAT를 통해 내부 장치에 접근할 수 있습니다. 최신 ILO 장치의 경우 포트 443에 대한 대상 포트 매핑을 생성할 필요가 없다는 점에 유의해야 합니다. 구형 ILO 및 IDRA 장치의 경우 대상 포트 매핑을 5900으로 유지해야 합니다 . IP 풀과 대상 포트 매핑이 구성되었으므로 이제 NAT 설정 탭을 선택하십시오. NAT 설정 페이지의 오른쪽 상단에서 더하기 기호를 선택합니다. 팝업 메뉴에서 외부 IP에 매핑할 대상 장치를 선택합니다. 계속을 선택하세요. 다음 페이지에서 IP 풀에서 외부 IP 주소, 외부 포트 및 대상 포트를 입력하십시오. 클라이언트 IP 주소와 만료일을 입력하는 옵션도 있습니다. 이제 추가를 선택하세요. NAT 설정 페이지에서 새로운 구성을 확인하실 수 있습니다. 대상 IP 주소 와 외부 IP 주소를 기록해 두세요. 테스트하려면 외부 IP 주소를 브라우저에 입력하세요 . 목표 웹페이지를 받게 될 것입니다. 이제 NAT IP를 사용하여 외부에서 서비스 프로세서에 액세스할 수 있습니다. 참고로 NAT 기능은 RM1048 모델에서만 사용 가능합니다 . RM1048이 MP1000에 등록된 경우 NAT는 계속 작동하지만 모든 구성은 RM1048에서 직접 수행해야 합니다 . 또한 RM1048을 등록 해제하면 사용자 지정 IP 풀 및 NAT 규칙이 삭제될 수 있으며 다시 구성해야 합니다. 이것으로 RM1048의 Mac 설정에 대한 영상 시청을 마치겠습니다 . 이러한 단계를 따르면 외부 네트워크에서 서비스 프로세서에 안전하고 효율적으로 액세스할 수 있습니다 .
