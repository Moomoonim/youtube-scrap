Tron 3 Nano를 교육용 모델로 사용하겠습니다. 로컬에 배포하거나 클라우드 제공업체를 통해 액세스할 수 있습니다. 다음은 llama.cpp를 통해 이 모델을 로컬에 배포하는 데 사용한 명령어입니다 . 이 점을 염두에 두고, 우리가 실제로 무엇을 만들지 살펴보겠습니다. 이 워크플로의 첫 번째 단계는 합성 데이터 생성입니다. 우리는 먼저 시드 데이터셋을 이 블록은 추론 및 데이터 생성을 위한 모델 엔드포인트의 위치를 ​​시스템에 알려줍니다. 여기서는 공급자 이름을 지정합니다 . 저는 그것을 로컬 모델 제공자라고 부르고 해당 엔드포인트의 URL을 제공하겠습니다. openrouter 또는 build.nvidia.com과 같은 원격 모델 제공업체를 사용하는 경우 API 키를 추가할 수도 있습니다. 다음으로 모델 NeMo Tron 모델에서는 적절한 키워드 인수를 전달하여 사고 모드를 활성화합니다 . 이제 합성 예제를 생성하는 데 사용될 시드 데이터셋을 추가하겠습니다 . 포옹하는 얼굴 데이터셋 블록을 추가하고 데이터셋 저장소를 지정합니다 . 이 경우에는 Onslaught Alpaca Clean 데이터셋을 사용합니다. 로드 버튼을 클릭하면 데이터를 미리 볼 수 있습니다 . 합성 데이터 생성 워크플로에서는 원래 출력 열을 삭제할 것입니다. 대신, 우리는 교사 모델이 생성한 새로운 출력값으로 그것을 대체합니다. 다음으로 LLM 텍스트 블록을 추가합니다. 이 블록은 모델과 프롬프트 템플릿을 사용하여 새로운 데이터를 생성합니다 . 먼저 이 블록의 출력에 이름을 지정합니다. 이 경우 '추론 추적'이라고 합니다. 이 중간 열을 최종 또한 일괄 생성을 구성할 수 있으므로 문제가 발생할 경우 실행의 안정성이 향상됩니다. 모든 설정이 완료되면 생성 작업을 시작합니다. 이 과정은 모델과 데이터셋 크기에 따라 다소 시간이 걸릴 수 있습니다. 실행이 완료되면 생성된 기록을 검사하여 학습 단계로 넘어가기 전에 출력 결과가 올바른지 확인할 수 있습니다 . 모델을 학습시키려면 스튜디오 탭으로
