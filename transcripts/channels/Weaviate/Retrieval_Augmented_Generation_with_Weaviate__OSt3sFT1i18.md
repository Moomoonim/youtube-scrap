## 스크립트

안녕하세요, 저는 VV8의 필립입니다. VV8로 제작된 새로운 시리즈에 오신 것을 환영합니다. 이 시리즈에서는 최신 오픈 소스 기여 프로젝트와 라이브 데모를 자세히 살펴보고, 더 나은 머신 러닝 파이프라인을 구축하기 위한 유용한 팁과 기술을 소개합니다. 이번 에피소드에서는 더 나은 검색 및 인자 생성 파이프라인을 위한 팁을 공개합니다. Rack은 대규모 언어 모델을 활용하고 모델의 오류를 줄여 더욱 정확한 출력과 더 나은 결과를 얻을 수 있도록 도와줍니다. Vivid는 오픈 소스를 사랑하며 여러분의 개발 과정을 더욱 편리하게 만들기 위해 매일 열심히 노력하고 있습니다. 애플리케이션과 머신 러닝 파이프라인 개발은 때때로 어려울 수 있으며, 오류나 문제에 직면하기도 합니다. 또한 새로운 API나 프레임워크를 배워야 하는 경우도 많습니다. VV8을 처음 접할 때도 새로운 것을 배우는 과정입니다. Vivid 오픈 소스 제품군에 새롭게 추가된 Verbal을 소개합니다. Verbal은 최고의 Rack 검색 도구로서 Vivid를 사용하여 더 빠르게 개발할 수 있도록 도와줍니다. VV8뿐만 아니라 다른 프레임워크에서도 사용할 수 있으며, 사용자가 직접 데이터를 가져와 필요에 맞게 조정할 수 있습니다. 오픈 소스이기 때문에 완벽하게 맞춤 설정이 가능하며, 개발에 도움이 되도록 이미 포함된 데이터와 함께 제공됩니다. Next.js용 Versal, Cohere, Hugging Face, Open AI, Weber는 내부적으로 어떤 작업을 수행할까요? Weber는 소위 ' Rack Retrieval Augmented Generation' 아키텍처를 사용합니다. 이 아키텍처는 LLM이 더 나은 결과를 생성하도록 돕고, 모델을 재학습해야 하는 시간 범위를 줄이거나 학습 데이터가 끝난 후 발생하는 이벤트에 대한 컨텍스트를 제공하는 데에도 도움이 됩니다. 예를 들어 Chat GPT를 보면 지식 범위 또는 소위 지식 차단(knowledge cutoff)이 고정되어 있어 2021년 9월 이후 발생한 이벤트에 대한 학습 데이터를 모델이 학습하지 못했습니다. 또한 Rec는 모델이 허구적인 내용을 만들어내는 문제, 즉 모델이 사실을 왜곡 하거나 현실을 반영하지 못하는 경우를 줄이는 데에도 도움이 됩니다. 모델이 무언가를 지어내지만 사용자에게는 그럴듯하게 들리고, 사실 확인 없이는 문제가 발생할 수 있습니다. 검색 증강 생성은 어떻게 작동할까요? 예를 들어 사용자가 "vv8이 무엇인가요?"라고 묻는 경우, 회사 지식 기반과 같은 내부 소스에서 관련 문서와 정보를 검색합니다. 그런 다음 이 정보를 LLM에 컨텍스트로 전달하여 질문에 대한 답변을 생성합니다. 정답은 100% 맞습니다. 왜냐하면 vv8은 인류에게 알려진 가장 멋진 벡터 데이터베이스이기 때문입니다. 또한 Rec는 머신 러닝 파이프라인의 모든 문제점을 해결하는 만능 해결책이 될 수 없습니다. 따라서 종종 랙과 GPT를 조합하여 미세 조정하는 하이브리드 접근 방식이 최첨단 결과를 가져올 수 있습니다. 이제 Verbal Verba를 자세히 살펴보겠습니다. Verba는 모든 vva 문서와 함께 기본적으로 제공됩니다. 여기에는 내부 및 외부 문서, vv8 관련 엔지니어링 블로그 게시물, YouTube 동영상 스크립트 등 Vivid를 사용하여 더 빠르게 개발하는 데 도움이 되는 모든 자료가 포함됩니다. 유용한 코드 스니펫도 출력합니다. Verba를 얼마나 쉽게 사용할 수 있는지, 그리고 개인적인 필요에 맞게 어떻게 변형하고 자체 데이터를 가져올 수 있는지 알아보겠습니다. verbal.vv8.io로 이동하여 Verba, 즉 Golden Wreck Retriever와 상호 작용해 보세요. Vivid로 초고속 개발을 도와줄 새로운 친구 Verba를 소개합니다. Verba는 프런트엔드에서 Next.js를 사용하고, 백엔드에서는 vv8과 GPT를 사용하여 구축되었습니다. 간단한 것부터 시작해 보겠습니다. 재귀를 사용하고 Verba에게 자신이 무엇이라고 생각하는지 물어봅니다. 기계 속의 유령을 보게 될까요? 인공 일반 지능(AGI)을 탐구하게 될까요? Verba는 설명을 제공할 뿐만 아니라 기계 세계 지배를 주장하지도 않으므로 인류는 적어도 조금 더 오래 살아남을 수 있습니다. Verba의 출력 내용을 살펴보고 정보 의 잠재적 출처를 찾아 더 흥미로운 통찰력을 얻을 수 있습니다. 이제 본격적인 작업에 들어가 보겠습니다. Vivade를 처음 접하는 우리는 Python 에서 VVS 근접 텍스트 기능을 사용하는 방법을 알고 싶어합니다. Verba가 답변과 관련 코드 스니펫을 제시합니다. 정말 멋지죠? 이제 이 코드 스니펫을 필요에 맞게 파이프라인에 적용할 수 있습니다. 가장 좋은 점은 이 라이브 데모를 사용하여 Verba에게 VV8에 대해 궁금한 점을 무엇이든 물어볼 수 있다는 것입니다. 사실 우리는 Verba를 사용하여 Verba 자체를 구축했습니다. 얼마나 거울 같나요? 아마도 차세대 Verba를 Verba Disconnect Edition이라고 부를 수 있을 것 같습니다. 데모가 마음에 드셨나요? Verba를 여러분의 컴퓨터에 설치하고 필요에 맞게 사용자 정의해 보세요. Verba는 오픈 소스이므로 모든 코드를 GitHub에 공개합니다. 경고: 이 예제에 표시된 코드는 다소 오래되었을 수 있으므로 GitHub 저장소를 주시하십시오. Robot 설치는 매우 간단하게 pip install만으로 완료할 수 있도록 설계했습니다. Verbal을 로컬에서 실행하고 싶을 때는 언제든지 vv8 embedded를 사용할 수 있으므로 인프라를 구축하거나 클라우드 또는 Docker 컨테이너를 통해 Viviate를 사용할 필요가 없습니다. 시작하려면 Python 3.9 이상이 설치되어 있는지 확인하십시오. 프로젝트를 위한 새로운 가상 환경을 생성하는 것이 좋습니다. 터미널에 `pip install golden rack`을 입력하고 Enter 키를 누르십시오. 다음으로, Open API 키를 ` open API key`라는 환경 변수로 설정해야 합니다. 현재 Verba는 Open AI 모델만 지원하지만 향후 더 많은 모델 제공업체를 통합할 예정입니다. 모든 준비가 완료되면 데이터를 가져오겠습니다. Open AI API 문서를 예시로 사용하겠습니다. 터미널에 ` verber import dash dash pass data slash open AI`를 입력하십시오. 이렇게 하면 파일이 vv8에 가져와집니다. Viviate embedded는 백그라운드에서 원활하게 실행되므로 걱정하지 마십시오. 데이터가 가져와지면 ` verb` 또는 `start` 명령으로 Verba를 실행하십시오. 로컬 호스트를 통해 로컬에서 액세스할 수 있습니다. 축하합니다! 로컬 머신에 Verbo를 성공적으로 설치하고 사용자 지정 데이터를 가져왔습니다. 이제 Verbo에게 OpenAI의 새로운 함수 호출 방식에 대해 물어보겠습니다. Verbo가 다른 프레임워크나 라이브러리와 어떻게 통합되는지 궁금하실 수도 있습니다. Verbo는 유연하고 모듈식으로 설계되었으며, 현재는 VV8의 네이티브 기법에 최적화되어 있지만 Haystack, Llama, Index, Linkcham 등과 같은 인기 라이브러리와도 쉽게 통합되도록 설계되었습니다. Verbo가 어떻게 구축되었는지 간단히 살펴보겠습니다. 먼저 데이터를 로드하고 텍스트 및 마크다운과 같은 다양한 파일 형식을 지원합니다. 그런 다음 가장 많이 사용되는 NLP 라이브러리인 Spacey를 사용하여 데이터를 청크하고 더 작은 부분으로 나눕니다. 그 후 데이터를 VV8에 입력합니다. 로딩 및 청크 분할 부분은 모두 사용자 정의할 수 있습니다. 이제 Verbo에게 VV8이 무엇인지 물어보겠습니다. VV8은 가져온 데이터에서 관련 청크를 찾기 위해 하이브리드 검색을 사용합니다. 즉, 기존 텍스트 검색과 벡터 검색을 결합한 것입니다. 검색 성능을 향상시키기 위해 사용하는 기술 중 하나인 청크 윈도우 접근 방식을 살펴보겠습니다. 각 청크의 주변 정보를 LLM의 컨텍스트에 연결함으로써, 해당 정보가 연결될 확률이 높고 최종 사용자에게 더 나은 답변을 제공하는 데 관련성이 높을 경우 결과 개선에 도움이 됩니다. 이렇게 얻은 컨텍스트와 사용자 쿼리는 OpenAI로 전송되어 답변을 생성합니다. 앞으로 Verbal에 이러한 검색 및 랙 최적화 기능을 더욱 추가할 예정이며, Verbal은 오픈 소스이므로 오픈 소스 vv8 패밀리의 일원이 되어 주시면 감사하겠습니다. Verbal에 대한 짧은 소개를 즐겁게 시청하셨기를 바랍니다. 개선 사항이나 추가해야 할 새로운 기능에 대한 아이디어가 있으시면 GitHub 저장소에 이슈를 등록 하거나 메시지를 보내주세요. Weber는 사용자별 컨텍스트와 관련성 있는 출력이 필요한 모든 애플리케이션에서 bv8을 사용하여 더 빠르게 구축할 수 있는 새로운 진입점이 될 것입니다. 시청해 주셔서 감사합니다. 다음 영상에서 뵙겠습니다.
