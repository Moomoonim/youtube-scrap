## 스크립트

이 튜토리얼에서는 Oracle Fusion Data Intelligence의 자연어 처리 기능 및 AI 지원을 통해 더 나은 결과를 얻기 위해 데이터 세트를 준비하고 비즈니스 친화적인 메타데이터를 개선하는 방법을 살펴보겠습니다. Oracle Fusion Data Intelligence(FDI)는 자연어 처리 기능과 AI 기반 인사이트를 제공하여 사용자가 데이터를 탐색하고, 시각화를 생성하고, 주요 패턴을 식별할 수 있도록 지원합니다. 이러한 기능을 최적화하려면 데이터 세트가 깨끗하고 명확하고 사용자 친화적인 명명 규칙을 사용하는 것이 필수적입니다 . 이 시나리오에서는 Oracle FDI의 AI 어시스턴트 및 자연어 처리 기능을 사용하여 분석할 수 있도록 깔끔하고 레이블이 잘 지정된 데이터 세트를 영업 분석가를 위해 만들고 싶습니다. 홈페이지에서 시작해서 만들기를 클릭한 다음, 데이터 세트를 클릭하여 판매 데이터 세트를 업로드하겠습니다. 내 매출 데이터 세트의 열 이름이 아직 업무용으로 적합하지 않아서 수정하겠습니다 . 대소 문자를 조정하거나 밑줄을 공백으로 바꾸는 것과 같은 간단한 변경은 가능하지만, 기본적인 정리 이상의 작업을 하려면 AI 어시스턴트 아이콘을 클릭한 다음 열 이름 생성 기능을 사용하여 약어를 풀이하면서도 간결한 형식을 유지하는, 더 명확하고 비즈니스 친화적인 열 이름 추천을 생성합니다. FDI의 데이터 준비 과정은 추적 및 반복이 가능하며, 이를 통해 시간이 지남에 따라 일관된 변환을 유지할 수 있습니다. 데이터 세트의 데이터 프로필과 열 데이터 유형도 확인할 수 있습니다. 텍스트로 저장된 데이터나 모호하거나 불분명한 열 이름처럼 데이터 유형이 일치하지 않는 부분을 찾아 수정하여 자연어 처리 기능이 데이터를 정확하게 해석할 수 있도록 하겠습니다. 이 경우에는 변경할 사항이 없습니다. 결측값 및 이상치에 대한 데이터 품질 지표를 검토하고, ' 지정되지 않은 값'의 높은 비율을 해결하겠습니다. 다음으로, 주요 열에서 유효하지 않은 값을 확인하고, 플래그가 지정된 값이 실제로 잘못된 것인지 확인한 후 필터링하거나 수정하겠습니다. 열 헤더나 값에 주 코드와 같은 약어가 사용된 경우 레이블을 업데이트하고 비즈니스 값을 표준화하여 비즈니스에 친숙하게 만들 수 있습니다. 이 날짜 열에 누락된 값이 있는지 확인하겠습니다. 옵션을 클릭한 다음 편집하여 대소 문자 구분 표현식을 사용하여 필요한 경우 표준화하거나 빈칸을 채우겠습니다. 변경 사항을 저장하고 데이터 세트 이름을 지정하겠습니다 . 다음으로, 정리된 데이터 세트를 검증하고 사용자가 Oracle Fusion Data Intelligence의 자연어 처리 및 AI 지원 기능을 사용하여 쉽게 분석할 수 있는지 확인하기 위한 통합 문서를 만들겠습니다. 자동 인사이트를 클릭한 다음 어시스턴트 탭을 클릭하겠습니다. AI 어시스턴트에서 이 데이터 세트에 대한 인덱싱이 비활성화되어 있으므로 데이터 창에서 데이터 세트를 마우스 오른쪽 버튼으로 클릭한 다음 검사를 선택하겠습니다. 검색 탭에서 도움말 및 홈페이지 검색을 위한 인덱스 데이터 세트를 설정하겠습니다. 다음으로, 범위 탭에서 AI 지원을 위해 인덱싱할 데이터 세트 열을 선택하겠습니다 . 이 설정은 사용자가 AI 지원에서 어떤 질문을 할 수 있는지 제어합니다 . 소비자에게 필요한 열만 인덱싱하겠습니다 . 저희 조직 사용자들은 주문 ID, 위도 또는 경도에 대해 문의할 필요가 없으므로 해당 항목을 선택 해제하겠습니다. 다음으로, 동료들이 사용할 가능성이 높은 동의어와 비즈니스 용어를 추가하여 데이터 세트 색인을 더욱 풍부하게 만들겠습니다 . 고객 이름 대신 '이름', 제품 카테고리 대신 '카테고리'와 같이 동의어 추천을 사용하겠습니다. 동료들이 주문 날짜만 물어볼 테니 배송 날짜 선택을 해제하고 변경 사항을 저장하겠습니다. 설정 탭에서 '지금 실행'을 선택하여 인덱싱을 적용하겠습니다. 이제 데이터 세트가 정리되어 비즈니스에 적합해졌으므로, 우리 조직의 사용자들은 Oracle FDI에서 시각화, 자연어 처리 기능 및 AI 기반 인사이트를 사용하여 데이터를 분석할 수 있습니다. 아래 링크에서 이 시리즈의 다른 비디오와 Oracle Fusion Data Intelligence 사용에 대한 추가 자료를 찾아보세요.
