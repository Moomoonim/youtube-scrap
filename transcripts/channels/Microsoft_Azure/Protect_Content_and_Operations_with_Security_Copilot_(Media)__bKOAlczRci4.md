## 스크립트

중요한 생방송 행사 중에 미디어 조직을 지원하는 Microsoft Security Copilot의 기능을 간단히 살펴보겠습니다 . Microsoft Security Copilot은 Microsoft의 보안 전문 지식과 글로벌 위협 인텔리전스를 기반으로 구축된 AI 기반 의사 결정 지원 시스템입니다. 이 시스템은 보안 환경 전반에 걸쳐 신호를 가속화하고 상호 연관시켜, 체계적이고 책임감 있으며 감사 가능한 대응 조치를 제공합니다. 이 데모에서는 라이브 스포츠 경기 중에 무단 스트림이 나타났을 때 시스템이 어떻게 대응하는지 살펴보겠습니다 . 세계적인 스트리밍 서비스 제공업체의 보안팀 소속이라고 상상해 보세요. 오늘은 맨체스터 유나이티드와 에버튼의 경기가 있는 날입니다. 수백만 명이 시청하고 있으며, 이러한 실시간 콘텐츠의 가치를 보호하는 것이 매우 중요합니다. 불법 복제로 인해 전 세계 스포츠 산업이 연간 최대 280억 달러의 손실을 입는 것으로 추산되므로, 매 순간이 중요합니다. 경기 시작 후 몇 분 만에 운영팀에서 무단 스트리밍을 발견했습니다. 불법 복제 콘텐츠는 공식 플랫폼에서 시청자를 빼앗고 , 라이선스 계약을 훼손하며 , 프리미엄 판권 계약의 수익을 감소시킵니다 . 신속하고 체계적인 대응은 단순히 보안 문제만이 아니라, 저작권 수익, 광고주 가치, 그리고 라이브 경험의 완성도를 보호하는 데에도 중요합니다. 운영팀은 추출된 스트림 URL과 그 안에 삽입된 보이지 않는 워터마크, 이렇게 두 가지 중요한 정보를 제공합니다. Microsoft Security Copilot을 사용하여 불법 복제 대응 에이전트를 실행하고 AliceJohnson01 계정과 관련된 모든 활동을 조사하도록 요청합니다 . Security Copilot은 몇 초 만에 ID, 엔드포인트 및 위협 인텔리전스 데이터를 활용하여 환경 전반의 신호를 상호 연관시킵니다. Microsoft Defender 및 Entra의 자동화 정책에 따라 불법 복제 대응 에이전트는 스트림 차단, 손상된 계정 비활성화 또는 관련 ID 정지와 같은 조치를 권장하거나 실행합니다. 연결된 보안 도구를 통해 복구 조치가 실행되면 Security Copilot은 명확하고 감사 가능한 사고 요약 보고서를 생성합니다. 이는 관련된 계정, 계정 간의 연결 관계, 수집된 증거, 각 조치의 근거 등을 문서화하여 법률팀이나 권리 보유자에게 신속하고, 방어 가능하며, 규정을 준수하는 방식으로 정보를 인계할 수 있도록 합니다. 이것이 개별적인 사건인지 아니면 더 광범위한 불법 복제 네트워크의 일부인지 확인하려면 "51.15.19.01.33과 관련된 IP 주소 및 호스팅 제공업체 정보를 보여주세요."라고 요청합니다. Security Copilot은 더 심층적인 분석을 위해 Microsoft Defender Threat Intelligence로 요청을 전달합니다. Microsoft Defender 위협 인텔리전스는 스트리밍 불법 복제와 관련된 IP 주소, 호스팅 제공업체 및 관련 도메인을 포함한 풍부한 컨텍스트 정보를 제공합니다. 이러한 정보를 바탕으로 팀은 작전 범위를 평가하고, 조치 강화 또는 광범위한 법 집행 등 다음 단계를 결정할 수 있습니다. Microsoft Security Copilot을 사용하면 보안 팀은 라이브 방송 중 무단 스트림을 감지하고, 소스를 추적하고, 즉시 문제를 해결하고, 공격 배후의 인프라를 파악할 수 있습니다. 과거에는 며칠에 걸친 수작업 조사와 여러 팀의 투입이 필요했던 작업이 이제는 가장 중요한 순간에 방송 규모로 단 몇 분 만에 완료됩니다.
