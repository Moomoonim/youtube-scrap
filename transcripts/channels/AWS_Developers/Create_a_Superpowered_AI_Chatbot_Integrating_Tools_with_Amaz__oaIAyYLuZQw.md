"오늘 어떠세요?"라고 물어보면 파운데이션 모델 에서 응답이 옵니다. 다음으로 "오늘은 무슨 날짜인가요?"라고 물어보겠습니다. 앞서 언급했듯이 파운데이션 모델은 오늘이 정확히 무슨 날짜인지에 대한 시간적 맥락을 알지 못합니다. 학습 날짜는 알고 있지만, 오늘이라는 날짜에 대한 시간적 정보는 없습니다. 외부 세계 또는 날짜에 대한 인식을 높이기 위해, 컨버스 API 내의 도구를 활용하여 모델에 추가 정보 또는 컨텍스트를 제공할 수 있습니다. 그러면 모델은 해당 정보를 활용하여 공식적인 응답을 처리할 수 있습니다. 여기에서 기록을 출력해 보겠습니다. 컨버스 API 내의 메시지가 어떻게 교대로 표시되는지 앞서 언급했었죠. 여기에는 사용자 도우미(User Assistant) 역할이 있습니다. 이것이 메시지 구조와 교대 표시 방식입니다. 이제 이 부분을 종료하고 다음으로 넘어가겠습니다. 메시지 구조를 제대로 작성하지 않으면 어떻게 되는지 보여드리겠습니다. 코드로 돌아가서 간단히 이 메시지를 주석 처리해 보겠습니다. 그리고 코드를 다시 실행해 보겠습니다. 위로 스크롤해서 확인해 보면 AI 응답이 메시지에 추가되지 않은 것을 알 수 있습니다. 이제 아래로 내려가서 주석을 지우고 코드를 실행해 보겠습니다. 파이썬과 도구를 사용하면 코드가 여전히 실행되는 것을 확인할 수 있습니다.
