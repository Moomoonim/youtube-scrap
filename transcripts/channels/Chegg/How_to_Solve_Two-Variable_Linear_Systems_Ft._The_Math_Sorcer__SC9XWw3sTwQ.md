## 스크립트

안녕하세요 여러분, 수학 마법사 CH입니다. 이번 영상에서는 두 변수 선형 시스템에 대해 알아보겠습니다. 먼저 연립방정식을 푸는 것부터 시작해 보죠. 두 개의 미지수가 있는 두 개의 방정식이 있습니다. 방정식은 x - 2y = 8과 12x + y = -2입니다. 풀이 과정을 살펴보겠습니다. 여러 가지 방법이 있는데, 소거법 또는 덧셈법이라고 하는 방법을 사용해 보겠습니다. 이 방법은 한 방정식에 다른 방정식을 더해서 변수를 없애는 것입니다. 두 번째 방정식에 -2를 곱하면 x가 -x가 되고, 이를 첫 번째 방정식에 더해서 x를 없앨 수 있습니다. 자, 두 번째 방정식에 -2를 곱해 보겠습니다. 풀이 과정을 보여드리겠습니다. 12x + y에 -2를 넣고 괄호를 칩니다. 한쪽에 한 일을 다른 쪽에도 똑같이 하면 됩니다. -2 * -2 = -2 * 12x = -2x = -2x + 12x = -2x + 12x = -2x + 12xx + 12xx = -2xx + 12xx + 12xx = -2xxx + 12xxxx = -2x ... USX -2 * Y는 -2y이고, 여기서는 -2 * -2가 되므로 4입니다. 첫 번째 방정식을 바로 아래에 적겠습니다. x - 2y = 8입니다. 잘했습니다. 이제 이들을 더해 보겠습니다. 더하면 x + x가 됩니다. 덧셈을 쓰면 -2y - 2y는 -4y이고, 4 + 8은 12이므로 -4y = 212가 됩니다. -4로 나누면 y = -3이 됩니다. 이 결과를 네모 안에 적어 두겠습니다. Y 값을 구했으니 이제 x 값만 구하면 됩니다. x 값을 구하려면 원하는 방정식에 대입하면 됩니다. 첫 번째 방정식에 대입해 보겠습니다. 그러면 x는 -2가 되고, y는 -3이 됩니다. y 는 8 과 같으므로 x는 -2 * 8입니다. -3은 +6이고 이것은 8과 같습니다. 양변에서 6을 빼면 x = 2가 됩니다. 따라서 답은 x = 2, y = -3입니다. 답을 나타내는 또 다른 방법은 순서쌍으로 나타내는 것입니다. 괄호 안에 x, y = 2, -3을 넣으면 연립방정식 의 해가 됩니다. 그래프로 나타내면 두 방정식을 그래프로 그렸을 때 두 점이 2, -3에서 만난다는 것을 의미합니다. 즉, 그래프로 나타낸 것입니다. 이제 다른 예제를 풀어보겠습니다. 때로는 해가 없거나 무수히 많은 해가 있는 경우가 있습니다. 이러한 경우를 살펴보고 연립방정식 x + 2y = 3과 3x - 6y = 1을 풀어보겠습니다. 소거법을 사용해 보겠습니다. 첫 번째 방정식에 3을 곱하면 -3x가 되고, 이를 두 번째 방정식에 더하면 x = 2, y = -3이 됩니다. 3x를 없애려면 첫 번째 방정식에 3을 곱하면 -3x가 되고, 3 * 2y는 6y가 됩니다. 그리고 3 * 3은 9이므로 첫 번째 방정식에 3을 곱하면 -3x + 6y = 9가 됩니다. 이제 두 번째 방정식을 바로 아래에 쓰고 더하면 -3x + 3x는 0이 되고, 6y + -6y는 0입니다. 9 + 1은 10이므로 0 = 10이 됩니다. 이것은 무엇을 의미할까요? 즉, 말이 안 된다는 뜻입니다. 다시 말해 해가 없다는 것입니다. 그래프로 생각해 보면, 앞서 하나의 해가 있을 때는 교점이 있다는 것을 알았습니다. 두 직선이 만나지 않으면 평행선이라는 뜻입니다. 따라서 여기에는 평행선이 있습니다. 두 개의 변수와 두 개의 방정식으로 이루어진 연립방정식에서 해가 없거나 두 개의 변수와 두 개의 방정식이 있을 때는 두 직선이 만나지 않습니다. 평행선 L이 있는 흥미로운 예시를 하나 더 살펴보겠습니다. x + y = 1과 2x + 2y = 2라는 연립방정식을 풀어보죠. 해를 하나씩 찾아보겠습니다. 이전처럼 소거법을 사용하겠습니다. 첫 번째 방정식에 -2를 곱해서 두 번째 방정식에 더하면 소거할 수 있습니다. -2x가 되고, -2 * y = -2y, -2 * 1 = -2가 됩니다. 그 아래에 두 번째 방정식을 쓰면 2x + 2y = 2가 됩니다. 이제 두 방정식을 더하면 -2x + 2x = 0, -2y + 2y = 0, -2 + 2 = 0이 됩니다. 따라서 0 = 0이 됩니다. 이것은 무엇을 의미할까요? 항상 참이라는 뜻입니다. 즉, x와 y에 어떤 값을 대입하더라도 항상 참입니다. 따라서 이 경우에는 무수히 많은 해가 존재합니다. 하지만 한 단계 더 나아가 보겠습니다. 무한히 많은 해를 쓰는 방법을 보여드리겠습니다. 수학의 아름다운 점 중 하나는 무한히 많은 해를 쓸 수 있다는 것입니다. 해 집합은 이 직선 위에 있는 모든 순서쌍의 집합입니다. 즉, x 쉼표, y 쉼표로 표현되는 모든 순서쌍(x + y)의 집합이며, x + y = 1입니다. 따라서 직선 위의 모든 점이 해입니다. 여기서 무슨 일이 일어나고 있냐면, 같은 직선이 두 번 그려져 있다는 것입니다. 기본적으로 첫 번째 직선이 두 번째 직선이 되고, 두 번째 직선은 첫 번째 직선을 두 배로 늘린 것입니다. 마치 직선 하나 위에 또 다른 직선이 있는 것과 같습니다. 따라서 직선 위의 모든 점은 이 두 직선의 교점입니다. 즉, 직선 위의 모든 점이 해입니다. 재미있는 문제죠? 이 영상에서 수학에 대해 조금이나마 배우셨기를 바랍니다. 도움이 되셨다면 CH의 다른 영상들도 확인해 보세요. 다음 영상에서 뵙겠습니다. 행운을 빕니다!
