## 스크립트

안녕하세요 개발자 여러분, 최신 대규모 언어 모델 소식을 전해드립니다. Meta에서 Lama 3.1 405b를 발표했습니다. 이는 최첨단 오픈 소스 LLM으로, 70b 및 8b 모델도 함께 업데이트되었습니다. 405b 모델은 Lama 컬렉션 중 가장 큰 규모 이며, 여러 주요 벤치마크에서 다른 주요 모델들을 능가하는 성능을 보여주었습니다. NVIDIA는 Meta와 협력하여 Lama 3.1 모델을 최적화하여 높은 처리량과 낮은 지연 시간을 제공함으로써 기업들이 이러한 모델을 자사 애플리케이션에 더욱 쉽게 도입할 수 있도록 했습니다. nvidia.com에서 Lama 3.1 405b를 무료로 사용해 보세요. NVIDIA 컴퓨팅 스택에서 완벽하게 가속되며 간단한 사용자 인터페이스를 제공합니다. 브라우저에서 모델과 직접 대화할 수 있으며 GPU가 필요하지 않습니다. 당사의 API 엔드포인트를 통해 애플리케이션 연결 및 프로토타입 제작을 무료로 간편하게 할 수 있습니다. 이 모델을 사용하여 더 작고 강력한 모델을 학습하기 위한 합성 데이터를 생성 하거나 애플리케이션에 직접 통합할 수 있습니다. 자세한 내용은 a로 이동하세요. 시작하려면 nvidia.com을 방문하세요.
