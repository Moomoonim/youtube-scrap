## 스크립트

안녕하세요 여러분, 저는 허깅페이스의 네이트입니다. 오늘은 Gradio와 PyTorch를 사용하여 그림 퀴즈 앱을 만들어 보겠습니다. 이 영상은 Gradio 웹사이트에 있는 가이드를 기반으로 제작되었으며, 해당 링크를 첨부하겠습니다. 우리의 목표는 알고리즘이 우리가 그린 그림을 얼마나 잘 해석하는지 확인하는 것입니다. 이를 위해 저는 Google에서 공개한 Quick Draw 데이터셋을 사용하여 이미 학습시킨 모델을 사용할 것입니다. Quick Draw 데이터셋에는 다양한 사물을 손으로 그린 ​​이미지가 많이 포함되어 있습니다. 궁금하신 분들은 제가 이 모델을 학습시키는 데 사용한 노트북을 사용해 보셔도 좋습니다. 아마 여러분도 더 나은 모델을 만들 수 있을 거라고 생각합니다. 자, 시작해 볼까요? 우리는 허깅페이스 스페이스를 무료로 사용하여 앱을 호스팅할 것입니다. 새 스페이스를 생성하고 이름을 ' Pictionary'로 지정하고 Gradio를 지정해 주세요. 스페이스가 생성되면 로컬 컴퓨터에 클론합니다. 여기에서 이미 몇 가지 파일이 다운로드된 것을 볼 수 있습니다. 그중 하나는 classnames.txt 파일로, 우리 모델에 사용될 클래스 이름이 포함되어 있습니다. 사전 학습된 모델은 예측 방법을 알고 있고, 다른 하나는 PyTorch model.bin으로, 사전 학습된 모델이 저장된 파일입니다. 이제 이 두 파일을 방금 복제한 저장소에 복사하겠습니다. 다음으로, Python 종속성을 정의하는 requirement.txt 파일을 생성합니다. 이 경우 Torch와 Gradio가 필요합니다. 그 후, 앱을 정의하는 app.pi 파일을 생성합니다. 먼저 몇 가지 import 문을 정의하고, classnames.txt 파일에서 레이블을 문자열 목록으로 읽어옵니다. 그런 다음 로드할 모델을 정의해야 합니다. 이를 위해 Gradio 가이드로 돌아가서 몇 줄을 복사하여 애플리케이션 파일에 붙여넣겠습니다. 다음은 모델 정의 코드입니다. 그 다음에는 pi 파일(Torch model.bin)을 로드 하고 모델을 평가 모드로 설정하여 예측을 수행할 준비를 합니다. Gradual Apps는 예측 함수를 정의하여 작동하는데, 여기서 im 변수는 0에서 255까지 스케일링된 NumPy 배열입니다. 자, 그럼 빠르게 텐서로 변환 하고 0에서 1 사이로 스케일링해 보겠습니다. 그 다음에는 표준 PyTorch 예측 코드를 사용합니다. ` torch.nograd` 컨텍스트 관리자를 사용하여 출력을 얻고, 소프트맥스를 사용하여 확률을 계산한 다음, `torch.topk`를 호출하여 예측된 상위 5개 레이블 인덱스를 가져옵니다. 마지막으로 이 인덱스를 사용하여 레이블 의 문자열 이름을 찾고 예측 확률에 매핑하여 반환합니다. 좋습니다. 이제 예측 함수가 준비되었으니 인터페이스를 정의해야 합니다. ` gradio` 인터페이스를 사용하고 방금 정의한 예측 함수를 전달합니다. 입력으로는 스케치패드(그림을 그릴 수 있게 해주는 도구)를 지정하고, 출력으로는 레이블을 지정합니다. 여기서 중요한 것은 ` live`를 ` true`로 지정하는 것입니다. 즉, 그림을 그리는 동안 실시간 예측 결과를 받게 됩니다. 이제 ` interface.launch`를 호출하면 됩니다. 좋습니다. 로컬에서 실행해 보니 잘 작동하는 것 같습니다. 정말 멋지네요! Hug and Face Spaces에 우리가 아까 만든 저장소를 푸시해서 전 세계와 공유해 봅시다. 잠시 기다리면 저장소가 빌드되고 브라우저에서 앱을 실행할 수 있습니다. 다시 말씀드리지만, 이 모델은 완벽하지 않으니 학습 코드를 확인하고 더 나은 모델을 만들어 보시길 바랍니다. 만약 제가 제한했던 100개 클래스 대신 Quick Draw 데이터 세트의 모든 클래스를 포함하는 더 나은 모델을 만들 수 있다면 보너스 점수를 드리겠습니다! 이렇게 라디오와 라즈베리 파이 토치를 사용하여 그림 퀴즈 앱을 만들었습니다. 이 영상이 도움이 되었다면 좋아요를 눌러주시고, 더 많은 콘텐츠를 보려면 저희 유튜브 채널을 구독해주세요. 머신 러닝에 관심 있는 수천 명의 사람들과 함께하려면 저희 디스코드 서버에도 가입하세요. 다음 영상에서 뵙겠습니다. 시청해 주셔서 감사합니다. 안녕히 계세요.
