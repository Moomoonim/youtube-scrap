## 스크립트

안녕하세요. 오늘은 여러분의 프런트엔드 애플리케이션 에 AI 챗봇 여행 어드바이저를 단 몇 분 만에 추가하는 방법을 보여드리겠습니다. 새로운 Amplify AI 키트를 사용하여 시작해 보겠습니다. 간단한 데모와 코드를 보여드리겠습니다. 먼저 데모 화면을 보여드리겠습니다. 지금 제 화면에는 Amplify AI 키트 여행 어드바이저라는 챗봇이 있습니다. 여기에 텍스트를 입력하고 여행 어드바이저에게 원하는 질문을 할 수 있는 입력란이 있습니다. 뉴욕시에서 가볼 만한 곳을 물어보고 엔터를 누르면, 이 챗봇 은 자동으로 저희의 대규모 언어 모델(이 경우 Claude 3)과 통신하여 정보를 스트리밍하기 시작합니다. 보시 다시피, 뉴욕시 에서 추천하는 주요 명소와 관광지가 표시됩니다. 센트럴 파크, 메트로폴리탄 미술관, 여러 박물관, 엠파이어 스테이트 빌딩 등이 있습니다. 보시다시피, 이것은 완전한 기능을 갖춘 챗봇입니다. 어떤 종류의 질문이든 입력할 수 있지만, 어떻게 작동하는지 살펴보겠습니다. 이 모든 것을 몇 분 안에 설정하고 앱에 추가할 수 있습니다. 지금 React를 사용하는 새로운 V 앱 안에 있는데, 여기서 몇 가지 라이브러리를 설치할 수 있습니다. AWS Amplify AI 키트를 시작하려면 `npm create amplify at latest` 명령어를 실행해야 합니다. 이 명령어를 실행하면 채팅 보드를 설정하는 데 필요한 모든 것이 설치됩니다. 또한 AWS Amplify Gen 2라는 것도 설정되어 모든 AWS 서비스와 통신할 수 있게 됩니다. 어떻게 작동하는지 보여드리겠습니다. 몇 가지 추가 라이브러리도 설치해야 합니다. ` mpm i AWS amplify UI react`, ` AWS amplify UI react Ai`, 그리고 `AWS amplify Library` 명령어를 실행합니다. 이 라이브러리들은 Node 모듈로 설치됩니다. 이제 V 앱 안을 보면 ` amplify`라는 새 폴더가 있고, 그 안에 ` off`와 `data` 폴더가 있습니다. 이것들이 AWS 서비스에 연결하는 데 필요한 모든 구성입니다. 이 경우에는 Amazon Bedrock과 Clad 3를 사용할 것이고, Amazon Cognito도 설정됩니다. 이 부분을 살펴보면 몇 줄의 코드밖에 안 되지만, 자동으로 생성되는 기본 코드 모음입니다. 이 새로운 데이터 리소스 파일에 대화형 API를 추가하여 챗봇을 만드는 방법을 보여드리겠습니다. 이 리소스 TS 파일에 기본 코드가 몇 개 보일 수 있는데, 이제 업데이트하는 방법을 보여드리겠습니다. 먼저 클라이언트 스키마를 가져와야 하고, 내보내기 유형 스키마와 정의된 데이터도 필요합니다. 이 부분은 어떤 권한 규칙을 사용할지 알려줍니다. 그리고 이 안에 새로운 채팅 AI를 추가하겠습니다. 이 리소스 파일은 대화 기능을 제공하며, 앱 동기화 백엔드를 생성하고 Amazon Bedrock에 연결한 다음, 우리가 사용할 Clad3 Sonet 대형 언어 모델에 연결합니다. 단 몇 줄의 코드로 이 모든 작업을 수행할 수 있습니다. 또한 시스템 프롬프트를 추가할 것입니다. 이 프롬프트는 대형 언어 모델에게 " 당신은 여행 상담사 처럼 도움을 주는 도우미입니다."라고 알려줍니다. 따라서 대형 언어 모델에 질문을 하면 여행 상담사처럼 응답하게 됩니다. 이제 리소스 파일 작성이 완료되었고 챗봇 작동 방식에 대한 아이디어가 생겼으니, AWS에 연결해야 합니다. 어떻게 연결하는지 보여드리겠습니다. 먼저 AWS 계정이 있어야 하고, Amazon Bedrock에 접속하여 모델 액세스에서 사용할 모든 모델을 활성화해야 합니다. 그렇지 않으면 작동하지 않습니다. 또한 AWS와 통신할 수 있도록 Identity Center 또는 AWS CLI를 설정하고 로컬 환경을 구축하는 것이 좋습니다. Amplify AWS 문서에서 '로컬 개발을 위한 AWS 구성'을 클릭하면 카운트 설정이 완료됩니다. 전체 비디오 와 필요한 모든 설정 방법을 확인할 수 있습니다. 저는 이미 설정했으므로 다음 단계는 MPX Ampex sandbox를 실행하는 것입니다. 이렇게 하면 임시 환경이 생성되고, AppSync가 생성되며, Bedrock 모델에 연결됩니다. 모든 작업은 백그라운드에서 자동으로 수행되므로 로컬에서 테스트할 수 있습니다. 이제 몇 가지 간단한 단계를 더 살펴보겠습니다. 먼저 메인 TSX 파일로 이동해야 합니다. 저는 시작하기 전에 미리 이 파일을 작성했습니다. UI React 라이브러리에서 인증자를 가져와 애플리케이션 전체를 감싸도록 했습니다. 또한 Amplify 구성 명령을 실행합니다. MPX Ampex sandbox 명령을 실행하면 파일 시스템의 루트 폴더에 amplify outputs라는 새 파일이 생성되고, 이 파일에 모든 구성 정보가 포함됩니다. Amplify를 설치 하고 Amplify 구성 파일을 다음과 같이 전달하기만 하면 됩니다. 이렇게 하면 리소스 파일로 돌아가서 확인할 수 있듯이 인증 규칙이 추가됩니다. 이 규칙은 인증된 사용자만 방금 생성한 챗봇을 사용할 수 있도록 합니다. 이를 사용하려면 이전에 언급했듯이 인증된 권한으로 생성된 Amazon Cognito도 필요합니다. 사용자가 먼저 로그인해야 하므로 메인 TSX 파일 안에 인증자 구성 요소가 있습니다. 이는 앱에 로그인하거나 로그아웃하는 방법을 추가하는 매우 유용한 연결 구성 요소입니다. 이제 npm run Dev를 실행하면 앱을 실행할 수 있습니다. 앱을 처음 로드하면 로그인할 수 있는 화면이 표시됩니다. 새 계정을 만들고 로그인하면 챗봇에 접속할 수 있습니다. 로그인 후에는 챗봇에 액세스할 수 있습니다. 마지막으로 앱 TSX 파일을 빠르게 설정해야 합니다. 이 파일에는 다음 내용이 포함됩니다. 챗봇과 실제로 대화하는 데 필요한 모든 것이 준비되어 있습니다. 먼저 AI 훅을 생성하고, 백엔드와 통신할 수 있도록 클라이언트를 생성해야 합니다. 그런 다음 AI 대화를 사용하기 위해 12번째 줄부터 18번째 줄까지 훅을 설정하고, UI React AI 라이브러리의 연결된 컴포넌트인 AI 대화 컴포넌트를 사용합니다. 훅에서 전달된 메시지를 전송하고 로딩 중인 메시지를 표시하도록 설정하면 됩니다. 이것이 메인 라우트이며 추가 라우트는 없습니다. 앱을 로드하면 Amplify AI 키트 트래블 바이저가 표시되고 질문을 시작할 수 있습니다. 보시다시피 단 몇 분 만에 Amazon BioLanguage 모델과 연결된 챗봇을 만들고 상호 작용할 수 있도록 구현했습니다. 몇 줄의 보일러플레이트 코드만으로 이 모든 것을 할 수 있습니다. 계속해서 사용해 보시려면 아래 설명란에 있는 링크를 확인해 보세요.
