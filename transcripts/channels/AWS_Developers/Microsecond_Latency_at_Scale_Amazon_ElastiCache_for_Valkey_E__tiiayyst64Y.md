## 스크립트

2024년 프라임 데이 기간 동안 아마존 엘라스틱해시는 단 하루 만에 1000조 건 이상의 요청을 처리했으며, 최고 성능은 분당 1조 건 이상의 요청을 처리했습니다. 이는 개발자들이 밤잠을 설치게 할 만한 규모입니다. 안녕하세요, 저는 브룩입니다. 오늘은 최근 Valky 지원을 발표한 아마존 엘라스틱해시에 대해 자세히 알아보겠습니다. 고성능 애플리케이션을 구축하거나 트래픽 급증에 대처해야 하는 경우 이 소식에 주목해야 합니다. 아마존 엘라스틱해시 Falky를 세 가지 핵심 영역으로 나누어 살펴보겠습니다. 먼저 기술 사양부터 살펴보겠습니다. 엘라스틱해시는 Valky 버전 7.2를 지원하며, 오픈 소스 고성능 키- 값 데이터 저장소입니다. Valky는 Linux Foundation에서 관리하고 있으며 AWS를 포함한 40개 이상의 기업에서 지원하고 있다는 점을 알아두는 것이 중요합니다. 이제 엘라스틱해시 Falky의 특징에 대해 이야기해 보겠습니다. 첫째, 서버리스 및 노드 기반 배포를 모두 지원하여 아키텍처에 유연성을 제공합니다. 성능 측면에서도 인상적입니다. 단일 노드 기반 클러스터에서 초당 5억 건의 요청을 처리할 수 있으며, 읽기/쓰기 지연 시간은 매우 낮습니다. 안정성 또한 엘라스틱해시 Falky의 핵심 특징입니다. Elastic은 99.99%의 가용성, 자동 스케일링, 그리고 재해 복구를 위한 멀티 AZ 배포를 통한 고가용성을 제공합니다. 또한, 비즈니스 연속성을 보장하는 크로스 리전 복제도 지원합니다. 두 가지 주요 이점은 성능 과 비용 측면에서 Elastic의 Falki가 가격 경쟁력을 크게 향상시켰다는 점입니다. Elastic 의 Server Feli는 다른 지원 엔진보다 33% 저렴하며, 노드 기반 클러스터의 경우 다른 지원 엔진보다 20% 저렴합니다. 이제 막 시작했거나 소규모 프로젝트를 진행하는 사용자에게 희소식은 서버리스의 최소 데이터 저장 용량이 기존 1GB에서 100MB로 낮아졌다는 것입니다. Redus OS를 사용하면 월 6달러부터 서버리스를 시작할 수 있습니다. 세 번째는 개발자 경험입니다. Elastic의 Falki는 Redus OSS와의 API 호환성을 유지합니다. 즉, 기존 코드를 수정 없이 그대로 사용할 수 있습니다. 그 외에도 개발자 친화적인 기능이 몇 가지 더 있습니다. 우선 Elastic Hash에서 Redus로 마이그레이션할 수 있습니다. AWS는 다운타임이 없는 오픈 소스 OSS인 Valky Glide를 출시했습니다. Valky Glide는 Java, Python, Node.js를 지원하며 Go 지원도 개발 중입니다. 이 클라이언트는 특히 예기치 않은 장애 발생 시 안정성을 향상하도록 설계되었습니다. 이제 Valky용 Elastic Hash 인스턴스를 설정하고 사용하는 방법을 살펴보겠습니다. 이 과정은 크게 네 단계로 구성됩니다. 먼저 서버리스 캐시를 생성합니다. 이 명령은 기본 보안 그룹을 사용하여 기본 VPC에 Valky와 호환되는 캐시를 생성합니다. 캐시는 수요에 따라 자동으로 확장되므로 노드 크기나 클러스터 구성에 대해 걱정할 필요가 없습니다. 다음으로 캐시와 동일한 VPC에 EC2 인스턴스를 설정합니다. 이 데모에서는 이미 설정되어 있다고 가정합니다. 세 번째로 EC2 인스턴스에 Valky CLI 유틸리티를 설치하고 설정해야 합니다. Elastic Hash 서버리스를 Valky에 사용하려면 TLS 지원이 필요하므로 TLS를 사용하여 빌드해야 합니다. 마지막으로 Valky CLI를 사용하여 캐시에 연결합니다. 연결되었으므로 자동차를 나타내는 해시 객체를 생성하고 특정 필드를 검색해 보겠습니다. 이를 통해 기존 시스템과의 호환성을 확인할 수 있습니다. Reddis OSS 명령어를 사용하는 기존 Reddis OSS 기반 애플리케이션은 변경 없이 그대로 작동합니다. Elastic Valki는 Reddis OSS의 친숙함과 성능 향상을 결합하여 프로덕션 환경에서 실질적인 차이를 만들어낼 수 있습니다. 프라임 데이와 같은 대규모 트래픽 급증을 처리하든 실시간 분석 시스템을 구축하든, 캐싱 구조를 구축할 때 고려해 볼 만한 가치가 있습니다. 현재 Reddis OSS용 Elasticache를 사용하고 있다면 다운타임 없이 Elasticache for Valki로 업그레이드할 수 있습니다. 또한 예약 노드를 사용하는 경우 동일한 제품군 내 모든 노드 크기에서 기존 할인 요금을 유지할 수 있습니다. 한번 사용해 보시고 사용 사례에서 성능이 어떤지 댓글로 알려주세요. 좋아요와 구독도 잊지 마시고 다음 영상에서 뵙겠습니다.
