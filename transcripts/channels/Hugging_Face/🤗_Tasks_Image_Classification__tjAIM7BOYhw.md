## 스크립트

'포옹하는 얼굴' 과제 시리즈에 오신 것을 환영합니다. 이 영상에서는 이미지 분류 작업에 대해 살펴보겠습니다. 이미지 분류는 이미지에 클래스를 할당하는 작업입니다. 이미지 분류 모델은 이미지를 입력으로 받아 클래스 레이블을 반환합니다. 이 모델은 이미지당 하나의 클래스 인스턴스만 포함된다고 가정합니다. 이미지 분류 모델은 일반적인 분류 지표를 사용하여 평가됩니다. 정확도와 같은 명확한 지표 외에도, 정밀도와 재현율이라는 두 가지 지표의 평균으로 계산되는 F1 점수가 일반적으로 사용되는 지표입니다 . F1 점수는 데이터 세트의 클래스 불균형을 고려하므로, 불균형 데이터 세트에서 모델이 예측을 얼마나 잘 수행하는지 더 잘 보여주는 지표입니다. 이 작업에 사용되는 예시 데이터 세트로는 CIFAR가 있습니다. 여기서는 각 이미지가 해당 이미지 와 연결된 레이블과 쌍을 이루고 있는 것을 볼 수 있습니다. 이미지 분류는 의료 영상부터 원격 탐사에 이르기까지 광범위한 문제에 사용됩니다. 한 가지 예로, CT 스캔 이미지에 암 조직이 포함되어 있는지 여부를 판별하는 것이 있습니다. 이미지 분류 작업에 대한 자세한 내용은 작업 페이지를 참조하세요 .
