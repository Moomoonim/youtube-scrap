## 스크립트

이 튜토리얼에서는 Oracle AI 데이터 플랫폼의 노트북 및 작업 실행에서 매개변수를 사용하는 방법을 알아봅니다 . 매개변수는 노트북 에 전달되고, 노트북에서 사용되며, 노트북에서 업데이트될 수 있는 값입니다. 또한 if-else 문에서 사용될 경우 작업 실행에 영향을 미칠 수 있습니다. 매개변수는 노트북을 프로그래밍 방식으로 실행하고 재사용 가능한 워크플로를 구축할 때 유용합니다. 이 시나리오에서는 카탈로그를 생성하고 데이터를 채운 다음, 두 번째 노트북에서 해당 데이터를 분석하려고 합니다. 매개변수를 사용하여 객체 이름을 정의하고 분석 실행 여부를 제어하겠습니다 . 첫 번째 노트북에서는 작업 수준 매개변수를 가져오겠습니다. 이 값들은 작업 수준에서 정의되어 실행 시 노트북으로 전달됩니다. 카탈로그 이름, 스키마 이름, 테이블 이름과 같은 값을 가져오기 위해 get 매개변수 함수를 사용하겠습니다. 매개변수가 제공되지 않으면 기본값이 사용됩니다. 그런 다음 이러한 매개변수 값을 연결하여 노트북 전체에서 사용할 완전한 테이블 이름을 생성합니다 . 다음으로, 수집 상태, 로드된 행 수, 대상 테이블 등 하위 작업에 전달할 작업 수준 매개변수를 설정 작업 값을 사용하여 정의하겠습니다. 그리고 기본값을 설정하겠습니다 . 그런 다음 노트북 으로 가져온 매개변수 값을 사용하여 카탈로그와 스키마를 생성합니다 . 다음으로 데이터를 생성하여 대상 테이블에 기록하겠습니다. 데이터를 입력한 후, 데이터 수집이 제대로 되었는지 검증하겠습니다. 테이블에 행이 존재하면 상태를 성공으로 표시합니다. 그렇지 않으면 실패로 표시됩니다. 데이터 수집이 완료되면 작업 수준 매개변수에 수집 상태와 로드된 행 수를 업데이트하고, 이러한 값 과 테이블 미리보기를 출력합니다. 두 번째 노트북에서는 동일한 작업 수준 매개변수를 참조하겠습니다. 또한 이전 작업에서 작업 수준 매개변수를 가져오겠습니다 . 작업 수준 매개변수는 해당 매개변수를 생성한 작업과 연결되어 있으므로, 이를 검색할 때는 올바른 작업 이름을 참조해야 합니다 . 그런 다음 이러한 매개변수를 사용하여 논리를 제어하겠습니다. 데이터 수집이 성공적이지 못한 경우, 노트북은 분석 단계를 건너뜁니다. 이제 이러한 노트북 과 매개변수가 워크플로에서 어떻게 작동하는지 살펴보겠습니다. 워크플로 페이지에서 내 작업을 열겠습니다. 여기서 저는 카탈로그, 스키마, 테이블 이름과 같은 작업 수준 매개변수를 정의했습니다. 여기에는 '데이터 수집'이라는 노트북 작업이 있는데 , 이 작업은 카탈로그를 생성하고 채우는 노트북을 실행하고, 작업 수준 매개변수를 가져오고, 결과에 따라 작업 수준 매개변수를 설정합니다. 또한, 데이터 수집 작업의 수집 상태를 확인하는 if-else 문을 구성했는데 , 작업 기반 구문을 사용하여 수집이 성공했는지 여부를 판단합니다. 결과가 성공이면 워크플로는 분석 노트북 실행 단계로 진행됩니다. 이로 인해 데이터 분석 작업이 수행되고, 이 작업에서는 분석 노트북이 실행됩니다. 이제 워크플로우를 실행하여 이러한 매개변수들이 어떻게 함께 작동하는지 살펴보겠습니다. 워크플로가 완료되면 그래프 탭에서 각 작업의 결과를 검토하여 데이터 수집이 성공적으로 완료되었는지 확인하고, 작업에 대한 매개변수 값과 데이터 미리보기를 볼 수 있습니다. 데이터 분석 작업의 경우, 이전 작업에서 전달된 매개변수를 기반으로 한 분석 결과를 볼 수 있으며 , 여기에는 데이터 분석 결과도 포함됩니다. 마지막으로, 마스터 카탈로그에 카탈로그, 스키마 및 테이블이 성공적으로 생성되었음을 확인할 수 있습니다. 노트북과 워크플로에서 매개변수를 사용해 보니 이제 실행을 동적으로 제어하고, 작업 간에 값을 전달하고, 더욱 유연한 데이터 파이프라인을 구축할 수 있게 되었습니다. 아래 링크에서 이 시리즈의 다른 동영상과 Oracle AI 데이터 플랫폼 사용에 대한 추가 자료를 찾아보세요.
