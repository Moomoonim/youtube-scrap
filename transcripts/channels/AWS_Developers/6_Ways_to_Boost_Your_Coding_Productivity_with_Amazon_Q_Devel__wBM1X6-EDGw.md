## 스크립트

Amazon Q 개발자 도구는 생산성 향상에 도움을 주는 생성 도구입니다. 기능 개발 최적화는 물론 코드 수정까지 지원합니다. 안녕하세요, 저는 티파니입니다. Amazon Q 개발자 도구에 대해 알아야 할 6가지 사항을 소개합니다. 첫째, Amazon Q 개발자 도구는 개발자 ID에 통합되어 있어 코드 바로 옆에서 Amazon Q와 직접 대화할 수 있습니다. Amazon Q에 질문하면 답변을 받을 수 있습니다. 둘째, 대화뿐 아니라 코드 설명도 요청할 수 있습니다. 관심 있는 코드 부분을 선택하고 마우스 오른쪽 버튼을 클릭한 다음 " Amazon Q로 보내기"를 선택하면 됩니다. 코드에 대한 추가 질문도 할 수 있습니다. 셋째, Amazon Q는 애플리케이션에 새로운 기능을 추가하는 데 도움이 되는 계획을 생성해 줍니다. 프롬프트에 "slev" 다음에 요청을 입력하면 Amazon Q가 계획을 제안하고, 동의하면 코드 변경 사항과 테스트 케이스를 생성하여 코드를 검토할 수 있도록 해줍니다. 넷째, Amazon Q를 사용하여 코드 최적화도 가능합니다. 최적화하려는 코드 부분을 선택하고 마우스 오른쪽 버튼을 클릭한 다음 " Amazon Q로 보내기"를 선택하면 최적화 방법에 대한 제안을 생성해 줍니다. 다섯 번째, 코드가 예상대로 동작하지 않을 때 해당 코드를 선택하고 마우스 오른쪽 버튼을 클릭한 다음 " Amazon Q로 보내기"를 선택하여 프롬프트에 댓글을 남겨주세요. 그러면 Amazon Q에서 문제 해결 방법을 제안해 줍니다. 여섯 번째, Amazon Q는 인프라스트럭처 코드(Infrastructure as Code)도 지원합니다. 예를 들어, 필요한 내용을 지정하여 클라우드포메이션 구성 파일을 생성하도록 요청할 수 있습니다. 그러면 구성 파일이 생성되고 애플리케이션 컴포저에서 확인할 수 있습니다. Amazon Q와 상호 작용하는 방법은 이 외에도 많습니다. 지금까지 대화형 인터페이스, 설명, 기능 개발, 최적화, 코드 수정, 인프라스트럭처 코드에 대해 살펴보았습니다. 이 영상이 도움이 되셨다면 좋아요를 누르고 AWS Developers YouTube 채널을 구독해주세요. 시청해주셔서 감사합니다.
