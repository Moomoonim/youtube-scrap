## 스크립트

이번 GitHub Copilot CLI 초보자 강좌에서는 기본적인 사용법을 알아보겠습니다 . 이 글에서는 Copilot CLI를 설치하는 방법, 로그인하는 방법, 그리고 Copilot CLI에 보낼 첫 번째 요청 몇 가지를 살펴보겠습니다. GitHub Copilot CLI는 데스크톱에서 바로 사용할 수 있는 AI 에이전트입니다 . 여느 AI 코딩 도우미와 마찬가지로 Copilot CLI를 사용하면 코드베이스를 탐색하고, 질문하고, 코드를 생성할 수 있습니다. 하지만 에이전트를 특별하게 만드는 것은 코드 빌드 및 테스트 실행과 같은 작업을 자율적으로 수행할 수 있는 능력, 심지어 오류가 감지될 때 코드를 업데이트하여 자체 복구 기능까지 갖추고 있다는 점입니다. Copilot CLI는 개발자로서 기존 워크플로에 자연스럽게 통합되어, 대화 형으로 작업을 할당하고 할 일 목록의 다른 항목을 처리하거나, 생성된 결과와 애플리케이션에 미치는 영향을 확인하면서 반복적으로 빌드하고 진행하면서 변경 사항을 요청할 수 있습니다 . Copilot CLI를 사용하면 클라우드 기반 에이전트인 Copilot 코딩 에이전트에 작업을 위임할 수도 있습니다 . Copilot CLI를 시작하려면 당연히 설치부터 해야 합니다. 이를 위한 핵심적인 크로스 플랫폼 방식은 npm을 이용하는 것입니다. github/copilot에서 npm install tick g 명령어를 사용하면 됩니다. winget이나 homebrew 같은 패키지 관리자를 사용하고 있다면, 해당 도구를 통해 Copilot CLI를 설치할 수도 있습니다. 자세한 내용은 해당 도구의 설명서를 참조하십시오 . 개인적으로는 Node.js를 통한 설치를 선호하지만, 이는 제 안에 있는 웹 개발자 기질 때문일지도 모릅니다. 제품을 설치한 후에는 copilot이라고 입력하여 실행할 수 있습니다. 사용할 수 있는 스위치는 여러 가지가 있으며, 이에 대해서는 이후 영상에서 자세히 설명하겠습니다. 처음 사용하시는 경우 GitHub 계정으로 로그인해야 합니다. 이것은 두 가지 일을 합니다. 첫째, 클라이언트를 Copilot 계정에 연결합니다. 둘째, GitHub MCP 서버에 연결하여 GitHub의 리소스에 대한 접근 권한을 부여합니다. 그건 나중에 다시 이야기해 보죠. Copilot을 사용하려면 Copilot이 폴더를 탐색하고 파일을 수정할 수 있도록 접근 권한을 부여해야 합니다 . 이 기능을 이번 세션에만 적용하거나, 이후 세션에 적용하도록 저장할 수 있습니다. 이렇게 하면 특정 프로젝트에서 Copilot을 다시 실행할 때 매번 승인할 필요 없이 간편하게 실행할 수 있습니다. 그 과정이 완료되면, 자유롭게 대화를 시작하고, 질문을 하고, 코드를 요청하거나 다른 작업을 진행할 수 있습니다. 먼저 몇 가지 기본 사항부터 살펴보겠습니다. Copilot 측에 프로젝트 개요를 요청해 보겠습니다. Copilot은 탐색을 수행하고, 중요한 파일을 열고, 발견한 내용을 보고합니다. 새로운 엔드포인트를 생성해달라고 요청하는 것처럼 코드를 요청할 수도 있습니다. 제가 요청을 하면 Copilot은 프로젝트를 다시 살펴보고 기존 문서와 예시를 찾아 최대한 기존 사례를 따르려고 노력할 것입니다. 다시 한번, Copilot은 파일 생성 권한을 요청할 것입니다. 제가 승인하겠습니다. 이제 새로운 엔드포인트가 생성되었습니다. 물론, 이것은 단지 시작일 뿐입니다. Copilot과 그 기능을 알아보는 가장 좋은 방법 중 하나는 Copilot에게 직접 물어보는 것입니다. 해당 문서들을 살펴보고, 그 문서 와 상호 작용하는 방법에 대한 지침을 제공할 것입니다. 실험 하고 탐구하세요. 물론, 이 시리즈의 나머지 영상들도 시청하실 수 있습니다 . GitHub Copilot CLI를 최대한 활용할 수 있도록 가장 일반적인 시나리오와 강력한 옵션 몇 가지를 안내해 드리겠습니다 .
