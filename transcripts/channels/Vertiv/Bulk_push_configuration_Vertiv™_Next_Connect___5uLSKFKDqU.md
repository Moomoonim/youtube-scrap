## 스크립트

이 비디오에서는 Vertiv Next Connect를 사용하여 엣지 디바이스에 구성 파일을 일괄 푸시하는 방법을 단계별로 안내합니다. 먼저 기기를 업데이트하려는 고객이 있는 곳으로 이동합니다. 장비 메뉴로 이동하여 장치 탭을 엽니다. 체크박스를 사용하여 업데이트할 모든 기기를 선택하세요. 참고로, 일괄 작업을 이용하려면 선택한 모든 기기가 동일한 모델이어야 합니다 . 선택이 완료되면 장치 목록 상단에 있는 일괄 프로비저닝 아이콘을 클릭합니다 . 일괄 프로비저닝 대화 상자에서 사용 가능한 작업 목록에서 구성 푸시를 선택합니다. 특정 작업이 회색으로 표시되면 선택한 기기에서 해당 작업이 지원되지 않는다는 의미입니다. 드롭다운 필터를 사용하여 사용 가능한 구성 파일 범위를 좁히세요. 원하는 파일을 찾으 려면 적절한 파일 형식과 검색 범위를 선택하세요 . 목록에서 원하는 구성 파일을 선택하십시오. 반드시 본인 또는 운영 파트너가 업로드한 파일만 사용하십시오 . Vertiv의 기본 예제는 검토, 수정 후 새 파일로 저장하지 않은 이상 사용하지 마십시오. 선택 후 '실행'을 클릭합니다. 푸시 알림이 성공했는지 여부를 확인할 수 있습니다. 실패할 경우 장치의 통신 상태를 확인하거나 구성 파일 의 형식 오류를 검토하십시오. 그게 다입니다 . Vertiv Next Connect에서 일괄 작업을 사용하여 여러 장치에 구성을 성공적으로 푸시했습니다. 더 많은 사용법 동영상을 보려면 Vertiv Next Connect 전체 교육 시리즈를 확인하세요.
