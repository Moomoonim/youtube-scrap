Repet은 완전히 격리되어 있어 다른 Repet과 분리되어 있기 때문입니다. 물론 다른 Repet과 연결하는 것은 고급 주제이며, 관련 영상도 준비되어 있습니다. 하지만 대부분의 경우, 이 격리된 환경은 매우 강력합니다. 왜냐하면 설정에 대해 신경 쓸 필요가 없기 때문입니다. 예를 들어, 파이썬 Repet이나 Node Repet에서 시작하지 않고 완전히 새로운 머신을 생성했다고 가정해 보겠습니다. 파이썬 프로젝트를 생성하려면 몇 가지 설정이 있는데, 제가 가장 선호하는 방법은 파이썬 명령어를 입력하는 것입니다. Repet에는 매우 편리한 명령줄 도구들이 있습니다. 셸에 `python`을 입력하고 ` Y`를 누르면 `repet` 명령어가 Python을 설치합니다. ` repet` 파일을 열어보면 설치가 완료된 것을 확인할 수 있습니다. 처음에는 파일이 숨겨져 있을 수 있지만, 점 세 개 아이콘을 클릭하고 ' 숨겨진 파일 표시'를 선택하면 ` repet` 파일을 볼 수 있습니다. ` modules` 인수에 ` python 311`이 추가된 것을 확인할 수 있습니다. 이제 `python`을 입력하면 Reple이 Python이 설치된 것을 인식합니다. 하지만 만약 프로젝트에 `python 312`가 필요하다면, `modules` 인수를 `python 312`로 변경하기만 하면 됩니다. 아, 그런데 환경을 다시 로드하는 명령어를 실행해야 합니다. 이제 `python 312`가 설치되었습니다. 이렇게 간단하게 Python 버전을 업데이트할 수 있습니다. 일종의 빠른 꼼수 또는 지름길이죠. ` npm`도 같은 방식으로 설치할 수 있습니다. `npm`을 입력하면 Reple이 `node`를 설치해야 한다고 인식하고, 이제 `nodejs`가 설치되었습니다. 하지만 더 간단한 방법도 있습니다. 바로 ` packages` 또는 `dependencies`를 이용하는 것입니다. 도구, 즉 종속성 도구는 이러한 모듈을 구성하는 더 빠르고 간단하며 직관적인 방법입니다. 예를 들어, 제가 입력하면 이미 Python이 구성되어 있고 패키지를 추가할 수 있습니다. 만약 이러한 모듈을 제거하고 싶다면 휴지통 아이콘을 클릭하면 repet 파일에서 해당 모듈이 제거됩니다. 동시에 새 모듈을 추가하고 여기서 검색할 수도 있습니다. 예를 들어 Python 312를 검색하면 모듈을 살펴보고 어떤 내용인지, 패키지 관리자와 필요한 구성 요소가 포함되어 있는지 확인할 수 있습니다. 그런 다음 모듈 파일에 다시 설치합니다. ' base'라고 표시되어 있지만 크게 걱정할 필요는 없습니다. 아직 괜찮을 겁니다. 이것이 Repel에 언어를 설치하는 기본 사항입니다. 이제 Python을 입력하면 Python이 설치됩니다. Python Repel을 포크하면 미리 구성된 환경을 repet 인스턴스로 복사하는 것입니다. 이 환경에는 언어 패키지가 포함되어 있으며, 패키지 관리를 더 쉽게 해주는 p 프로젝트 파일도 함께 제공됩니다. 그럼 다시 원래대로 돌아가 보겠습니다. 홈페이지 말이죠... 음, 제가 이상한 것들을 잔뜩 만들지 않도록 이 부분은 삭제할게요. 이제 'Python Reppel 생성'을 클릭해 보겠습니다. 이렇게 빈 릴을 만들고 Python을 설정해서 작동하도록 만들었습니다. 기존에 만들던 Python Reppel과 어떻게 다를까요? 보시다시피, Poetry 파일과 P Project 파일이 설정되어 있습니다. 이 파일들은 Python 파일을 관리하는 아주 쉬운 방법입니다.
