## 스크립트

GitHub Copilot 코드 검토 에이전트에 AI 피드백과 코드 분석 엔진의 확정적 탐지 기능을 결합한 더욱 지능적인 에이전트 워크플로를 도입하여 성능을 향상시켰습니다 . Copilot님을 이번 풀 리퀘스트의 검토자로 지정했습니다. 이제 세션을 열어 에이전트가 저장소 전체의 컨텍스트를 수집하고, 도구를 호출하고, 검토 결과를 구성하는 방식을 확인할 수 있습니다. 이제 Copilot은 제 전체 저장소를 분석하여 파일과 서비스 전반에 걸쳐 더욱 풍부한 컨텍스트를 파악할 수 있으며, CodeQL과 같은 확정적 탐지 기능을 실행하여 정확하고 보안을 고려한 정확성 중심의 피드백을 제공할 뿐만 아니라, 일반적인 문제에 대한 즉각적인 유효성 검사를 제공하는 린터도 실행합니다. 이제 Copilot 코드 리뷰가 GitHub Actions에서 실행되므로 저장소의 Actions 탭에서 전체 워크플로를 모니터링할 수 있습니다 . 에이전트 오케스트레이션 도구가 저장소를 탐색하고 결과를 풀 리퀘스트에 게시하는 것을 볼 수 있습니다. CodeQL이 통합됨으로써 GitHub의 보안 기능을 뒷받침하는 업계 최고의 분석 엔진을 그대로 활용할 수 있습니다 . 또한 에이전트는 저장소를 전체적으로 이해하기 때문에 불일치 및 잠재적인 호환성 파괴 변경 사항도 감지할 수 있습니다 . 자, 다시 풀 리퀘스트로 돌아가서, Copilot의 의견은 명확하고 실행 가능한 지침과 함께 인라인에 반영되며 , 가능한 경우 커밋 제안 버튼을 사용하여 한 번의 클릭으로 수정 사항을 적용할 수 있습니다. 하지만 이제 GitHub Copilot 코딩 에이전트에 작업을 인계할 수도 있습니다. Copilot은 제안된 수정 사항이 현재 브랜치에 적용된 스택형 풀 리퀘스트를 생성하므로 변경 사항을 별도로 검토하고 병합할 수 있습니다 . 여러 가지 제안이 있는 경우 , 상담원은 이를 종합적으로 적용하고 그 사이의 잠재적인 충돌을 해결합니다. Copilot이 어떻게 검토하는지 확인하고 싶다면 저장소에 사용자 지정 지침을 추가할 수 있습니다. Copilot은 사용자의 규칙, 패턴 및 지침을 의견과 제안에 반영합니다. 피드백을 반영한 후에는 Copilot에 다시 검토를 요청하여 새로운 검토 과정을 거칠 수 있습니다 . 재검토할 때마다 중복이 제거됩니다. Copilot은 새로운 통찰력에 집중하여 중요한 신호는 높이고 잡음은 낮춥니다.
