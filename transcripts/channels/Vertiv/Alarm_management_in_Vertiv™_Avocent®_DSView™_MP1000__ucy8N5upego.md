## 스크립트

[music] This video will cover the Vertive DS solution MP1000 alarm management. Starting off in the MP1000 web interface on the appliance view page. You'll see that I have a RACK UPS and a rack PDU connected. From here they have some alarms set off. To view the alarm page on the left hand side under administration, select alarms. Here there are three tabs. One for active alarms, one for alarms that have been cleared, and then the last tab is for all alarms. Below those tabs, you have the option to filter your alarms. To clear an alarm, select the desired alarm. You can then click the brush icon to clear the alarm. It will now appear in the cleared alarms tab. If you'd like to receive email notifications of any alarms, first you'll have to set up your email server with the MP1000. On the left hand sidebar under administration, [music] select system settings. From here, navigate to email server configuration. Then input the necessary parameters for your already configured email server. Next, scroll down to notification configuration and enable the send email notifications radio button and select save. Now that your email server has been set up, on the lefth hand sidebar, select notification settings. Under notification policy in the right hand side, select the plus sign. In the add notification policy menu, you can configure the name of your notification, which severity, whether or not to notify the alarm has been cleared, and who the email should be sent to.
