## 세션별 요약

### 「CUDA: New Features and Beyond | NVIDIA GTC 2024」
- **링크**: https://www.youtube.com/watch?v=pC0SIzZGFSc
- **업로드일 / 분량**: 2024-04-09 / 약 5,848단어
- **발표자**: 스티븐 존스(Stephen Jones) — 엔비디아 CUDA 아키텍트(저명 소프트웨어 아키텍트, 2008년 CUDA 선임 엔지니어로 입사, SpaceX 근무 경력, 케임브리지대 항공우주공학 석사)

발표의 큰 틀은 "가속 컴퓨팅의 진짜 제약은 전력"이라는 명제다. 존스는 데이터센터가 개수가 아니라 메가와트 단위로 발표된다는 점을 짚으며, 하루 6~7개의 데이터센터가 신설되고 북미에 5GW 규모가 있으며 내년 3GW가 추가된다고 말한다. 중간 규모 데이터센터는 약 20MW를 소비하고, 임대료도 월 킬로와트 단위로 부과된다. 두 배 빠른 칩을 만들어도 전력이 두 배면 의미가 없으므로 "20MW를 어떻게 활용하느냐"가 관건이며, 이는 데스크톱(미국 1.5kW, 영국 3kW 콘센트 제한)에도 똑같이 적용된다. 무어의 법칙 그래프를 들어 트랜지스터 밀도는 기하급수적으로 늘지만 전력 소모는 그만큼 빨리 줄지 않는다는 점을 전력 장벽의 근거로 제시한다.

전력 소모의 두 축은 연산과 데이터 이동이다. 연산 측면에서는 정밀도별 곱셈 에너지를 비교한다. 배정밀도(FP64)는 단정밀도의 약 2.5배 전력을 쓰고, 곱셈 비용은 소수부 자릿수의 제곱에 비례한다. 텐서 코어는 연산을 묶어 규모의 경제를 만들며, 16비트 비교 시 예상치(1.5배)가 아니라 4배 효율이 나온다. 동료 아삼 하이다르의 연구를 소개하며, 16비트 텐서 코어로 LU 분해의 핵심 연산을 수행하고 반복(GMRES) 과정으로 64비트 정확도까지 끌어올리는 혼합 정밀도 기법이 네이티브 배정밀도 정확도를 넘어서면서 GH200에서 와트당 플롭스를 거의 6배, 속도를 거의 4배 높였다고 말한다(cuSolver에 구현). 도쿄대 요코타 리오 교수 팀은 저정밀 정수 텐서 코어로 행렬 곱셈을 구현해, 배정밀도 유닛이 없는 L40·L4급 칩에서 성능 6~7배, 와트당 성능 7~8배 향상, A100 대비 절반 성능을 달성했다고 소개한다.

이어 텐서 코어 접근 경로 세 가지(cuBLAS/cuBLAS LT 라이브러리, 세밀 제어용 Cutlass)와, 커널 내부에서 라이브러리를 호출하게 해 주는 디바이스 확장 라이브러리(cuBLAS Dx, FFT Dx)를 설명한다. 전처리·행렬곱·후처리를 한 커널로 융합하면 데이터를 한 번만 적재하므로 성능이 3배 향상된 사례를 보인다. 조합 폭발(슬라이드의 4단계 예시만으로 64가지) 때문에 사전 빌드가 불가능해 JIT 컴파일이 핵심이 되었고, CUDA 11.8 이후 18개월간 최소 프로그램의 컴파일 오버헤드를 6분의 1로 줄였다고 밝힌다. 파이썬 지원(라이브러리·도구 전반, Cutlass 파이썬 인터페이스와 PyTorch 연동, Nsight의 파이썬 프로파일링), 미분 가능 파이썬 GPU 커널 프레임워크 Warp, NumPy를 수천 GPU로 자동 확장하는 Legate/cuNumeric과 Jax XLA 플러그인 통합도 차례로 소개한다.

통신 측면에서는 NVSHMEM과 GPUDirect의 진화를 다룬다. GPU→네트워크 전송이 4홉에서 3홉, 2.5홉(CPU는 설정만, GPU가 트리거), 커널 초기화 방식의 2홉까지 줄었고, 그래프 신경망 학습에서 2.5단계 방식이 기존보다 20% 빠르며 전체 학습 2배, 특징 전송은 10배 이상 빨라졌다고 말한다. Grace Hopper의 NVLink C2C 통합 메모리에 대해서는 CPU(지연 최적화)·GPU(대역폭 최적화)를 단일 주소 공간으로 묶어 반복 접근 시 최대 10배 향상, CSCS 알프스 머신의 ICON 기후 코드(해양 CPU+대기 GPU 동시 실행)에서 64 GPU 규모 3배 가속, LLM 미세 조정에서 중간 텐서를 재계산 대신 오프로드해 20% 가속, 그래프 신경망에서 2배 가속 사례를 든다. 마지막으로 6~7년 전 구상했던 CUDA 그래프의 조건 노드(if/while)가 몇 주 전 CUDA 12.4에서 구현되어, CPU 개입 없이 GPU 안에서 수렴 루프 같은 데이터 종속 제어 흐름을 완전히 실행할 수 있게 되었다고 발표한다. 질의응답에서는 전력 측정은 DCGM 같은 시스템 수준 도구의 영역이라는 점, 장비 통합의 에너지 절감 효과는 결국 "전자를 몇 인치만 이동시키는" 통신 비용 절감에서 온다는 점을 답했다.

### 「What's Next in Generative AI | Brad Lightcap, OpenAI COO and Manuvir Das, NVIDIA VP | NVIDIA GTC'24」
- **링크**: https://www.youtube.com/watch?v=M2s17pAvUz8
- **업로드일 / 분량**: 2024-04-10 / 약 4,396단어
- **발표자**: 브래드 라이트캡(Brad Lightcap, OpenAI COO) × 마나브 도스(Manuvir Das, 엔비디아 엔터프라이즈 컴퓨팅 부문 부사장) 대담. 진행 소개: 엔비디아 수석 전략가(자막 표기 "월리스 밀스")

엔비디아 비즈니스 인사이트 트랙의 첫 대담으로, 도스가 전날 기조연설에서 젠슨 황이 첫 DGX 시스템(DGX-1)을 OpenAI에 직접 전달했던 일화를 언급하며 시작한다. 라이트캡은 자신의 역할을 "연구 자체를 빼고 전부", 즉 연구실의 기술을 고객·사용자·파트너에게 적용하는 일이라 소개하고, 지금은 "1회 초의 시작"이라며 기술 곡선의 초기 단계임을 강조한다. ChatGPT는 애초 기업용 제품이 아니었지만 출시 후 약 6개월간 기업 시장을 관찰한 끝에 ChatGPT Enterprise를 내놓았고, 현재 포춘 500대 기업의 90% 이상이 어떤 형태로든 ChatGPT를 사용한다고 밝힌다. 재무팀이 스프레드시트를 넣고 조정 작업을 시키는 등 부서마다 수직적 특화 개발 없이도 활용처를 스스로 찾아냈다는 점을 특징으로 꼽는다.

기업 도입 방법론에 대해 라이트캡은 2023년의 고객 미팅을 "영업이 아니라 심리 상담"이라 표현한다. C레벨이 온갖 고민을 쏟아내며 "AI가 다 해결해 주느냐"고 묻는 상황에서, 그의 조언은 문제를 제한하라는 것이다. 사업에서 부족한 두세 영역(대표적으로 고객 지원)을 골라 데이터·프로세스·모델 역량을 연결해 첫 구현을 만들고 거기서 확장하라고 권한다. AI 선도 기업 클라라(Klarna)가 워크플로의 아주 작은 부분·특정 데이터셋·구체적 구현부터 시작해 확장한 사례를 든다. 동시에 "가치의 90%는 직원들에게 도구 접근성을 주고 너무 복잡하게 생각하지 않는 데서 나온다"며 전사적 정교한 전략보다 민주적 접근을 권한다. 맞춤화에 대해서는 GPTs(채팅 GPT로 쉽게 만드는 맞춤 모델)와 커스텀 모델(특정 사용 사례에 맞춘 전면 맞춤화)을 스펙트럼의 양 끝으로 설명하고, 기업 AI 배포를 인적 자본 구조에 비유한다 — 박사 25,000명을 고용하지 않듯 모든 문제에 최신 대형 모델이 필요하지 않으며, 인턴급·중간관리자급·전문가급 모델이 각자 자리를 갖되 기준점이 6개월마다 바뀐다는 것이다.

대담의 후반부는 에이전트와 추론으로 향한다. 라이트캡은 현재의 정보 검색형 활용을 "세계 최악의 데이터베이스 — 느리고 비싸고 100% 정확하지도 않다"고 자평하며, 진짜 기대하는 방향은 추론 에이전트라고 말한다. 이를 위해 모델의 추론 능력 향상과 행동 기능 부여 두 가지가 다음 물결의 핵심이며, 의료 기록에서 정보를 추출하는 데 그치지 않고 후속 진료·처방·복약 안내·2주 후 리마인드까지 여러 단계를 잇는 시스템을 예로 든다. 행동 경로가 모델에 알려져 있다면 남은 문제는 각 단계 수행에 필요한 정보 접근이라는 견해도 밝힌다.

회고 대목에서는 GPT-3가 유용성의 '캐즘'을 넘었다고 보지 않았고 GPT-4가 그 첫 모델이 되리라 판단해 2023년 3월 출시에 계획을 맞춰 두었는데(GPT-4 학습은 2022년 중반 시작, 출시 몇 달 전 완료) ChatGPT의 반응이 예상을 뛰어넘었다고 말한다. "GPU가 더 많았으면 좋았겠다"는 농담과 함께, ChatGPT 무료 제공이 세계 곳곳의 예상 못한 활용을 낳은 것을 잘한 결정으로 꼽는다. 마지막으로 인터페이스의 미래에 대해, 오늘 태어난 아이는 햄버거 메뉴와 제출 버튼 같은 GUI를 낯설어할 것이며 "10년 후 아이에게 2020년식 노트북을 주면 말을 걸고 반응을 기다릴 것"이라는 그림으로 대담을 맺는다.

### 「Insights from Kaggle Grandmasters and Experts on Competitive AI and LLM Frontiers | NVIDIA GTC 2024」
- **링크**: https://www.youtube.com/watch?v=k2EcIX0HgzA
- **업로드일 / 분량**: 2024-04-10 / 약 4,819단어
- **발표자**: 데이비드 오스틴(David Austin, 엔비디아, 사회) + 패널: 지(G, 엔비디아 LLM 기술팀 데이터 과학자·Kaggle 그랜드마스터), 크리스(Chris, 엔비디아 선임 데이터 과학자·수학 박사·Kaggle 그랜드마스터 4관왕), 로라(Laura, 엔비디아 연구 관리자·전 뮌헨공대 교수), 카즈키(Kazuki, Kaggle 그랜드마스터·추천 시스템 전문)

엔비디아의 Kaggle 그랜드마스터·전문가 패널이 LLM·비전·RAG·경진대회의 최신 흐름을 문답 형식으로 훑는다. 먼저 지가 생성형 모델 학습 단계를 사전학습(인터넷 대규모 텍스트) → 지도 미세조정(사람이 라벨링한 소규모 고품질 데이터) → RLHF/DPO(선호 피드백) → 가드레일 적용의 순서로 정리한다. 크리스는 언어 모델을 GPT(디코더, 다음 단어 예측에 강함), BERT(인코더, 마스킹 복원으로 학습해 어휘·구조·의미 이해에 강함), T5(인코더-디코더) 세 유형으로 나눠 사전학습 방식과 아키텍처 차이를 설명하고, 카즈키는 학생 요약 평가·지문 복잡성 평가 같은 분류형 대회에는 BERT, 코드 생성에는 GPT를 쓰는 식의 사용처 구분을 덧붙인다.

로라는 LLM이 컴퓨터 비전에 가져온 변화를 CLIP 중심으로 설명한다. 텍스트와 이미지 임베딩을 같은 공간에 정렬함으로써 자연어로 비전 시스템과 상호작용할 수 있게 되었고, 고정 클래스 분할에서 벗어나 사용자가 프롬프트로 지정한 무엇이든("소화전, 개, 소") 분할하는 개방형 세계 장면 이해가 가능해졌다는 것이다. DALL-E류 생성 모델도 이 정렬을 활용한다고 말하며, 향후 과제로 텍스트-비디오(Sora 언급)의 시간적 일관성 문제, 자막이 동작·행동까지 기술하는가의 문제, 3D 생성과 기하학·형태 특징과 언어의 연결을 꼽는다.

RAG 대목에서 크리스는 검색 증강 생성의 원리를 설명하고 Kaggle 'LLM 과학 시험' 대회 경험을 공유한다. 제출 자원 제약 때문에 대형 모델 대신 600만 개 위키피디아 문서 전체를 함께 제출해 검색+소형 LLM으로 문제를 푸는 방식이 우승 솔루션이었고, 본인이 만든 까다로운 양자물리 문제도 순식간에 맞히며 정확도가 97~98% 수준이었다고 말한다. 카즈키는 RAG 대 미세조정 비교 논문들에서 거의 모두 RAG가 우세하며, 미세조정은 파괴적 망각 때문에 최신 정보 주입에 어렵고 비용도 크다고 정리한다. 지는 RAG 응용을 개인정보 보호형(로컬 오픈소스 LLM+벡터 DB, 전시장의 'Chat with RTX'와 Nemo 에이전트 데모)과 최신성 향상형(뉴스·금융·검색·코파일럿)으로 나눠 소개한다.

경진대회 지형 변화로는 훈련 데이터를 아예 주지 않거나 극소량만 주는 대회의 증가가 논의된다. LLM 에세이 탐지 대회는 예시 데이터가 3개뿐이라 참가자들이 Llama 2·Mistral 계열 등으로 직접 훈련 데이터를 생성하고 테스트 분포를 추정해야 했으며, 다양성(모델·온도 다변화)이 핵심이었다고 한다. 크리스는 아마존 주최 KDD 컵 2023에서 다국어 추천 3개 과제(데이터 풍부 언어, 소외 언어, 미존재 상품 생성)를 임베딩 전이와 인코더·디코더 결합으로 풀어 엔비디아 팀이 3개 미니 대회 전부 1위를 했다고 소개한다. 질의응답에서는 "대회가 자본 싸움이 되지 않겠느냐"는 물음에 코드 제출형 대회의 컴퓨팅 제약이 공정성을 만들고 압축·양자화 혁신을 이끈다는 답, 전문가 조합(MoE 스타일 앙상블)과 QLoRA처럼 단일 GPU로도 가능한 기여 사례, 과학 시험 솔루션을 20~30GB 단일 GPU에서 재현하는 오픈소스 작업(FP8 양자화로 벡터 DB 110GB→6GB) 등이 언급된다. 남은 과제로는 접근성(모델 경량화·추론 속도)과 수학적 추론·논리의 약점이 꼽혔다.

### 「Robotics in the Age of Generative AI with Vincent Vanhoucke, Google DeepMind | NVIDIA GTC 2024」
- **링크**: https://www.youtube.com/watch?v=vOrhfyMe_EQ
- **업로드일 / 분량**: 2024-04-11 / 약 4,536단어
- **발표자**: 빈센트 반후크(Vincent Vanhoucke) — 구글 딥마인드 로봇공학 수석 연구원 겸 시니어 디렉터(로봇 학습 컨퍼런스 CoRL 창설자). 좌장: 엔비디아 로봇공학 연구 책임자(자막 표기 "토 폭스")

반후크는 구글에서 초기에 GPU를 대량 확보해 세계 최초로 GPU 학습 심층신경망을 제품(구글 음성 검색)에 적용했던 일화로 시작한 뒤, 대규모 언어 모델의 등장이 로봇공학의 토대를 어떻게 다시 짜게 했는지를 연대기적으로 풀어간다. LLM 등장 당시 로봇공학계에는 FOMO가 있었지만 "이길 수 없으면 함께하라"며 연결고리를 탐구했고, 그 연결이 예상보다 훨씬 깊었다는 것이 발표의 골자다. 첫 시도는 챗봇에게 로봇 역할을 시키는 것이었는데, 커피 만들기의 상식적 절차는 잘 알지만 로봇의 실제 능력과 환경은 전혀 모른다는 간극이 드러났다. 이를 메운 것이 SayCan(자막 표기 '션') 프로젝트로, LLM이 제안하는 행동 가설들을 강화 학습으로 얻은 가치 함수가 현재 상황에서의 실행 가능성으로 점수 매겨 재순위화하고, 계획 문제를 기하학이 아닌 의미론 공간으로 끌어올렸다.

이어 로봇 내부의 인지-계획-제어 파이프라인에서 계획기를 LLM으로 바꾸자 자연어가 내부 API가 되었고, 시각 언어 모델·오디오 모델 등 여러 모델이 "로봇 안의 작은 채팅방"에서 대화하며 세계 상태에 합의하는 소크라틱 모델 구조로 발전했다고 설명한다. 이 구조는 내부 독백이 완전히 읽히는 인간 중심적 시스템이어서 실패 감지·재계획(탄산음료가 사라지면 다른 것을 찾는 사례)이 가능하고, 공이 두 개인 전자레인지 과제처럼 모호할 때는 적합 예측(conformal prediction)으로 모호성을 감지해 되묻는다. 데이터 수집을 위해 로봇에게 스스로 탐색 목표를 세우게 한 실험에서는 로봇이 노트북 집기를 좋아해 "전기 제품·날카로운 물건 금지" 같은 자연어 안전 지침(챗봇의 헌법적 AI와 유사한 의미론적 안전 계층)을 추가했다는 일화도 전한다. 제어 쪽에서는 '정책으로서의 코드(Code as Policies)'로 LLM이 인지·제어 API를 조합한 코드를 재귀적으로 생성하게 했고, 네발 로봇에게 대화("발을 더 높이", 엄지 올리기/내리기)만으로 하이파이브를 가르치고 그 대화를 다시 학습시켜 더 적은 턴으로 배우는 모델을 만든 사례, 오픈소스 시뮬레이터 MuJoCo 3세대와 GPU 병렬 구현을 소개한다.

후반부는 모델 융합의 역사다. PaLM-E(자막 'Paline')는 비전 인코더와 언어 모델을 함께 학습시킨 초기 멀티모달 모델로, 로봇용으로 만들었는데도 시각 질의응답·캡션 등 일반 작업 성능이 유지되었고 나중에 의료 데이터로 미세 조정되어 당시 최첨단 멀티모달 의료 모델(Med-PaLM M)이 되었다. 또 로봇 간 긍정적 전이가 처음 확인되어, 특정 로봇 전용 데이터만 쓰는 것보다 모든 로봇 데이터(심지어 시각 질의응답까지)를 합쳐 학습한 모델이 더 나았다고 강조한다. RT-1은 명령·이미지를 토큰화해 제어 동작을 직접 출력하는 엔드투엔드 트랜스포머로 3Hz로 구동되며, 처음으로 훈련 작업 성능을 포화시켰다. 제거 실험에서 가장 다양한 소량의 데이터를 빼자 성능이 급락해 "데이터 다양성이 핵심이며 단일 과제 집중이 오히려 해가 된다"는 교훈을 얻었다. RT-2는 대형 시각 언어 모델에 로봇 행동을 '또 하나의 언어'로 추가한 모델로, 본 적 없는 테일러 스위프트 사진 위로 대구 통조림을 옮기고 "바나나를 2+1의 합으로 옮겨" 같은 추론 결합 명령을 수행한다. 스케일링 법칙이 로봇 기초 모델에도 나타나며 아직 포화되지 않았다고 말한다. 여러 연구실과 데이터를 모은 크로스 임베디먼트 실험(Open X-Embodiment)에서는 정규화도 하지 않은 잡다한 데이터로 학습한 모델을 대학 파트너들이 제로샷으로 받아 기준선을 넘었다. 질의응답에서는 안전은 심층 방어에 의미론적 계층을 더하는 것이고 현실 관찰로 접지하면 환각이 크게 준다는 점, 현 VLM의 기하·공간 추론 약점과 폐루프 시각 서보 제어로의 보완, 생성 코드는 시뮬레이션에서 먼저 검증한다는 점, 가장 기대하는 응용은 시스템 통합 없이 자연어로 로봇을 재할당하는 것임을 답했다.

팬은 2016년 알파고-이세돌 대국을 보며 느낀 흥분과, 알파고가 "한 가지밖에 못 한다"는 한계 인식을 출발점으로 삼는다. 범용 에이전트를 기술 수·신체(embodiment) 수·현실(reality) 수라는 세 축의 지도로 정의하고, 올해 초 젠슨 황의 지원으로 설립한 GEAR 랩(Generalist Embodied Agent Research, 유쿠 주와 공동 리더)의 여정을 이 축들을 따라 소개한다. 범용 에이전트의 요건으로 무한한 환경, 대규모 사전 지식, 확장 가능한 기초 모델 세 가지를 꼽고, 첫 실험장으로 역사상 가장 많이 팔린 게임이자 활성 플레이어 1억 4천만 명(영국 인구의 두 배 이상)의 마인크래프트를 택한다. MineDojo 프레임워크는 시뮬레이터 API, 데이터베이스(유튜브 영상 30만 시간 이상·자막 20억 단어 이상, 7,000페이지 멀티모달 위키, 서브레딧), 모델로 구성된다. 영상과 대본을 대조 학습으로 정렬한 MineCLIP은 행동 영상과 텍스트 설명의 연관성을 0~1로 채점하는 언어 조건 보상 모델이 되어 강화 학습의 보상 함수로 쓰이며, 팬은 이를 "본질적으로 RLHF"라고 설명한다.

2023년 GPT-4 등장 이후 만든 Voyager는 '행동으로서의 코딩'을 구현한 에이전트다. 마인크래프트 세계를 텍스트화하는 오픈소스 모드를 통해 GPT-4가 자바스크립트 스킬 코드를 생성하고, 실행 오류·에이전트 상태(배고픔·체력)·세계 상태 세 가지 피드백으로 자가 수정하며, 숙달된 기술을 스킬 라이브러리에 저장해 재귀적으로 능력을 부트스트랩한다. "최대한 많은 새 아이템을 얻으라"는 상위 지시만으로 자동 커리큘럼을 실행하며 사람 개입 없이 수 시간씩 탐험·제작·전투를 이어 가고, 조감도 비교에서 가장 넓은 이동 반경을 보여 '보이저'라는 이름이 붙었다. 배고픈 에이전트가 고양이·주민 살해를 스스로 기각하고 돼지 사냥 기술을 새로 배우는 내부 독백 사례도 소개한다. 다음 축인 다중 신체 제어로는 스탠퍼드와 공동 개발한 MetaMorph를 설명한다. 로봇을 관절 운동학 트리로 토큰화해 "신체를 문장으로" 표현하고, 수천 가지 팔다리 구성의 로봇을 하나의 트랜스포머 정책으로 병렬 학습시켜 계단·불규칙 지형·장애물 회피를 수행하며 본 적 없는 형태에도 제로샷 일반화됨을 보였다.

세 번째 축(현실 간 전이)은 Isaac Sim이 담당한다. 실시간보다 천 배 빠른 물리 시뮬레이션으로 가상 훈련 10년 치를 3일에 압축하고(무술 캐릭터 사례), 레이 트레이싱 기반의 사실적 렌더링과 절차적 무한 세계 생성으로 "1만 개의 시뮬레이션에서 훈련하면 물리 세계는 10,001번째 현실이 된다"는 구도를 제시한다. 이 위에서 Eureka는 GPT-4가 환경 코드와 작업 설명을 읽고 보상 함수를 생성·샘플링하면, 대규모 병렬 시뮬레이션 덕에 보상 함수 하나당 며칠이 아닌 약 20분 만에 강화 학습을 끝내고, 자동 피드백 보고서로 자기 성찰·개선을 반복하는 진화적 탐색 시스템이다. 다섯 손가락 로봇 손의 펜 돌리기처럼 사람이 수동 조정하기 악몽 같은 과제에서 전문가가 만든 보상 함수보다 나은 결과를 얻었다. 팬은 이를 추론 전용 블랙박스 LLM(외부 루프)이 학습 가능한 신경망(내부 루프)을 지시하는 '하이브리드 그래디언트 아키텍처'라 부른다. 마지막으로 전날 기조연설에서 발표된 프로젝트 그루트(GR00T)를 GEAR 로드맵의 핵심으로 소개한다. 휴머노이드용 기초 모델을 목표로, 푸리에 인텔리전스 GR-1의 영상 기반 춤 모방, 원격 조종 시연 학습(과즙 짜기), 드럼 연주 사례와, DGX(학습)·OVX(시뮬레이션)를 조율하는 컴퓨팅 오케스트레이션 시스템 OSMO를 언급한다. 질의응답에서는 시스템 1(고주파 운동 제어)과 시스템 2(저주파 추론)의 결합, MineCLIP의 언어 조건 판별자적 성격, 시뮬레이션-현실 격차와 도메인 무작위화, "로봇 제어 데이터는 인터넷에서 긁을 수 없다"는 데이터 문제(인터넷+시뮬레이션+실로봇 데이터 조합 전략), Sora류 영상 모델에서 행동 추출의 난제 등을 다뤘다.

지식재산권 주제에서 커닝햄은 미국 저작권청이 기계 생성 결과물 자체는 저작권 보호 대상이 아니라고 판단한 점을 들어, 지재권법의 근본 목적이 인간의 지적 노력 보호에 있고 기계에는 창작 유인이 필요 없으므로 보호가 기계 창작물로 확대되지는 않을 것이라 전망한다. 대신 프롬프트를 넘어 스케치·조합 등 인간 통제가 늘면서 인간 기여분과 기계 기여분의 경계 판별이 법원의 난제가 될 것이라 본다. 그린은 소유권 문제를 운영자·알고리즘 제작자·데이터 제공자가 얽힌 협업으로 보되 책임은 결국 인간에게 귀속된다고 정리하고, 이는 챗봇이 고객에게 잘못된 정보를 제공해 수백 달러의 손해를 입힌 에어캐나다 책임 판결 논의로 이어진다. 커닝햄은 "AI 도구도 다른 소프트웨어와 다를 바 없으며, 법률상 AI 예외 조항은 없다"는 입장으로, 작년 4월 FTC 등 미국 기관들의 공동 성명과 뉴햄프셔의 바이든 음성 가짜 전화에 기존법이 적용된 사례를 든다.

선거를 앞둔 딥페이크·허위 정보에 대해서는 인식 제고와 제작자·조직에 대한 책임 추궁("기술이 아니라 사용 목적과 의도를 평가해야 한다")이 강조되고, 커닝햄은 수정헌법 제1조 때문에 규제는 실제 위험을 특정해 좁게 설계해야 하며 딥페이크의 실제 영향 규모에 대한 논쟁이 이어질 것이라 전망한다. 안전장치로는 프롬프트 필터(맥락 의존성 때문에 규칙화가 어렵고, 낚시 이메일을 막으려면 이메일 작성 자체를 막아야 하는 딜레마), RLHF(과도하게 보수적이 되는 부작용), 기본 LLM의 출력을 다른 LLM이 평가하는 고비용 방식이 소개된다. 오픈소스 공개 여부에 대해서는 Llama 2의 가중치·레이어를 분석해 참/거짓 표현을 식별한 표현 공학 연구처럼 폐쇄형으로는 불가능한 안전성 연구의 이점과 오남용 위험의 균형 문제로 정리하고, [밀란 무스] 모델(3,840억 개 매개변수로 언급)의 오픈소스 공개 소식도 거론된다. 규제 방향에 대해 커닝햄은 EU AI 법안처럼 대규모 감시·자동화된 중대 결정 등 제한적 사용 사례를 금지하는 접근을 지지하되, 혁신하지 못한 기회비용은 파악하기 어렵다며 광범위한 규제를 경계한다. 마무리 발언에서 패널들은 각각 조직이 개발 단계에서 윤리를 진지하게 다루는 것, AI가 기존 불평등을 강화하지 않고 모두에게 이익이 되는 것과 NIST AI 프레임워크 같은 합의된 기준, 위험 벤치마크 개발, 컴퓨터공학·경영 교육에서 윤리학 필수화를 '윤리적 소원'으로 꼽았다.

### 「Accelerating Drug Discovery by Combining Quantum-Based Models w/ Machine Learning | NVIDIA GTC 2024」
- **링크**: https://www.youtube.com/watch?v=iv2y-cb2Yt4
- **업로드일 / 분량**: 2024-04-12 / 약 1,897단어
- **발표자**: 자막 표기 "SBAN 대학교의 루아 가더" — 소속 대학·성명의 정확한 표기는 자막 훼손으로 특정 불가(프랑스 소재 대학 연구자, Tinker-HP 개발 그룹)

사전 녹화형 단독 강연으로, 분자 시뮬레이션에서 양자 기반 모델과 머신러닝을 결합해 신약 개발을 가속하는 연구를 소개한다. 원 영상이 약 1,897단어 분량의 짧은 발표라 요약도 상대적으로 짧다. 발표자는 먼저 분자 시뮬레이션의 품질이 원자 간 상호작용 포텐셜 모델의 정확도에 달려 있으며, 신약 개발에서는 단백질·RNA 같은 표적에 결합해 기능을 억제하는 소분자를 찾기 위해 결합 부위와 결합 과정을 모델링해야 한다고 설명한다. 전통적 2체(pair) 모델로는 부족한 이방성·환경 반응성을 담기 위해, 전하 밀도의 다중극(multipole) 기술과 다체 분극(many-body polarization)을 포함한 차세대 편극성 모델을 사용한다. 이를 통해 약한 상호작용까지 포함한 미묘한 에너지 차이, 결합 자유 에너지 계산, 중금속·이온성 액체 모델링이 가능해진다고 말한다.

이어 고성능 구현의 여정을 다룬다. 10년 전에는 고성능 편극성 모델 구현이 전무했고 OpenMP 공유 메모리 병렬화 수준이었기에, MPI 기반 CPU 구현의 Tinker-HP를 개발해 페타스케일에 대비했다(2018년 Chemical Science 논문). 이후 NVIDIA GPU용 버전을 개발했는데(2021년 Journal of Chemical Theory and Computation 논문), 구현은 두 갈래다 — OpenACC 지시어에 전적으로 의존하는 배정밀도 버전(V100·A100용)과, OpenACC로 데이터 전송을 처리하되 최적화된 CUDA 커널을 쓰는 혼합 정밀도 버전(에너지·힘 커널은 단정밀도, 누적은 배정밀도). 거의 모든 연산을 GPU에 올려 CPU-GPU 동기화를 최소화하고, 다중 GPU는 3D 도메인 분해와 CUDA 인식 MPI로 직접 통신한다. 벤치마크는 프랑스 Genci의 Jean Zay와 엔비디아 Selene(DGX-A100, NVSwitch) 슈퍼컴퓨터에서 수행되어, DHFR(약 2만 원자)에서 하루 40ns 이상, 100만 원자 이상 STMV에서 하루 4ns 이상, 700만 원자 이상 시스템에서 하루 약 1ns 수준의 처리량을 얻었다. STMV 기준으로 8코어 CPU의 기존 Tinker OpenMP 구현 대비 다중 GPU CUDA 구현은 약 6,000배 성능 향상이라고 밝힌다. 소규모 시스템은 GPU 1개로 충분하고 약 20만 원자부터 다중 GPU가 유리해진다는 스케일링 특성도 제시한다.

응용의 중심은 소분자 결합 친화도 예측이다. 결합 상태와 비결합 상태 사이의 자유 에너지 차이를 연금술적(alchemical) 방법과 열역학 사이클로 계산하며, 이는 수많은 긴 분자동역학 궤적을 요구하므로 고성능 코드가 필수적이다. 블라인드 방식의 SAMPL 챌린지에서 편극성·다중극 AMOEBA(자막 표기 'amiba') 모델이 반복적으로 우수한 성적을 냈고, 작년 챌린지에서는 거의 모든 경우 실험값과 [1킬로그램/몰] 이내(자막 훼손 표기)로 일치해 최첨단 성능에 해당한다고 말한다. 마지막으로 머신러닝 결합을 다룬다. 편극성 모델도 단거리 양자 효과와 반응성(결합 파괴)을 못 담으므로, 정제된 양자역학 데이터셋으로 학습한 머신러닝 포텐셜을 Deep-HP 플랫폼으로 Tinker-HP에 통합했다. 접근은 두 가지 — 관심 영역은 ML, 나머지는 편극성 힘장으로 처리하는 임베딩 방식과, ML로 원자 특성(전하·부피 등)을 예측해 고전 함수 형태에 넣는 'Phoenix'(force field enhanced neural network interactions) 등가 접근이다. AMOEBA 단독 대비 ML 결합 시 일부 시스템에서 RMS 오차가 1.81에서 1 이하(자막 표기 kJ/mol)로 약 2배 감소했고, CH4·물·HF의 해리 곡선에서 기존 ML 모델 단독은 비물리적 결과를 내는 반면 Phoenix는 기준값에 근접해 반응성을 확보했음을 보인다. 이 도구들은 프랑스·미국 연구진이 설립한 Cubit Pharmaceuticals에서 실제 신약 개발에 활용 중이라고 맺는다.

### 「Accelerating Simulations of Multiscale Chemical Reactors | NVIDIA GTC 2024」
- **링크**: https://www.youtube.com/watch?v=nABKmVJDBz0
- **업로드일 / 분량**: 2024-04-15 / 약 2,180단어
- **발표자**: 3인 공동 — 엔비디아 머신러닝 연구원(자막 표기 "판다", 전 Shell HPC 연구원), 하렐 파텔(Shell 테크놀로지 센터 뱅갈로르, 과학 머신러닝 연구원), 티밀(자막 표기, SoftServe R&D 연구원)

Shell과 SoftServe의 협력으로 NVIDIA Modulus를 사용해 물리 정보 신경망(PINN)으로 다상 화학 반응기 시뮬레이션을 가속한 사전 녹화 발표다. 원 영상이 약 2,180단어의 짧은 기술 발표라 요약도 간결하다. 도입부에서 PINN을 물리(지배 방정식 기반 시뮬레이션)·데이터(방정식이 알려지지 않은 관계나 센서 데이터)·인공신경망의 교차점으로 정의하고, 물리 기반 손실 함수를 최소화하므로 일반 머신러닝과 달리 무의미한 예측을 피하도록 훈련된다는 가치 제안을 제시한다. 배경은 가스-액체 전환(GTL) 공정으로, Shell은 1993년 말레이시아 빈툴루(자막 표기 "벤투")에 첫 상업 플랜트를 가동한 시장 선도 기업이며 현재 카타르에서 펄(Pearl) 플랜트를 운영한다. 탄소 함유 물질을 합성가스(일산화탄소+수소)로 전환한 뒤 피셔-트롭쉬 반응기에서 액체 연료·왁스 같은 합성 탄화수소로 바꾸는 공정이 핵심이다.

이 반응기의 모델링은 다중 물리·다중 스케일 문제다. 공장 전체 → 반응기 → 촉매 펠릿 → 표면 미세운동학 → 분자 이론까지 스케일이 캡슐화되어 있어, 상위 스케일을 풀려면 하위 스케일의 결과가 필요하다. 발표는 이 중 미세운동학 모델과 펠릿 모델 두 가지에 PINN을 적용한다. 파텔이 설명하는 미세운동학 모델은 반응물이 생성물로 전환되는 속도를 기술하는 대수적 비선형 연립방정식으로, 탄소 원자 n개를 모델링하면 n+1개의 방정식(사슬 성장 확률 n개 + 촉매 활성 부위의 빈자리 비율 1개)이 된다. 전통적으로는 SciPy 등의 근 찾기 솔버로 풀며 단일 코어 CPU에서 약 0.1초가 걸리는데, 다중 스케일 모델링에서는 이를 무수히 반복해야 해 비효율적이다. PINN 대리 모델은 고정 데이터셋 없이 입력 매개변수 공간(농도·분압·온도)을 무작위 샘플링하고 기존 물리 모델과의 잔차를 손실로 학습한다. 결과적으로 중앙값 상대 오차 0.1%를 유지하면서, 동일 CPU에서 배치 크기를 키울 때 [10배에서 3배], V100 GPU에서는 [10배에서 5배]의 속도 향상(자막의 지수 표기 훼손 추정 부분은 원문 그대로 표기)을 얻었다고 밝힌다. 학습된 모델은 미분 가능하므로 원하는 수율 프로파일에 맞는 온도·압력 조건을 찾는 최적화에도 쓸 수 있다.

이어 티밀이 확산 PINN(DPNN)을 설명한다. 펠릿 외부 표면의 반응 조건을 입력으로 받아 펠릿 내부의 온도·물질 농도의 반경 방향 분포 곡선 전체를 출력하고, 이를 앞서 학습한 미세운동학 PINN과 결합해 모든 지점의 반응 속도를 계산한 뒤 펠릿 부피로 적분해 탄화수소 생성 속도와 반응물 소모 속도를 얻는다. 이 이론 기반 워크플로는 실험 데이터에 계수를 맞추는 기존의 경험적 소스 항 접근과 달리 명확한 화학적 해석을 제공하면서도 계산 비용은 경험식보다 약간 높은 수준에 그친다. 정확도는 올레핀·파라핀 생성 속도, 반응물 소모량, 펠릿 온도 프로파일의 상대 오차가 일반적으로 2% 미만이고, 속도는 단일 CPU 코어 기준 기존 솔버 대비 거의 세 자릿수 향상, GPU 사용 시 그 이상이라고 보고한다. 결론적으로 물리 정보 신경망이 미세운동학과 펠릿 두 스케일 모두에서 기존 수치 해법을 대체할 수 있음을 입증했으며, 전체 반응기 규모 모델과 궁극적으로는 디지털 트윈 구축에 활용하겠다는 계획으로 마무리한다.

### 「Enabling Digital Twins for Science: A Perspective from CERN openlab | NVIDIA GTC 2024」
- **링크**: https://www.youtube.com/watch?v=70RxWJbes9E
- **업로드일 / 분량**: 2024-04-15 / 약 2,248단어
- **발표자**: 마리아 지로네(Maria Girone) — CERN 오픈랩(openlab) 책임자(전 openlab CTO). 진행: 톰(자막에서 성·소속 특정 불가)

원 영상이 약 2,248단어의 비교적 짧은 발표라 요약도 간결하다. 지로네는 CERN을 세계 최대 입자물리 연구소로 소개하며, 우주의 기본 입자와 법칙을 이해하기 위해 빅뱅 직후의 상태를 재현하는 가속기 시스템과, 충돌을 관측하는 거대한 카메라 격의 검출기를 설명한다. 대표 설비인 대형강입자충돌기(LHC)는 지하 100m, 둘레 27km에서 절대영도에 가까운 영하 273도의 초전도 자석으로 입자를 광속에 가깝게 가속하며, 범용 실험 2기(ATLAS 및 또 하나의 범용 검출기 — 자막에는 "대형 아틀라스와 아틀라스"로 훼손 표기)와 쿼크-글루온 플라스마를 연구하는 ALICE, 물질-반물질 비대칭을 연구하는 LHCb가 있다. 초당 4천만 번의 충돌에서 수백만 개의 전자 신호를 읽어 선택·필터링을 거쳐 초당 수천 건의 이벤트만 기록하며, 이미 엑사스케일 과학의 영역에 있다고 말한다. AI는 데이터 수집, 엣지 저지연 1차 필터링, 시뮬레이션, 재구성, 분석까지 전 단계에서 활용되고 있다.

현재 LHC는 3차 가동(Run 3)의 데이터 수집 2년 차로, 전체 예상 데이터의 10%만 수집한 상태다. 2030년까지 고휘도 LHC(HL-LHC)로 업그레이드해 나머지 90%를 수집할 예정인데, 이 전환은 교차당 평균 충돌 수가 현재 50에서 200으로 늘어나는 훨씬 복잡한 이벤트 분석을 뜻한다. 이에 따라 가속기 업그레이드와 장기 가동 중단, 더 세밀한 검출기 교체, 필터링 패러다임 변경이 필요하고, 고정된 자원 예산 안에 들어가기 위한 코드 현대화, 하드웨어 가속기 도입, 스토리지 절감, AI, 나아가 양자 컴퓨팅까지 연구 개발이 진행 중이라고 설명한다. 미래 프로젝트로는 제네바 지역 쥐라 산맥과 살레브 산맥 사이, 레만 호수 아래를 지나는 약 100km 터널의 미래원형충돌기(FCC) 타당성 조사가 이미 시작되었다고 소개한다.

이런 과제 때문에 산업계·타 과학 분야와의 협력이 핵심이며, 그 창구가 20년 이상 활동해 온 CERN openlab이다. openlab은 3년 단위 단계로 운영되고 현재 8단계에 진입했으며, 지속 가능한 컴퓨팅·스토리지 개척, 신흥 컴퓨팅과 AI 활용, 과학-산업 간 기술 교류를 목표로 한다. 오늘의 주제인 디지털 트윈에서는 유럽연합 집행위원회 지원의 interTwin 프로젝트를 소개한다. 약 30개 기관이 참여해 오픈소스 플랫폼과 개방 표준으로 학제 간 통합 디지털 트윈 엔진 프로토타입을 공동 설계하며, CERN은 대규모 AI 워크플로 핵심 엔진과 연합 데이터 레이크 인프라에 전문성을 보탠다. 물리학 쪽 사용 사례로는 생성형 알고리즘으로 검출기 반응을 시뮬레이션해 Geant4(자막 표기 "JM4") 같은 최첨단 도구와 비교 가능한 고속 시뮬레이션을 구현하는 입자 검출기 디지털 트윈이 있고, 전파천문학·중력파·격자 QCD 분야, 그리고 산불·폭풍·홍수·가뭄 같은 극한 기상 현상 대비용 기후·환경 트윈도 포함된다. 유럽중기예보센터(ECMWF)·폴란드 슈퍼컴퓨팅 센터와는 ERA5 데이터셋으로 학습하는 대기 모델링 기반 모델 프로젝트도 진행 중이다. 최근에는 엔비디아 옴니버스와의 개념 증명으로 CAD 모델을 USD로 가져와 빔라인 등 설비를 협업 시각화했으며, 검출기·가속기 조립 시뮬레이션, 협소 공간 로봇 응용, 시뮬레이션 이벤트 시각화로 확장하고 싶다는 계획을 밝힌다. 발표는 HPC 분야 여성 커뮤니티에 대한 감사 등 다양성 언급으로 마무리되고, 질의응답에서는 신경망 기반 트윈 결과를 정책 결정자에게 설명하는 문제에 대해 "아직 도입 초기 단계라 향후 과제에 가깝다"고 답했다.

- **업로드일 / 분량**: 2024-04-16 / 약 5,852단어
- **발표자**: 데이비드 루안(David Luan, Adept CEO·공동 창업자, 전 OpenAI 엔지니어링 부사장) × 브라이언 카탄자로(Bryan Catanzaro, 엔비디아 응용 딥러닝 연구 부사장) 대담

두 사람의 대담은 엔비디아가 자체 AI를 개발하는 이유에서 출발한다. 카탄자로는 첫째로 가속 컴퓨팅의 본질 — "가속 컴퓨팅은 거의 모든 면에서 감속 컴퓨팅", 즉 특화가 핵심이며 무엇을 특화할지 알려면 AI를 직접 만들어야 한다는 점, 둘째로 모든 기업이 자기 데이터와 정체성으로 AI를 접목하도록 돕는 플랫폼 사업의 필요를 든다. 스케일링에 대해 그는 "20년간 AI 확장성에 투자해 왔다"며 2008년 ICML에서 GPU 머신러닝 논문을 발표하던 시절을 회고하고, 데이터와 컴퓨팅의 규모가 세상을 바꾼다는 확신이 지금은 자명해 보이지만 "필요한 건 확률론 박사가 더 많다고 믿고 싶은" 연구자들에게는 실망스러운 결론이기도 하다고 말한다. 루안은 AlexNet의 본질이 새 아이디어보다 합성곱 신경망을 GPU 2개에 효율적으로 매핑한 공학이었다는 점, GPT-2 논문에서 모델링 서술은 한 단락뿐이라 학계의 혹평을 예상했고 실제로 받았다는 일화로 "AI 발전의 메타 게임은 기존 학계에서 무시당한다"는 관찰을 보탠다.

루안은 Adept를 "인간이 컴퓨터에서 하는 모든 것을 할 수 있는 AI 에이전트 훈련"을 목표로 하는, 제품과 연구를 공동 설계하는 회사로 소개한다. 이메일로 온 청구서를 퀵북스에 입력하거나, 물류 고객사가 컨테이너 생애주기(위치 추적·통관 확인)를 Adept로 자동화한 사례처럼, 모델이 의도적으로 80%를 수행하고 나머지 20%를 인간이 감독하는 구조를 지향한다. 이 감독 피드백이 데이터 플라이휠이 되어 모델을 개선한다는 것이다. 카탄자로는 이를 받아 "쉽게 접근 가능한 토큰의 시대가 끝나가고 있다"고 진단한다. 대규모 언어 모델 훈련에 수십조 개의 텍스트 토큰이 필요한데 이는 인류가 인터넷에서 접근 가능하게 쓴 텍스트 총량과 거의 같으며, 남은 길은 전문화라는 것이다. 가장 가치 있는 데이터는 가장 철저히 보호되는 데이터(개인의 문자·의료 기록, 기업의 비밀)라는 논지와 함께, "모든 회사는 비밀 위에 세워진다 — 젠슨이 30년간 가속 컴퓨팅을 외쳐도 세상이 이해하지 못한 것처럼"이라는 비유를 든다. 루안은 2018년 더크 킹마(Durk Kingma)와의 술자리 대화("행동 복제가 일반 지능으로 가는 경로일지 모른다")를 회고하며 현재 LLM이 바로 그것이지만, 모델은 훈련 데이터의 가장 똑똑한 데이터만큼만 똑똑하고 새로운 지식 발견은 오히려 불이익을 받는 한계가 있다고 지적한다. ASCII 아트 때문에 학습이 발산했던 일화, 캐논 프린터 시리얼 번호로 가득했던 코퍼스 등 데이터 품질의 '전투 상처'도 오간다.

미해결 연구 과제로 카탄자로는 추론 시점의 적응형 컴퓨팅을 꼽는다. 현재 모델은 모든 토큰에 같은 계산을 쓰지만, 시험 문제처럼 어떤 답은 천 배 더 생각해야 하며, "배포 단계의 씁쓸한 교훈(bitter lesson)"이 아직 실현되지 않았다는 것이다. 루안은 사전학습이 능력의 상한을 정하고, 사후학습(SFT·RLHF·강화 학습·자기 실행)이 향후 1~2년간 불연속적 발전을 낳을 영역이라고 본다. 카탄자로는 비욘세를 예로 들어 지능의 다차원성(80억 인구에 80억 차원)을 이야기하며 사람을 대체하는 AI보다 문자·수학·계산기처럼 인지를 확장하는 '인지 도구'로서의 AI를 지지하고, 두 사람 모두 상호작용 원칙을 처음부터 다시 설계해야 한다는 데 동의한다. 기대 분야로 루안은 행동 궤적까지 포함하는 옴니모달 기초 모델과, 구글 시절 자금 지원을 도왔던 암스테르담 팀의 사례 — 지구를 셀로 나눠 텐서로 취급해 다음 시간 단계를 예측하는 것만으로 물리 시뮬레이터를 능가한 날씨 예측 모델 — 를 든다. 카탄자로는 가상 세계(옴니버스)와 AI가 만드는 새로운 미디어, 그리고 저정밀 연산이 한계에 달한 뒤의 희소성(sparsity) 활용을 꼽는다. 질의응답에서는 매개변수 수를 카메라 화소 전쟁에 비유하며 처리 플롭스가 더 나은 지표라는 답, 다음 토큰 예측의 단순성은 생화학의 단순성이 지능을 부정하지 않는 것과 같다는 방어, 합성 데이터는 유용하지만 결국 생성기 자체를 모델링하게 되는 함정을 경계한다는 논의가 이어졌다.

### 「Deploying AI in Real-World Robots | Aaron Saunders, Boston Dynamics CTO | NVIDIA GTC 2024」
- **링크**: https://www.youtube.com/watch?v=9vxQALsfpcY
- **업로드일 / 분량**: 2024-04-17 / 약 5,664단어
- **발표자**: 아론 손더스(Aaron Saunders) — 보스턴 다이내믹스 CTO(로봇공학 20년 경력)

손더스는 "30년 된 스타트업" 보스턴 다이내믹스의 역사를 10년 단위로 개관한다. 첫 10년은 로봇이 아니라 마크 레이버트가 MIT에서 시작한 물리 기반 시뮬레이션 사업이었고, 중간 10년은 로봇이 현실임을 입증하는 시기, 지금은 상용화 시기다. 현재 직원 약 800명에 약 1,500대의 로봇을 실제 환경에 배치했다. 제품은 셋 — 반도체 공장 지하의 열화상 설비 검사, 원자력 해체 현장, 광산 등에서 수천 대가 자율 운용되는 4족 보행 로봇 Spot, 트럭에서 골판지 상자를 내리는 물류 로봇 Stretch(올해 약 300만 개의 상자를 옮길 전망으로, 흰긴수염고래 200마리 무게에 해당한다는 비유를 전한다), 그리고 상용 판매 계획은 없지만 기술을 견인하는 연구 플랫폼 휴머노이드 Atlas다. 회사의 핵심 역량은 고도로 통합된 하드웨어·소프트웨어이며, 뛰어난 하드웨어가 시뮬레이션-실제 격차를 줄여 AI 배포를 성공시킨다고 강조한다. 상업적 목표가 연구의 집중력을 만든다는 점도 반복된다. 여흥으로는 엔지니어가 ChatGPT를 Spot에 연결해 만든 '빈정거리는 조쉬' 관광 가이드 데모를 소개하며, 공학적으로는 단순한 연결이지만 로봇과 대화하는 미래를 보여 준다고 평한다.

기술 서사의 축은 "동작을 더 빨리, 더 신뢰성 있게 만드는 법"이다. 5~6년 전 Atlas의 점프 하나를 추가하는 데 단순 모델 기반 제어의 수동 조정으로 몇 달~몇 년이 걸렸던 시절에서, 참조 궤적(오프라인 최적화, 애니메이션, 모션 캡처, 영상)을 입력받는 모델 예측 제어(MPC)로 옮겨 왔다. 초기 백플립은 로봇이 완전히 회전하지 못해 플랫폼 위에서만 가능했는데, 단일 질량 근사와 운동학 매핑의 2단계 캐스케이드를 전신 동역학·관성을 동시에 푸는 단일 최적화로 묶자 로봇이 스스로 몸을 웅크리는 동작을 '선택'하며 평지 백플립에 성공했다는 일화가 대표적이다. 이 툴체인은 현재 조작(manipulation)으로 확장 중으로, 무거운 자동차 휠과 머플러를 자율적으로 집어 옮기는 초기 결과를 보여 준다. 관성적으로 유의미한 무거운 물체와의 상호작용이 의도된 난제이며, 물체 사전 정보와 학습된 파지 모델을 쓰되 픽셀-투-모션의 완전한 엔드투엔드 AI는 아니라고 선을 긋는다.

GTC 발표의 핵심은 Spot에 강화 학습(RL)을 상용 배포한 이야기다. Spot 함대는 누적 25만 km(3개월마다 지구 한 바퀴 분량)를 걸었지만 여전히 예외 상황이 나온다. 고객사의 유출 방지 구역 — 비눗물로 덮인 플라스틱 시트 바닥 — 에서 미끄러져 넘어지는 문제를 계기로, 휴리스틱이 게이트(보행 패턴)를 선택하던 구조 대신 RL 정책이 단일 MPC 컨트롤러의 매개변수를 조정하는 하이브리드 접근을 택했다. 마찰 계수·높이·경사를 바꿔 가며 시뮬레이션 검증한 결과 낙상 확률이 더 넓은 지형에서 낮아졌고, 부수적으로 해당 소프트웨어 스택의 연산 부하를 25% 줄였다. 신뢰성 지표로는 소프트웨어 버전 2.0에서 보행 낙상이 잦았던 수준에서 3.3 버전에 이르러 50km당 1회 수준으로 개선되었고, RL 도입 버전에서도 이 품질을 유지했다고 밝힌다. 사내 테스트 로봇들은 24시간 365일 가동되며 매주 약 2,000시간을 걷는다. "비결정적 컨트롤러를 어떻게 믿느냐"는 질문에는 "다른 컨트롤러와 똑같이 테스트, 테스트, 테스트"라고 답한다. 발표 말미에 엔비디아와 협력한 신제품 'Spot RL 연구 키트'를 공개한다 — 저수준 제어 API, Jetson AGX Orin 페이로드, 엔비디아 AI 개발 도구 지원으로 구성되며, 올해 하반기 차기 릴리스부터 파일럿 신청을 받는다. 보스턴의 AI 연구소(The AI Institute)가 첫 베타 고객으로 픽셀-투-모션 데모를 빠르게 만들었고 일부를 오픈소스 예제로 공개할 예정이다. 질의응답에서는 현대차 인수 후에도 상업화 여정은 연속적이라는 점, 옴니버스는 합성 데이터·시뮬레이션에서 가치가 크다는 점, 하드웨어 최대 병목은 배터리(고객은 최소 8시간을 원하고 Stretch는 16시간 구동)라는 점, 제품 보안·사이버 보안 체계 등이 다뤄졌다.

GTC 회고로는 Jetson 차세대 모듈 Thor와 프로젝트 그루트(AGX 폼팩터 800테라옵스, FP8 최적화, 100기가비트 이더넷 — 현행 AGX Orin 약 275테라옵스·64GB 대비 대폭 향상), 짐 팬의 체화 에이전트 연구, MIT 송 한(Song Han) 연구실의 VILA 계열 비전 언어 모델·AWQ·TinyChat, 최적화 추론에 쓰는 CMU Catalyst의 MLC/TVM을 언급한다.

회의의 최대 안건은 홈어시스턴트(Home Assistant) 통합이다. 목표는 LLM·VLM·ASR(음성 인식)·TTS(음성 합성)를 Orin Nano 8GB급 소형 저가 장비에서 동시 구동해 가정·로봇에 배포 가능한 인지 음성 에이전트를 만드는 것으로, 자연스러운 대화를 위해 매 턴 1~1.5초 수준의 응답 지연을 목표로 삼는다. 구체적 1단계는 홈어시스턴트의 Wyoming 프로토콜(오디오 스트림·TTS·ASR)용 컨테이너를 Jetson에서 CUDA 가속으로 재빌드하는 것이며, 우선 지원 대상은 Piper TTS, Faster Whisper, OpenWakeWord다. 참석한 홈어시스턴트 팀 마이크와 Piper의 ONNX 런타임 실행, 스트리밍 모드(인코더·디코더 분리), TensorRT 백엔드 프로파일링, 샘플링 레이트(22kHz 대 48kHz)와 음질, Riva ASR·TTS의 메모리 부담(5~6GB) 같은 실무 사항을 논의하고, GPU 사용률 10% 이하가 바람직하다는 목표치도 오간다. K2/Sherpa 같은 대안 ASR, Ollama의 Jetson 지원(홈어시스턴트가 Ollama 모델을 지원하므로 통합 경로가 됨), ESP32 박스·M5 Atom Echo(약 13달러)·ReSpeaker 등 위성 장치 하드웨어, 카메라·마이크·화면이 통합된 저가 클라이언트 기기의 필요성, 공개 도메인 음성 기증으로 비영어권 Piper 음성을 만드는 프로그램(스튜디오 대여비 지원)도 다뤄진다.

두 번째 안건은 '컨트롤러 LLM'이다. 사용자와 직접 상호작용하며 하위 전문 모델 파이프라인을 재조정하는 상위 모델 개념으로, Llama 7B로 시스템 프롬프트에 함수 목록을 넣고 날씨·시간 조회 같은 함수 호출(JSON 출력)을 구현한 초기 실험을 보여 준다. JSON은 토큰이 약 128개 늘어 속도가 느려지는 트레이드오프가 있고, 벡터 DB(FAISS 플랫 인덱스, MS COCO 35만 임베딩 처리) 기반 RAG를 장기 기억으로 붙여 "사용자에 대해 학습하는 어시스턴트"를 만들겠다는 구상, RAG로 함수 정의 자체를 동적으로 불러와 컨텍스트를 아끼자는 아이디어가 이어진다. 비전 쪽에서는 VLM이 Nano에서 초당 1프레임, AGX에서 약 3프레임(이미지 1장 = 클립 인코더 기준 576토큰, 프리필 약 300ms)이라는 현황과, 최대 8장 이미지의 연속 스트리밍·KV 캐시 롤링 윈도 처리 문제를 설명한다. 파트너 게리는 64GB AGX Orin에서 Mixtral급 대형 모델을 6비트 GGUF로 미세 조정·구동해 초당 약 50토큰을 얻은 경험, llama.cpp 대비 네이티브 엔진의 이점, 병렬 세션에 유리한 WasmEdge를 공유한다. 마지막 안건은 ML DevOps로, JetPack 6부터 GPU 커널 모듈 드라이버 분리로 최신 CUDA(12.4)를 직접 설치할 수 있게 된 변화, jetson-containers 빌드 시스템의 CUDA 버전별 자동 재빌드와 자체 pip 서버, 로컬 LLM 라이브러리의 NanoLLM 개명(허깅페이스 유사 API 대비 약 10배 성능, 멀티모달 채팅·KV 캐시 유지·ASR/TTS/웹서버 플러그인), TensorRT-LLM 지원 계획과 Day-0 모델 지원(Gemma 사례), Mamba 같은 신형 아키텍처 관찰 등이 공유된다. 회의는 격주 개최 합의, 포럼 기반 안건 접수, 시각 장애인 보조 기기 등 커뮤니티 응용 사례 소개로 마무리된다.
