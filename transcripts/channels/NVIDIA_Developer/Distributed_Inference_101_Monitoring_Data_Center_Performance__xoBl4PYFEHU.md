## 스크립트

안녕하세요. 오늘은 NVIDIA Dynamo 배포 환경에서 실시간으로 메트릭을 모니터링하고 시각화하는 방법을 보여드리겠습니다. 이 데모에서는 Dynamo serve 명령줄 도구를 사용하여 Dynamo를 이미 배포했다고 가정합니다. 이 배포 환경에는 두 개의 Vllm 워커와 그 앞에 KV 캐시 인식 라우터가 있습니다. 또한, 이 배포 환경 앞에는 OpenAI 호환 API 서버가 있으며, 쿼리를 실행하면 현재 Vllm 워커들이 Deep Seek R1 Distilled Llama 모델을 제공하고 있음을 알 수 있습니다. 이제 백그라운드에서 몇 가지 요청을 보내 부하를 발생시켜 보겠습니다. Dynamo 배포 환경의 메트릭을 모니터링하기 위해 Dynamo에는 다양한 Dynamo 배포 환경을 가리키도록 유연하게 구성할 수 있는 메트릭 애플리케이션이 제공됩니다. 이 애플리케이션은 주기적으로 배포 환경의 모든 워커에서 노출되는 모든 메트릭 또는 데이터를 수집하고, 모든 정보를 집계하여 시각화를 위해 Prometheus 호환 메트릭 서버에 게시합니다. 시각화에는 Grafana를 사용하겠습니다. Grafana는 호스팅된 Prometheus 메트릭 서버를 참조하여 데이터를 가져와 시각화합니다. 브라우저에서 대시보드를 살펴보겠습니다. 여기에는 여러 패널로 구성된 대시보드가 ​​있습니다. 먼저 표시 되는 주요 지표 몇 가지를 살펴보겠습니다. 왼쪽 상단에는 워커별 KV 캐시 사용률이 있습니다. 이는 LLM 워커 환경에서 두 개의 VM 워커를 사용하는 경우를 기준으로 각 워커에 대한 라인이 하나씩 표시되며, 현재 사용 중인 KV 캐시 메모리 양을 실시간으로 시각화한 것입니다. 각 워커는 일반적으로 추론 중에 KV 캐시 블록을 저장하기 위해 일정 비율의 메모리를 할당하는데, 이 표시는 현재 사용 중인 메모리 양을 보여줍니다. 마찬가지로 Dynamo 워커는 처리할 수 있는 최대 요청 용량을 설정할 수 있습니다. 이 패널은 각 워커가 전체 용량 중 현재 몇 개의 요청을 사용하고 있는지 시각화합니다. 이제 워커별 정보뿐만 아니라 모든 워커의 평균 사용률도 확인할 수 있습니다. 예를 들어 KV 캐시 사용률 게이지는 두 워커 모두 현재 60%의 사용률을 보여주고 있는데, 이는 평균값과 일치합니다. 마찬가지로 모든 워커의 평균 요청 슬롯 사용률도 확인할 수 있습니다. 더 자세히 살펴보기 전에 다음으로 넘어가겠습니다. 서버로 보내는 요청 유형을 약간 수정하여 프롬프트와 접두사가 겹치는 요청을 보내는 대신, 프롬프트와 겹치는 빈도가 매우 높은 요청을 보내도록 업데이트할 것입니다. 이렇게 하면 워커 에서 KV 캐시 적중률이 높아질 가능성이 커집니다. 대시보드로 돌아가서 KV 캐시 적중률에 초점을 맞춘 패널들을 살펴볼 수 있습니다. 예를 들어, 워커별 패널에는 각 워커에 대해 KV 캐시에서 적중한 토큰 또는 토큰 블록의 비율을 보여주는 두 줄이 있습니다. 예를 들어, 이 녹색 줄은 각 요청 프롬프트에서 겹치는 토큰의 KV 캐시 적중률이 약 15%임을 보여줍니다. 워커별 보기 외에도 모든 워커에 대한 전체 평균을 보여주는 집계 보기도 있습니다. 프롬프트가 많이 겹치도록 로드 또는 트래픽 패턴을 업데이트한 후 KV 캐시 적중률이 급격히 증가하는 것을 확인할 수 있습니다. 워커별 정보를 보는 것은 흥미로운데, 왜냐하면 우리는 또한 저희 배포 환경에서 KV 캐시 인식 라우터를 사용하면, 각 워커의 부하가 노란색과 녹색 선으로 표시되는데, 실제로는 약간씩 다르게 확장되는 것을 볼 수 있습니다. 워커 간에 무작위 또는 라운드 로빈 방식의 스케줄링이 이루어진다면 각 워커의 부하가 비슷하게 나타날 수 있지만, KV 캐시 인식 라우터를 사용하면 확연한 차이가 나타납니다. 녹색 워커는 KV 캐시 적중률이 더 높고, KV 캐시 사용률은 더 낮으며, 요청 슬롯 사용률은 더 높습니다. 즉, KV 캐시 인식 라우터는 KV 캐시 적중 가능성이 높은 중복 요청을 녹색 워커에 스케줄링하려고 시도하는 것입니다. 만약 트래픽 패턴을 더욱 개선하여 더 많은 고유한 프롬프트를 가진 요청을 보내면, 이 패널에서 KV 캐시 적중률이 떨어지는 것을 확인할 수 있을 것입니다. 이는 Dynamo 배포 환경에서 얻을 수 있는 정보의 일부 예시일 뿐입니다. 시청해 주셔서 감사합니다.
