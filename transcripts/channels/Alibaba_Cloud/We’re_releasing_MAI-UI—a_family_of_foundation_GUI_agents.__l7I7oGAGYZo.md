## 스크립트

Tony Lamp는 UI라는 기본 GUI 에이전트 제품군을 공식적으로 오픈 소스로 공개했습니다. 이 제품군은 일반적인 GUI 기반 및 모바일 GUI 탐색 벤치마크에서 최첨단 성능을 확립하며, 효율적인 2B부터 대규모 23B 모듈에 이르기까지 모든 스펙트럼에 걸쳐 주요 클로즈드 소스 및 오픈 소스 모듈을 모두 능가합니다. 이제 2B 및 8B 변형을 오픈 소스로 제공하여 특정 수준의 GUI 기능을 주머니 속에서 직접 사용할 수 있도록 하고 GUI 에이전트 분야에서 발생하는 실제 문제를 해결합니다. 내 UI는 여러 가지 발전된 기능을 도입했습니다. 이는 MCP2 칠 콜링, 노후화된 사용자 상호 작용 장치, 클라우드 협업을 기본적으로 통합하고, 여러 화면을 통해 찰칵 거리는 소리를 멈추기 위해 필요한 거리를 계산하는 데 필요한 강화 학습을 GUI 에이전트에 허용하는 최초의 기반 모델입니다 . 제 UI는 MCP 증강 기술을 도입하여 프레임 단위로 여러 단계를 거치는 UI 상호 작용을 하나의 효율적인 API 호출로 압축합니다. 예를 들어, 지도상의 거리를 한 번의 요청으로 직접 조회할 수 있습니다 . 이는 가장 강력한 기준선 대비 MCP 관련 작업의 성공률을 32.1% 포인트 향상시킵니다 . 조이 인텔리전스란 조종사 로서 사용자와 협력하는 방법을 아는 것을 의미합니다 . 지침이 모호할 경우, 제 UI는 잘못된 추측에 따라 행동하는 대신 상담원 사용자 상호 작용을 통해 사전에 명확화를 요청합니다. 이러한 능동적인 에이전트-사용자 상호작용은 모호한 작업에서 성공률을 기존 최고 수준 대비 18.7%포인트 향상시킵니다 . 고성능, 네트워크 연결 불필요 , 강력한 개인정보 보호 기능을 제공합니다. My UI는 자체 기기 클라우드 협업 시스템을 통해 기능을 제공합니다 . 경량 로컬 에이전트는 실행 및 모니터링을 처리하며, 실행이 사용자 의도와 다를 경우에만 클라우드 모델로 전환됩니다. 이 시스템은 기기 성능을 33% 향상시키고 클라우드 API 코드량을 40% 이상 줄여줍니다 . 또한, 우리는 반복적인 배포와 동적 환경에서의 강화 학습 훈련을 통해 온라인 강화 학습을 위한 대규모 병렬 환경을 구축하고 환경 상호 작용 단계를 확장합니다 . 제 UI는 마치 실제 상황에서 사람이 행동하는 것처럼 끊임없이 변화합니다 . 저희 프레임워크는 512개의 병렬 환경에서 온라인 강화 학습을 지원하고 최대 학습 범위를 50명의 직원으로 확장하여, 다양한 동적 환경과 장기적인 과제, 그리고 안드로이드 세계 벤치마크에서 UI의 성공률을 지속적으로 향상시킬 수 있도록 합니다. 당사의 온라인 강화 학습 시스템은 SF 팀의 기준선 대비 지속적이고 안정적인 성능 향상을 달성하는 동시에 광범위한 벤치마크에서 최첨단 성능을 확립합니다. 내 UI의 강력한 기반 기능은 광범위한 실용적인 가능성을 열어줍니다. 실제로 어떻게 작동하는지 살펴볼까요?
