## 스크립트

In this video, we will walk you through the AMD Resource Manager. The AMD Resource Manager provides administrators with tools to oversee and control the platform's computational resources and user access. Its key capabilities include cluster management, monitoring, and maintaining teams access to computational resources. We'll go through dashboard overview, how to create a project, defining project quota and settings, and onboarding of users. Let's take a look at how it works. We'll start with the dashboard page. The dashboard page provides an overview of the clusters, nodes, GPUs, and the workloads running on your cluster. Below you can view the consumption by project, such as the number of allocated or utilized GPUs and number of workloads for each project. You create projects to organize and manage work. A project includes users and compute resource quota for the workloads and is isolated from other projects, meaning workloads and secrets in one project are not accessible from another, but the compute resources can be dynamically shared based on real time usage. If you want to view the consumption details for a specific project, you can click on a project to access additional information. For example, here you see an overview of workloads in the demo project, the number of GPU devices utilized and allocated, memory usage, and more. Below, you can also see a list of the workloads in the project, with the relevant information for each workload displayed. Finally, if we scroll down in the dashboard, you can see memory and device utilization over time at various intervals. For information about your clusters, go to the clusters page. Here you will see a list of the clusters, including information regarding nodes, GPUs, and workloads. Click on a cluster to get additional metrics and information for that specific cluster. On the projects page, you have an overview of all the projects, their status, and allocations. To create a new project, click on Create Project. Give it a name, add a short description and select your cluster. Once done, click on Create Project. Once created, project settings will open and you can decide the project's guaranteed allocation of resources. Let's add guaranteed allocation. The quota guarantees the project and its workloads a minimum share of resources in the dynamic resource sharing. The assigned quota can act as project and workload priority classes, so that workloads from projects with high quota pause workloads from projects with no or low guaranteed quota when needed. You can also edit the settings for secrets. Let's add an already existing example secret. You can see that it gets added and goes into pending state while being synced. For storage you can add S3 buckets in the storage tab. In the users tab, you add members to your project. Let's add our user to the project. You can see that it shows up in the list of members. Lastly, in general settings, you can edit project information or delete your project. Once the project is created, it will show up on the project's page. To make changes or edit the project, click on the project and then click on the Project Settings button in the top right corner. For onboarding users to AMD Resource Manager, let's take a look at the documentation. Navigating to the Quickstart section. The AMD Resource Manager provides several options for onboarding users. Here in the documentation, you'll find instructions for so and for inviting users via email or manually. Now you have seen how the AMD Resource Manager provides you with the necessary tools to oversee and control your platforms computational resources, projects, and user access and you are ready to start managing your AI workloads efficiently.
