## 스크립트

[음악] 저는 Anthropic의 외국어 [음악] 엔지니어입니다. Claude를 최대한 활용할 수 있도록 지원하고 안전을 최우선으로 생각합니다. 프롬프트 엔지니어링에 처음 관심을 갖게 된 건 작년 8월입니다. Anthropic에서 언어 모델 레드팀을 활용한 피해 감소에 대한 논문을 발표했는데, 바로 읽고 매료되었습니다. 언어 모델 연구에 안전을 최우선으로 접근하는 회사가 있다는 사실에 감명을 받았고, 모델이 다양한 프롬프트에 대해 어떤 방식으로 출력하는지 살펴보는 것이 매우 흥미로웠습니다. 레드팀 공격은 프롬프트 익스플로잇이나 악명 높은 탈옥(jailbreak)으로 알려져 있습니다. 논문을 읽고 영감을 받아 탈옥을 시작하게 되었습니다. 탈옥은 언어 모델에 적용된 필터를 우회하기 위해 작성된 특정 프롬프트입니다. 프롬프트 엔지니어링은 언어 모델에서 최상의 응답을 얻기 위해 프롬프트를 최적화하는 작업입니다. Anthropic에서는 프롬프트 엔지니어링에 있어 경험적이고 테스트 중심적인 접근 방식을 취합니다. 새로운 프롬프트를 작성할 때마다 일련의 테스트를 거 칩니다. Claude의 성능을 과학적으로 측정하기 위한 벤치마크를 통해 모델을 최대한 활용할 수 있는 몇 가지 모범 사례를 발견했습니다. 그럼 바로 살펴보겠습니다. Claude의 성능을 극대화하기 위한 다섯 가지 팁을 소개합니다. 첫째, 작업을 명확하게 설명하세요. Claude는 명확하고 직접적이며 구체적인 지시에 잘 반응합니다. 예를 들어, 텍스트에서 개인 식별 정보를 제거하도록 Claude에게 지시한다고 가정해 보겠습니다. 개인 식별 정보 제거의 의미를 정확하게 설명하면 Claude가 제거해야 할 텍스트 부분을 인식하는 데 도움이 됩니다. 예를 들어 이메일 주소와 전화 번호 등이 있습니다. 둘째, 프롬프트의 각 부분을 XML 태그로 표시하세요. XML 태그는 다음과 같습니다. Claude는 이러한 구조에 특히 주의를 기울이도록 정밀하게 조정되었습니다. 이 예시에서는 XML 태그를 사용하여 Claude가 개인 식별 정보를 제거해야 하는 텍스트의 시작과 끝을 나타냅니다. 셋째, 예시를 많이 제공하세요. 예시가 많을수록 좋습니다. 다양한 예시를 제공하면 Claude가 작업을 수행하는 방법을 학습하는 데 도움이 됩니다. 앞서 언급한 개인 식별 정보 제거 프롬프트의 경우, XML 태그 내에서 텍스트를 개인 식별 정보로부터 제거하는 방법을 예시로 제공합니다. 넷째, 긴 컨텍스트를 활용하세요. Claude는 최대 10만 개의 토큰, 즉 약 7만 단어까지 읽을 수 있습니다. 또는 위대한 개츠비 전체 분량만큼 긴 시간 동안 생각할 수도 있고, 마지막 팁은 클로드에게 생각할 시간을 주는 것입니다. 연구자들은 언어 모델이 최종 답변을 내놓기 전에 생각할 시간을 주면 성능이 향상된다는 사실을 발견했습니다. 클로드의 경우, 복잡한 질문에 답하기 전에 아이디어를 기록할 수 있도록 사고 태그를 사용합니다. 이 예시에서 보시다시피 클로드는 사고 태그 안에서 추론을 시작한 다음 최종 답변을 출력합니다. 자, 이것들이 클로드를 최대한 활용하기 위한 저의 주요 팁이며, 저와 저의 프롬프트 개발 여정에 대한 간략한 소개였습니다. 최신 프롬프트 모범 사례를 확인하려면 개발자 커뮤니티 사이트인 Developer Dog를 방문해 보세요. 아직 클로드 API에 접근할 수 없다면 claude.ai에서 지금 바로 프롬프트 엔지니어링 연습을 할 수 있습니다.
