## 스크립트

안녕하세요. 이 짧은 데모 비디오에 오신 것을 환영합니다. 이 비디오에서는 설계 체크리스트에 액세스하는 방법을 설명합니다. 설계 체크리스트는 ARM 전문가들이 ARM IP를 사용하는 SOCKS를 설계하는 엔지니어를 위해 제작했습니다. 엔지니어가 설계의 중요한 측면을 빠르고 쉽게 검증하여 오류를 방지하고 시스템이 목적에 적합하며 ARM에서 권장하는 설계 지침을 준수 하는지 확인할 수 있도록 도와줍니다. ARM 설계 체크리스트는 ARM 문서와 함께 사용하여 설계 성공에 대한 신뢰도를 높이는 데 도움이 됩니다. 체크리스트는 해당 IP 또는 IP에 대한 유효한 라이선스를 보유한 파트너만 사용할 수 있습니다. 설계 체크리스트는 구성되지 않은 버전과 구성된 버전의 두 가지가 있습니다. 구성 되지 않은 버전의 체크리스트는 IF 및 else 문을 사용하여 가능한 모든 구성에 대한 검사를 표시합니다. 구성된 버전의 체크리스트는 검사를 생성하기 전에 시스템 구성 중에 선택한 사항을 고려하여 해당 구성에 특정한 검사만 표시합니다. 구성 되지 않은 체크리스트는 RIP Explorer의 제품 다운로드 허브와 개발자용 문서 허브에서 다운로드할 수 있습니다. arm.com에서 제공하는 IP Explorer를 사용하여 구성되지 않은 버전과 구성된 버전의 설계 체크리스트에 액세스하는 방법을 보여드리겠습니다. IP Explorer에서 구성된 체크리스트에 액세스하려면 IP Explorer에 로그인해야 합니다 . arm.com에서 arm 계정을 사용하여 구성 되지 않은 버전의 체크리스트를 다운로드하려면, 검색 하려는 IP 유형( 프로세서, 시스템 IP, 서브시스템 또는 인터커넥트)에 따라 해당 타일을 클릭한 다음, 검색하려는 IP 제품 이름을 입력합니다. 이 예에서는 Cortex M85 CPU를 검색합니다. 검색 결과 상단의 Cortex M85 타일을 클릭합니다. 프로세서 페이지가 로드되면 화면 오른쪽에 IP 다이어그램이 표시됩니다. 페이지를 아래로 스크롤하면 " 설계 체크리스트" 섹션이 있습니다. 화살표를 클릭하여 섹션을 확장 하고 "다운로드"를 클릭하여 구성 되지 않은 버전의 체크리스트를 PDF 형식으로 다운로드합니다. 구성된 버전의 설계 체크리스트는 IP Explorer에서만 다운로드할 수 있으며 두 가지 방법으로 다운로드할 수 있습니다. 기본 IP 구성을 사용하여 설계 체크리스트를 다운로드하려면 IP 페이지 하단으로 스크롤하여 " 설계 체크리스트" 섹션에 도달한 다음 " 다운로드"를 클릭하여 기본 구성을 기반으로 체크리스트를 생성합니다. 구성된 버전의 체크리스트에는 if 또는 else 문이 표시되지 않습니다. 플랫폼이 선택한 구성을 고려하여 체크리스트를 생성하기 때문입니다. 또는 IP 파일의 사용자 지정 버전을 저장하여 프로젝트 사양에 맞게 구성을 변경할 수 있습니다. 이 사용자 지정 구성을 기반으로 설계 체크리스트를 생성하면 파일이 생성되기 전에 설정이 반영되므로 사용자 설정에 해당하는 항목만 표시됩니다. 이 데모를 시청해 주셔서 감사합니다. 도움이 되셨기를 바랍니다.
