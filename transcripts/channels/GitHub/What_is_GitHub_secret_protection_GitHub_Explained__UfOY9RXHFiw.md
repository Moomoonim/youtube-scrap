## 스크립트

[음악] 개발자들은 API 키, 토큰, 비밀번호와 같은 비밀 정보를 매일 사용합니다 . 비밀 정보는 무단 접근을 막기 위한 것이지만, 노출될 경우 순식간에 악용될 수 있습니다 . GitHub 비밀 보호 기능은 비밀 정보 유출을 방지하고 비밀 정보를 안전하게 보호해 줍니다. 여기에는 푸시 알림 보호 기능이 포함되어 있어 모든 푸시 알림을 실시간으로 스캔하고 기밀 정보가 노출되기 전에 차단합니다 . GitHub는 Git 이슈, 풀 리퀘스트 댓글 및 기타 비밀 정보가 숨겨질 수 있는 곳뿐만 아니라 전체 Git 기록까지 스캔합니다. 비밀 정보가 발견되면 GitHub는 해당 정보가 활성화되어 있는지 확인하고, 공개적으로 노출되었는지 여부를 점검하며, 즉각적인 조치가 필요한 사항의 우선순위를 정하는 데 도움을 줍니다. GitHub Copilot의 비밀 정보 스캔 기능을 사용하면 표준 형식이 아닌 비밀번호와 같은 비밀 정보도 쉽게 감지할 수 있습니다. GitHub는 또한 150개 이상의 토큰 발급 기관과 협력하여 전체 개발자 커뮤니티를 보호하기 위해 해당 기관의 비밀 키를 탐지하는 도구를 구축하고 있습니다 . GitHub 비밀 보호 기능은 정보 유출을 방지하고, 자격 증명을 보호하며, 코드를 안전하게 배포하는 데 도움이 됩니다. [음악]
