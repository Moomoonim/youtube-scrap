## 스크립트

안녕하세요, Repet의 Matt입니다. 오늘은 Repet Agent 사용 및 구축과 관련된 몇 가지 흥미로운 업데이트 소식을 전해드리겠습니다. 이번 업데이트는 Repet Agent를 통해 최대한 많은 것을 구축할 수 있도록 설계되었습니다. 요금 청구는 민감한 주제일 수 있다는 점을 잘 알고 있기 때문에 모든 사용자 여러분께 이러한 변경 사항을 투명하게 알려드리고자 합니다. 무엇이 새로워졌을까요? 기존 Agent를 사용해 보신 분들은 아시겠지만, 현재 6시간마다 구축할 수 있는 양에 사용량 제한 또는 할당량이 있습니다. 이는 최적의 사용 환경을 제공하지 못하는 문제입니다. 그래서 이제 이 할당량을 없앴습니다. 어떻게 적용될까요? Core 또는 Team 구독자분들은 이미 구독에 포함된 사용 크레딧을 받고 계십니다. 이 크레딧은 배포나 데이터베이스 등에 자동으로 적용되었는데, Agent도 여기에 포함됩니다. 이제 매달 멤버십에 포함된 크레딧을 통해 추가 요금 없이 Agent를 무제한으로 사용할 수 있습니다. 또한 매달 제공되는 크레딧 양도 늘려 Core 구독에 포함된 크레딧을 최대한 활용할 수 있도록 했습니다. 크레딧은 원하는 속도로 자유롭게 사용하실 수 있습니다. 에이전트를 정말 즐겁게 사용하신다면 크레딧을 모두 소진한 후에도 전혀 방해받지 않고 계속 사용하실 수 있습니다. 크레딧을 모두 소진하신 후에는 사용량 기반 결제를 통해 계속 사용료를 지불하는 옵션이 제공됩니다. 이제 Repet Agent 사용량을 쉽게 모니터링할 수 있도록 사용량 알림 기능과 계정 수준에서 설정할 수 있는 한도 기능을 추가할 예정입니다. 또한 사용량 페이지에 AI 패널을 추가하여 프로젝트 전체에서 에이전트 비용이 얼마나 드는지 정확하게 확인할 수 있도록 할 것입니다. 에이전트 사용량은 체크포인트 기반으로 계산됩니다. 체크포인트는 Git 커밋과 비슷하게 생각하시면 됩니다. Git에 익숙하지 않으신 분들을 위해 설명드리자면, 에이전트가 사용자에게 결과를 반환하기 위해 수행하는 일련의 단계 또는 작업이라고 생각하시면 됩니다. 체크포인트를 선택한 이유는 에이전트가 반환하는 결과물을 실제로 확인할 수 있기 때문입니다. 다른 유사한 도구들은 사고 토큰이나 처리 단계 등을 기준으로 비용을 청구하지만, 저희는 이러한 방식이 불투명하고 실제 작업량을 정확하게 반영하지 못한다고 생각합니다. 더욱 투명하게 운영하기 위해 에이전트가 수행하는 체크포인트를 기반으로 시스템을 구축하고 있습니다. 이 모든 정보는 계정의 사용량 페이지에서 확인하실 수 있습니다. 저는 Rebel Agent의 Matt입니다. 지금까지 Rebel Agent를 사용하여 더 나은 애플리케이션을 더 많이 개발할 수 있도록 에이전트 사용량 청구 방식을 변경한 내용을 설명드렸습니다. 다음 시간에 뵙겠습니다. 평화!
