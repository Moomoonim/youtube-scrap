## 스크립트

Hello, my name is Ryan Wolf. I'm going&nbsp; to walk you through some of the recently&nbsp;&nbsp; added features for image data curation in NeMo&nbsp; Curator. The goal of this demo is to curate a&nbsp;&nbsp; high-quality data set of text and image pairs for&nbsp; training text-to-image generative models. First,&nbsp;&nbsp; we're going to create image embeddings&nbsp; for each image in our data set. Then,&nbsp;&nbsp; using those embeddings, classify the&nbsp; images with an aesthetic score. Finally,&nbsp;&nbsp; we'll perform semantic deduplication on them.&nbsp; All the steps in the pipeline run on GPUs,&nbsp;&nbsp; so make sure you have one if you're following&nbsp; along. The notebook provides code for downloading&nbsp;&nbsp; a sample data set of 20,000 text-image&nbsp; pairs, and I've already downloaded it. The first step in curation is creating image&nbsp; embeddings for each image in the data set.&nbsp;&nbsp; The rest of the modules take these embeddings as&nbsp; input, so first, we'll load the data set from disk&nbsp;&nbsp; and filter out any entries that might have failed&nbsp; to download. Next, we'll choose which embedding&nbsp;&nbsp; model we want to use. Here, we choose the vision&nbsp; encoder from one of OpenAI's original CLIP models.&nbsp;&nbsp; Now we can create the embeddings and save them to&nbsp; disk, and NeMo Curator will automatically use all&nbsp;&nbsp; the GPUs available on your system to parallelize&nbsp; the embedding creation across all of them. Now that we have the embeddings, let's do some&nbsp; filtering with them. We can use an aesthetic&nbsp;&nbsp; classifier to score each image on a scale from&nbsp; 0 to 10 of how visually pleasing the image is to&nbsp;&nbsp; look at. If we filter the images that only&nbsp; have an aesthetic score of six or above,&nbsp;&nbsp; we should get some high-quality images. Let's&nbsp; take a look at the result of filtering. Here,&nbsp;&nbsp; we can see that we get a good-looking photo&nbsp; of a motorcycle leaning against a brick wall. For the final part of the demo, let's semantically&nbsp; deduplicate our data set. Images are considered&nbsp;&nbsp; semantic duplicates if they capture the same&nbsp; content. Their pixel values don't necessarily&nbsp;&nbsp; have to be identical. Training on duplicate data&nbsp; is not as effective as training on unique data,&nbsp;&nbsp; so let's use NeMo Curator to take care&nbsp; of this. I'll run the clustering step&nbsp;&nbsp; while I explain what clustering is. Clustering&nbsp; uses RAPIDS-accelerated K-means clustering to&nbsp;&nbsp; put each embedding into a cluster. Then,&nbsp; during the next stage of deduplication,&nbsp;&nbsp; we compute the pairwise cosine similarity between&nbsp; all image embeddings within each cluster. If two&nbsp;&nbsp; image embeddings have very high similarity,&nbsp; we discard one of them as it's a duplicate. Let's perform this cluster-level deduplication&nbsp; and remove the duplicates from our data set.&nbsp;&nbsp; Then we can look at the results. Here, we&nbsp; can see each image, its nearest neighbor,&nbsp;&nbsp; and the similarity between the two, where one is&nbsp; exact similarity (exactly the same image) and zero&nbsp;&nbsp; is not identical at all. If we take a look at&nbsp; two images that were considered duplicates, we&nbsp;&nbsp; can see that they are indeed semantic duplicates&nbsp; with only slight variations between the images. With that, we now have a high-quality&nbsp; data set that we can use to train a&nbsp;&nbsp; text-image generative model. This&nbsp; tutorial is available on the NeMo&nbsp;&nbsp; Curator repository if you want to&nbsp; try it out yourself. Thank you.
