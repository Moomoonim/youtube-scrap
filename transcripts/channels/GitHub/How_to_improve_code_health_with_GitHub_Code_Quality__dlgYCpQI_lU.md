## 스크립트

대규모 소프트웨어 조직에서 팀과 저장소 전반에 걸쳐 일관된 코드 품질을 유지하는 것은 신뢰성, 규정 준수 및 장기적인 유지 관리성을 위해 필수적입니다. GitHub 코드 품질은 더욱 스마트하고 유연하며 관리하기 쉬운 기능을 갖춘 강력한 엔터프라이즈급 인사이트를 제공하며, 현재 공개 미리보기로 제공됩니다 . GitHub 공동 품질 관리 기능은 개발자와 팀에게 소프트웨어 상태에 대한 포괄적인 가시성과 제어 권한을 제공하여 저장소 전반에 걸쳐 유지 관리 가능성과 기술 부채를 추적하고 , 프로덕션 환경에 배포하기 전에 위험 요소와 실행 가능한 지침을 파악하고 , 품질 게이트를 적용하여 조직 정책을 개발 워크플로에 직접 통합할 수 있도록 지원합니다. GitHub는 코드 스캔과 별개로 품질 분석을 실행할 수 있는 기능을 도입하여 코드 품질 기능을 확장했으며, 이를 통해 분석 워크플로우 관리 및 최적화에 더 큰 유연성을 제공합니다 . 또한 복잡한 코드 문제를 식별하고 수정 속도를 높이기 위해 AI 기반 전력 감지 기능을 도입했습니다. 당사의 정적 분석 엔진인 CodeQL에서 얻은 인사이트를 제공하는 새로운 코드 품질 대시보드가 ​​출시되었습니다. 자체 호스팅 실행기 지원을 통해 이제 팀은 자체 기업 인프라 내에서 안전하게 품질 분석을 수행할 수 있습니다 . 실제 작동 방식은 다음과 같습니다. 개발자는 풀 리퀘스트를 제출하면 AI 기반 품질 피드백을 즉시 받을 수 있습니다. 그러면 팀은 자동화된 인사이트를 바탕으로 문제를 조기에 해결할 수 있습니다 . 품질 게이트는 규정 준수를 강제하여 위험한 코드가 병합되는 것을 방지합니다. 품질 관리 단계를 미리 구성해 보세요. AI 기반 인사이트를 활용하여 조직 전반의 거버넌스를 간소화하세요. 팀이 안전하고 신뢰할 수 있으며 유지 관리가 용이한 소프트웨어를 대규모로 제공할 수 있도록 지원하세요.
