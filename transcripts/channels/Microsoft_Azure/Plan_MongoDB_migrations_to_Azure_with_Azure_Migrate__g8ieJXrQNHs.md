## 스크립트

[음악] 안녕하세요 여러분, 환영합니다. 이 비디오에서는 Azure Migrate를 사용하여 MongoDB 서버 배포를 Azure로 마이그레이션하는 계획을 세우는 방법을 살펴보겠습니다 . Azure Migrate를 사용하면 MongoDB 인스턴스를 검색하고 Azure Document DB 및 Azure VM으로 마이그레이션할 수 있는지 평가할 수 있습니다. 구체적으로 말하자면, MongoDB 워크로드 의 마이그레이션 및 현대화를 가능하게 하는 측면에서 이야기하는 것입니다 . Azure 로의 마이그레이션을 위한 새로운 MongoDB 평가 기능을 통해 마이그레이션 준비 상태 및 장애 요인, 권장 대상 Azure 서비스 및 적절한 크기의 SKU, 그리고 권장 사항의 근거를 파악할 수 있습니다. Azure에서 MongoDB 서버 배포를 실행하는 데 드는 비용 추정치와 마이그레이션 지침도 확인할 수 있습니다. 권장되는 방식으로 마이그레이션을 진행하려면 다음과 같은 단계를 수행해야 합니다. Azure로 MongoDB 서버 배포를 마이그레이션하기 전에, MongoDB 서버를 성공적으로 검색하는 데 필요한 모든 전제 조건이 충족되었는지, 그리고 검색 관련 문제가 모두 해결되었는지 확인해야 합니다. 필수 조건에 대한 자세한 내용은 aka.ms/azuremigratedbdiscovery를 참조하세요. 검색이 성공적으로 완료되면 데이터베이스 블레이드로 이동하여 MongoDB 평가를 시작할 수 있습니다. 평가할 MongoDB 인스턴스를 선택하고 ' 평가 생성'을 클릭하면 됩니다. 평가를 생성하는 동안 마이그레이션 대상 지역, 소스 워크로드의 기본 환경 유형( 예: 개발, 테스트 또는 프로덕션)과 같은 Azure 대상 속성을 지정하여 적절한 가격 및 SKU를 적용할 수 있습니다. 통화, 종량제, 1년 또는 3년 예약 인스턴스, Azure 절약 플랜과 같은 절약 옵션 및 평가 기준이 포함됩니다. Azure 하이브리드 혜택을 이용하면 Azure VM으로 마이그레이션할 때 자체 Windows Server 또는 선택한 Linux Server 라이선스를 Azure로 가져올지 여부를 지정할 수도 있습니다 . '기본값 편집'을 클릭하면 활용하려는 오퍼링 의 대상 서비스 계층을 지정 하거나, Azure Migrate가 최적의 설정을 결정하도록 기본값을 그대로 둘 수 있습니다 . 모든 세부 정보를 지정한 후 ' 검토 및 평가 생성'을 클릭할 수 있습니다 . 모든 것이 괜찮아 보이면 ' 만들기'를 클릭하세요. 평가 결과는 몇 분 안에 검토 가능합니다. 보시다시피 저희는 서버 두 대 와 인스턴스 두 개를 평가했습니다. 또한, 저희가 보유한 모든 인스턴스가 지원 중단 상태가 아님을 확인할 수 있습니다. MongoDB 서버 인스턴스 및 데이터베이스에 대한 다양한 마이그레이션 방식의 준비 상태 와 Azure에서 이러한 워크로드를 실행하는 데 필요한 예상 비용을 확인할 수 있습니다. Azure Document DB 및 Azure VM과 같은 Azure의 각 MongoDB 배포 대상에 맞춘 보고서를 자세히 살펴보거나 요약 된 권장 보고서를 참조할 수 있습니다. 권장 보고서는 선택한 마이그레이션 기본 설정에 따라 MongoDB 서버 배포를 Azure로 마이그레이션하는 가장 효율적인 방법을 제시합니다 . Azure Migrate는 마이그레이션 준비 상태와 예상 비용을 모두 고려하여 완전히 발견되지 않은 MongoDB 배포를 포함하여 모든 MongoDB 배포가 마이그레이션에서 누락되지 않도록 합니다. 이 경우, 현대화를 위한 우리의 의도에 따라 MongoDB 서버 인스턴스 두 개 모두를 재플랫폼화하는 것을 권장합니다 . 더 자세히 살펴보니, 권장되는 패스 서비스는 Azure Document DB인 것을 알 수 있습니다. 이제 localhost.localdomain의 27017번 인스턴스에 대한 평가 세부 정보를 살펴보겠습니다. 이 인스턴스는 MongoDB 인스턴스이며, 제가 현대화하려는 앱의 데이터 계층을 나타냅니다 . Azure로 마이그레이션할 준비가 되었으며, 앞서 언급한 현대화 목표를 고려할 때 권장 대상은 Azure Document DB임을 알 수 있습니다 . 권장 구성은 M60 16V 코어, 컴퓨팅 성능 기준으로 64GB 메모리 , 그리고 128GB 프리미엄 SSD 스토리지를 포함하며, 가격은 약 1930달러입니다. 더 자세한 내용을 통해 종합적인 성능을 확인할 수도 있습니다. 준비 상태 탭을 사용하면 Azure의 모든 MongoDB 대상에 대한 준비 상태를 파악할 수 있습니다. Azure Document DB로의 현대화 관련 경고를 이해하려면 몇 가지 경고를 해결해야 하지만 이러한 변경 사항은 Azure로의 마이그레이션 자체에는 지장을 주지 않는다는 점을 알 수 있습니다. 목표 추천 탭에서는 이상적인 목표가 어떻게 결정되었는지 설명합니다. 이 경우 MongoDB 서버는 Azure Document DB를 사용할 준비가 되어 있었습니다. 또한, Azure에서 이 인스턴스를 실행하는 비용이 두 가지 옵션 중 가장 낮을 것으로 예상됩니다. 이 작업에 권장되는 도구는 Azure Document DB 마이그레이션 확장 프로그램임을 알 수 있습니다. Azure Migrate의 권장 사항 덕분에 MongoDB 배포를 정확하게 검색하는 데 필요한 자격 증명이나 권한이 없었더라도 모든 MongoDB 배포를 빠짐없이 마이그레이션할 수 있었습니다. 이제 각 목표에 대한 방향성 보고서를 살펴보겠습니다. 특히 통과한 목표에 대한 보고서는 실행 및 유지 관리 측면에서 비용 효율성이 높으므로 더욱 중요합니다. MongoDB에서 Azure Document DB로의 마이그레이션 준비 보고서를 살펴보면 두 MongoDB 인스턴스 모두 Azure Document DB로 마이그레이션할 준비가 되었음을 확인할 수 있습니다. 목표 편향 비용, 준비 상태 및 마이그레이션 지침을 확인할 수 있습니다. 보시다시피 Azure Migrate는 Azure VM의 MongoDB 서버에 대한 전용 평가 보고서를 제공하며 , 이는 최소한의 노력으로 Azure VM으로 마이그레이션하기 위한 리프트 앤 시프트 또는 복제 기반 접근 방식을 목표로 합니다 . 권장 Azure VM 대상 편차 비용, 준비 문제 및 경고, 마이그레이션 지침을 확인할 수 있습니다. MongoDB를 Azure Document DB 또는 Azure VM의 MongoDB 서버로 마이그레이션할 때의 컴퓨팅 및 스토리지 비용 분포를 검토할 수 있습니다. 언제든지 설정으로 이동하여 예약 용량, 마이그레이션 전략, Azure 하이브리드 혜택 등의 선택 사항을 변경하여 평가를 사용자 지정하고 비용 변화를 확인한 후 최적의 조합을 선택할 수 있습니다. 또한, 평가 보고서를 내보내어 공유하거나 오프라인에서 활용할 수 있습니다 . 이 데모에서는 Azure Migrate에서 제공하는 모든 기능을 활용하여 대규모 MongoDB 서버 인스턴스를 검색하고 평가하는 방법을 다룹니다 . Azure MongoDB 평가 생성 및 다양한 옵션에 대한 내용을 포함했습니다. 온 프레미스에서 호스팅되는 MongoDB를 Azure에 배포하는 대상과 적절한 크기의 SKU 권장 사항, 관련 근거 및 마이그레이션 지침, 그리고 비용 세부 정보를 제공하여 Azure Migrate를 사용하여 데이터 마이그레이션 우선순위를 쉽게 정할 수 있도록 지원합니다. 시작하실 때 이 화면에 있는 Azure Migrate 설명서와 같은 자료를 활용하시면 됩니다. 탐색 및 평가가 완료되고 신뢰도가 높은 마이그레이션 계획을 수립한 후에는 Azure DocumentDB 마이그레이션 VS Code 확장 기능을 활용하여 MongoDB 서버 배포를 Azure DocumentDB로 마이그레이션하거나 Azure Migrate 서버 마이그레이션 기능을 사용하여 서버를 Azure 가상 머신으로 옮길 수 있습니다. 실제 마이그레이션을 진행하기 전에 프로덕션 워크로드에 영향을 주지 않고 테스트 마이그레이션을 수행할 수도 있습니다. 이 영상을 시청해 주셔서 감사합니다.
