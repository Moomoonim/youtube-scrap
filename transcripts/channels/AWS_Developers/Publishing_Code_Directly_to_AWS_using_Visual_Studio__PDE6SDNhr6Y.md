## 스크립트

안녕하세요 여러분, 브랜든 마이크입니다. AWS 툴킷에 대한 또 다른 영상으로 돌아왔습니다. 이번 영상에서는 비주얼 스튜디오에서 AWS로 직접 배포하는 방법을 알아보겠습니다. 툴킷 설치 및 사용 방법을 보여주는 첫 번째 영상을 아직 보지 않으셨다면, 이 영상을 잠시 멈추고 설명란에 있는 링크를 클릭해 주세요. 자, 시작해 볼까요? [음악] 여기 비주얼 스튜디오가 있습니다. 지금까지 내장 템플릿을 사용하여 새로운 ASP.NET Core 웹 API를 만들었습니다. 어떻게 작동하는지 보여드리기 위해 지금 실행 중입니다. 백그라운드 코드를 보면 날씨 예보라는 API가 있는데, 이 API는 무작위 날씨 정보를 반환합니다. 로컬에서 실행 중이므로 '날씨 예보'를 입력하여 해당 API에 접속할 수 있습니다. 무작위 날씨 정보가 표시되고, 새로 고침하면 더 많은 무작위 날씨 정보가 나타납니다. 이제 클라우드에 배포할 차례이므로 실행을 중지하겠습니다. AWS 탐색기가 보이시죠? 확인해 보겠습니다. 솔루션 탐색기에서 프로젝트를 마우스 오른쪽 버튼으로 클릭하고 '실행'을 선택합니다. AWS에 게시하면 이제 게시된 AWS 창이 나타납니다. 여기에는 웹 API를 게시하는 몇 가지 옵션이 있습니다. 권장되는 방법인 Linux를 통해 Elastic Beanock에 게시하거나, Windows에 게시하거나, adbs Fargate를 사용하여 ECS에 게시하거나, adbs App Runner에 게시할 수 있습니다. 하지만 여기서는 Elastic Beanock에 직접 게시할 것이므로, Elastic Beanock을 선택하고 게시를 클릭합니다. 이제 adbs 툴킷이 코드를 컴파일하고 클라우드에 게시합니다. 잠시 후 AWS에서 API가 실행되는 것을 확인할 수 있습니다. 잠시 후 어떻게 보이는지 확인해 보겠습니다. 이제 모든 작업이 완료되었습니다. 웹 API가 AWS 클라우드에서 실행 중입니다. 왼쪽에서 Elastic Beanock 인스턴스를 새로 고침하면 방금 게시한 " Hello Visual Studio Toolkit Web API"를 볼 수 있습니다. 오른쪽에는 실제 엔드포인트가 있습니다. 이 URL을 브라우저에 입력하면 이전에 생성한 API이므로 응답이 표시됩니다. 날씨 예보 API를 입력하면 로컬에서 실행했을 때처럼 무작위 날씨 정보가 표시됩니다. 이제 AWS의 Elasticsearch에서 앱을 실행하고 있으며, 이전처럼 새로고침하면 계속해서 무작위 날씨 정보가 표시됩니다. 따라서 앱이 로컬 환경에서처럼 제대로 작동하고 있음을 알 수 있습니다. 오늘 AWS 툴킷 for Visual Studio를 사용하여 몇 번의 클릭만으로 앱을 클라우드에 직접 게시하는 방법을 알아보았습니다. 이 영상이 도움이 되었다면 좋아요 버튼을 누르고 구독하여 AWS 툴킷 시리즈의 다음 영상을 놓치지 마세요. 감사합니다.
