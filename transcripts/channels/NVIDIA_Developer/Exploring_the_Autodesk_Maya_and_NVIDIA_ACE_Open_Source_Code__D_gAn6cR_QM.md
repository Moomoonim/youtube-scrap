## 스크립트

이번 비디오 튜토리얼 시리즈를 마무리하면서 Maya 플러그인의 소스 코드를 아주 간단히 살펴보겠습니다. GitHub URL로 돌아가시면 코드를 찾을 수 있습니다. 코드는 MIT 라이선스로 배포되므로, 책임감 있는 사용자라면 코드를 수정하거나 원하는 대로 사용할 수 있습니다. 코드를 사용하려면 Visual Studio 2.22가 필요하며, My DevKit도 필요합니다. My DevKit은 여기에서 다운로드할 수 있습니다. 다시 GitHub로 돌아가서 Maya Ace Nvidia Maya Ace GitHub로 이동하면 코드를 찾을 수 있습니다. 모든 것이 여기에 있습니다. 코드를 복사하거나 로컬로 가져오려면 이 URL을 복사하기만 하면 됩니다. 그런 다음 Visual Studio에서 폴더를 열면 됩니다. 저는 이 폴더를 선택하겠습니다. 지금은 비어 있습니다. 자, 그럼 새 터미널을 열고 ` get clone`을 입력한 다음 붙여넣겠습니다. 그러면 전체 코드가 보일 겁니다. 여기서 중요한 건 ` depths` 폴더의 종속성에 Maya 개발자 키트가 필요하다는 겁니다. 다시 여기로 돌아가서 웹사이트에 접속합니다. 저는 Maya 2025를 사용하고 있으니 이 버전을 다운로드하겠습니다. 다운로드가 완료되면 폴더에 붙여넣기만 하면 됩니다. ` depths` 폴더로 가서 여기에 붙여넣겠습니다. 압축 파일인데, 여기에 붙여넣으면 압축을 풀면 ` Dev git base`라는 파일이 생깁니다. 이게 바로 종속성을 빌드하는 데 필요한 파일입니다. 그런 다음 실행해야 할 명령어가 있는데, 제가 제대로 된 폴더에 있는 건지 모르겠네요. Maya Ace 폴더에 있습니다. `Fetch`를 입력하면 종속성이 다운로드됩니다. 자, 이제 다 끝났으니 뭘 해야 할까요? 관심 있으신 분들을 위해 간단히 터미널을 닫겠습니다. 더 이상 필요 없으니까요. 소스 폴더로 이동하시면 핵심 코드가 있는 곳을 간단히 살펴보실 수 있습니다. 여기서 시간을 들여 자세히 공부하시면 됩니다. Maya Ace 클라이언트로 이동하시면 'commands'라는 폴더가 있고, ' request animation' 폴더를 보시면 마이크로서비스에 연결하고 데이터를 요청하는 코드가 있습니다. Ace 클라이언트에는 프레임을 수신하고 데이터를 주고받는 하위 함수들도 있습니다. gRPC 프로토콜에 관심이 있으시다면 ' Ace gRPC C P' 폴더에 있습니다. 물론 모든 것을 자세히 설명하지는 않겠습니다. 단지 어디에 있는지 알려드리고, 이를 바탕으로 코드를 확장하고, 추론하고, 다양한 작업을 수행할 수 있도록 하는 것이 목적입니다. Maya Ace를 즐겁게 사용해 보시길 바랍니다. 그걸로 멋진 걸 해 보세요
