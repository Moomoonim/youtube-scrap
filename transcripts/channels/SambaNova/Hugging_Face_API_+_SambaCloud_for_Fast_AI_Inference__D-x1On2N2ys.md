Hi. Today, I'm going to show you how you can provide blazing fast AI inference using the Hugging Face API powered by the SambaNova Cloud. Hugging Face is an AI community building the future. You can see an amazing number of different applications or spaces, and a great number of data sets that you can use to fine-tune your models. The Samba Cloud provides the fastest AI inference on the largest models powered by our specialized AI chips built right here at SambaNova. When you first log in into Hugging Face, you can see a ton of different models by selecting the models link right here. After that, you can select a different inference provider like SambaNova to see which models that inference provider actually powers. One of my favorite models is DeepSeek-R1-0528. And you can select actually an inference provider here. You can select SambaNova, and maybe use one of his examples like explain quantum computing in simple terms. The great thing about using the Hugging Face API is that it is open AI compatible, and you can select different models just providing something like this. Let's go ahead and compare SambaNova to different providers here. I selected DeepSeek-R1-0528 and a provider SambaNova and another provider by Fireworks. I'm going to use the same prompt, explain quantum computing in simple terms, and run it across the different models in this playground. You can see that the SambaNova provider ended quicker and the latency is smaller than the Fireworks provider.
