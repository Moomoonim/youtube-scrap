GitHub는 Copilot CLI의 강력한 기능을 자체 애플리케이션에 통합할 수 있도록 하는 GitHub Copilot SDK를 발표했습니다. 단일 또는 다중 턴 실행 루프, 도구 호출 과 같은 것들을 생각해 보고, 에이전트 기반 워크플로의 강력한 기능을 애플리케이션에 실제로 적용해 보세요. 예를 들어 버크를 생각해 보세요. 버크는 데스크톱과 대화하고 원하는 대로 창을 재배열할 수 있는 앱을 만들었습니다. 캐시디를 살펴보죠. 캐시디는 자신의 프로젝트 관리에 도움이 되는 귀여운 앱을 만들었습니다 . 케일라는 로그를 분석하고 이상 징후, 패턴 및 전반적인 상황에 대한 요약을 얻는 데 도움이 되는 앱을 개발했는데, 이 앱은 그녀가 더 많은 통찰력을 얻는 데 도움이 되는 도구입니다 . 자 , 이제 뭘 만들어볼까 생각해 봤어요. 나에게 중요한 것은 무엇인가? 저는 배우는 것에 열정적이고, 끊임없이 배우며, 다른 사람들이 성장하도록 돕는 데에도 열정적입니다. 그래서 저는 당신의 컴퓨터에서 실행되도록 설계된 Next.js 앱을 만들었습니다. 여러 가지 패키지들을 조합해서 사용합니다 . 그러니까, 이 프로그램은 Octokit 라이브러리를 사용해서 사용자의 GitHub 프로필에서 일부 정보를 가져옵니다 . 음, Copilot SDK를 사용해서 툴 호출을 할 수도 있었지만, 저는 앱에서 몇 가지 다른 접근 방식을 사용해 보기로 했습니다. 그러니까, 그건 앱이 아니에요. 그럼 가서 앱 자체를 한번 살펴볼까요?
