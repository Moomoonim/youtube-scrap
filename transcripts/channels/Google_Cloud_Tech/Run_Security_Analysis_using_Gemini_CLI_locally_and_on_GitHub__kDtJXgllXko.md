## 스크립트

[음악] 인공지능의 사용으로 오늘날 작성되는 코드의 속도와 양이 몇 배로 증가했습니다. 코드 리뷰, 특히 보안 관점에서의 코드 리뷰를 효율적으로 진행하기 위해 인공지능( AI)의 강력한 기능을 활용하는 것이 큰 도움이 됩니다. [음악] Gemini CLI에는 보안 분석을 실행하기 위한 Google에서 개발한 오픈 소스 확장 프로그램이 있습니다 . 보안 확장 기능은 비밀 관리, 안전 하지 않은 데이터 처리, 주입 취약점, 인증 및 LLM 안전성을 포함한 다양한 취약점 검사 기능을 제공합니다. 가장 최근에는 구글 기반의 OSV( 오픈소스 취약점 데이터베이스)를 사용한 종속성 검사 기능도 추가했습니다. 구글 소유의 많은 저장소에서 이미 풀 리퀘스트를 검토하기 위해 보안 확장 프로그램을 사용하기 시작했습니다. 간단한 예시 몇 가지를 살펴보겠습니다. Gemini CLI에서 제공하는 이 예제는 임의 파일 읽기에 관한 것입니다. 이것도 Gemini CLI에서 가져온 것으로, 환경 축소 로직을 우회하는 방법에 관한 것입니다. 프로젝트 칩에서 나온 이 취약점은 경로 탐색 공격에 대한 것입니다. Flutter에서 나온 이 예시는 타임스탬프를 해시 코드로 사용하는 방법을 보여줍니다. [음악] 이제 로컬에서 보안 확장 프로그램을 사용하는 방법과 GitHub Actions를 통해 GitHub에서 PR을 검토하는 방법을 살펴보겠습니다 . [음악] 로컬에서 사용하려면 먼저 확장 프로그램을 설치해야 합니다. 설치가 완료 되면 프로젝트에서 Gemini를 엽니다. 슬래시(/) 명령어 보안을 사용하여 확장 프로그램의 사용자 지정 명령어를 불러온 다음 실행할 사용자 지정 명령어를 선택하세요. 자연어를 사용하여 명령어를 사용자 지정할 수 있습니다. 내 모든 HTML 파일을 스캔하세요. 확장 프로그램이 읽기 전용 작업을 수행하기 때문에 Ctrl+Y 키를 눌러 Yolo 모드를 켤 수 있습니다. 먼저 감사 범위를 정의하기 위해 할 일 목록을 생성합니다. 그런 다음, 범위 내의 파일을 분석하고 진행 상황에 따라 작업을 완료 표시합니다. 마지막으로, 연구 결과를 요약하여 제시합니다. 이러한 로컬 분석을 실행하는 것은 특히 코드를 공개적으로 커밋하기 전에 개별 코드 기여자에게 좋은 습관입니다. 하지만 팀이나 여러 기여자가 있는 GitHub 저장소를 관리하는 경우, 보안 확장 프로그램을 CI/CD의 일부로 통합하면 일부 사용자가 로컬에서 먼저 실행하는 것을 잊더라도 모든 사용자의 기여가 동일한 기준을 충족하도록 보장할 수 있습니다 . 설정하려면 공식 보안 확장 저장소에서 예제 워크플로를 복사하여 사용자 저장소에 붙여넣으세요. 다음으로, 워크로드 ID 페더레이션을 사용하여 GitHub에서 Google Cloud로의 인증을 구성하는 셸 스크립트를 실행하여 이러한 작업 변수를 생성합니다 . 워크플로가 준비되면 새 PR이 워크플로를 트리거하고 보안 확장 기능을 호출하여 보안 검토를 수행합니다. 기존 PR의 경우, @GeminiCLI/review를 입력하여 리뷰를 시작할 수 있습니다. [음악] 오늘 보안 확장 기능을 통해 보안 결함을 즉시 식별하고 수정하여 보안 수준을 낮출 수 있게 되었습니다. 이 보안 확장 기능은 확장 가능한 아키텍처로 설계되었기 때문에 향후 더욱 발전된 보안 분석 기술이 도구로 활용 가능해지면 그 기능이 확장될 것이라고 확신합니다. [음악] 방금 보안 확장 프로그램 [음악]을 소개하고 로컬 환경과 GitHub에서 사용하는 방법을 보여드렸습니다 . 저희는 여러분이 코드 기반 [음악] 환경에서 이를 사용해보고 CI/CD 워크플로에 포함시키는 더욱 창의적인 방법을 실험해 보시기를 기대합니다. 무료 Google Cloud 크레딧이 제공되는 이 코드 랩에서 Gemini CLI 보안 확장 프로그램을 직접 사용해 보고 의견을 알려주세요 .
