Java용 ADK 1.0 출시를 발표하게 되어 기쁩니다. 하지만 코드와 기능에 대해 자세히 알아보기 전에, 지난주에 Java 1.0용 ADK를 사용하여 즉흥적으로 코딩한 멋진 기능 하나를 보여드리겠습니다 . 이것 좀 봐. 정말이지, 이거 얼마나 놀라운 일인가요? Comic Trip은 여행 사진을 멋진 만화로 만들어주는 앱입니다. 사진과 함께 설명, 주변 명소 정보도 제공합니다. 저는 Google의 Stitch를 사용하여 UI 디자인을 코딩했고 , Antigravity와 Quarkus Java 프레임워크 및 Java용 ADK를 사용하여 백엔드를 개발했습니다. 걱정하지 마세요, 제가 모든 것을 보여드리겠습니다. 실제로 여러분은 ADK for Java를 사용하여 이처럼 멋진 작업을 직접 수행할 수 있습니다 . 코드, 프롬프트, 모든 것을 공유하겠습니다. 준비가 된? 갑시다 . 코드를 살펴보기 전에 Java 1.0용 ADK에 대해 할 말이 많습니다. 새로운 기능과 개선 사항이 많이 추가되었습니다. 코믹 트립 에이전트에 대해 자세히 알아보기 전에, 나노 바나나로 만든 이 스케치 노트를 통해 몇 가지 특징을 간단히 보여드리겠습니다. 우선, 저희는 상담원의 역량을 확장할 수 있는 강력한 도구를 보유하고 있습니다. 저희는 Google 지도 도구와 같은 새로운 기반 도구를 활용하여 상담원의 답변을 Google 지도의 위치 및 장소 데이터에 기반하도록 지원합니다 . URL 컨텍스트 도구를 사용하면 복잡한 웹 검색 파이프라인을 구축할 필요 없이 웹 콘텐츠를 쉽게 가져올 수 있습니다. Vertex AI의 Docker 컨테이너 또는 클라우드에서 실행되는 코드 실행기 덕분에 에이전트는 안전하게 코드를 실행할 수 있습니다 . 또한 에이전트가 컴퓨터 사용 도구와 더욱 상호 작용할 수 있도록 하는 새로운 추상화 기능이 추가되었습니다. 이 기능은 에이전트가 브라우저나 컴퓨터에 액세스할 수 있도록 구현할 수 있는 인터페이스를 제공합니다. 에이전트 수명 주기의 주요 지점에 로직을 삽입하기 위해 콜백을 사용해 본 경험이 있을 수 있습니다. 예를 들어 안전 장치 구현, 상태 관리, 관찰 가능성 확보 등에 사용할 수 있습니다. 하지만 이제 여러분은 두 가지 새로운 추상화 개념을 활용할 수 있게 되었습니다. 하나는 전체 에이전트 시스템을 포괄하는 앱이고, 다른 하나는 다중 에이전트 시스템의 모든 에이전트에 정책을 적용할 수 있는 플러그인입니다. 로깅 플러그인, 컨텍스트 필터링 플러그인, 전역 명령 플러그인과 같은 몇 가지 내장 플러그인이 있습니다. 예를 들어, 모든 요원들이 해적처럼 말하거나, 아니면 전부 대문자로 대답하며 소리치도록 하고 싶을 수도 있습니다 . 에이전트 간 상호작용이 풍부해질수록 컨텍스트를 처리하는 문제가 발생합니다. 컨텍스트가 너무 커지면 LLM이 혼란스러워질 수 있으므로 컨텍스트 오류를 ​​방지하기 위해 컨텍스트 엔지니어링 기법을 적용해야 합니다 . ADK 이벤트 압축, 요약, 토큰 수 제한 등을 위해 내장된 메커니즘을 사용할 수 있으며, 물론 사용자 지정 전략을 구현할 수도 있습니다 . 에이전트에게 상당한 자율성을 부여하더라도, 인간의 도움이 필요한 경우가 분명히 존재합니다. 예를 들어, 사람의 승인이 필요한 시스템이나 담당자가 누락된 추가 정보가 필요한 경우 등이 있습니다 . 이러한 인간 참여 시나리오의 경우, 상담원이 선호하는 사람과 상호 작용할 수 있도록 구성할 수 있는 도구 확인 솔루션이 있습니다. 서비스는 ADK 에이전트의 핵심 기능입니다. Vertex AI 또는 Firestore에 상태를 저장하여 장기적으로 기억할 수 있는 새로운 서비스가 추가되었습니다. 또한 아티팩트의 경우 이제 Google Cloud Storage 버킷에 블롭을 저장할 수 있습니다 . 마지막으로, A2A(에이전트 간) 프로토콜과의 통합에 대해 말씀드리겠습니다. 이 프로토콜을 통해 에이전트들은 다른 프레임워크, 프로그래밍 언어 또는 플랫폼의 에이전트를 포함하여 다양한 모델 방식으로 다른 에이전트와 상호 작용할 수 있습니다. 하지만 마치 빨랫감 목록을 훑어보듯 모든 기능을 자랑하기보다는, 이러한 새로운 기능과 개념들을 활용한 예시를 하나씩 살펴보겠습니다. 저희 코믹 트립 에이전트는 여행 사진을 빈티지 팝아트 만화 일러스트로 변환해 드립니다. 다음은 제가 만든 코믹 트립 애플리케이션의 인터페이스입니다 . Quarkus 프레임워크로 개발된 Java 애플리케이션입니다. 이전 탐험들을 만화 형식으로 재현한 작품들을 이미 보실 수 있습니다. 드래그 앤 드롭하거나 클릭하여 새 사진을 업로드할 수 있습니다. 혹시 궁금해하실까 봐 말씀드리자면, 저는 UI 디자이너가 아니어서 프론트엔드 작업은 AI의 도움을 받았습니다. 그래서 저는 구글 스티치를 사용하여 이 애플리케이션의 디자인을 만들었습니다 . 사용자가 사진을 업로드하면 약 1분 후에 모든 빈티지 만화 일러스트가 표시되는 여행 상세 정보 화면으로 이동합니다. 최근에 보수 공사를 마친 파리 노트르담 대성당 사진을 여기에 올렸습니다. 아래쪽 사진 중 하나를 클릭하면 담당자가 구글 지도에서 가져온 주변 명소에 대한 추가 정보를 확인할 수 있습니다 . 좋아요, 여러분은 소시지가 어떻게 만들어졌는지 궁금하실 거라고 생각해요, 그렇죠? 자, 시작해 볼까요? 코믹 트립 에이전트는 실제로 다중 에이전트 시스템입니다. 이 시스템은 제미니 3 플래시를 사용하여 사진을 분석하고, 사진 속 내용을 파악하며, 사진이 촬영된 위치를 추측하는 일련의 과정으로 구성되어 있습니다. 그다음에는 두 가지 일을 하는 병렬 흐름이 있습니다. 관심 지점 안내 담당자는 구글 지도 도구를 사용하여 해당 위치 주변의 관심 지점을 찾고 있습니다 . 동시에 나노 바나나 2로 구동되는 에이전트가 빈티지 만화 일러스트를 제작합니다. 먼저 이야기의 배경을 설정하는 첫 번째 인물부터 살펴보겠습니다. 이 에이전트는 입력 이미지를 받아 이미지에 대한 설명을 출력하고 이미지가 촬영된 위치를 추측합니다. 우리는 이 정보를 출력 키를 통해 에이전트 상태에 저장합니다. 관심 지점 에이전트는 에이전트 상태를 사용하여 설명과 위치를 가져온 다음 Google 지도 도구를 사용하여 주변 랜드마크를 검색합니다. 만화 작가가 나노 바나나 2 모델을 사용하고 있습니다. 업로드된 사진을 빈티지 만화 일러스트로 변환해 줍니다 . 또한 사진에 대한 설명을 가져와 만화 캡션을 추가합니다 . 우리는 모델이 추가 텍스트 없이 이미지만 출력하도록 구성합니다. 하지만 아직 끝나지 않았습니다. 모델 호출 후 콜백에서 생성된 응답 중 생성된 만화 이미지가 포함된 부분을 필터링하고 클라우드 스토리지 버킷의 아티팩트 서비스에 저장합니다 . 모든 에이전트를 정의하고 나면 , 이들을 병렬 및 순차 에이전트 내부에 연결하여 다중 에이전트 시스템의 전체 흐름을 구성합니다. 이제 이벤트 루프를 준비할 차례입니다. 저희 에이전트형 앱을 나타내는 이 앱 컨셉을 살펴보세요. 이는 주요 흐름을 근본 원인으로 삼습니다. 그리고 보세요, 새로운 플러그인 시스템도 있네요. 여기서는 시스템 내의 모든 하위 에이전트에 적용될 로깅 플러그인을 정의합니다 . 따라서 각 에이전트를 개별적으로 구성할 필요 없이 모든 내용이 기록됩니다. 실행기를 정의할 때, 생성된 일러스트레이션을 버킷에 저장하는 새로운 Google Cloud Storage 아티팩트 서비스인 아티팩트 서비스를 설정합니다 . 이렇게 해서 저희는 코믹 트립 앱을 개발했습니다. 저희는 구글 클라우드 스토리지 아티팩트 서비스, 나노 바나나 2와 같은 최신 모델, 그리고 구글 지도에서 관심 지점을 표시하는 도구 등 멋진 신규 서비스를 많이 사용했습니다. 우리는 메인 앱을 정의하고 플러그인을 활용하여 로깅을 전역적으로 적용했습니다. 이 모든 것은 Java 1.0용 ADK 덕분입니다. 더 자세히 알아보고 싶다면 Comic Trip 앱의 코드를 살펴보거나, Java 1.0용 ADK의 주요 기능에 대한 자세한 내용을 담은 블로그 게시물을 읽어보고, 문서와 템플릿 프로젝트의 링크를 통해 더 빠르게 시작할 수도 있습니다. 시청해 주셔서 감사합니다. 여러분이 ADK for Java를 사용하여 어떤 에이전트를 구축할지 기대하겠습니다 . 건배.
