## 스크립트

GitHub Copilot과 JBrains IDE는 강력한 새로운 기능을 통해 모델 컨텍스트 프로토콜을 지원합니다 . 오늘은 외부 도구와 컨텍스트를 IDE에 직접 가져오는 기능들을 보여드리겠습니다. 첫째, MCP를 지원하는 에이전트 모드입니다. 에이전트 모드를 사용 하면 GitHub Copilot이 더욱 자율적으로 작동할 수 있습니다. 이 저장소에 어떤 미해결 문제가 있는지 물어볼 수 있고, Copilo는 GitHub MCP 서버를 사용하는 방법을 알고 있습니다 . 목록에 추가되면, 해당 기능에 문제를 구현하도록 요청하고 작업을 시작할 수 있습니다. Copilot은 파일 읽기, 작업 계획 수립, 출력 결과 등 각 단계를 자세히 설명합니다. 출력을 빌드하고 유효성을 검사하기 위한 터미널 명령을 실행할지 확인하는 메시지가 표시됩니다. 오류가 발생하더라도 문제가 해결될 때까지 자동으로 계속 작동합니다. 변경 사항을 검토하고, 추가 안내 메시지를 통해 출력 결과를 수정하고, 만족스러우면 승인할 수 있습니다. 다음은 MCP의 새로운 개선 사항 중 하나인 샘플링 기능입니다. 설정 &gt; 모델 컨텍스트 프로토콜로 이동하여 Copilot이 전역 및 서버 수준에서 사용할 수 있는 모델을 구성할 수 있습니다. 그러면 제가 선호하는 모델로 도구를 호출하고 채팅 창에서 바로 결과를 확인할 수 있습니다. MCP 프롬프트도 새롭게 추가된 기능입니다. 슬래시(/)를 입력하면 설치된 MCP 서버의 프롬프트를 탐색할 수 있습니다 . 그러면 프롬프트를 선택하고 팝업 창을 통해 인수를 입력한 다음 실행할 수 있습니다. 프롬프트에 파일이나 이미지와 같은 리소스가 필요한 경우 , 해당 리소스는 자동으로 참조로 추가됩니다 . 저는 추가적인 맥락 정보를 얻기 위해 MCP 서버를 활용할 수도 있습니다 . 컨텍스트 추가를 클릭한 다음 NCP 리소스를 클릭하면 사용 가능한 NCP 서버 중에서 선택할 수 있습니다. 파일 시스템 서버와 같은 리소스를 제공하는 MCP 서버의 경우 , 위에서 언급한 기능을 사용하면 특정 구성 파일이나 패턴을 직접 선택할 수 있습니다. 그리고 여기서부터 정말 흥미로워집니다. MCP 유도. 저장소 구성 정보 추출을 호출하면 Copilot이 구조화된 대화 흐름을 통해 안내해 줍니다. 단계별로 답변할 수 있으며, IDE를 다시 시작해도 대화 기록이 유지됩니다 . 이 기능은 실제 시나리오, 구성 마법사, 요구 사항 수집 또는 안내형 문제 해결과 같은 상황에서 매우 유용합니다. 사용자가 사전에 어떤 정보를 제공해야 할지 고민할 필요 없이 Copilot이 적절한 질문을 던져주기 때문입니다. 이것이 바로 Jet Ideas에서 MCP와 함께 GitHub Copilot을 사용할 때 얻을 수 있는 강력한 효과입니다. 즐거운 코딩 되세요.
