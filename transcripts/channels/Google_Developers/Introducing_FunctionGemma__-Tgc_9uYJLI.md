## 스크립트

[음악] 저희가 지금까지 출시한 가장 작은 모델인 Gemma 3 270M을 출시했을 때 , 커뮤니티에서는 공구 호출 기능을 요청했습니다. 오늘 저는 함수 호출에 특화된 Gemma 3(2억 7천만 개의 매개변수를 가진 모델)의 특별 버전인 Function Gemma를 소개하게 되어 매우 기쁩니다. Function Gemma는 자연어 처리 기능도 그대로 유지하고 있습니다. Function Gemma는 자연어를 함수 호출 및 API 작업으로 변환할 수 있는 빠르고 안전하며 비용 효율적인 앱을 구축하려는 개발자를 위해 설계되었습니다. Function Gemma는 용량이 작음에도 불구하고 적절한 함수를 판별하도록 학습되었으며, 특정 작업에 더욱 강력하게 대응하도록 세밀하게 조정할 수 있습니다. 예를 들어, 이미 알려진 기능들을 가진 앱이 있다면 , Function Gemma를 해당 기능들에 특화된 전문가로 세밀하게 조정할 수 있습니다. 이를 통해 규모가 훨씬 큰 모델 과 동일한 성공률을 보일 수 있는 특수 모델을 만들 수 있습니다 . 기본 모델의 크기가 작고 파라미터 수가 2억 7천만 개에 불과하기 때문에 임베디드 및 모바일 하드웨어에서도 입력 처리 및 동작 수행 속도가 매우 빠릅니다 . GPU나 NPU 같은 가속기를 활용하면 훨씬 더 빠른 속도가 가능해집니다. 모바일 개발자에게 Function Gemma는 채팅 기반 상호 작용을 넘어 자연어를 기기 에서 완전히 실행할 수 있는 실행 가능한 동작으로 변환할 수 있는 기회를 제공합니다 . Function Gemma를 선보이기 위해 Google AI Edge를 사용하여 모바일용 데모를 여러 개 제작했습니다 . 이제 라빈에게 마이크를 넘겨서 Function Gemma가 실제로 어떻게 작동하는지 보여드리겠습니다. 모바일 액션은 사용자가 음성 또는 텍스트 입력을 통해 기기에서 특정 작업을 실행할 수 있는 데모 앱입니다. 이를 구현하기 위해 Function Gemma를 기반으로 하는 모델을 미세 조정했으며, 모델이 사용할 수 있는 도구로 전달되는 소수의 함수를 활용했습니다. 내일 점심 일정을 캘린더에 추가하든, 존을 내 연락처에 추가하든, 아니면 단순히 손전등을 켜든, 이 모델은 자연어를 분석하여 명령을 실행할 올바른 기기 내 도구를 식별합니다. 여기에서 순서를 확인할 수 있습니다. 모델이 명령어를 해석하고 앱이 호출할 적절한 함수를 요청하는 과정을 살펴보세요. Function Gemma를 개발하는 동안 새로운 함수 호출 형식을 사용함으로써 기본 Gemma 3 270M 모델에만 프롬프트를 사용하는 것보다 정확도가 향상되는 것을 확인했습니다. 추가적인 미세 조정을 거친 결과, 모바일 액션 데모에 사용된 작업에서 기본 Function Gemma 270M 모델보다 정확도가 더욱 향상된 것을 확인했습니다. 데모 버전을 최적화하는 단계별 방법을 게시했으니 직접 시도해 보세요. 이 데모는 Google Play 스토어에서 찾을 수 있는 Google AI Edge Gallery 앱에서 사용해 보실 수 있습니다. 다음 데모에서는 정교하게 조정된 Function Gemma 모델이 사용자 명령에 따라 모바일 게임의 게임 메커니즘을 어떻게 구동하는지 보여드리겠습니다 . 이 대화형 미니 게임에서 플레이어는 음성 명령을 사용하여 가상의 토지를 관리합니다. "맨 윗줄에 해바라기를 심고 물을 주세요."라고 말할 수 있습니다. 그런 다음 모델은 특정 그리드 좌표를 사용하여 작물 심기 또는 작물에 물 주기와 같은 특정 앱 기능을 선택하고 해당 작업을 수행하기 위한 게임 로직을 실행합니다. 자유 형식 입력에서 함수 호출과 인수를 생성할 수 있는 모델을 사용하면 사용자 쿼리에서 데이터를 조회하거나 , 쿼리를 적절한 하위 에이전트로 라우팅하거나, 게임 및 앱과 상호 작용하는 새로운 방식을 제공하는 등 다양한 사용 사례를 구현할 수 있습니다. Function Gemma는 소비자용 하드웨어에서 안정적으로 작동할 수 있을 만큼 크기가 작아 새로운 사용 사례를 가능하게 할 뿐만 아니라 개인 정보 보호, 오프라인 기능, 클라우드 비용 절감 등 기기에서 AI를 실행할 때 얻을 수 있는 일반적인 이점도 제공합니다. 이것들은 단지 몇 가지 예일 뿐입니다. 하지만 Function Gemma는 세밀한 조정을 위해 설계되었으므로, 자신 만의 AI 워크플로우를 구동하는 데 필요한 특수 함수 호출 모델을 직접 만들 수 있습니다. 해당 모델은 Hugging Face, Kaggle, Vertex AI 등 일반적인 플랫폼에서 구할 수 있습니다. 저희의 모든 Gemma 모델과 마찬가지로, 이 모델 또한 Hugging Face Transformers, Ollama, vLLM, llama.cpp, Light RT, MLX 등과 같은 인기 있는 도구 및 프레임워크에서 작동합니다. 어디서 어떻게 조율할지는 당신에게 달려 있습니다. TRL, Unsloth, Vertex AI 중 어떤 것을 선호하시든 Function Gemma는 이 모든 것과 호환됩니다. 함수 호출 형식 및 모범 사례에 대해서는 Gemma 쿡북에 포함된 가이드와 예제를 참조하여 시작해 보세요. 지금 바로 모델 튜닝을 시작하세요 . Function Gemma를 사용하여 어떤 통화를 걸게 될지 정말 기대됩니다. [음악]
