# 자동화·증강 양축 동시 최적화 사례 — 저장소 수집 스크랩 한정 탐색

> 이론 기준: Raisch & Krakowski (2021), *AMR* 46(1): 192–210.
> 논문 사례 목록은 `docs/RAISCH_KRAKOWSKI_2021_CASES.md` 참조.
> 탐색 범위: **본 저장소가 수집한 `transcripts/**/*.md` 9,431건 한정.** 외부 검색 미사용.

## 1. 무엇을 "양축 최적화"로 셀 것인가

논문은 자동화(automation)와 증강(augmentation)의 단순 병존이 아니라, **분화(differentiation)와
통합(integration)을 함께 갖춘 선순환**만을 성공 사례로 본다. 그래서 다음 4개 조건을 코딩 기준으로
삼았다. 두 축 어휘가 함께 나온다는 것만으로는 사례로 세지 않았다.

| 코드 | 논문 근거 | 조작적 정의 |
|---|---|---|
| **AUTO** | p.194 | 기계가 과업을 인계, 인간을 루프에서 제외 |
| **AUG** | p.194 | 인간이 루프에 남아 기계와 밀착 협업 |
| **CYCLE** | p.196–197 (시간축) | 증강 학습 → 견고화 → 자동화, 또는 조건 변화 시 증강 회귀 |
| **SPILL** | p.197 (공간축) | 한 과업의 자동화가 인접 과업의 증강을 유발 |
| **REINVEST** | p.201 (UBS 패턴) | 자동화로 확보한 자원을 증강에 재투자 |
| **RESP** | p.200 (통합 조건) | 인간이 프로세스 전체 책임·승인·감사를 보유 |

## 2. 방법

`analysis/paradox_scan.csv` — 전 스크랩을 위 6개 축으로 규칙기반 코딩(한/영 이중 어휘, 순수 정규식).
5,742건(본문 300단어 이상)이 채점 대상.

이어서 **창(window) 동시출현 추출**을 수행했다. AUG 마커 전후 700자 안에 AUTO 마커가 함께 존재하는
구절만 잘라내, "같은 과업/프로세스를 말하면서 두 축을 함께 설계한" 진술만 남겼다.
→ **355개 구절 / 275개 영상**. 여기에 CYCLE·SPILL·REINVEST·RESP 가점과 수치 언급 가점을 주어
정렬한 뒤, 상위 구절을 전수 판독해 **실제 조직 사례**만 추렸다(벤더 제품 데모·일반론 제외).

재현 명령:

```bash
python scan_paradox.py   # → analysis/paradox_scan.csv
python cooc.py           # → 동시출현 구절 355건
```

> "our vision here is over time we believe that **autonomous medical coding is possible** … but we probably
> get there by **first having a co-pilot that helps a medical coder and then over time as accuracy is
> validated we then move into autonomous coding**"

> "not only the ability to automate this at scale but also provide the **audit trail** … what the demo is

**왜 중요한가.** JP Morgan Chase·Symrise의 "증강 1~2년 → 견고화 → 자동화" 경로를 **사전에 명시한

판단하기 위한 **HITL 대시보드**라는 계측 장치가 함께 등장한다. 감사 추적(audit trail)은 논문이
통합 조건으로 든 "인간의 프로세스 총괄 책임"(p.200)의 구현체다.
ICD-10 코드 조합의 순열이 감당 불가라 규칙기반 자동화가 불가능하다는 설명도 p.195의 논지와 같다.

## 5. 판독 결과에 대한 유의사항

1. **표본이 공급측에 치우쳐 있다.** 9건 중 7건이 벤더·컨설팅 공식 채널 자료다. 자동화·증강을
   동시에 잘하고 있다는 서술은 대부분 **자사 제품의 성공 서사**로 제시된다. 90%·92%·85% 같은
   수치는 전부 **자체 보고치**이며 독립 검증된 값이 아니다. 논문의 Unilever·UBS 수치와 같은 한계다.
2. **실패·악순환 사례는 거의 잡히지 않는다.** 논문이 경고한 자동화 편중의 탈숙련·경로고착
   (p.199)이나 증강 편중의 몰입 상승은, 코퍼스에서 일반론("AI 파일럿 95% 실패")으로만 등장하고
   **특정 조직의 실패 사례로는 서술되지 않는다.** 공식 채널 수집 구조상 당연한 편향이며,
   `sig_deskilling` 출현율이 ~0%인 것(`docs/CODEBOOK_v2.md`)과도 일치한다.
3. **자막 품질 한계.** 다수가 기계 번역 자막이라 "휴머 인더루프", "체포(=챗봇)", "진흥화(=지능화)"
   같은 오인식이 섞여 있다. 정규식 어휘에 변이형을 넣어 보정했으나 재현율은 완전하지 않다.
   인용 시 **원 영상으로 발화를 재확인**할 것.
4. **논문 사례와의 대조.** 논문의 핵심 사례 Symrise는 코퍼스 언급 0건이고, JP Morgan Chase·
   Unilever·UBS도 자동화–증강 맥락으로는 등장하지 않는다. 즉 **학술 문헌의 정전(canon) 사례와
   실무 담론이 공유하는 사례는 사실상 없다.** 위 9건은 코퍼스가 독자적으로 제공하는 신규 사례군이다.
