## 스크립트

혹시 코드를 프로덕션 환경에 배포하고 나서 바로 그 코드가 무슨 일을 하는지, 어떻게 하는지, 심지어 왜 그런 결정을 내렸는지조차 잊어버린 적 있으신가요? 저도 그런 적은 없어요. 그런 코드는 배포하는 순간 레거시 코드가 되어버리죠. 하지만 질문 하나만 하면 코드를 이해할 수 있다면 어떨까요? 저는 AWS의 수석 개발자 옹호자(Principal Developer Advocate)인 제나 폰입니다. Amazon Q Developer를 사용하면 IDE에서 레거시 코드를 단 몇 초 만에 해독할 수 있다는 것을 보여드리겠습니다. IDE에서 익숙하지 않은 코드를 보고 계신가요? 어쩌면 예전 동료가 남겨준 코드일 수도 있겠죠. 몇 시간씩 리버스 엔지니어링을 하는 대신, 코드 블록을 선택하고 마우스 오른쪽 버튼을 클릭한 다음 Amazon Q Developer 메뉴에서 '설명'을 선택해 보세요. 몇 초 만에 코드가 무엇을 하는지 명확하고 자연스러운 언어로 설명해 줍니다. 이제 과거에 작성했던 코드든, 새로운 프로젝트에 참여하는 코드든, 아니면 동료가 남긴 코드를 넘겨받는 것이든, 코드베이스를 이해하는 데 걸리는 시간을 크게 줄일 수 있습니다. 복잡한 패턴이나 Dyra 최단 경로 알고리즘 같은 까다로운 코드도 마찬가지입니다. 코드를 선택하고 '설명'을 선택하면 Amazon Q Developer가 단계별로 코드를 분석하고 자연어로 번역해 줍니다. 복잡한 논리를 쉬운 영어로 풀어 설명하여 고급 개념을 더 쉽게 이해할 수 있도록 도와줍니다. 채팅창에서 추가 질문을 통해 궁금한 점을 명확히 할 수도 있습니다. 이제 오래되고 지저분한 코드를 개선해야 하는데 어디서부터 시작해야 할지 모르겠다고 가정해 보세요. Amazon Q Developer를 사용하면 가독성, 효율성 또는 구현의 다른 측면을 개선하는 리팩토링 제안을 받을 수 있습니다. 리팩토링할 코드를 선택하고 '리팩토링'을 선택하면 맞춤형 제안을 받을 수 있습니다. 마치 전문가 코드 리뷰어가 바로 옆에서 코드 최적화 및 모범 사례를 안내해 주는 것과 같습니다. 코딩 생산성을 향상시킬 준비가 되셨나요? Amazon Q Developer를 사용하여 AI 기반 코드 이해 및 리팩토링의 강력한 기능을 경험해 보세요. 자세한 내용은 설명란을 참조하세요. 미래의 당신은 분명 만족할 것입니다. 이와 같은 영상을 더 보고 싶다면 AWS Developers YouTube 채널을 구독하고 좋아요를 누르거나 댓글을 남겨주세요. 생성형 AI가 코딩 방식을 어떻게 바꾸고 있는지에 대한 의견을 공유해 주세요.
