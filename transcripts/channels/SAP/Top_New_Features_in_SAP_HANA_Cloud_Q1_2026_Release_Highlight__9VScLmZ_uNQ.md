## 스크립트

Hi, everyone. It's Thomas, your lead product manager for SAP HANA Cloud. The first release of 2026 is just around the corner, and I'm excited to give you an exclusive preview of some of the innovations coming with our Q1 release of SAP HANA Cloud. This release continues SAP HANA Cloud's journey as the database AI was looking for. We're introducing new capabilities that make it easier to explore data, integrate across SAP platforms, analyze performance, and build intelligent applications. So let's jump right in and take a look at some of the highlights. First up, we're introducing the discovery agent and the data agent in SAP HANA Cloud. Today, working with enterprise data often requires deep knowledge of the underlying database. You need to know where the data lives, how tables are related, and how to write a right SQL query. Well, for many developers and data users, this can become a major barrier when they simply want to explore data and retrieve insights. The discovery agent and data agent are designed to solve exactly that challenge. Instead of writing queries manually, you can rely on a custom database object knowledge graph and simply describe what you want to use via natural language. For example, you might ask, predict a sales conversion probability for all customers and show the details. The discovery agent finds the relevant data using the knowledge graph, while the data agent converts the request into SQL and executes it in SAP HANA Cloud. The outcome is a much more intuitive way to work with enterprise data. You can explore, analyze, and act on data without needing deep knowledge of the schemas or your database artifacts. The perfect foundation for data analysis in natural language or interactions with other agents. If you're equally excited about these capabilities and want to benefit from the new agents early on, don't miss to register for our beta program, giving customers and partners the opportunity to experiment with conversational agent-driven data discovery directly on enterprise data. Next, let's talk about semantic onboarding of calculation views into SAP Business Data Cloud. Many organizations already use calculation views in SAP HANA Cloud to model and structure their data and analysis. With this innovation, you can now bring those existing assets directly into SAP Business Data Cloud through semantic onboarding. This innovation allows you to selectively onboard calculation views from SAP HANA Cloud and integrate them into a unified business data cloud experience without data movement based on remote data connectivity. The benefit is clear. You can reuse existing models and SAP HANA Cloud artifacts, while at the same time complementing it with the capabilities provided by SAP Business Data Cloud. This helps organizations to benefit from both approaches, extending existing analytics assets with Business Data Cloud, while still having the possibility to evolve SAP HANA-based calculation views. Another highlight of the Q1 release is the new performance analysis application in SAP HANA Cloud. Troubleshooting database performance can sometimes require deep expertise and multiple tools. This new application simplifies the process by providing guided workflows directly within the central administration environment. The application includes predefined analysis presets, which offer ready-to-use workflows for common performance scenarios such as CPU bottlenecks, memory pressure, or lock contention. Each preset provides structured diagnostic steps and guidance, making it easier to quickly identify and resolve performance issues. For deeper investigation, the application also includes an on-demand chart library allowing to add specialized performance charts and metrics to your analysis workspace. Together, these capabilities lower the expertise barrier for troubleshooting, while still enabling detailed, flexible performance analysis when needed. Let's continue with improvements in text classification capabilities in SAP HANA Cloud. With this release, we're introducing enhancements to the predictive analysis library that improve performance and efficiency for text classification tasks, as well as ease of use. For example, we're enabling text feature processing with automated machine learning models, making it easier to integrate text analytics into applications. These improvements allow you to achieve more accurate results while also benefiting from faster computation times and reduced memory usage while running text classification analysis, making SAP HANA Cloud an even stronger platform for building intelligent applications. And finally, a quick look at some additional innovations coming in the Q1 release. These include a direct connection option for replicas, enabling simplified connectivity when working with replicated systems. In addition, SAP HANA Cloud expands its machine learning capabilities with feature agglomeration and affinity propagation clustering using vector data. Moreover, we continue expanding with additional data centers, bringing SAP HANA Cloud closer to your region of choice. As always, these are just a few of the innovations coming with our SAP HANA Cloud Q1 2026 release. If you'd like to learn more, stay tuned for our upcoming What's New in SAP HANA Cloud webcast, where we will explore more of these features in detail. Thanks for tuning in and don't forget to stay connected with our SAP HANA Cloud community for the latest updates and subscribe to our playlist. See you soon again.
