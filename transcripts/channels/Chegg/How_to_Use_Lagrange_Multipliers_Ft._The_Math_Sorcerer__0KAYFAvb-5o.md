( 여기서 x² + y²를 볼 수 있죠.) 그리고 이 문제에서 C는 4입니다. 따라서 C는 4입니다. 그래서 우리는 X² + y² = 4를 얻습니다. 다시 말해 g = x² + y² + c입니다. 자, 이제 기울기를 구해봅시다. 함수 f의 기울기는 구성 요소가 모두 편미분인 벡터라는 것을 기억하세요. 공식을 알려드리기 위해 여기에 적어 놓겠습니다. 첫 번째 구성 요소는 X에 대한 편미분이므로 FX이고, 두 번째 구성 요소는 Y에 대한 편미분입니다. 따라서 f의 기울기는 구성 요소가 FX와 FY인 벡터와 같습니다. 자, 이제 실제로 기울기를 계산해 보겠습니다. 이 맨 위 줄에서 바로 시작하겠습니다. 여기서 기울기를 계산할 것입니다. 먼저 f를 X에 대해 편미분합니다. f는 x² - y² + 1입니다. X에 대한 편미분을 취할 때 모든 y는 상수이므로 y²의 미분값은 0입니다. 따라서 첫 번째 편미분값은 2x가 됩니다. 그리고 Y에 대한 편미분값은 이 경우 x²의 미분값은 z이고, 1의 미분값은 0입니다. y는 상수이므로 -2y가 됩니다. 따라서 X에 대한 편미분은 2x이고, Y에 대한 편미분은 -2y입니다. y는 λ와 같으므로 이제 G의 기울기를 구하겠습니다. G는 훨씬 간단합니다. X에 대한 미분은 2x이고, Y에 대한 미분은 2y입니다. X에 대해 미분할 때 모든 y가 상수이므로 y²의 미분은 0이고, 마찬가지로 Y에 대해 미분할 때 x²의 미분은 0입니다. 이제 두 벡터가 같고, 성분을 같게 놓아 보겠습니다. 먼저 2x - 2y를 곱하면 2λx = 2λy가 됩니다. 이렇게 쓰겠습니다. 이제 두 벡터가 같고, 성분이 같으므로 2x = 2λx입니다. 첫 번째 항과 두 번째 항을 같다고 놓으면 -2y = 2λy가 됩니다. 정말 멋지네요! 자, 이제 흥미로운 일이 벌어집니다. 첫 번째 방정식을 풀어서 어떤 결과가 나오는지 봅시다. 양변에서 2x를 빼면 2λx - 2x = 0이 됩니다. 2x를 밖으로 빼낼 수 있을 것 같네요. 2x를 밖으로 빼내면 2x - λ = 0이 됩니다. 즉, 2x = 0 또는 λ - λ = z가 됩니다. 그런데 이런 문제의 대수 계산은 가끔 정말 복잡해집니다. 항상 결과가 다르기 때문에 그냥 이것저것 시도해 보고 어떤 결과가 나오는지 보는 게 좋습니다. 지금 우리가 하고 있는 것도 바로 그거죠. 2x를 빼고, λ를 0으로 놓고, 2로 나누면 x = 0이 되고, 1을 더하면 λ = 1이 됩니다. 자, 이제 무슨 일이 일어나고 있는지 생각해 보고, 다음 몇 단계를 제대로 이해해 봅시다. 다시 한번 조건을 적어볼게요. 우리의 조건은 x² + y² = 4였죠. 보통 이런 문제를 풀 때는 이 조건을 사용해야 해요. 람다 와 x를 구할 때, 그리고 방정식을 다룰 때는 항상 제약 조건을 염두에 두어야 합니다. 모든 것을 잘 생각해 보세요. 자, x = z, 즉 람다 = 1입니다. x가 0일 때를 생각해 봅시다. 제약 조건에 0을 대입하면 0² + y² = 4가 됩니다. 즉, y² = 4가 되는 거죠. 양변에 제곱근을 취하면 플러스 마이너스가 되므로 y는 플러스 마이너스 2가 됩니다. 따라서 x가 0일 때 제약 조건에 0을 대입하면 y² = 4가 되고, 양변에 제곱근을 취하면 y(± 2)가 됩니다. 이제 순서쌍 0, 2, 0, -2를 사용하겠습니다. 문제의 마지막 부분은 최댓값과 최솟값을 찾는 것입니다. 이것이 정답은 아니지만 중요합니다. 다른 경우는 람다가 1일 때입니다. 람다가 1이면 어떻게 되는지 생각해 봅시다. 람다가 1이면 이 방정식을 보세요. -2y = 2λy, 즉 -2y가 됩니다. 람다가 1이면 2y가 됩니다. 이는 y가 0이 된다는 것을 의미합니다. -2y는 2y와 같을 수 없습니다. 확신이 서지 않는다면 양변에 2y를 더해 보세요. 그러면 4y = 0이 됩니다. 따라서 람다가 1이면 y는 0입니다. 이제 0을 제약 조건에 대입하면 x² + 0² = 4가 됩니다. 즉, x² = 4입니다. 이전과 마찬가지로 제곱근을 취하면 ±2가 됩니다. 방금 했던 것과 매우 유사합니다. 따라서 순서쌍 두 개를 얻게 됩니다. y는 z이고 x는 ±2입니다. -2를 빼면 20이 되고, -20이 되므로 네 개의 순서쌍이 생깁니다. 이제 이 숫자들을 원래 함수에 대입해 보겠습니다. 원래 함수는 f(x) = y = x² - y² + 1입니다. 이 순서쌍들을 모두 함수에 대입하면 가장 큰 값이 최댓값이고 가장 작은 값이 최솟값입니다. 하나씩 살펴보겠습니다. 먼저 f(0, 2)는 0² - 2² + 1 - 4 + 1이 되므로 최솟값은 -3입니다. 0 -2도 마찬가지로 0² - 2² + 1이 됩니다. -2²는 4이지만 음수가 있으므로 -4 + 1이 되어 최솟값은 -3입니다. 마지막으로 f(2, 0)을 보면 다음과 같습니다. 2^ 2, 즉 2^2 - 0^2 + 1 = 5가 됩니다. 4 + 1은 5이고, -2.0도 마찬가지로 -2^2 + 1 = 5가 됩니다. 이제 답을 구했으니 적어 보겠습니다. 최솟값은 -3으로 가장 작은 수입니다. 최솟값은 0, 2, -2 두 곳에서 나타납니다. 즉, 0 ± 2입니다. 온라인 과제를 할 때 순서쌍을 요구하는 경우가 많습니다. 최댓값은 5로 가장 큰 수 입니다. 최댓값은 2, 0, -2 두 곳에서 나타납니다. 즉, ± 2입니다. 정말 어려운 문제였네요. 이런 문제들은 다 꽤 어렵다는 걸 알아두세요. 이 문제는 비교적 쉬운 편이지만, 앞으로 더 어려워질 수도 있습니다. 난이도는 람다와 X 값을 찾는 것과 그 결과를 확인하는 데 얼마나 어려운지에 따라 달라집니다. 하지만 이 문제를 풀 때 가장 중요한 것은 이 두 방정식에서 시작해서 차근차근 풀어나가는 것입니다. 이 영상이 누군가에게 도움이 되었기를 바랍니다. 재밌게 보셨다면 chag의 다른 영상들도 확인해 보세요. 다음 영상에서 뵙겠습니다. 행운을 빌고, 건강하세요!
