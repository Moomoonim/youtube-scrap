## 스크립트

Vertiv Next Connect 플랫폼에서 Vertiv 구성 파일을 사용하는 방법에 대한 안내서에 오신 것을 환영합니다. 이 비디오에서는 Vertiv 엣지 디바이스에서 구성 파일을 검색, 보고, 준비하는 방법 과 이러한 파일의 구성 방식을 이해할 수 있습니다 . Vertiv 설정 파일은 JSON 형식으로 제공되며, 기능별로 호스트 설정, 장치 설정, 알람 설정의 세 가지 범주로 분류됩니다. 각각은 뚜렷한 목적을 가지고 있습니다. 호스트 파일에는 네트워크 및 통신 설정이 포함되어 있습니다. 장치 파일에는 장치별 설정 및 레이블이 포함되어 있습니다 . 경보 파일에는 경보 임계값과 알림 규칙이 포함되어 있습니다. 이 파일들은 기기에 내장된 웹 인터페이스에서 직접 이용할 수 있습니다. 권장되는 워크플로는 다음과 같습니다. Vertiv 장치 하나를 웹페이지 인터페이스를 사용하여 수동으로 구성합니다. 해당 장치에서 JSON 구성 정보를 추출합니다 . 다른 유사한 장치에도 설정을 적용하려면 약간의 수정을 하십시오 . 이렇게 하면 제대로 작동하는 기준선을 확보하고 수동 입력 오류를 방지할 수 있습니다. 구성 파일을 가져오려면 엣지 디바이스와 동일한 네트워크에 있는 컴퓨터에서 브라우저를 엽니다. 브라우저 주소창에 기기의 IP 주소와 해당 API 경로를 입력하세요. 호스트 구성을 입력하려면, 장치 구성을 입력하려면, 알람 구성을 입력하려면, 각 페이지에는 해당 JSON 구성 콘텐츠가 브라우저에 직접 표시됩니다 . 파일을 로컬 컴퓨터에 저장하려면 브라우저 창에서 마우스 오른쪽 버튼을 클릭하고 '다른 이름으로 저장'을 선택하세요. 파일을 JSON 확장자로 저장하세요. 예를 들어, 필요한 경우 파일 이름을 변경할 수 있지만 JSON 확장자는 반드시 유지해야 합니다. Vertiv NCC Connect에 구성 파일을 업로드하는 데 정리 작업이 필수적인 것은 아니지만, 파일을 더 쉽게 읽거나 수정할 수 있도록 Visual Studio Code, Notepad++, 온라인 JSON 형식 지정 도구 등의 도구를 사용하여 파일을 열어 정리하는 것이 도움이 될 수 있습니다. Visual Studio Code에서는 마우스 오른쪽 버튼을 클릭하고 '문서 서식'을 선택하면 JSON 콘텐츠가 자동으로 들여쓰기되고 구조화됩니다. 이렇게 하면 서식 문제를 더 쉽게 파악 하고 설정을 탐색할 수 있습니다. 파일 형식을 지정한 후에는 여러 유사한 Vertiv 장치에 적용하도록 변경 사항을 적용할 수 있습니다 . 여기에는 장치 이름, 레이블, 경보 임계값, 네트워크 설정 조정(다른 사이트에 적용하는 경우)이 포함됩니다 . 의도적으로 표준화한 경우가 아니라면 기기별 고유 데이터를 덮어쓰지 않도록 주의하십시오. 사용 가능한 모든 설정 및 값에 대한 자세한 내용은 Vertiv 공식 공개 API 사양을 참조하십시오. 해당 문서는 JSON 파일에서 사용되는 모든 지원 필드, 구조 및 데이터 유형을 설명하는 문서로, 여기에서 다운로드할 수 있습니다 . 그게 다입니다 . 이제 Vertiv NCC Connect 플랫폼에서 사용할 Vertiv 구성 파일을 검색, 정리 및 준비하는 방법을 알게 되었습니다 . 구성된 장치에서 시작하여 설정을 추출하고 필요에 따라 편집한 다음 배포 전체에 적용합니다. 이 모든 작업을 사람이 읽기 쉬운 개방형 JSON 파일을 사용하여 수행할 수 있습니다. 시청해 주셔서 감사합니다. 더 많은 사용법 동영상과 지원 정보를 원하시면 교육 자료실을 계속 확인해 주세요.
