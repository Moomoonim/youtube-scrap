## 스크립트

여기서 우리는 새로운 기능과 승인 기준을 선형적으로 설명하는 데 문제가 있습니다. Linear 내에서 이슈를 Copilot에 할당하면 GitHub Copilot 코딩 에이전트에 직접 이 작업을 위임할 수 있으며, 그러면 새로운 에이전트 작업이 생성됩니다. Copilot은 문제 설명 및 댓글을 포함하여 해당 문제와 관련된 콘텐츠를 자동으로 수신합니다 . GitHub에 새 브랜치와 초안 풀 리퀘스트가 생성되며, Copilot은 작업 진행 상황을 지속적으로 업데이트하고 해당 풀 리퀘스트를 기존 이슈에 연결합니다. 또한 선형 보기로 활동 보기를 열어 코파일럿 에이전트 작업 세션 에서 직접 스트리밍되는 로그를 확인할 수 있습니다 . 모든 작업이 GitHub에서 이루어지기 때문에 GitHub Actions, 통과해야 하는 워크플로, 코드 소유자의 필수 검토 , 브랜치 보호 등 기존 정책 및 구성이 모두 적용됩니다.
