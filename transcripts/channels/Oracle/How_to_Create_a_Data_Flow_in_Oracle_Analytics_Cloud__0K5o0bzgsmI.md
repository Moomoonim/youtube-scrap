## 스크립트

이 튜토리얼에서는 Oracle Analytics Cloud 및 Fusion Data Intelligence에서 데이터 흐름을 생성하는 방법을 알아봅니다. 데이터 흐름을 통해 데이터를 구성하고 통합하여 사용자가 수동 코딩 기술 없이도 분석에 사용할 수 있는 선별된 데이터 세트를 생성할 수 있습니다 . 데이터 흐름을 사용하여 데이터 세트를 생성하고, 여러 소스의 데이터를 결합하고 , 데이터를 집계하고, 머신 러닝 모델을 학습시키거나, 예측 머신 러닝 모델을 데이터에 적용하고, OCI Vision 서비스를 통해 AI를 사용하여 객체 감지, 이미지 분류 또는 텍스트 감지를 수행할 수 있습니다. 이 시나리오에서는 원시 주문 라인 데이터를 판매 실적 보고에 사용할 수 있는 두 가지 분석 준비 데이터 세트로 변환하는 데이터 흐름을 생성해야 합니다 . 홈페이지에서 '만들기'를 선택한 다음 ' 데이터 흐름'을 선택하여 데이터 흐름 생성을 시작하겠습니다. 주문 내역 데이터 세트를 검색하여 데이터 흐름에 추가하겠습니다. 이 데이터 세트에는 제품, 수익 및 기타 열을 포함한 판매 데이터가 있으며, 저희 팀이 분석할 예정입니다. 기본적으로 모든 열이 선택되어 있지만, 분석에서 노출되고 싶지 않은 민감한 데이터( 주문 품목 ID 및 신용 카드 번호 포함)와 필요 없는 열은 제거하겠습니다. 주문 및 고객 정보에 주, 우편번호, 도시, 지역 정보를 추가하여 지리적으로 더욱 풍부하게 만들고 싶습니다 . 데이터 흐름에 주 및 지리 데이터가 포함된 다른 데이터 세트를 연결하기 위해 '단계 추가'를 선택한 다음 '데이터 추가'를 선택하겠습니다 . 그다음에는 주별 데이터 세트를 검색해서 데이터 흐름에 추가하겠습니다. 주(state) 데이터 세트를 추가한 후, 주문 내역 데이터 세트와 조인하겠습니다. Oracle Analytics에서 조인 키를 제안하지만, 제가 직접 조인을 확인하겠습니다. 주별 데이터 세트를 선택하면 포함할 열을 선택할 수 있습니다. 이 예시에서는 모든 항목을 그대로 유지하겠습니다. 다음으로 '단계 추가'를 선택한 다음 '열 추가'를 선택하겠습니다 . 목표 달성 여부, 미달성 또는 초과 여부를 평가하는 표현식을 사용하여 '목표 달성률'이라는 계산 열을 만들겠습니다. 이를 통해 우리 팀은 매출 목표를 달성했는지, 그리고 어떻게 달성했는지 파악할 수 있습니다 . 계산 결과를 검증하고 적용하겠습니다. 다음으로, 데이터 흐름에 구간화를 추가하여 목표 달성도를 구간별로 분류하기 위해 '단계 추가'와 '구간 설정'을 선택하겠습니다. 목표 달성도를 위한 네 개의 사용자 지정 구간을 추가하여 달성도 밴드를 만들겠습니다. 방식을 수동으로 설정한 다음 목록으로 이동하여 빈을 사용자 지정하겠습니다. 목표 달성률이 80% 미만인 경우를 위험군으로 분류하겠습니다. 80~95%가 치료가 필요합니다. 진행률은 95~105%로 예상대로입니다. 그리고 105% 이상을 기대 이상의 성과로 평가했습니다. 성취도 등급 열의 미리보기가 표시됩니다. 다음으로, 데이터 흐름을 분기하여 두 개의 별도 데이터 세트를 생성하는 단계를 추가하겠습니다. 첫 번째 분기에서는 국가 열을 기준으로 미국 데이터를 필터링하여 미국 지도부 보고서용 데이터를 생성합니다 . 그다음 더하기 아이콘을 선택하고, 국가를 선택한 후, 미국을 검색하여 필터에 추가합니다. 그런 다음 미국에 대한 필터 데이터를 미리 봅니다 . 첫 번째 데이터 세트의 이름을 미국 매출 목표 달성률이라고 하겠습니다. 두 번째 출력에서는 전역 목표 달성이라는 의미로 필터 없이 데이터 세트를 직접 저장하겠습니다 . 데이터 흐름을 실행하기 전에 데이터 세트와 출력 설정에서 열 데이터 유형과 기본 집계를 확인하겠습니다 . 마지막으로, 데이터 흐름을 판매 목표 달성으로 저장하겠습니다. 그런 다음 데이터 흐름을 실행하여 데이터 세트를 생성합니다. 데이터 흐름이 완료되면 두 개의 출력값을 얻게 됩니다. 미국 매출 목표 달성 데이터 세트와 모든 지역의 목표 달성 데이터 세트. 홈페이지로 돌아가서 데이터를 선택하면 프로세스가 성공적으로 실행되었는지 확인할 수 있습니다. 미국 매출 목표 달성률과 글로벌 목표 달성률에 대한 성공적인 결과 데이터 세트를 검색하고 검증하겠습니다. 데이터 흐름을 구축했으니 이제 데이터를 정리하고 통합하여 영업팀이 데이터를 분석하는 데 사용할 수 있는 선별된 데이터 세트를 만들 수 있습니다. 아래 링크에서 이 시리즈의 다른 비디오와 Oracle Analytics Cloud 및 Fusion Data Intelligence 사용에 대한 추가 자료를 찾아보세요.
