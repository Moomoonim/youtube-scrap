## 스크립트

시크(Deep Seek)라는 새로운 대규모 언어 모델이 속도, 비용, 성능 면에서 AI 커뮤니티를 놀라게 하며 큰 화제를 모으고 있습니다. 과연 딥시크 R1은 어떻게 그렇게 뛰어난 성능을 발휘하는 것일까요? 딥시크 R1은 오픈 AI 01의 경쟁 모델로, 최종 결론에 도달하기 전에 답변을 심사숙고하는 추론 기반 모델입니다. 특히 복잡한 추론이 필요한 어려운 논리적 작업에 탁월한 성능을 보여줍니다. 지금까지 오픈 AI가 01을 어떻게 학습시켰는지 정확히 알려지지 않았지만, 딥시크의 이번 논문을 통해 몇 가지 통찰력을 얻을 수 있었습니다. 그렇다면 딥시크 R1은 어떻게 학습될까요? 대규모 언어 모델(LLM) 학습에는 일반적인 과정이 있습니다. 1단계: 데이터 수집, 2단계: 트랜스포머 모델 구축, 3단계: GPU에 막대한 투자, 4단계: LLM이 오랜 기간 동안 방대한 데이터 세트를 통해 사람처럼 글을 쓰는 방법을 학습합니다. 하지만 잘 알려지지 않은 마지막 단계가 있습니다. 바로 강화 학습입니다. LLM 학습은 종종 Rhf(Reinforcement Learning Function)라고 불리는 인간 피드백 기반 강화 학습을 거칩니다. 채팅에서 어떤 답변을 선호하는지 물어보는 경험을 해보신 적이 있나요? 선호하는 답변을 선택하면 그 정보가 데이터 세트에 추가되는 경우가 많습니다. 오픈 AI를 활용하여 채팅 기능을 개선하는 데 사용하는 이 기술은 사용자의 입력과 선택된 응답을 쌍으로 수집하고, 이를 사용자 피드백 데이터 세트에 연결합니다. 이 데이터를 사용하여 보상 모델이라는 완전히 다른 모델을 학습시키는데, 이 모델은 사람들이 어떤 응답을 선호하는지 파악하는 방법을 학습합니다. LLM 학습의 마지막 단계는 이 보상 모델을 기반으로 세대에 보상을 부여하는 것입니다. 이를 통해 모델은 인터넷 포럼 사용자처럼 말하는 것에서 유용한 채팅 도구로 발전하는 방법을 배우게 됩니다. 일반적으로 강화 학습(RL) 과 보상 모델을 사용하여 LLM을 학습시키지만, 딥시크는 복잡한 추론 작업을 위해 R10을 다른 방식으로 개발했습니다. 딥시크 R10은 사전 지도 학습 없이 RL만을 사용하여 학습되었으며, 보상 학습을 위해 크고 비용이 많이 드는 맞춤형 모델을 만드는 대신, 딥시크 연구원들은 그룹 상대 정책 최적화(GRPO)라는 다른 프로세스를 활용했습니다. 이 프로세스는 다음 방정식으로 나타낼 수 있습니다. 이 복잡한 공식에 대한 자세한 설명은 생략하고, 모델 학습 과정을 좀 더 개략적으로 살펴보겠습니다. 강화 학습에서는 두 가지 모델, 즉 원본 모델과 다음 학습 단계를 거친 업데이트된 모델을 사용할 수 있습니다. 업데이트된 모델의 성능을 평가하기 위해 원본 모델에서 여러 답변을 추출하여 업데이트된 모델에서 추출한 동일한 답변들과 비교합니다. 각 답변에는 해당 보상이 부여되는데, 이는 보상 모델이 아닌 매우 구체적인 하드코딩된 함수 집합에서 비롯됩니다. 예를 들어, 이 경우 모델은 정답을 맞혔을 때 보상을 받지만, 출력 형식을 올바르게 지정했을 때도 보상을 받습니다. 모델의 매개변수는 업데이트된 모델 에서 추출한 모든 답변에 대한 각 보상의 크기를 평가하여 조정할 수 있습니다. 이 값은 두 가지 요소, 즉 업데이트된 모델과 원본 모델의 차이와 평균 보상에 따라 정규화됩니다. 이 과정이 바로 이해되지 않더라도 걱정하지 마세요. 보상 모델 없이, 모델이 스스로 진화하고 학습하여 무엇을 더 잘할 수 있는지 파악하는 것으로 생각하면 됩니다. 연구자들은 보상 모델을 직접 구현할 필요가 없습니다. 모델에 문제를 해결하는 최선의 방법을 알려주는 것 외에도, 모델이 더 높은 보상을 얻도록 학습한 한 가지 방법은 문제를 완전히 독립적으로 더 깊이 생각하는 것이었습니다. 딥 시크 R1은 더 많은 추론이 더 나은 해결책을 제공한다는 것을 학습했는데, 이는 우리 인간에게는 상식과 같은 것입니다. 예를 들어, 논문에서 저자는 모델이 자신의 현재 사고방식에 결함이 있음을 깨닫는 '아하 모멘트'를 경험하고, 그 후 다시 처음부터 시작한다고 설명했습니다. R10의 또 다른 흥미로운 측면은 추론 및 사고 과정에서 사용하는 언어를 자주 혼동한다는 점입니다. 어떤 언어는 특정 생각을 다른 언어보다 훨씬 더 잘 전달할 수 있지만, 이러한 점과 기타 형식 관련 문제로 인해 R10은 최종 모델로 적합하지 않았습니다. 따라서 연구진은 강화 학습만을 사용하여 모델을 훈련하는 대신, 먼저 대량의 생성 데이터(대부분 추론 예제)를 사용하여 딥 시크 G3 기본 모델을 훈련한 다음, 추론 출력을 사람이 더 읽기 쉽게 만들기 위해 강화 학습을 추가로 실시했습니다. 생성된 데이터를 사용한 이러한 콜드 스타트 ​​방식을 통해 모델 출력 형식을 좀 더 보기 좋게 만들 수 있었고, 결과적으로 AI 비서로서 더 잘 작동하게 되었습니다. 이것이 바로 딥 시크 R1이 탄생한 배경입니다. 중국의 한 독립 연구팀이 모델 학습 방법에 대한 자세한 정보를 제공하고 오픈 소스로 공개했는데, 이 모델이 기존의 OpenAI1과 어깨를 나란히 하고 일부 벤치마크에서는 오히려 능가하는 성능을 보여주고 있다는 소식을 들었습니다. 게다가 비용도 매우 저렴하고 속도도 빠릅니다. 오픈 소스라는 점도 빼놓을 수 없죠. 저희는 이미 Verba에 DeepSeek 오픈 소스 모델을 추가했고, 직접 사용해 볼 수 있는 레시피도 제공하고 있습니다. 하지만 모든 LLM 앱과 마찬가지로 데이터를 해당 플랫폼으로 전송한다는 점을 명심하고 개인정보 보호 문제에 주의해야 합니다. 이처럼 새로운 모델 학습 방법에 대한 자세한 정보를 얻을 수 있다는 것은 정말 멋진 일입니다. 오픈 소스이기 때문에 저희 인프라에서도 사용할 수 있고, API를 통해 개인 데이터를 전송할 때 보안 문제를 걱정할 필요도 없습니다. 이 긴 영상을 끝까지 시청해 주셔서 감사합니다. 모든 자료는 설명란에 링크되어 있습니다.
