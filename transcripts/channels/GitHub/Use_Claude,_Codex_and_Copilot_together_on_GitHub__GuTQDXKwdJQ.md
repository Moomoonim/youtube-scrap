## 스크립트

GitHub Copilot을 사용하면 에이전트 HQ에서 원하는 에이전트를 선택하여 개발 작업을 순차적으로 실행하는 방식에서 동시에 실행하는 방식으로 전환할 수 있습니다 . GitHub의 에이전트 탭에서 모든 클라우드 에이전트 세션을 관리할 수 있습니다. 여기에서 임시 작업을 코파일럿, 클로, 바이앤트로픽, 코덱스 또는 사용자 지정 에이전트에 할당할 수 있습니다. 이 도구를 사용하면 GitHub의 중앙 집중식 위치 에서 모든 작업을 모니터링할 수도 있습니다 . 현재 대부분의 변경 요청은 이슈를 통해 접수되며, Copilot Codex나 Claude와 같은 에이전트에 이슈를 직접 할당할 수 있습니다. 기반으로 사용할 브랜치를 선택하고, 원하는 에이전트를 선택한 다음 에이전트가 나머지를 처리하도록 하십시오. 영감은 책상에서 멀리 떨어진 곳을 포함하여 어디에서든 떠오를 수 있습니다. GitHub 모바일 앱에서 에이전트를 관리하고 작업을 할당할 수도 있습니다 . 개발자들이 대부분의 시간을 IDE에서 보내는 만큼, IDE에서 제공하는 동일한 기능에 접근할 수 있을 거라고 기대하는 것은 당연합니다. VS Code에서는 IDE에서 로컬 및 클라우드 에이전트 세션을 모두 관리할 수 있습니다. 이전과 마찬가지로 사용자 지정 에이전트 또는 지정된 모델을 사용하여 Claude, Codex 또는 Copilot에 할당할 수 있습니다 . 이러한 도구를 사용하면 기존 워크플로 내에서 병렬 코딩 에이전트 세션을 할당하고 관리할 수 있습니다.
