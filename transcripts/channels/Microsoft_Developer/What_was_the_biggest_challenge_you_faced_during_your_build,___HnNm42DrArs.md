## 스크립트

We used AI and specifically GitHub Copilot along with the Azure SQL database free offer to build this dental clinic solution. On paper, I was amazed with the ease of the development process with GitHub Copilot. However, not everything went as planned. We wanted to make sure security was built into the application and that's when we found that GitHub Copilot had some challenges applying managed identities when connecting to AI models in Microsoft Foundry. With a little bit of help, I provided [music] the right documentation to the model and then it was able to iterate and correct itself and then we were able to land a secured solution. So, my learning from this is the human is still very much needed in the loop and when you put together with the power of AI, you have a truly productive experience developing these solutions.
