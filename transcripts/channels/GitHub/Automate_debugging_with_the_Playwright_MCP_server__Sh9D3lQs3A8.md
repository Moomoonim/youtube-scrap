## 스크립트

Playright MCP 서버를 사용하면 Copilot 에이전트 모드에 버그와 재현 단계를 설명하고, Copilot이 문제를 확인하고, 무엇이 잘못되었는지 발견하고, 수정 사항을 확인할 수 있습니다. 메시지가 전송된 후, Copilot은 현재 미리 보기로 제공되는 할 일 목록 MCP 서버를 사용하여 작업을 추적합니다. 서버 시작 방법에 대한 안내를 따른 다음, Playright를 사용하여 버그를 확인하는 단계를 진행할 것입니다. 현재 상황을 파악하기 위해 극작가의 페이지 호출 기능을 사용할 수 있습니다 . 그런 다음 페이지의 게시자 선택기를 사용하여 버그를 재현하려고 시도합니다. 그것은 모든 것이 보고된 대로임을 밝혀냅니다 . 필터는 아무런 기능도 하지 않습니다. 이 정보를 바탕으로 이제 애플리케이션 코드에 관심을 돌립니다 . 이 프로그램은 프런트엔드 파일, 즉 게임 목록 컴포넌트를 열고 해당 코드가 제대로 되어 있는지 확인합니다. 다음으로, Playright로 돌아가 네트워크 호출을 검사하여 호출이 올바르게 이루어지고 있는지 확인하고, 실제로 올바르게 이루어지고 있음을 확인합니다. 그러면 백엔드가 열리고 우리의 오타를 발견합니다 . 네, 바로 그 부분을 고쳐야 합니다. 해당 수정 사항을 생성하고 Playright에 반환하여 제대로 작동했는지 확인합니다 . 페이지가 새로고침될 때까지 기다린 후 선택기를 다시 시도합니다. 지금은 모든 것이 정상적으로 작동하고 있습니다. 마지막으로 할 일 목록을 업데이트하여 작업이 성공적으로 완료되었음을 표시합니다. Playright MCP 서버를 활용하면 Copilot이 웹 애플리케이션 개발을 더욱 효과적으로 지원할 수 있습니다 . 단순히 엔드투엔드 테스트를 작성하는 것뿐만 아니라, 변경 사항에 대한 실시간 검증도 수행합니다. [음악]
