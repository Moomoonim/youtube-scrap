## 스크립트

안녕하세요 여러분, 저는 엔비디아의 딥러닝 개발자 옹호자 스벤 칠튼입니다. 오늘 AWS 온에어에서는 클라우드 환경이든 온프레미스 환경이든 엔비디아의 새로운 Reva Parakeet Nim을 어떻게 활용할 수 있는지 보여드리겠습니다. 엔비디아가 최근 40개 이상의 추론 모듈(NIM)에 대한 일반 액세스를 허용했다는 사실을 알고 계실 것입니다. Nim은 AI 모델, 애플리케이션 및 서비스를 최적화된 컨테이너로 패키징하여 사용자가 클라우드, 데이터 센터 또는 워크스테이션에서 실행할 수 있도록 합니다 . 빌드 페이지에서 Nim에 대해 자세히 알아볼 수 있습니다. nvidia.com에서 Llama 370b Instruct Foundation 모델과 같은 일부 Nim 모델을 사용하면 Python Node.js 또는 curl 명령어를 사용하는 Unic 셸을 통해 OpenAI API를 이용하여 NVIDIA 서버 에서 호스팅되는 서비스와 상호 작용할 수 있습니다. OpenAI에서 호스팅되는 모델을 쿼리하는 데 익숙하다면 모델 이름과 엔드포인트를 변경하고 NVIDIA API 키를 제공하기만 하면 이러한 Nim 모델에 액세스할 수 있습니다. NVIDIA 원격 호스팅을 사용할 수 없는 경우에도 Nim 모델을 Docker 컨테이너로 다운로드하여 원하는 환경에서 호스팅할 수 있습니다. 경우에 따라 자체 호스팅 액세스를 신청해야 하지만, 대부분 비교적 빠른 시일 내에 승인될 것입니다. 이 데모에서는 NVIDIA의 Reva Parakeet Nim 모델에 초점을 맞출 것입니다. 2024년 6월 초 녹화 시점을 기준으로 Parakeet 0.6b 스트리밍 음성 인식 모델( 영어, Bert 자동 구두점 기능 포함)은 Nim 모델로 제공되는 유일한 Reva 모델입니다. 다른 ASR 모달리티, 모델 아키텍처 및 언어는 물론 음성 합성 및 기계 번역 서비스에 대해서는 계속해서 살펴보시기 바랍니다. 현재는 NGC에서 기존 Reva 리소스를 사용하고 있지만, Parakeet Nim을 AWS에서 실행할 수 있도록 해당 리소스의 Nim 버전이 곧 제공될 예정입니다. NVIDIA는 NVIDIA GPU에 최적화된 AMI를 사용하는 것을 권장합니다. AWS Marketplace에서 쉽게 찾을 수 있으며, Parakeet Nim을 자체 호스팅할 수 있는 권한을 신청하고 획득하면 해당 AMI에서 EC2 인스턴스를 시작할 수 있습니다. 권한을 획득하면 이 안내 문서 또는 이와 매우 유사한 문서에 액세스할 수 있습니다. 이제 터미널을 열고 모든 설정을 진행해 보겠습니다. 투명성을 위해 말씀드리자면, 저는 AWS EC2 인스턴스가 아닌 NVIDIA 서버에서 이 데모를 실행하고 있습니다. 이 Nim은 H100, A100 또는 L40 GPU를 필요로 합니다. 최선을 다했지만 이 비디오를 녹화할 시간 내에 적절한 GPU 유형의 EC2 인스턴스를 확보할 수 없었습니다. 하지만 Nim 설정 절차는 호스트가 클라우드에 있든 온 프레미스에 있든 동일합니다. 먼저 적절한 Docker 컨테이너를 다운로드해 보겠습니다. NVIDIA SMI를 호출하면 이 노드에 L40 GPU가 포함되어 있음을 확인할 수 있으므로 다음과 같이 설정합니다. GPU 유형을 소문자로 l40 X1로 지정합니다. 다음으로 앵무새 모델 파일을 다운로드할 디렉토리를 준비합니다. 해당 파일은 GPU 유형에 따라 달라지므로 디렉토리 이름에 GPU 유형을 포함했습니다. 그런 다음 모델 파일을 Repository 디렉토리에 다운로드합니다. Reva QuickArt 스크립트를 실행하는 것과는 중요한 차이점이 있습니다. 방금 다운로드한 모델은 이미 l40 GPU에 최적화되어 있습니다. Reva QuickArt 스크립트는 모델 의 중간 표현인 armier 파일을 다운로드한 다음 호스트 GPU에 최적화합니다. 이러한 차이점 때문에 기존 Reva 버전은 h100, a100, l40 외에도 다양한 NVIDIA GPU 유형에서 실행할 수 있습니다. 모델 파일을 다운로드한 후 음성 Nim 컨테이너를 분리 모드로 실행합니다. 다음으로 음성 Nim 컨테이너에 대해 gRPC 상태 검사를 실행합니다. 콘솔에 " 컨테이너 상태"가 표시되면 서비스가 추론 준비가 된 것입니다. 다른 메시지가 표시되면 상태 검사를 너무 일찍 종료한 것일 수 있습니다. 음성 Nim 컨테이너 빠른 시작 가이드의 마지막 단계로 컨테이너의 transcribe file 스크립트를 사용하여 녹음 파일을 텍스트로 변환합니다. 한 남성이 자연어 처리가 무엇인지 묻고 있는데, 컨테이너에도 관련 내용이 포함되어 있습니다. 참고로 이 Nim에는 오프라인 모델이 포함되어 있지 않으므로 스트리밍 모델을 사용하여 파일을 텍스트로 변환합니다. Parkeet Nim의 기능을 더 자세히 보여주기 위해 동료가 개발한 간단한 Gradio 웹 앱을 실행하고 약간 수정했습니다. 이 앱을 통해 사용자는 지정된 Reva 서버(이 경우 제가 Parkeet Nim을 실행 중인 노드)에서 ASR 모델을 사용하여 자신의 음성을 텍스트로 변환할 수 있습니다. 제 목소리로 어떻게 작동하는지 살펴보겠습니다. 저는 Amazon의 AWS 온에어 이벤트에서 Nvidia Reva Parkeet Nim의 기능을 시연하고 있습니다. 구두점은 좀 더 개선할 필요가 있지만, 전반적으로 텍스트 변환은 상당히 훌륭하다고 생각합니다. 이 비디오에서는 Nvidia의 최신 음성 인식 모델 중 하나가 포함된 Nvidia Reva Parkeet Nim을 설정하고 실행했습니다. 이를 사용하여 간단한 웹 앱에서 실시간 음성을 텍스트로 변환했습니다. 현재 Nim의 Reva 음성 AI 모델, 서비스 및 언어 지원은 제한적이지만, 향후 지원이 확대되어 결국 기존 Nim에서 제공하는 수준과 같아질 것입니다. Reva가 NGC 체크 빌드에 있습니다. nvidia.com에서 정기적으로 업데이트를 확인하세요.
