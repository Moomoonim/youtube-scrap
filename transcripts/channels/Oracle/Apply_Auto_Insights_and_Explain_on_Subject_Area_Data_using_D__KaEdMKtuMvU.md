## 스크립트

이 튜토리얼에서는 Oracle Fusion Data Intelligence에서 주제 영역 데이터를 기반으로 생성된 데이터 세트를 분석하기 위해 Auto Insights 및 Explain 기능을 사용하는 방법을 알아봅니다 . 주제 영역은 수많은 항목을 포함할 수 있으며 , 분석을 어디서부터 시작해야 할지 항상 명확하지는 않습니다. Auto Insights와 Explain 기능을 활용하면 시각화 자료를 생성하고 검토할 수 있어 시간을 절약하고 분석 속도를 높일 수 있습니다. 이 시나리오에서 저는 Auto Insights와 Explain 기능을 사용하여 재무제표의 GL 대차대조표 영역을 분석하고 싶지만, 이러한 기능은 데이터 세트에서만 작동합니다. 그래서 데이터 흐름을 사용하여 하위 집합을 데이터 세트로 추출하고 거기서 분석하겠습니다. 홈페이지에서 시작해서 만들기를 선택한 다음 데이터 흐름을 선택하겠습니다. 다음으로, 재무제표(GL) 대차대조표 주제 영역에서 가져온 원본 데이터를 추가하겠습니다. 이 데이터 흐름이 생성할 데이터 세트에서 원하는 열을 선택하겠습니다. 계속 진행하려면 최소 하나의 열을 선택해야 합니다. 그럼 시간을 확장해서 회계연도, 회계 분기, 회계기간을 선택하겠습니다. 다음으로, 몇 가지 원장 속성을 추가하겠습니다. 원장 세트 이름, 원장 이름 및 잔액 조정 세그먼트 이름입니다. 이제 현금, 매입채무, 매출채권, 총자산, 총부채 등 분석하고 싶은 몇 가지 지표를 추가하겠습니다. 그다음, '선택 항목 추가'를 선택하여 이 열들을 데이터 흐름에 추가하겠습니다. ' 단계 추가'를 선택한 다음 '데이터 저장'을 선택 하고 출력 데이터 세트 이름을 'GL 재무상태표 데이터 세트'로 지정하겠습니다. 데이터 저장 단계에서는 열 설정을 검토하겠습니다. 예를 들어, 회계연도는 시간 레이블이므로 속성으로 처리하도록 설정하겠습니다. ' 저장'을 선택 하고 데이터 흐름 이름을 '재무제표 데이터 흐름'으로 지정하겠습니다. 이제 데이터 흐름을 실행하여 데이터 세트를 생성하겠습니다. 작업이 진행되는 동안 작업 상태를 확인하여 데이터 세트를 사용할 준비가 되었는지 알 수 있도록 하겠습니다. 홈페이지로 돌아가서 탐색기를 선택한 다음 데이터를 선택하겠습니다. 데이터 흐름 탭에서 데이터 흐름 실행이 완료된 것을 확인할 수 있습니다. 작업이 완료되면 데이터 저장 단계를 사용했으므로 새로운 데이터 세트가 표시될 것으로 예상합니다 . 데이터 섹션으로 이동하여 GL 대차대조표 데이터 세트가 사용 가능한지 확인하겠습니다. 다음으로, 이 데이터 세트를 사용하여 통합 문서를 만들겠습니다 . 그다음에는 자동 분석 패널을 열겠습니다. 이 데이터 세트에 대해 인사이트 기능이 아직 활성화되지 않았다는 알림이 표시됩니다. 그럼 데이터 세트를 마우스 오른쪽 버튼으로 클릭하고 ' 검사'를 선택하겠습니다. 그다음, 인사이트 사용을 선택하고 저장한 후 닫겠습니다. 인사이트 기능을 활성화하면 백그라운드에서 추천 시각화 자료가 생성되기 시작합니다 . 데이터 세트에 따라 몇 분 정도 소요될 수 있습니다. 그러한 인사이트가 생성되는 동안, 저는 ' explain on ledger name' 명령어를 사용하여 데이터 세트에서 어떤 패턴이 두드러지는지 파악할 것입니다. 장부 이름을 마우스 오른쪽 버튼으로 클릭하고 설명을 선택하겠습니다. Explain은 해당 원장 열에 대한 기본 사실, 주요 동인, 세그먼트 및 이상 현상에 대한 분석을 제공합니다 . 해당 열에 대한 기본 정보는 유용하므로 캔버스에 추가하겠습니다. 이제 자동차 관련 인사이트를 사용할 수 있게 되었으니, 제안된 시각화 자료들을 검토해 보겠습니다. 옵션을 비교하고 설명을 읽기 쉽도록 패널을 확장하겠습니다. 매출채권 기준 상위 10개 원장 이름 시각화 자료에 제가 필요한 정보가 있으니 캔버스에 추가하겠습니다 . 시각화 기능은 다른 시각화 기능과 마찬가지로 작동하며, 필요에 따라 나중에 사용자 지정할 수 있습니다. 데이터 분석을 계속하고 싶지만, 이번에는 전체 주제 영역을 대상으로 하고 싶습니다 . 열 이름과 데이터 유형이 일치하므로 데이터 세트를 마우스 오른쪽 버튼으로 클릭하고 '데이터 세트 바꾸기'를 선택하여 원래 주제 영역 데이터 세트로 바꾸겠습니다. 시각화에 사용된 측정값이 올바르게 매핑되는지 확인하겠습니다. 스키마가 일치하기 때문에 기존 시각화는 계속 작동합니다. 이제 해당 분야 전체 데이터를 기반으로 작동합니다 . 필드가 일치하지 않으면 다시 매핑하거나 시각화를 다시 만들어야 합니다 . 데이터 흐름을 사용하여 주제 영역 데이터를 데이터 세트로 변환했으므로 이제 자동 인사이트 및 설명 기능을 사용하여 분석 시작점을 신속하게 생성한 다음, 더 자세한 정보가 필요할 때 전체 주제 영역으로 다시 전환하여 탐색을 계속할 수 있습니다. 아래 링크에서 이 시리즈의 다른 비디오와 Oracle Fusion Data Intelligence 사용에 대한 추가 자료를 찾아보세요.
