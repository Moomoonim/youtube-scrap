## 스크립트

[음악] Azure 마이그레이션 시리즈의 또 다른 비디오에 오신 것을 환영합니다 . 이번 에피소드에서는 Azure 마이그레이션 웨이브 계획 기능을 사용하여 대규모 인프라를 Azure로 마이그레이션하기 위한 정밀한 계획을 수립하는 방법을 다룹니다. 이전 영상들을 보셨다면 , 일반적인 이민 과정이 결정, 계획, 실행의 단계로 나뉜다는 것을 이미 알고 계실 겁니다 . Azure로 마이그레이션하기로 결정했다면 Azure 마이그레이션 평가를 사용하여 애플리케이션 에 적합한 대상 Azure 서비스를 확인할 수 있습니다 . 또한 애플리케이션 마이그레이션을 언제 어떻게 수행할지에 대한 계획도 세워야 합니다 . 바로 이 부분에서 Azure 마이그레이션 웨이브 계획이 중요해집니다 . Azure Migrate의 웨이브 계획 기능을 사용하면 대규모 마이그레이션을 웨이브라고 하는 배치 단위로 계획할 수 있으므로 빠른 성과를 파악하고, 종속성 위험을 관리하고, 마이그레이션 불확실성을 줄일 수 있습니다. 웨이브 플래닝은 서버, 데이터베이스, 웹 앱을 포함한 전체 인벤토리를 애플리케이션 중심적인 접근 방식으로 Azure 마이그레이션 프로젝트에서 계획할 수 있도록 지원합니다. 웨이브 계획을 수립하기 전에 Azure 마이그레이션 프로젝트를 생성했는지 확인하십시오. 현재 작업량을 확인하세요. 종속성 분석을 사용하여 비즈니스 부서용 애플리케이션을 만들고 종속적인 워크로드를 그룹화하세요 . 워크로드를 쉽게 식별하고 범위를 지정할 수 있도록 적절한 태그를 지정하십시오. 마이그레이션 전략 및 Azure 대상을 파악하기 위한 평가를 수행합니다. 이제 데모를 통해 마이그레이션 웨이브를 생성하는 방법을 살펴보겠습니다. 마이그레이션 웨이브를 생성하려면 마이그레이션 프로젝트 개요의 웨이브 계획 타일에서 웨이브 생성 버튼을 클릭해야 합니다 . 생성 흐름 중에 평가를 활용하면 웨이브 의 대상 및 도구에 대한 Azure 권장 사항을 사용할 수 있으므로 더 빠르게 계획을 수립할 수 있습니다. 이번 업데이트에 추가될 신청서를 검토하고 수정할 수 있습니다. 이번이 첫 번째 마이그레이션 단계이므로 위험을 최소화하기 위해 복잡성이 낮은 애플리케이션부터 마이그레이션하는 것이 좋습니다. 구성 요소를 검토한 후 파동을 생성합니다. 이와 유사하게, 마이그레이션 스테이징 계획을 정의하는 여러 웨이브를 생성 하고 웨이브 계획 페이지에서 확인할 수 있습니다. 파동이 생성되면 다음 단계는 파동을 어떻게 이동시킬지에 대한 계획을 세우는 것입니다. 물결 모양 아이콘을 클릭하면 마이그레이션을 준비하는 데 필요한 모든 단계를 확인할 수 있습니다 . 평가에서 수집된 Azure의 권장 사항을 기반으로 기본값으로 설정된 Azure 대상 및 도구를 검토하고 업데이트할 수 있습니다. 이번 마이그레이션 단계에서는 데이터베이스 마이그레이션 서비스를 이용하여 MySQL 데이터베이스를 Azure Database for MySQL로 마이그레이션하는 것을 목표로 합니다 . 그리고 Tomcat 서버는 서버 마이그레이션을 사용하여 Azure VM에서 호스팅됩니다. 선택한 도구에 따라 온프레미스에서 Azure 대상으로 워크로드를 마이그레이션하는 데 필요한 작업도 검토할 수 있습니다. 웨이브 플래닝은 Azure Migrate에서 지원하는 모든 워크로드 및 대상에 대한 계획 작업을 지원합니다 . Azure 마이그레이션 웨이브 계획은 목표와 도구를 기반으로 사전 작업도 권장합니다. 또한 웨이브 실행의 시작일과 목표일을 추적할 수 있습니다 . 사전 요구 사항 및 구성이 완료되면 계획이 완료되고 마이그레이션을 시작할 준비가 된 것입니다. 이 비디오에서는 태그, 중요도, 복잡성, 워크로드 속성 등의 정보를 사용하여 워크로드와 애플리케이션을 그룹화함으로써 Azure 마이그레이션 웨이브 계획을 활용하여 웨이브를 생성하는 방법을 배웠습니다. Azure 마이그레이션 권장 사항을 통해 미리 채워진 일정, 필수 조건 및 마이그레이션 작업을 식별하여 자세한 실행 계획을 수립하는 방법을 살펴보았습니다 . 다음 단계로, 계획된 날짜에 마이그레이션 단계를 실행하고 Azure Migrate를 사용하여 전체 마이그레이션 과정을 중앙에서 추적할 수 있습니다. 즐거운 이주 되세요. [음악]
