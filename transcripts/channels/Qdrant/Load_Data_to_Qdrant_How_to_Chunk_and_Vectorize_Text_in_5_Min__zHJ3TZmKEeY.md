## 스크립트

Quadrant를 벡터 데이터베이스로 사용하는 것을 좋아 하지만 모든 문서와 비정형 데이터를 최적화된 벡터 인덱스로 더 쉽게 변환할 수 있는 방법을 찾고 있다면, 오늘 소개해 드릴 완벽한 도구가 있습니다. 바로 Vectorize입니다. 시작하려면 클러스터와 Quadrant가 필요하며, 플랫폼으로 이동해야 합니다. Vectorize doio에 접속하여 Vectorize 계정을 생성하면 다음과 같은 대시보드가 ​​나타납니다. 시작하려면 여기에서 ' 새 파이프라인'을 클릭하세요. Amazon S3, Dropbox, Google Drive와 같은 플랫폼에 문서가 있는 경우 해당 커넥터 중 하나를 사용할 수 있습니다. 웹 페이지를 스크래핑하려면 WebCrawler를 사용할 수도 있습니다. 하지만 오늘 제가 보여드릴 것은 파일 업로드 커넥터입니다. 이 커넥터를 사용하면 문서를 Quadrant에 가장 간단하게 가져올 수 있습니다. 먼저 새 파일 업로드 커넥터를 생성하고 TV 쇼 '프렌즈'의 대본 모음을 사용하겠습니다. 이 대본들은 ' 프렌즈' 첫 번째 에피소드의 대본 24개입니다. 이 파일들을 여기에 드래그하여 업로드하면 됩니다. 이제 업로드가 완료되었으니 저장할 수 있습니다. 다음으로 추출기를 구성해야 합니다. 추출기에는 세 가지 옵션이 있습니다. Vectorize는 빠른 추출기를 제공하는데, 이는 텍스트 위주의 간단한 PDF나 Word 문서에 적합합니다. Vectorize Iris는 더 복잡한 작업을 수행합니다. 표, 그래프, 텍스트 및 기타 복잡한 레이아웃을 포함하는 복잡한 문서에서 데이터를 추출해야 하는 경우 훨씬 더 나은 결과를 얻을 수 있습니다. Mixed는 두 가지 장점을 모두 제공합니다. 빠르고 저렴한 추출기를 먼저 사용하고, 더 나은 처리가 필요한 경우, 해당 추출기로 문서를 처리할 수 없으면 Iris로 업그레이드합니다. 저는 일반 텍스트 문서에는 Fast를 사용하겠습니다. 청크 크기와 청크 오버랩을 포함한 청크 전략을 설정할 수 있습니다. 다음으로 임베더를 구성해야 합니다. 임 베더는 OpenAI 또는 VoyageAI와 같은 AI 플랫폼을 사용합니다. AWS 또는 Google을 사용하는 경우 Bedrock 및 Vertex도 지원합니다. OpenAI에서 API 키를 가져와 이름을 지정하고 새 커넥터를 생성하기만 하면 됩니다. 저는 이미 설정해 두었으므로 여기에서 선택하겠습니다. 마찬가지로 Vector 데이터베이스에서도 연결하면 됩니다. 쿼드런트 클러스터에 연결하려면 쿼드런트에서 새 커넥터를 선택하고 클러스터로 이동한 다음 이 텍스트 상자에서 클러스터 호스트 엔드포인트를 찾습니다. API 키를 생성하려면 여기에서 ' 생성'을 클릭하여 새 API 키를 만들 수 있습니다. API 키를 생성했으면 커넥터에 입력합니다. 그러면 다음과 같은 화면이 나타납니다. 파이프라인이 쿼드런트에 완전히 연결된 것을 확인할 수 있습니다. 이 파이프라인에 'friend scripts'라는 이름을 지정하겠습니다. 간단히 보여드리기 위해 위쪽 다른 탭에서 쿼드런트 UI를 열어 놓았습니다. 아직 쿼드런트에 아무것도 생성하지 않았기 때문에 컬렉션이 없습니다. 이제 벡터라이즈에서 파이프라인을 생성 하고 이 friend scripts를 모두 인덱스로 변환해 보겠습니다. 배포 프로세스가 시작됩니다. 파이프라인이 완전히 배포되고 백 필링이 시작되는 데 몇 초밖에 걸리지 않습니다. 이제 파이프 라인이 파일 업로드 커넥터에 있던 도크를 검색하기 시작하는 것을 볼 수 있습니다. 도크를 검색하면 다음과 같은 작업이 진행됩니다. 텍스트 추출, 청크 분할, 벡터 생성, 그리고 쿼드런트에 데이터를 채우는 과정을 시작합니다. 보시다시피 현재 24개의 문서가 있습니다. 앞서 언급했듯이 프렌즈 시즌 1에는 24개의 에피소드가 있었고, 이 모든 문서를 처리하여 벡터를 생성하고 쿼드런트에 저장했습니다. 이제 쿼드런트 UI로 돌아가면 컬렉션이 생성된 것을 확인할 수 있습니다. 여기에서 벡터 인덱스가 채워진 것을 확인할 수 있습니다. 이제 벡터화를 좀 더 자세히 살펴보려면 개요 탭에서 Rag Sandbox라는 옵션을 사용할 수 있습니다. Rag Sandbox는 LLM이 다양한 질문에 어떻게 응답하는지, 쿼드런트 검색 인덱스에서 가져온 컨텍스트를 어떻게 사용하는지 정확하게 확인할 수 있는 엔드 투 엔드 테스트 도구입니다. 예를 들어 프렌즈에 대한 질문을 해보겠습니다. 로스와 모니카의 관계는 무엇인가요? 이 질문은 쿼드런트에 쿼리를 보내고, 해당 질문에 대한 컨텍스트를 가져옵니다. 저는 LLM을 사용하고 있습니다. 33억 7천만 개의 인덱스가 Grock에서 실행되어 프롬프트를 전달합니다. 가장 먼저 Quadrant에서 반환된 결과를 정확하게 확인할 수 있습니다. 좋은 점은 코사인 유사도 외에도 관련성 점수를 얻을 수 있다는 것입니다. 또한 쿼리 재작성도 자동으로 처리해 줍니다. 다른 질문을 했을 때 어떤 소스에서 결과가 반환되었는지도 확인할 수 있습니다. 따라서 코드를 연결하기 전에 인덱스가 원하는 대로 작동하는지 테스트하기에 좋은 방법입니다. 이 기능에 만족하고 애플리케이션에 통합할 준비가 되면 파이프라인 보기로 돌아가 연결 탭에서 검색 엔드포인트에 액세스할 수 있습니다. 이 검색 엔드포인트는 선택 사항이며, 물론 Quadrant에 직접 쿼리할 수도 있습니다. 이 기능을 사용하면 쿼리 재작성과 함께 순위 재조정이 자동으로 수행됩니다. 또한 입력을 벡터화하여 애플리케이션을 간소화하고 전반적인 정확도를 높여 더 빠르게 앱을 구축할 수 있습니다. 이제 모든 준비가 완료되었습니다. 사분면 내에 완전히 채워진 인덱스가 있으며, 직접 사용해 보시려면 플랫폼으로 이동하세요. .io에서 계정을 만들면 몇 분 만에 Rag 파이프라인을 실행할 수 있습니다. 자, 여러분, 다음 시간에 또 뵙겠습니다. 시청해 주셔서 감사합니다. 안녕히 계세요.
