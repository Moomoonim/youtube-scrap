## 스크립트

Chat RTX는 별도의 코드 작성 없이 로컬 컴퓨터에서 LLM(Late Log Me)을 쉽게 실행할 수 있도록 해주는 유용한 도구입니다. Chat RTX는 입력된 텍스트 문서를 스캔하여 그 내용을 바탕으로 답변을 생성합니다. 이는 RAG(Retrieval Augmented Generation) 기술을 활용하여 이루어지며, 선택한 텍스트 문서의 정보는 사용자의 쿼리를 기반으로 검색되어 LLM 응답의 컨텍스트로 사용됩니다. 이 튜토리얼에서는 다음 단계를 안내합니다. Chat RTX 다운로드, 설치 및 실행, 그리고 관련 컨텍스트가 있는 경우와 없는 경우의 LLM 응답 시연. 파일을 다운로드하려면 브라우저를 통해 NVIDIA Chat RTX 다운로드 페이지로 이동하여 " 지금 다운로드" 버튼을 클릭하세요. 최적화 팁: 파일 용량이 크므로 다운로드 관리자를 사용하여 다운로드 속도를 높이는 것이 좋습니다. 다운로드 URL을 다운로드 관리자에 입력하기만 하면 됩니다. 다운로드가 완료되면 zip 폴더의 압축을 풀고 설치 실행 파일을 두 번 클릭한 후 화면의 지시에 따라 설치를 완료하세요. 이제 도구를 실행할 차례입니다. 도구를 찾아 클릭하세요. 잠시 후 도구의 그래픽 사용자 인터페이스가 나타납니다. 브라우저가 자동으로 열리지 않으면 URL을 복사하여 브라우저 주소창에 붙여넣으세요. 이제 모든 준비가 완료되었습니다. 준비됐습니다. 이제 시연으로 넘어가겠습니다. Rag를 시연하기 위해 AI가 생성한 짧은 스릴러 소설을 문서로 선택했습니다. 이 소설에는 화가 올리버 테이트와 형사 마크 레이놀즈가 등장합니다. 소설은 아래 비디오 설명에서 찾을 수 있습니다. 데이터 세트 창에서 빈 디렉토리를 선택합니다. 즉, LLM이 스캔할 파일이 없으므로 참조할 텍스트도 없습니다. 그런 다음 "올리버는 누구인가요?"라고 물으면 LLM은 정중하게 모른다고 답합니다. 이제 소설이 담긴 텍스트 파일이 있는 폴더로 이동합니다. 이 폴더에는 원하는 만큼 텍스트 파일을 넣을 수 있습니다. 파일 처리가 완료되면 도구가 질문에 답할 준비가 됩니다. " 올리버 테이트는 누구인가요?"라고 다시 물으면 소설을 기반으로 한 유익한 답변이 나옵니다.
