## 스크립트

rmip Explorer에 오신 것을 환영합니다. IP Explorer는 다양한 ARM IP 제품을 비교하고, 시스템 시뮬레이션에서 벤치마크 코드를 실행하고, ARM 기반 아키텍처 설계의 첫 단계를 수행할 수 있는 웹 기반 환경입니다 . IP Explorer로 이동하세요. arm.com에 로그인하면 먼저 컨셉 생성, 다양한 ARM IP 탐색, 클라우드에서 시뮬레이션된 프로세서에서 코드 실행 등의 옵션이 표시됩니다. 먼저 사용 가능한 다양한 ARM 프로세서를 살펴보겠습니다. 프로세서 검색창에 모든 프로세서 목록이 표시됩니다. 다양한 필터를 사용하여 원하는 프로세서 유형을 좁힐 수 있습니다. Cortex M 프로파일만 표시해 보겠습니다. 여러 프로세서의 기능을 표 형식으로 비교할 수 있습니다. 관심 있는 프로세서를 선택하고 비교를 클릭하면 다양한 데이터 포인트의 비교표가 표시됩니다. 프로세서 목록으로 돌아가서 하나를 선택하여 자세히 살펴보고 대화 상자 에 표시된 대로 다양한 옵션을 구성할 수 있습니다. 여기에서 구성에 따라 IP 없이 RTL을 렌더링할 수도 있습니다. 마찬가지로 관련 섹션 에서 다른 유형의 RIP, 상호 연결 시스템 IP 및 전체 ARM 서브시스템을 탐색할 수 있습니다. ARM IP Explorer가 차세대 ARM 기반 설계를 정의하는 데 유용하고 매력적인 도구가 되기를 바랍니다.
