## 스크립트

이 비디오에서는 NVCF 웹사이트에 접속하여 Maya에서 MicroS 서비스를 사용할 수 있도록 API 키를 발급받는 방법을 보여드리겠습니다. 따라서 올바른 웹사이트에 연결하려면 빌드 페이지로 이동하시면 됩니다. nvidia.com에 접속하면 이 웹사이트로 이동합니다. 여기에는 몇 개의 탭이 있습니다. 원한다면 오디오 투 페이스를 체험해 볼 수 있고, 몇 가지 오디오 파일을 선택하여 재생할 수도 있습니다. 하지만 이 튜토리얼의 목표는 여기서 재생하는 것이 아니라 Maya에서 재생하는 것입니다. 따라서 Maya에서 재생하려면 API 설정으로 이동해야 합니다. 여기에는 필요한 정보가 많이 있습니다. 일부 정보는 이미 Maya에 설정되어 있지만, 필요할 경우 가져올 수 있도록 다시 한번 알려드립니다. 클라이언트에 연결할 때는 이 사이트, 즉 JPC nvcf nvidia.com 포트 443에 연결할 것입니다. Maya에서는 앞에 https가 붙은 이 주소를 사용합니다. 그리고 두 개의 함수 ID와 여러 숫자가 있는데, 이 숫자들은 중요하므로 복사해서 잘 보관해 두세요. 마크 모델은 함수 ID 이고, 클라 모델을 사용하려면 여기에 있는 함수 ID를 사용하면 됩니다. 이 ID 들을 잘 보관해 두면 필요할 때 다시 확인할 수 있습니다. 여기서 중요한 것은 API를 사용해 보려면 API 키를 받아야 한다는 것입니다. API 키를 클릭하면 메뉴가 나타나는데, 회사 이메일로 로그인하면 5,000 크레딧을, 개인 이메일로 로그인하면 1,000 크레딧을 받는다는 안내가 나옵니다. 즉, 회사 이메일로 로그인하면 마이크로서비스를 5,000번 무료로 호출할 수 있고, 개인 이메일로 로그인하면 1,000번 무료로 호출할 수 있다는 뜻입니다. 만약 이 서비스를 실제 운영 환경에서 사용하려면, 추가 크레딧 구매 등 관련 계약을 체결해야 할 수도 있습니다. 하지만 체험판으로는 이 정도 크레딧이 제공됩니다. 저 창을 띄우면 API 키를 생성하라는 메시지가 나타납니다. ' 키 생성'을 클릭하면 여기에 키가 표시됩니다. 만약 아직 API 키가 생성되지 않았다면 이 부분은 비어 있을 겁니다. 하지만 이 키를 복사할 수 있습니다. 아주 중요한 것은 키를 복사해서 안전한 곳에 보관하는 것입니다. 복사한 API 키는 나중에 필요할 때 언제든 사용할 수 있도록 비밀 장소에 보관해 두세요. D2F 서비스든 다른 마이크로서비스든, NVIDIA에서 제공하는 다른 서비스를 사용해 보고 싶을 때 유용하게 쓸 수 있습니다. 이제 창을 닫고 API 키를 안전한 곳에 저장했습니다. 이제 제 계정으로 돌아가서 API 키를 사용할 수 있습니다. 보시다시피 달러 기호와 변수 이름이 표시되는데, 이게 기본값입니다. 이 부분은 나중에 자세히 살펴보겠습니다. 지금은 그냥... 음, API 키를 붙여넣겠습니다. 제 비밀 저장소에서 복사해서 여기에 붙여넣을게요. 이제 API 키가 준비됐으니 마이크로서비스를 테스트해보고 제대로 작동하는지 확인해 볼 준비가 거의 다 됐습니다. 하지만 지금 이 장면에는 오디오가 없어서 오디오를 추가해야 합니다. 오디오 메뉴로 가서 오디오를 가져오면 됩니다. 이건 샘플 장면에서 다운로드한 오디오 파일인데, 이걸 가져와서 여기에 붙여넣겠습니다. 전체 사운드를 표시할 공간이 충분한지 확인해야겠네요. 대략 이 정도면 50 정도 될 것 같습니다. 153이 되겠네요. 여기가 타임라인이고, 이게 제가 사용할 오디오 파일입니다. 애니메이션 플레이어에서 보시면 오디오 파일이 기본적으로 설정되어 있지 않으니 오디오 파일을 제공해야 합니다. 이제 Maya에 가져왔으니 클릭할 수 있고, 이제 요청 시 활성화되는 오디오 파일이 되었습니다. 이제 준비됐습니다. 물론 애니메이션을 요청하는 것은 서버 가용성과 인터넷 연결 상태에 따라 달라집니다. 웹에 접속하여 애니메이션을 요청하면 애니메이션이 다운로드됩니다. 따라서 몇 초 정도 걸릴 수 있고, 서버가 너무 바쁠 때도 있으니 애니메이션을 받을 때까지 충분히 기다려 주시기 바랍니다. 제 경우에는 애니메이션 요청 후 몇 초가 걸렸고, 이제 애니메이션이 준비되었으니 Tenure에서 재생할 수 있습니다. Tenure에서는 더 많은 레저 활동을 즐길 수 있지만, 그녀의 출판물은 제대로 작동하지 않습니다. 이제 제 API 키가 작동하고 마이크로서비스에 연결되었으며, 재생을 시작하고 자동에서 얼굴까지 다양한 결과를 얻을 준비가 되었습니다. 다음 비디오에서는 이러한 모든 설정을 살펴보고 다양한 감정을 표현하는 방법, 립싱크 개선 방법 등을 알아보겠습니다. 이것이 다음 비디오의 주제입니다. 이 비디오를 마치기 전에, 제가 보여드리고 싶은 것은 API 키를 환경 변수로 설정하는 방법입니다. 이렇게 하면 매번 API 키를 입력할 필요가 없습니다. 자, 다시 돌아가서 이 부분을 지우고 달러 기호($)를 넣겠습니다. 방금 여기에 붙여넣었으니 다시 입력하겠습니다. nvcf apore aior key 이제 Windows 설정에서 환경 변수를 찾아야 합니다. 계정의 환경 변수를 편집하고 새 API 변수를 만듭니다. 이름은 달러 기호($)를 제외하고 기존 변수와 동일하게 지정합니다. 여기에 API 키 값을 붙여넣고 공백을 넣은 다음 확인을 클릭합니다. 준비가 되면 확인을 클릭하고 로그아웃 후 다시 로그인해야 환경 변수가 적용됩니다. 이렇게 하면 마이크로서비스를 사용할 수 있습니다. 제 경우에는 환경 변수가 이미 설정되어 있었습니다. 이대로 두고 API 키를 변경한다고 가정해 보겠습니다. 애니메이션을 최대한 활용하고 감정의 강도를 과장하기 위해 다른 애니메이션을 요청하겠습니다. 그러면 좀 더 멋진 애니메이션이 나올 거예요. 요트 타기를 위한 여가 시간은 더 많아졌지만, 그녀의 출판물은 별로 좋지 않네요. 이게 API 키를 얻어서 제대로 작동하는지 확인하는 워크플로입니다. 다음 영상에서는 이러한 모든 설정과 마이크로서비스 에서 애니메이션을 요청할 때 애니메이션을 조정하는 방법을 살펴보겠습니다.
