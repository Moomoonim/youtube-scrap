## 스크립트

안녕하세요, Repet의 Matt입니다. 오늘은 Claude Sonet 3.5 모델 버전 2에 포함된 Anthropic의 새로운 컴퓨터 사용 기능을 시작하는 방법을 보여드리겠습니다. 이름이 좀 길긴 하지만, 컴퓨터 사용은 Claude가 여러분의 컴퓨터를 제어할 수 있도록 해주는 Anthropic의 새로운 기능입니다. 일반적으로 컴퓨터를 제어하는 ​​도구를 설정하는 것은 어렵지 않습니다. API 작동 방식을 이해하거나 시작하는 데 관심이 있다면, 모든 설정을 거치는 것이 부담스러울 수 있습니다. 하지만 Repet을 사용하면 아주 빠르게 시작할 수 있습니다. 필요한 것은 Anthropic API 키뿐입니다. 30초 안에 설정하는 방법을 보여드리겠습니다. 바로 시작해 보겠습니다. 이것은 컴퓨터 사용 템플릿입니다. 설명란에 링크를 걸어두겠습니다. ' 템플릿 사용'을 클릭하겠습니다. 원하는 이름으로 지정할 수 있습니다. 제 개인 계정에 있는지 확인하겠습니다. 그리고 ' 템플릿 사용'을 클릭할게요. 그러면 이 전체 환경이 복제됩니다. 모든 구성, 종속성, 컴퓨터 사용에 필요한 모든 것이 여기에 준비되어 있습니다. 오른쪽 하단에 비밀 키를 관리할 수 있는 팝업 창이 나타나는데, Anthropic API 키 비밀 키가 있지만 값이 없다는 메시지가 표시됩니다. ' 비밀 키 추가'를 클릭하고 '실행'을 클릭하면 됩니다. 환경이 미리 구성되어 있고 모든 설정이 완료되었기 때문에 복제본을 ' 포크'하면 전체 환경이 복제됩니다. 여기 데모 페이지가 있는데, 개발 URL을 클릭하면 해당 페이지로 이동하여 전체 화면으로 표시됩니다. 이제 컴퓨터에 원하는 명령을 내릴 수 있습니다. 예를 들어, ' 샌프란시스코에서 도쿄까지 가는 항공편을 찾아줘'라고 말할 수 있습니다. 오늘 아침은 좀 힘들었지만, 다들 아시잖아요. 여기서부터 Replic 내부에 존재하는 Firefox 인스턴스를 실행합니다. 따라서 여기에 보이는 모든 것은 Replic 내부에서 실행되고 있습니다. 방금 복제한 이 환경에는 자체적인 Firefox 환경이 있습니다. 보시다시피, 컴퓨터 사용이 Firefox를 열고 google.com/flights로 이동하여 샌프란시스코에서 도쿄로 가는 항공편을 검색하기 시작합니다. 이렇게 모든 것이 미리 구성된 컴퓨터 사용 환경을 만들었습니다. 원한다면 이 환경에 들어가서 파일을 살펴보면서 어떤 일이 일어나고 있는지, Anthropic 팀이 무엇을 만들었는지, 컴퓨터 사용 기능이 어떻게 작동하는지 이해할 수 있습니다. 그리고 자신 만의 애플리케이션을 만들거나 멋진 것을 만들거나 컴퓨터 사용을 가지고 놀 수도 있습니다. 시작할 수 있는 재미있는 애플리케이션이 많이 있습니다. 다시 한번 말씀드리지만, 저는 Replic 개발자 관계 담당자 Matt입니다. 지금까지 30초 만에 컴퓨터 사용을 시작하는 방법을 알아보았습니다. 다음 시간에 뵙겠습니다. 평화!
