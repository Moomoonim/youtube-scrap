## 스크립트

샌드박싱을 사용하면 Copilot을 로컬 환경이나 클라우드 환경에서 격리된 상태로 실행할 수 있습니다 . 로컬 샌드박스를 생성하려면 Copilot을 시작하고 샌드박스 활성화를 사용합니다. 일단 시작하면 평소처럼 코딩하고 , 코드 업데이트 요청을 보내고 , Copilot에게 테스트 실행을 지시하면 모든 작업이 격리되고 통제된 환경에서 진행됩니다. 또한 샌드박스를 로컬에서 구성할 수 있습니다. 이를 통해 MCP 및 LSP 서버, 키체인, 로컬 파일 시스템에 대한 접근 권한과 로컬 네트워크 또는 인터넷에 대한 접근 권한을 설정할 수 있습니다. 또한 `\n` 명령어를 사용하여 샌드박스 기능을 비활성화할 수도 있으므로 필요에 따라 샌드박스 기능을 켜고 끌 수 있습니다. 클라우드 샌드박스를 사용하려면 클라우드 인수를 사용하여 Copilot을 실행합니다. 이렇게 하면 내 세션이 실행될 원격 클라우드 인스턴스가 생성됩니다 . 이전과 마찬가지로, Copilot에 여러 가지 요청을 할 수 있습니다. 예를 들어, 제가 만들고 있는 웹사이트에 적합한 인증 제공업체를 제안하고 구현해 달라고 요청할 수 있습니다. 이전과 마찬가지로 Copilot은 요청을 이행하여 라이브러리를 설치하고 테스트를 실행합니다. 클라우드 기반이기 때문에 원격 액세스가 자동으로 활성화되어 GitHub에 접속할 수 있는 곳이라면 어디에서든 중단했던 작업을 이어서 할 수 있습니다. 샌드박스(로컬 또는 클라우드)를 사용하면 안전하게 실험하고 개발할 수 있습니다.
