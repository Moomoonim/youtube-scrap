## 스크립트

안녕하세요 여러분, 1분 Gradio에 오신 것을 환영합니다! Gradio의 개념이나 기능을 1분 안에 설명해 드리는 코너인데요, 오늘은 동적 렌더링에 대해 이야기해 보겠습니다. 동적 렌더링이란 무엇일까요? 일반적으로 Gradio 애플리케이션에서 컴포넌트를 정의하면 해당 컴포넌트들이 렌더링되고 레이아웃은 고정됩니다. 즉, Gradio 애플리케이션을 사용하는 모든 사용자에게 동일한 레이아웃이 표시됩니다. 하지만 때로는 사용자가 특정 옵션을 선택했거나 앱과 상호 작용한 방식에 따라 레이아웃을 변경하고 싶을 때가 있습니다. 예를 들어, 사용자가 YouTube URL을 선택하면 텍스트 상자를 표시하고, 오디오 또는 비디오 입력을 선택하면 오디오 입력란을 표시하고 싶습니다. 이를 위해 Gradio의 컴포넌트를 활용할 수 있습니다. 렌더링 데코레이터는 입력값을 매개변수로 받습니다. 이것이 소스(Source)입니다. 이 값을 변경하면 다른 것을 렌더링하고 싶다면, 함수를 정의하면 됩니다. 함수 이름은 무엇이든 될 수 있지만, 여기서는 ' Sources'라고 하겠습니다. 함수 안에서는 IF 문이나 for 루프를 사용하여 입력값에 따라 컴포넌트를 렌더링합니다. 예를 들어, ' Sources'가 오디오이면 오디오 컴포넌트를, 비디오이면 비디오 컴포넌트를 렌더링하는 식입니다. 보시다시피, 이제 ' 오디오'를 선택하면 오디오 컴포넌트가 렌더링되고, '비디오'를 선택하면 비디오가 표시됩니다. YouTube URL을 선택하면 플레이스 홀더가 있는 텍스트 상자가 표시됩니다. 이것이 코드의 전부입니다. 이 데코레이터를 사용하여 이벤트 리스너를 추가하거나 다른 작업을 수행할 수도 있습니다. 사용자가 이전에 수행한 작업에 따라 Gro 애플리케이션의 레이아웃이나 이벤트 리스너를 변경하고 싶을 때 매우 유용합니다. 시청해 주셔서 감사합니다.
