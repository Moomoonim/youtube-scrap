## 스크립트

당신은 세상을 움직이는 코드를 빠르게 배포하고 있지만, 공격자들도 마찬가지로 빠르게 움직입니다. 또한 보안 문제를 수동으로 식별하는 것은 시간이 많이 걸리고 오류 발생 가능성이 높습니다. GitHub 코드 보안 기능을 사용하면 작업 속도를 저하시키지 않고 취약점을 찾아 수정할 수 있습니다 . 이 과정은 CodeQL을 이용한 보안 검사로 시작되며 , CodeQL은 코드베이스 전체의 보안 위험을 식별합니다. 취약점이 발견되면 Copilot Autofix는 문제를 설명하고 풀 리퀘스트에 바로 수정 방법을 제안합니다. 보안 캠페인을 통해 보안 팀은 대규모 보안 부채를 관리하고, 개발자가 기존 취약점을 해결하도록 우선순위를 설정하고 일정을 관리할 수 있습니다 . 이 모든 과정에서 종속성 검토는 오픈 소스 패키지의 위험 요소를 자동으로 스캔하여 취약점 및 라이선스 문제가 코드베이스에 유입되는 것을 방지합니다. GitHub 코드 보안을 사용하면 개발자 중심의 위험 보호 기능을 워크플로 전반에 걸쳐 제공받을 수 있으므로 안심하고 배포할 수 있습니다.
