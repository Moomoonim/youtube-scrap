## 스크립트

MSE는 세계 최대의 컨테이너 해운 회사입니다. [음악] 우리가 매일 해결하는 이러한 모든 물류 문제를 해결하려면 기술 패턴에 의존해야 합니다. 바로 이러한 이유로 저희는 오랜 기간 동안 마이크로소프트와 협력해 왔습니다. SQL Server에서는 성능, 가용성 및 보안이 가장 중요합니다. 기존 ETL 프로세스로는 6시간마다 데이터를 받았습니다. [음악] 패브릭용 SQL 서버의 미러링 덕분에 실시간으로 데이터를 분석 솔루션에 가져올 수 있게 되었는데, 이는 우리에게 매우 중요한 요소입니다. 거의 실시간으로 더 빠르고 스마트한 의사 결정을 내릴 수 있기 때문입니다 . 변경 이벤트 스트리밍은 푸시 데이터 모델을 실시간으로 구현할 수 있는 가능성을 제공합니다. SQL Server 2025 개발자가 데이터베이스 내에서 JSON을 사용할 수 있게 된다면 특히 BI 사업 부문에 있어 엄청난 발전이 될 것입니다. 그렇게 하면 개발 최적화를 달성할 수 있을 것입니다. 이제 AI와 [음악] 벡터 검색, 임베딩 덕분에 데이터베이스 엔진의 검색 기능이 엄청나게 향상될 것입니다. SQL Server는 우리 시스템을 구동하는 데 핵심적인 역할을 합니다 . 그것이 없었다면 우리는 오늘날의 위치에 있지 못했을 것입니다.
