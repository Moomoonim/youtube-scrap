## 스크립트

Nvidia biion Nemo는 통합 UI와 독립형 API를 제공하여 사용자 지정 워크플로 및 신약 개발 파이프라인을 신속하게 구축하는 데 사용할 수 있는 모델 및 도구에 원활하게 액세스할 수 있도록 합니다. 이 비디오에서는 Nvidia biion Nemo GitHub 예제에서 제공하는 가상 약물 스크리닝 워크플로를 살펴보겠습니다. 시작하기 위해 GitHub 저장소를 복제하고 포함된 실행 스크립트를 사용하여 예제 노트북이 포함된 컨테이너를 준비했습니다. 컨테이너를 실행한 후 웹 브라우저에서 예제 노트북에 액세스할 수 있습니다. 가상 스크리닝 워크플로는 단백질 구조 예측, 소분자 생성 및 분자 도킹을 위해 biion Nemo 모델을 사용하여 소분자 리간드와 단백질 표적의 결합 친화도를 예측합니다. 먼저 bioo 서비스 구성 셀에서 NGC API 키를 사용하여 API 액세스를 구성 하고 몇 가지 종속성을 설치합니다. 그런 다음 서비스를 쿼리하여 사용 가능한 NGC 모델을 확인할 수 있습니다. 이를 위해 먼저 Bemo 클라이언트를 가져온 다음 NGC 자격 증명을 사용하여 Python 클라이언트 API를 인스턴스화합니다. 사용 가능한 모델을 찾는 것은 클라이언트 API에서 모델 목록 함수를 호출하는 것만큼 간단합니다. 서비스 액세스가 확인되면 단백질 서열을 조회하는 것으로 시작합니다. 디하이드로폴레이트 환원효소(DHFR)는 신약 개발에서 흔히 사용되는 결합 표적입니다. 먼저 OpenFold를 사용하여 아미노산 서열을 기반으로 3D 단백질 구조를 예측합니다. 다음 단계는 도킹 특성을 테스트할 표적 분자(Li)와 표적 분자 세트를 생성하는 것입니다. 이를 위해 알려진 DHFR 저해제 데이터베이스를 시드(seed)로 사용하여 MoFlow의 심층 그래프 생성 모델을 통해 유사한 특성을 가진 새로운 분자를 생성합니다. 이제 OpenFold에서 얻은 DHFR 단백질 구조와 MoFlow에서 생성한 표적 저해제 세트를 활용하여 Diff-DoC 도킹 모델을 통해 다양한 포즈에 대한 결합 친화도를 테스트할 수 있습니다. 이 예시에서는 각 Li와 분자에 대해 20개의 포즈를 생성하고, 도킹 포즈를 시각화한 후 포즈 신뢰도를 통해 결과의 품질을 평가합니다. 이 예시 워크플로는 BiMo를 사용한 신약 개발 프로세스의 시작점을 제공합니다. 이 워크플로의 단계는 더 넓은 검색 공간으로 쉽게 확장하거나, 신뢰도가 높은 결과를 반복적으로 활용하여 추가적인 표적 분자를 생성함으로써 더욱 정교하게 다듬을 수 있습니다. BiMo는 간단한 API 호출을 통해 이러한 모델에 접근할 수 있도록 지원하므로, 이러한 스크리닝 워크플로를 새로운 사용 사례에 빠르고 쉽게 적용할 수 있습니다.
