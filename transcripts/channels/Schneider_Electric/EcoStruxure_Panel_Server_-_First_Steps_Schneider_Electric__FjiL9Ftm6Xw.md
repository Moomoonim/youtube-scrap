## 스크립트

네트워크에서 클릭하여 사용 가능한 장치를 검색하세요 . 패널 서버가 자동으로 검색되지 않으면 추가 조치가 필요합니다. 이 영상 후반부에서 더 자세한 설명을 드리겠습니다. 탐색기에 패널 서버가 나타나면 더블클릭하여 웹 서버를 엽니다. 그러면 웹 브라우저는 해당 장치의 기본 IP 주소에 접속하여 웹 페이지로 이동합니다. IP 주소를 수동으로 얻는 방법. 기기가 자동으로 감지되지 않으면 IP 주소를 수동으로 입력하여 웹 페이지에 접속할 수 있습니다. 이 프레임에는 기본 IP 주소가 표시됩니다. IP 주소를 완성하려면 시리얼 번호의 마지막 두 자리를 16진수에서 10진수로 변환해야 합니다. 예를 들어, 시리얼 번호의 마지막 두 자리가 17과 10이라면 , 16진수로 나타내면 각각 23과 16이 됩니다 . 웹 브라우저에 접속하면 개인정보 보호 오류 메시지가 나타납니다. '고급'을 클릭한 다음 '진행'을 클릭하세요. 이제 비밀번호를 설정할 시간입니다. 비밀번호 설정에 필요한 사항들을 꼼꼼히 확인하시고, 준비가 되면 '새 비밀번호 설정'을 클릭하세요. 이제 웹페이지에 접속해 보겠습니다. 사용자는 보안 관리자이고 비밀번호는 방금 전에 설정되었습니다. 이제 패널 서버가 시운전 단계에 들어갈 준비가 되었습니다.
