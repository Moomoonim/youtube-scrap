## 스크립트

오늘 저희는 Cerebrris의 빠른 추론 기능과 Docker Compose를 결합하여 격리된 AI 개발 환경을 제공하는 멀티 에이전트 시스템인 DevDuck을 소개하게 되어 매우 기쁩니다. Docker는 격리되고 재현 가능한 환경을 생성함으로써 개발자가 애플리케이션을 구축하고 배포하는 방식을 혁신했습니다 . Devduct는 Docker의 안전성과 세계에서 가장 빠른 AI 추론 기능을 결합하여 한 단계 더 나아갑니다. Debbduck은 안전하고 재현 가능한 컨테이너를 생성하여 초당 2,500개 이상의 토큰으로 코드를 생성하고 실행할 수 있도록 합니다. DevDuck은 복잡한 로컬 환경 대신 모든 것을 깔끔하고 격리된 상태로 유지합니다. 오늘은 DevDuck을 사용하여 놀랍도록 빠르고 안전한 AI 코딩 환경을 구축하는 방법을 살펴보겠습니다 . 이 단계별 가이드에서는 여러분의 컴퓨터에 DevDuck을 설정하는 방법을 안내해 드리겠습니다. 시작하려면 Docker가 설치되어 있어야 하고 무료 Cerebrus API 키가 필요합니다. cloud.us.ai로 가서 가입할게요. 그런 다음 대시보드에서 API 키를 가져오세요 . 다음으로, 다음 명령어를 실행하여 저장소를 복제하십시오 . 이제 마지막 파일에 Cerebras API 키를 추가하세요. 이를 통해 DevDuck은 가장 빠른 추론 모델에 연결됩니다 . 이제부터 마법 같은 순간이 시작됩니다. DevDuck을 빌드하고 시작하세요. 일단 실행이 완료되면 DevDuck에게 샌드박스 초기화를 요청하기만 하면 몇 초 만에 격리된 컨테이너가 자동으로 생성되는 것을 볼 수 있습니다 . 그게 다입니다. 이제 여러분은 빠르고 안전하며, 개발 과정을 완벽하게 투명하게 파악하면서 AI 개발을 경험할 준비가 되었습니다 . 다음 코딩 프로젝트에 DevDuck을 사용해 보세요. 초고속 컨테이너에서 어떤 멋진 결과물을 만들어낼지 기대하겠습니다.
