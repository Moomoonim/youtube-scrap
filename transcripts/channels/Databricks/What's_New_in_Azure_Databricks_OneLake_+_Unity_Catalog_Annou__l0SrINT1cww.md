## 스크립트

스콧, 데이터 분석과 관련하여 Azure 데이터 브릭에 새로 추가된 기능 과 주요 소식에 대해 간략하게 설명해 주 시겠어요? 음, 제 생각에 이번 주 두 회사 간의 가장 큰 소식은 아마도 마이크로소프트의 원레이크(One Lake) 솔루션과 데이터 빅스의 유니티 카탈로그(Unity Catalog) 솔루션 간의 통합일 것입니다. 앞서 말씀드렸듯이 데이터를 복사할 필요 없이 원활하게 통합할 수 있는 기능입니다. 응. 아시다시피, 이는 조직이 보유한 데이터를 활용할 수 있도록 해줍니다. 아시다시피, 복사할 때마다 복사 과정에 약간의 지연이 발생하잖아요. 음, 복사하는 데 추가 비용이 들어요. 그리고 결국, 모든 기존 기록 시스템과 다양한 분석 시스템의 데이터를 호숫가 별장에 완벽하게 통합할 수 있다면, 그 데이터를 활용하여 더 빠르고 저렴하며 효율적으로 더 큰 가치를 얻을 수 있을 것입니다. 그래서 이번 발표는 원 레이크(One Lake)와 유니티 카탈로그(Unity Catalog) 전반에 걸친 통합이라는 측면에서 우리에게 매우 중요한 소식입니다. 그리고 그렇게 하면 전체 데이터 구성 요소와 마이크로소프트 생태계를 하나의 통합된 관리 환경에서 활용할 수 있게 됩니다.
