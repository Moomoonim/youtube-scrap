## 스크립트

그렇다면 MCP란 무엇일까요? 많은 분들이 이미 알고 계신다고 말씀하셨지만, 간단히 설명드리자면 MCP는 AI가 외부 세계와 상호작용하는 방식입니다. 그리고 그것은 주로 두 가지를 의미합니다. 첫째, 모델이 학습하지 않은 컨텍스트 정보까지 가져올 수 있다는 점입니다. 그러니까, 이 정보는 모델의 학습 종료일 이후에 공개된 정보일 수도 있고 , 아니면 비공개 정보였을 수도 있습니다. 만약 여러분이 공개 웹 에서 접근할 수 없는 내부 정보를 가지고 있고, LLM이 그 정보에 대해 교육을 받았다면 어떨까요? 둘째로, 이는 외부 세계와 상호 작용하여 부작용을 일으키는 방식입니다. 따라서 로컬 파일 시스템이나 GitHub 저장소 또는 Figma 디자인에 파일 시스템이나 파일을 생성할 수 있습니다. MCP는 생후 약 11개월이 되었으니 아직 1년도 안 됐어요. 음, 앤트로픽은 작년 11월에 그것을 만들었습니다. 그리고 저는 그것이 기술적 혁신이라기보다는 사회적 혁신에 더 가깝다고 말하고 싶습니다. 왜냐하면 기존에 함수 호출 API가 존재했지만, 그다지 주목받지 못했기 때문입니다 . 그래서 Anthropic은 해당 API를 중심으로 표준을 만들고, 최초의 GitHub MCP 서버를 포함하여 30개의 고품질 참조 서버를 통해 커뮤니티를 육성했습니다 . 이것은 저희 MCP 서버의 모습입니다. 그래서 우리에게는 여러 가지 도구가 있습니다. 앞서 말씀드렸듯이, Anthropic이 최초의 서버를 만들었고 , 그들은 그것이 초기 MCP 서버 세트 중에서 가장 인기 있는 서버라고 말했습니다 . 그래서 저희는 그들과 협력하여 MCP 서버의 소유권을 확보했고, 원래 타입스크립트로 작성되어 있던 것을 Go 언어로 다시 작성하게 되었습니다. 그래서 저희는 그걸 출시했고, 꽤 인기가 있었어요. 그럼 이 프로젝트가 어떤 역할을 하는지, 그리고 지역 사회와 어떻게 소통했는지에 대해 이야기해 보겠습니다. 저희가 출시했던 주에, 실제로 GitHub 전체에서 가장 인기 있는 오픈 소스 프로젝트였습니다. 그래서 GitHub 플랫폼을 에이전트로 활용하려는 잠재적인 수요가 있다는 것을 알게 되어 매우 흥미로웠습니다.
