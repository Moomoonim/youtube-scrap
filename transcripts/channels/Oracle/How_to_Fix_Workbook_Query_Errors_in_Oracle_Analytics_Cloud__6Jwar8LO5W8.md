Oracle Analytics Cloud에서 다른 사용자가 데이터 세트와 같은 관련 항목에 액세스하지 못할 수 있다는 경고 메시지가 표시됩니다. 접근할 수 없는 자산을 확인하려면 여기를 클릭하여 목록을 확인하세요. 이 경우 공급업체 지리 정보 데이터는 비공개 폴더 에 저장되어 있으므로 자동으로 공유할 수 없습니다 . 확인하겠습니다 . 내 폴더에 저장된 자산은 기본적으로 비공개이므로, 이동하거나 공유하지 않는 한 다른 사용자는 접근할 수 없습니다 . 동료들이 접근할 수 있도록 기본 데이터 세트를 제 폴더에서 공유 폴더로 옮기겠습니다. 카탈로그에서 데이터 세트 작업 메뉴를 선택한 다음, 공유 폴더로 이동하여 데이터 세트를 배치합니다 . 데이터 세트는 통합 문서와 같은 폴더에 있을 필요는 없으며, 통합 문서 사용자가 접근 권한을 가진 위치에만 있으면 됩니다. 이제 소비자 계정으로 로그인해서 통합 문서를 열겠습니다. 저는 통합 문서와 데이터 세트 모두에 접근 권한이 있으므로 시각화가 성공적으로 로드됩니다. 데이터 세트를 공유 위치로 옮겼으므로 이제 사용자들이 오류 없이 통합 문서에 액세스하고 데이터를 성공적으로 조회할 수 있는지 확인할 수 있습니다. 이 시리즈의 다른 동영상과 Oracle Analytics Cloud 사용에 대한 추가 자료를 보려면 아래 링크를 이용하세요.
