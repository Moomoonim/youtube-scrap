## 스크립트

[음악] GitHub CLI에서 GitHub Agentic Workflows 확장 프로그램을 설치하세요. 저장소로 이동하여 Agentics 컬렉션에서 첫 번째 Agentic 워크플로인 일일 저장소 상태, [음악]을 추가하세요 . 워크플로를 실행할 에이전트로 GitHub Copilot, Claude 또는 Codex 중에서 선택할 수 있습니다. GitHub Copilot을 선택하고 개인 액세스 토큰을 추가해 보겠습니다. 우리는 이 워크플로우 [음악]를 수락하고 병합한 다음 실행하도록 합니다. 병합된 풀 리퀘스트를 살펴보겠습니다. 여기서는 컴파일된 GitHub Actions 워크플로와 소스 마크다운 파일을 볼 수 있습니다. 이 파일에는 트리거, 읽기 전용 권한, 도구 및 쓰기 시 안전한 출력에 대한 기본 설정이 포함되어 있습니다. 또한 자연어로 작성된 작업 설명이 포함된 마크다운 파일도 있습니다. 이 경우, 보고서와 관련된 새 이슈를 생성하는 작업 설명입니다 . '작업' 탭으로 이동하면 워크플로가 현재 실행 중임을 확인할 수 있습니다. 모든 절차가 완료될 때까지 기다리겠습니다. 엄청난. 생성된 문제 보고서를 살펴보겠습니다. 우리는 일일 저장소 상태 워크플로에서 생성된 보기 좋은 상태 보고서를 볼 수 있습니다 .
