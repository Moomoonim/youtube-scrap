## 스크립트

안녕하세요 여러분, 반갑습니다. 이 비디오에서는 Azure Migrate를 사용하여 PostgreSQL 서버 배포를 Azure로 마이그레이션하는 계획을 세우는 방법을 살펴보겠습니다. Azure Migrate를 사용하면 PostgreSQL 인스턴스를 검색하고 평가하여 Azure Database for PostgreSQL 및 Azure VM으로 마이그레이션할 수 있습니다. 특히 새로운 Azure PostgreSQL 평가 기능을 통해 PostgreSQL 워크로드의 마이그레이션 및 현대화를 지원하는 측면에서 이야기하고 있습니다 . 권장 대상 Azure 서비스로의 마이그레이션 준비 상태 및 장애 요인, 적정 규모의 편향, 그리고 권장 사항의 근거를 이해할 수 있습니다. Azure에서 PostgreSQL 서버 배포를 실행하는 데 드는 비용 추정치와 권장 접근 방식을 사용하여 마이그레이션하기 위해 수행해야 하는 단계인 마이그레이션 지침도 확인할 수 있습니다 . PostgreSQL Server 배포를 Azure로 마이그레이션하기 전에, PostgreSQL Server를 성공적으로 검색하는 데 필요한 모든 전제 조건을 충족하고 검색 관련 문제를 해결해야 합니다. 필수 조건에 대한 자세한 내용은 aka.ms/asurigrate/postgressql discovery를 참조하세요. 검색이 성공적으로 완료되면 데이터베이스 블레이드로 이동하여 PostgreSQL 평가를 시작할 수 있습니다. 평가할 PostgreSQL 인스턴스를 선택 하고 '평가 생성'을 클릭하면 됩니다. 평가를 생성하는 동안 마이그레이션 대상 지역, 소스 워크로드의 기본 환경 유형(개발, 테스트 또는 프로덕션)과 같은 Azure 대상 속성을 지정하여 적절한 가격 책정 및 편차를 적용할 수 있습니다. 종량제, 1년 또는 3년 예약 인스턴스, Azure 절약 플랜과 같은 통화 절약 옵션 및 평가 기준이 있습니다. Azure 하이브리드 혜택을 이용하여 Azure VM으로 마이그레이션할 때 자체 Windows 서버 또는 선택한 Linux 서버 라이선스를 Azure로 가져올지 여부를 ' 기본값 편집'을 클릭하여 지정할 수도 있습니다. 대상 서비스 계층을 지정하여 활용할 Azure PostgreSQL 제품을 지정할 수도 있고, 기본값을 그대로 두어 Azure Migrate가 최적의 솔루션을 결정하도록 할 수도 있습니다. 모든 세부 정보를 지정한 후 '검토 및 평가 생성'을 클릭할 수 있습니다 . 모든 것이 괜찮아 보이면 ' 만들기'를 클릭하세요. 평가 결과는 몇 분 안에 검토 가능합니다 . 보시다시피 저희는 13개의 서버와 17개의 인스턴스를 평가했습니다. 또한, 저희가 제공하는 여러 서비스들이 지원이 종료되었거나 종료가 임박했음을 확인할 수 있습니다. 또한, 저희의 발견 성공률은 100%입니다. Azure에서 PostgreSQL 서버 인스턴스 및 데이터베이스에 대한 다양한 마이그레이션 방식의 준비 상태와 해당 워크로드를 실행하는 데 필요한 예상 비용을 확인할 수 있습니다 . Azure Database for Postgress SQL과 같이 Azure의 각 Postgress SQL 배포 대상에 맞춘 보고서를 자세히 살펴보거나 요약 된 권장 보고서를 참조할 수 있습니다. 권장 보고서는 선택한 마이그레이션 기본 설정에 따라 PostgreSQL 서버 배포를 Azure로 마이그레이션하는 가장 효율적인 방법을 제시합니다. Azure Migrate는 마이그레이션 준비 상태와 예상 비용을 모두 고려하여 완전히 검색되지 않은 PostgreSQL 배포를 포함하여 모든 PostgreSQL 배포가 마이그레이션 과정에서 누락되지 않도록 합니다. 이 경우, 현대화를 위한 의도에 따라 13개의 PostgreSQL 서버 인스턴스를 재플랫폼화 하고 그중 2개를 재호스팅하는 것이 권장됩니다. 더 자세히 살펴보면, 권장되는 서비스는 PostgreSQL Flexible Server용 Azure 데이터베이스이며, 해당 서비스는 Azure VM임을 알 수 있습니다. 이제 Airsic Backend 5432에 대한 평가 세부 정보를 살펴보겠습니다. Airsic Backend는 PostgreSQL 인스턴스이며, 제가 현대화하려는 앱의 데이터 계층을 나타냅니다 . Azure Database for PostgreSQL로 마이그레이션할 준비가 완료되었으며, 앞서 언급한 현대화 목표를 고려할 때 권장 대상은 Azure Database for PostgreSQL임을 알 수 있습니다 . 권장 구성에는 범용 V4 시리즈 8V 코어, 컴퓨팅 성능 기준으로 32GB 메모리 , 그리고 237달러 상당의 128GB 프리미엄 SSD 스토리지가 포함됩니다. 또한 할당된 코어, CPU 사용률, 메모리 사용량 등과 같은 집계된 성능 통계를 더 자세히 볼 수 있습니다. 준비 상태 탭에서는 Azure의 모든 PostgreSQL 대상에 대한 준비 상태를 파악할 수 있습니다. PostgreSQL용 Azure 데이터베이스로의 현대화와 관련된 문제점을 이해하려면 몇 가지 문제를 해결해야 한다는 것을 알 수 있습니다 . 이 경우, 데이터베이스 준비 상태 평가를 위해 필요한 권한만 부여하면 됩니다. 목표 추천 탭에서는 이상적인 목표가 어떻게 결정되었는지 설명합니다 . 이 경우 PostgreSQL 서버는 Azure Database for PostgreSQL을 사용할 준비가 되어 있었습니다. 또한, Azure Database for PostgreSQL에서 이 인스턴스를 실행하는 비용이 두 가지 방식 중 가장 저렴할 것으로 예상됩니다. 이 작업에 권장되는 도구는 PostgreSQL용 Azure 데이터베이스 마이그레이션 서비스임을 알 수 있습니다. Azure Migrates의 권장 사항 덕분에 PostgreSQL 배포를 정확하게 검색하는 데 필요한 자격 증명이나 권한이 없었더라도 모든 PostgreSQL 배포를 누락 없이 마이그레이션할 수 있었습니다. 이제 각 목표에 대한 방향성 보고서를 살펴보겠습니다. 특히 실행 및 유지 관리에 비용 효율성이 높은 통과 목표에 대한 보고서를 중점적으로 살펴보겠습니다. Azure Database for PostgreSQL 전용 준비 상태 보고서를 살펴보면 17개 인스턴스 중 13개 인스턴스가 Azure Database for PostgreSQL로 마이그레이션할 준비가 되었거나 마이그레이션 조건을 충족하는 상태임을 확인할 수 있습니다. MySQL Linux 앱 5 5432의 Azure 데이터베이스(Postgress SQL용)에서 시스템 리소스 메트릭을 확인할 수 있는 권한이 부족하여 상태가 '알 수 없음'으로 표시된 것을 확인할 수 있습니다. 이 인스턴스를 PostgreSQL용 Azure 데이터베이스로 마이그레이션하는 데 관심이 있다면 채택할 수 있는 해결 방법이 있음을 알 수 있습니다. Azure Migrate는 Azure VM에서 실행되는 PostgreSQL 서버에 대한 전용 평가 보고서를 제공하며, 이는 최소한의 노력으로 기존 시스템을 Azure VM으로 마이그레이션하는 리프트 앤 시프트 또는 복제 기반 접근 방식을 목표로 합니다. Azure VM의 PostgreSQL용 Azure 데이터베이스 또는 PostgreSQL 서버로 마이그레이션할 때 컴퓨팅 및 스토리지 비용 분포를 검토할 수 있습니다. 언제든지 설정으로 이동하여 예약 용량, 마이그레이션 전략, Azure 하이브리드 이점 등의 선택 사항을 변경하여 평가를 사용자 지정하고 비용 변화를 확인한 후 최적의 조합을 선택할 수 있습니다. 또한, 평가 보고서를 내보내어 공유하거나 오프라인에서 활용할 수 있습니다 . 이 데모에서는 Azure Migrate에서 제공하는 모든 기능을 활용하여 대규모 PostgreSQL 서버 인스턴스 및 데이터베이스를 검색하고 평가하는 방법을 설명합니다. Azure Migrate를 사용하여 데이터 마이그레이션 우선순위를 쉽게 정할 수 있도록 Azure PostgreSQL 평가 생성 및 다양한 옵션, Azure PostgreSQL 배포 대상 및 적정 규모 편향 권장 사항과 관련 근거, 마이그레이션 지침 및 비용 세부 정보를 포함했습니다. 시작하실 때 이 화면에 있는 Azure Migrate 설명서와 같은 자료를 활용하시면 됩니다. 탐색 및 평가가 완료 되고 신뢰도가 높은 마이그레이션 계획을 수립한 후에는 Azure Database for PostgreSQL 마이그레이션 서비스를 활용하여 PostgreSQL 인스턴스를 Azure Database for PostgreSQL로 마이그레이션하거나 Azure Migrates 서버 마이그레이션 기능을 사용하여 서버를 Azure 가상 머신으로 리프트 앤 시프트할 수 있습니다 . 실제 마이그레이션을 진행하기 전에 프로덕션 워크로드에 영향을 주지 않고 테스트 마이그레이션을 수행할 수도 있습니다 . 이 영상을 시청해 주셔서 감사합니다 .
