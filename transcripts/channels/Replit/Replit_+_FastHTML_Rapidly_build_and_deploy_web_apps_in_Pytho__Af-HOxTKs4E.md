## 스크립트

안녕하세요, 저는 Repet에서 개발 관계 업무를 담당하는 Matt입니다. 혹시 프런트엔드 애플리케이션을 만들어 보신 적 있으신가요? 특히 파이썬을 사용해서 만들어 보신 적이 있다면, DevX 환경이 그다지 좋지 않았거나 개발 자체가 어려웠던 경험이 있으실 겁니다. 오늘 저는 Fast HDML이라는 프레임워크를 소개하려고 합니다. Fast HDML을 사용하면 HDMX, CSS, HTML을 활용하여 파이썬 프런트엔드 애플리케이션을 매우 빠르게 개발할 수 있습니다. 다른 프레임워크와는 달리 Fast HDML은 완벽하게 커스터마이징이 가능합니다. 저는 Fast HDML을 사용하여 개인 블로그의 방명록을 만들고 배포했는데, 깔끔한 CSS UI와 반응형 데스크톱 및 모바일 인터페이스를 구현했습니다. 가장 좋은 점은 프레임워크를 이해하고 나면 단 몇 시간 만에 개발할 수 있다는 것입니다. Fast HDML은 파이썬 클래스를 사용하여 HTML 컴포넌트를 정의합니다. 여러분이 익숙한 다른 프런트엔드 프레임워크와 매우 유사한 인터페이스를 가지고 있으며, 제 앱의 코드는 V나 XJS에서 볼 수 있는 코드와 거의 비슷합니다. 다만 파이썬 구문을 사용한다는 점이 다르죠. Fast API 파이썬 프레임워크에 익숙하시다면, Fast HDML도 매우 유사하다는 것을 아실 수 있을 겁니다. 저는 Fast HDML을 사용하여 제 블록의 방명록을 만들었고, 데이터는 키-값 데이터베이스에 기록됩니다. Replic을 사용하면 세션과 사용자 간에 데이터가 유지됩니다. 홈페이지를 구축하는 메인 라우트 와 다른 사용자가 정보를 제출할 때 데이터를 제출하거나 가져오는 라우트가 있습니다. 코드는 설명란에 있으니, 포크해서 Replic에서 사용해 보세요. Replic에서 템플릿을 포크하는 것은 클릭 한 번이면 되고, 실행 버튼을 클릭하면 브라우저에서 바로 실행됩니다. 이 코드는 다른 환경에서도 호환되지만, Replic에서 실행하지 않는 경우 repc 키-값 데이터베이스를 교체해야 합니다. 가장 좋은 점은 몇 번의 클릭만으로 배포하고 Replic 배포를 통해 사용자 지정 URL을 제공하여 사용자가 제 블로그를 다시 방문할 수 있도록 했다는 것입니다. 저는 Replic 개발팀의 Matt입니다. 지금까지 빠른 HTML에 대한 소개와 제 개인 방명록을 보여드렸습니다. 다음에 또 뵙겠습니다. 평화!
