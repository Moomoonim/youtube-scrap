## 스크립트

NVIDIA 엔지니어의 100%가 코드 생성에 AI를 사용합니다 . 같은 수의 엔지니어가 이전 보다 세 배나 많은 코드를 체크인합니다 . 이 정도 규모에서는 사람 검토자 만으로는 코드 품질을 높게 유지하는 것이 불가능합니다 . Code Rabbit의 리뷰 담당자는 볼륨이 커짐에 따라 음악에 대한 자세한 피드백을 제공합니다 . 이 에이전트는 최첨단 기능을 위해 Claude 및 GPT와 같은 [음악] 프론티어 모델을 사용하는 모델 시스템 과 가장 빠른 응답 시간을 위해 독점 데이터로 맞춤화된 개방형의 효율적인 NVIDIA NeMo Triton 모델을 사용하는 시스템입니다 . Code Rabbit은 NVIDIA의 코드, 기술 자료 , 추적 도구, 문서 등을 활용하여 변경 사항을 완벽하게 파악합니다. NeMo Triton은 방대한 컨텍스트 길이와 추론 기능을 활용하여 반복적으로 컨텍스트를 요약하고, 통찰력을 추출하고, [음악] 문제를 표시하고 [음악] 해결책을 제안하는 최첨단 모델을 위한 컨텍스트를 패키징합니다. 엔지니어들이 반복적으로 작업을 진행함에 따라, 코드가 병합될 때까지 이 과정이 계속됩니다. 이제 코드에 대한 피드백을 받는 데 며칠이 아닌 몇 분밖에 걸리지 않습니다.
