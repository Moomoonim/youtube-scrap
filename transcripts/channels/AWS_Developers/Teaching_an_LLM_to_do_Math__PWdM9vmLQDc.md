## 스크립트

단 몇 줄 의 코드로 AI에게 수학을 가르칠 수 있다고 하면 믿으시겠어요? 저는 AWS의 수석 개발자 옹호자 Jenna Pon입니다. 오늘은 Amazon Bedrock을 사용하여 대규모 언어 모델이 수학 계산을 수행하도록 하는 방법을 보여드리겠습니다. 대규모 언어 모델은 여러 면에서 뛰어나지만, 정밀한 계산에는 어려움을 겪고 최신 정보를 제공하지 못합니다. 바로 이 부분에서 도구 사용이 중요해집니다. 날씨 API, 주식 데이터에서 실시간 데이터를 가져오거나 Amazon Bedrock의 Converse API를 사용하여 복잡한 수학 계산까지 수행할 수 있다고 상상해 보세요. 필요에 따라 AI가 사용할 특정 도구 또는 함수를 정의할 수 있습니다. 이를 통해 AI 와 사용자 지정 함수 또는 도구 간의 원활한 상호 작용이 가능해지고, 양쪽의 장점을 결합할 수 있습니다. 간단한 예로 숫자의 코사인 값을 계산하는 방법을 살펴보겠습니다. 먼저 Amazon Bedrock Converse API를 사용하여 Python 스크립트에서 코사인 도구를 정의합니다. Amazon Bedrock Converse API를 사용하여 도구 사양 형식을 정의한 다음, 도구 목록에 있는 대화를 도구 구성으로 Cloud 모델에 전달합니다. 여기서 시스템 프롬프트도 사용하고 있다는 점에 주목하세요. 모델은 도구를 사용하여 수학 연산만 수행하도록 설계되었으며, 응답을 처리하는 동안 모델이 도구를 요청하는지 확인합니다. 도구가 존재하면 스크립트는 파이썬의 수학 라이브러리를 사용하여 코사인 값을 계산하고, 그 결과를 도구 결과로 모델에 전달합니다. 이는 원래 대화의 일부로 전달되며, 이를 통해 모델의 자연어 이해 능력을 활용하면서 정확한 수학 계산을 보장할 수 있습니다. 마치 인공지능(G)이 모델에게 언제 어떻게 사용해야 하는지 정확히 아는 첨단 계산기를 제공하는 것과 같습니다. 하지만 만약 문제가 발생한다면 어떻게 될까요? 예를 들어 코사인 함수를 사용할 수 없게 되었다고 가정해 보겠습니다. 코사인 함수를 주석 처리하여 오류를 시뮬레이션하고, 오류 상태를 추가하여 이 오류를 모델에 보고할 수 있도록 합니다. 도구 결과에 오류 상태를 전송함으로써 모델은 작업 실패를 알게 되고, 한계를 설명하고 다른 작업을 지원하도록 제안하는 등 상황을 적절하게 처리합니다. 이 경우 근사값을 제공하고 , 이는 단지 근사값일 뿐이라는 점을 알려줍니다. 이러한 오류 처리는 인공 지능이 예상치 못한 상황에 적응할 수 있는 견고한 시스템을 구축하는 데 도움이 됩니다. 사용자에게 의미 있는 답변을 제공하는 것은 단순히 수학 문제를 푸는 것이 아니라, 신뢰할 수 있고 유연한 AI 비서를 만들고 맞춤 설정하는 것입니다. AI가 수학 문제를 풀고, 최신 주가를 확인하고, 현재 날씨를 파악할 수 있도록 학습시키는 것도 중요합니다. 아래 설명란에 있는 GitHub 저장소의 블로그 게시물을 참고하여 Amazon Bedrock 도구를 통해 AI를 맞춤 설정하는 방법을 알아보세요. 더 많은 영상을 보고 싶으시다면 AWS Developers YouTube 채널을 구독하고, 이 영상에 좋아요를 누르거나 Amazon Bedrock 도구를 어떻게 활용하고 있는지 댓글로 남겨주세요.
