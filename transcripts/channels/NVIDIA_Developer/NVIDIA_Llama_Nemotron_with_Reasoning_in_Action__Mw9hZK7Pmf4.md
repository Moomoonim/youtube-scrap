## 스크립트

In this short demonstration, we'll be looking&nbsp; at how Llama 3.3 Nemotron Super 49B can be an&nbsp;&nbsp; effect of reasoning on and off model that you can&nbsp; use in your agentic workflows. You'll notice in&nbsp;&nbsp; the top left corner on this question about pizza&nbsp; toppings that we've enabled reasoning. This is&nbsp;&nbsp; done just through the system prompt, so there's&nbsp; no additional scaffolding required. You just set&nbsp;&nbsp; the system prompt to allow detailed thinking.&nbsp; You'll notice that because that's been set, we&nbsp;&nbsp; work through this example in a classic reasoning&nbsp; model fashion. There are a lot of intermediate&nbsp;&nbsp; thought tokens followed by the final response.&nbsp; However, with the same model, with a slightly&nbsp;&nbsp; modified system prompt, we can actually see&nbsp; reasoning off behavior, which is going to give us&nbsp;&nbsp; direct responses to questions, allowing us to save&nbsp; compute when we don't need to do that reasoning as&nbsp;&nbsp; well. This model is incredible at instruction&nbsp; following as well as tool calling, allowing it&nbsp;&nbsp; to really slot into that agentic workflow with one&nbsp; single model that can fit on a single data center&nbsp;&nbsp; GPU. You can learn more at build.nvidia.com,&nbsp; where the model card will explore all the details.
