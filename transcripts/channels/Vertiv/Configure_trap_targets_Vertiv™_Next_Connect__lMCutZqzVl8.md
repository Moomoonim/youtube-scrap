## 스크립트

Welcome to this how to video on setting the Vertive Next Connect agent as an SNMP trap target. In this tutorial, we'll show you how to configure Vertive Libert intellis cards so the local agent can receive SNMP trap notifications. Let's start. To configure SNMP trap targets for an Intellislot device, you'll first need to export the configuration file from the device. This file is exported from configuration export import menu found on the communication tab under the support menu. This file is in text format and contains all relevant communication settings. Once on this menu, you will need to click enable and login with administrator credentials. You will then be able to select export to export the configuration. Protected fields like passwords or community strings won't be shown, so you'll need to manually enter those values. Open the configuration file in a text editor. For SNMPv1 or V2C, locate or add the trap target section. Each target should include an IPv4 address. This should be the IP of your connect agent, a trap port, a trap community string set to public. Note, the community string must be set to public for the agent to properly receive and interpret the trap. This requirement will be revised in the future. For SNMPv3 traps, the target details are tied to the SNMPv3 user configuration. This includes username, access type, authentication method, and the authentication secret. Make sure the trap target details are correctly embedded in the SNMPv3 user section. Once you've added in the SNMP trap details, you will need to save the file to your machine. Once edited, you will need to access the Vertive Next Connect web interface to upload the configuration file to the Vertive Next Connect platform, then push it to the Edge device. To add the configuration file in Vertive Next Connect, go to the equipment menu and then the configurations menu. Select the add button and populate the name, configuration type, and model fields. Depending on the card type, you will select one of the card config options for configuration type. Then select the upload button to select the file you saved previously and click on save. to push the configuration file to the edge device. From the device menu, select multiple like devices and click on the bulk provisioning icon in the upper right corner. This will take you to the bulk provisioning menu to select the bolt push configuration from the drop- down menu. Then select the configuration type. This will match what you selected when you uploaded the file. You can now select the file you previously uploaded and click on run. And that's it. You've now learned how to set the vertive next connect agent as a trap target for vertive liber and teleslot devices allowing the agent to receive real-time alerts across your environment.
