## 스크립트

안녕하세요, 슈나이더 일렉트릭의 다니엘입니다 . 오늘 살펴볼 내용은 새 TeSys Terra 서버에 초기 IP 주소를 할당하는 방법입니다. 자, 여기 있는 제 장치를 예로 들면 , 처음에는 내장 이더넷 포트를 사용하거나 HMI 포트와 함께 사용할 수 있습니다. 내장 이더넷 포트를 사용할 경우, MAC 주소에서 계산된 기본 IP 주소를 사용하게 됩니다. [음악]에서 이전에 HMI에 대해 설명했듯이 , 우리는 실제 HMI 장치와 전면의 키패드만 사용할 것입니다. 이제 LTMT CUF 모듈을 Terra에 연결했습니다. [음악] 일단 시작되면 기기 자체에 구성이 되어 있지 않기 때문에 내부 트립이 발생할 수 있습니다. 여기서 IP 주소를 설정하려면 메뉴로 들어가야 합니다. 제 경우에는 PIN 번호가 비어 있으므로 그대로 사용하고 초기 설정 단계로 돌아가겠습니다. 초기 설정에서 몇 가지 메뉴가 더 있는데, 여기서는 소통을 중점적으로 살펴봅니다. 통신 분야에서는 이더넷이 있습니다. 여기서는 포트 구성으로 이동하여 Modbus TCP 또는 이더넷 IP 사용 여부, 이중화 프로토콜 사용 여부 , 이더넷 IP 프로파일링 사용 여부 및 기타 설정을 지정할 수 있습니다. 여기서 가장 중요한 것은 IP 구성입니다. 따라서 여기서 DHCP, 부트 P 또는 수동 IP를 사용할지 여부를 결정할 수 있습니다. 대부분의 경우 IP 주소는 수동으로 설정해야 합니다 . 그리고 다시 거기서 나와서 IP 주소 설정으로 스크롤을 내립니다. 여기에서 키를 사용하여 IP 주소를 설정할 수 있습니다. 보시다시피 이미 여기에 하나 설정해 두었습니다 . 서브넷 마스크를 설정해야 하는 경우, 바로 아래 메뉴에서 동일한 작업을 수행할 수 있습니다. 설정이 완료되면, 종료하려고 할 때 저장 여부를 묻는 메시지가 나타나고, 확인 버튼을 누르면 IP 주소가 장치에 저장되었다는 메시지가 표시됩니다. 이제 장치를 재부팅해야 합니다. 그러면 장치가 새 IP 주소로 재부팅될 것입니다 . Tesys Tetha의 경우, 장치의 기본 IP 주소는 이더넷 포트 바로 위에 인쇄된 MAC 주소를 사용하여 찾을 수 있습니다. 기본 IP 주소는 169.254로 구성됩니다 . 그 다음 두 자리 숫자입니다. 두 번째 끝 숫자는 MAC 주소의 두 번째 옥텟을 의미합니다. 예시에서 4D는 16진수로, 정수로 변환하면 77입니다. 마지막 숫자는 MAC 주소의 마지막 옥텟을 10진수로 변환한 값으로, 이 경우 5E는 94입니다. 따라서 MAC 주소가 001A2B3C4D5E인 [음악] 장치의 기본 IP 주소는 169.254.77.94입니다. [음악] 좋습니다. 여기 메인 웹페이지가 나타나면 사용자 이름과 비밀번호를 입력해야 하는 것을 볼 수 있습니다. 이 경우 기본 사용자 이름은 administrator 이고 기본 비밀번호는 대문자 S로 시작하는 Schneider@24이며 , 이는 화면에 표시되어 있습니다. 그 정보를 입력하고 나면 비밀번호를 변경하라는 메시지가 나타납니다. 따라서 여기서는 오른쪽 에 적힌 비밀번호 규칙을 준수하고, 해당 규칙과 일치하는지 확인해야 합니다. 그 정보를 입력하시면 다시 로그인할 수 있습니다. 자, 이제 관리자 이름과 새로 설정한 비밀번호를 입력해야 합니다. 그렇게 하시면 Terra 장치의 실제 웹 서버에 로그인할 수 있습니다. 여기서부터 다양한 메뉴들이 눈앞에 펼쳐집니다. 자, 우리가 실제로 원하는 메뉴는 설정 메뉴입니다. 설정 메뉴에서는 통신 및 이더넷 구성에도 접근할 수 있습니다. 자, 그럼 설정 화면으로 들어가서 IP 주소 설정 방식을 변경할 수 있습니다 . 그래서 저희의 경우 수동 주소를 원하므로 IP 주소를 입력할 수 있습니다. 원한다면 서브넷 마스크를 변경할 수 있습니다 . 기본 음악 게이트웨이를 비롯한 여러 설정을 변경할 수 있습니다. 하지만 그렇게 하면 IP 주소가 변경되었기 때문에 웹 서버에서 로그아웃되고, 그 후에 새 IP 주소로 장치에 다시 로그인할 수 있습니다. 오늘 Axis Terra IP 할당에 대해 함께 살펴보는 시간에 참여해 주셔서 감사합니다. 다뤄줬으면 하는 다른 영상이 있다면 아래 댓글로 알려주세요.
