## 스크립트

저는 오리예요. 저는 GitHub의 선임 제품 디자이너이며, GitHub 모바일에서 Copilot CLI 또는 VS Code를 사용한 원격 제어 세션 디자인에 참여했습니다. 컴퓨터에서 음악을 재생하여 작업을 시작한 다음, 휴대폰으로 원격 접속하여 이동 중에도 작업을 계속할 수 있습니다. 저는 조쉬입니다. [음악] 저는 GitHub의 엔지니어인데, GitHub의 모든 에이전트 서비스가 똑같은 언어를 사용하는 것 같아요. 그 덕분에 가능해진 것 중 하나가 원격 제어입니다. 저는 Copilot CLI를 사용하여 연결 상태를 유지하고 새로운 작업을 시작하고 응답할 수 있으며, 로컬 작업을 계속 진행할 수 있습니다. 여러 에이전트 세션을 동시에 실행할 수 있습니다. 모든 음악 세션을 한눈에 볼 수 있습니다. 원격 제어를 통해 노트북 앞에 있지 않아도 작업 진행 상황을 확인하고 작업을 지시할 수 있습니다. 그러면 당신은 하고 싶은 일을 무엇이든 할 수 있게 됩니다. 책상 가까이에 있지 않아도 코드를 가까이에서 접할 수 있습니다.
