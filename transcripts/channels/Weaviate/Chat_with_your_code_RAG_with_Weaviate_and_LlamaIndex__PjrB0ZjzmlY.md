## 스크립트

GitHub URL을 입력하고 코드에 대한 질문을 해보세요. 오늘 우리가 만들려는 것은 바로 이것입니다. 코드 임베딩 저장을 위해 we8을 사용하고, AMA를 통해 Moll을 llm으로 사용하며, 프런트엔드로는 Streamlid를 사용할 것입니다. 그리고 이 모든 것을 통합하기 위해 Llama Index를 사용할 것입니다. v8로 이동해 보겠습니다. 무료 샌드박스 클러스터를 생성하려면 wv8 URL과 wv8 API 키를 기록해 두세요. 프로젝트에 EMV 파일을 만들고 비밀 코드를 입력하세요. 먼저 언어 모델을 설정해야 합니다. 다음으로 프로그래밍 언어에 따라 저장소에서 파일을 로드하고 청크 단위로 분할합니다. 코드 스플리터는 각기 다른 방식으로 인스턴스화됩니다. 먼저 파일을 로드하고 청크 단위로 분할하는 함수를 정의합니다. 이제 지원하려는 모든 프로그래밍 언어에 대해 이 함수를 호출하여 청크를 가져옵니다. 그런 다음 이전에 생성한 weit 인스턴스에 연결하고 이전에 생성된 코드와 해당 임베딩을 벡터 데이터베이스에 저장합니다. 마지막으로 구성 요소를 사용하여 리트리버 쿼리 엔진을 인스턴스화하여 Rack 파이프라인을 완성할 수 있습니다. 모든 것을 간단한 Streamlit 앱 의 app.py 파일에 래핑합니다. Streamlit에서 데이터 앱으로 이동하여 새 앱을 클릭하고 app.py 파일을 선택한 다음 실행을 클릭합니다. 그러면 코드 Rack 애플리케이션과의 채팅이 시작됩니다.
