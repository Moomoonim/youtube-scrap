## 스크립트

[Music] Hi, I'm Bangliu, CTO and co-founder of Source Graph. Source graph is a leading code intelligence platform that allows developers to rapidly search, write, and understand code by bringing insights from their entire codebase right into their editor. Our AI powered coding assistant helps developers and companies create the software you use every single day. One of the biggest challenges our customers face is understanding and managing their large legacy code bases. Modernization is key and this can be a huge barrier to innovation and progress. We recently partnered with Lidos, a government and commercial tech leader to solve this specific problem using the power of Llama. Lidos developers work in highly secure environments running on Amazon web services and they needed an agentic tool set that could answer questions about code bases, automate code modernization and documentation and helped debug. We knew using an open source LLM would be an ideal solution due to security and cost constraints. However, with other open source models, we repeatedly ran into two major issues. High latency and outof-date training data. Once we implemented Llama, timeouts stopped and the model's code libraries were up to date. By using Llama and Source Graph, Lidos has seen a 20% increase in developer efficiency, a 20% improvement in development velocity, and a 92% reduction in time loss to context switching and learning. Today, Lidos is also able to engineer and implement features 33% faster. With Llama and Source Graph, Lidos found an open source technology they could bring to bring leading Genai innovation to customers with fixed budgets who don't invest in anything that does not advance the mission. Llama powered innovation has proven to be a valuable asset to Lidos. Their success in combining Llama and Source Graph has given Lidos a competitive edge and we're proud that we play a role in helping them get there.
