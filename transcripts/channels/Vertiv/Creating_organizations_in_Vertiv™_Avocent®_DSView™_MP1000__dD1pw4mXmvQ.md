## 스크립트

[music] This video will cover the Verdiff DS view solution MP1000 organization structures. Once you are logged into the MP1000 web interface on the left hand side below appliance view, select organizations. On the organizations page, you can see the ungrouped devices organization. This contains [music] all of the connected target devices that have not yet been added to a created organization. On the right hand side, we are going to select the plus sign to manage organizations. In the organization editor, here's where you'll be creating a new organization. For this video, I'm going to create an organization titled sales lab. Since I just created the sales lab organization and have not yet added any devices, you can see that there is no data to display. Going back, I'm going to select some of the ungrouped devices and add them to the sales lab organization. After adding some devices to the sales lab organization and expanding, [music] you can now see the added devices below. I'm going to go ahead and create another organization labeled tech support lab. Here I'm going to add some more devices to the tech support lab organization. After closing the organization editor, you can view the following organizations below. The ungrouped devices organization, the sales lab, and the tech support lab. You'll notice that the devices that were originally in ungrouped devices will now be moved to the appropriate organizations. On this page, you have the option to delete, merge, and upgrade the firmware of the selected devices. Depending on the device, you are also able to launch a session. For any further configuration, you can open the organization editor, select the desired organization, and make the necessary changes. If you select the vertical ellipses, [music] you'll have the option to delete the created organizations. This concludes our topic discussing the MP1000 organization structures.
