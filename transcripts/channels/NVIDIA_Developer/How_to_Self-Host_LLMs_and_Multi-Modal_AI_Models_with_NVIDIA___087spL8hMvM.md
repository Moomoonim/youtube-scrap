## 스크립트

[음악] Nvidia로 가속되는 최신 생성형 AI 모델을 사용해 보고 싶으신가요? 오늘은 단 하나의 명령어로 고성능 GPU 가속 추론을 위한 최신 AI 모델을 안전하고 비공개적으로 자체 인프라에 배포하고 테스트하는 방법을 보여드리겠습니다. 먼저 빌드 시 Nvidia API 카탈로그에서 어떤 모델을 사용할 수 있는지 확인해 보겠습니다. nvidia.com에는 안정 확산, ESM 폴드 등 다양한 분야에서 사용할 수 있는 여러 모델이 있지만, 오늘 우리가 사용할 모델은 Llama 3입니다. 웹 브라우저에서 바로 모델을 테스트하고 성능을 확인할 수 있습니다. 예를 들어, GPU 컴퓨팅에 대한 라임을 작성하도록 모델에 요청해 보겠습니다. 결과는 다음과 같습니다. 호스팅된 API를 사용하여 API 키를 생성하고 여기에 제공된 샘플 코드 스니펫을 사용하여 프로그래밍 방식으로 모델을 테스트할 수도 있습니다. Nim을 직접 배포하려면 이 페이지의 Docker 탭으로 이동하여 Nim 컨테이너를 다운로드하고 자체 환경에서 실행하는 방법에 대한 지침을 확인하세요. Nim을 다운로드하려면 계정을 등록해야 합니다. NVIDIA AI Enterprise 라이선스를 통해 Nim에 액세스하려면 회사 이메일로 등록 하거나 NVIDIA 개발자 프로그램을 통해 무료로 Nim에 액세스하려면 개인 이메일로 등록할 수 있습니다. 필요에 맞는 옵션을 선택하세요. 이제 명령줄로 이동하여 배포 프로세스를 살펴보겠습니다. 먼저 해야 할 일은 다음과 같습니다. NVIDIA 컨테이너 레지스트리에 로그인 하려면 Docker 엔진과 Docker 명령 줄 도구가 미리 설치되어 있어야 합니다. Docker login 다음에 NVC r을 입력하면 됩니다. NVIDIA 컨테이너 레지스트리의 사용자 이름에는 달러 기호($)와 Ooth 토큰을 사용하고, 비밀번호에는 API 카탈로그 웹 페이지에서 얻은 API 키를 붙여넣겠습니다. 이제 컨테이너 레지스트리에 인증이 완료되었습니다. 다음 단계는 세션에 동일한 API 키 값을 저장하는 NGC API 키라는 환경 변수를 생성하는 것입니다. 저는 이미 이 작업을 완료했으므로 여기서는 생략하겠습니다. 이제 실행을 시작하려면 Docker run 명령 하나만 입력하면 됩니다. 이 명령은 컨테이너 이미지를 다운로드하고, 필요한 모델 가중치를 다운로드하고, 로컬 API 엔드포인트로 사용할 수 있는 Nim 마이크로서비스를 배포합니다. 여기에는 몇 가지 유용한 플래그가 있습니다. 첫 번째는 gpus 플래그로, Docker가 실행 중인 컨테이너에 모든 GPU를 노출하도록 지시합니다. 두 번째는 Docker Node가 이전에 설정한 API 키 환경 변수를 노출하도록 하는 것입니다. 마지막으로 Nim 컨테이너 내의 Nim docash 디렉터리에 이 경로를 마운트합니다. Nim은 이 디렉터리에 모델 가중치를 다운로드하고 저장하여 별도의 경로가 필요하지 않도록 합니다. 향후 배포 시 다시 다운로드되도록 설정하고, 다음으로 Nim이 로컬 사용자 권한으로 실행되도록 지정합니다. 마지막으로 컨테이너 내부에서 외부로 8000번 포트를 노출합니다. 이 포트는 실행 중인 Nim과 상호 작용하기 위해 모든 HTTP 요청을 보내는 주요 포트입니다. 마지막 부분은 실제 컨테이너 이미지, 이미지 경로 및 태그입니다. Nim을 배포할 때 이미지 경로에 모델 이름을 포함한다는 점에 유의하세요. 이 경우 LL 38b 모델을 배포하고, Llama 370b 모델이나 다른 모델을 배포하는 경우에는 다른 이미지 경로를 사용해야 합니다. 로그의 끝으로 스크롤하면 마지막 메시지가 서비스가 8000번 포트에서 실행 중이며 요청을 수신할 준비가 되었음을 알려줍니다. 서비스가 준비되었는지 확인하기 위해 다른 터미널로 이동하여 curl을 사용하여 상태 준비 요청을 보내면 서비스가 준비되었다는 응답을 볼 수 있습니다. 이제 Nim이 준비되었습니다. 요청을 보내 보겠습니다. 다시 터미널에 이 명령어를 붙여넣으면 제한을 요청하는 요청을 빠르게 받을 수 있습니다. 웹 인터페이스에서 봤던 것처럼 아름다운 시가 담긴 응답을 받았습니다. 이렇게 해서 최신 커뮤니티 AI 모델 중 하나를 자체 NVIDIA 가속 인프라에 배포하여 안전하고 고성능 추론을 구현했습니다. 더 많은 Nim 예제를 실행해 보려면 설명란에 있는 Jupyter Notebook과 관련 자료를 확인하세요.
