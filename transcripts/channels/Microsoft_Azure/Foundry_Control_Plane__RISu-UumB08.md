## 스크립트

요원은 어디에나 있습니다. 개발자들은 단순히 하나의 에이전트만 만드는 것이 아닙니다. 그들은 여러 음악 클라우드 플랫폼에서 플릿을 관리하고 있습니다. Microsoft Foundry는 Foundry Control Plane을 통해 관찰 가능성, 보안 및 제어 기능을 한 곳에 통합합니다. Microsoft Agent 365와 통합된 Foundry 제어판은 Microsoft, 타사 플랫폼 또는 다른 클라우드에서 구축된 에이전트를 포함하여 조직 전체의 모든 에이전트를 완벽하게 파악할 수 있도록 지원합니다. 개발자는 이제 성능, 비용 및 안전성에 대한 가시성을 하나의 통합된 보기에서 제공받으면서 한 곳에서 구축 및 운영할 수 있습니다 . 에이전트 제어를 통해 프롬프트 [음악]부터 도구, 출력에 이르기까지 에이전트의 동작 방식을 정확하게 정의할 수 있습니다. 게다가 마이크로소프트 퍼뷰(Microsoft Purview)와도 완벽하게 연동되어 처음부터 민감한 정보를 안전하게 보호합니다. 에이전트 확산과 에이전트 간 ID 혼동을 피하고, 모든 에이전트에게 검증된 신원과 소유자를 부여하십시오. 또한 Microsoft Defender 기반의 실시간 방어 기능도 이용할 수 있습니다. 모든 에이전트, 모든 플랫폼. 파운드리 [음악] 제어 평면.
