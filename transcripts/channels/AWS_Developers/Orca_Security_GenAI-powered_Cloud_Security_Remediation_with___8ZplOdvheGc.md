## 스크립트

안녕하세요, 저는 AWS 솔루션 아키텍트 Hero입니다. 안녕하세요, 저는 Orca Security의 AI 혁신 디렉터인 Shai Alon입니다. 이것은 제 아키텍처입니다. Shai, 이것은 Gen Power 복구 도구인데, 어떤 문제를 해결하는 데 사용되나요? Orca Security 플랫폼은 클라우드 환경에서 많은 문제를 발견하지만, 문제를 발견하는 것은 시작에 불과합니다. 실제로 문제를 해결해야 하는데, 고객마다 아키텍처가 매우 다양하기 때문에 이는 매우 어려운 과제입니다. 바로 이 부분에서 이 기능이 중요한 역할을 합니다. 기본적으로 알림 UI에서 고객에게 " CLI로 해결하시겠습니까? 아니면 클라우드 콘솔에서 수정하시겠습니까? 아니면 CloudFormation이나 다른 공급업체의 인프라 코드에서 수정하시겠습니까?"라고 묻습니다. 고객은 한 번의 클릭으로 API에 요청을 보내고, 이 요청은 미들웨어를 통해 AI 복구를 담당하는 Pod에 직접 전달됩니다. 따라서 목표는 사용자에게 복구를 위한 구체적인 지침 목록을 제공하는 것입니다. 네, 맞습니다. 사용자는 원하는 형식을 지정할 수 있습니다. 그 후에는 어떤 일이 발생하나요? 어, Pod는 저희 보안 데이터베이스인 IDDS에 접속합니다. 모든 경고와 인벤토리가 여기에 저장되어 있죠. 그리고 저희는 해당 경고에 대한 구체적인 정보를 찾아냅니다. 예를 들어 CVE라면 어떤 유형의 CVE인지, 설명은 어떤지 등을 확인합니다. 이 정보는 Bedrock의 클라우드 기반 LLM에 접속하여 해당 정보를 제공하는 데 사용됩니다. 즉, 사용자가 요청한 정보는 다음과 같고, 저희는 해당 경고에 대한 정보를 가지고 있으며, 이 문제를 해결해야 합니다. 그런데 혹시 CLA CLOM LLM을 사용하고 계신가요? 네, 맞습니다. CLOM은 특정 작업에는 매우 뛰어난 범용 LLM이지만, 보안 이벤트 관련 해결 단계를 위한 훈련은 되어 있지 않은 것 같습니다. 맞나요? 네, 맞습니다. 실제로 저희도 그 점을 파악했습니다. 처음에는 OpenAI를 사용했는데, LLM은 문제 해결 방법에 대한 기본적인 정보를 제공하는 데는 효과적이었습니다. 하지만 더 높은 정확도를 원했을 때는 다른 방법을 찾아야 했습니다. 저희는 연구원들이 선별한 정보를 통해 LLM을 보강해야 할 필요성을 느꼈고, 바로 이 지점에서 Bedrock으로 전환하게 되었습니다. 우선, 기존 LLM이 Bedrock 덕분에 매우 효율적으로 개선되었을 뿐만 아니라, 지식 기반(Knowledge Base)이라는 개념이 도입되었습니다. Bedrock에서는 연구원들이 PDF, 텍스트 또는 기타 어떤 형식으로든 선별된 정보를 간편하게 업로드할 수 있는 인터페이스를 제공합니다. 이렇게 업로드된 정보는 개방형 검색 서버리스 서비스에서 처리되어 색인화됩니다. 네, 맞습니다. 저희는 실제로 아무것도 하지 않습니다. 모든 정보가 지식 기반 시스템에 내장되어 있기 때문입니다. 네, 바로 이 점이 Bedrock의 장점 중 하나입니다. 데이터 수집 코드를 직접 작성할 필요가 없기 때문입니다. 따라서 CLM은 특정 계정의 보안 문제 및 경고에 대한 구체적인 상황 정보뿐만 아니라, 정상적인 상황의 모습 과 문제 해결에 효과적인 패턴에 대한 정보도 얻을 수 있습니다. 네, 맞습니다. 이 모든 정보는 사용자에게 제공되며, 사용자는 채팅창을 통해 질문할 수도 있습니다. 예를 들어, 사용자가 "이 명령어를 시도해 봤는데 작동하지 않았습니다."라고 말하면, 이 내용은 전체 컨텍스트와 함께 LLM(Long Leadership Manager)에 다시 전달됩니다. 그러면 LLM은 문제를 해결할 다른 방법을 제안하거나 권한 문제일 수도 있습니다. 텍스트 입력란이 생기기 전에는 일반적인 해결 단계만 제공했을 텐데, 사용자에게 텍스트 입력란을 제공함으로써 사용자가 원하는 바에 따라 맞춤형 답변을 제공할 수 있게 되었습니다. 네, 맞습니다. 덕분에 사용자가 무엇을 원하는지 더 잘 이해할 수 있게 되었습니다. 예를 들어, 사용자들은 앞으로 이 문제가 다시 발생하지 않도록 보안 정책을 만들고 싶다고 말했습니다. 텍스트로 질문할 수 있게 되면 흥미로운 점들이 많이 나타납니다. 그리고 시스템을 사용하는 사람들에게도 훨씬 더 나은 경험을 제공할 것이라고 생각합니다. 보안 문제를 해결하기 위해 다른 사람에게 티켓을 발행하는 대신, 지침을 받고 즉시 조치를 취할 수 있기 때문입니다. 네, 확실히 시간과 노력을 많이 절약할 수 있습니다. 번거로움 없이 정말 사랑받는 기능이에요. 샤이, 이렇게 멋진 아키텍처를 공유해 주셔서 정말 감사합니다.
