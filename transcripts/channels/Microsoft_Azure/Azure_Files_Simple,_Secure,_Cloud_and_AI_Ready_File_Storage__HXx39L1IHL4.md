## 스크립트

Azure Files는 애플리케이션, 팀, 음악 및 AI 중심 환경 전반에서 데이터에 빠르고 안전하며 간편하게 액세스해야 하는 조직을 위해 최신 클라우드 네이티브 파일 스토리지를 제공합니다. Azure에 직접 통합된 Azure Files는 기존 파일 서버를 관리하는 데 드는 부담 없이 엔터프라이즈급 안정성, 낮은 지연 시간 및 글로벌 가용성을 갖춘 완전 관리형 SMB 및 NFS 파일 공유를 제공합니다 . 조직은 Windows 애플리케이션을 현대화하고, Azure Virtual Desktop 배포를 가속화하며, Azure 서비스와 원활하게 통합되는 관리형 SMB 및 NFS 공유를 통해 클라우드 네이티브 워크로드를 지원합니다 . Azure Files는 Azure Storage Mover와 파트너 주도 마이그레이션 도구를 통해 클라우드 도입을 간소화하여 팀이 대규모로 파일 공유를 이동하고 스토리지 비용을 최적화할 수 있도록 지원합니다. Microsoft Entra ID 지원, B2B 액세스 및 관리형 ID와 같은 보안 및 ID 분야의 혁신은 제로 트러스트 원칙을 강화하고 내부 팀과 외부 협력자의 액세스를 간소화합니다 . [음악] 스냅샷, 소프트 삭제, 엔터프라이즈급 복구를 위한 Azure Backup과 같은 내장 기능을 통해 비즈니스 핵심 역량의 복원력을 강화하세요. Azure File Sync를 사용하여 하이브리드 아키텍처를 지원하세요. [음악] 이를 통해 지사, 글로벌 협업 및 Azure Arc 기반 관리에 대한 지연 시간 없는 액세스가 가능합니다. [음악] Azure Files는 레거시 워크로드를 현대화하고 총 소유 비용을 절감하는 동시에 클라우드에 최적화된 안전하고 안정적인 파일 스토리지를 통해 클라우드 네이티브 및 AI 애플리케이션을 실행할 수 있도록 지원합니다 . Azure Files, 간편하고 안전하며 클라우드 환경에 최적화되어 있습니다.
