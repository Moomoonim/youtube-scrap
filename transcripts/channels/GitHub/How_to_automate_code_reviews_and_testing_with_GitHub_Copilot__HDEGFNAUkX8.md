## 스크립트

제가 얼마 전에 풀 리퀘스트를 하나 생성했는데, 솔직히 말해서 이상적인 상태는 아닙니다. 저는 올바른 코딩이나 보안 관행을 따르지 않았습니다 . 팀원들이 내 엉망진창인 상황을 보기 전에, 부조종사와 코드 스캐닝 담당자에게 도움을 요청할 수 있겠어. 보도 자료 메인 페이지를 살펴보니, 제가 제공했던 간략한 설명에 더해 Co-Pilot 측에서 변경된 파일과 검토 내용을 자세히 나열한 것을 확인할 수 있습니다. 조금 더 스크롤해 보면, 코파일럿의 첫 번째 호출을 볼 수 있습니다. 보안에 취약한 코드를 추가했습니다. 저는 함수를 직접 호출하는 대신 exec 명령어를 사용합니다 . Copilot이 바로 여기에 해결 방법을 제안하고 있습니다. 지금은 이대로 두겠습니다. 나중에 코드 스캔을 할 예정인데, 어떤 결과가 나오는지 확인하고 싶거든요 . 하지만 걱정하지 마세요, 해결될 겁니다. Copilot 리뷰에서 제 코드의 타입 힌트 관련 문제점 몇 가지를 추가로 지적해 주었습니다. 함수 반환 값 중 하나가 빠진 것 같고, 다른 하나는 완전히 잘못된 것 같습니다. 앞서 말씀드렸듯이, 제 홍보 전략은 이상적이지 않습니다. 마지막으로, GitHub의 보안 도구를 사용하여 우리가 작성한 코드의 취약점을 검사한 결과를 확인할 수 있습니다 . 파이썬 exec 함수 호출을 감지했습니다. 하지만 저는 보안 전문가가 아니어서 이 문제를 어떻게 해결해야 할지 잘 모르겠습니다. Copilot Autofix의 코드 스캔 기능 중 하나가 취약점에 대한 설명과 해결책을 제시했습니다. 그 제안을 실행에 옮기겠습니다. 그러니까 찾았다는 건 해결했다는 뜻이죠. 브랜치와 PR을 업데이트하면 코드 스캔이 자동으로 다시 실행되어 생성된 코드가 취약점을 해결했음을 확인할 수 있습니다. 업데이트된 코드에 대해 실행되는 모든 보안 스킨과 테스트들을 확인할 수 있습니다. 파일 탭을 살펴보면 변경 사항을 더 자세히 확인할 수 있는데, 코파일럿 리뷰의 권장 사항 도 여기에 표시되는 것을 알 수 있습니다. 반환 유형을 업데이트하라는 제안을 바로 여기에 적용해 보겠습니다. 저는 IDE로 돌아가지 않고도 이 작업을 수행할 수 있습니다. 이 기능을 가능하게 하는 설정들을 간단히 살펴보겠습니다. 내 저장소 설정을 열어보면 규칙 세트가 있습니다. 테스트 및 보안 목적으로 만들어진 계정이 하나 있습니다 . 풀 리퀘스트가 필요하며, 검토자 수를 한 명으로 설정했습니다. 또한 DevOps 프로세스를 간소화하기 위해 Copilot에 자동으로 리뷰를 요청하고 있습니다 . 프런트엔드 및 백엔드 테스트 형태로 상태 확인 기능을 활성화했습니다. 이는 저장소에 정의된 워크플로에 포함된 내용이며, emerge를 완료하기 전에 반드시 필요한 단계입니다. 마지막으로, 코드 스캔 결과가 명확해야 한다는 점도 요구하고 있습니다. Copilot의 검토 과정을 돕기 위해 C-pilot 지침 파일을 만들었습니다. 이 파일은 저장소의 일부이며, 솔직히 말해서 C-Pilot을 사용하는 개발자가 있는 모든 저장소에 생성되어야 합니다. 지침 파일을 사용하면 추가적인 맥락 정보를 제공할 수 있습니다. Copilot Review는 이 파일을 사용하여 당사의 업무 방식을 더 잘 파악하고 더 나은 제안을 제공합니다. 지금은 이 저장소에 PR을 생성하는 사람이 저뿐만이 아닙니다 . Copilot도 마찬가지이므로 다른 개발자의 코드와 마찬가지로 해당 코드도 검토해야 합니다 . 해당 PR에는 빌드 내용과 변경된 파일에 대한 자세한 설명이 나와 있습니다. 코드를 열어서 웹사이트를 실행해보고 어떻게 보이는지 확인하고 싶어요. 저는 해당 브랜치에 코드 스페이스를 열어서 바로 그렇게 할 수 있습니다 . 그로 인해 생성된 필터 기능은 제대로 작동하는 것 같습니다 . 하지만 게임을 실행해 보니 별점이 반쪽짜리로 표시되는 것을 발견했습니다 . 소수점 부분에 그라데이션 채우기 기능이 있으면 좋겠네요. 리뷰로 돌아가서, 댓글에 Copilot님을 태그하고 요청 사항을 남기겠습니다. Copilot은 범위 확장에 대한 불평 없이 업데이트 작업에 착수합니다. 작업이 완료되면 코드 공간으로 돌아가 코드를 가져와 사이트를 다시 실행하면 업데이트된 내용을 확인할 수 있습니다. 훨씬 낫네요. 지금 모습이 정말 마음에 들어요. 하지만 저는 다른 개발자들과 마찬가지로 Copilot이 제출한 PR에 대한 모든 테스트가 통과하는지 확인하고 싶습니다. 보안상의 이유로 제가 승인하지 않으면 Copilot의 PR 관련 작업은 실행되지 않습니다 . 그렇게 하죠. 그들이 합격 하고 모든 것이 순조롭게 진행되는지 확인하십시오. 우리는 개발자 코드와 부조종사 코드 모두를 검토하고 검증할 수 있는 완벽한 도구 모음을 갖추고 있음을 알 수 있습니다.
