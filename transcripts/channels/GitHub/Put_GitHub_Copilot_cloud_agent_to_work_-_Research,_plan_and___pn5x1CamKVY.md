## 스크립트

Copilot 클라우드 에이전트의 유연성이 훨씬 향상되었습니다. 이제 에이전트 탭에서 Copilot Cloud Agent에게 계획 수립, 질문 답변, 코드 변경 등 세 가지 작업을 모두 동일한 대화 내에서 PR 없이 수행할 수 있습니다. 내 애플리케이션의 현재 사용자 인증 방식을 살펴보는 것부터 시작할 수 있는데, 그러면 바로 이 채팅창에서 심층적인 조사 세션이 시작됩니다. 그러면 에이전트를 사용하여 사용자 인증 흐름을 계획할 수 있습니다. 실제로 변경 작업을 진행할 준비가 되면 프롬프트를 입력하고, 세션이 완료되면 PR을 생성할지 여부를 결정하기 전에 변경 사항을 검토할 수 있습니다 . 이제 먼저 계획을 세우고, 준비가 되면 코딩하고, 원하는 방식으로 PR을 생성할 수 있습니다. 자세한 내용은 gh.io/copilotcloudagents에서 확인하세요.
