## 스크립트

몇 분 만에 생성되는 플랫폼 랜딩 존을 통해 클라우드 도입 여정을 가속화할 수 있다는 사실을 알고 계셨나요? 자동화된 인사이트와 간소화된 배포 단계를 통해 필요에 맞춘 안전하고 확장 가능한 랜딩 존을 원활하게 계획, 평가 및 배포하세요. 첫날부터 민첩성과 거버넌스를 확보하고 인프라를 미래 지향적인 Azure 환경으로 전환하세요. 마이그레이션 에이전트는 고객이 Azure로 마이그레이션하는 과정에서 플랫폼 랜딩 존의 계획 및 배포를 가속화하도록 설계되었습니다. 조직의 Azure 랜딩 존 아키텍처 및 지침에 따라 플랫폼 랜딩 존을 설정하는 업무를 맡은 솔루션 아키텍트, 클라우드 엔지니어 또는 DevOps 담당자라면 이 새로운 마이그레이션 에이전트가 바로 당신을 위해 만들어졌습니다. 이 에이전트는 설계 문서 작성 지원부터 자동화된 인프라 코드 생성 및 감사, 그리고 CI/CD 배포 지원에 이르기까지 모든 단계를 간소화합니다. 플랫폼 랜딩 존 계획은 자동화된 추천, 상황별 안내, 빠른 피드백, 즉각적인 디자인-코드 생성 기능을 통합한 대화형 안내 경험으로 거듭납니다. 간단한 안내로 빠르게 시작하세요 . 플랫폼 착륙 구역을 만들고 싶습니다. 마이그레이션 에이전트는 마이그레이션 프로젝트 이력 및 클라우드 도입 프레임워크 지침에 맞춰 플랫폼 랜딩 존 설정을 자동으로 생성하고, 모든 권장 사항을 명확한 데이터 기반 논리로 설명합니다. 플랫폼 랜딩 존에 관련된 모든 이해 관계자는 에이전트를 사용하여 모든 구성 요소에 대한 답변을 얻고, 의사 결정을 가속화하고, 의문을 해소하고, 공식 Azure 및 클라우드 도입 프레임워크 문서에 대한 직접 링크를 통해 검증된 정보에 액세스할 수 있습니다. 몇 분 안에 설계 문서와 인프라스트럭처 코드 파일이 하나의 zip 파일로 결합된 플랫폼 랜딩 존을 다운로드할 수 있습니다. 이제 생성된 랜딩 영역을 VS Code에서 열어야 합니다. 플랫폼 랜딩 존의 압축을 풀고 Visual Studio Code를 열면 GitHub Copilot에게 "다음에는 무엇을 해야 할까요?"라고 물어 작업을 계속할 수 있습니다. Azure Migrate MCP 서버와 에이전트 모드의 GitHub Copilot을 사용하면 플랫폼 랜딩 영역을 Azure에 더욱 세밀하게 사용자 지정하고, 감사하고, 배포할 수 있습니다 . 먼저, Azure Migrate MCP 서버를 설정할지 묻는 메시지입니다. 이 경우에는 이미 실행 중입니다. 그러니 그냥 '진행'이라고 입력하시면 됩니다. 다음으로, Azure Migrate 프로젝트에 연결할 것인지 확인하는 절차가 진행되며, 이를 통해 두 에이전트 간에 컨텍스트가 공유됩니다. MCP 서버 내에는 정책 관리, 랜딩 존 검토 및 배포에 도움이 되는 여러 도구가 있습니다. 해당 도구를 직접 사용하거나, 이와 같이 일반 텍스트로 질문을 할 수 있습니다. 개발 테스트 환경에 맞게 이 설정을 사용자 지정할 수 있도록 도와주세요. GitHub Copilot 에이전트는 마이그레이션 에이전트로부터 추가 컨텍스트를 가져오기 전에 확인을 요청합니다 . 지금 여러분은 사전 예방적 추천 기능의 성능을 직접 목격하고 계십니다 . DDoS 공격 방지 기능 비활성화를 통한 비용 절감 이나 명명 규칙 업데이트와 같은 작업은 자동으로 수행됩니다. 또한 플랫폼 랜딩 영역은 사용 사례에 맞춰 실시간으로 선별된 수천 개의 Azure 정책을 활용할 수 있습니다 . 보시다시피 , 개발 및 테스트 환경에서는 일부 제한을 완화할 수 있으며 , 버튼 클릭 한 번으로 해당 제한을 제외할 수도 있습니다. 마지막으로 담당자는 변경 사항을 모두 요약한 문서를 작성하여 승인 또는 추가 맞춤 설정을 위해 제출할 수 있습니다. 감사합니다.
