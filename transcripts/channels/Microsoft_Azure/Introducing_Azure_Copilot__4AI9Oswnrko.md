## 스크립트

Azure Copilot은 Azure용 에이전트 인터페이스로, 강력한 거버넌스를 통해 워크로드를 마이그레이션, 운영 및 최적화하는 에이전트 시스템을 제공합니다 . Azure로 워크로드를 마이그레이션할 준비가 되면 마이그레이션 에이전트가 워크로드 검색을 간소화하고 , 상호 종속성을 매핑하고, 워크로드 요약을 생성합니다. 이는 다양한 옵션에 대한 ROI 분석을 통해 마이그레이션에 대한 사업 타당성 근거를 제공합니다. 에이전트는 관련 워크로드를 그룹화하고 클라우드 준비 상태를 평가하며 앱 현대화를 위한 자세한 분석 및 권장 사항과 함께 권장 마이그레이션 경로를 제공하여 마이그레이션 계획 실행을 지원합니다. 마이그레이션 평가를 GitHub 리포지토리에 직접 연결하고 평가의 모든 컨텍스트를 포함하는 GitHub 이슈를 생성할 수 있습니다. C-pilot은 Azure의 모범 사례 및 권장 사항에 따라 인프라를 배포하는 데 도움을 줍니다. 새로운 애플리케이션을 호스팅하기 위해 에이전트는 사용자와 함께 워크로드 계획, 이유, 장단점을 고려한 계획을 수립하고 [음악]은 적절한 리소스 전략을 제공합니다. GitHub에서 풀 리퀘스트를 생성하는 데 사용할 수 있는 IA 템플릿을 배포할 준비를 합니다. 워크로드가 배포되면 Copilot은 Azure 서비스 전반의 워크플로에서 사용할 수 있으므로 환경을 운영하고 최적화하는 데 도움이 됩니다. 에이전트를 사용하여 클라우드 비용, 탄소 배출량을 최적화하고 클라우드 복원력을 향상시키도록 권장 사항을 실행하세요. 리소스 활용을 최적화하려면 편향 권장 사항, 잠재적 절감액, 현재 활용도와 예상 활용도 비교, 그리고 성능 저하 없이 리소스를 축소할 수 있는 CLI 명령어를 활용하세요 . 미션 크리티컬 워크로드의 경우, 복원력이 부족한 리소스를 식별하고 복원력이 뛰어난 워크로드에 대한 이중화를 구현하는 데 도움이 되는 지침을 제공하여 고가용성을 확보하십시오. 애플리케이션이 제대로 작동하지 않을 때 Azure Copilot은 발생하는 경고를 조사하는 데 도움을 줍니다. 상담원은 잠재적인 문제를 식별하고, 근본 원인 분석 요약을 제공하며, 경고를 해결하기 위한 지침을 제시합니다. Azure C-Pilot은 VM, 데이터베이스 또는 Kubernetes 리소스 전반에서 [음악] 문제를 진단하고 완화하는 데 도움을 줄 수 있습니다 . 오류가 발생하면 영향을 받는 서비스를 식별하고, 상태 점검을 실행하며, 자세한 추론 추적을 통해 문제를 파악합니다. 오류를 해결하기 위해 수동으로 또는 자동으로 문제를 해결하거나 상담원에게 Microsoft 지원팀으로 문제를 전달해 달라고 요청할 수 있습니다. Azure C-Pilot을 사용하여 모든 워크로드를 효율적이고 일관성 있게 제어하며 실행하세요.
