Keras를 확장하면 자체 체크포인트 콜백을 구현하고, 원하는 체크포인트 라이브러리를 실행하고, 어떤 체크포인트를 기록할지, 얼마나 자주 기록할지, 어떤 형식으로 기록할지 등을 완전히 사용자 정의 기준으로 코드를 작성할 수 있습니다. 오늘은 Orbax라는 라이브러리를 사용하여 Keras를 확장하고 JAX 백엔드를 통해 멀티 호스트 환경에서 사용자 지정 체크포인트를 수행하는 방법을 알아보겠습니다 . Orbax는 JAX 생태계 내 사용자 에게 권장되는 기본 체크포인팅 라이브러리입니다 . 이 시스템은 체크포인트 관리와 구성 가능하고 확장 가능한 직렬화 기능을 모두 제공합니다. Orbax 체크포인트 기능은 체크포인트 로직을 사용자 정의할 수 있을 뿐만 아니라, Keras 배포 API를 사용한 멀티 호스트 학습도 지원합니다. 현재 기본 Keras 체크포인트 기능은 멀티 호스트를 지원하지 않기 때문입니다. 이 체크포인트 방식은 특히 JAX 백엔드를 위해 고안되었습니다 . 따라서 첫 번째 단계는 Orbax 체크포인트 라이브러리를 설치하고 Keras 백엔드 환경 변수가 JAX로 설정되어 있는지 확인하는 것입니다. Orbax를 Keras에 통합하려면 두 개의 유틸리티 클래스를 생성해야 합니다. Keras Orbax 체크포인트 관리자 및 Orbax 체크포인트 콜백. 간략히 말하자면, Keras Orbax 체크포인트 관리자는 Orbax를 사용한 체크포인트 구현의 세부 사항을 담당하고, Orbax 체크포인트 콜백은 Keras 콜백 시스템과의 연결을 제공합니다. 각각을 좀 더 자세히 살펴보겠습니다. Keras Orbax 체크포인트 관리자는 Orbax의 기본 체크포인트 관리자를 확장하고 Keras 함수를 사용하여 상태 가져오기, 저장 및 복원 기능을 구현합니다 . 기본적으로 저희는 Keras에서 사용할 맞춤형 Orbax 체크포인트 관리자를 만들고 있습니다. 초기화 함수에서는 체크포인트 디렉터리, 에포크당 단계 수, 유지할 체크포인트 개수와 같은 몇 가지 중요한 옵션을 구성합니다. Keras Orbax 체크포인트 관리자는 Keras 모델의 내부 get state tree 및 set state tree API를 사용하여 가중치, 옵티마이저 상태 및 메트릭을 포함한 모델 변수를 저장하고 복원합니다. 이제 내부를 살펴보고 각 기능을 좀 더 자세히 알아보겠습니다. ` getstate` 메서드에서는 Keras의 `getstatetree`를 사용하여 모델의 전체 상태를 가져옵니다. 하지만 이 과정에서 Orbeax가 체크포인트 목적으로 별도로 저장하는 메트릭도 함께 수집됩니다 . 따라서 상태와 지표를 쌍으로 반환하기 전에 지표를 분리하겠습니다 . 상태 저장 코드는 아주 간단합니다. 말 그대로 단 두 줄뿐입니다. 방금 작성한 상태 가져오기 함수를 사용한 다음, 해당 상태와 메트릭을 Orbeax의 저장 메서드에 전달합니다. 복원 상태에서는 먼저 `getstate`를 호출하여 모델 구조를 `self.restore`에 제공함으로써 전체 체크포인트 상태를 가져옵니다. 체크포인트 상태를 얻으면 Keras의 setstatetree를 사용하여 체크포인트된 모델의 가중치를 반영하도록 모델을 업데이트합니다. Orbeax 체크포인트 콜백은 자체 개발한 체크포인트 관리자의 저장 및 복원 기능을 사용하여 표준 Keras 콜백을 확장한 것으로, 각 학습 에포크의 시작과 끝에 모델 상태를 자동으로 저장하고 복원합니다 . 경계 조건 검사가 상당히 많지만, 여기서 주요 기능은 열차 시작 시 체크포인트 관리자의 상태 복원 기능을 호출하고, 에포크 종료 시 상태를 저장하는 것입니다 . 즉, 장치 오류, 정전 또는 VM 선점 등의 상황이 발생하더라도 한 에포크 분량 이상의 작업 손실은 발생하지 않습니다. 이러한 유틸리티가 준비되면 Orbeax 체크포인트 사용은 간단합니다 . 네, 맞습니다. 이 내용을 복사해서 코드에 붙여넣으시면 됩니다. 이제 Orbeax 체크포인트 콜백 인스턴스를 model.fit 메서드 내의 callbacks 인수에 전달할 수 있습니다. 가장 최근 체크포인트 외에 더 많은 체크포인트를 저장하려면 최대 저장 횟수 인수를 늘리면 됩니다. 학습 과정에서 콜백은 두 가지 작업을 수행합니다. 첫째, 훈련 시작 시 최신 체크포인트가 있는 경우 이를 복원하여 훈련을 올바르게 재개할 수 있도록 합니다 . 둘째, 각 에포크가 끝날 때마다 ` save state`를 사용하여 현재 모델 상태를 명시적으로 저장합니다. 예를 들어, 간단한 모델을 5 에포크 동안 학습시키면 각 에포크가 끝날 때마다 오르페우스 체크포인트가 저장되었다는 메시지가 생성됩니다. 학습이 완료되면 체크포인트 파일은 지정된 Orpheus 체크포인트 디렉터리에서 확인할 수 있습니다. 다음은 학습이 완료된 후 남은 파일들입니다 . 제가 5개의 에포크를 요청했고 첫 번째 에포크가 0번째 에포크이므로 , 가장 최근의 에포크는 1, 2, 3, 4번째 에포크입니다. 최대 유지 인수를 1로 설정했으므로 남은 에포크는 이것뿐입니다. 만약 우리가 세 개를 선택했다면, 가장 최근의 체크포인트 세 개, 즉 2번, 3번, 4번 체크포인트를 선택하게 될 것입니다. 필요에 맞게 이 값들을 조정하면 곧바로 손쉽게 체크포인트 기능을 사용할 수 있을 것입니다 .
