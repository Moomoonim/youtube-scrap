## 스크립트

본 연구에서는 수천 개의 모션 클립을 포함하는 데이터 세트로 언어 기반 물리 애니메이션 모델의 학습을 확장하기 위한 프레임워크인 Super Paddle을 제시합니다. 물리 기반 애니메이션 기술은 시뮬레이션된 캐릭터의 다양한 운동 기능을 재현할 수 있지만, 사용자가 이러한 시뮬레이션된 캐릭터의 동작을 직접 제어하는 ​​것은 매우 어려울 수 있습니다. 자연어는 전문가와 비전문가 모두에게 접근 가능한 표현력이 풍부한 인터페이스를 제공 하지만, 대규모 모션 데이터 세트를 사용하여 언어 기반 컨트롤러를 학습하기 위해 강화 학습을 확장하는 것은 어려울 수 있습니다. 본 연구에서는 물리적으로 시뮬레이션된 캐릭터를 위한 대규모 언어 기반 컨트롤러 학습을 위해 강화 학습에 점진적 지도 증류 방법을 결합한 Super Paddle을 소개합니다. Super Paddle의 컨트롤러는 5,000개 이상의 모션 클립을 포함하는 데이터 세트에서 SKS(Structured Character Strategies)를 재현할 수 있습니다. 본 시스템은 실시간으로 작동하며 사용자의 명령 변화에 상호 작용적으로 반응할 수 있습니다. Super Paddle은 세 단계로 구성됩니다. 첫 번째 단계에서는 데이터 세트 의 모든 모션 클립에 대해 개별 컨트롤러를 학습합니다. 두 번째 단계에서는 데이터 세트를 무작위 그룹으로 분할하고 하이브리드 강화 학습 및 목표 함수 지도 증류를 사용하여 각 그룹에 대해 다중 모션 컨트롤러를 학습합니다. 마지막으로 최종적으로 데이터를 증류합니다. 모든 컨트롤러를 함께 사용하여 각 단계에서 단일 글로벌 세금 조건 컨트롤러를 학습시킵니다. 이를 통해 점진적으로 더욱 범용적이고 강력한 모델을 생성합니다. 최종 컨트롤러는 단순한 이동 기술부터 춤이나 무술과 같은 복잡한 동작에 이르기까지 텍스트 프롬프트에서 수천 가지 동작을 재현할 수 있습니다. 저희 모델을 물리 시뮬레이션 캐릭터를 위한 언어 기반 컨트롤러 학습의 기존 방법과 비교했습니다. 기존 방법은 대규모 데이터셋 학습에 어려움을 겪고 있으며, 저희 모델만큼 높은 품질의 동작을 생성할 수 없습니다. 언어 기반 컨트롤러는 물리 기반 캐릭터 애니메이션의 도입 장벽을 낮추고, 새로운 사용자 경험을 제공하며, 애니메이션 분야 에서 스토리텔링과 표현의 새로운 가능성을 열어줄 잠재력을 가지고 있습니다. 시청해 주셔서 감사합니다.
