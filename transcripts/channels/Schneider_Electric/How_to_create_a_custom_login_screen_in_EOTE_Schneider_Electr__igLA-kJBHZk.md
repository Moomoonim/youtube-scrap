## 스크립트

이 비디오에서는 Opera Terminal Expert에서 여기에 표시된 것과 같은 사용자 지정 로그인 화면을 만드는 방법을 보여드리겠습니다 . 이는 기본 로그인 화면을 대체하는 기능으로, 기본 로그인 화면에서는 비밀번호 변경 버튼을 비활성화할 수 없습니다. 사용자 이름 과 비밀번호, 그리고 보안이 활성화된 숫자 표시 장치로 보안이 이미 설정된 프로젝트부터 시작하겠습니다. 두 번째 화면에서는 사용자 지정 로그인 화면을 구성하겠습니다. 원한다면 콘텐츠 화면에서도 이 작업을 수행할 수 있습니다 . 이 예제에서는 도구 상자에서 텍스트 상자 3개, 문자열 표시기 2개, 스위치 2개를 추가하겠습니다. 첫 번째 텍스트 상자에는 '사용자'를, 두 번째 텍스트 상자에는 '비밀번호'를 입력합니다. 세 번째 텍스트 상자의 경우, 이 예시에서는 'invalid string'이라는 이름의 문자열 변수를 생성하고 바인딩합니다. 이 변수를 사용하면 잘못된 사용자 이름과 비밀번호라는 텍스트가 표시됩니다. 다음으로 스위치로 넘어가서, 두 번째 스위치에는 로그인 텍스트를, 세 번째 스위치에는 로그아웃 텍스트를 추가합니다. 추가적인 설정은 스크립트를 통해 진행됩니다. 다음으로 문자열 표시를 구성합니다. 사용자와 연결된 문자열 표시의 경우 , 현재 값에 target.target01.securitysettings.usernameenter 속성을 바인딩합니다. 그리고 비밀번호와 관련된 문자열 표시를 위해 비밀번호 입력 속성을 바인딩합니다. 그다음, 부품들을 원하는 대로 배열하세요. 이제 스크립트를 사용하여 로그인 및 로그아웃 버튼을 구성할 차례입니다. 먼저 로그인 스크립트부터 시작하겠습니다. 먼저, 로그인 스위치를 참조하여 화면 객체 값을 오른쪽에 두고 터치 트리거를 추가합니다. 아래에는 보안 작업 블록을 추가하고 기본 작업은 그대로 둡니다. 다음으로, 잘못된 사용자 이름 또는 비밀번호 메시지에 대한 if-else 논리 연산을 추가합니다. target.target01.securitysettings.currentsecuritylevel이 0과 같은 비교 조건을 추가합니다. 아래에서는 값 변경 작업을 추가하여 잘못된 [music] 문자열 변수를 잘못된 사용자 이름 또는 비밀번호 메시지로 설정합니다. 그렇지 않은 경우에는 동일한 값 변경 작업을 복사하여 붙여넣지만 메시지는 비워 둡니다. 로그아웃 스크립트는 훨씬 간단합니다. 이 경우에는 로그아웃 스위치에 터치 트리거를 추가하고 로그아웃에 대한 보안 작업을 추가하기만 하면 됩니다. 끝났으면 화면으로 돌아가죠 . 여기서 잘못된 사용자 이름 또는 비밀번호 메시지의 색상을 변경하고, 비밀번호의 경우 기밀 유지를 위해 별표[음악]로 표시되도록 설정하세요. 자, 이제 프로젝트를 테스트해 보겠습니다. 잘못된 사용자 이름이나 비밀번호를 입력하면 오류가 발생합니다. 올바른 정보를 입력하면 해당 내용이 사라지고 숫자 표시창이 잠금 해제됩니다.
