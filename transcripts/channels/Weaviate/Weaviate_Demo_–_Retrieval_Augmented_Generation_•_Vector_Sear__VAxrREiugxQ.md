## 스크립트

안녕하세요 여러분, Weavate Factor 데이터베이스 기반의 검색 증강 생성 데모를 살펴보겠습니다. 이 데모에는 생성 모델과 벡터화 모델이 사용되며, Rack과 밀접하게 관련된 생성 피드백 루프라는 개념도 알아보겠습니다. 이 개념에 대한 설명은 이 블로그 게시물에 있습니다. 저희는 Airbnb 데이터를 사용할 것이며, 이 데이터 역시 이 블로그 게시물에 있습니다. 제가 보여드릴 모든 내용은 여러분 도 직접 시도해 볼 수 있습니다. 이것은 Vivid 콘솔입니다. Vivid 클라우드 서비스에서 실행되는 V8 인스턴스에 연결할 수 있는 곳입니다. 저는 GraphQL을 사용하여 데이터 세트를 검색할 것이지만, Python, JavaScript, Java 등 원하는 언어를 사용할 수도 있습니다. 그럼 이 데이터 세트에 무엇이 있는지 살펴보겠습니다. 이 데이터 세트에는 Airbnb 숙소 목록이 포함되어 있습니다. 여기에는 호스트 이름, 지역, 가격, 객실 유형 등의 UC 정보가 있습니다. 하지만 한 가지 눈에 띄는 점은 설명이 없다는 것입니다. 이는 의도적인 것으로, 이 데이터 세트에는 설명이 포함되어 있지 않습니다. 따라서 저희는 우리가 할 일은 RAG를 적용하는 것이고, RAG는 이런 식으로 작동합니다. 모듈 인비테이터가 이 작업을 대신해 줍니다. 자, 시작해 보겠습니다. ' 생성'을 선택하고, 단일 결과만 표시하도록 지정합니다. 즉, 모든 결과를 처리하는 대신 하나씩 처리합니다. 그런 다음 단일 결과에 대해 프롬프트를 지정합니다. 프롬프트는 제가 준비한 것입니다. 여기 복사해서 붙여넣겠습니다. 기본적으로 " 여기에 에어비앤비 숙소에 대한 간단한 설명을 작성하세요"라고 말하는 것 입니다. 숙소 이름은 이 이름과 연관되도록 정의합니다. 호스트 이름도 포함하도록 지정합니다. 처음 세 개에 대해 이렇게 해보면 실제로 어떤 일이 일어나는지 이해하는 데 도움이 될 것입니다. 이제 쿼리를 실행하고 결과를 확인해 보겠습니다. 여기 보이는 것이 바로 RAG가 작동하는 모습입니다. 이제 숙소 정보와 그 숙소 정보를 기반으로 생성된 결과가 있습니다. 보기 좋은 숙소 설명이 제공되었지만, 문제는... 문제는 아니지만 흥미로운 점은 이것이 마치 일방통행과 같다는 것입니다. 기본적으로 결과를 생성 모델을 통해 전달하고 다시 받는데, 멋진 점은 이 결과를 데이터베이스에 저장 하고 검색할 수 있다는 것입니다. 방법이 있고, 아주 간단한 방법을 찾았습니다. 여기 파이썬 예제가 있습니다. 보시다시피, 똑같은 프롬프트가 있고, 이것은 생성된 콘텐츠로 모든 목록을 업데이트하는 간단한 파이썬 코드 조각입니다. 실행해서 어떤 결과가 나오는지 보겠습니다. 다시 여기로 돌아가서, 이제 이 부분을 완전히 삭제할 수 있습니다. 필요 없으니까요. 이전과 같은 쿼리를 실행해 보겠습니다. 제한을 제거하면 됩니다. 보시다시피, 이제 목록들이 설명 필드에 저장되어 있습니다. 여기서 Review의 벡터화 모듈이 작동합니다. 첫 번째 목록을 보면, 이제 이 목록이 벡터 임베딩되었는지 확인할 수 있습니다. 그러면 결과가 표시될 것입니다. 네, 맞습니다. 첫 번째 목록을 아래로 쭉 스크롤하면 이 목록에 부여한 벡터 임베딩이 있습니다. 이 임베딩을 사용하면 벡터 검색을 할 수 있습니다. 벡터 인덱스와 빔 인덱스를 결합한 하이브리드 검색을 해보겠습니다. 예를 들어 " 공원 근처의 아늑한 장소" 또는 "내 강아지"와 같은 검색어를 입력해 보겠습니다. 검색 버튼을 누르면 쿼리가 벡터화되고, 동시에 하이브리드 검색이 수행되어 결과가 반환됩니다. 보시다시피 "아름다운 공원 옆에 위치한 존의 청소 서비스 부서에 오신 것을 환영합니다"와 같은 결과가 표시됩니다. 좋은 결과라고 할 수 있겠죠. 여기서 흥미로운 점은 원래 데이터 세트에 없었던 설명에 대해서도 벡터 검색을 할 수 있다는 것입니다. 더 나아가서 생성된 설명을 사용하여 또 다른 검색을 수행할 수 있습니다. 생성된 설명을 사용하여 단일 결과를 생성하고 프롬프트로 이동한 다음 다음과 같이 입력할 수 있습니다. 음, 자, 이제 시작해 볼까요? 예를 들어, " 다음 내용이 내 강아지에게 좋은 목록인지 잘 모르겠어요." 또는 "잘 모르겠네요." 같은 식으로 말할 수 있겠죠. 그리고 나서 설명을 원한다고 말할 테니 설명을 가져올 겁니다. 이제 이 코드를 실행하면 쿼리를 벡터화하여 데이터 객체를 반환하고, 생성된 콘텐츠를 사용하여 질문에 대한 답을 찾으려고 시도합니다. 어떤 결과가 나오는지 볼까요? 보시 다시피, 같은 결과가 나왔지만 답변도 함께 제공됩니다. "이 수업은 강아지 훈련에 좋은 선택입니다. 왜냐하면 아파트가 아름다운 공원 근처에 있기 때문입니다." 등등. 이것은 벡터 데이터베이스를 사용하고 벡터 검색을 수행하며 검색 증강 생성 또는 순위 지정을 적용하는 예입니다. 또한, 생성된 피드백 루프라는 개념을 도입하여 랙에서 나온 데이터를 데이터베이스에 다시 저장하여 검색할 수 있도록 했습니다. 도움이 되었기를 바라며, 여러분이 VV8과 이러한 모델 및 모듈을 사용하여 무엇을 만들지 기대하겠습니다.
