## 스크립트

로그인 패널 서버 웹 페이지. 설정, Modbus 장치, [음악] 사용자 지정 모델로 이동하세요. [음악]을 새로운 사용자 지정 모델에 업로드해 봅시다. 이 모델 유형에서 [음악] 장치를 추가하세요 . 사용자 지정 모델은 여러 [음악] 버전으로 존재할 수 있으므로 EPC 웹 도구에서 모델을 약간 수정하고 새 버전을 다시 로드합니다. 이 예시에서는 이 모델에서 측정 항목 하나(음악)를 제거하겠습니다. 지금 [음악] 내보내기를 클릭하세요. 가져오기를 클릭하고 [음악] 최신 버전을 선택하세요. 기기가 이미 이 모델 패널 [음악] 서버에 연결되어 있는 경우, PI S는 해당 기기의 버전을 자동으로 업데이트하지 않습니다. 수동으로 업데이트하려면 ' 버전 전환'보다 큰 옵션으로 이동한 다음 새 버전을 선택하십시오. 모델에 연결된 장치가 없는 경우 이 단계는 불필요합니다. PI S에서 이전 버전의 모델을 제거할 수 있습니다.
