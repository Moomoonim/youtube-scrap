## 스크립트

이번 GitHub Copilot CLI 초보자용 에피소드에서는 MCP(모델 컨텍스트 프로토콜)에 대해 알아보겠습니다. MCP는 에이전트가 코드 작성 외에도 더 많은 작업을 수행할 수 있도록 해주는 개방형 API 표준입니다. 코딩은 단순히 코드를 작성하는 것 이상의 의미를 지닙니다. 테스트 빌드 및 작성과 같은 작업 외에도 관리해야 할 이슈, 생성해야 할 PR, 상호 작용해야 할 데이터베이스 등 여러 가지가 있습니다. 에이전트는 자율적으로 행동할 수 있는 능력을 가지고 있으므로, 이러한 유형의 리소스에 대한 접근 권한을 부여할 수 있다면 매우 좋을 것입니다. 바로 이 지점에서 MCP, 즉 모델 컨텍스트 프로토콜이 중요한 역할을 합니다 . MCP는 AI 에이전트가 상호 작용할 수 있도록 하는 개방형 AI 표준입니다 . MCP를 통해 조직은 문서, 자산 및 기능을 공개하여 AI 에이전트의 기능을 향상시킬 수 있습니다. 이것의 훌륭한 예로는 GitHub Copilot CLI에 이미 내장된 GitHub MCP 서버 , 즉 GitHub MCP 서버를 들 수 있습니다. 이 서버를 통해 GitHub의 문서와 이슈, 풀 리퀘스트와 같은 자산에 모두 접근할 수 있습니다. 제가 즐겨 사용하는 Playwright와 Svelte라는 툴을 통해 MCP 서버 관리 방법과 몇 가지 기능을 소개하고자 합니다. Copilot CLI에서 MCP 서버를 추가하려면 MCP 명령어를 사용합니다. 그러면 인터페이스에서 새 MCP 서버를 추가하라는 메시지가 표시되고, 서버 이름과 MCP 서버를 시작하는 방법에 대한 세부 정보를 제공하도록 요청받게 됩니다. 서버에 접근하는 두 가지 핵심 방법은 서버를 로컬에서 실행하는 것( 일반적으로 NPX를 사용하는 Node를 통해)과 URL을 통해 원격으로 호스팅하는 것입니다. 사용하려는 MCP 서버의 설명서를 참조하여 제공해야 할 세부 정보를 확인하십시오 . 극작가를 추가하려면 먼저 이름을 입력해야 합니다. Playwright MCP 서버는 로컬 서버이므로 해당 옵션은 기본값으로 두고, 문서에서 복사한 NPX 명령어를 사용하여 서버를 시작하겠습니다. Svelte를 추가하는 과정도 동일합니다. 하지만 이번에는 원격 서버이므로 HTTP를 지정하고 해당 원격 서버의 URL을 제공하겠습니다. 다시 말씀드리지만, 그 내용도 문서에서 가져온 것입니다. 이제 Playwright부터 시작해서 각각의 기능을 실제로 어떻게 활용하는지 살펴보겠습니다. Playwright는 웹 애플리케이션을 위한 엔드투엔드 테스트 프레임워크입니다. Playwright MCP 서버를 사용하면 AI 에이전트가 Playwright를 사용하여 웹 앱과 상호 작용할 수 있습니다 . MCP 서버를 사용하면 기능 검증이 가능합니다. Copilot에게 앱 내 필터링 기능을 찾아보도록 메시지를 보내겠습니다. 제 경우에는 Copilot에게 MCP 서버를 사용하도록 명시적으로 지시하고 있습니다. 필수 사항은 아니지만, 저는 AI 비서를 사용할 때 기본적인 철학을 가지고 있습니다. 만약 제가 그 로봇이 무엇을 하는지 확인하고 싶 거나, 알아야 할 필요가 있는 것이 있다면, 저는 항상 그 로봇에게 말해줄 거예요. 그리고 이제 Copilot이 MCP 서버를 사용하는 모습을 볼 수 있습니다 . 사이트를 살펴보고, 사이트와 상호 작용하며, 필터 기능이 존재하고 사용자가 기대하는 대로 작동하는지 확인합니다. 자, 이제 Svelte MCP 서버에 대해 이야기해 보겠습니다. Svelte에 대해 잘 모르시는 분들을 위해 설명드리자면, Svelte는 제가 개인적으로 가장 좋아하는 프런트엔드 웹 프레임워크입니다. Svelte MCP 서버는 문서도 제공하고 앱의 모범 사례를 검토할 수 있는 아주 유용한 기능도 제공하는데 , 바로 제가 원하는 기능입니다. 다시 한번, 이전과 마찬가지로 프롬프트를 보내고 Svelte를 사용하도록 지정합니다. Copilot은 MCP 서버를 사용하여 앱을 검사하는데, 이 경우 생성된 목록의 인덱싱에서 작은 문제를 발견했습니다. Copilot에게 업데이트를 요청했고, 업데이트가 시작되었습니다. 단 몇 분 만에 문제가 해결되었습니다. 적어도 제 코드에는 문제가 있네요. MCP를 통해 Copilot CLI의 기능을 향상시킬 수 있습니다. 외부 문서에 액세스하여 Copilot이 필요한 정보를 항상 최신 상태로 유지하고 , 외부 리소스를 활용하여 사용자를 대신하여 작업을 수행할 수 있습니다. 이를 통해 더욱 강력한 AI 코딩 도우미를 만들 수 있습니다.
