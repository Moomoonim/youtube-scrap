## 스크립트

GitHub Universe 무료 가상 이용권부터 악명 높은 셸 로그에 대한 심층 분석까지 다룹니다. 이 모든 것과 그 이상의 내용을 이번 다운로드 에피소드에서 확인하세요. 최신 개발자 소식과 오픈 소스 프로젝트를 다루는 프로그램, The Download의 새로운 에피소드에 오신 것을 환영합니다. 안녕하세요, 저는 GitHub의 개발자 옹호 담당자인 Kadesh Kerr입니다. 자, 그럼 시작해 볼까요? GitHub Universe가 샌프란시스코에서 개최되기까지 4일 남았습니다. 혹시 모르셨다면 알려드리자면 , GitHub Universe는 올해 무료 가상 패스를 제공하여 집에서 편안하게 기조 연설, 세션 및 워크숍에 참여할 수 있도록 하고 있습니다. 붐비는 곳을 피하는 내향적인 사람이든, 아니면 편안한 슬리퍼 차림으로 코딩하는 것을 선호하는 사람이든, 집을 나서지 않고 참여할 수 있는 좋은 기회입니다. 놓치지 마세요. githubuniverse.com 에서 디지털 패스를 신청하세요 . 그리고 GitHub Universe에 대해 말하자면, GitHub 샵에서 10월 27일에 Universe 컬렉션을 출시합니다. 이 컬렉션에는 스타일리시한 긴팔 티셔츠와 신비로운 소장품이 포함되어 있어 심야 디버깅 세션을 더욱 풍성하게 만들어 줄 것입니다. 온라인 쇼핑이든 오프라인 쇼핑이든, 품절되기 전에 마음에 드는 상품을 구매하세요. 버그를 해결하는 데 이보다 더 확실한 증거는 없을 테니까요 . 인터넷을 구하는 일이 전업 직업이 된 이야기를 다시 한번 살펴보겠습니다. Log Shell을 기억하시나요? 전 세계 디지털 세계에 충격을 안겨준 악명 높은 자바 로깅 라이브러리 결함 . 모든 것은 마인크래프트 메시지 하나에서 시작되었고, 결국 수십억 대의 기기에 영향을 미치는 결함을 해결하기 위해 관리자들이 분주히 움직이는 것으로 끝났습니다 . 러브 포 J의 관리자 중 한 명인 크리스찬은 전 세계적인 관심 속에서 이 문제를 해결하는 데 따른 엄청난 개인적 부담을 털어놓았습니다 . 다행인 점은 GitHub 보안 오픈 소스 기금이 크리스티안과 같은 유지 관리자들에게 교육, 자료 및 자금을 지원하기 위해 나섰다는 것입니다. 목표는 포탄 발사 실패와 같은 불운한 사태가 다시 발생하는 것을 막는 것입니다 . 핵심 교훈은 입력값을 검증하고, 위험한 기본 설정을 비활성화하며, 항상 로컬 관리자에게 친절하게 대하라는 것입니다 . 그들은 인터넷의 숨은 영웅들입니다 . 크리스티안과의 전체 인터뷰는 GitHub의 YouTube 채널에서 시청하실 수 있습니다. 이것으로 이번 주 방송은 마무리입니다. 컨퍼런스부터 위기까지, 이번 주는 개발자 세계에서 지루할 틈이 없다는 것을 증명했습니다 . 다음 시간까지 계속 코딩하시고, 호기심을 잃지 마세요. 그리고 GitHub Universe에서 다시 만나요!
