## 스크립트

대신 GET 메시지를 작성하는 데 너무 많은 시간을 허비하고 계신가요? 안녕하세요, 저는 스튜어트입니다. 오늘은 Amazon Q 개발자 CLI가 워크플로를 개선하는 데 어떻게 도움이 되는지 보여드리겠습니다. Amazon Q 개발자 CLI는 개발 프로세스를 향상시키는 세 가지 강력한 컨텍스트 수정자를 제공합니다. `@ git`은 현재 브랜치, 스테이징 및 스테이징되지 않은 변경 사항, 커밋 기록을 포함한 Git 저장소 상태를 공유합니다. `@EnV`는 로컬 셸 환경 변수를 제공하여 Amazon Q가 사용자의 설정에 대한 통찰력을 얻도록 합니다. `@history`는 Amazon Q에 최근 셸 명령을 보여주어 작업에 대한 컨텍스트를 제공합니다. 이러한 수정자를 통해 Amazon Q는 사용자의 특정 개발 환경을 더 잘 이해하고 더욱 관련성 있고 맞춤화된 지원을 제공할 수 있습니다. 이제 `@git` 수정자를 자세히 살펴보고 Git 커밋 메시지를 개선하는 방법을 알아보겠습니다. 제 프로젝트를 몇 가지 변경했고 이제 커밋을 위해 스테이징해야 합니다. 먼저 `git ad` 명령을 사용하여 새 요구 사항 텍스트 파일과 메인 코드 업데이트를 스테이징합니다. 이제 `Q track` 명령을 사용하여 프롬프트 끝에 `@git` 수정자를 추가합니다. 보시다시피 Amazon Q는 Git 컨텍스트를 분석하여 명확한 메시지를 생성합니다. 모든 변경 사항의 핵심을 간결하게 담아내는 커밋 메시지는 팀에 유용한 정보를 제공하고 깔끔한 커밋 기록을 유지하는 데 도움이 됩니다. ` at` Git 수정자는 Amazon Q Developer CI가 개발 환경이나 컨텍스트를 통합하여 Git 워크플로를 간소화하는 방법의 한 예일 뿐입니다. Amazon Q는 생산성 향상을 위한 맞춤형 지원을 제공합니다. 복잡한 프로젝트를 진행하든, 단순히 더 나은 커밋 메시지를 작성하고 싶든, Amazon Q Developer CLI는 상세한 커밋 메시지를 생성하고, 환경별 조언을 제공하며, 최근 작업 내용을 요약하여 팀 내 협업과 코드 유지 관리를 개선하는 데 도움을 줄 수 있습니다. 지금 바로 Amazon Q Developer CLI를 사용하여 Git 워크플로를 개선하고 팀 협업을 강화하세요. 자세한 내용은 설명을 참조하고 지금 바로 시작하세요.
