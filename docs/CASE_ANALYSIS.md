## B. 문제 상황 — 코퍼스가 진술하는 개입 이전

- **AIG**: 상업 언더라이팅이 사업의 70%인데 **50년간 프로세스 불변**. 미국 보험의 주 단위 규제로
  데이터 표준 부재 → 브로커별 불일치·깨진 PDF·레거시. 언더라이터가 **5~10개 문서, 최대 100페이지**를
  검토해 건당 **3~4주**. 그 결과 **접수된 모든 건을 검토하는 것이 사실상 불가능**하고, 경쟁사도 같은
  건을 견적하므로 **속도가 곧 수주**다
- **미 국무부**: 종이 차트 → 코로나 대응 엑셀. **15년간 세 번 좌초한 EHR**. 상용 EHR은 "청구 최적화"
  설계라 부적합
- **일반 진술**(2025-01): "계획과 실행의 간극", 아웃오브더박스 소프트웨어의 부적합

## C. 개입의 메커니즘

```
원천 데이터(브로커 PDF·엑셀·DB·도면·계약)
   ↓ 인제스천 — 언더라이팅 결정을 좌우하는 약 100개 속성 자동 추출
온톨로지 (고객 고유의 사물·개념·관계 지도)
   ↓ 증강 — 내외부 소스 자동 검색·검증·보강
   ↓ RAG — 프롬프트+쿼리 생성 → 관련 컨텍스트 반환(검색 벡터 제한) → LLM이 출처 청크와 함께 응답
인간(언더라이터) — 확인·수정  ← "human in the loop"
   ↓ 우선순위 부여
결정 → 실행 이력이 온톨로지로 되먹임(R1 진술)
```

**세 겹의 구조가 반복된다.** ① 데이터 계층을 온톨로지로 재조직 → ② 에이전트가 그 위에서 작동 →
③ 결정 이력이 다시 온톨로지에 축적. AIG의 **다섯 원칙**(단일 유스케이스 집중 · 현업 공동 설계 ·
human in the loop · 에이전틱 모듈 아키텍처 · 사전 정의 지표로 측정)이 이 메커니즘의 도입 규범이다.

**조직 측면**: GE Aerospace 증언에 따르면 단일 온톨로지 레이어를 갖는다는 것은 제품별 정렬을 버리고
**전사 차원의 "내부 대화를 강제"**하는 일이며 "매우 어려운 과제"다. Kavanaugh는 6개월 집중 계약 후
6개월 연장했고, 결국 "다른 모든 소프트웨어가 존재를 정당화해야" 하는 상태로 간다.

**평가 계층**(AIP Evals): 모델×프롬프트 그리드 서치 → 실패 테스트케이스가 에이전트 디버깅 플로로
피드백 → 프롬프트 개선안 제안. ⚠️ 그러나 **전수 검토는 스케일되지 않고**, 해법은 에이전트가
에이전트를 디버그하는 재귀다.

**관측 계층**(Observability): 함수 실행 이력·트레이스·**토큰/비용 메트릭**·OpenTelemetry 커스텀 스팬.
⚠️ 알림·페이징은 2025-09 시점에 **로드맵**.

# 2. Zapier — 분모의 사유화

| **분석 단위** | **한 회사가 모델 평가 기준과 인간 숙련 기준을 동시에 소유할 때의 효과** |
| 코퍼스 | 135편 / `ax_core` 119편(**88%, 전 채널 최고 밀도**) / anti-wash 99 |

## B. 문제 상황

- 사내 도입률이 **GPT-4 이전 한 자릿수**였다(CEO 자기 기준선)
- 외부 진단: **"AI 도입의 80%가 실패하는 이유는 어떻게·왜 써야 하는지 아무도 가르쳐주지 않기 때문"**
- 자사 진단: **"우리는 초기에 강한 운영모델을 만드는 데 실패했다"**(GTM 리드)
- 상담 사례의 **"열에 아홉은 실제로 AI가 필요 없었다"**(호스트) — 지난 10년의 결정론적 자동화로 충분

## C. 개입의 메커니즘

**세 개의 계층을 한 회사가 운영한다.**

```
① 연결 계층 — 9,000개 앱 통합, MCP, Skills
② 평가 계층 — Automation Bench
      영업·마케팅·재무·인사 도메인에서 600개 과제 구성
      ├ 과제 선정: Zapier에서 관찰된 워크플로 유형 中 "가장 어려운 세트"를 의도적으로 선택
      ├ 실행: 테스트 대상 모든 모델에 600개 전부 실행 후 채점
      ├ 측정 제외: 챗봇 지연 시간
      ├ 비용 기준: 협상가 아닌 공개가, "절대 비용보다 상대 비용"
      └ 데이터셋: 비공개(학습 오염 방지 명분 / 외부 검증 불가 결과)
③ 숙련 계층 — AI Fluency Framework
      단계: activated → adaptive → transformative ("아무도 4단계로 건너뛰지 않는다")
      구성: 절반이 기술 역량, 절반이 질문·판단·이해관계자 인식
      적용: 2025년 봄부터 지원자 100% · 직무 100%
      배포: 오픈소스 공개 → 외부 기업(Orium) 인사 운영에 실제 이식 확인
      확장: 1차 스크리닝을 인간 리크루터 / AI 에이전틱 리크루터 중 선택
```

**실무 계층(회계팀)의 운영 규범**
- 150개 이상 자동화·에이전트(이메일 수신함, 월말 결산, 매입채무, 규정 준수)
- **신뢰 구축 절차**: "여러 번 실행 → 예외 상황 파악 → 전부 검증 → 그제서야 담당자를 시스템에서 제외"
- **절대 원칙**: "회계와 관련된 어떤 사안도 인간의 승인 없이 AI가 최종 결정을 내리지 않는다"
- **자동 게시를 켤 수 있지만 켜지 않는다** — "제한 사항이 아니라 우리의 감사 증거"
