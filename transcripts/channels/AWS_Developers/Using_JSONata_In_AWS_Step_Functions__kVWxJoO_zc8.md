## 스크립트

AWS Step Functions에서 데이터를 더 쉽게 쿼리하고 싶으신가요? 안녕하세요, 저는 AWS Step Functions의 수석 개발자 겸 옹호자인 Eric Johnson입니다. 개발자들은 AWS Step Functions에서 JSON 경로를 사용할 때 많은 추가 단계나 전환을 거치지 않고 원하는 데이터를 얻기가 어렵다고 말합니다. 이제 Jonata 지원이 AWS Step Functions에 추가되어 훨씬 쉬워졌습니다. Jonata는 워크플로에서 데이터를 선택하고 변환하는 강력한 쿼리 및 표현 언어입니다. 상태 수준 또는 함수 수준에서 JSON을 사용할 수 있습니다. 이제 작업 자체에 어떤 변화가 있는지 살펴보겠습니다. 실제로 작업이 상당히 간소화되었습니다. 이전에는 입력 경로, 매개변수, 결과 선택기, 결과 경로, 출력 경로가 있었지만, 이제는 인수와 출력만 있습니다. 하위 흐름에 대한 작업 실행 전 인수, 실행 후 출력, 훨씬 간소화된 테스트 등이 가능합니다. 구문도 업데이트되었습니다. 다음 예제를 살펴보겠습니다. 여기서는 전체 이름을 사용하고 있습니다. 이름과 성을 결합하여 전체 이름을 얻으려고 합니다. 전체 이름은 동적 데이터이지만 더 이상 달러 기호($)를 사용하지 않고 전체 이름을 그대로 사용합니다. 이름 키를 입력한 다음, 이름과 성을 결합하여 문자열 "The Jon am"을 만듭니다. 그리고 중요한 부분은 문자열을 중괄호로 묶고, 시작과 끝에 퍼센트 기호(%)를 붙이는 것입니다. 이렇게 하면 Step Functions에게 이것이 Jonata임을 알려주고 JSON 형식으로 파싱하도록 지시합니다. JSON에는 몇 가지 예약 변수가 있습니다. Step Functions 환경에서는 생소할 수 있는 용어를 사용하는데, 새로운 Step Functions 워크플로 변수에 대해 들어보지 못했다면 아래 링크된 관련 영상을 확인해 보세요. Jonata에서도 이러한 예약 변수를 사용하며, 앞으로 나올 예제에서도 몇 가지를 보게 될 것입니다. 이 특정 예약 변수는 `states` 예약 변수 이며, 상태를 입력값으로 사용합니다. 입력값에는 상태에 대한 원시 입력값이 포함되므로, 원시 입력값을 빠르게 얻을 수 있는 방법입니다. 그러면 상태값을 바로 확인할 수 있습니다. 작업이 성공하면 결과(results)가 표시되고, 실패하면 오류 출력이 표시됩니다. 마지막으로 컨텍스트(context)가 표시되는데, 이는 JSON Path와 동일합니다. JSON Path에서는 JSON 네이티브 함수, 문자열 함수, 숫자 함수, 숫자 집계 함수, 배열 함수, 객체 함수 등 다양한 함수를 사용할 수 있습니다. 나열하자면 끝이 없겠지만, AWS Step Functions용 ​​JSON Path에서는 내장 함수를 대체하는 함수들도 제공됩니다. 예를 들어, ` partition` 함수는 큰 배열을 분할하고, `range` 함수는 값 배열을 생성하며, `hash` 함수는 주어진 입력의 해시값을 계산하고, ` random` 함수는 난수를 생성하고, `uu ID` 함수는 고유 ID를 생성한 다음 JSON 문자열로 파싱합니다. 이처럼 JSON에 내장된 모든 강력한 기능을 활용할 수 있습니다. 자, 그럼 몇 가지 예제를 살펴보겠습니다. 첫 번째 예는 제가 사용하는 워크플로로, 여러 레코드가 있는 데이터베이스를 마이그레이션하고 소유자를 한 이메일에서 다른 이메일로 변경해야 하는 경우입니다. 우선 변경할 ID가 필요하므로, 해당 ID는 states에서 가져오겠습니다. 입력. 네 번째 줄을 보시면 달러 기호 없이 ID가 있고, 앞뒤에 Cur Q 퍼센트 기호가 있어서 이를 식별합니다. 그리고 맨 아래로 내려가서 현재 날짜를 생성하려고 하는데, 이 날짜가 업데이트된 시점이기 때문입니다. Now 함수를 사용하면 다른 곳에서 날짜를 가져오거나 Lambda 함수로 내보낼 필요 없이 중간에 바로 Now 함수를 사용할 수 있습니다. 마지막으로 13번째 줄에서 new owner라는 변수를 사용하는데, 여기서 new owner는 달러 기호와 new owner가 합쳐진 형태입니다. 이 변수는 기존 소유자의 ID를 가져옵니다. 또 다른 예로, 같은 레코드에서 모든 레코드의 변경 사항을 출력해야 하는데, 각 레코드의 전체 내용이 필요한 것이 아니라 ID, 이전 소유자, 새 소유자만 필요한 경우를 생각해 보겠습니다. 이때 중괄호와 퍼센트 기호, 그리고 달러 기호를 사용하여 JSON 데이터를 가져올 수 있습니다. 저는 실제로 그 데이터를 ' Dot'이라는 변수에 저장하고, 각 레코드에서 원하는 데이터가 담긴 템플릿을 변수에 전달합니다. 그러면 해당 배열을 순회하면서 매핑을 통해 ID를 가져올 수 있습니다. 문자열을 사용하고, 특히 Dynb에서 변수에서 이전 소유자 와 새 소유자를 가져옵니다. 이렇게 하면 방대한 데이터가 담긴 거대한 레코드 배열을 빠르고 간결한 변경 세트로 변환하여 어떤 레코드가 변경되었는지 알려줄 수 있습니다. Jonata를 사용하면 훨씬 더 많은 기능을 보여드릴 수 있지만, 이것은 간단한 개요일 뿐입니다. 문서를 읽고 워크플로 스튜디오를 사용해 보면서 Jonata에서 제공하는 힌트와 인텔리센스 기능 등을 살펴보시길 바랍니다. 이와 같은 영상을 더 보고 싶으시다면 채널을 구독해주세요. 특히 이 영상과 함께 볼 수 있는 변수 관련 영상도 꼭 시청해 보세요. 변수와 Jonata는 함께 사용하면 전환 및 워크플로 작업을 훨씬 효율적으로 만들어 줍니다. 제 이름은 에릭 존슨입니다. 좋은 하루 보내세요.
