## 스크립트

터미널의 Copilot CLI부터 MCP 레지스트리 출시까지, 개발자들은 그 어느 때보다 빠르게 코딩하고, 협업하고, 혁신할 수 있는 강력한 새로운 도구를 얻게 되었습니다 . 이 모든 것과 그 이상의 이야기를 이번 The Download 에피소드에서 만나보세요. [음악] 최신 개발자 소식과 오픈 소스 프로젝트를 다루는 프로그램, The Download의 새로운 에피소드에 오신 것을 환영합니다. 안녕하세요, 저는 GitHub의 개발자 옹호 담당자인 카데샤카 커입니다. 자, 그럼 시작해 볼까요? GitHub Copilot은 오랫동안 Internet Explorer에서 믿음직한 조력자 역할을 해왔지만, 이제 망토를 두르고 명령줄로 바로 뛰어듭니다. 공개 미리보기로 제공되는 새로운 Copilot CLI는 유전 알고리즘 AI를 로컬 환경에서 바로 사용할 수 있도록 해줍니다. 설치하고 인증만 하면 바로 사용할 수 있습니다 . 마치 코딩에 정통한 친구가 있어서 오타를 절대 지적하지 않고 main.py 파일이 어디에 있는지 항상 알고 있는 것과 같습니다 . MCP를 통한 긴밀한 GitHub 통합 덕분에 Copilot CLI를 사용하면 터미널을 벗어나지 않고도 이슈를 조회하고, 기능을 구현하고, 풀 리퀘스트까지 생성할 수 있습니다 . 게다가, 당신은 언제나 모든 것을 통제할 수 있습니다. 모든 변화는 여러분의 승인을 기다립니다 . 자, 한번 시도해 보시고 얼마나 빨리 배송할 수 있는지 확인해 보세요. 그리고 만약 그게 멋지다고 생각했다면, 키보드를 꽉 잡으세요. GitHub MCP 레지스트리가 여기 있으니까요. 적합한 MCP 서버를 찾는 것은 마치 해시 스택에서 세미콜론을 찾는 것과 같았습니다. GitHub MCP 레지스트리에 접속하세요. MCP 서버를 찾을 수 있는 새로운 원스톱 플랫폼입니다. 탐색은 간편하고, 설치는 클릭 한 번이면 되며, 레지스트리는 상호 운용성을 고려하여 설계되었습니다. Figma 컨텍스트, Postman API, Terraform 인프라 또는 Dinatra의 관찰 가능성을 통합하든 관계없이 레지스트리는 커뮤니티 기여를 통해 성장할 것이며, 곧 자체 게시가 원활해져 개발자 세계가 더욱 친근하고 개방적인 공간이 될 것입니다. 훌륭한 모델 선택 도구를 좋아하는 분들을 위해, 에이전트 코딩에 최적화된 OpenAI의 GPT5 코덱과 Claude Opus 4.1이 이제 GitHub Copilot에서 제공됩니다 . 자세한 사항은 공식 문서를 참조하십시오 . 그리고 여러분의 코딩 시간이 더욱 더 멋지기를 바랍니다. 인공지능 어시스턴트가 여러분의 코드베이스, 문서, 또는 진짜 답이 담긴 슬랙 스레드를 알고 있었으면 좋겠다고 생각해 본 적 있으신가요? Copilot Spaces가 출시되었습니다. Teams에서 컨텍스트 모음을 구성하여 필요한 위치에 정확하게 AI 응답을 배치할 수 있습니다. MCP 원격 서버를 통한 원활한 IDE 통합 덕분에 워크플로우를 벗어나지 않고도 전문가의 도움을 받을 수 있습니다. 초기 사용자들은 이미 쿼리 언어부터 테스트 생성에 이르기까지 모든 것에 대한 맞춤형 도우미를 구축하고 있으며, 이는 일반적인 전문가가 아닌 특정 분야의 전문가가 필요할 때 유용합니다 . Copilot Spaces는 여러분과 여러분의 상황을 지원합니다. OpenAI와 엔비디아는 차세대 AI 모델 구동을 위해 무려 10가와트 규모의 엔비디아 시스템을 구축할 계획을 발표했습니다 . 그 정도 전력이면 작은 나라 하나에 전력을 공급하거나, 적어도 아주 똑똑한 신경망을 훈련시키기에 충분합니다. 엔비디아가 최대 1,000억 달러를 투자하고 2026년에 1단계가 시작될 예정인 이번 파트너십은 인공지능 초 지능과 세계 최대 규모의 'Hello World' 프로그램 구현의 발판을 마련할 것입니다. 지금도 건설 시간이 빠르다고 생각하셨다면, 이 전력망에 연결되면 얼마나 더 빨라질지 기대해 보세요. 기본 채팅 설정에 만족하지 마세요. 최고의 성능을 경험해 보세요! 이 VS Code 팁에서는 GitHub Copilot용 사용자 지정 채팅 모드를 만드는 방법을 보여줍니다 . 코딩 스타일에 맞춰 프롬프트와 설정을 조정하세요 . 어려운 작업에 도전하고 싶으신가요? 짐승 모드로 돌입하세요. 빠른 답변이 필요하신가요? GPT5 Mini의 강력한 모드를 사용해 보세요 . 이 요약을 공유해 주신 버크 홀랜드에게 진심으로 감사드립니다 . 이제 담당 에이전트는 원하는 만큼 적극적이거나 차분하게 행동할 수 있습니다. 코드를 활성화하고 승리하세요. 꿈꾸는 사람들, 만들어내는 사람들, 그리고 공짜 간식을 좋아하는 모든 분들! 샌프란시스코 에서 열리는 GitHub Universe 2025 티켓을 받을 수 있는 절호의 기회입니다 . 한 명의 행운의 개발자에게는 세션, 데모, 자격증 취득 등 다채로운 프로그램으로 가득한 2일간의 행사에 참여할 수 있는 일반 입장권이 제공됩니다 . 경품 행사에 참여하고 행운을 빌어보세요. 어쩌면 업계 최고 전문가들과 직접 만나 네트워킹할 기회를 얻게 될지도 모릅니다. 샌프란시스코에 계시지 않나요? 걱정 마세요. 가상 티켓은 무료이며, 화면을 통해 현장의 흥분을 그대로 전달합니다. 이것으로 이번 주 주요 소식을 마무리하겠습니다. 열정을 유지하고, 호기심을 잃지 마세요. CLI든, IDE든, 아니면 우주 전체든, GitHub는 모든 개발자를 위한 무언가를 준비하고 있다는 것을 기억하세요 .
