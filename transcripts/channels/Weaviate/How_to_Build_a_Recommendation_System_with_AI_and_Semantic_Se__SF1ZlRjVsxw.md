TS 엔드포인트는 요청 본문에서 쿼리를 추출한 다음 이를 거의 텍스트 객체로 웹 클라이언트에 전달하고 검색과 거의 동일한 방식으로 책 벡터를 쿼리합니다. py는 결과를 클라이언트로 다시 전송하며, 이 결과는 Nextjs 애플리케이션의 상태 변수에 저장되도록 이미 설정되어 있습니다. 추천 그리드는 근접 텍스트 쿼리를 통해 얻은 시맨틱 검색 결과에서 가져온 책 목록과 함께 표시됩니다. 이 책들은 '추천 도서' 변수에 저장되어 있습니다. 인덱스의 JSX에서 쿼리가 수행된 후, 추천 도서 목록을 순회하며 추천 그리드를 나타내는 관련 div를 반환합니다. 그리드는 flex wrap div로 스타일링되어 있어 행이 채워지면 부모 컨테이너로 확장되고 감싸집니다. 추천 목록을 순회하면서 책의 썸네일, 제목, 그리고 책에 대해 자세히 알아보기 버튼과 같은 책 세부 정보를 화면에 표시합니다. 버튼을 탭하면 모달이 화면에 나타납니다. 모달에는 책을 선택하고 상태 변수에 저장하는 로직이 있으며, 모달이 화면에 표시되도록 하는 추가 상태 변수도 설정되어 있습니다. 모달의 작동 방식을 간략히 살펴보면, '자세히 알아보기' 버튼을 클릭하면 '모달 열기' 함수가 트리거되어 책 세부 정보를 받습니다. 어떤 책이 선택되었는지 확인 하고, 해당 책을 선택된 책 상태 변수에 저장합니다. 또한 모달의 표시 여부를 관리하는 상태 변수(모달 열림)도 만들 것입니다. 이 상태가 true로 설정되면 모달이 화면에 표시됩니다. 이 모달에는 책의 썸네일, 저자 정보, 장르, 평균 평점, 출판 연도, 책 설명이 포함되며, 이 모든 정보는 선택된 책 상태에서 가져옵니다. 또한 해당 책의 ISBN(국제 표준 도서 번호)이 있으므로, 클릭 시 아마존 검색 결과에 해당 책을 표시하는 간단한 쿼리를 실행할 수 있습니다.
