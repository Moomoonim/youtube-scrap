## 스크립트

안녕하세요 여러분, GitHub Copilot CLI 초보자 시리즈에 다시 오신 것을 환영합니다. 이 영상에서는 CLI 명령어 전체 개요를 살펴보겠습니다. 자 , 그럼 시작하겠습니다. {슬래시} 명령어는 Copilot CLI 내의 제어 인터페이스입니다. 이러한 기능은 사용자가 웹사이트를 조종하고, 변경 사항을 검사하고, 컨텍스트를 관리하고, 세션을 전환하고, 권한을 깔끔하게 유지하는 데 도움이 됩니다. 가장 인기 있는 것들 몇 가지를 빠르게 살펴보겠습니다. 모든 {슬래시} 명령어를 보려면 {슬래시}를 입력하고 스크롤하여 옵션을 살펴보세요. 사용하는 모델을 변경하려면 {슬래시} 모델을 입력하세요. 여기에서 사용 가능한 모델 목록을 확인 하고 작업에 따라 원하는 모델을 선택할 수 있습니다 . 일부 모델은 리팩토링과 같은 빠르고 간단한 작업에 적합하고, 다른 모델은 기능 계획과 같은 심층적인 추론에 더 적합합니다 . 이 목록은 새로운 모델이 출시됨에 따라 변경될 수 있으며, 사용 중인 요금제와 조직에서 활성화한 기능에 따라 달라집니다. 오른쪽에 있는 숫자는 비용 배율을 나타내므로, 어떤 모델이 플랜에 포함되어 있고 어떤 모델에 추가 비용이 발생하는지 확인할 수 있습니다. 모델을 선택하셨으니 이제 토큰 사용량을 살펴보시는 것이 좋습니다. 그렇게 하려면 컨텍스트를 입력하세요. 이 화면에서는 남은 토큰 수와 시스템 여유 공간 및 버퍼 용량을 확인할 수 있습니다. 컨텍스트 내에서 더 많은 공간을 확보하려면 {슬래시} compact를 입력하여 대화를 요약하고 새 세션을 시작하지 않고 계속 진행할 수 있습니다. Copilot CLI의 가장 큰 장점은 사용량 한도에 도달하기 시작하면 자동으로 이 작업을 수행해준다는 것입니다 . 프로젝트의 새로운 부분으로 넘어가는 경우 수동으로 수정할 수도 있고, 완전히 처음부터 다시 시작하려면 `/`를 사용할 수도 있습니다. 이전 세션을 이어서 하려면 {슬래시} resume를 입력하세요. 이렇게 하면 로컬 세션과 원격 세션을 포함하여 이전에 참여했던 세션 목록이 표시됩니다. 이전 세션에 들어가면 세션 기록이 표시되고 동일한 컨텍스트에서 작업을 계속할 수 있습니다. Copilot을 사용하여 프로젝트를 변경한 후에는 `{/} diff` 명령어를 실행하여 변경 사항을 확인할 수 있습니다 . Copilot을 종료하지 않고 다른 프로젝트 작업을 시작하려면 `{/} cwd`를 입력하여 작업 디렉토리를 다른 저장소로 변경할 수 있습니다. 또한, Copilot의 작업 범위를 프로젝트의 특정 부분으로 제한하려면 저장소 내에서 이 기능을 사용할 수도 있습니다. 마지막으로, 예를 들어 " 이 세션에서 항상 파일 편집 허용"과 같이 특정 도구에 대한 권한을 허용했지만, 다른 저장소로 이동하여 더욱 신중하게 작업하고 싶을 때 해당 권한을 취소하려면 `{/} reset allowed tools` 명령어를 실행하여 도구 승인을 재설정할 수 있습니다. 이러한 {슬래시} 명령어를 사용하면 Copilot CLI를 더욱 세밀하게 제어할 수 있으므로 목록에 있는 다른 명령어와 함께 꼭 확인해 보세요.
