## 스크립트

이 튜토리얼에서는 Oracle Analytics Cloud에서 RPD 파일을 사용하여 시맨틱 모델을 공유하는 방법을 알아봅니다 . 시맨틱 모델 개발자는 여러 OAC 인스턴스 에서 동일한 주제 영역이 필요할 때 모델을 공유합니다 . 내보내기 및 가져오기를 하면 별도의 복사본이 생성되므로 공유에는 유용하지만 인스턴스 간 변경 사항이 동기화되지 않아 공동 작업에는 적합하지 않습니다. 이 시나리오에서는 제 OAC 인스턴스 에서 공급망 시맨틱 모델을 RPD 파일로 내보내고 동료와 공유하여 동료가 자신의 인스턴스로 가져오도록 하겠습니다. 제 홈페이지부터 설명드리겠습니다. 네비게이터를 열고 시맨틱 모델을 선택하겠습니다. 공유하고 싶은 공급망 모델을 찾아서 열겠습니다. 여기서는 주제 영역, 논리적 및 물리적 계층, 연결 관계와 같은 세부 정보를 확인할 수 있습니다. 페이지 메뉴를 열고 내보내기를 선택하겠습니다. 이름은 그대로 두고 내보내기 유형으로 저장소 문서 파일(RPD)을 선택하겠습니다 . 이제 파일을 보호하기 위해 비밀번호를 입력해야 합니다 . 제가 동료와 내보내기 파일을 공유할 때, 이 비밀번호를 함께 알려드리겠습니다. 마지막으로 내보내기를 선택하겠습니다. 페이지 하단에서 내보내기 진행 상황을 확인할 수 있습니다. 완료되면 '내보내기 성공'을 선택하고 '로그 보기'를 클릭하여 오류나 경고가 있는지 확인합니다. 그다음에는 다운로드를 선택해서 RPD 파일을 제 기기에 다운로드하겠습니다. 파일을 받았으니 동료와 공유해서 불러올 수 있도록 하겠습니다. 이 페이지는 제 동료의 홈페이지입니다. 이제 그들에게 있어서 가져오기 과정이 어떻게 진행되는지 보여드리겠습니다. 홈페이지에서 시작해서 ' 생성'을 선택한 다음 '시맨틱 모델'을 선택하겠습니다. 모델에 이름을 지정하고 만들기를 선택하겠습니다. 시맨틱 모델 생성 페이지에서 RPD 파일을 사용하고 있으므로 파일 가져오기 옵션을 선택하겠습니다 . 내 기기에서 공급망 모델 RPD 파일을 찾아서 열기를 선택하겠습니다. 모델 잠금을 해제하기 위해 내보내기 과정에서 설정한 비밀번호를 입력하겠습니다. 그럼 이제 가져오기를 선택하겠습니다. 가져오기가 완료되면 확인을 누르겠습니다. 주제 영역 및 모델 계층을 포함한 공급망 의미 모델 사본이 이제 이 인스턴스에서 사용 가능 하며 새로운 분석을 수행할 준비가 되었습니다. 제 인스턴스에서 시맨틱 모델을 내보내고 다른 인스턴스로 가져왔으므로, 이제 저와 제 동료는 동일한 공급망 주제 영역의 사본을 각각 갖게 되었습니다 . 그래서 우리는 각자의 환경에서 독립적으로 일할 수 있습니다. 아래 링크에서 이 시리즈의 다른 비디오와 Oracle Analytics Cloud 사용에 대한 추가 자료를 찾아보세요.
