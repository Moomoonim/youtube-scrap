## 스크립트

Weeviate Gorilla 프로젝트를 소개하게 되어 매우 기쁩니다. 저희는 오픈 소스 Llama(70억 개 매개변수를 가진 대규모 언어 모델)를 미세 조정하여 자연어 명령어를 Weeviate의 GraphQL 검색 API로 변환하도록 했습니다. 이렇게 대규모 언어 모델들을 저희 Gorilla와 연동시켜 Weeviate를 더욱 효과적으로 활용할 수 있도록 했습니다. Gorilla는 검색 인식 미세 조정을 통해 특정 API 세트에 특화된 소규모 언어 모델입니다. 이 프로젝트는 자연어 명령어를 Weeviate의 GraphQL API로 변환함으로써 사용자가 Weeviate를 더 쉽게 사용할 수 있도록 하는 좋은 부수적인 효과도 있습니다. 예를 들어, 합성 쿼리를 사용하는 방법이나 실행 가능한 모든 쿼리를 익히는 데 드는 학습 곡선을 줄여줍니다. 또한, 이 프로젝트는 쿼리 라우터 역할도 합니다. SQL 쿼리와 벡터 검색을 결합하는 것에 대한 흥미로운 논의가 많은데, Gorilla는 자연어 명령어를 입력받아 이러한 기능을 바로 사용할 수 있도록 제공합니다. 그리고 SQL 스타일이나 게이트 쿼리처럼 기호 집계를 수행하는 집계 쿼리를 완화할 수 있는지 여부, 벡터 검색을 수행한 다음 벡터 검색 결과에 대해 기호 집계를 수행하는 멋진 트릭샷 등 다양한 흥미로운 기능들을 살펴볼 수 있습니다. 이 프로젝트는 LLM과 도구 사용의 미래에 대해 궁금하다면 소프트웨어 전반에 걸쳐 흥미로운 내용을 담고 있다고 할 수 있습니다. API 세트가 있고, 자체 지시 프롬프트를 사용하여 학습 데이터 세트를 생성하는 방법, 허깅 페이스 어메이징 패스 라이브러리를 사용하여 Llama 7B를 미세 조정하는 방법, Substratus를 사용하여 Kubernetes와 K8 학습을 오케스트레이션하는 방법, 결과 시각화, 그리고 이러한 유형의 평가를 어떻게 생각하는지 등을 확인할 수 있습니다. 마지막으로, 토론에서 더 자세히 다루겠지만, 서두에서 간단히 언급하고 싶은 것은 이 프로젝트가 소프트웨어 통합에 미칠 수 있는 영향입니다. 자연어 명령을 사용하여 Llama 인덱스를 활용한 질문 답변 시스템을 구축하는 것을 상상해 볼 수 있습니다. Weviate는 시각화 및 스트림릿 기능을 제공하며, OpenAI의 코드 인터프리터처럼 파일을 입력 하고 그래프로 만들어 달라고 요청할 수 있습니다. 저희는 코드를 작성하고 V8과 같은 특정 라이브러리를 사용하는 LMS에 상당히 가까워지고 있습니다. 그래서 이 프로젝트는 정말 흥미롭고 즐겁게 작업했습니다. 자세히 살펴보겠습니다. 이 영상은 Weviate Gorilla 프로젝트를 설명하며, 시각적인 요소를 더해 소개를 이어가겠습니다. 핵심 아이디어는 LOM(Learning Object Model) 도구를 사용하여 대규모 언어 모델을 외부 도구와 연결함으로써 모델의 기능을 강화하고 생산성을 높이는 것입니다. 예를 들어 " 지금 보스턴의 날씨는 어떻습니까?"라는 질문에 답하려면 언어 모델링, 인터넷, 심지어 인간의 피드백을 통한 강화 학습에만 의존해서는 안 됩니다. 이러한 질문에 대한 새로운 해결책은 대규모 언어 모델을 타사 API와 연결하는 것입니다. 대규모 언어 모델과 날씨 API를 연결하여 대규모 언어 모델이 날씨 API와 통신할 수 있도록 하는 것입니다. API 호환 방식으로 요청 형식을 지정해야 합니다. 예를 들어, 이 API는 ' 도시'라는 입력 인수에 '보스턴 매사추세츠'와 같은 문자열을 기대하거나, 우편번호를 기대하는 경우가 있을 수 있습니다. 우편 번호를 입력받아야 하는 경우, 대규모 언어 모델이 특정 구문에 맞춰 요청을 포맷하는 방법을 학습해야 합니다. 만약 API가 '보스턴 매사추세츠'라는 문자열을 기대하는데, 대규모 언어 모델이 ' 02210'과 같은 응답을 반환한다면, API는 응답하지 못할 뿐만 아니라 날짜 인수도 처리하지 못할 수 있습니다. API는 특정 구문을 기대하며, 대규모 언어 모델이 이 구문을 따르도록 해야 합니다. 날씨 API 예시는 비교적 간단하지만, 웹 기반 API는 이보다 훨씬 복잡합니다. 핵심은 대규모 언어 모델을 이러한 외부 도구들과 연결하여 성능을 향상시키고, 최신 정보를 유지하며, 연산을 수행할 수 있도록 하는 것입니다. 따라서 대규모 언어 모델을 계산기, 코드 실행기, 검색 엔진, 데이터베이스는 물론 날씨 API나 개인 캘린더와 같은 도구들과 연결합니다. 대규모 언어 모델은 우리 삶의 조종사이자 조력자가 되어가고 있습니다. 그럼 자세히 살펴보겠습니다. 이 프로젝트에서는 Weviate를 대규모 언어 모델 도구로 활용하기 위해, 이미 데이터 스키마 와 데이터가 로드된 Weviate 인스턴스가 실행 중이라고 가정합니다. 그리고 이 실행 중인 데이터베이스에 대한 API 요청 및 검색 요청 형식을 지정하는 방법을 배우고 있습니다. 나중에는 대규모 언어 모델이 새로운 클래스를 생성하고, 새로운 데이터를 채우는 등 더욱 확장된 아이디어에 대해 논의할 것입니다. 예를 들어, 상당히 복잡한 Weviate 쿼리를 포함하는 자연어 명령이 있다고 가정해 보겠습니다. " 최대 거리가 0.15인 전사 자세와 유사한 요가 자세의 평균 복잡도는 얼마입니까?" 이 명령을 Weviate 쿼리로 변환합니다. 여기서 요가 자세 클래스를 집계하고, 벡터 검색을 사용한 다음, 기호 집계를 통해 벡터 검색 결과의 평균 복잡도를 얻습니다. 이 쿼리는 다소 복잡해 보일 수 있으며, 많은 Weviate 초보 사용자가 이러한 기능을 알지 못할 수 있습니다. 이와 같은 다른 기능도 있습니다. 핵심 아이디어는 자연어 명령을 이러한 쿼리로 변환하는 것입니다. 이를 위해 자연어 명령을 입력으로 받는 학습 데이터 세트를 생성해야 합니다. 집계, 벡터 검색으로 구성된 이 기능에 대한 API 참조는 다음과 같습니다. 급증(Surge) 현상을 살펴본 후, 반환된 Wevia 클래스의 특정 속성 결과의 평균을 계산하고, 요가 자세에 대한 사용자 지정 스키마를 활용합니다. 이 스키마에는 복잡성 수준과 같은 속성뿐만 아니라 벡터 검색을 통해 전사 자세를 검색할 수 있는 벡터화된 속성도 포함되어 있습니다. 이미 아시다시피, 대규모 언어 모델이 도구를 더 쉽게 사용할 수 있도록 하는 것은 사람이 도구를 더 쉽게 사용할 수 있도록 하는 것과 같습니다. 따라서 이 영상은 자연어 쿼리(예: "John과 그 전체 이름을 포함하는 연락처의 전체 이름과 이메일을 보여주세요")를 입력받으면, Wev8 GraphQL Gorilla가 내부적으로 스키마와 API 참조를 사용하여 이를 적절한 GraphQL 쿼리로 변환하고 실행하는 자동 API를 제안합니다. 또한 다음 구문을 사용하여 생성된 쿼리를 시각화할 수 있는 옵션도 제공합니다. 자동 API 제안에 대해서는 영상 후반부에서 자세히 설명하겠습니다. 이 영상은 API에 맞게 LLM을 미세 조정하는 방법을 궁금해하는 모든 분들에게 유용할 것입니다. 이미 여러 API를 보유하고 있거나 소프트웨어에서 자연어 명령을 더 쉽게 사용할 수 있도록 하려는 경우, 이 영상이 도움이 될 것입니다. 이 프로젝트에서 우리가 이 모델을 만들기 위해 수행한 모든 작업에 대한 개요를 살펴보겠습니다. Wevigate GraphQL Gorilla를 학습시키기 위해 2분 동안 수행한 모든 작업을 간략하게 설명하겠습니다. 먼저 네 가지 데이터 세트가 있습니다. 첫 번째는 합성 데이터베이스 스키마가 포함된 지식 기반입니다. GBT4에게 Levia 데이터베이스 스키마의 구조를 알려주고, 최소 두 개의 텍스트 속성, 최소 하나의 정수 또는 숫자 속성, 최소 하나의 부울 속성, 그리고 이 클래스에서 다른 클래스로의 최소 하나의 상호 참조를 작성하도록 요청했습니다. 자동차부터 악기까지 다양한 주제를 다루는 50개의 모형 스키마를 생성했습니다. 두 번째는 API 참조 지식 기반입니다. 여기에는 모든 API가 포함되어 있으며, 하이브리드 검색, 웨어, 자동 컷, 재순위 지정 등 46개의 API가 있습니다. 이 중 일부는 원자적 API( 예: BM25)로, BM25만 설명합니다. 또한 웨어 필터와 함께 BM25를 사용하는 방법과 같은 구성적 API 참조도 있습니다. 마지막으로 작업 예제가 있습니다. 이는 API 참조와 사용자 지정 스키마를 새로운 스키마로 변환하는 방법을 보여주는 수동으로 작성된 예제입니다. 사용자 정의 스키마 API 참조와 쿼리를 자연어 명령으로 변환하는 방법뿐만 아니라 쿼리 자체도 다룹니다. 합성 예제를 생성하여 학습에 사용할 것이기 때문입니다. 먼저 합성 데이터베이스 스키마와 API 참조, 그리고 이 작업을 수행하는 방법에 대한 예제를 포함하는 지식 기반을 가져와 모든 데이터베이스 스키마와 API를 순회하며 새로운 쿼리를 생성합니다. 이렇게 해서 합성 스키마에 대한 2300개의 새로운 쿼리를 만들었습니다. 그런 다음 이 쿼리를 실행하려는 경우 사용할 자연어 명령을 생성합니다. 이제 이것이 자기 학습 알고리즘의 전체입니다. 쿼리 데이터 세트와 이러한 쿼리를 실행할 때 사용할 자연어 명령 데이터 세트, 이렇게 두 가지 데이터 세트를 갖게 되었습니다. 또한 이 자연어 명령 세트를 사용하여 검색 성능을 평가할 수 있습니다. 자연어 명령을 쿼리로 입력하고 합성 자연어 명령과 합성 쿼리를 생성하는 데 사용된 API 참조를 반환하는지 확인합니다. 그런 다음 자연어 명령에 있는 새로운 쿼리를 가져와 미세 조정 데이터에 템플릿화합니다. 미세 조정 데이터에서 입력은 합성 데이터베이스 스키마, 검색된 API 참조, 그리고 합성 자연어 명령이 됩니다. 이를 통해 합성 쿼리를 예측할 수 있습니다. 우리는 이를 Substratus에서 사용하고 Kubernetes 및 Kubernetes 학습을 오케스트레이션합니다. 또한 Hug and Face PEF 라이브러리를 사용하여 Guerrilla Large Language 모델을 학습합니다. 그런 다음 Guerrilla Large Language 모델을 평가합니다. 먼저 실행 여부를 확인하고, V8을 사용하여 스키마를 순회하며 Wii V8에서 인스턴스를 생성합니다.
