## 스크립트

안녕하세요 여러분, 저는 콜라라입니다. 오늘은 카티시아의 LINE SDK와 Sbras 기반 모델을 사용하여 음성 에이전트를 구축하는 방법을 알려드리겠습니다. 보시다시피, 저희 추론 문서에는 간단한 에이전트를 구축하는 방법을 설명하는 튜토리얼이 있으며, 이 튜토리얼에는 저희 음성 에이전트의 전체 저장소 링크가 포함되어 있습니다 . 시작하기 전에 몇 가지 참고 사항이 있습니다 . 이 링크를 클릭하여 SRES API 키를 확보해야 합니다. 그리고 카르티시아 계정도 필요합니다. 필요한 모든 패키지가 포함된 PI project.2ML 파일이 있는지 확인해 주세요. 그런 다음 시작할 수 있습니다. 이제 play.cartisia.ai/aents로 이동하여 음성 에이전트를 클릭하세요. 보시다시피, 저는 이미 에이전트를 준비 하고 배포했지만, 여러분의 GitHub 저장소를 에이전트 플랫폼에 연결하는 방법을 보여드리겠습니다. 자, 그럼 여기를 클릭하고 계정을 선택하겠습니다. 이미 GitHub 계정을 연결했으므로 추가 조치는 필요하지 않습니다. 만약 계정이 없으시다면, GitHub ID를 추가하라는 메시지가 표시될 것입니다. 보시다시피 제 플랫폼에 저장소 두 개를 추가했습니다 . 제가 보여드릴 옵션을 선택하고, 메인 브랜치를 선택한 다음 배포를 클릭하겠습니다. 중요한 점은 이 배포가 실패할 가능성이 매우 높다는 것입니다. 제가 여기에 환경 변수를 추가하지 않았기 때문입니다. 그러니 여기에 여분의 API 키를 추가하고 ' 추가'를 클릭하면 에이전트가 배포될 것입니다. 이제 이 요원이 준비될 때까지 기다릴 필요 없이, 이미 여기 준비된 요원이 한 명 있습니다. 그럼 저는 그걸 클릭해 볼게요. 상담원이 준비되어 운영 모드에 들어가면 바로 통화할 수 있습니다. 그럼 실제로 어떤 일이 벌어지는지 한번 봅시다 . 안녕하세요, 저는 Cartisia에서 제공하는 음성 상담원입니다 . 무엇을 만들고 싶으세요? 할로윈을 맞아 아파트를 꾸미고 싶어요. 할로윈 장식으로 어떤 테마를 생각하고 계세요? 유령 같은. 푸키를 반려동물로 등장시키고 싶으신가요, 아니면 캐릭터로 등장시키고 싶으신가요 ? 내 아파트가 이렇게 보이길 원해요. 푸키는 당신에게 어떤 모습으로 보이나요? 음, 유령이랑 거미줄이 많아요. 블랙라이트를 인테리어에 활용하실 건가요? 네, 왜 안 되겠어요? 무서운 소리를 추가하실 건가요? 아마도.
