## 스크립트

Azure 무료 평가판부터 시작해 보는 것을 추천합니다. 이 덕분에 Azure의 모든 리소스를 테스트하고 사용해 볼 수 있는 200달러를 받게 되었고, 완전 무료 옵션이 있는 Azure SQL도 사용해 볼 수 있게 되었습니다 . 그래서 무료 체험 기간 동안 제공되는 금액을 사용하지 않고도 이용할 수 있겠네요. 그러면 컨테이너 앱과 정적 웹 앱을 사용하여 웹사이트와 백엔드를 구축할 수 있습니다. 물론, 인공지능도 조금 넣어줘야겠죠. 그래서 저는 Azure Open AI도 사용할 예정이며, 이를 통해 AI 기능이 포함된 풀스택 웹사이트를 기본적으로 무료로 구축할 수 있습니다. 그러면 저는 [음악]을 GitHub 저장소에 연결하여 게시하고 친구, 가족, 심지어 직장 동료들과 공유할 수 있습니다. 그리고 가장 좋은 점은 모든 에뮬레이터가 설치되어 있고, 특히 오프라인 사용이 완전히 무료인 SQL Server Developer Edition 덕분에 제 컴퓨터에서 오프라인으로 작업할 수 있다는 것입니다. 그래서 저는 제 컴퓨터에서 완전히 편안하게 오프라인으로 작업한 다음, 준비가 되면 모든 것을 Azure에 게시할 수 있습니다 . 정말 좋네요.
