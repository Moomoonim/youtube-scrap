## 스크립트

[음악] Azure 마이그레이션 및 마이그레이션 시리즈의 또 다른 비디오에 오신 것을 환영합니다 . 이번 에피소드에서는 MySQL 워크로드를 Azure로 마이그레이션하는 데 필요한 모든 정보를 공유합니다. 이전 영상들을 보셨다면 , 일반적인 이민 과정은 결정, 계획, 실행의 세 단계로 나뉜다는 것을 이미 알고 계실 겁니다 . MySQL 마이그레이션을 시작하려면 먼저 Azure Migrate를 사용하여 환경 내 MySQL 데이터베이스 인스턴스와 해당 속성을 검색하고, Azure로 마이그레이션할 준비가 된 인스턴스를 포함하는 신뢰할 수 있는 마이그레이션 계획을 수립해야 합니다. 특히 Azure에서 제공하는 완전 관리형 서비스형 데이터베이스인 Azure Database for MySQL을 마이그레이션할 때 필요한 권장 사항 및 관련 비용을 확인할 수 있습니다. 이제 온 프레미스 MySQL에서 Azure MySQL Flexible Server 데이터베이스로의 전환 평가 데모를 바로 살펴보겠습니다. Azure 포털에서 Azure 마이그레이션을 검색하고 프로젝트로 이동합니다. 왼쪽 목차의 ' 인벤토리 탐색' 아래에서 검색된 모든 데이터베이스의 인벤토리가 포함된 '데이터베이스' 블레이드를 찾으세요 . MySQL 또는 Maria DB 데이터베이스 인스턴스만 표시되도록 목록을 필터링하려면 상단에서 MySQL 및 Maria DB를 선택하세요. 평가를 생성하려면 몇 가지 데이터베이스 인스턴스를 선택해야 합니다. 특정 열 속성을 사용하거나 태그를 사용하여 필터를 적용할 수 있습니다. 이제 몇 가지 사례를 선택 하고 '평가 생성'을 클릭해 보겠습니다. 평가에 친근한 이름을 붙여드리겠습니다. 저는 이것을 MySQL 데모라고 부르겠습니다. 다음으로, 요구 사항에 맞게 평가 속성을 사용자 지정할 수 있습니다. 대상 위치에 따라 평가에 사용할 Azure 지역이 결정됩니다 . 지역별로 꼬치구이 의 가격과 공급 상황이 다르기 때문에 이는 중요합니다. 소스 워크로드의 환경 유형( 예: 개발, 테스트 또는 프로덕션)을 지정하여 적절한 가격을 적용할 수도 있습니다. 통화, 종량제, 1년 또는 3년 예약 인스턴스, Azure 절약 플랜과 같은 절약 옵션, 그리고 평가 기준을 통해 최대 절감 효과를 고려한 총소유비용(TCO)을 예측하고 최적의 규모를 갖춘 Azure 대상을 식별할 수 있습니다. ' 기본값 편집'을 클릭하면 서비스 계층과 같은 MySQL 대상별 속성을 지정할 수 있습니다. 모든 세부 정보를 지정한 후 ' 검토 및 평가 생성'을 클릭할 수 있습니다 . 모든 것이 괜찮아 보이면 ' 만들기'를 클릭하세요. 평가 결과는 몇 분 안에 검토 가능합니다. 이 평가에서는 MySQL 인스턴스 8개를 호스팅하는 서버 8대를 평가 대상으로 삼았음을 확인할 수 있습니다. 그중 6명은 이주 준비가 완료되었고, 2명은 이주를 위한 몇 가지 조건을 충족하는 것으로 확인되었습니다. 개요 화면에는 월별 예상 리소스 비용( 451달러)의 세부 내역이 표시됩니다. 이 중 컴퓨팅 비용은 310달러, 스토리지 비용은 21달러, 보안 비용은 119달러입니다. 여기서 좀 더 자세히 살펴보고 인스턴스 수준의 권장 사항을 알아보겠습니다. Azure Database for MySQL에서 두 개의 인스턴스가 사용 준비 완료로 표시되었고, 나머지 여섯 개는 Azure VM에 사용하도록 권장되었습니다 . Azure DB for MySQL로 전송되는 항목들을 확인해 보겠습니다. 여기서는 두 경우 모두 수명이 다한 상태입니다. 세부 정보를 클릭하면 MySQL 버전에 따른 인스턴스 분포를 시각화할 수 있습니다. 각 사례를 더 자세히 살펴보기 위해, 좀 더 깊이 들어가 보겠습니다 . 요약 탭에서는 준비 상태, 대상 구성, 권장 마이그레이션 도구 및 이 MySQL DB 인스턴스에 적용된 태그에 대한 간략한 세부 정보를 확인할 수 있습니다. 준비 상태 탭에서 준비 상태 문제 및 경고를 검토하고 시정 조치를 취할 수 있습니다. 소스 속성 탭에서 대상 구성을 식별하는 데 사용된 소스 인스턴스 속성을 확인하십시오 . 여기에서 컴퓨팅 성능 데이터 및 기타 인스턴스 세부 정보를 확인할 수 있습니다. 대상 권장 사항 탭에서는 Azure Database for MySQL의 대상 구성 과 온 프레미스에서 실행 중인 MySQL 데이터베이스 인스턴스에 대한 모든 세부 정보를 확인할 수 있습니다. 또한 각 자원 유형별 월별 비용 내역을 시각화하고 권장 사항의 근거를 검토하여 평가 결과가 어떻게 산출되었는지 이해할 수 있습니다. 탐색 및 평가가 완료되고 신뢰도 높은 마이그레이션 계획을 수립한 후에는 Azure 데이터베이스 마이그레이션 서비스를 활용하여 모든 소스에서 모든 위치에 저장된 최대 1.5테라바이트[음악] 크기의 데이터 세트를 UI 기반으로 빠르고 간편하게 온라인 및 오프라인으로 마이그레이션할 수 있습니다 .
