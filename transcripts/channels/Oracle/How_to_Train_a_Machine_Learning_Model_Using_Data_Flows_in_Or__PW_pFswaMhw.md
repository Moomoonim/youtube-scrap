## 스크립트

이 튜토리얼에서는 Oracle Analytics Cloud의 데이터 흐름을 사용하여 머신 러닝 모델을 학습시키고 적용하는 방법을 알아봅니다 . 머신러닝 모델은 과거 데이터에서 패턴을 발견하고 미래 결과를 예측하는 데 도움을 줍니다. Oracle Analytics Cloud에서는 고급 코딩 없이도 데이터 흐름을 사용하여 모델을 학습시킬 수 있습니다. 이 시나리오에서 저는 인사 분석가이며, 직원 이직률을 분석하여 인재 유지 노력을 집중해야 합니다. 저는 이직률 값이 포함된 과거 데이터 세트 와 이직률을 알 수 없는 데이터 세트를 가지고 있습니다. 먼저 새 데이터 흐름을 생성 하고 예측 하려는 이직률 값이 이미 포함된 데이터 세트를 선택하겠습니다 . 모델 학습 전에 예측 에 기여하지 않는 열을 제거하겠습니다 . 이 데이터 세트에서는 ID 열을 선택한 다음 제거하겠습니다. 나머지 열들은 직원 관련 정보를 제공하므로 그대로 두겠습니다. 다음으로, 데이터 흐름에 머신 러닝 단계를 추가하겠습니다 . 예/아니오 결과를 예측하는 것이므로 , 단계 추가 메뉴에서 이진 분류기 학습을 선택하겠습니다. 다음 대화 상자에서 분류 알고리즘으로 나이브 베이즈를 선택하겠습니다 . 이는 인력 이탈 예측과 같은 이진 분류 문제에 대해 빠르고 효과적인 방법이기 때문입니다. 모델 설정에서 예측하고자 하는 값인 '이탈률'을 목표 열로 정의하겠습니다. 그럼 이제 목표 변수에서 긍정 클래스를 ' 예'로 설정하겠습니다. 제가 원하는 결과가 바로 그것이기 때문입니다. 나머지 설정은 기본값 그대로 두겠습니다. 학습 분할 비율 설정은 모델 학습과 테스트에 사용되는 데이터의 비율을 제어합니다. 여기서는 기본 80/20 학습 분할이 잘 작동합니다. 일반적으로 80에서 90 사이의 값이면 적절합니다. 이제 '모델 저장'을 선택하고 모델 이름을 입력한 다음 데이터 흐름을 저장하겠습니다. 그다음에는 데이터 흐름을 실행하겠습니다. 실행이 완료되면 모델을 검사하여 성능과 품질을 검토할 수 있습니다. 내비게이터를 선택한 다음 머신 러닝을 선택하겠습니다. 모델을 마우스 오른쪽 버튼으로 클릭하고, 검사를 선택한 다음 품질을 선택하겠습니다. 모델에 대한 다른 세부 정보도 검토할 수 있습니다. 다음으로, 직원 속성은 포함되어 있지만 이직률 데이터는 포함되지 않은 데이터 세트에 해당 모델을 적용해 보겠습니다. 새 데이터 흐름을 만들고 데이터 세트를 선택하겠습니다. 학습된 모델을 적용하려면 ' 단계 추가'를 선택하고 '모델 적용'을 선택하세요. 모델 선택 대화 상자에서 이전에 생성한 모델을 선택한 다음 확인을 클릭합니다. 이제 결과를 볼 수 있습니다. 각 예측에 대해 예상 이직률과 신뢰도 점수를 추가하겠습니다. 다음 단계는 모든 입력 열이 학습 모델에 사용된 필드와 일치하는지 확인하는 것입니다 . 입력 섹션에서는 각 모델 열에 맞는 올바른 입력 열을 하나씩 선택하겠습니다 . 데이터 저장 단계를 추가 하고 데이터 세트 이름을 입력하겠습니다. 각 열의 측정값과 속성 지정이 정확한지 확인하기 위해 검토도 하겠습니다. 이제 데이터 흐름을 저장 하고 실행하여 예측값을 생성하겠습니다. 새 데이터 세트를 통합 문서에서 열고 결과를 검토할 표를 만들겠습니다. 데이터 창에서 이름, 성, ID 및 예측값을 선택하고 테이블을 생성합니다. 퇴사할 것으로 예상되는 직원만 표시되도록 예측값을 기준으로 필터를 추가하겠습니다. 마지막으로, 이직 위험이 있는 직원 수를 예측하기 위해 직원 수 지표를 추가하겠습니다 . 데이터 흐름을 활용하여 머신러닝 모델을 학습시키고 적용했으므로, 이제 직원 이직률을 더 정확하게 예측 하고 선제적으로 대응할 수 있습니다. 아래 링크에서 Oracle Analytics Cloud 사용에 대한 더 많은 비디오와 자료를 찾아보세요.
