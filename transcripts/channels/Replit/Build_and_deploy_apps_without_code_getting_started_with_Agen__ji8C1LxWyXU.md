## 스크립트

안녕하세요, Repet의 Matt입니다. 오늘은 Repet 에이전트와 어시스턴트를 이용해 단 몇 분 만에 AI 앱을 만드는 방법을 보여드리겠습니다. 코드를 한 번도 작성해 본 적이 없거나, 앱을 만들거나 배포해 본 경험이 없더라도 걱정하지 마세요. 아이디어에서 애플리케이션을 만들어 인터넷에 게시하고 사람들과 공유하는 방법을 알려드리겠습니다. 왜 이렇게 쉬운지, Repet이 어떻게 작동하는지, 이러한 도구들이 어떻게 활용되는지, 그리고 제가 이 도구들을 이용해 어떻게 앱을 개발했는지, 지난 몇 달 동안 어떤 작업을 할 수 있었는지 자세히 설명해 드리겠습니다. 여기가 Repet 홈페이지입니다. Repet 구독을 구매하고 Repet 에이전트에 액세스하면 이 화면이 나타납니다. 만들고 싶은 것은 무엇이든 설명할 수 있습니다. 예를 들어, 버튼을 누를 때마다 인터넷에서 무작위로 고양이 이미지를 보여주는 고양이 생성기를 만들어 보겠습니다. 아주 간단하죠? 프롬프트 기능이 처음이시라면, 더 자세한 정보를 추가하려면 '프롬프트 개선' 버튼을 클릭하면 됩니다. 프롬프트를 개선하기 위해 몇 가지 모범 사례를 소개하고 좀 더 자세한 내용을 추가해 보겠습니다. 또한 언제든지 아이디어를 얻거나 연결을 추가할 수 있다는 점에 유의하세요. 애플리케이션을 개선하기 시작하면 편리한 파일 첨부 버튼도 사용할 수 있습니다. 웹사이트를 복제하고 싶을 때 유용합니다. 웹사이트를 언급하여 스크린샷을 찍 거나 페이지 콘텐츠를 프롬프트에 직접 복사하는 등의 작업도 가능합니다. 하지만 이 영상은 소개 영상이므로 간단하게 진행하려고 합니다. " 지금 만들기 시작" 버튼을 클릭해 보겠습니다. AI를 사용하여 개발하고 코드를 작성하는 것이 처음이라면 다소 어렵게 느껴질 수 있습니다. 하지만 걱정하지 않으셔도 됩니다. 여기서 만들기 시작하면 에이전트가 가장 먼저 하는 일은 계획을 제안하는 것입니다. 이 계획은 우리가 무엇을 만들고 싶은지 생각하는 데 도움이 되고, 올바른 것을 만들고 있는지 확인하며, 바로 후속 기능을 추가할 수 있도록 해줍니다. 자, 이제 Flask와 JavaScript를 사용하여 귀여운 고양이 이미지 생성기를 만들어 보겠습니다. 너무 걱정하지 마세요. 프레임워크가 처음이시라면, 음, 제가 원하는 것과 정확히 일치하는 것 같으니 ' 플랜 승인'을 클릭하겠습니다. 에이전트가 코드를 작성 하고 전체 개발 환경을 구성하기 시작할 것입니다. 이것이 Repet을 다른 여러 옵션 과 차별화하는 점입니다. 파일 트리가 있는 자체 환경을 구축하여 터미널 명령을 실행하고, 파일을 편집하고, 파일을 가져가고, 원할 때 언제든지 ZIP 파일로 다운로드할 수 있습니다. 정말 훌륭한 기능이죠. 데이터베이스나 클라우드 서비스를 추가하거나 추가 기능을 추가하는 등의 작업도 가능하지만, 지금은 너무 걱정하지 않으셔도 됩니다. 앱을 만들어 보겠습니다. 코드가 많이 작성되는 것을 보시겠지만, 너무 부담스러워하지 마세요. AI를 이용한 개발, 즉 학습은 시계를 분해하는 과정과 비슷하다고 생각합니다. 시계는 이미 작동하고 있죠. 에이전트를 사용하는 것도 MVP(최소 기능 제품)를 만드는 과정입니다. 이미 작동하는 무언가를 제공해 주기 때문에 그 작동 방식에 대해 너무 걱정할 필요가 없습니다. 이게 어떻게 만들어졌는지, 혹은 이 안에 있는 여러 구성 요소들이 어떻게 작동하는지 같은 건 신경 쓰지 않아도 돼요. 우리가 걱정해야 할 건 이미 작동하는 이 시스템을 기반으로, 무슨 일이 일어나고 있는지 이해하고, 구성 요소를 하나씩 제거 하거나 수정 하거나 작은 부분들을 조정해서 이 시스템이 어떻게 작동하는지 제대로 파악할 수 있느냐는 거죠. AI를 활용한 개발, 에이전트와 어시스턴트를 활용한 개발이 바로 그런 거예요. 자, 그럼 한번 살펴볼까요? ' 고양이 생성'을 클릭하면 고양이 사진이 나오네요. 예상했던 대로예요. 멋지죠? 그럼 다음은 뭘까요? MVP를 만들어 봤는데, 에이전트가 이 시스템을 만드는 데 도움을 줬어요. 그런데 디자인이 마음에 쏙 들지는 않네요. UI를 좀 더 예쁘고, 좀 더 재미있게 바꿔 달라고 해 볼게요. 예를 들어, 저는 이모티콘을 좋아해서 고양이 이모티콘 같은 걸 추가해서 앱의 외관을 개선해 달라고 해 볼까요? 음, 네, 그렇게 하는 건 좀 아닌 것 같네요. 좋은 시작이네요. 음, 에이전트로 어떻게 빌드하는지, 어시스턴트로 어떻게 빌드하는지 알아볼까요? 저는 보통 에이전트로 시작하는데, 에이전트가 전체 개발 환경을 구성해 주기 때문에 시작하기에 정말 편해요. 음, 그리고 나서 전반적인 변경 작업을 할 때 에이전트를 사용해요. 예를 들어 UI를 바꿔보자거나, 기본적인 기능을 구현해 보자 ​​같은 거죠. 그런 다음 더 세밀한 수정을 위해 어시스턴트로 전환합니다. 어시스턴트가 어떻게 작동하는지는 잠시 후에 자세히 살펴보겠습니다. 음, 제가 말씀드렸듯이, 저는 이미 작동하는 것으로 시작하기 때문에 프레임워크나 백엔드, 코드, 여러 가지 언어 같은 것들은 크게 신경 쓰지 않습니다. 우리가 할 일은 이 애플리케이션을 자세히 살펴보고 작동 방식을 이해하는 것입니다. 이렇게 충분히, 충분히 여러 번, 그리고 정말 호기심 많고 깊이 생각하다 보면 이러한 것들이 어떻게 작동하는지 실제로 배우게 될 것입니다. 에이전트를 사용하는 방법, 스크린샷 찍기 등도 마찬가지입니다. 솔직히 이 데모를 진지하게 할 수는 없네요. 에이전트가 스크린샷을 찍고 있어요. 앱의 스냅샷을 찍어서 모든 게 제대로 로드되는지 확인하는 거죠. 자, 여기 애니메이션도 있고 움직이는 부분도 좀 있어요. 최고의 고양이 생성기 이미지를 만들려고 한 건 아니지만, 이 정도면 제가 원하는 것에 더 가깝죠. 자, 이제 작동하는 게 생겼으니 앱을 다시 로드하고 어시스턴트로 전환할게요. 새 탭을 열고 어시스턴트를 열겠습니다. 왜 하필 어시스턴트를 하냐고요? 어시스턴트는 특정 부분을 수정하는 데 정말 유용해요. 파일의 작은 부분을 변경하는 데 아주 좋고, 앱의 기능을 세밀하게 조정할 수 있게 해 주거든요. 예를 들어 이 고양이 생성기 앱이 있다고 가정해 볼게요. 시각적인 변화를 좀 더 주고 싶다면 어시스턴트에게 다크 모드를 추가하고, 토글 버튼으로 다크 모드와 라이트 모드를 전환할 수 있는지 물어볼 수 있어요. 다들 다크 모드를 좋아하잖아요. 다크 모드 고양이도 필요하죠. 어시스턴트는... 파일을 읽어서 편집하는 과정을 보여드리겠습니다. 이제 어떤 파일을 편집하고 있는지 정확하게 보여줍니다. 좀 더 구체적으로 어떤 부분이 변경되는지 보여주기 때문에, CSS라는 것을 추가하고 있는 것을 볼 수 있습니다. ' 다크'라는 테마를 추가하고 일반 색상 구성표와는 다른 색상을 정의하고 있네요. HTML에는 토글 버튼 처럼 보이는 것을 추가했고, JavaScript에서는 이러한 변경 사항을 적용하는 것 같습니다. 어시스턴트가 변경 사항을 적용해도 기본적으로 자동으로 적용되지는 않습니다. 방금처럼 미리 보기를 한 다음 '적용'을 클릭하면 변경 사항이 적용되고 앱이 다시 시작됩니다. 이제 배경색을 어둡게 바꾸는 버튼이 생겼네요. 텍스트가 조금 밝은데, 읽기 쉽게 하려면 텍스트 색상을 변경하는 게 좋을 것 같습니다. 어쨌든 방금 변경 사항을 적용해서 다크 모드를 만들었습니다. 어시스턴트는 반복 작업에 더 유용하네요. 이러한 변화를 통해 정확히 무슨 일이 일어나고 있는지 확인할 수 있을 뿐만 아니라, 새 채팅을 만들고 " 이 앱이 어떤 프레임워크로 만들어졌는지 이해하는 데 도움을 주세요"라고 말할 수도 있습니다. 그러면 AI 어시스턴트가 프로젝트를 살펴보고 해당 디렉터리의 파일을 읽어 앱이 어떻게 만들어졌는지 알려줍니다. 예를 들어 " Flask를 사용하고 있습니다.
