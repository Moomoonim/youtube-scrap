## 스크립트

안녕하세요 여러분, 저는 앰버입니다. MCP 서버용 데이터 브릭의 최신 릴리스 몇 가지를 소개해 드리게 되어 기쁩니다. 플레이 그라운드에서 외부 MCP 서버를 사용하고 있을 수도 있습니다. 이를 위해 LLM을 선택하고 도구를 활성화하면 됩니다. 그래서 저는 외부 MCP 서버를 도구로 사용했습니다 . Unity 카탈로그 기능, 벡터 검색 또는 지니 공간용 내부 관리 MCP 서버 등 추가 서버를 추가할 수 있습니다. 여기에 외부 검색이 있습니다. 여기는 타발리스입니다. 인공지능 기반 검색 엔진입니다. 거기에 정보를 저장해 두면, 예를 들어 데이터 브릭에서 에이전트 브릭이란 무엇인지와 같은 질문을 할 수 있습니다. 괜찮은. 그래서 클로드는 테이블 검색을 사용하고 있습니다. 여기서 우리는 에이전트 브릭이 일반적인 기업 AI 사용 사례에 맞춰 도메인별 고품질 AI 에이전트 시스템을 구축하고 최적화하는 노드 기반 접근 방식임을 알 수 있습니다. 에이전트 브릭에 대해 더 자세히 알아보려면 추가 정보를 참조하세요. 그렇다면 이러한 MCP 서버는 어디에 저장되는 걸까요? 그러니까 제가 카탈로그로 이동해서 유니티 카탈로그의 외부 데이터로 들어가면, 연결 목록으로 들어가고 아래로 스크롤하면 MCP 서버를 볼 수 있습니다. 이것은 제가 이미 구축한 Tavi MCP 서버입니다 . 자세한 내용은 해당 내용을 참조하십시오. 이는 MCP 서버에 대한 관리 기능을 제공합니다. 다시 연결 이야기로 돌아가서, 연결 유형이 HTTP인 한 새 외부 서버를 만들고 연결 이름을 지정할 수 있습니다 . 이제 이런 식으로 연결을 설정할 필요는 없습니다. 현재 마켓플레이스에서 MCP 서버를 이용하실 수 있습니다. 마켓플레이스로 이동하여 제품 섹션에서 AI 항목을 클릭하면, 일반적으로 모델이 표시되던 위치에 이제 모델과 MCP 서버가 표시됩니다. 이제 MCP 마켓플레이스에 매일 새로운 제품과 서비스가 추가되는 것을 확인할 수 있습니다 . 여기서 타비를 볼 수 있습니다 . 그래서 이제는 처음에 유니티 카탈로그를 거치는 방식 대신 이 방법으로 간단하게 설치할 수 있습니다. 이것이 바로 저희 마켓플레이스에서 추가 MCP 서버를 추가하는 방법입니다 . 자, 이제 에이전트 탭으로 들어가면 에이전트 브릭을 볼 수 있고, 여러 에이전트를 관리하는 슈퍼바이저를 만들려면 여기에서 Genie 스페이스와 에이전트 엔드포인트를 추가할 수 있습니다. 예를 들어 지식 도우미 브릭을 만들었다면 Unity 카탈로그 기능과 외부 MCP 서버를 사용해야 합니다. 에이전트로 돌아가서 보면, MCP 카탈로그가 이 MCP 서버 탭 아래에 표시되는 것을 확인할 수 있습니다. MCP 카탈로그는 데이터베이스 브릭에 있는 모든 내부, 외부 및 사용자 정의 MCP 서버를 포함하고 관리합니다. MCP 서버를 찾을 때 가장 먼저 살펴봐야 할 곳입니다. 여기에서 서버 URL을 복사하고 사용 가능한 도구 및 서버 유형을 확인할 수 있습니다.
