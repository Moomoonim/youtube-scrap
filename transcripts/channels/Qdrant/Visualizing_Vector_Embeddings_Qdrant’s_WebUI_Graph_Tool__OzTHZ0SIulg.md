## 스크립트

웹 UI를 사용하여 데이터 세트에 숨겨진 관계를 시각화할 수 있습니다. 먼저 연습용 데이터 세트를 가져와야 합니다. 여기서는 '컬렉션' 탭에서 '중간 여정' 데이터 세트를 컬렉션으로 가져오겠습니다. 새 컬렉션과 중간 여정 이미지를 데이터 포인트로 확인할 수 있습니다. '그래프' 탭에서 이러한 포인트 샘플을 시각화하여 서로 어떻게 관련되어 있는지 볼 수 있습니다. 900개의 이미지 샘플을 생성 하고 트리 그래프를 사용하여 연결해 보겠습니다. 트리는 유연하게 확대/축소 및 늘림 기능을 사용하여 포인트 간의 관계를 명확하게 파악할 수 있습니다. 관련 포인트 클러스터가 더 잘 보이면 확대하여 각 클러스터를 확인해 보세요. 관련 포인트들이 시각적으로 얼마나 유사한지 확인할 수 있습니다. 이 기능은 숨겨진 연결과 데이터 세트를 찾아내는 데 매우 유용합니다. 이 기능을 직접 사용해 보려면 아래 설명 의 지침을 참조하세요.
