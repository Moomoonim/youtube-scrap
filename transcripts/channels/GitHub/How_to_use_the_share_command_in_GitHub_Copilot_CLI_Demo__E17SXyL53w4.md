## 스크립트

안녕하세요 여러분, 저는 스콧입니다. 오늘은 GitHub Copilot을 사용해서 코드베이스를 살펴보고, 필요하다면 Gist로 공유해 보려고 합니다. 이 경우, 저는 Windows 기반 Linux인 WSL 내부에 GitHub Copilot의 CLI를 설치했습니다 . 저는 가서 {슬래시} 모델을 클릭하고 저희가 보유하고 있는 13명, 아니 14명의 모델 중에서 아무거나 하나를 고를 수 있습니다 . 클로드 오푸스, 클로드 소네트, 어떤 것이든 내가 좋아하는 것을 고를 수 있어. 제가 지금 사용하고 있는 윈도우로 전환해서 PowerShell이나 명령 프롬프트에서 Copilot을 실행할 수도 있습니다. 그리고 저는 이 코드베이스를 탐색하도록 요청할 것이고, Handy라는 훌륭한 오픈 소스 음성 인식 도구를 사용할 것입니다. ASCII 아트로 된 건축 다이어그램을 만들어 주실 수 있나요 ? 저는 이 코드베이스를 잘 이해하지 못해서, 여기서 무슨 일이 벌어지고 있는지 파악하고 싶습니다. 그 모든 일은 현지에서 이루어졌습니다. Handy는 handy.computer에서 확인할 수 있는 훌륭한 오픈 소스 프로젝트입니다. 이 프로젝트는 GitHub에서 호스팅되고 있으며, 로컬 에이전트이기 때문에 로컬 도구를 사용할 수 있으므로 코드베이스 구조를 탐색하기 시작할 것입니다. 그러니까, 이것들은 서로 다른 디렉토리들을 호출하는 겁니다. 그것은 해당 부분을 검색하려고 할 것입니다 . 자, 시작해 볼까요? 제 팟캐스트 관리 코드베이스에 대한 ASCII 아키텍처 다이어그램을 만들고 있습니다. 이 경우에는 미들웨어, 즉 타입스크립트 미들웨어가 코드베이스 구조를 탐색하기 시작하는 것을 볼 수 있습니다 . 오푸스에는 좀 과할지도 모르지만, 뭐 어쩌겠어요? 자, 시작해 볼까요 . 그것을 보여줍니다. 그 부분에 대해 좀 더 자세히 설명해 주시겠어요? 라우팅 부분을 구체적으로 이해하고 싶습니다. 왜냐하면 새로운 코드베이스를 처음 접하는 경력 초보 엔지니어들에게는 라우팅이 혼란스러울 수 있기 때문입니다. 그래서, 저는 지금 이 기기에 대고 수다를 떨고 있어요 . 더 자세한 맥락이 있으면 더 나은 결과를 얻을 수 있고, 저는 타이핑을 많이 하지 않아요. 저는 그것과 이야기하는 것을 정말 좋아해요. 내 손에 부담이 덜 가니까요. 자, 됐습니다. 이제 Next.js 내부의 앱 라우터 에 초점을 맞춘 보기 좋게 확장된 다이어그램을 얻게 되었습니다. 이렇게 하니 이해하기 쉽고, 원한다면 architecture.md 파일에 저장해 둘 수도 있겠네요. 워드나 파워포인트 같은 프로그램을 자동화해서 뭔가를 만들 수 있을 것 같아요. 인어처럼 활용해서 인어 관련 도표나 그림을 만들 수도 있었을 텐데. 하지만 제가 여기서 하려는 작업의 목적상, 이 ASCII 아키텍처 다이어그램이 꽤 괜찮아 보입니다. 페이지 경로에 대한 생각은 거의 끝났습니다. 자, 됐습니다. 레이아웃 중첩, 요청 흐름. 맞습니다 . 이것은 제 팟캐스트의 대시보드입니다. 좋아요, 이제 {슬래시}를 입력하면 사용 가능한 모든 {슬래시} 명령어가 나오는데, 제가 여기서 관심 있는 건 공유(share)입니다. 제가 그 내용을 요약해서 공유해 드리겠습니다. 이 글에서는 저희가 진행하는 세션 전체를 공유할 예정입니다. 아키텍처 다이어그램이 아니라 세션 전체 내용입니다. 이 경우에는 우선 핵심적인 내용을 알려드리겠습니다. 그 내용을 여기서부터 전해드리겠습니다. 이제 GitHub Copilot 세션이 생겼습니다. 이 내용을 비밀에서 공개로 바꿀 수 있어요. 그러면 우리는 더 많은 정보를 얻게 됩니다. 로그인한 사용자 정보, 제가 구성한 MCP 서버, 그 이유, 주고받은 내용, 제가 살펴본 모든 것, 그리고 ASCII 아키텍처 다이어그램까지 모두 확인할 수 있습니다. 아주 멋져 보여요. 좋아요, 개념들을 살펴보죠. 논리적인 추론을 이해할 수 있습니다. 보세요, 사용자가 저 ASCII 다이어그램을 더 자세하게 설명해달라고 하네요. 바로 그 부분에서 제가 라우터에 대한 자세한 정보를 요청했어요 . 작지만 좋은 기능이네요. GitHub Copilot에는 공유 기능이 내장되어 있습니다. GitHub Copilot CLI는 Windows에서는 ` winget install github.copilot` 명령어를, Mac에서는 `brew` 명령어를, Linux 또는 WSL에서는 `brew` 명령어를 사용하여 설치할 수 있습니다. copilot.github.com에서 확인해 보세요. 감사해요.
