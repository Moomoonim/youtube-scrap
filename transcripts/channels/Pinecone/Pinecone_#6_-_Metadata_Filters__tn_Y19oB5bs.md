## 스크립트

이 비디오에서는 PineCone의 메타데이터 필터링을 검색에 활용하는 방법을 살펴보겠습니다. 메타데이터란 키-값 쌍을 의미합니다. 예를 들어, 임의의 벡터들을 만들고 각 벡터에 서로 다른 영화 장르를 할당해 보겠습니다. 코미디나 다큐멘터리처럼 말이죠. 이것이 바로 이 예시에서 사용하는 메타데이터 태그의 한 예입니다. 각 벡터에는 '장르'라는 메타데이터 항목이 연결되어 있고, 그 값은 ' 코미디'나 '드라마'와 같은 문자열입니다. 숫자 메타 데이터나 배열도 사용할 수 있으므로 PineCone의 메타데이터는 매우 유연하게 활용할 수 있습니다. 벡터 검색에서 메타데이터를 사용하는 것은 다소 어려운 주제입니다. 메타데이터를 기반으로 필터링하면서 근사 최근접 이웃 인덱스를 통해 검색하는 것은 쉽지 않기 때문입니다. 하지만 PineCone은 단일 단계 필터링이라는 기술을 사용하여 메타데이터 필터링을 매우 빠르게 처리합니다. 실제로 대부분의 검색에서 메타데이터 필터를 추가하면 검색 속도가 향상됩니다. 앞서 예시에서 ' 코미디' 장르에 속하는 유사한 벡터만 검색하고 싶다면, PineCone을 통해 그렇게 할 수 있습니다. 검색 속도를 높이기 위해 Pinecone을 사용해 보겠습니다. 먼저 Python 클라이언트가 설치되어 있는지 확인하고, Pan Code를 임포트합니다. API 키는 여기에서 발급받아야 하며, 이 인수에 API 키를 추가하여 Pinecone에 대한 연결을 초기화합니다. 다음으로 인덱스에 대한 연결을 초기화합니다. 인덱스가 없다면 생성해야 합니다. 여기서는 이미 1만 개의 벡터가 있지만, 메타데이터 유형을 사용하여 벡터를 업데이트하는 방법을 보여드리겠습니다. 여기에서 임의의 벡터 두 개를 생성 하고 ID도 두 개 지정하겠습니다. 메타데이터 목록은 비어 있으므로 이제 메타데이터를 추가해 보겠습니다. 각 벡터의 메타데이터는 딕셔너리 형태로 저장됩니다. 장르를 추가해 보겠습니다. 첫 번째 벡터는 코미디로 설정하고, 개봉일도 추가합니다. 첫 번째 벡터는 2018년 에 개봉했다고 가정합니다. 이제 두 개의 벡터가 있으므로 메타데이터를 더 추가해 보겠습니다. 다시 장르를 추가하고, 두 번째 벡터는 코미디로 설정하겠습니다. 드라마라고 가정하면 연도는 2021년으로 표시됩니다. 이제 모든 벡터에 동일한 메타데이터를 사용할 필요가 없습니다. 예를 들어, 여기서 연도를 제거해도 문제가 없지만, 대부분의 인덱스에서는 입력하는 메시지와 일관성을 유지하는 것이 좋습니다. 이제 실행해 보겠습니다. 이것은 이전에 보셨을 법한 일반적인 인덱스 수정 코드입니다. ID와 벡터를 사용하고 이제 메타데이터를 추가했습니다. 벡터로 변경하고 메타데이터를 추가하면 zip 함수에 추가하기만 하면 됩니다. 실행해 보면 인덱스에 두 개의 벡터가 더 추가된 것을 볼 수 있습니다. 메타데이터를 추가하는 것은 매우 쉽습니다. 이제 실제로 메타데이터를 쿼리해 보겠습니다. 임의의 쿼리를 생성하고 여기에 메모를 남겨 두겠습니다. 이것이 인덱스에 포함된 메타데이터입니다. 먼저 메타데이터 필터 없이 쿼리해 보겠습니다. 반환되는 내용을 볼 수 있습니다. 메타데이터 포함 옵션을 true로 설정했으므로 반환되는 내용을 확인할 수 있습니다. 몇 가지 결과가 있습니다. 사실, 좀 더 잘 보이도록 줄여볼게요. 자, 이제 이 세 가지 일치 항목을 반환해 보겠습니다. 우리가 하고 싶은 것은 다큐멘터리, 다큐멘터리, 코미디 중에서 다큐멘터리는 제외하고 싶다고 가정해 보는 것입니다. 이럴 때는 아래로 스크롤하면 '같지 않음' 필터가 있습니다. MongoDB는 쿼리와 프로젝션 방식 으로 작동하기 때문에 이 필터는 동일하지 않습니다. 하지만 ' 같지 않음' 필터를 필터 매개변수에 추가할 수 있습니다. 필터 매개변수에는 필터링할 필드를 지정합니다. 예를 들어 '장르'라고 지정하고, 다른 딕셔너리에는 적용할 필터 유형을 지정합니다. 여기서는 '같지 않음' 필터를 사용 하고 다큐멘터리는 제외하고 싶다고 가정해 보겠습니다. 이제 실행해 보고 결과를 확인해 보겠습니다. 보시다시피, 모든 항목이 필터링되어 더 이상 다큐멘터리가 반환되지 않습니다. 만약 다큐멘터리만 원한다면 '같음'으로 변경하면 됩니다. 그러면 결과가 달라지는 것을 볼 수 있습니다. 지금은 다큐멘터리만 반환한다고 가정해 보겠습니다. 만약 다큐멘터리를 원하지만 최근 작품, 예를 들어 2020년과 2021년 작품만 반환하고 싶다면 어떻게 해야 할까요? 쉼표를 추가하고 다음 줄로 넘어가서 연도를 입력합니다. 여기서 '연도 &gt; &gt;'를 지정해야 합니다. 즉, 2020년과 2021년 작품을 반환하려면 2019년을 입력하거나, '&gt; 또는 같음' 옵션을 사용할 수 있습니다. 그러면 2020년을 제외하고 2020년 과 2021년 작품만 반환되는 것을 확인할 수 있습니다. 이제 특정 연도 범위로 제한하고 싶을 수도 있습니다. 예를 들어 2018년을 제외하고 2020년 작품만 반환하도록 조건을 설정할 수 있습니다. 그럼 이제 2018년, 2019년, 그리고 2020년까지 포함시켜 볼게요. 2021년은 제외하고, 2021년 미만으로 설정해서 이 명령어를 실행하면 2020년 과 2018년 사이, 즉 두 해 사이의 데이터만 필터링되는 것을 볼 수 있습니다. 자, 이게 바로 Pumpkin에서 메타데이터 필터링을 하는 방법입니다.
