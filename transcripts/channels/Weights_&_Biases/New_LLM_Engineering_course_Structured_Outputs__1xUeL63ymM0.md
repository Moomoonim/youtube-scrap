## 스크립트

[음악] JSON과 파이썬에서 딕셔너리를 다루는 건 꽤 [음악] 불편해요. 런타임이나 작업 중에 코드베이스에서 이런 작은 문제를 감지하는 게 쉽지 않죠. 타입 검사를 하면 코드를 훨씬 읽기 쉽고 안전하게 작업할 수 있고, 골칫거리도 줄어들 거예요. Hentic은 스키마를 자동으로 생성하는 데 아주 뛰어나요. 복잡한 op 객체를 직접 입력할 필요 없이 ` model Json Json schema`만 실행하면 객체를 얻을 수 있죠. 프롬프트는 아주 간단해요. 그냥 ' Harry Potter'라는 이름이에요. 이제 이 코드를 실행하면 나이와 이름이 포함된 객체를 추출할 수 있어요. 이 예시에서는 house 속성이 house 열거형 값 중 하나예요. 여기 있는 모든 예시를 보면 입력값이 지난 3주 동안의 최신 개발 및 인공지능인 걸 알 수 있어요. 이제 미리 보기 쿼리가 좀 더 간단하게 작성된 걸 볼 수 있죠. Chain of Thought를 사용해서 시간을 파악하고 모든 토큰 사용량도 추적할 수 있어요. [음악]
