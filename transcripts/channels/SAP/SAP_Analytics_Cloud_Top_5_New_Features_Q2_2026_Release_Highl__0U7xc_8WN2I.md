[음악] 이번 릴리스에서는 비대칭 보고라는 강력한 새 기능을 소개하게 되어 매우 기쁩니다 . 실제 기획 및 재무 보고에서 비즈니스 사용자는 유연성, 다양한 보기 방식, 다양한 수준의 세부 정보, 그리고 의미 있는 비교 정보를 모두 한 곳에서 필요로 합니다. 자, 이제 실제로 작동하는 모습을 살펴보겠습니다 . 이 데모에서는 계정이 행에 표시되는 롤링 예측 테이블을 구축했습니다. 표의 각 열에는 1월부터 4월까지의 실제 수치를, 나머지 기간에 대한 예측치를 표시합니다. 또한 연간 실적과 예측치를 전체 기간에 걸쳐 보여주는 자료도 제공합니다. 이와 함께 분기별로 집계된 연간 예산을 제시하고 , 마지막으로 예산과 실제 지출액에 예측치를 더한 값의 차이를 보여주는 델타 값을 계산합니다. 자, 이제 이 세 가지 혁신 기술이 어떻게 함께 작동하는지 살펴보겠습니다. 첫 번째 혁신 기능인 측정 입력 제어 및 제한된 측정값과 교차 계산을 통해 현재 날짜, 예측 버전 및 통화 측정값이라는 세 가지 입력 제어 기능을 활용할 수 있습니다. 이것들은 테이블을 동적으로 움직입니다. 예를 들어, 현재 날짜를 사용하면 마감일을 4월에서 7월로 조정할 수 있습니다. 두 번째 혁신 기능은 나머지 기간에 대한 동적 시간 필터로, 2025년 7월을 선택하면 1월 부터 7월까지의 실제 데이터가 자동으로 표시되도록 합니다 . 또한, 다른 입력 제어 기능을 통해 사용자는 예측 버전 이나 통화를 실시간으로 전환할 수 있습니다. 마지막으로, 테이블 위젯의 가시성 필터는 표시되는 항목을 제어합니다. 실제 수치와 예측치는 월별로, 연간 예산은 분기별로 나타냅니다. 테이블을 선택하고 오른쪽에 있는 빌더 패널을 열면 열에 제한된 측정값을 사용하고 있음을 확인할 수 있습니다 . 제한 조치 두 가지를 먼저 수정해 보겠습니다 . 실제 측정 방식은 통화 입력 제어를 동적 측정 방식으로 활용하는데, 이것이 바로 저희의 첫 번째 혁신입니다. 이 시간 범위는 현재 날짜 입력 컨트롤을 기준으로 하여 동적으로 설정됩니다 . 두 번째 혁신은 기간을 범위로 설정하고 마감일을 자동으로 결정하는 기능을 포함합니다 . 나머지 연도 예측에도 동일한 논리가 적용됩니다 . 또한 통화 입력 컨트롤을 동적 측정값으로 사용하고 예측 버전 입력 컨트롤과 함께 사용하여 버전을 동적으로 선택합니다. 시간 범위는 현재 날짜를 기준으로 동적으로 설정되며, 현재 기간의 남은 기간과 다음 기간부터 시작하는 옵션을 사용하여 예측 기간을 정의합니다. 이 경우, 마감일 다음 달부터 해당 기간 종료일까지입니다. 마지막으로 세 번째 혁신 기능인 테이블 위젯의 가시성 필터는 비대칭 레이아웃을 허용하기 위해 측정 구조에서 활성화해야 합니다. 그러면 각 제한 조치에 따라 제한됩니다 . 예를 들어, 실제 측정값은 시간 차원에 가시성 필터를 사용하여 월별 구성원만 표시합니다. 나머지 연말 전망에도 동일하게 적용됩니다 . 하지만 연간 및 분기별 데이터를 표시하는 연간 예산 측정치의 경우, 가시성 필터는 연간 및 분기별로 설정되어 있습니다. 연간 실적과 예측치를 합산한 전체 기간 의 합계만 표시하려면 가시성 필터에서 합계만 선택합니다. 이러한 혁신 기술들을 함께 사용하면 진정한 비대칭 보고가 가능해지고, 완전히 동적인 롤링 예측 테이블을 구축할 수 있습니다. 다음으로, 복합 아티팩트에 대한 버전 관리 지원을 추가할 예정입니다. 이를 통해 합성 설계자는 각 합성물별로 최대 10개의 버전을 관리할 수 있습니다. 여기서는 디자인 단계에서 합성된 이미지를 볼 수 있으며, 저는 이 합성 이미지를 타일로 정의합니다 . 버전 관리 창을 열고 버전을 저장합니다. 저는 그걸 원본이라고 부르고 저장해 둡니다 . 이제 버전 기록에는 원래 버전으로 표시됩니다 . 자 , 이제 합성 이미지를 수정하겠습니다. [음악] 예를 들어, 차트의 기간을 2024년 1분기에서 2025년 2분기로 변경하고 싶다면 '설정'을 클릭합니다. 다시 새 버전으로 저장하면 이제 그것이 현재 버전 또는 활성 버전이 되며, 이 버전이 스토리에서 사용될 것입니다. 합성 이미지를 사용하는 제 스토리로 돌아가서 새로 고침을 선택합니다. 새로 로드된 스토리는 방금 수정한 활성 합성 버전을 반영하며, 새로운 기간은 2024년 1분기에서 2025년 2분기로 변경되었습니다. 원래 버전으로 복원하는 것도 가능합니다. 먼저 합성 파일을 열고 원본 버전을 선택한 다음 복원 버튼을 클릭합니다. 그래서 원래 버전이 복원되었고, 다시 스토리로 돌아가서 새로고침하면 원래 버전이 활성화된 것을 확인할 수 있습니다. 이번 릴리스에서는 데이터 내보내기 API 와 델타 계산 작업을 작업 모니터에 추가했습니다. 작업 모니터에 표시되는 데이터 추출 작업을 통해 초기 전체 로드 및 데이터 구독 작업의 현재 상태를 모니터링할 수 있습니다. 한번 살펴볼까요? 탐색 메뉴의 시스템 폴더 안에 있는 작업 모니터를 열면 데이터 추출 작업을 볼 수 있습니다. API 탭에서 실행 중인 작업을 보기 위해 필터를 비활성화했습니다. 이 예시에서는 현재 실행 중인 작업이 없습니다. API 클라이언트로 전환하여 데이터 추출 작업을 실행합니다. 여기서는 예측 버전을 기준으로 필터링한 모델의 팩트 테이블을 내보냅니다 . 참고로 페이지 크기별로 10,000개의 레코드를 추출합니다 . 작업을 새로고침하면 작업이 대기 중인 것을 확인할 수 있습니다. API 클라이언트에 구성된 추출 작업 및 레코드 수를 포함하여 이 작업에 대한 자세한 내용을 열어서 확인할 수 있습니다. 다시 작업 화면으로 돌아가면 OData 넥스트 링크를 실행하여 추출할 나머지 레코드를 생성할 수 있습니다. 이제 나머지 기록이 담긴 두 번째 페이지를 볼 수 있습니다 . 다음으로 공용 차원, 환율표, 표준 단위표 등 추가 아티팩트에 대한 데이터 추출 작업을 생성해 보겠습니다. 작업 모니터를 새로 고치면 해당 작업들이 성공적으로 완료된 것을 확인할 수 있습니다. 이러한 작업을 선택하면 작업 기간 및 추출된 레코드 수와 같은 자세한 정보를 확인할 수 있습니다 . 작업 모니터에 새 소스 열이 추가되어 소스 개체로 다시 이동할 수 있습니다 . [음악] 데이터 추출 작업의 보존 기간은 7일입니다. 다음으로 작업 모니터에서 델타 계산 작업 도입에 대해 살펴보겠습니다 . 다시 한번, 탐색 메뉴의 시스템 폴더에서 작업 모니터를 열고 데이터 내보내기 API 탭에서 델타 계산 옵션을 선택합니다. 모델에 구독 기능을 추가하여 변경 사항을 수집합니다. 이 작업을 처음 실행하면 모든 팩트 데이터 내용이 포함된 초기 로드가 생성됩니다. 다음은 추출 예시입니다. 이제 모델로 이동하여 사실 데이터에 몇 가지 변경 사항을 적용하고 이를 게시하여 변경 사항을 저장해 보겠습니다. 이 작업은 기존 팩트 테이블 값과 새 팩트 테이블 값의 차이를 계산하는 델타 계산 작업을 활성화합니다. 이제 작업 모니터에서 해당 작업을 확인 하고 이미 성공적으로 완료되었음을 알 수 있습니다. 자세한 정보를 얻으려면 해당 직무를 선택할 수 있습니다 . 이번 분기에는 빌더 패널 및 스타일링 패널과 별도로 접근할 수 있는 분리형 데이터 패널을 소개하게 되어 매우 기쁩니다. 이제 사용자는 데이터 패널, 빌더 패널 및 스타일링 패널에 빠르게 접근할 수 있는 간소화된 오른쪽 도구 모음을 이용할 수 있습니다. 스토리 탭에서 스토리를 생성하면 새 스토리의 오른쪽에 데이터 패널이 바로 나타납니다. 이 도구는 모델, 데이터 세트, 데이터 소스 또는 파일을 사용하여 스토리에 데이터를 추가하는 방법에 대한 안내를 사용자에게 제공합니다. 이 예시에서는 모델을 선택하겠습니다. 즐겨찾기에서 모델을 선택하면 추가된 후 측정 값, 구조, 계산, 그리고 가능한 경우 위치 치수와 같은 모델 객체를 볼 수 있습니다. 데이터 패널에서 사용자는 모델러 또는 데이터 분석기로 쉽게 이동할 수 있으며 , 해당 도구는 새 탭에서 열립니다. 이전에는 사용자가 이동하기 전에 먼저 스토리를 저장해야 했습니다. 또한 데이터 패널에서 직접 설명, ID, 또는 ID 와 설명을 모두 선택하여 전환할 수 있는 옵션을 추가했습니다 . 또한 데이터 패널의 크기를 조절할 수 있는 옵션도 제공합니다 . 데이터 패널을 통해 스토리에 추가 모델을 쉽게 추가할 수도 있습니다 . 여기에 새로운 모델을 추가하겠습니다. 이것도 제가 즐겨찾기에 추가한 것이고, 추가하자마자 데이터 패널에 새 모델과 관련 객체들이 바로 나타납니다 . 이제 스토리에서 데이터 패널이 어떻게 작동하는지 살펴보겠습니다 . 여기에 막대 그래프가 있는데, 여기에 측정값과 차원을 추가하고 싶습니다. 먼저 '인원수' 측정항목을 선택하고, 해당 측정항목을 차트 위젯으로 드래그하면 측정항목 영역이 활성화 되고 파란색으로 강조 표시됩니다. 다음으로, 경력 수준 차원을 드래그하면 적절한 영역만 파란색으로 강조 표시되는 것을 볼 수 있습니다. 그래서 이 [음악] 경우에는 색상이나 차원에 제 차원을 더할 수 있습니다. 이 경우에는 치수를 선택합니다. 또한, 기본 데이터 모델을 변경하고 싶을 경우 , 데이터 모델을 선택하고 추가하려는 객체(예: 총마진 계정)를 선택한 다음 차트에 로드하기만 하면 됩니다 . 다른 모델에서 새 객체를 추가하는 즉시 데이터 소스가 재설정되고 있다는 경고 메시지가 표시되며, 이를 수락 하고 진행할 수 있습니다. 이는 이번 분기에 새롭게 도입된 분리형 데이터 패널이 가져다주는 몇 가지 큰 장점에 불과합니다. 더 자세한 내용을 보시려면 전체 영상 시청을 부탁드립니다. 마지막으로, 이번 릴리스를 통해 사용자는 파일 열기 및 저장 대화 상자에서 최근 항목과 즐겨찾기에 직접 액세스할 수 있게 되었습니다 . 이 탭을 사용하면 최근에 사용했거나 즐겨찾기에 추가한 스토리, 모델 및 폴더에 빠르게 액세스할 수 있으므로 파일 저장소 계층 구조를 탐색할 필요가 없습니다. 이 이야기에서 우리는 데이터 세트 또는 모델을 선택하려고 합니다. 아주 간단하지만 매우 효과적입니다. 이제 팝업 창의 보기 탭에서 즐겨찾기와 최근 항목을 선택할 수 있습니다.
