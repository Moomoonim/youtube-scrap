## 스크립트

Hi I'm Masha and I manage the NVIDIA Kaolin&nbsp; Library which has many useful functions for 3D&nbsp;&nbsp; deep learning and a PyTorch API. Today let's talk&nbsp; about meshes! When working on 3D and deep learning&nbsp;&nbsp; it's hard to avoid polygonal surface meshes in&nbsp; your pipeline. For example you might use deep&nbsp;&nbsp; learning to modify an input mesh or generate&nbsp; a new one, or train on large data sets of 3D&nbsp;&nbsp; shapes like ShapeNet or Objaverse. Kaolin library&nbsp; has a new SurfaceMesh class that makes dealing&nbsp;&nbsp; with meshes and their PyTorch tensor attributes&nbsp; easier. Let's dive right in! On the surface a&nbsp;&nbsp; surface mesh is simple. Common 3D file formats&nbsp; can be read into tensors representing verices&nbsp;&nbsp; or their positions in space and faces, which are&nbsp; indices into the vertex tensor. For example faces&nbsp;&nbsp; of a quad mesh have four vertices and faces of a&nbsp; triangle mesh have three. Let's go ahead and load&nbsp;&nbsp; this armchair with Kaolin. Kaolin can load .USD,&nbsp; .gltf and .obj formats. How do we know what just&nbsp;&nbsp; loaded? Let's simply print this mesh. By default&nbsp; we only load the bare bones geometry. We'll come&nbsp;&nbsp; to normals and other attributes in a moment. For&nbsp; now we loaded vertices and faces. We can clearly&nbsp;&nbsp; see the size of each PyTorch tensor, its type,&nbsp; as well as the device where it is located. But&nbsp;&nbsp; what if your mesh has both triangles and quads?&nbsp; You can no longer neatly represent faces as a&nbsp;&nbsp; two-dimensional index tensor. To read any mesh&nbsp; in Kaolin as a triangular mesh simply specify&nbsp;&nbsp; triangulate=True. You will now see that all the&nbsp; faces are triangular and there are twice as many. Observe that some attributes are also listed as&nbsp; auto-computable. Recall that the faces tensor&nbsp;&nbsp; contains indices into the vertex array. What if&nbsp; for some building block of your code you actually&nbsp;&nbsp; need 3D vertex locations of every face stored&nbsp; in a separate array? It's easy enough to index,&nbsp;&nbsp; but caching and bookkeeping can get annoying.&nbsp; SurfaceMesh allows you to compute such indexed&nbsp;&nbsp; attributes automatically on access. For example,&nbsp; let's try simply accessing mesh face vertices.&nbsp;&nbsp; We see that now this value is available:&nbsp; for every vertex of every phase we have XYZ&nbsp;&nbsp; vertex location in 3D. We can also compute face&nbsp; normals simply from vertex locations. You see&nbsp;&nbsp; that the face normals value is now set. But of&nbsp; course if your mesh already comes with normals,&nbsp;&nbsp; it's much better to load that. Now we have a lot&nbsp; more tensors to work with. You have the normals&nbsp;&nbsp; array which is not associated to vertices or&nbsp; faces in any way, but face normals index now&nbsp;&nbsp; provides an index into the normals array for&nbsp; every vertex of every face. Similarly for UVs&nbsp;&nbsp; and face UVs index. We also provide materials.&nbsp; Now let's cover common mesh manipulations that&nbsp;&nbsp; might come up in deep learning. I can convert&nbsp; my mesh to a batch representation and print it.&nbsp;&nbsp; Now you will see for all of the attributes except&nbsp; for faces we added a batch dimension. We're also&nbsp;&nbsp; able to concatenate meshes with fixed topology.&nbsp; We can also convert our mesh to another device,&nbsp;&nbsp; for some or all attributes. For example, let's&nbsp; try just converting the vertices. You will see&nbsp;&nbsp; that now the device of only the vertex attributes&nbsp; is set to CUDA. Now if you run this for all of the&nbsp;&nbsp; attributes you will see that all of the attributes&nbsp; are now on the first device. You could also set&nbsp;&nbsp; mesh to, for example, your primary GPU. For more&nbsp; useful things that the SurfaceMesh can do for you,&nbsp;&nbsp; I encourage you to check out our detailed&nbsp; documentation as well as a notebook under&nbsp;&nbsp; our GitHub: kaolin, examples, tutorial, working&nbsp; with meshes. It covers some additional features&nbsp;&nbsp; of surface mesh. For example gradient flow through&nbsp; auto-computable attributes. We hope this helps you&nbsp;&nbsp; in your deep learning workflows!
