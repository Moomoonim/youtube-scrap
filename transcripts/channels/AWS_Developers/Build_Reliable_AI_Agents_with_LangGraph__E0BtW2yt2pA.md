## 스크립트

에이전트가 대세이지만, 에이전트를 구축하고 신뢰성을 확보하는 것은 진정한 도전입니다. 저는 Lang Chain의 Lance입니다. 저희는 에이전트에 대해 많은 시간을 투자해 왔으며, 신뢰할 수 있는 에이전트를 구축하는 데 도움이 되는 Lang Graph라는 새로운 라이브러리를 개발했습니다. 지금부터 그 방법을 보여드리겠습니다. 이 에이전트는... `py`는 에이전트를 구성하는 데 사용할 파이썬 스크립트입니다. 먼저 모델을 가져오겠습니다. 여기서는 Chad Anthropic을 사용하겠습니다. 몇 가지 도구를 정의할 건데, 이 경우에는 아주 간단한 예제로 덧셈, 곱셈, 나눗셈 도구를 정의하겠습니다. 좋습니다. 이것들이 에이전트가 사용할 도구들입니다. 이 도구들을 리스트로 정의하고 Chad Anthropic에 바인딩하겠습니다. 여기서는 Cloud3 Sonet을 사용하겠습니다. 이것은 Lang Graph와 Anthropic의 통합을 사용합니다. 보시다시피, `bind tools` 메서드가 매우 편리하게 제공됩니다. 이렇게 도구를 LLM에 바인딩합니다. 이제 도구가 포함된 모델이 준비되었습니다. 이 모델을 에이전트로 사용하고 싶습니다. Lang Graph를 사용하면 이를 매우 쉽게 구현할 수 있습니다. Lang Graph에서는 에이전트가 수행할 단계를 생각할 수 있습니다. 각 단계는 기본적으로 노드이며, 단계는 엣지로 연결됩니다. 즉, Lang Graph는 에이전트가 수행할 수 있는 제어 흐름을 노드와 엣지로 구성된 그래프로 표현합니다. 이것은 노드가 하나만 있는 매우 간단한 예입니다. 이건 제 어시스턴트 노드인데, 기본적으로 위에서 정의한 모델을 호출할 겁니다. 랭 그래프에는 또 다른 멋진 기능이 있는데, 바로 '상태(State)'라는 겁니다. 상태를 통해 노드 간에 정보를 전달할 수 있죠. 이 상태는 랭 그래프 의 내장 메시지 상태 객체인데, 이 객체는 여러 키를 포함하고 있습니다. 그중 하나가 바로 ' 메시지' 키입니다. 이 노드에서는 채팅 모델을 호출하고, 모델의 출력값을 '메시지' 키로 반환하는 겁니다. 랭 그래프를 이용하면 에이전트를 노드 와 엣지로 이루어진 그래프 형태로 구성할 수 있습니다. 각 노드는 상태 변수와 상호작용할 수 있고, 이 상태 변수는 에이전트 간에 정보를 전달하는 데 사용됩니다. 자, 이제 에이전트를 구성해 보겠습니다. 노드를 추가해 볼게요. 하나는 어시스턴트 노드이고, 다른 하나는 도구 노드입니다. 도구 노드에는 위에서 정의한 도구 목록을 전달합니다. 이제 로직을 설정해 볼까요? 엣지는 에이전트의 로직을 정의합니다. 먼저 어시스턴트 노드로 이동한 다음, 조건부 엣지를 추가해서 도구 노드로 이동하거나 다시 어시스턴트 노드로 돌아갈 수 있도록 하겠습니다. 그리고 마지막으로, Lang graph를 사용하면 파이썬 스크립트로 에이전트를 아주 간단하게 구성할 수 있고, 그 다음에는 빌더만 하면 됩니다. 컴파일, 이렇게 에이전트를 컴파일하는 겁니다. 자, 이게 바로 에이전트 그래프죠. 이제 그다음엔 뭘 할까요? Lang Graph Studio라는 아주 훌륭한 라이브러리가 있습니다. Lang Graph의 일부인데, 이걸 사용하면 에이전트 그래프를 시각화할 수 있어요. 제가 바로 열어볼게요. 이게 방금 Studio에서 만든 에이전트입니다. 이 멋진 IDE에서 에이전트의 레이아웃을 살펴볼 수 있죠. 먼저 어시스턴트 노드로 이동합니다. 여기서 채팅 모델을 호출할 거예요. 채팅 모델이 도구를 호출하면, 조건부 엣지를 사용해서 도구 노드로 이동합니다. 조건부 엣지는 출력을 확인하고 다시 도구 노드로 이동한 다음 어시스턴트로 돌아갑니다. 더 이상 도구 호출이 없을 때까지 이 과정이 반복됩니다. 그러면 종료됩니다. 이렇게 에이전트 레이아웃을 볼 수 있습니다. 이제 테스트해 볼게요. 새 스레드를 만들고 에이전트를 선택한 다음, 2와 3을 곱해서 입력해 보겠습니다. 제출하면 어시스턴트가 실행되고, Claude가 응답하고, 도구를 호출하는 것을 볼 수 있습니다. 도구 호출이 완료되면 종료됩니다. Lang Graph의 장점이 바로 이런 거죠. Lang Graph Studio는 Lang Graph를 사용하여 구축한 에이전트를 디버깅하고 테스트하는 데 매우 효과적인 시각적 환경을 제공합니다. 모든 것이 연결되어 있으며 Lang Graph Cloud를 사용하여 배포할 수도 있습니다.
