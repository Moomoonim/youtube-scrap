## 스크립트

GitHub Universe는 제가 너무나 기대하고 있는 행사입니다. 유니버스에서는 여러분이 중요하게 생각하는 것을 바탕으로 자신만의 모험을 선택할 수 있습니다 . 창의적인 에너지와 분위기에 중점을 둡니다. 모든 것이 매우 상호작용적입니다. 여기서는 만지고 놀 수 있어요. 저는 제 호기심을 널리 퍼뜨릴 수 있다고 생각합니다. 메이커 스페이스에 정말 귀여운 GitHub 램프가 있었는데, 그걸 직접 만들어 볼 수 있었어요. GitHub Universe는 경력을 발전시키고자 하는 개발자에게 완벽한 곳입니다. 핵심은 팀에 필요한 음악적 지식에 접근하는 것입니다. 협상은 정말, 정말 잘 진행됐어요. 강연이 너무 많아서 뭘 골라야 할지 행복한 고민이네요. 제가 참석했던 다른 행사들에서는 느끼지 못했던 오픈 소스나 개발자 커뮤니티에 대한 전반적인 열정 같은 것들이 훨씬 더 많이 느껴졌습니다. 기조연설만으로도 GitHub가 새롭게 선보이는 계획과 기능들을 볼 수 있어서 한 단계 발전한 기분입니다. 이곳에서 업계 전반의 동향을 파악할 수 있습니다. 정말 활기 넘치는 곳이었어요. 제게는 활력을 주는 느낌이에요. 유니버스는 사람들이 모여 아이디어를 공유하고 서로 협력하여 엔지니어링 커뮤니티로서 함께 성장할 수 있는 훌륭한 기회이자 공간입니다. 모두가 GitHub에서 개발합니다. 그래서 그들이 여기에 있을 이유는 아주 분명합니다. 바로 개발자들이 여기에 있기 때문입니다. GitHub Universe는 제가 가장 좋아하는 컨퍼런스입니다. 이러한 행사에서 맺는 관계는 앞으로의 경력에 ​​큰 도움이 될 것입니다. [음악]
