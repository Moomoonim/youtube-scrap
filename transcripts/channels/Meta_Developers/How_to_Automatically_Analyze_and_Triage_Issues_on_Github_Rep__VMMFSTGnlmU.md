## 스크립트

안녕하세요, 저는 Llama의 Meta에서 파트너 엔지니어로 일하는 Suraj입니다. 엔지니어로서 저는 오픈 소스 저장소를 관리하는 것이 보람 있는 경험이 될 수 있다는 것을 알고 있지만, 문제를 분류하고, 풀 리퀘스트를 검토하고, 댓글에 시기적절하게 답변하는 데 상당한 노력이 필요하다는 것도 알고 있습니다. 그래서 저희는 Llama를 사용하여 저장소를 분석하고 유용한 보고서를 생성함으로써 관리자를 지원하는 도구를 개발했습니다. 이 튜토리얼에서는 Llama 모델을 사용하여 비정형 데이터를 분석하고 팀에 유용한 보고서를 생성하는 방법을 배웁니다. Llama는 모든 분석 또는 보고 작업에 적용할 수 있지만 , 이 튜토리얼에서는 GitHub 이슈 분류를 예시로 들어 이러한 개념을 설명하겠습니다. GitHub 문제 분류 도구는 저장소에서 문제를 가져와 분석 및 분류하고, 논의 중인 주요 과제를 식별하고, 시각화를 포함한 포괄적인 보고서를 생성합니다. 이 모든 작업은 Llama의 언어 이해 기능을 통해 가능합니다 . 먼저 분석할 원본 데이터를 가져오는 것부터 시작해 보겠습니다. 일반적으로 이러한 데이터는 데이터베이스나 파일 저장소에서 가져올 수 있지만, 저희의 경우 GitHub API를 사용하여 저장소에서 이슈를 가져옵니다. 다음으로, 우리를 도와줄 라마를 불러오겠습니다 . 이슈 관련 게시글은 내용이 길어지고 다루는 범위가 넓어질 수 있기 때문에, Llama는 각 논의 내용을 요약하여 명확하고 간결하게 유지합니다. 하지만 그게 다가 아닙니다 . 또한 Llama를 사용하여 문제를 더 자세히 분석하고 문제의 범주 및 심각도, 언급된 코드베이스 부분, 관련 사용자 의 감정 및 전문성 수준, 문제 의 가능한 원인 및 제안된 해결 방법과 같은 유용한 메타데이터를 생성합니다. 추론 과정 전반에 걸쳐 일관성을 유지하기 위해 프롬프트에 대상 JSON 스키마를 포함합니다. 이러한 방식으로 모든 출력과 메타데이터가 동일한 형식을 따르므로 Llama의 응답을 후속 작업에서 쉽게 활용할 수 있습니다. 이제 이 모든 정보는 토론 내용당 한 행씩 SQL 데이터베이스에 깔끔하게 저장됩니다. 이러한 설정을 통해 지난 몇 차례의 릴리스 동안 사용자 감정이 어떻게 변화했는지 추적하는 것과 같은 유용한 후속 분석을 수행할 수 있습니다 . 자, 이 모든 것에서 소화해야 할 정보가 정말 많습니다 . 그래서 우리는 보고서를 생성하기 위해 다시 한번 Lama를 사용합니다. 이 보고서는 유지 보수 담당자를 위한 핵심 사항과 실행 항목을 요약하여 제공합니다. Llama로 구축한 문제 해결 도구는 개발자들이 직면한 주요 과제를 정확히 파악하는 데 도움이 되므로 엔지니어링 팀은 적절한 솔루션을 구축하는 데 집중할 수 있습니다 . 이제 시스템의 핵심 구성 요소를 하나씩 살펴보겠습니다. 이것들을 기초라고 생각하세요. 이러한 기능을 활용하여 자신만의 맞춤형 분류 도구를 만들거나, 원한다면 완전히 다른 보고 도구를 구축할 수도 있습니다. llm.py. LLM 추론의 모든 마법이 바로 여기서 일어납니다 . Llama는 로컬 환경에 배포하거나 원하는 클라우드 제공업체에 연결할 수 있습니다. 여기 있는 config YAML 파일에는 GitHub 토큰, 모델 구성, 이슈 요약, 메타데이터 및 최종 보고서 생성 방법을 안내하는 프롬프트와 같은 모든 중요한 설정이 포함되어 있습니다. Utils에는 GitHub 이슈를 가져오고 데이터를 처리하는 데 유용한 유틸리티 함수가 포함되어 있습니다 . 더욱 쉽게 이해할 수 있도록 , 코드베이스에는 각 코드 단계를 보여주는 워크스루 노트북이 포함되어 있습니다 . 환자 분류 도구를 실행하는 것은 간단합니다. 먼저 필요한 종속성을 설치하십시오. 다음으로 config.yaml 파일을 업데이트하세요. API 접근을 위해 GitHub 토큰을 설정하세요. Llama를 로컬에 배포할지 또는 클라우드 제공업체를 사용할지 선택하십시오. 프롬프트와 JSON 스키마를 사용자 지정할 수도 있습니다. 마지막으로 간단한 명령어로 도구를 실행하세요 . GitHub 분류 도구는 Llama 모델이 단순한 텍스트 생성을 넘어 실용적인 데이터 분석 도구를 만드는 데 어떻게 활용될 수 있는지 보여줍니다. GitHub 이슈를 분석함으로써 유지 관리자는 사용자의 불편 사항을 이해하고, 반복되는 주제를 파악하며, 개선 사항의 우선순위를 정할 수 있습니다. 트리아지 도구에 대해 더 자세히 알아보거나 코드를 사용하여 개발을 시작하고 싶다면 아래 설명에 있는 링크를 클릭하여 Llama 쿡북 페이지를 방문하세요. 이 예시가 여러분이 Llama 모델을 사용하여 자신만의 보고 및 분석 시스템을 구축하는 데 있어 훌륭한 출발점이 되기를 바랍니다 . 시청해 주셔서 감사합니다. llama.com에서 Llama 모델을 사용하여 지금 바로 나만의 애플리케이션 개발을 시작해 보세요. 저희는 새로운 기능과 역량을 적극적으로 개발하고 있습니다. 최신 소식을 받아보시려면 GitHub에서 저희를 팔로우하세요 . 여러분이 무엇을 만들어낼지 정말 기대됩니다.
