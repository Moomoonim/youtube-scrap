## 스크립트

여러분, 저는 프레디이고 그 라디오의 엔지니어 중 한 명입니다. 오늘은 여러분의 노트북에서 로컬로 실행되는 대규모 언어 모델의 UI를 5분 안에 구축하는 방법을 보여드리겠습니다. 네, 정말로 5분도 안 걸렸어요. 자, 그럼 시작하겠습니다 . 자, 그럼 먼저 사용할 파이썬 패키지를 설치해 보겠습니다. LLM 실행에는 llama.cpp의 Python 바인딩을 사용하고, UI 구축에는 Gradio를 사용할 예정입니다. 저는 GPU가 없기 때문에 CPU 지원만 포함된 llama.cpp를 설치하고 있습니다. 하지만 GPU 지원 기능을 포함하여 설치하고 싶으시다면 llama.cpp Python의 GitHub 저장소를 참조하세요. 자, 그럼 다음으로 가장 먼저 할 일은 허깅 페이스 허브에서 모델 파일을 다운로드하는 것입니다. 자, 여기서는 Hugging Face CLI를 사용하여 허브에서 Qwen 15억 명령어 모델을 다운로드하고 있습니다. 그리고 저는 Gradio에 기본적으로 설치되어 있는 Hugging Face CLI를 사용하고 있습니다. 물론, 다른 모델을 사용하고 싶다면 저장소 ID 와 파일 이름만 변경하면 됩니다. 자 , 이제 코드로 넘어가서 Gradio와 llama.cpp 파일에서 llama 클래스를 가져오겠습니다 . 그다음에는 허브에서 방금 다운로드한 파일을 가리키도록 하여 llama 클래스의 인스턴스를 생성합니다. 그다음에는 두 단계에 걸쳐 Gradio UI를 구축해 보겠습니다 . 첫 번째 단계는 예측 함수를 정의하는 것입니다. 자, 우선 Gradio UI에 저장된 기록을 llama.cpp에서 예상하는 형식으로 변환하겠습니다. 자, 이게 바로 첫 번째 파트에서 일어나는 일입니다 . 그리고 두 번째로 할 일은 그 기록을 llama.cpp 채팅 자동 완성 API에 전달하는 것입니다. 그런 다음 응답 토큰을 하나씩 스트리밍하여 UI에서 스트리밍 효과와 같은 효과를 생성합니다. 그런 다음 해당 함수를 채팅 인터페이스로 전달합니다. 이것으로 끝입니다. 로컬 환경이나 스페이스에서 실행되는 UI를 사용하여 GGML로 변환된 거의 모든 LLM 파일과 상호 작용할 수 있습니다. 네, 그게 다입니다. 영상에 사용된 모든 자료는 설명란에서 확인해 주세요 . 네, 어떻게 생각하시는지 알려주세요.
