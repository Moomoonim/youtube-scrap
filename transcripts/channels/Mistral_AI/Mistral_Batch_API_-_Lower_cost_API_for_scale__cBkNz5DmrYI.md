## 스크립트

대규모 언어 모델에 많은 요청을 보내야 하지만 결과를 바로 얻을 필요는 없다고 가정해 보세요. 훌륭한 해결책은 배치 API를 사용하는 것입니다. 배치 API를 사용하면 모든 요청을 일괄 처리하여 처리되는 대로 결과를 받을 수 있습니다. 이는 효율성과 확장성을 최적화합니다. 가장 좋은 점은 일반 동기 API 호출보다 비용이 50% 저렴하다는 것입니다. 이 비디오에서는 배치 API를 사용하여 이처럼 많은 영수증에서 정보를 추출하는 방법을 보여드리겠습니다. 구매한 품목, 카테고리, 가격에 대한 세부 정보를 가져올 것입니다. 바로 시작해 보겠습니다. 먼저 필요한 라이브러리(mro AI 및 데이터 세트)가 모두 설치되었는지 확인합니다. 이제 영수증 이미지를 가져와야 합니다. Hugging Face에서 영수증 이미지를 찾았 습니다. Hugging Face에서 찾은 이 저장소에서 영수증 이미지 데이터 세트를 로드합니다. 이 코드는 데이터 세트를 로드하고 pandas 데이터 프레임으로 변환합니다. 로드하는 데 몇 분 정도 걸릴 수 있지만, 데이터는 다음과 같습니다. 처음 다섯 행은 영수증 이미지입니다. 우리는 영수증 이미지에만 관심이 있으므로 이미지 하나를 살펴보겠습니다. 인덱스 1이 표시된 두 번째 이미지를 살펴보겠습니다. 일부 정보가 흐릿하게 보이는 이유는 확실하지 않지만 괜찮습니다. 우리는 주로 구매한 품목과 가격에 관심이 있습니다. 배치 API를 시작하기 전에 Mystro API를 사용하여 단일 이미지에서 정보를 추출하는 방법을 살펴보겠습니다. 먼저 이미지를 Base64로 인코딩된 문자열로 변환하는 `formatimage` 함수를 정의해야 합니다. API에서 허용하는 형식으로 이미지를 변환해야 하므로 이 과정이 필요합니다. 다음으로 API 키를 사용하여 Mr 클라이언트를 초기화할 수 있습니다. 이 노트북을 실행하는 경우 자신의 API 키를 사용하는 것이 좋습니다. 이제 Base64로 인코딩된 이미지 와 텍스트 명령어를 포함하는 메시지 페이로드를 생성할 수 있습니다. 텍스트 명령어는 모델에게 영수증에 있는 각 품목의 이름과 가격을 추출하고, 각 품목을 의료, 식품, 음료, 여행 또는 기타 카테고리 중 하나로 분류한 다음, 결과를 잘 구조화된 JSON 객체로 반환하도록 지시합니다. 여기서는 최신 멀티모델인 `PixelLarge`를 사용하고 있으며, 응답 형식을 JSON 객체로 지정하기 위해 JSON 모드를 활성화했습니다. 또한 `Prix`를 설정하여 정확한 응답을 보장합니다. 응답이 중괄호로 시작하는 것은 사실 필수적인 것은 아니지만, 응답이 중괄호로 시작하는 JSON 객체를 반환하는지 확인하기 위한 것입니다. 이제 결과를 보면 영수증 에서 추출한 항목 목록을 나타내는 JSON 객체가 있습니다. 요청한 대로 이름과 가격, 분류 정보가 포함되어 있습니다. 이제 하나의 이미지를 처리하는 방법을 알았으니, 배치 API를 사용하여 여러 이미지를 처리해 보겠습니다. 먼저 배치를 생성해야 합니다. 예를 들어 10개의 이미지를 처리해 보겠습니다. 여기서는 처리할 이미지 수만큼 JSON 요청 목록을 생성합니다. 각 요청에는 추적을 위한 사용자 지정 ID, 최대 토큰 수, 그리고 방금 본 메시지 페이로드가 포함됩니다. 여기서 유일한 차이점은 각 요청에 대해 다른 이미지를 선택한다는 것입니다. 따라서 이 목록에는 10개의 이미지가 있습니다. 이제 이러한 JSON 요청을 하나의 배치 데이터 문자열로 결합할 수 있습니다. 배치 데이터는 기본적으로 10개의 API 요청으로 구성됩니다. 다음으로 파일을 사용하여 배치 데이터를 업로드하겠습니다. 업로드 방법에서 파일 이름과 파일 내용(방금 살펴본 10개의 API 요청) 및 이 파일의 용도( 배치 API용)를 정의합니다. 그런 다음 방금 정의한 배치 데이터 변수의 세부 정보를 살펴볼 수 있습니다. 다음으로 배치를 사용하여 배치 작업을 생성합니다 . 일자리. `create` 메서드에서 입력 파일로 방금 업로드한 배치 데이터의 ID를 지정합니다. 사용할 모델로는 `Pixel Large Latest`를 정의해야 합니다. 또한 완료 확인 엔드포인트와 선택적 메타데이터도 정의해야 합니다. 이제 배치 작업이 생성되었습니다. 생성된 작업을 확인해 보면 상태가 ' 대기 중'으로 표시되어 아직 시작되지 않았음을 알 수 있습니다. 배치 작업 세부 정보를 보면 현재 실행 중인 것을 확인할 수 있습니다. 약 1분 후 상태가 '성공'으로 변경됩니다. 이 경우에는 프로세스가 거의 즉시 완료되었지만, 요청 내용과 사용 가능한 컴퓨팅 리소스에 따라 배치 생성에 최대 24시간이 소요될 수 있습니다. 하지만 제가 테스트했을 때는 매우 빨랐습니다. 여기에서 요청 총 수, 실패한 요청 수, 성공한 요청 수, 완료된 요청 비율 등의 세부 정보를 출력할 수도 있습니다. 이제 출력 파일을 다운로드하여 배치 결과를 확인할 수 있습니다. 출력 파일을 살펴보면 10개의 API 요청에 대한 10개의 출력을 나타내는 10개의 행이 있습니다. 각 출력에는 고유 ID가 있으며, 여기서 사용자 지정 ID는 우리가 제공한 것입니다. 응답에서 사용한 모델을 확인할 수 있습니다. 토큰 사용 정보를 확인할 수 있고, UT 내용도 볼 수 있습니다. 마지막 단계로 배터리 결과에서 정보를 추출하여 pandas 데이터프레임에 저장하려고 합니다. 코드는
