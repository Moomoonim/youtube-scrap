## 스크립트

This is axelottle 3D, a unified model for 3D generation from incomplete and multimodal observations. Whether reconstructing from photos, completing oluded geometry, or editing existing shapes, Axelottal 3D handles it all. Let's take a closer look. Recent 3D generation methods have made remarkable progress in quality, but assume ideal conditions. A single clean image with full object visibility. In practice, objects are often partially hidden, captured from sparse viewpoints, or available as partial 3D data. And sometimes you simply want to edit an existing shape, fixing imperfections or changing specific parts. Researchers have tackled each of these challenges, but separately. Each powerful within its own scope, but none generalized across all four. We observe that all of these tasks share a common structure. completing a 3D object from incomplete observations and this is the core insight behind axelottal 3D given multimodal inputs our method encodes each modality and fuses them into multimodal condition tokens these tokens condition a diffusion transformer to generate completed shape latent key is in our training strategy we simulate diverse partial observations and mix input on the fly from large-scale 3D data sets. This enables robust crossmodel reasoning allowing the model to generalize across various scenarios. We demonstrate axelottal 3D in a real world image to 3D pipeline. Starting from a few photos, our pipeline predicts cameras and 3D points, aligns them, and passes them into our model to generate the final mesh. The result is a complete 3D mesh from casually captured images. Axelottal 3D also enables precise local shape editing. Users specify edits by painting directly on a rendered view. An inpointing model then generates the edited appearance which our model lifts into updated 3D geometry by conditioning on the original point cloud. The model preserves the unedited regions while applying precise localized changes. Axelottal 3D can also extract and complete objects from real world captured scenes. The user first segments an object from the scene. The segmented splats then provide conditioning points for our model which generates a simulation ready mesh. Unlike raw gausian splat segments which contain large missing regions, our completed meshes enable more accurate physics simulation of the captured objects. While our model faithfully follows input points, future work could explore balancing this fidelity with robustness to noisy inputs. We hope Axelott 3D encourages more unified and practically grounded approaches to 3D generation, building towards models that handle the full complexity of a real world capture.
