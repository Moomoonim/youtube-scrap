## 스크립트

Arm Performance now integrates seamlessly with Claude Desktop and Claude Code. Once you've added the Performance MCP server to Claude, it'll have access to all of Performance's run data. Performance's profiling includes the source code, profiling data, disassembly, and information about the target platform. It wraps all of this data into a payload that makes it easy for Claude to dissect, allowing Claude to become your personal performance analysis expert, providing actionable evidence-based recommendations about the performance of your code and what you can do to optimize it. Detailed analysis and expertise at your fingertips with Claude and Performance.
