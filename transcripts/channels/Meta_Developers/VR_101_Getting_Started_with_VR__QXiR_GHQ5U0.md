## 스크립트

안녕하세요 여러분 저는 딜메르 발레시요스입니다. Meta에서 개발자 지원 업무를 맡고 있습니다. 본 세션의 주제는 VR 개발을 시작하는 방법과 Meta Horizon Store에서 몰입 경험을 해보는 방법입니다. Unity 게임 엔진 프로젝트 설정 도구인 Meta SDK와 빌딩 블록 등의 필수 도구도 다룰 예정입니다. 이 세션의 목표는 여러분의 첫 VR 경험 환경을 Meta Quest 헤드셋으로 배포하는 것입니다. 시작하려면 Meta Quest 몰입 경험을 구현하기 위한 시스템의 최소 사양부터 확인하세요. macOS, Windows 또는 Linux에서 개발할 경우 다음 사양을 권장합니다. Windows는 Windows 10 이상 Intel x64 아키텍처 프로세서 Arm64, DirectX 이상 Vulkan 지원 GPU입니다. macOS의 경우 Big Sur 11 이상 실리콘 프로세서 Apple M1 이상 Linux 22.04 또는 Ubuntu 24.04 x64 아키텍처 프로세서 OpenGL 3.2 이상 또는 Vulkan 지원 Nvidia나 AMD GPU입니다. 이제 컴퓨터 사양을 확인했으므로 VR용 Unity 프로젝트 제작으로 넘어가겠습니다. 이를 위해 먼저 Unity.com 다운로드 페이지로 가서 Unity Hub라는 도구를 다운로드하여 설치하세요. 참고로 Unity Hub는 독립 실행형 애플리케이션입니다. Unity 프로젝트 Unity 에디터 설치 및 학습 리소스를 관리하는 중앙 허브 역할을 하죠. 다음 단계로 넘어가기 전에 Unity 계정을 만들고 무료 라이센스를 받아 두는 것을 추천합니다. Unity Hub를 열고 설치를 클릭하세요. 그리고 여러분의 시스템과 호환되는 최신 Unity 6 버전을 설치하세요. 저는 Windows 용 Unity를 설치하겠습니다. Visual Studio를 IDE로 설정하세요. 다른 IDE를 사용하고 싶다면 나중에 변경할 수 있습니다. 그런 다음 Android 빌드 지원 OpenJDK, Android SDK NDK 도구를 활성화합니다. Unity 6가 설치되었으므로 신규 Unity URP 프로젝트를 생성할 수 있습니다. URP는 성능 최적화 크로스 플랫폼 호환성 모터 렌더링 기능 덕분에 VR 개발에 권장하는 렌더링 파이프라인입니다. 새 프로젝트를 클릭하고 맨 먼저 Universal 3D 템플릿을 선택하세요. Unity 조직을 선택하거나 조직이 없는 경우 id.unity.com으로 가서 만든 다음 선택하면 됩니다. 프로젝트 이름을 지정하세요. 저는 Blossom Buddy로 하겠습니다. 프로젝트 위치 선택 후, 마지막으로 '프로젝트 만들기'를 클릭합니다. 이제 독립형 프로젝트가 생성되었습니다. Meta Quest 장치용 프로젝트를 빌드하려면 대상 플랫폼을 Meta Quest로 전환해야 합니다. 이렇게 하려면 파일, 빌드 프로파일로 가서 Meta Quest를 선택해 활성화합니다. 그런 다음 플랫폼 전환을 클릭하세요. 새로운 대상 플랫폼과 호환되는 에셋 포맷을 Unity로 불러 스크립트를 다시 컴파일해야 하는데 이 작업은 시간이 다소 걸립니다. 이제 Meta Quest 프로젝트가 생성되어 시작할 준비가 되었습니다. 계층 구조에 세 가지 게임 객체가 있습니다. 메인 카메라, 방향 광원 그리고 글로벌 볼륨입니다. 글로벌 볼륨은 후처리 단계에서 사용합니다. 메인 카메라와 글로벌 볼륨은 삭제하겠습니다. 세션 후반에 카메라 빌딩 블록을 사용해 메인 카메라를 추가할 거예요. 메인 카메라 게임 오브젝트에 헤드셋 위치와 방향을 검색하는 입력 바인딩이 있습니다. Meta 패키지에서 SDK를 다운로드하고 불러오면 카메라 세팅뿐만 아니라 다른 VR용 구성요소도 설정할 수 있습니다. 개별 패키지를 설치하여 프로젝트를 깔끔하게 유지하는 것을 권장합니다. 참고로 Meta XR Interaction SDK를 설치하면 됩니다. 당사의 권장 사항을 지키려면 개발 단계에서 필요한 것만 설치하세요. 우리는 Unity Asset Store로 가서 Meta Mixed Reality Utility Kit 에셋과 Meta XR Core SDK를 추가하겠습니다. 이 에셋으로 Mixed Reality 환경에서 카메라, 컨트롤러 추적 환경 레이 캐스팅 등의 핵심 기능을 사용할 수 있습니다. 오늘 이를 사용해 3D 오브젝트를 렌더링하고 배치해 보겠습니다. 패키지 관리자로 가보면 새로운 에셋이 있을 겁니다. Meta Mixed Reality Utility Kit를 설치하면 Meta XR Core SDK는 자동으로 설치될 겁니다. Mixed Reality Utility Kit에 연결되어 있으니까요. 아직 XR 기능을 활성화하지 마세요. 이미 자동으로 설치된 Unity Core OpenXR 플러그인뿐만 아니라 Meta OpenXR 패키지도 필요합니다. 메타 기술이 적용된 OpenXR 기반의 오클루전 및 환경 레이 캐스팅을 활용하려면요. 이제 Unity에 MetaXR Tools라는 새로운 옵션이 보일 겁니다. 이것을 클릭하고 프로젝트 설정 도구를 선택하세요. 이것은 잠시 후에 다시 다루겠습니다. 우선 OpenXR이 Standalone과 Meta Quest 플랫폼에 올바르게 구성되었는지 확인해 보겠습니다. MetaQuest 및 Standalone의 MetaXR 기능 그룹을 활성화한 후 OpenXR로 가서 인터랙션 프로파일 활성화하기에 새 옵션을 추가합니다. Oculus Touch 컨트롤러 프로파일을 선택하면 Unity에서 OpenXR 입력 매핑을 정확하게 바인딩합니다. 그다음 Meta Quest Occlusion과 Meta Quest Session을 활성화합니다. 두 플랫폼에서 이 작업을 다시 한번 수행합니다. 저는 Meta Quest에 Oculus Touch Controller 프로파일을 추가하지 않을 겁니다. 이는 프로젝트 설정 도구로 해결할 겁니다. MetaXR을 클릭하여 프로젝트 설정 도구로 돌아갑니다. 이 도구로 일반적인 설정 문제를 검토하고 수정해서 SDK 프로젝트를 빠르게 구성할 수 있습니다. 모범 사례, 호환성 및 최적화 기준에 맞는 규칙을 시행해서요. 'Fix All'을 클릭하여 권장 사항을 두 플랫폼에 적용합니다. 이 도구가 어떤 설정을 변경하는지 충분히 이해하려면 권장 사항을 꼼꼼히 읽어보시기 바랍니다. 자, Meta Quest에 프로젝트를 배포하려면 몇 가지 중요한 빌딩 블록을 추가해야 합니다. 먼저 빌딩 블록부터 살펴보겠습니다. Meta XR 도구를 클릭한 다음 빌딩 블록을 클릭합니다. 빌딩 블록은 기본적으로 다양한 SDK를 캡슐화한 기본 구성 요소로 이를 통해 손 추적, 컨트롤러 추적 패스스루 및 인터랙션 기능을 최소한의 코딩으로 프로젝트에 적용시킬 수 있습니다. 제가 좋아하는 이 빌딩 블록의 장점 중 하나는 다양한 그룹 빌딩 블록 컬렉션을 보유한 점입니다. 그래서 사용 사례에 맞는 블록을 빠르게 찾을 수 있습니다. Mixed Reality를 클릭하고 패스스루 빌딩 블록을 클릭하면 연관성 외 추가적인 블록 세부 정보를 알 수 있죠. 더하기 기호를 클릭하여 패스스루 빌딩 블록을 추가하면 계층 구조에 두 개의 블록이 추가된 것을 볼 수 있습니다. 하나가 카메라인데 패스스루 빌딩 블록에 연결되어 있으며 다른 하나는 패스스루 빌딩 블록입니다. Meta Quest 컨트롤러를 추적하고 렌더링하기 위해 컨트롤러 추적 빌딩 블록도 추가하겠습니다. 기본 모델로 장면을 테스트하려면 계층구조에 마우스 우클릭하고 3D 오브젝트를 클릭한 다음 큐브를 추가합니다. 이름은 Simple Red Cube로 하겠습니다. 빠르게 기본 빨간색을 이 큐브에 적용해 눈에 보이게 만들겠습니다. 몰입 경험을 다루고 있기 때문에 큐브의 위치와 크기가 올바른지 확인해야 합니다. Unity에서 1유닛은 1미터라는 점을 명심하세요. 큐브 크기를 각 축의 1/10로 축소하고 y축과 z축의 위칫값을 각각 1로 수정합니다. 이렇게 하면 이 심플한 빨간색 큐브는 앱을 실행하면 사용자 앞에 나타납니다. 프로젝트 설정 도구로 돌아가서 모든 변경 사항을 검토하세요. 새 빌딩 블록을 추가해 업데이트하면 새로운 권장 사항이 있을 수도, 없을 수도 있습니다. 이제 Meta Quest 기기에서 개발자 모드를 활성화하는 방법을 보여드리겠습니다. 개발자 모드를 사용하려면 Meta 계정이 필요합니다. 만약 없다면 developers.meta.com/horizon으로 가서 로그인한 후 Meta 계정을 만드세요. 이메일 주소와 기타 개인 정보를 추가하세요. 다음 단계로 넘어가 2단계 인증이나 결제 방법으로 계정을 인증하세요. 다음을 클릭하고 조직 이름을 입력하면 계정이 생성될 겁니다. 이제 모바일 기기에 Meta Horizon 앱을 다운로드하고 새로 만든 계정으로 로그인하세요. 새 장치에 페어링하라는 메시지가 표시되면 Meta Quest 모델을 선택하고 지침에 따라 헤드셋을 페어링하세요. 페어링이 완료되면 헤드셋 설정으로 이동하세요. 개발자 모드 개발자 모드 옵션을 켜서 활성화합니다. Meta Quest 장치와 컴퓨터를 USB-C 케이블로 연결하세요. USB-C 3.0 이상의 속도를 지원하는 케이블을 사용하는 것이 좋습니다. 헤드셋에 USB 연결히라는 메시지가 표시됩니다. USB를 연결을 하세요. Unity에서 파일, 빌드 프로파일을 클릭하면 Run Device 드롭다운에 내 장치가 있을 겁니다. 없다면 새로 고침하고 선택하세요. Build and Run을 클릭하고 앱에 APK 이름을 입력합니다. 앱에 HelloRedCube.apk를 입력하겠습니다. 좋습니다, 성공했어요. 이제 Meta Quest 기기에서 VR 환경이 완벽하게 실행됩니다. 카메라, 패스스루 컨트롤러 추적 기능이 있고 심플한 빨간색 큐브도 사용자 앞에 있습니다. 하지만 인터랙션이 조금 아쉬운 것 같습니다. 빌딩 블록의 놀라운 기능을 사용하기 위해 Meta XR Interaction SDK 패키지를 소개하겠습니다. 먼저 패키지 관리자에서 가져옵니다. My Assets에 없다면 Unity Asset Store에서 검색해 보세요. 심플한 빨간 큐브에 있는 인터랙티브 요소를 옮겨 보세요. 이는 기본 데모에 SDK 잡기 기능을 추가한 것입니다. 컨트롤러의 잡기 인터랙션이 완벽하게 작동합니다. 더 좋은 점은 컨트롤러나 손으로 매끄럽게 전환할 수 있다는 것입니다. 이제 헤드셋으로 빨간색 큐브가 잘 보입니다. 하지만 여기가 끝이 아닙니다. 큐브를 이 멋진 로봇으로 바꿔 더 완성도 있는 데모를 만들어 보겠습니다. Instant Content Placement라는 빌딩 블록을 추가합니다. 이 빌딩 블록은 실시간으로 깊이 감지 데이터를 이용해 공간을 설정하지 않고도 표면에서 지점을 찾아 정확히 맞춥니다. 추가된 빌딩 블록 중 일부를 삭제하겠습니다. Environment Raycast 관리자는 제외합니다. Plant Placement Robot 컨트롤러라는 Instant Content Placement 커스텀 버전이 있으니까요. 이 버전은 로봇을 식물의 스폰 포지션으로 안내하고 로봇 애니메이션 상태를 관리합니다. 이 구성 요소의 라인 렌더 레퍼런스도 수정해야 합니다. 로봇 애니메이터 컨트롤러 식물 배치 시 사용하는 손과 컨트롤러 그리고 스폰할 식물 목록이죠. 이제 현재 장면을 장면 목록에 추가하고 새 빌드를 생성하여 배포해 보죠. 이번에는 원하는 위치를 조준하는 옵션을 추가해서 A 버튼을 눌러 새로운 식물을 스폰하겠습니다. 우리 로봇도 식물 위치로 이동합니다. 공간을 따로 설정할 필요가 없습니다. Instant Content Placement 빌딩 블록과 Environment Raycast 관리자는 실제 공간에 레이캐스트를 쉽게 사용할 수 있게 해줍니다. 이상입니다. 모든 단계를 이해하셨나요? 그렇다면 잘하셨습니다! 세션을 시청해 주셔서 정말 감사합니다. 첫 VR 경험 제작에 대한 기본 방법을 이해하는 데 도움이 되었길 바랍니다. 마지막으로 Meta XR Interaction SDK를 다운로드하거나 오늘 알려드린 독립 패키지 중 하나를 가지고 프로토타입 앱이나 게임을 만들어 보세요.
