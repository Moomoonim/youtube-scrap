## 스크립트

인프라는 성능, 신뢰성, 보안, 확장성 및 비용 효율성이 서로 조화롭게 작동하도록 설계될 때 최상의 성능을 발휘합니다. Azure는 컴퓨팅, 스토리지 및 네트워킹 전반에 걸쳐 시스템 수준의 접근 방식을 제공하여 오늘날의 워크로드와 미래의 워크로드를 위한 인프라를 구축, 실행, 최적화할 수 있도록 지원합니다 . 우리는 여러분이 비용을 관리하고, 성능을 극대화하며, 클라우드 투자가 실질적인 비즈니스 가치를 창출하도록 돕는 실용적인 전략들을 분석해 볼 것입니다. 저희가 구축하는 서비스는 설계 단계부터 안전하며, 기본적으로 안전하고, 운영 또한 안전합니다. 이는 우리가 하는 모든 일과 우리가 만드는 모든 것의 지침이 됩니다. 우리는 총체적인 [음악적] 접근 방식, 즉 회복 탄력성의 의미를 이해하는 것에서 시작하는 여정에 대해 이야기하고 있습니다. Azure IAS를 사용하면 [음악] 단순히 워크로드를 실행하는 것만이 아닙니다. 당신은 혁신을 가속화하고 비즈니스를 성장시키고 있습니다 . [음악]
