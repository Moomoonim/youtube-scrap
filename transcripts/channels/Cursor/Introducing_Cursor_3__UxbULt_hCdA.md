## 스크립트

Coding is changing and it's changing for the better. The gap between imagination and reality is shrinking to an instant and it's because coding agents are getting so good. They're getting smarter, they're getting faster and so that's why we're excited to announce Cursor 3. It's a home for your agents and it combines the power of a professional development environment, language servers, files, remote SSH with all of the models and the ability to run as many agents as you want anywhere. Either quickly on your computer or you can hand off entire projects to agents that run in the cloud. &gt;&gt; In the new Cursor, the way you build software is you're talking to agents. You have all of your agents in one place. You can look at changes. You can test them out and then take them all the way to a merged PR. You can dive deep when you really need to, looking at changes, clicking around, going to definition. Probably the most exciting part is that local and cloud are really, really seamless. You can pull an agent locally. You can iterate with it and then zap it back up onto the cloud when you want to let it work on its own. It's really fun to work with agent locally, but then at the end of the day, you want to be in a zen state where you're interacting with all these different agents that are running on different machines. &gt;&gt; We announced Cloud a month ago where agents can now run code end to end with their own sandbox and work on full projects. We announced Composer 2 a couple of weeks ago, which is a frontier model with incredibly high limits and very quick speeds. And now we have Cursor 3 out into the world. And so with these pieces together of model, product and runtime, we're excited to build toward a world where agents really feel like colleagues and where you can build anything you'd like on a computer instantly.
