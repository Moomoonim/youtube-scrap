## 스크립트

As your project grows, every wrong line creates confused users and unusable agents. So what if you could audit your entire doc site in under a minute? Hi, I'm Sarah Chieng from Cerebras, and today I am joined by Paul Klein from Browserbase. We built a Docs QA agent powered by Cerebras and Browserbase, and we're giving you the cookbook to build it yourself. Point it at any documentation site, the agent crawls every single page, checks every link, reads every code snippet, and compares it all against your actual GitHub repo. It returns a full report: what's broken, where, and why, and with suggested fixes and source references. 30 pages, 43 issues found, all in under one minute. This is only possible with Cerebras. Running inference on the world's largest AI chip, the Wafer Scale Engine 3, Cerebrus delivers over 3,000 tokens per second, 15 times faster than on GPUs. Browserbase is a headless browser. It gives the AI the ability to use the browser, just like you would to do work online for you. Paired with Browserbase's headless browser infrastructure, you have a QA pipeline that would take a developer 10 hours a week compressed into a single run. To build this yourself, our full cookbook is live right now. You'll get starter code, API guides, and free credits for both Cerebras and Browserbase. Let's start building.
