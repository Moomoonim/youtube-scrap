## 스크립트

안녕하세요 여러분, 브랜든 마이크입니다. 오늘 영상에서는 제가 가장 좋아하는 AWS 개발자 도구 중 하나인 AWS 툴킷에 대해 이야기해 보겠습니다. [음악] 계속 시청해 주세요! 아직 설치하지 않으셨다면 먼저 설치해 주셔야 합니다. AWS 툴킷은 Visual Studio, Visual Studio Code, JetBrains Rider용 확장 프로그램으로 제공됩니다. 설치하려면 Visual Studio Marketplace로 이동하여 다운로드를 클릭하면 설치 가능한 실행 파일이 다운로드됩니다. 다운로드가 완료되면 파일을 더블 클릭하여 확장 프로그램을 설치합니다. 이제 Visual Studio에서 확장 프로그램을 설치했으니, 몇 가지 기능을 사용해 보겠습니다. 먼저 AWS Explorer를 열어 보겠습니다. AWS Explorer를 사용하면 AWS 계정에 연결 하고 AWS에서 사용하는 모든 기능과 상호 작용할 수 있습니다. 먼저 계정에 연결해 보겠습니다. 사용자 추가 버튼을 클릭하면 액세스 키(ACC 키 ID)와 비밀 액세스 키를 입력하라는 메시지가 나타납니다. 입력된 값은 다음과 같습니다. 저는 현재 AWS 콘솔에 있습니다. 이제 살펴보겠습니다. 광고 콘솔에서 IM ID 및 액세스 관리로 이동합니다. 여기에서 사용자를 클릭하고 기존 사용자가 없으면 추가하겠습니다. 제 경우에는 Visual Studio Toolkit을 클릭합니다(철자가 틀렸네요). 보안 자격 증명으로 스크롤하고 다시 스크롤하여 액세스 키 생성을 클릭합니다. 액세스 키 생성을 클릭하고 기타를 선택한 다음 값을 입력합니다. Visual Studio Toolkit이 됩니다. 그러면 액세스 키와 비밀 액세스 키가 생성됩니다. 이 값을 복사하여 Visual Studio Toolkit의 자격 증명 관리자에 붙여넣습니다. 이제 AWS에 인증 및 연결되었으므로 Visual Studio Toolkit에서 사용 가능한 모든 서비스를 볼 수 있습니다. 예를 들어 클라우드에서 실행 중인 기존 AWS Lambda 함수가 있는데, 여기에서 상호 작용할 수 있습니다. 하지만 먼저 새 Lambda 함수를 만들어 보겠습니다. 새 프로젝트로 이동합니다. Toolkit의 가장 좋은 기능 중 하나는 다양한 템플릿입니다. CloudFormation 템플릿과 광고 Lambda 템플릿이 있습니다. 이제 새 AWS Lambda 프로젝트를 만들고 이름을 AWS Toolkit으로 지정합니다. 빈 함수 하나만 있으면 됩니다. Lambda 함수입니다. 이 함수는 아주 아주 간단합니다. 문자열을 입력받아 대문자로 변환합니다. 이제 AWS에 직접 게시해 보겠습니다. 여기에서 프로젝트를 마우스 오른쪽 버튼으로 클릭하고 " AWS Lambda에 게시"를 선택합니다. 함수 이름( AWS 툴킷이라고 지었습니다)을 입력하고 IM 자격 증명을 선택합니다. 저는 이미 클라우드에 게시한 AWS Lambda 함수에서 사용하던 기존 자격 증명을 사용하겠습니다. 그런 다음 "업로드"를 클릭하면 끝입니다. 마우스 클릭 몇 번으로 템플릿을 사용하여 새로운 AWS Lambda 함수를 만들고 AWS 클라우드에 게시했습니다. 이제 게시가 완료되면 AWS 탐색기 왼쪽 패널에 함수가 바로 표시됩니다. 여기에서 함수를 확인할 수 있습니다. 이제 클라우드에서 실행 중이므로 함수를 실행해 볼 수 있습니다. 입력값을 제공하지 않았기 때문에 오류가 발생하므로 소문자로 "hello world"라는 문자열을 입력해 보겠습니다. 다시 실행하면 정상적으로 작동합니다. 저희 응답은 대문자로 된 "Hello World"입니다. 마우스 클릭 몇 번만으로 Visual Studio용 AWS 툴킷의 템플릿을 사용하여 클라우드에서 실행되는 서버리스 Lambda 함수를 만들 수 있습니다. Visual Studio 툴킷의 또 다른 멋진 기능은 로그를 확인할 수 있다는 것입니다. 제가 만든 기존 함수를 살펴보겠습니다. 이 함수는 모바일 앱에서 업로드한 이미지에서 썸네일을 생성하는 함수입니다. 여기에서 클라우드에서 실행 중인 함수의 로그에 액세스하여 모든 것이 계획대로 진행되고 있는지 확인할 수 있습니다. 함께해 주셔서 감사합니다. AWS 클라우드에서 실행하려면 Visual Studio Code와 Write에 Visual Studio용 AWS 툴킷을 다운로드하고 설치하세요. [음악] 오늘 시청해 주셔서 감사합니다. 이 영상이 마음에 드셨다면 아래의 좋아요 버튼을 누르고 구독하여 다음 영상을 놓치지 마세요.
