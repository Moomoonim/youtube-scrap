## 스크립트

저희 목표는 Codex가 여러분이 구축하는 모든 곳에 함께하는 것입니다. 많은 분들에게 그것은 윈도우일 것입니다. 그래서 오늘은 Codex 앱을 Windows용으로 출시하려고 합니다. Codex 앱을 사용하면 여러 프로젝트를 하나의 중앙 인터페이스에서 관리할 수 있습니다. Windows용 Codex 앱은 새롭게 마련된 전용 Windows 샌드박스 내에서 PowerShell을 사용하여 완전히 네이티브 방식으로 실행됩니다. 또한 Codex 앱에서 사용자들이 좋아하는 모든 기능을 추가할 예정입니다. 여기에는 Codex의 기능을 쉽게 발견하고 확장할 수 있는 스킬 , Codex가 백그라운드에서 자동으로 작동하도록 하는 자동화 기능, 동일한 프로젝트 내에서 여러 독립적인 작업을 처리할 수 있는 작업 트리 등이 포함됩니다 . 저희 스킬 갤러리에서 윈도우 앱 개발자를 위한 WinUI 전용 스킬과 같은 새로운 윈도우 전용 스킬도 찾아보실 수 있습니다. Windows Subsystem for Linux를 사용하여 앱을 개발하는 것을 선호하는 사용자를 위해 코딩 에이전트와 통합 터미널을 WSL 내에서 작동하도록 전환하는 기능을 추가했습니다. Microsoft Store 또는 openai.com/codex에서 앱을 다운로드하고 기존 ChatGPT 구독 또는 API 키를 사용하여 로그인하세요. 여러분이 무엇을 만들어낼지 정말 기대됩니다.
