## 스크립트

이 튜토리얼에서는 Oracle Analytics Cloud에서 외부 소스 에서 생성된 데이터 세트 테이블을 다시 로드하는 방법을 알아봅니다 . 외부 연결을 사용하여 데이터 세트를 구축할 때 OAC는 성능 향상을 위해 데이터의 캐시된 복사본을 저장할 수 있습니다 . 새로 고침은 소스 시스템에 대해 쿼리를 다시 실행하여 캐시된 데이터를 새로 고칩니다 . 이 시나리오에서는 판매 대시보드를 검토하고 있는데 , 표시된 수치가 지난주 캐시된 데이터를 반영하고 있습니다. 데이터 세트가 캐싱을 사용하기 때문에 최신 결과를 보려면 데이터를 다시 로드해야 합니다 . 홈페이지에서 시작해서 내비게이터를 선택한 다음 데이터를 선택하겠습니다. 외부 연결( 이 경우에는 Oracle Autonomous AI 데이터베이스)을 통해 생성된 데이터 세트를 찾겠습니다. 데이터 세트를 마우스 오른쪽 버튼으로 클릭하고 ' 데이터 새로 고침'을 선택하겠습니다. 데이터 새로고침 탭에는 내 데이터 세트에 있는 모든 테이블이 나열됩니다. 자동 캐싱으로 설정된 테이블만 다시 로드할 수 있습니다. 일부 테이블은 실시간 테이블로 설정되어 있어 쿼리가 매번 소스에 대해 직접 실행되고 다시 로드할 필요가 없습니다. 새로 고칠 테이블을 선택한 다음 지금 실행하겠습니다. 이렇게 하면 소스 시스템에 대해 쿼리가 다시 실행되고 선택한 테이블에 대한 캐시가 새로 고쳐집니다. Oracle Analytics Cloud는 백그라운드에서 새로 고침 작업을 실행하며 , 기록 탭에서 진행 상황을 추적할 수 있습니다 . 수동으로 새로고침하고 싶지 않다면 캐시된 테이블을 자동으로 새로 고치도록 일정을 설정할 수 있습니다. 일정 탭을 선택한 다음 새로 만들기를 선택하겠습니다. 일정 대화 상자에서 반복 옵션으로 '매일'을 선택하고 종료 날짜 와 시간을 지정합니다. 확인하겠습니다 . 이제 Acme 판매 데이터 세트에서 판매 테이블을 새로 고치는 일일 일정을 확인할 수 있습니다 . 일정을 선택하여 실행 기록을 포함한 세부 정보를 검토하겠습니다. 데이터 세트 테이블을 다시 로드하고 일정을 설정했으므로 이제 수동으로 새로 고침할 필요 없이 대시보드를 최신 상태로 유지할 수 있습니다 . 아래 링크에서 이 시리즈의 다른 비디오와 Oracle Analytics Cloud 사용에 대한 추가 자료를 찾아보세요.
