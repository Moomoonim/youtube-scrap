## 스크립트

음악 분야의 업무량과 AI 기술의 가치가 높아질수록 위험도 증가합니다. 데이터 노출, 서비스 중단, 규정 준수 의무, 그리고 끊임없이 변화하는 법률은 클라우드 환경에서 [음악]을 운영할 때 직면할 수 있는 복잡한 문제들 중 일부에 불과합니다. 마이크로소프트는 데이터 보안의 중요성을 잘 알고 있으며, 고객 데이터에 대한 완벽한 제어와 신뢰를 유지하는 것이 무엇보다 중요하다고 생각합니다. 그래서 마이크로소프트 Azure는 모든 공용 리전에서 사용자가 데이터를 완벽하게 제어할 수 있도록 설계했습니다. 음악 파일이 어디에 저장되는지, 어떻게 보호되는지, 그리고 누가 접근할 수 있는지에 대한 정보입니다. Azure Key Vault Premium 과 Azure Key Vault Managed HSM은 Microsoft를 포함한 모든 에이전트가 데이터를 암호화하는 암호화 키를 포함하여 데이터 및 비밀에 대한 무단 액세스를 차단하도록 설계, 배포 및 운영됩니다 . Azure Key Vault Premium은 엔터프라이즈 규모 에서 타의 추종을 불허하는 가용성과 복원력을 제공하여 가장 큰 규모의 금융 및 정부 워크로드에 대해서도 지속적인 운영과 안심을 보장합니다. 역할 기반 [음악] 액세스 및 HSM 기반 키 보호와 같은 엔터프라이즈급 운영 제어를 통해 Azure Key Vault Premium은 전용 하드웨어 관리의 필요성을 없애 면서 민감한 암호화 [음악] 자산에 대한 거버넌스, 규정 준수 및 복원력을 보장합니다 . 음악 격리, 규정 준수 및 성능 요구 사항이 더 까다로운 조직의 경우 Azure 관리형 HSM 음악은 최고 수준의 운영 보안을 제공합니다. [음악] 전용 SGX 인클레이브와 쌍을 이루는 FIPS 140-3 레벨 3 인증 HSM을 활용합니다 . 관리형 HSM은 금융, 정부, 의료와 같은 산업 분야의 엄격한 규제 및 준수 요구 사항을 지원하는 동시에 고객 키가 Microsoft 운영자와 완전히 격리되도록 보장합니다 . HSN의 물리적 위치를 제어해야 하는 조직의 경우, HSM으로 관리되는 기능을 통해 사내 또는 신뢰할 수 있는 타사 서비스 제공업체를 통해 외부 키 관리가 가능합니다. [음악] Azure Key Vault Premium과 관리형 HSM을 사용하면 모든 조직은 원하는 지역 에 데이터와 비밀 정보를 안전하게 저장할 수 있으며, 허가 없이는 누구도 해당 비밀 정보에 접근할 수 없다는 확신을 가질 수 있습니다. 마이크로소프트는 클라우드의 이점을 저해하지 않으면서 모든 고객 워크로드에 대해 데이터 주권 및 [음악] 보안을 보장하기 위해 최선을 다하고 있습니다.
