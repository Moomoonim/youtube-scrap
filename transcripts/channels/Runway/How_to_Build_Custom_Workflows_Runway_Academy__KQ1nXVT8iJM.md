[music] Now, we're going to connect our text node to the system prompt input of the LLM node, which is serving as the system instructions. 다음으로 첫 번째 LLM 노드의 출력을 텍스트 프롬프트 입력에 연결합니다. 이렇게 하면 LLM에게 더 큰 목록에서 첫 번째 프롬프트만 추출하도록 지시하게 됩니다. 마지막으로, LLM 노드의 출력을 이미지 생성 노드의 프롬프트 입력에 연결하고, 제품 이미지를 이미지 슬롯 1에 입력합니다.
