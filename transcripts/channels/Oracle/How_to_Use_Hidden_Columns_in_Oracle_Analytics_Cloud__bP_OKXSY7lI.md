## 스크립트

이 튜토리얼에서는 Oracle Analytics Cloud 시각화에서 숨겨진 열을 사용하는 방법을 알아봅니다 . 숨겨진 열을 사용하면 해당 열을 표시하지 않고도 시각화에서 정렬, 그룹화, 집계, 필터링 또는 계산을 실행할 수 있습니다 . 이 기능을 사용하면 해당 열이 시각화에 나타나지 않도록 하더라도 해당 열을 사용하여 시각화를 정의하거나 서식을 지정할 수 있습니다. 이 시나리오에서는 고객에게 제품별 최근 판매량을 보여주고 싶습니다 . 숨겨진 열을 포함하는 시각화를 생성하여 최종 사용자에게 직접 표시 하지 않고도 특정 데이터 요소를 사용할 수 있도록 하겠습니다 . 새 통합 문서를 만들기 위해 주문 내역 데이터 세트를 선택하겠습니다. 먼저 사용자들이 제품과 관련 지표를 분석할 수 있도록 표 형식의 시각화 자료를 만들겠습니다. 제품명, 주문 수량, 판매량, 배송비를 모두 선택하겠습니다. 그런 다음 ' 판매'를 마우스 오른쪽 버튼으로 클릭하고 '시각화 선택'을 선택한 후 '테이블'을 선택합니다. 이 차트에서 제품들을 제품 카테고리 와 하위 카테고리 순으로 정렬해 주시면 좋겠습니다. 이렇게 정렬하려면 제품 카테고리와 제품 하위 카테고리를 테이블 행 맨 위로 드래그하면 됩니다. 이제 제품들은 제품 카테고리와 제품 하위 카테고리별로 표에 그룹화되어 있습니다. 순서는 그대로 유지하고 싶지만, 사용자는 표에서 제품 카테고리나 제품 하위 카테고리를 볼 필요가 없습니다. 제품 카테고리를 마우스 오른쪽 버튼으로 클릭하고 숨기기를 선택하겠습니다. 그런 다음 제품 하위 카테고리에 대해서도 동일한 단계를 반복하여 숨깁니다. 해당 열들이 여전히 보이는 것처럼 표의 순서가 유지됩니다. 다음으로, 사용자가 제품 하위 카테고리별 주문 수량을 비교하고 수익성이 높은 영역을 강조 표시할 수 있도록 또 다른 표 형식 시각화를 만들겠습니다. 제품 하위 카테고리 와 매출을 다중 선택한 다음, 매출을 마우스 오른쪽 버튼으로 클릭하고 시각화 선택을 선택한 후 테이블을 선택하여 캔버스에 새 시각화로 표시합니다. 사용자들은 수익성이 높은 하위 카테고리가 강조되도록 테이블 순서를 조정해야 합니다. 그럼 표 행에서 수익을 매출 바로 아래로 끌어다 놓겠습니다. 수익 열 헤더를 마우스 오른쪽 버튼으로 클릭하고 수익이 높은 순서부터 낮은 순서로 정렬하여 수익이 가장 높은 제품 하위 카테고리가 맨 위에 표시되도록 하겠습니다. 현재 정렬 순서를 유지하고 싶지만 , 사용자는 표에서 수익을 볼 필요는 없습니다. 그럼, 행 드롭 대상에서 수익을 마우스 오른쪽 버튼으로 클릭하고 숨기기를 선택하겠습니다. 제품 하위 카테고리별 판매량 표는 수익 열이 더 이상 표시되지 않더라도 수익 순으로 정렬된 상태를 유지합니다. 다음으로, 사용자들이 제품 카테고리 별 주문 수량 데이터를 분석할 수 있도록 막대 그래프를 만들겠습니다 . 데이터 창에서 주문 수량과 제품 카테고리를 선택한 다음, 제품 카테고리를 마우스 오른쪽 버튼으로 클릭합니다. 시각화 선택을 클릭한 다음 가로 막대 차트를 선택하세요. 사용자가 각 제품 카테고리 내의 하위 카테고리를 쉽게 구분할 수 있도록 제품 하위 카테고리를 색상 드롭 영역으로 드래그하겠습니다. 보다 보기 쉽게 주문량 순으로 정렬된 막대 그래프로 복원하겠습니다. 막대 그래프가 사용자 요구 사항을 명확히 충족하므로 제품 하위 카테고리 범례는 더 이상 필요하지 않습니다. 색상 선택 영역에서 제품 하위 카테고리를 마우스 오른쪽 버튼으로 클릭하고 숨기기를 선택하겠습니다. 해당 열은 이제 숨겨지고 범례가 제거되었습니다. 하지만 사용자는 막대 위에 마우스를 올려놓으면 각 세그먼트가 어떤 하위 범주 에 속하는지 확인할 수 있습니다. 숨겨진 열은 시각화에서 제거되지만 툴팁에는 계속 표시된다는 점을 유의하십시오. 즉, 사용자는 시각화에서 막대, 표시 또는 데이터 포인트 위에 마우스를 올리면 숨겨진 세부 정보를 계속 확인할 수 있습니다 . 숨겨진 열을 사용하여 정렬, 그룹화 및 서식을 세밀하게 조정함으로써 통합 문서 사용자 의 사용자 경험을 향상시킬 수 있습니다 . 아래 링크에서 이 시리즈의 다른 비디오와 Oracle Analytics Cloud 사용에 대한 추가 자료를 찾아보세요.
