## 스크립트

안녕하세요, repet의 Matt입니다. 오늘은 언어를 설치하고 repet 프로젝트를 열 때 작업 공간을 구성하는 방법을 보여드리겠습니다. 여기 repet 작업 공간이 있습니다. 빈 repet 프로젝트가 보이시죠? README 파일 하나만 있고, 셸도 비어 있습니다. 먼저 언어를 추가해 보겠습니다. 종속성 탭으로 이동하면 언어와 패키지 두 가지 유형의 종속성을 설치할 수 있습니다. 먼저 새 모듈을 추가해 보겠습니다. Python을 설치할게요. Python 3.13을 설치하려면 다운로드 아이콘을 클릭하면 됩니다. 모듈이 설치되었죠. 다음으로 Python 패키지 관리자로 이동하여 새 패키지를 추가해 보겠습니다. 여기서는 pandas라고 하겠습니다. pandas가 보이시죠? piie에서 제공하는 올바른 P 패키지입니다. 설치를 클릭하면 pandas가 설치됩니다. 왼쪽에서 몇 가지 변화를 볼 수 있습니다. p 프로젝트가 생성되었죠. toml 파일이 있는데, 이것이 바로 우리가 사용하는 패키지 관리자 UV가 종속성을 관리하는 데 사용하는 파일입니다. requirements.txt 파일이나 다른 종속성 관리 방법을 아시는 분들은 아시겠지만, 종속성은 버전 번호와 함께 나열됩니다. 종속성을 추가하는 방법은 여러 가지가 있습니다. 예를 들어, 여기에 numpy 1213과 같은 패키지를 추가할 수도 있지만, 그렇게 하는 대신 셸에서 `UV add numpy`와 같이 입력할 수 있습니다. 사실 pandas와 함께 이미 추가되어 있어야 하지만, 이제 numpy가 종속성 창에 추가된 것을 볼 수 있습니다. 간단히 말해, 파이썬 패키지 관리를 설정한 것입니다. 파이썬 템플릿을 사용하는 경우 이 과정이 이미 설정되어 있어 모든 패키지가 이미 표시될 가능성이 높지만, 처음부터 시작하는 방법을 명확하게 설명하고 싶었습니다. 앞서 언어를 설치하고 종속성을 설치하는 방법을 설명했으니, 이제 종속성을 관리하고 실행 버튼을 구성하여 빌드를 시작하는 방법을 보여드리겠습니다. 이 설정은 반복 파일에 포함되어 있으며, 이를 확인하려면 세 개의 점을 클릭 하고 '숨겨진 파일 표시'를 클릭해야 할 수도 있습니다. 그러면 설정 파일에서 해당 내용을 볼 수 있습니다. 실행 버튼은 간단하게 ` Python main.py`와 같이 설정할 수 있습니다. 이는 main.pi 파일을 실행하는 Python 명령어입니다. 예를 들어, ` if name equals main`과 같이 설정하면 기본 Python 실행 명령어가 실행됩니다. ` hello world`를 실행해 보겠습니다. 간단하죠? 이제 실행 버튼을 클릭하면 화면에 색종이 조각이 흩날리고 콘솔에 `hello world`가 표시되는 것을 볼 수 있습니다. 이 Rebel 보드는 특정 파일을 실행하도록 설정되어 있으며, Python과 필요한 종속성도 설치되었습니다. 템플릿에서 시작하는 경우 이러한 것들이 이미 설치되어 있을 가능성이 높지만, Node 템플릿에서 Python을 추가하려면 동일한 과정을 따르면 됩니다. 다시 한번 말씀드리지만, 이 기능을 사용할 수 있습니다. 의존성 탭에서 시스템 모듈과 시스템 의존성을 설치합니다. 여기서 병렬적인 점은 모듈은 repet 파일의 modules 매개변수로 제어되고, 실행 명령은 Run 매개변수로 제어된다는 것입니다. 패키지 관리자를 사용하는 경우, 예를 들어 Python을 사용하는 경우 repet의 기본값은 UV입니다. 이 패키지 관리자를 사용하는 경우 P 프로젝트 toml 파일에서 해당 모듈들을 정의할 수 있습니다. Node.js를 사용하는 경우 package.json 파일에서 정의합니다. 이렇게 몇 분 만에 Python을 설치하고, 의존성을 구성하고, 언어를 설치했습니다. 이것이 repet에서 Python의 의존성과 언어를 관리하는 방법입니다. repet에 대한 설명은 여기까지입니다. 다음에 또 뵙겠습니다. 평화!
