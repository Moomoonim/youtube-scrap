## 스크립트

현대의 대규모 AI 학습은 방대한 양의 데이터와 컴퓨팅 리소스를 소모하는 복잡한 작업입니다. 네트워크를 통해 동기화된 여러 분산 노드와 장치에서 실행되는 이러한 복잡한 워크로드를 최적화하는 것은 성능 병목 현상을 정확히 파악하기 어려운 과제입니다. 개발자는 클러스터 규모 컴퓨팅에서 생성되는 엄청난 양의 메트릭을 수집하고 분석할 수 있어야 합니다. Insight Systems는 NVIDIA의 무료 시스템 전체 성능 프로파일링 및 분석 도구로, 통합 타임라인에서 성능 메트릭을 시각화하여 개발자가 병목 현상을 신속하게 진단하고 애플리케이션 성능을 향상시킬 수 있도록 지원합니다. Insight Systems 버전 20247 Point1은 클러스터 또는 클라우드 애플리케이션의 스토리지 사용량을 프로파일링하고 최적화하는 새로운 기능을 도입했습니다. DDNA AAI 400 X2 데이터 인텔리전스 플랫폼을 사용하여 최신 AI 스토리지 워크로드를 가속화하는 AI 학습 애플리케이션을 프로파일링하면서 이러한 기능을 시연하겠습니다. 프로파일링 데이터를 수집하기 위해 DDNA X Escaler 클라이언트 성능 카운터 수집과 프로파일링된 애플리케이션에서 호출된 Linux POSIX 함수 추적을 활성화하는 명령줄 옵션이 있는 NUS 실행 파일을 사용합니다. 프로파일링 세션이 종료되면 보고서 파일이 생성되며, 이 파일은 로드하여 볼 수 있습니다. Insight Systems 타임라인은 애플리케이션이 스토리지에 액세스하는 데 사용한 Linux POSIX 함수와 DDN Exos 스케일러 클라이언트 드라이버에서 보고한 성능 지표를 표시합니다. 이러한 지표는 애플리케이션 에서 수행한 스토리지 관련 활동의 결과입니다. Insight Systems는 개발자가 노드 클러스터 전체의 성능 지표를 검토할 수 있도록 다중 노드 분석을 위한 레시피라는 Python 스크립트를 포함하는 분석 프레임워크를 제공합니다. Insight Systems 버전 202 24.71에서는 스토리지 사용량을 검사할 수 있는 새로운 데이터 분석 레시피가 도입되었습니다. 여기에는 클러스터 수준 스토리지 처리량 그래프와 다중 노드 스토리지 처리량 히트맵이 포함됩니다. 레시피는 개발자가 유휴 스토리지 시간, 최대 스토리지 사용 시간을 파악하고 애플리케이션 스토리지 사용량을 최적화하여 성능을 향상시키는 데 도움이 됩니다.
