AWS 콘솔 또는 API를 사용하여 가드 레일을 구축할 수 있습니다. 두 방법 모두 과정은 동일합니다. 먼저 구성을 설정하여 가드 레일을 생성합니다. 차단할 토픽을 정의하고, 유해하거나 민감한 콘텐츠를 처리할 필터를 제공합니다. 또한 프롬프트와 사용자 응답에 대한 메시지를 작성하여 차단 여부를 결정합니다. 가드 레일에는 최소 하나 이상의 필터와 프롬프트 및 사용자 응답이 차단될 때 표시될 메시지가 포함되어야 합니다. 원한다면 기본 메시지를 사용할 수도 있습니다. 나중에 필터를 추가하고 가드 레일을 기반으로 구축하여 더 많은 구성 요소를 추가할 수 있습니다. 가드 레일을 수정하여 필요한 모든 구성 요소를 구성함으로써 이를 수행할 수 있습니다. 이제 설정해 보겠습니다. Jupyter Notebook에서 Python 과 가드 레일 API를 사용하여 설정하겠습니다. 여기서는 모든 핵심 기능이 구현되는 메인 함수에 집중하겠습니다. PII 가드 레일 생성 함수는 AWS Bedrock을 위한 강력한 개인 식별 정보(PII) 보호 가드 레일을 구축합니다. 이 함수는 Bedrock 클라이언트 가드 레일 이름, 설명, 그리고 세 가지 핵심 매개변수를 받아 여러 계층의 정교한 데이터 개인 정보 보호 설정을 통해 이를 수행합니다. 또한 이 함수를 통해 정확한 보안 및 구현에 있어 유연성을 확보할 수 있습니다. 이 함수의 포괄적인 전략은 여러 가지 중요한 보호 메커니즘을 포함합니다. 민감한 정보가 감지될 때 명확하게 전달하는 사용자 지정 차단 메시지를 설정하여 데이터 보호의 투명성을 보장합니다. 이 함수는 이메일 주소, 전화번호, 신용카드 정보, 사회 보장 번호, 실제 주소와 같은 중요한 개인 식별 정보 유형을 식별합니다. 표준 감지 외에도 고급 사용자 지정 거부 기능을 통합할 수도 있습니다. 이 패턴은 특히 복잡한 이메일 주소와 형식을 포착하도록 설계되었습니다. 예를 들어, 이 가드 레일은 한 단계 더 나아가 잠재적인 부정행위에 대한 강력한 콘텐츠 필터링을 구현하고 특정 민감한 키워드에 대한 단어 정책을 통합하여 보안을 강화합니다. 이를 통해 잠재적인 정보 유출에 대한 다중 장벽을 구축합니다. 이러한 다각적인 접근 방식은 입력 및 출력 시나리오 전반에 걸쳐 민감한 개인 데이터에 대한 포괄적이고 지능적인 보호를 보장합니다. 함수가 호출되면 가드 레일이 생성되고, 고유 식별자 또는 가드 레일 ID가 생성됩니다. 이를 통해 개인 식별 정보(PII) 보호 구성을 정확하게 추적하고 관리할 수 있습니다. 반환된 가드 레일은 향후 참조 또는 추가 보안 관리에 사용할 수 있습니다. 이제 이 코드를 실행하고 출력을 얻으면 나중에 다른 코드에서 사용할 수 있도록 일부 세부 정보를 복사합니다. 가드 레일을 생성했으면 일부 데이터를 사용하여 테스트해야 합니다. 이 예에서는 JSON 파일을 사용할 수 있습니다. JSON 파일은 각 줄에 유효한 JSON 객체가 포함된 텍스트 기반 파일 형식입니다. 기본적으로 줄 바꿈 문자로 구분된 JSON 객체의 모음입니다. 따라서 읽고 처리하기가 매우 쉽습니다. 대규모 데이터 세트의 경우에도 이 JSON L 파일에는 피자 주문에 대한 고객 피드백 데이터가 포함되어 있습니다. 각 행은 고객 ID, 피드백 내용, 피자 종류, 평점 및 연락처 정보를 포함한 단일 피드백 기록을 나타냅니다. 또한 모델 입력 섹션이 있는데, 이는 모델이 피드백을 분석하는 데 필요한 지침을 제공합니다. 이 데이터는 감성 분석 모델을 학습하는 데 사용되며, 고객 선호도 추세를 파악하거나 고객 서비스를 개선하는 데에도 활용될 수 있습니다. 하지만 이 파일에는 개인 정보 보호가 매우 중요한 정보가 많이 포함되어 있으므로, 이제 이 파일을 S3 버킷에 업로드했습니다. 다음 단계에서 GW를 테스트하여 모든 것이 제대로 작동하는지 확인하기 위해 S3 버킷의 일부 세부 정보가 필요합니다. GW 설정이 완료되었으므로 이전에 복사한 가드레일 ID와 S3 버킷 정보를 여기에 추가해야 합니다. 이 정보를 새 Jupyter Notebook에 추가했습니다. 이 스크립트는 Amazon Web Services Bedrock 플랫폼과 Anthropic Cloud AI 모델을 사용하여 고객 피드백을 분석하도록 설계된 고급 컨텍스트 처리 및 보안 메커니즘을 나타냅니다. 이 스크립트 의 주요 목표는 고객 피드백을 분석하는 것입니다. 이 스크립트는 모든 민감한 입력 데이터를 처리하는 강력하고 안전한 인텔리전스 시스템을 구축하는 동시에 콘텐츠 및 안전 성능을 보장하기 위한 것입니다. 이 프로그램의 핵심에는 피자 가드레일 파이썬 클래스가 있습니다. 이 클래스는 고객 데이터가 머신 러닝 모듈 로 전송되기 전에 사전 정의된 규칙을 준수하는지 확인합니다. 또한 가드레일 정책의 식별자를 가지고 있으며, 이 식별자는 모델 입력 및 메타데이터와 같은 요구 사항 필드를 지정하고 이메일, 전화번호 및 고객 의 개인 정보와 같은 데이터를 검증하는 패턴을 정의합니다. 이 클래스에는 두 가지 주요 기능이 있습니다. 첫 번째는 입력 데이터의 유효성을 검사하는 `Apply` 기능입니다. 이 기능이 성공하면 AWS Bedrock으로 데이터를 전송하여 가드레일 정책을 적용합니다. 두 번째는 가드레일을 사용하여 모델을 호출하는 기능입니다. 이 기능은 검증된 데이터를 사용하여 Amazon Bedrock을 통해 Anthropic Claw 또는 모델을 호출합니다. 모델은 데이터를 처리하고 프로그램이 추가 작업에 사용할 수 있는 응답을 반환합니다. 이 코드의 메인 함수는 모든 것을 통합합니다. AWS 서비스를 연결하고, 식별 가능한 고객 10명이 있는 "Pizza Batch Input 10"이라는 파일을 가져옵니다. 세부 정보는 S3 버킷에서 가져와 각 고객 레코드를 처리합니다. 각 레코드에 대해 피자 가드레일 클래스를 사용하여 데이터의 유효성을 검사하고 , 모든 것이 유효하면 Clae 모델로 전송합니다. 프로그램은 출력에서 다른 이름, 이메일 주소, 전화번호와 같은 민감한 정보를 삭제하여 결과를 표시합니다. 잠시 멈추고 커피 한 잔 마시면서 결과를 확인해 보겠습니다. 결과가 나왔으니, 이 프로그램이 고객 피드백을 단계별로 처리하는 방식을 살펴보고, 특히 Amazon Bedrock 가드레일을 중심으로 데이터 개인 정보 보호 및 민감한 정보 보호를 어떻게 보장하는지 알아보겠습니다. 출력 결과를 보면 레코드 ID 001부터 시작합니다. 스크립트는 가드레일을 적용하여 데이터의 유효성을 검사하고, 유효성 검사가 완료되면 Anthropic Clae 모델을 호출합니다. 입력에는 피드백 요약인 "동네 최고의 피자"라는 메시지가 포함되어 있습니다. 이는 버섯 피자에 대한 피드백이며 평점은 1.0입니다. 고객 이름, 이메일 주소, 전화번호와 같은 민감한 정보가 포함되어 있습니다. 모든 데이터는 Amazon GuardRoute에 의해 삭제되고 ' 삭제됨'과 같은 자리 표시자로 대체됩니다. 모델 응답은 모순을 보여주지만, 고객이 피자를 칭찬했음에도 불구하고 평점이 매우 낮다는 점은 모순일 수 있습니다. 이는 비꼬는 말투, 피자 이외의 다른 부분에 대한 불만족, 또는 평점 오류 등 여러 가지 이유로 설명될 수 있습니다. 분석 결과, 고객의 설명이 이러한 불일치를 해결하는 데 도움이 될 것으로 나타났습니다. 첫 번째 고객에 대한 처리가 완료되면 스크립트는 다음 고객 레코드로 이동하고, 동일한 패턴을 반복하며 모든 민감한 데이터를 100% 안전하게 보호합니다. Amazon GuardRoute는 모든 고객 데이터를 보호하는 데 중요한 역할을 해왔으며, 이름, 이메일, 전화 번호와 같은 민감한 정보가 검증 또는 처리 과정에서 유출되지 않도록 보장합니다. 또한 모델이 실행 가능한 인사이트를 위한 피드백에만 집중할 수 있도록 지원합니다.
