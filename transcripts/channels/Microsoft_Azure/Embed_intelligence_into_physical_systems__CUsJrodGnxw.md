NeMo tron은 Nvidia에서 제작했으며 Foundry Local 카탈로그에서 무료로 이용할 수 있습니다. 이와 동시에 카메라에서 프레임이 캡처되고, 개방형 어휘 감지기를 포함한 다양한 비전 모델이 작업 영역 내의 객체를 인식하고 해당 좌표를 제공합니다. 이 모든 정보는 어떤 작업을 수행할지 결정하기 위해 작은 언어 모델에 입력됩니다. Qwen 3을 선택한 이유는 추론 및 도구 호출을 지원하고 Foundry Local 카탈로그에서 무료로 사용할 수 있기 때문입니다 . 이 경우 Qwen은 사용 가능한 네 가지 도구 호출 중에서 지시에 가장 적합한 것을 선택하고, 무엇을 집어 올리고 어디에 놓을지 등의 매개변수를 설정합니다 . 이 예시는 매우 기본적인 것이지만, 로봇 공학에 대한 에이전트 기반 접근 방식의 잠재력을 보여줍니다. 입력, 특히 사람과의 상호작용(음악 포함)은 복잡할 수 있지만, 로봇은 그럼에도 불구하고 사용자가 무엇을 의도했는지 파악할 수 있습니다. 선택된 도구 호출은 일련의 동작 순서를 대기열에 추가하고 나머지는 다른 로봇과 마찬가지로 작동합니다. Azure의 적응형 클라우드 접근 방식은 이러한 시스템을 구축하고 운영하는 것을 그 어느 때보다 쉽게 ​​만들어주는 여러 가지 방법을 제공합니다 . 모든 것은 컴퓨팅 인프라에서 시작됩니다. 이전에는 대형 서버의 Azure Local에서만 사용할 수 있었던 Azure 기반 프로비저닝 및 관리와 같은 기능이 이제 더 작은 폼 팩터에서도 미리 보기로 제공됩니다 . Azure를 사용하면 키보드와 모니터를 연결할 필요 없이 이 산업용 컴퓨터와 같은 장비에 Azure Linux를 원격으로 프로비저닝할 수 있습니다 . 또한 Azure Resource Manager를 통해 통합 제어 평면에서 머신을 기본적으로 관리할 수 있으며, 이는 클라우드 VM과 매우 유사하여 대규모 환경에서 반복성, 거버넌스 및 모니터링을 제공합니다. 예를 들어, Microsoft Entra ID를 사용하여 누가 해당 기기에 액세스할 수 있는지 구성할 수 있습니다. 물리 시스템에 인텔리전스를 내장하기 위해 Foundry Local이 경량 컨테이너 이미지 형태로 Linux 시스템용 프리뷰 버전으로 제공됩니다 . Foundry Local은 AI 에이전트와 모델을 배포하고 실행하는 일관된 방법을 제공하며, 앱 컨테이너와 함께 배포되고 OpenAI 호환 REST 엔드포인트를 통해 액세스할 수 있는 추론 서버를 포함합니다. 이를 통해 신뢰할 수 있는 출처에서 다양한 출판사의 최신 AI 모델을 쉽게 얻을 수 있습니다. 이름만 입력하면 Foundry Local이 방대한 카탈로그에서 해당 모델을 불러옵니다 . 또한 GPU와 같은 사용 가능한 가속기를 감지하고 활용하여 성능을 자동으로 극대화하고, 커널 드라이버부터 사용자 모드 라이브러리에 이르기까지 전체 스택이 [음악]에 맞춰 준비되도록 보장합니다. 저희의 경우, Foundry Local은 Lenovo 장비에 탑재된 NVIDIA RTX GPU를 사용하여 실시간으로 빠른 추론을 제공합니다. 이러한 시스템을 여러 사이트로 확장하려면 운영 가시성과 컨텍스트가 필수적이며, 이것이 바로 Azure IoT Operations를 배포하는 이유입니다. 예를 들어, 저희 로봇 팔은 너무 멀리 있는 물체에는 닿을 수 없습니다. 이러한 현상이 언제, 얼마나 자주 발생하는지는 중요한 통찰력을 제공할 수 있습니다. Azure IoT Operations는 다양한 커넥터와 산업용 MQTT 브로커를 포함하는 엣지용 통합 데이터 플레인으로, 로컬 프로토콜과 로봇과 같은 자산을 클라우드에 연결하여 기능 원격 측정 데이터를 읽고 구성을 다시 기록할 수 있습니다. 배포가 완료되면 운영 경험을 활용하여 데이터 흐름을 구성하고, 변환을 사용하여 로봇의 원격 측정 데이터를 가공한 다음, Microsoft Fabric에 데이터를 중앙 집중화할 수 있습니다. 그러면 데이터 팀에서 시각화를 생성하고 실시간 인텔리전스를 사용하여 로봇의 동작 방식을 더 잘 이해할 수 있습니다. 인공지능의 발전과 Azure의 적응형 클라우드 접근 방식이 결합되어 물리적 시스템에 지능을 내장하는 것이 그 어느 때보다 쉬워지고 있다는 것은 분명합니다. 오늘 바로 시작하실 수 있습니다. 소형 폼팩터 Linux 인프라, Linux용 Foundry Local 및 Azure IoT 운영은 모두 공개적으로 사용할 수 있습니다. 한번 사용해 보시고 의견을 알려주세요. 시청해 주셔서 감사합니다.
