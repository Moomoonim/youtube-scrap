## 스크립트

안녕하세요, 저는 오토입니다. 이번 영상에서는 요원 스킬에 대해 이야기해 보겠습니다. 오늘날 상담원들은 매우 똑똑하지만, 실제 업무에 필요한 전문 지식을 항상 갖추고 있는 것은 아닙니다 . 이러한 문제를 해결하는 데 도움이 되는 기술이 필요합니다. 스킬은 클라우드가 당면한 작업과 관련될 때 자동으로 활용할 수 있는 전문 지식을 체계적으로 정리한 폴더라고 생각할 수 있습니다 . 그리고 가장 중요한 것은 이러한 기술들이 클라우드 코드, API, 그리고 cla.ai 전반에 걸쳐 활용 가능하다는 점입니다. 스킬 작동 방식은 다음과 같습니다. 시스템 시작 시 설치된 모든 스킬의 이름과 설명만 시스템 프롬프트에 로드됩니다. 이 기능은 스킬 하나당 약 30~50개의 토큰을 소모하며, 클로드에게 해당 스킬의 존재를 알려줍니다. 사용자의 입력 내용이 스킬 설명과 일치하면 Claude는 전체 skill.md 파일을 동적으로 불러와 컨텍스트에 표시합니다. 마지막으로, 스킬이 다른 파일이나 스크립트를 참조하는 경우, 해당 파일이나 스크립트도 필요에 따라 순차적으로 로드되어 실행됩니다. 이러한 점진적 공개 방식을 통해 컨텍스트 창을 과도하게 복잡하게 만들지 않고도 복잡한 작업을 수행하는 데 필요한 다양한 스킬을 설치할 수 있습니다. 그럼 스킬이 클로드의 다른 기능들과 어떻게 어우러지는지 살펴보죠 . 스킬은 클로드에게 전문적인 작업을 수행하는 방법을 가르쳐주는 반면, Claude.md 파일은 클로드에게 특정 프로젝트에 대한 정보를 알려줍니다. 텍스트 스택, 코딩 규칙, 저장소 구조와 같은 것들입니다. CloudMD 파일은 저장소에서 코드와 함께 저장됩니다 . CloudMD 파일에는 [음악]에서 Nex.js JS와 Tailwind를 사용한다는 내용이 포함될 수 있습니다 . 하지만 기술은 어떤 프로젝트에서든 활용할 수 있는, 휴대성이 뛰어난 전문 지식입니다. 따라서 프런트엔드 디자인 기술을 활용하면 클로드에게 타이포그래피 표준, 애니메이션 패턴, 레이아웃 규칙 등을 알려줄 수 있고, UI 구성 요소를 구축할 때 음악이 자동으로 활성화됩니다 . 반면 MCP 서버는 범용 통합 기능을 제공하며, 단일 프로토콜을 통해 Claude를 GitHub, Linear, Postgress 등과 같은 외부 컨텍스트 소스에 연결합니다. MCP는 데이터에 연결합니다. 기술은 클로드에게 그것을 어떻게 활용해야 하는지 가르쳐줍니다. 따라서 MCP 서버는 클로드에게 데이터베이스에 대한 접근 권한을 제공할 수 있지만, 데이터베이스 쿼리 기술은 클로드에게 팀의 쿼리 최적화 패턴을 가르쳐줄 수 있습니다. 마지막으로, 서브 에이전트는 고정된 역할을 가진 전문 AI 보조원입니다. 각 하위 에이전트는 고유한 컨텍스트 창, 사용자 지정 프롬프트 및 특정 도구 권한을 갖습니다. 해당 기술은 모든 요원이 사용할 수 있는 휴대 가능한 전문 지식을 제공합니다 . 따라서 프런트엔드 개발자 하위 담당자는 컴포넌트 패턴 기술을 사용할 수 있습니다. 반면 UI 검토 하위 에이전트는 디자인 시스템 스킬을 사용할 수 있지만, 둘 다 동일한 접근성 표준 스킬을 로드하고 사용할 수 있습니다. 그리고 가장 좋은 점은 이러한 기능들이 서로 연동되도록 설계되었다는 것입니다. cloudMD 파일이 기초를 형성합니다. MCP [음악] 서버는 데이터를 연결합니다. 하위 담당자들은 각자의 역할과 기술에 특화되어 있으며, 전문성을 바탕으로 모든 업무를 더욱 효율적이고 능동적으로 만들어줍니다. 결론적으로, 스킬을 활용하면 워크플로우를 재사용 가능한 기능으로 패키징할 수 있습니다. 예를 들어 신입 사원이 팀의 코딩 표준을 익히도록 돕거나, 모든 PR이 특정 보안 모범 사례를 준수하도록 보장하거나, 데이터 분석 방법론을 팀 전체와 공유하는 것 등이 가능합니다. 이처럼 스킬을 활용하면 Claude를 통해 더 많은 것을 성취할 수 있습니다 . 저희는 여러분께서 이 기능들을 사용해 보시고 작업 흐름을 어떻게 개선할 수 있는지 직접 확인해 보시기를 권장합니다.
