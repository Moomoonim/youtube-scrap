VS Code는 에이전트 호스트에 bang 명령어를 추가하여 에이전트 호스트 세션에서 터미널 명령어를 직접 실행할 수 있도록 했습니다 . 이 에디터는 에이전트 세션을 위한 실제 런타임을 제공합니다. 마이크로소프트 코믹챗은 이제 오픈 소스입니다. 1996년에 출시된 이 IRC 클라이언트는 대화를 말풍선, 포즈, 표정이 있는 만화 패널로 바꿔주었습니다 . 또한 이로 인해 Comic Sans라는 폰트가 초창기에 활용했던 작업 중 하나를 맡게 되었습니다. 마이크로소프트 리서치 가상 세계 그룹에서 제작했습니다. 코믹챗은 인터넷 익스플로러 3과 윈도우 98 이후 버전에 포함되어 제공되었습니다. 이 프로그램은 텍스트를 읽어 대화 단서를 파악하고, 패널 레이아웃과 캐릭터 제스처를 선택했습니다. 이 저장소에는 원본 소스 스냅샷과 최신 Visual Studio, 최신 IRC 서버 및 고해상도 Windows 디스플레이를 위한 현대화 실험이 포함되어 있습니다. 인터페이스 팀이 정말 기발한 시도를 했던 시대의 소스 코드를 좋아한다면 이 저장소를 열어보세요. 그리고 crates.io를 사용하면 Cargo가 실제로 다운로드할 코드를 확인할 수 있습니다. 일반적으로 크레이트 페이지에는 특정 릴리스 에 게시된 모든 파일을 탐색할 수 있는 할당량이 있습니다 .
