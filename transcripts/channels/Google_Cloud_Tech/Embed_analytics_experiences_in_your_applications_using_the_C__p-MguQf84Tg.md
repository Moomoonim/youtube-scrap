## 스크립트

데이터에 질문하고 바로 정확한 답변을 얻을 수 있다면 얼마나 좋을까요 ? SQL 쿼리도, 대시보드 클릭도 필요 없습니다. 바로 그것이 대화 형 분석 API가 만들어진 목적입니다. 이는 제미니 스택의 일부이며, 사용자가 보유한 데이터를 기반으로 대화형 인텔리전스를 애플리케이션에 바로 내장할 수 있도록 해줍니다 . 그렇다면 대화형 분석 API란 무엇일까요? API는 Looker 내부의 대화형 분석을 구동하는 엔진과 동일한 엔진에 대한 개발자 인터페이스입니다. 하지만 웹 페이지에서 사용하는 대신, 어디에서든 API를 호출할 수 있습니다. 여러분은 스키마, 비즈니스 로직 및 데이터 연결을 이해하는 AI 에이전트인 데이터 에이전트를 생성합니다. 그런 다음 API를 통해 자연어 쿼리를 설정하면 에이전트가 쿼리를 SQL 또는 Look으로 변환하여 구조화된 결과를 반환합니다 . 하지만 이는 제어할 수 없는 정적인 모델일 뿐만은 아닙니다. API는 시스템 명령과 작성자 컨텍스트를 지원하므로 모델의 기반을 유지하기 위해 자체 명령과 예제를 정의할 수 있습니다 . 예를 들어, 상담원에게 특정 필드를 기준으로 항상 필터링하도록 지시하거나 , 샘플 자연어 질문과 그에 상응하는 쿼리를 제공하거나, 주요 용어집을 정의하거나, 스키마 관계를 사용하여 테이블을 결합하는 방법을 설명하도록 할 수 있습니다 . 또한 이 API는 상태 유지 세션과 상태 비유지 채팅을 통한 다양한 대화 관리 옵션을 지원합니다. 이러한 옵션을 통해 기존 에이전트 또는 대화 객체의 상태 관리를 사용할지, 아니면 동적으로 생성되는 인라인 컨텍스트를 사용하는 완전히 상태 비저장 애플리케이션을 구축할지 결정할 수 있습니다. API에는 데이터 에이전트를 통해 음악을 생성, 공유 및 채팅하고 상태 비저장 채팅을 사용할 수 있는 권한을 부여하는 사전 정의된 규칙이 포함된 AM 액세스 제어 기능이 내장되어 있습니다. 또한 API이기 때문에 Mini Live API 또는 다른 LLM 도구와 결합하여 다중 턴 다중 소스 추론을 수행할 수 있습니다. 예를 들어, Looker MCP 서버 또는 ADK(에이전트 개발 키트)를 사용하여 다른 에이전트에 연결할 수 있습니다. 사실, ADK의 ask data insights 도구를 사용해 보셨다면 이미 대화형 분석 API가 어떻게 작동하는지 보셨을 겁니다. 이 API는 정적인 대시보드를 넘어 더 많은 기능을 활용하고자 할 때 사용합니다 . 어떤 필터를 클릭해야 할지 추측하는 대신, 상담원이 쿼리 구조를 추론하도록 하여 동적으로 질문할 수 있습니다. 이 기능은 마치 대화처럼 느껴지는 분석 기능을 제공 하지만, 안전하게 보호된 데이터를 기반으로 작동합니다. 이제 실제로 어떻게 작동하는지 살펴보겠습니다 . quickserts 저장소를 클론하면 파이썬으로 작성된 바로 실행 가능한 예제를 찾을 수 있습니다 . 다음은 채팅 메시지를 보내고 응답을 처리하는 간단한 파이썬 코드입니다. 에이전트는 질문을 해석하고 , 적절한 BigQuery 쿼리를 실행하여 자연어와 구조화된 결과를 모두 포함하는 응답을 제공하므로 앱에서 원하는 방식으로 응답을 처리할 수 있습니다 . 그렇다면 어떻게 시작해야 할까요? 아래 링크를 확인 하고 빠른 시작 앱을 사용해 보세요. 데모 및 도구 저장소를 탐색하여 코드 예제를 살펴보세요 . 그런 다음 원하는 언어로 SDK를 사용하여 데이터 에이전트 구축을 시작할 수 있습니다 . 대화형 분석 API는 데이터를 단순한 숫자 이상의 의미 있는 정보로 변환합니다. 그것은 그것을 대화로 바꿔줍니다. 시청해 주셔서 감사합니다. 즐거운 건축 시간 되세요!
