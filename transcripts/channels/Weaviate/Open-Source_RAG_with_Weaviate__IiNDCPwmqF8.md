## 스크립트

안녕하세요 여러분, 저는 we8의 에드워드입니다. we8과 함께하는 흥미로운 시리즈에 오신 것을 환영합니다. 오늘은 오픈 소스 도구인 Verba, Golden Rec Rever의 최신 업데이트를 살펴보겠습니다. 모든 새로운 기능을 살펴보고, 80페이지 분량의 특별 논문을 업로드하고 채팅하는 방법을 알아보고, 여러분의 기기에 Verba를 설치하는 방법도 알아보겠습니다. 흥미로우시다면, 시작해 볼까요? RAG는 검색, 증강, 생성의 약자로, 우리가 가진 데이터와 상호 작용할 수 있도록 해줍니다. 예를 들어 " wv8이란 무엇인가?"와 같은 쿼리를 입력하면, 문서 블록이나 전사본으로 구성된 지식 기반에 접근합니다. 그런 다음 벡터 검색을 통해 관련 정보를 검색하고, 이렇게 검색된 문서는 대규모 언어 모델의 컨텍스트로 사용되어 응답을 생성합니다. 이러한 고급 모델을 사용하면 데이터를 자유자재로 다룰 수 있을 뿐만 아니라 개발자에게는 직관적으로 간단합니다. 개발자에게 있어 효율적이고 정확하게 특정 정보를 검색하는 것은 항상 어려운 과제였습니다. 우리는 모두 Stack Overflow와 같은 플랫폼에서 해결책을 찾거나 Google에서 div를 가운데 정렬하는 방법을 10번째로 검색해 본 경험이 있을 것입니다. 하지만 고유한 문제에 직면하거나 방대한 문서를 탐색해야 할 때는 이러한 방법만으로는 해결책을 찾기 어려울 수 있습니다. 우리 각자의 문제점을 해결하는 데 Verba가 중요한 역할을 합니다. Verba는 오픈 소스 랙 툴로, 데이터와의 상호 작용 방식을 혁신적으로 변화시킵니다. 프런트엔드를 통해 Spacey, Hugging Face, Unstructured Cohere, Open AI 등 인기 라이브러리를 사용하여 데이터를 수집할 수 있습니다. Verba의 가장 큰 장점은 pip install 명령 하나로 간편하게 설치하고 실행할 수 있다는 점입니다. 대화형 채팅 인터페이스를 통해 데이터와 소통할 수 있을 뿐만 아니라, 제공되는 정보의 출처까지 검증할 수 있습니다. 이를 입증하기 위해 WEA 문서, 블로그 게시물, 비디오 스크립트로 구성된 라이브 데모를 구축했습니다. 이 데모는 데이터 관련 모든 질문에 대한 최고의 자료입니다. 하이브리드 검색 작동 방식이 궁금하거나 Python 에서 근접 텍스트 기능을 구현하는 방법에 대한 지침이 필요하든, Verba는 더 나은 개발자가 될 수 있도록 도와줍니다. Verba는 혁신과 협업 의 중심지인 오픈 소스 생태계에 완벽하게 통합됩니다. Sentence Transformers와 같은 Hugging Face 모델과 Meta의 Lava 2 모델을 포함한 획기적인 오픈 소스 LLM을 활용할 수 있도록 완벽하게 설계되었습니다. 하지만 Verba 의 새롭게 리팩토링된 코드는 이 외에도 훨씬 더 많은 가능성을 열어줍니다. Verba는 사용자와 오픈 소스 파트너 모두가 맞춤형 구성 요소를 Verba Rec 파이프라인에 손쉽게 통합할 수 있도록 지원하는 무궁무진한 가능성을 제공합니다. Verba의 핵심 기능에 대해 더 자세히 살펴보겠습니다. Verba는 다양한 형식의 데이터(텍스트, 마크다운, JSON, PDF 파일 등)를 지원하는 다목적 도구입니다. Spacy 기반의 청킹 프로세스는 문서를 효율적으로 분할하는 두 가지 방법을 제공합니다. Spacey는 자연어 처리를 위한 가볍지만 강력한 도구입니다. Verba는 Sentence Transformers, OpenAI Ada 모델, Coher 모델을 지원하여 Vi8에 데이터를 임베딩할 때 특히 뛰어납니다. Rat의 하이브리드 검색 및 AutoCard 기능을 사용하여 관련 청크를 효율적이고 정확하게 검색할 수 있습니다. 하이브리드 검색은 기존 키워드 검색과 벡터 검색을 결합하여 두 가지 장점을 모두 활용하고 결과를 크게 향상시킵니다. 이 모든 기능을 통해 사용자는 최신 OpenAI Turbo 모델인 Lama 2 또는 C 등 다양한 LLM 중에서 선택하여 응답을 생성할 수 있습니다. Verba는 좋은 사용자 경험을 보장하기 위해 속도와 성능을 최우선으로 생각합니다. 이를 위해 토큰 스트리밍을 구현하여 응답에 더 빠르게 접근할 수 있도록 했습니다. Verba와의 상호 작용은 더욱 자연스러워졌습니다. Verba는 대화 맥락을 도입하여 직관적인 사용성을 제공하고 효율성을 더욱 높이기 위해 대화 기록까지 포함하는 시맨틱 캐시를 강화했습니다. 즉, Verba는 더 빠르게 응답할 뿐만 아니라 대화 흐름을 더 잘 이해하고 맥락에 맞춰 응답합니다. 이제 Verba를 테스트해 보겠습니다. 제 친한 친구가 최근에 제출한 80페이지 분량의 B 논문을 입력으로 사용하겠습니다. 이 논문은 독일 에너지망의 자산 탐지를 위한 CNN 모델 학습에 초점을 맞추고 있으며, 흥미로운 통찰력으로 가득 차 있습니다. 이 논문은 어떤 데이터든 활용하여 상호 작용할 수 있는 좋은 예시이며, Verba가 정보를 탐색하고 검색하기 위해 제공된 맥락에 전적으로 의존해야 하는 시나리오를 잘 보여줍니다. 따라서 LLMS의 학습 데이터는 사용할 수 없습니다. Verba에서 "문서 추가"를 클릭합니다. 여기에서 사용할 리더 유형을 구성할 수 있습니다. 이 사용 사례에서는 비정형 PDF 리더를 사용하여 논문을 읽겠습니다. B 논문 파일을 업로드하도록 선택합니다. 다른 청킹 기법 이나 임베딩을 선택할 수도 있지만, 현재 설정을 유지하겠습니다. 기본 설정으로 두고 가져오기를 누르면 621개의 청크가 wv8에 입력됩니다. 문서 페이지에서 다시 확인해 보면 입력된 모든 문서를 보고 검색할 수 있으며, 학사 논문도 모든 설정과 함께 포함되어 있는 것을 확인할 수 있습니다. 이제 질문을 시작할 수 있습니다. 먼저 이 논문의 목표가 무엇인지 물어보겠습니다. 답변은 스마트 메타데이터를 사용하여 기존 가구에 특정 자산(예: 태양광 발전 시스템, 배터리 저장 장치, 펌프)이 있는지 예측하는 것이라는 것입니다. 오른쪽에는 정보를 생성하는 데 사용된 개별 청크가 있습니다. 좀 더 자세히 알아보고 CNN 학습에 사용된 데이터가 무엇인지 물어보겠습니다. 답변은 CNN이 시간별 에너지 소비량 측정값을 포함하는 독일 스마트 미터 데이터로 학습되었다는 것입니다. 흥미롭네요. CNN의 F-스코어에 대해 물어보겠습니다. Verba는 자동으로 쿼리를 저장하여 향후 자동 완성 기능을 제공한다는 점에 유의하세요. 네 가지 예측(벽면 태양광 발전 시스템, 배터리 저장 장치, 펌프 예측)에 대한 네 가지 F-스코어가 있는 것 같습니다. 정말 심도 있는 논문이네요. 마지막으로 질문을 마무리하겠습니다. 보시다시피, Verba는 쿼리에 필요한 컨텍스트가 없으면 그 사실을 알리고, 잘못된 정보를 제공하는 대신 가지고 있는 컨텍스트를 활용하여 답변을 시도합니다. 이렇게 단 분 만에 Verba는 이 방대한 문서에 대한 자세한 분석 결과를 제공합니다. 따라서 BOR 논문, 기술 매뉴얼, 기타 데이터 세트 등 어떤 자료든 Verba를 사용하여 정보 접근 및 상호 작용 방식을 개선할 수 있습니다. Verba를 직접 사용해보고 싶으신가요? 걱정 마세요. 설치는 매우 간단하며, 제가 방법을 알려드리겠습니다. 먼저 시스템에 Python( 가급적 버전 3.9 이상)이 설치되어 있어야 합니다. ` python D-version` 명령어를 사용하여 Python 버전을 확인해 보겠습니다. Verba를 설치하기 전에 가상 환경을 설정해야 합니다. 어떤 방법을 사용하든 상관없지만, 이 예시에서는 가상 환경을 사용하겠습니다. 환경을 활성화하는 것도 잊지 마세요. 이제 환경이 활성화되었으니 다음 단계인 Verba 설치를 진행할 준비가 되었습니다. ` pip install golden verba` 명령어를 사용하여 Verba의 기본 설치를 완료합니다. 이 설치에는 Cohere 와 OpenAI가 기본적으로 지원되며, 특히 얼굴 인식 모델에 관심 있는 분들에게 유용합니다. `pip install golden verba` 명령어를 사용하면 Transformers Torch, Hugging Face Hub와 같은 추가 종속성이 원활하게 통합됩니다. 이제 `pip install golden [Music] verba`를 입력해 보겠습니다. 모든 것이 설치되면 API 키를 저장할 .dot 환경 파일을 생성합니다. 이 예제에서는 Coher II key 변수를 설정하여 Coher IPI 키를 추가합니다. 이제 ` verba start` 명령어를 사용하여 Verba를 실행할 준비가 되었습니다. 이 명령어는 로컬 호스트 8000에서 Verba 프런트엔드를 실행합니다. Verba의 상태 페이지로 이동하여 사용 가능한 라이브러리와 키에 대한 정보를 확인하고 Coher [Music] 키가 표시되는지 확인해 보겠습니다. 좋습니다. 이제 테스트해 보겠습니다. 블록을 사용하는 인기 샌드박스 게임인 Minecraft의 위키피디아 페이지를 불러오겠습니다. Verba에게 Minecraft가 무엇인지 물어보면 "목표가 없고 자유도가 높은 샌드박스 게임"이라고 답합니다. 제가 아는 Minecraft와 비슷하네요. 이렇게 몇 분 만에 Verba를 설정하고 첫 번째 구성 요소를 불러왔습니다. 다양한 제공업체로부터 API 키를 가져오는 방법에 대한 자세한 지침은 GitHub 페이지를 참조하세요. 모든 설치 옵션과 WEA 배포 방법을 다루는 종합 가이드를 찾을 수 있습니다. Verba는 오픈 소스 커뮤니티 및 파트너와의 협력을 통해 개발되었습니다. 새로운 모듈식 아키텍처를 통해 사용자는 새로운 기능을 쉽게 추가하여 Verba를 특정 요구 사항에 맞게 맞춤 설정할 수 있습니다. Verba의 새 버전은 커뮤니티 여러분과 다양한 사용자의 훌륭한 기여 없이는 불가능했을 것입니다. 여러분의 지원에 진심으로 감사드리며 앞으로도 오픈 소스를 계속 지원해 주시기를 바랍니다. 이 멋진 여정을 여러분과 함께 나눌 수 있어 기쁘며, Verba에 새로운 기능을 추가하는 작업을 계속하고 있습니다. 이 영상에서는 새로운 Verba 업데이트, 데이터와 상호 작용하는 방법, 그리고 기기에 설치하는 방법을 자세히 살펴보았습니다. 이 영상을 즐겁게 시청하셨기를 바라며, 다음 영상에서 뵙겠습니다. 안녕히 계세요.
