WE8은 키워드 검색과 벡터 검색을 결합한 하이브리드 검색도 제공하여 두 기술의 장점을 모두 활용할 수 있도록 합니다. RAG 시스템에서는 생성형 대규모 언어 모델(GLA)을 사용하여 벡터 데이터베이스와 사용자의 질문에서 제공하는 문맥을 기반으로 자연어 응답을 생성할 수 있습니다. 즉, 미리 정의된 옵션이나 사용자 워크플로에 의존할 필요 없이 더욱 효율적 이고 효과적인 상호 작용을 제공할 수 있습니다. WE8에서는 오픈 소스 RAG 애플리케이션인 Verba를 개발했으며, 이 데모에서는 Airbnb의 고객 문서를 사용하여 Airbnb 챗봇으로 맞춤 설정했습니다. 사용자는 예약 관련 질문을 하고 관련 문서를 받고 액세스할 수 있습니다. 원본 소스를 활용하여 더욱 자연스럽고 상호작용적인 대화형 환경을 구현합니다. 먼저 사용자의 질문을 벡터화하여 벡터 데이터베이스에서 하이브리드 검색을 통해 가장 유사한 컨텍스트를 찾습니다. 그런 다음 해당 컨텍스트와 원래 질문을 결합하여 생성형 대규모 언어 모델(LL)의 프롬프트를 생성합니다. LL 모델은 이러한 모든 정보를 사용하여 대화형 응답을 생성합니다. RX(Return to Action) 방식도 문제를 잘 해결하지만, AI 에이전트를 활용하여 파이프라인의 다양한 측면을 개선할 수 있습니다. AI 에이전트는 사용자 질문 분석 및 처리, 의사 결정, 애플리케이션 기능 향상을 위한 작업 실행 등의 작업을 수행할 수 있는 자율 시스템입니다. 에이전트는 종종 이전 대화를 기반으로 사용자 질문을 재작성하고 미리 정의된 작업을 결정하는 데 사용됩니다. 생성된 피드백 루프를 수행하는 에이전트를 추가하면 파이프라인 의 속도를 높이고 비용을 절감할 수 있음을 보여드리겠습니다. 생성형 피드백 루프는 LL 모델에서 생성된 결과를 데이터베이스에 저장하는 단계를 추가합니다. 이 기술을 통해 챗봇의 지식 기반을 시간이 지남에 따라 자동으로 확장하고 다양한 질문을 처리하는 능력을 향상시킬 수 있습니다. 생성된 답변을 저장함으로써 시스템은 유사한 질문에 대해 캐시된 결과를 제공하여 비용을 절감합니다. 예를 들어 시간과 비용을 절약하고 싶다고 가정해 보겠습니다. GPT 4나 Gemini 같은 고급 생성형 모델은 Llama 7B 같은 소형 모델보다 성능이 더 좋은 경우가 많지만, 비용도 훨씬 많이 듭니다. 여기서 생성 피드백 루프라는 멋진 기법을 활용할 수 있습니다. 사용자가 질문을 하면 과거에 제기된 모든 질문과 답변 쌍을 검색하여 유사한 질문이 있는지 확인합니다. 유사한 질문이 없으면 고가의 모델을 사용하여 Vector 데이터베이스의 컨텍스트를 활용해 답변을 생성합니다. 유사한 질문이 이미 있는 경우에는 저렴하고 작은 모델을 사용하여 새 사용자의 질문에 맞게 답변을 약간 조정합니다. 이 워크플로는 생성 피드백 루프 기반의 고급 캐싱이라고 생각할 수 있습니다. 지금까지 사용 사례에 대해 많이 이야기했지만, WE8과 같은 Vector 데이터베이스 에서 이를 구현하는 것이 얼마나 실현 가능할까요? WE8은 Rag와 생성 피드백 루프를 모두 쉽게 구현할 수 있도록 다양한 기능을 제공합니다. 이미 관련 블로그, 비디오, 데모 프로젝트 및 노트북이 많이 있지만, WE8이 제공하는 주요 기능 몇 가지를 살펴보겠습니다. 벡터라이저, 생성형 대규모 언어 모델, 심지어 REMER까지 모든 유형의 모델과 통합할 수 있는 다양한 옵션이 있습니다. OpenAI GPT, Atom 모델, Google Palm, Gemini, Coher Mistol을 비롯하여 Olama 기반의 수많은 오픈 소스 모델까지 폭넓은 목록을 제공합니다. 이러한 모듈은 상호 교환이 매우 용이하도록 설계되어 모델 간 전환이 간편합니다. 통합 외에도 검색 쿼리 유형을 다양하게 선택할 수 있습니다. 순수 키워드 검색, 순수 벡터 검색, 또는 두 가지 검색 유형의 장점을 결합한 하이브리드 검색 중에서 선택할 수 있습니다. 하지만 RAG 및 생성형 피드백 루프의 경우 검색 생성에 두 번째 단계를 추가해야 합니다. 다행히도 검색 쿼리 위에 완전히 새로운 논리 시스템을 작성하는 대신 생성 모듈을 사용하여 검색 쿼리와 생성 쿼리를 하나로 결합할 수 있습니다. 생성 모듈에는 단일 프롬프트 검색과 그룹화된 작업 검색의 두 가지 옵션이 있습니다. 단일 프롬프트 검색에서는 시스템이 쿼리 결과의 각기 다른 객체에 대한 생성 응답을 반환합니다. 프롬프트 이름을 사용하여 검색 컨텍스트에 포함할 객체 속성을 정의할 수 있습니다. 예를 들어, 받은 모든 연락처를 스페인어로 번역하고 싶다고 가정해 보겠습니다. 이를 위해서는 벡터 데이터베이스 그룹 작업 검색에서
