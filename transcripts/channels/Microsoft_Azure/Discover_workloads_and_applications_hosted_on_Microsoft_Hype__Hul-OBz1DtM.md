## 스크립트

[음악] 이 비디오에서는 Azure Migrate 어플라이언스를 사용하여 HyperVA 상태를 검색하는 방법을 배우게 됩니다 . 시작하기 전에 링크된 비디오를 시청하고 Azure Migrate 프로젝트가 이미 설정되어 있는지 확인하세요. 어플라이언스를 배포하기 전에 몇 가지 사전 준비 사항을 충족해야 합니다. 먼저, 해당 장비가 네트워킹 요구 사항을 충족하고 필요한 모든 엔드포인트에 연결할 수 있는지 확인하십시오. 다음으로, 설명서에 제공된 스크립트를 사용하여 HyperV 호스트를 검색 가능하도록 준비합니다 . 설치된 소프트웨어, 서버 종속성, SQL Server, PostgreSQL, MySQL 데이터베이스 및 웹 애플리케이션 검색을 포함하는 게스트 및 워크로드 검색을 활성화하려면 Windows 관리자 자격 증명과 Linux 루트 자격 증명이 필요합니다. 관리자 또는 루트 자격 증명 대신 자격 증명 보안 모범 사례 가이드를 따라 Windows, Linux 및 SQL에 대해 최소 권한 사용자 지정 계정을 만들 수도 있습니다. Azure Migrate 프로젝트 개요 페이지에서 어플라이언스를 사용하여 검색을 클릭하고 가상화 환경을 HyperV로 선택합니다. 기기 이름을 지정 하고 프로젝트 키를 생성하세요. VHD 템플릿 내에서 새 어플라이언스 VM을 설정하거나 zip 파일을 사용하여 기존 서버를 어플라이언스 VM으로 변환할 수 있습니다. 이번 데모에서는 zip 파일을 다운로드하겠습니다 . 압축 파일(Azure Migrate 설치 프로그램 파일)을 관리자 권한으로 실행하고 어플라이언스 유형을 HyperV로 선택하십시오. 클라우드 유형과 어플라이언스를 공용 엔드포인트 또는 사설 엔드포인트 연결로 설정할지 여부를 선택하십시오. 압축 파일 실행이 완료되면 어플라이언스 구성 관리자 웹 앱이 자동으로 실행됩니다. 첫 번째 확인 사항은 필요한 Azure 엔드포인트에 연결할 수 있는지 확인하는 것입니다. 서버가 프록시 서버 뒤에서 실행 중인 경우 프록시 서버 정보를 추가하십시오. 인증형 및 비인증형 프록시 서버가 모두 지원됩니다. 시간 동기화 검사는 어플라이언스의 시간이 Azure와 동기화되어 검색이 원활하게 이루어지도록 보장합니다. 다음 단계는 이 어플라이언스를 Azure 마이그레이션 프로젝트에 등록하는 것입니다. 여기에 Azure 포털에서 생성한 프로젝트 키를 붙여넣어야 합니다 . 이 단계에서는 업그레이드 및 등록 작업이 동시에 실행됩니다. 기본적으로 자동 업그레이드가 활성화되어 있으므로 어플라이언스 관리에 대해 걱정할 필요가 없습니다. 다음 단계는 Azure에 로그인하는 것입니다. 여기에 사용할 사용자 계정은 해당 기기를 프로젝트에 등록할 수 있는 충분한 권한을 가지고 있어야 합니다 . 즉. 필수 조건 검사가 완료되면 HyperV 호스트의 자격 증명을 추가합니다. 사용자 이름과 비밀번호를 입력한 후, 알아보기 쉬운 이름을 자격 증명에 지정할 수 있습니다 . 어플라이언스는 포트 5986 의 HTTPS 프로토콜을 사용하여 HyperV 호스트와 통신합니다. 대상 서버에서 필수 조건이 충족되지 않으면 HTTP 및 포트 5985로 통신이 전환됩니다. 포트 5986을 통한 HTTPS 통신을 강제하려면 해당 확인란을 선택하고 대상 서버 에서 인증서 필수 조건이 충족되었는지 확인하십시오 . 이제 HyperV 호스트 정보를 제공해야 합니다. HyperV 호스트 정보를 여러 개 추가하거나 CSV 템플릿을 사용하여 서버 정보를 여러 개 가져올 수 있습니다. 이 데모에서는 단일 호스트의 FQDN을 해당 호스트의 사용자 친화적인 자격 증명 이름과 매핑합니다. 여기서 중요한 점은 자격 증명이 항상 기기 내부에 저장된다는 것입니다 . 자격 증명은 데이터 보호 API(DPA API)를 사용하여 암호화됩니다 . 이는 소프트웨어 인벤토리를 더욱 심층적으로 탐색하기 위한 안전한 256비트 암호화입니다 . SQL 및 네트워크 부하에 대한 에이전트리스 방식의 종속성 분석 및 발견. 서버 자격 증명을 제공해야 합니다. 여기에 다양한 유형의 자격 증명을 추가할 수 있습니다 . 서버 집합에 대한 도메인 자격 증명을 추가하거나, 이러한 자격 증명 풀을 제공하여 Windows, Linux 및 SQL 자격 증명과 같은 비도메인 자격 증명을 추가할 수 있습니다 . 어플라이언스는 이러한 자격 증명을 지능적으로 매핑하고 심층적인 검색을 수행합니다. 장비 관련 문제가 발생할 경우, 지원 요청을 접수할 필요 없이 진단 실행을 통해 자체적으로 문제를 진단할 수 있습니다 . 모든 자격 증명을 추가한 후 '검색 시작'을 클릭하여 검색 프로세스를 시작하세요. 데이터가 Azure 포털에 반영되는 데 약 10~15분이 소요됩니다. HyperV 서버 마이그레이션을 준비하려면 HyperV 복제 공급자를 다운로드하십시오 . 다음 영상에서 액션 센터에서 발견된 재고 문제 해결 방법(음악 포함)을 살펴보고 사업 계획을 수립하는 방법을 알아보세요 . [음악]
