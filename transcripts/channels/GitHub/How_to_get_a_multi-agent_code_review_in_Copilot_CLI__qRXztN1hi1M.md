## 스크립트

안녕하세요, 저는 Copilot CLI 팀의 에반 보일입니다. 이번 영상에서는 Copilot CLI 고급 사용 팁과 요령을 알려드리겠습니다. 코드 리뷰를 위해 업로드하기 전에, 저는 `{/} review` 명령어를 실행하는 것을 좋아합니다. 이 기능은 버그, 잠재적인 보안 문제, 성능 문제를 찾아내고 코드 검토 단계에 들어가기 전에 이러한 문제를 제기하는 데 도움이 되는 프롬프트를 사용합니다. 이것의 가장 멋진 점은 검토를 실행하고 프롬프트에서 여러 모델을 사용하도록 요청할 수 있다는 것입니다. 저는 신호 강도를 높이기 위해 제미니, 코덱스, 오푸스를 자주 사용하여 여러 에이전트의 코드 검토를 받습니다 . 종종 이러한 여러 모델들이 서로 일치하지 않고, 서로 다른 버그를 제기하며, 서로 다른 버그를 발견하는 경우가 있습니다.
