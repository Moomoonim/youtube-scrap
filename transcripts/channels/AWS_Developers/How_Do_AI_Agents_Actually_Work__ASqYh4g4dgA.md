And you need to be very descriptive in the description, in plain English, because the LLM will read through the description to try to understand what each of those functions is actually doing. For example, if you ask a question about the architecture of your company, and you have this first function called answer_query that is connected to a RAG, so retrieval-augmented generation, to get information from your company, then you can ask the question and the LLM will think to itself, "If I need to answer a question about my company, I need to use this first tool." So it will go through a Lambda handler. And the Lambda handler will trigger the answer_query function, get the information from your RAG, and then send the answer to your user.
