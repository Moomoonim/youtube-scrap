## 스크립트

오늘은 Azure Storage Mover의 클라우드 간 마이그레이션 기능을 사용하여 AWS S3에서 Azure Blob Storage로 데이터를 안전하게 전송하는 방법을 살펴보겠습니다 . 시작하기 전에 몇 가지 사항이 제대로 준비되었는지 확인해야 합니다. 먼저, 스토리지 무버 및 Azure Arc 리소스를 배포할 수 있는 권한이 있는 활성 Azure 구독이 있어야 합니다. 또한, 마이그레이션할 Amazon S3 버킷에 접근 권한이 있는 AWS 계정이 필요합니다 . 다음으로, 대상으로 사용할 Azure 스토리지 계정이 필요합니다. 먼저 Azure 포털에서 스토리지 이동 리소스로 이동합니다. 새로운 스토리지 이동 서비스를 만들려면 '생성'을 선택하세요 . 구독 및 리소스 그룹을 지정하고 인스턴스 이름 및 지역에 대한 세부 정보를 제공하십시오 . 모니터링 탭에서 로그를 활성화하려면 다음을 선택하세요. 다음을 선택하고 원하는 태그를 추가하세요. 세부 정보를 확인하려면 다음을 선택하고 검토 후 생성을 클릭하세요. 개요 창에서 멀티클라우드 마이그레이션 탭을 선택합니다. 그런 다음 멀티클라우드 커넥터 생성을 선택하고 AWS 커넥터 추가 페이지를 엽니다. 드롭다운 목록에서 커넥터 리소스를 생성할 프로젝트 세부 정보, 구독 및 리소스 그룹을 지정합니다 . 커넥터 세부 정보 섹션에 커넥터 이름과 Azure 지역을 추가하세요 . 마지막으로 AWS 계정 유형을 선택하고 커넥터가 데이터를 이동할 소스의 AWS 계정 ID를 입력합니다 . 모든 값을 확인하고 다음을 클릭하십시오. 이렇게 하면 해결 방법 탭으로 이동합니다. 여기서는 AWS 리소스를 검색 및 관리하고 스토리지 무버에 대한 전송 작업을 활성화할 수 있는 인벤토리 및 스토리지 데이터 관리 솔루션을 커넥터에 추가합니다. 인벤토리를 추가할 때 주기적인 동기화를 활성화하는 데 필요한 권한과 스캔할 AWS 리전을 지정하라는 메시지가 표시됩니다 . 매개변수를 저장합니다. 스토리지 데이터 관리 솔루션을 추가하려면 ' 추가'를 클릭하여 토글하세요. 입력한 값이 올바른지 확인하고 다음을 선택하십시오. 인증 템플릿 탭에서는 AWS 포털을 사용하여 AWS 클라우드 포메이션 스택을 생성하는 방법에 대한 화면 지침을 제공합니다 . ' 다음'을 선택하여 태그 탭으로 이동하세요. 이곳에서 조직과 관련된 매개변수를 기반으로 리소스를 식별하는 데 도움이 되는 태그를 지정할 수 있습니다 . '다음'을 선택하고 ' 검토 및 생성' 탭에서 입력한 모든 설정이 올바른지 확인하십시오. 확인이 완료되면 '생성'을 선택하여 멀티클라우드 커넥터를 배포하세요. 완료되면 새로 생성된 커넥터의 개요 페이지가 표시됩니다. 커넥터 구성이 완료되었으므로 이제 마이그레이션 프로젝트와 작업 정의를 생성해야 합니다. 스토리지 이동 인스턴스에서 프로젝트 생성을 선택합니다. 프로젝트 이름과 설명을 입력하고 ' 생성'을 선택하세요. 프로젝트가 탐색기 창에 나타나면 해당 프로젝트를 선택한 다음 작업 정의 만들기를 선택합니다 . 기본 탭에서 이름을 입력하고 마이그레이션 유형으로 클라우드 간 마이그레이션을 선택합니다 . '다음'을 눌러 소스 탭으로 이동하세요. 엔드포인트 필드에서 기존 엔드포인트를 선택하세요 . 기존 엔드포인트를 소스로 선택하고 열리는 창에서 AWS S3 버킷을 선택합니다 . 다음을 선택하세요. 대상 탭에서 엔드포인트 필드에 기존 엔드포인트 참조를 선택하고 대상 Azure Blob Storage 엔드포인트를 선택합니다. 다음을 선택하세요. 설정 탭에서 복사 모드로 ' 콘텐츠를 대상으로 병합' 또는 ' 원본을 대상으로 미러링' 중 하나를 선택 하고 '다음'을 클릭합니다. 검토 탭에서 매개변수가 올바른지 확인하고 만들기를 선택하여 작업을 배포하세요. 그러면 연결된 프로젝트에서 해당 작업이 표시되는 탐색기 창으로 이동합니다. 이제 마지막 단계는 마이그레이션 작업을 실행하는 것입니다. 마이그레이션 작업 탭으로 이동합니다. 새로 생성한 작업을 선택하고 ' 작업 시작'을 클릭하세요. 해당 서비스는 스토리지 및 블롭 계정에 역할을 할당합니다. 완료되면 '시작'을 선택하여 작업을 시작하십시오. 마이그레이션 개요 탭에서 진행 상황을 모니터링할 수 있으며, 데이터가 성공적으로 복사되었는지 확인할 수 있습니다. 완료되면 로그를 검토하고 마이그레이션을 검증할 수 있습니다.
