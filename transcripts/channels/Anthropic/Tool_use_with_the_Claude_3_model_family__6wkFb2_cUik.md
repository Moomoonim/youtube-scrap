## 스크립트

클라우드 3 모델 제품군의 최신 기능 중 하나는 도구 사용, 즉 함수 호출 기능입니다. 클라우드에서 사용할 수 있는 도구는 JSON 스키마로 표현되며, 이 스키마는 모델에게 도구의 기능과 생성 과정에서 허용하는 인수에 대한 정보를 제공합니다. 모델은 모든 도구를 호출할 수 있으며, 클라이언트는 해당 호출을 처리 하고 결과를 반환할 수 있습니다. 예를 들어, 가장 빠르고 저렴한 모델인 Haiku는 웹페이지 가져오기 도구와 표준 Python 리펠 도구에 접근할 수 있어 인터넷에서 정보를 검색 하고 코드를 실행할 수 있습니다. 이제 Haiku를 사용하여 가장 인기 있는 정렬 알고리즘 중 하나인 퀵 정렬 구현을 검색하고 샘플 입력에서 실행 속도를 확인해 보겠습니다. Haiku는 매우 빠르기 때문에 토큰 생성 과정을 더 잘 볼 수 있도록 데모 속도를 5배로 늦췄습니다. Haiku가 여러 도구를 연결하여 작업을 수행할 수 있음을 확인할 수 있습니다. 모델이 다른 모델을 도구로 호출할 수 있게 되면 더욱 흥미로워집니다. 예를 들어, 온라인에서 가장 빠른 퀵 정렬 구현을 찾고 싶다고 가정해 보겠습니다. 여기서는 가장 고급 모델인 Opus에게 100개의 구현을 찾도록 요청합니다. GitHub에서 라이선스가 허용된 퀵 정렬 구현들을 사용하고, 100개의 Haiku 모델이 각 구현의 속도를 측정하는 테스트를 작성합니다. 그런 다음 실행 중에 가장 빠른 퀵 정렬을 찾아낼 수 있습니다. 내부 작동 방식은 다음과 같습니다. Opus에 서브 에이전트 디스패치 도구를 제공하여 이 작업을 병렬화합니다. 이 도구는 프롬프트 템플릿을 작성하고 인자 목록을 제공할 수 있습니다. Haiku 서브 에이전트는 각각 템플릿에 자신의 인자를 채워 넣습니다. 모든 응답은 Opus로 반환되고, Opus는 가장 빠른 구현을 반환합니다. 여기에서 가장 빠른 결과를 확인할 수 있으며, 다른 구현에는 없는 추가 최적화 기능도 포함되어 있습니다. 서브 에이전트와 함께 도구를 사용하는 것은 Opus의 지능과 Haiku의 속도 및 경제성을 결합하여 대규모 정보를 효율적으로 처리하는 훌륭한 방법입니다. 곧 사용해 보시길 바랍니다.
