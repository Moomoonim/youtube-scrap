Azure 전용 호스트의 비용 밀도 최적화와 관련하여 Boost를 사용하여 VM 밀도를 높이 거나 기존 VM을 확장할 수 있습니다. Azure 지역 또는 가용성 영역에서 제공하는 성능 향상 효과를 고려하여 가능한 경우 워크로드를 더 적은 수의 호스트로 통합하십시오. 부스트 기능이 제공되는 지역에서만 이용 가능합니다 . 호스트 장애 또는 유지 보수 시 복원력을 향상하고 영향 범위를 줄이려면 가용성 영역 사용을 고려하십시오 . 핵심은 이것입니다. Azure는 Azure Boost를 통해 플랫폼별 IAS를 근본적으로 개선하여 최고 수준의 성능, 보안 및 안정성을 제공합니다. 여러분의 애플리케이션이 이러한 잠재력을 발휘할 수 있도록 하는 길은 명확합니다. 기반을 현대화하세요. Azure Boost 하드웨어를 기반으로 구축할 수 있는 최신 VM 시리즈 중에서 선택하세요 . 최신 운영체제를 사용하세요 . 최근에 지원되는 OS 이미지를 선택하십시오. 이는 최고의 성과를 달성하는 데 필수적입니다 .
