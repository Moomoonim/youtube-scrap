## 스크립트

Amazon Q의 흥미로운 소식을 들으셨나요? Visual Studio Code 마켓플레이스에 Amazon Q 전용 확장 프로그램이 출시되었습니다! 새로운 코드베이스를 개발하든, 디버깅을 하든, 아니면 일상적인 작업을 빠르게 처리하든, Amazon Q Developer는 인라인 코드 자동 완성, AI 기반 코드 분석 등 다양한 기능을 통해 생산성을 향상시켜 줍니다. 2024년 4월 30일부터 Amazon Code Whisperer도 Amazon Q Developer에 통합되어 Amazon Q Developer에서 모든 놀라운 기능을 사용할 수 있게 되었습니다. 자, 그럼 시작해 볼까요? 먼저 Amazon Q Developer를 설치해야 합니다. 이미 AWS Toolkit 에서 Amazon Q 또는 Amazon Code Whisperer를 사용하고 있었다면 AWS Toolkit을 업데이트하면 새로운 Amazon Q Developer가 자동으로 설치됩니다. AWS Toolkit이 없어도 Amazon Q Developer를 사용할 수 있습니다. 함께 설정해 ​​보겠습니다. Visual Studio Code를 열고 확장 프로그램으로 이동하여 Amazon Q Developer를 검색하고 설치합니다. 이제 Amazon Q Developer 아이콘이 표시될 것입니다. 로그인 방법은 두 가지가 있습니다. 무료로 사용하려면 'Amazon Q Developer'를 사용하는 방법이 있습니다 . 첫 번째 옵션은 무료 사용이고, 두 번째 옵션은 프로 라이선스를 받는 것입니다. Amazon Q 개발자 프로 라이선스를 구독하면 이 비디오 후반부에서 설명할 고급 기능을 사용할 수 있습니다. ' 무료 사용'을 클릭하고 ' 계속'을 클릭해 보겠습니다. 그러면 빌더 ID로 로그인할 수 있는 브라우저 창이 열립니다. 여기에 표시된 코드가 브라우저에 있는 코드와 일치하는지 확인해야 합니다. 코드가 일치하는 것 같으니 확인하고 ' 계속'을 클릭합니다. 빌더 ID에 로그인한 적이 없거나 빌더 ID 계정을 만든 적이 없다면 여기에서 빌더 ID 계정을 만들 수 있습니다. 저는 이미 빌더 ID가 있으므로 로그인하겠습니다. 이제 ID 확장 프로그램이 빌더 ID 데이터에 액세스하도록 허용할지 확인해야 합니다. 확장하여 어떤 항목에 액세스할지 확인할 수도 있습니다. ' 액세스 허용'을 클릭하면 됩니다. 이제 Visual Studio Code로 돌아갈 수 있습니다. 빌더 ID가 성공적으로 연결되었습니다. Amazon Q에 대한 추가 설정을 할당하거나 더 자세한 정보를 찾으려면 아래 상태 표시줄에서 Amazon Q를 클릭하세요. 또는 지금 로그아웃할 수도 있습니다. 제가 코드를 열어본 app.py 파일은 제가 작성한 간단한 애플리케이션입니다. 이 코드에 대해 좀 더 자세히 알고 싶다면, 이해하고 싶은 코드를 선택하기만 하면 됩니다. 예를 들어, create case 함수를 선택해 보겠습니다. 마우스 오른쪽 버튼을 클릭하고 " Amazon Q로 보내기 및 설명" 옵션을 선택하면 됩니다. 이 코드는 Amazon Q 채팅 창으로 전송되어 해당 코드에 대한 설명을 요청합니다. Amazon Q가 이 함수의 용도를 얼마나 빠르게 파악하고 핵심 정보와 함수에 대한 설명을 제공하는지 확인할 수 있습니다. 이제 Amazon Q와 채팅을 계속하면서 코드에 대해 더 질문할 수 있습니다. 정말 흥미롭지 않나요? 이 외에도 훨씬 더 놀라운 기능들을 사용할 수 있습니다. 예를 들어, create case 함수가 있다고 가정해 보겠습니다. 이 함수를 기반으로 Amazon Q가 해당 함수를 호출할 수 있는 curl 명령어를 제공해 주도록 요청할 수 있습니다. Amazon Q가 제 함수에 대한 추가 정보를 얼마나 빠르게 제공하는지 확인할 수 있습니다. 지금까지 Builder에 대해 이야기했던 내용입니다. 빌더 ID 외에도 앞서 언급했듯이 Amazon Q의 고급 기능을 사용할 수 있는 두 번째 옵션이 있습니다. 이를 위해 빌더 ID에서 로그아웃 하고 프로 라이선스가 있는 Amazon Q를 사용해 보겠습니다. AWS 콘솔에서 Amazon Q에 접속하여 IM Identity Center에 연결되었는지 확인합니다. 조직 인스턴스가 연결되어 있지 않으면 생성해야 합니다. 설정 방법에 대한 단계별 설명은 블로그 링크를 참조하세요. 이제 구독하고 Amazon Q 개발자의 최종 사용자가 될 사용자 및 그룹을 할당할 수 있습니다. 완료되면 다음과 같이 표시됩니다. 여기에서 시작 URL을 복사하여 Visual Studio Code로 돌아가 붙여넣습니다. 올바른 버전인지 확인하고 진행합니다. 이제 AWS Identity Center를 사용하여 인증 절차를 다시 진행합니다. 로그인하면 빌더 ID에서 제공하는 모든 기능 외에도 두 가지 추가 기능을 사용할 수 있습니다. 첫 번째는 '개발자'를 사용하여 Q에 새로운 기능을 구현하도록 요청할 수 있다는 것입니다. 제 예시에서는 사례 생성 및 사례 가져오기 기능만 있습니다. Q 에게 새로운 업데이트 케이스 함수를 정의해 달라고 요청하겠습니다. 프롬프트를 입력하고 Q가 계획을 생성하도록 하겠습니다. [음악] 이제 Amazon QBE가 상세한 계획을 생성한 것을 볼 수 있습니다. app.py 파일을 업데이트해야 하고, 추가 정보를 입력해야 하며, update case라는 함수를 생성하고, 케이스 ID를 사용하여 update case라는 이름의 라우트를 생성해야 한다고 나와 있습니다. 또한 Lambda 핸들러도 업데이트해야 합니다. 좋습니다. SAP를 사용하여 이 애플리케이션을 배포하는 데 사용할 수 있는 템플릿도 업데이트되었습니다. 아주 좋습니다. 이제 코드를 생성해 달라고 요청하겠습니다. 이 작업은 시간이 조금 걸리므 로 커피를 마시고 잠시 후에 화면을 다시 확인해 주세요. 시간을 절약하기 위해 일부 프로세스를 가속화하겠습니다. 보시다시피 update case라는 새로운 함수와 라우트가 제안되었고, Lambda 핸들러에 SF PA가 추가되었으며, 템플릿도 업데이트되었습니다. 이제 변경 사항을 빠르게 확인할 수 있습니다. 마음에 드는 변경 사항이 있으면 간단히 '코드 삽입'을 선택하여 모든 파일에 해당 변경 사항을 적용하거나, 피드백을 제공하여 기대에 부합하는 더욱 정교한 코드를 생성하도록 요청할 수 있습니다. 프로 라이선스에는 ' 변환(Transform)'이라는 또 다른 기능이 포함되어 있는데, 이 기능을 사용하면 Java 8 또는 11 Ming 프로젝트를 Java 70으로 변환하거나 마이그레이션할 수 있습니다. 빠른 시작을 위한 내용은 여기까지입니다. 이 영상이 마음에 드셨다면 좋아요를 누르고 AWS 개발자 채널을 구독해 주세요. Amazon Q 확장 프로그램을 설치하고 앞으로의 개발에 집중해 보세요. 더 자세한 내용이나 소프트웨어 개발 경험을 한 단계 끌어올릴 수 있는 흥미로운 새로운 방법들을 알아보려면 아래 설명란의 링크를 확인하세요. 즐거운 코딩 되시고 다음 영상에서 뵙겠습니다!
