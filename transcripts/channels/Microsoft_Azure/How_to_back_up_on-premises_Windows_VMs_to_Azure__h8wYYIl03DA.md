## 스크립트

이 데모에서는 [음악] Azure를 사용하여 온프레미스 Windows Server 가상 머신을 백업하는 방법을 보여드리겠습니다. 먼저 Microsoft Azure Recovery Services( MARS) 에이전트를 설치하세요. 다운로드한 설치 프로그램을 찾아서 더블 클릭하여 실행하세요. Microsoft Azure Recovery Services [음악] 에이전트 설정 마법사가 열립니다. 설치 폴더를 선택하고 임시 백업 데이터를 저장할 캐시 위치를 지정하십시오 . 시스템이 프록시를 통해 인터넷에 연결하는 경우 , 프록시 주소, 포트 번호 및 필요한 경우 인증 정보를 제공하십시오 . 로그인 후 설치를 진행하세요. 설치 후 [음악]을 클릭하여 등록을 진행하세요. Azure 포털에서 이전에 다운로드한 자격 증명 모음 파일을 찾아 선택합니다 . 이 단계에서는 Azure의 복구 [음악] 서비스 자격 증명 모음에 에이전트를 등록합니다. 저장소에서 안전한 네트워크 음악 전송을 위해 개인 엔드포인트가 활성화되어 있는지 확인하십시오 . 랜섬웨어의 변조를 방지하기 위해 백업 불변성이 활성화되어 있습니다 . 암호화는 Azure Key Vault 에 저장된 암호문을 사용하여 구성되며, 중복 유형은 영역별 복원력 또는 지역 복원력으로 설정됩니다 . 암호화 암호를 생성하라는 메시지가 나타나면 암호를 생성하십시오 . 이 암호는 [음악] Azure로 전송되는 모든 백업을 보호합니다. 분실 시 마이크로소프트에서 복구할 수 없으므로 안전하게 보관하십시오 . 완료되면 '완료'를 선택하여 등록을 완료하세요. 자, 이제 백업 일정을 설정해 보겠습니다. 서버에서 Microsoft Azure 백업 애플리케이션을 엽니다. 작업 창에서 [음악] 백업 예약을 클릭하여 구성 마법사를 실행합니다. '항목 추가'를 선택한 다음 보호할 데이터를 선택하세요. 시스템 상태 또는 특정 [음악] 파일 및 폴더를 백업할 수 있습니다. 선택 후 확인을 클릭하고 다음을 클릭하세요. 백업 실행 시점을 정의하세요. [음악] 매일 또는 매주. 목표 회복 시점에 맞춰 타이밍을 조정하세요 . 예를 들어, 8시간 [음악] RPO는 하루 세 번의 백업으로 달성할 수 있습니다. 다음으로 백업 파일을 보관할 기간을 정하십시오 . 규정 준수 및 저장 요구 사항에 따라 일별, 주별, 월별 사본에 대해 별도의 보존 기간을 설정할 수 있습니다. 첫 번째 백업 시 네트워크를 통해 자동으로 데이터를 Azure에 직접 업로드하도록 선택하세요. 설정 세부 정보를 꼼꼼히 검토하십시오 . 확인이 완료되면 완료를 클릭하세요. 마법사가 음악 백업 일정을 생성하고 구성이 성공적으로 완료되었음을 확인합니다. 설정을 검증하려면 수동 백업을 시작하십시오 . [음악] 작업 창에서 지금 백업을 클릭하세요 . 데이터가 안전하게 Azure로 전송되고 암호로 암호화되는 동안 콘솔에서 진행 상황을 모니터링하세요 . [음악] 백업이 성공적으로 완료되었으며, 이제 데이터는 암호화 및 보존 정책이 적용된 Azure에 안전하게 저장됩니다. 이 데모에서는 [음악] Mars 에이전트를 설치 및 등록하고 , 암호화 및 백업 [음악] 정책을 구성하고, Azure에 안전한 백업을 수행했습니다. 이 설정은 온프레미스 Windows [음악] 서버 워크로드에 대해 안정적이고 규정을 준수하며 복원력이 뛰어난 보호 기능을 보장합니다. 백업 작업이 생성되면 Mars 에이전트 인터페이스 에서 직접 백업을 모니터링하고 관리하거나 Azure 포털을 통해 중앙 집중식으로 [음악] 가시성과 보고 기능을 활용할 수 있습니다.
