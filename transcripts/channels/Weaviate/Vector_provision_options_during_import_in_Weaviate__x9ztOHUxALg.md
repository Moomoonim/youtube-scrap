OpenAI API의 API 키 와 인스턴스 URL을 제공합니다. 여기에는 출력을 표시하는 간단한 헬퍼 함수가 있습니다. 인스턴스에 대한 'Mission' 메트릭을 가져와서 테스트해 보겠습니다. 스키마를 간단히 확인하여 빈 인스턴스임을 보여드리겠습니다. 좋습니다. 이제 데이터를 로드해 보겠습니다. 여기 세부 정보가 중요합니다. 로드하는 데이터는 본문, 제목, 국가 등의 와인 리뷰 데이터 세트입니다. 데이터를 로드하는 헬퍼 함수를 ​​사용했고 이제 객체를 가져올 준비가 되었습니다. 이전에 얻은 벡터를 사용하여 객체를 추가해 보겠습니다. OpenAI 벡터라이저를 설정하여 스키마에 '와인 리뷰'라는 클래스를 다음과 같이 추가합니다. 스키마를 다시 확인하면 리뷰 클래스가 추가된 것을 볼 수 있습니다. 아래쪽에는 벡터라이저가 OpenAI 모듈로 지정되어 있습니다. 이제 객체를 추가할 준비가 되었습니다. 다음으로 배치 프로세스를 설정하고 객체를 하나씩 로드합니다. 배치에 추가하려면 데이터 객체와 클래스 이름만 추가하면 됩니다. 이제 완료되었습니다. 참고로 벡터가 없는 데이터 객체는 다음과 같습니다. 제대로 작동했는지 확인해 보겠습니다. 집계 쿼리를 실행해 보면 데이터베이스에 50개의 객체가 있는 것으로 나타납니다. 꽤 괜찮아 보입니다. 벡터 검색을 시도해 보겠습니다. 제가 좋아하는 과일 향이 나는 프랑스 와인과 관련된 리뷰를 찾기 위해 근접 텍스트 쿼리를 실행해 보겠습니다. 결과는 어땠을까요? 꽤 괜찮아 보입니다. 첫 번째 리뷰는 다음과 같습니다. 두 번째는 과일에 대한 이야기인데, 꽤 흥미롭네요. 전반적으로 좋아 보입니다. 다음 부분으로 넘어가서, 이제 자체 벡터를 사용하여 객체를 가져와 보겠습니다. 동일한 단계를 거치고, 스키마에 객체를 추가합니다. 이 객체를 '다른 와인 리뷰'라고 부르고, 스키마에 새 클래스로 추가합니다. 여기서는 벡터라이저가 지정되지 않았다는 점에 유의하세요. 이제 객체를 추가할 수 있습니다. 시연을 위해 임의의 의미 없는 벡터를 몇 개 남겨두겠습니다. 여기서는 리스트 컴프리헨션을 사용하여 이러한 벡터를 생성하는 것을 볼 수 있습니다. 이 벡터들은 아무 의미가 없지만, 각 객체에 대해 고유한 벡터를 얻게 됩니다. 이제 이 코드를 실행하여 데이터베이스에 데이터를 가져오고 벡터 검색을 다시 시도해 보겠습니다. 벡터라이저가 없으므로 근접 텍스트 검색은 사용할 수 없지만, 근접 벡터 검색을 사용하여 임의의 자체 벡터를 기준으로 검색할 수 있습니다. 검색 결과가 표시되고, 맨 위 결과가 소스 벡터와 매우 가깝다는 것을 알 수 있습니다. 아래로 스크롤하면 검색 결과의 맨 끝, 즉 마지막 벡터가 가장 멀리 떨어져 있는 것을 볼 수 있습니다. 우리가 기대하는 환상적인 결과가 나왔습니다. 입력 벡터를 제공하고 벡터라이저를 사용하는 다른 경우를 살펴보겠습니다. 어떻게 구현하고 왜 그렇게 해야 할까요? 먼저 방법을 살펴보겠습니다. 다른 클래스를 생성하고, 이전과 동일한 과정을 거쳐 추가합니다. 벡터라이저를 다시 추가했고, 객체를 추가합니다. 이 경우 데이터 객체에서 문자열을 생성하고, OpenAI를 사용하여 벡터를 가져온 다음, 해당 벡터를 EV8에 수동으로 전달합니다. 이 설정으로 다른 벡터 검색을 시도해 보겠습니다. for 루프에서 마지막으로 사용한 것과 동일한 데이터 객체와 생성된 벡터를 사용합니다. 검색 결과가 쿼리 객체와 동일하게 나오고 나머지 결과도 상당히 합리적으로 나오는 것을 보니 잘 작동하는 것 같습니다. 하지만 더 중요한 것은 이 설정이 유용한 이유는 자체 벡터를 사용하면서도 근접 텍스트 검색을 계속 사용할 수 있기 때문입니다. 여기에서 바로 확인할 수 있습니다. 동일한 근접 텍스트 검색을 자체 벡터를 사용하여 실행했는데, 벡터 덕분에 이것이 가능합니다. 이 두 모델은 모두 동일한 모델, 즉 오픈 AI에서 가져온 것입니다. 요약하자면, 벡터를 Aviate에 제공하거나 Weeviate에서 벡터화를 처리하도록 할 수 있습니다. 어떤 방식을 사용할지는 원하는 결과에 따라 다릅니다. 객체가 포함된 벡터를 제공하면 Weviate는 해당 벡터를 사용합니다. 벡터화 방식을 지정하지 않으면 텍스트 근처를 사용할 수 없다는 점을 기억하세요. 따라서 경우에 따라 벡터화 도구를 사용하고 직접 벡터를 업로드하는 것이 두 가지 장점을 모두 얻을 수 있는 방법이 될 수 있습니다. 시청해 주셔서 감사합니다. 다음 시간에 뵙겠습니다.
