Nex.js JS 15.5 버전이 이번 주에 출시되었는데, 솔직히 말해서 개발자들이 정말 좋아할 만한 업그레이드가 가득합니다. 기존 Linton 제거, AMP 사용 중단 경고, 그리고 더 빠른 빌드를 위한 Turboack 통합에 대해 이야기하고 있습니다. 하지만 진짜 승자는 바로 여기 있습니다. 이제 타입 라우트는 빌드 시점에 링크 오류를 잡아내어 프로덕션 환경에 배포되지 않도록 합니다. 더 이상 사용자에게 깨진 내비게이션 화면을 보여주지 않습니다. 버전 16이 출시될 예정이지만, 15.5 버전은 현재 운영 중인 앱에 필요한 최적화 기능을 제공합니다 . 개발자 도구 개선에 대해 이야기하자면 , GitHub는 새로운 에이전트 패널을 통해 GitHub Copilot을 github.com에 직접 통합했습니다. 이건 생각보다 훨씬 큰일이에요. 이제 IDE와 브라우저 사이를 오가는 대신 GitHub 인터페이스에서 바로 저장소별 작업을 실행할 수 있습니다 . 브라우저 기반 설정 덕분에 Copilot은 저장소 구조, 문제, 풀 리퀘스트 및 프로젝트 기록에 대한 모든 컨텍스트를 파악할 수 있습니다. 그러니까 단순히 자동 완성 기능만 있는 게 아니라, 프로젝트 생태계 전체를 이해하는 거죠. 새로운 상담원 패널과 GitHub 변경 로그에 대한 자세한 내용은 여기에서 확인할 수 있습니다. GitHub 이야기를 하는 김에 말씀드리자면, GitHub Actions에서 조직 관리자가 신뢰할 수 없는 작업을 차단하고 워크플로 전반에 걸쳐 보안 강화를 적용할 수 있는 보안 제어 기능을 출시했습니다. 이는 매우 흔한 공격 경로가 되었던 공급망 취약점을 직접적으로 해결합니다. 이제 타사 작업을 검증하고 세부적인 보호 기능을 통해 CI/CD 파이프라인을 강화할 수 있습니다 . 실제 운영 환경에서 작업을 실행하는 경우 이러한 제어 기능은 절대적으로 필수적입니다. 자, 이제 수십 년 동안 존재해 온 것에 대해 이야기해 보겠습니다 . 리눅스 커널이 리누스 터볼의 첫 출시 이후 34주년을 맞았습니다 . 이 오픈 소스 프로젝트는 30년 이상 발전해 왔으며, 이제 스마트폰부터 우리가 매일 의존하는 전체 클라우드 인프라에 이르기까지 모든 것을 구동하고 있습니다. 리눅스 커널의 생일을 축하합니다. 자, 이제 여러분이 꼭 알아야 할 주요 사건들로 돌아가 보겠습니다.
