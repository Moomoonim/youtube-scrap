## 스크립트

AWS 콘솔 클릭을 실제 운영 환경에서 사용할 수 있는 코드로 변환할 수 있다면 얼마나 좋을까요? 안녕하세요, 저는 스튜어트입니다. AWS 콘솔 투 코드(Consult to Code)를 통해 이 모든 것이 어떻게 가능한지 보여드리겠습니다. 이제 AWS 콘솔 투 코드(Consult to Code)는 Amazon EC2, RDS, VPC를 지원합니다. 향상된 플랫폼은 프로토타입, 녹화, 코드 생성을 관리할 수 있는 간소화된 인터페이스를 제공합니다. 또한 EC2 인스턴스, 자동 스케일링 그룹, 고급 코드 생성 기능에 대한 미리 보기 기능도 제공하며, 이 모든 기능은 Amazon Q 머신 러닝 모듈( mods)을 기반으로 합니다. Amazon EC2 인스턴스를 시작하는 예시 시나리오부터 시작해 보겠습니다. 먼저 Amazon EC2 콘솔에 접속합니다. Amazon AWS 콘솔 오른쪽에 새로운 콘솔 투 코드(Consult to Code) 위젯이 보일 것입니다. ' 녹화 시작'을 클릭하고 작업을 수행합니다. 이 예시에서는 EC2 인스턴스를 시작할 것입니다. 그러면 새 EC2 인스턴스를 생성하는 단계가 기록됩니다. 새 EC2 인스턴스 시작이 성공적으로 완료된 것을 확인할 수 있습니다. 이제 '녹화 중지' 버튼을 클릭하면 녹화된 작업 목록을 볼 수 있습니다. 또한 녹화된 작업 목록에서 실행 중인 작업을 검토할 수도 있습니다. 드롭다운 목록에서 유형을 선택하여 적절한 작업을 필터링한 다음, 여기서는 '인스턴스 실행' 작업을 선택하고 ' CLI 복사'를 선택하여 해당 AWS CLI 명령을 복사합니다. 이것은 AWS 콘솔 코드에서 얻은 CLI 명령 출력입니다. 이 명령은 쉽게 수정할 수 있습니다. 예를 들어, 여러 인스턴스를 생성하도록 업데이트하거나, 다양한 인스턴스 유형을 생성하도록 수정할 수 있습니다. 이는 매우 단순화된 예이지만, 동일한 기술을 다른 워크플로에도 적용할 수 있습니다. 그렇다면 이것은 무엇을 의미할까요? 이제 이 코드를 재사용하고 CLI 내에서 다시 실행할 수 있다는 뜻입니다. 원클릭 CLI 코드 생성 환경은 작업이 실행될 때 사용한 API 명령을 기반으로 합니다. 이 예에서는 P2 인스턴스를 시작할 때 사용한 명령입니다. 콘솔에서 작업을 완료하면 보조 화면에 기록된 작업이 표시되고, 시작 및 중지 기능이 있는 대화형 UI 덕분에 프로토타이핑을 위한 작업 범위를 명확하게 설정할 수 있다는 점이 흥미롭습니다. 콘솔 코드 작성(CDK)은 기본적인 CLI 명령을 넘어 클라우드 인프라를 코드로 정의하는 오픈 소스 프레임워크이며, AWS 콘솔 코드를 사용하여 AWS 클라우드포메이션을 통해 프로비저닝할 수도 있습니다. AWS CDK 코드를 생성할 수 있습니다. 현재 Java, Python, TypeScript를 사용하여 인프라 워크플로우를 생성할 수 있습니다. EC2 인스턴스 시작 사례를 계속해서 살펴보겠습니다. Amazon EC2 콘솔에서 AWS 콘솔 투 클라우드 위젯을 찾습니다. 오른쪽에 있는 기록된 작업 테이블에서 "인스턴스 실행" 작업을 선택합니다. 여기서는 " CDK Python 생성"을 선택하겠습니다. 이렇게 하면 AWS CDK Python 코드가 생성됩니다. 드롭 다운 목록에서 "Python 생성" 버튼을 선택할 수 있습니다. 코드 생성은 Amazon Q 머신 러닝 모델을 기반으로 하며, 깔끔하고 바로 사용 가능한 프로덕션 환경용 템플릿을 생성합니다. 필요에 따라 코드를 사용자 지정할 수 있습니다. 코드를 복사하거나 다운로드할 수 있습니다. 그런 다음 이 코드를 Python CDK 프로젝트에 통합할 수 있습니다. 이제 기록된 작업 페이지로 돌아가서 기록을 재설정할 수 있습니다. 팝업 창이 나타나 기록된 작업을 재설정하고 지울 것인지 확인합니다. 콘솔 투 코드의 기록된 작업 테이블에는 특정 브라우저 탭 내 현재 세션에서 수행된 작업만 표시되므로 이전 세션이나 다른 세션의 작업은 저장되지 않습니다. 참고로 브라우저 탭을 새로 고침하면 기록된 모든 작업이 손실됩니다. 누구나 AWS Consult to Code를 사용하여 인프라 워크플로에 필요한 AWS CDK 명령 또는 CLI 명령을 생성할 수 있습니다. 하지만 생성된 모든 코드는 배포하기 전에 테스트하고 검증하는 것이 좋습니다. 이 영상이 도움이 되셨다면 좋아요를 누르고 개발자 YouTube 채널을 구독해주세요. 시청해주셔서 감사합니다.
